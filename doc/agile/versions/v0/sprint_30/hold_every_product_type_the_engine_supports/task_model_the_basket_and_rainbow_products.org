* Goal

The four basket and rainbow products have a data model, a projection reader and writer, and a builder, and a trade of each is held, exported as the element ORE reads, and imported back unchanged.

* Acceptance

- each of the four types names an instrument table, and the tables carry the constituents and the terms the products state
- the projection reads the element into rows and writes it back, value for value
- each type has a builder, and a term a builder is not given does not compile
- the catalogue routes all four, and a test asserts the routing
