#+title: How do I run the party_currencies commands from the shell?
#+description: Every command the party_currencies submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:party_currencies:

This file documents the party_currencies resource at the shell, one section per command. Every command is a subcommand of =party_currencies=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: D6C42391-5292-5A4B-9239-0FB239D396E5
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
party_currencies list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =refdata.v1.party_currencies.list=.

#+name: party_currencies-list
#+begin_src ores-shell :tangle party_currencies-list.ores :exports none
party_currencies list --limit 1
#+end_src

** =get=
:PROPERTIES:
:ID: A139022F-8EE4-5911-9807-880881380817
:END:

Reads the one row its key addresses. A key states every identifying column, so a partial key is refused rather than answered with an arbitrary row.


The command is shaped like this:

#+begin_example
party_currencies get <party_id> <currency_iso_code>
#+end_example

It is addressed at =refdata.v1.party_currencies.get=.

#+name: party_currencies-get
#+begin_src ores-shell :tangle party_currencies-get.ores :exports none

#+end_src

** =add=
:PROPERTIES:
:ID: 8954D297-5FF6-5602-BDB5-CFEEFDC59C37
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.


The command is shaped like this:

#+begin_example
party_currencies add <party_id> <currency_iso_code> <reason> <commentary>
#+end_example

It is addressed at =refdata.v1.party_currencies.put=.

#+name: party_currencies-add
#+begin_src ores-shell :tangle party_currencies-add.ores :exports none

#+end_src

** =set=
:PROPERTIES:
:ID: 086C3F6E-E902-5A50-A0FB-428CA10FEB11
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved. Passing --version makes the write conditional on the version the caller last read.


The command is shaped like this:

#+end_example

It is addressed at =refdata.v1.party_currencies.put=.
