* Result

The writes under another name are gone. =save=, =update= and =create= became
=put=, which the closed set defines as create or replace: ten subjects across
analytics, iam, refdata and reporting.

One pair needed a decision rather than a rule. =iam.v1.accounts.save= creates
an account and =iam.v1.accounts.update= partially updates one; both would have
landed on =iam.v1.accounts.put=, which is two declarations on one address. The
create-or-replace keeps =put= and the partial update became
=iam.v1.ops.update_account=.
