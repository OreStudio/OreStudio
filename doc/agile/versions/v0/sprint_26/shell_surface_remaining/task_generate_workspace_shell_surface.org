* Notes

The three operation messages resolve and set the acting workspace and its trade
scope. The service answers them from the caller's session rather than from a row,
which is the same reason the account menu's sign-in and sign-out are hand-written:
a unit that sends a request and prints the reply cannot express changing this
client's own context.

The =workspace= entity renders its unit, so the component does have a shell surface.
Nothing hand-written registers a workspace menu.
