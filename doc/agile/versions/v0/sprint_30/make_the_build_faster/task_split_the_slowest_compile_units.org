* Goal

No single compile unit takes more than 5 min on the CI runner, so a cold build is no longer held up by one file. Today ores.synthetic.core.tests unity_0 takes 24 min, ores.iam.core unity_1 10 min, ores.marketdata.api unity_12 7 min and ores.shell synthetic_commands.cpp 7 min.

* Acceptance

- -ftime-trace output for each slow unit names the cause.
- After the fix, no compile unit takes more than 5 min on the CI runner.

* Plan

1. Run -ftime-trace on the slowest units to find the cause.
2. The trace showed template instantiation of the =std::tuple= that
   =wire_fields()= returns for each type. Every use of a field list
   instantiated the full tuple machinery for the list size.
3. Replace the tuple with =ores::utility::codec::field_list=, a flat list
   that the codecs walk with a fold expression. Regenerate every
   generated header that builds a field list.
4. Measure each unit again on the CI runner after the merge. Split any unit
   that is still above 5 min.
