* Decisions

- The Boost port check resolves a header to the port that ships it, not to the
  directory it happens to sit in. Boost.ContainerHash ships
  boost/functional/hash.hpp, so the check no longer asks for boost-functional.
- The site build is paced by schedule rather than by push, because one build
  outlives the gap between pushes to main: consecutive pushes cancelled each
  other, and the cancellation left the deployed pages behind main.
