#+title: Bloomberg data format
#+description: The id scheme, the fields and the mapping we use for Bloomberg, and where Bloomberg documents them.

* Summary

Bloomberg identifies an instrument by a ticker and a yellow key, and a value by a field mnemonic. We store the ticker and the field exactly as Bloomberg writes them. The simulated Bloomberg source publishes the same names, so a live adapter replaces it with no change in the catalogue.

* Detail

** The id scheme

The scheme code is =bbg_ticker=. An id is the ticker, a space and a yellow key such as =Curncy=, =Index=, =Equity=, =Comdty= or =Corp=. A pricing source can sit between them: =EURUSD Curncy= and =EURUSD BGN Curncy= are two ids. The catalogue holds the id with its spaces. The yellow key tells the asset class, but the ticker part has no single grammar.

** The fields

A field is the mnemonic that Bloomberg gives a value. We use these:

| Field | Meaning | Where Bloomberg serves it |
|-------+---------+----------------------------|
| =PX_LAST= | The last or closing price | reference data (=//blp/refdata=) |
| =PX_BID=, =PX_ASK= | The bid and ask price | reference data (=//blp/refdata=) |
| =BID=, =ASK=, =LAST_PRICE= | The streaming bid, ask and last price | market data subscription (=//blp/mktdata=) |

One id carries many fields, so the field is part of the vendor instrument. The same ticker with two fields is two vendor instruments.

** On the wire

An adapter of this provider sends the tick fields below. See [[id:97208391-AE4B-4032-9744-8F8B228FD567][The adapter subjects]] for the subject.

| Tick field | Example |
|------------+---------|
| id scheme | =bbg_ticker= |
| external id | =EURUSD Curncy= |
| field | =PX_LAST= |
| value | =1.0842= (decimal text) |

The ingress subject token for the id is =EURUSD%20Curncy=. The service never decodes the token. It reads the id from the payload.

** The mapping

A vendor instrument maps to one oresmd item. =bbg_ticker= / =EURUSD Curncy= / =PX_LAST= maps to
=oresmd://fx/EUR?type=quote&instrument=fx_spot&quote=rate&ccy=USD=. The LSEG instrument ~EUR=~ maps to the same item, so the two providers quote one EUR/USD spot.

** Minted ids

Bloomberg publishes some points of a curve only as a chain, with no ticker of their own. For such a point we mint a ticker in Bloomberg's style, set =minted= and write the reason in the deviation note. A live adapter must turn a minted id into the real chain request.

** What the simulator does

The simulated Bloomberg source publishes ticks with =bbg_ticker=, the ticker and the field above. It does not speak =blpapi=. Nothing behind the adapter seam is simulated. See [[id:AC0C19EF-158C-4766-8661-A1DCECE3D424][Vendor adapters]].
