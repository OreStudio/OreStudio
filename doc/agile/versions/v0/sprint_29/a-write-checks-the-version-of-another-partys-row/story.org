* Goal

A write from a party that sees other parties is checked against its own row. Today the generated refdata service reads the current row of a write by its key alone. A session of a parent party sees its subsidiaries' rows too, and a convention id is held by every party, so the claimed version is checked against whichever party's row comes first. The person gets a false version conflict:
