* Result

- How do I run codegen? leads with ./compass.sh diff and ./compass.sh generate;
  the Python entry points stay for scaffolding and single-address runs, and the
  whole-component section points at compass-ng.
- The eight per-layer regeneration recipes, Regenerate all layers and Add a new
  codegen entity model name ./compass.sh generate instead of codegen
  regenerate; the revert-the-other-entities steps are gone, because compass-ng
  writes only what changed.
- The two memories that forbade tree-wide runs (generate one entity at a time;
  regenerate only the drift-free components) now state that compass-ng
  generate is the tree-wide run on a drift-free tree, and keep their rule for
  the Python codegen.
- The CMake source-list recipe and the compass-codegen-sync-cmake-sources skill
  lead with ./compass.sh generate; regenerate_cmake_component_files.py stays as
  the fallback without compass-ng. component_files and er_diagram are
  confirmed: each caught its planted drift, and each writes its outputs byte
  for byte as its script does.
