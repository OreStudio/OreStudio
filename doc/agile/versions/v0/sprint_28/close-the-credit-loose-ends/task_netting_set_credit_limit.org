* Goal

Where one netting agreement covers trades under several credit limits,
netting is restricted to the trades within one limit, so the limit is part
of what identifies a netting set. The =netting_set= entity has no limit
column, because no credit limit entity exists to reference. Model the
credit limit, then add it to the netting set and to the pin that holds a
set to its agreement.
