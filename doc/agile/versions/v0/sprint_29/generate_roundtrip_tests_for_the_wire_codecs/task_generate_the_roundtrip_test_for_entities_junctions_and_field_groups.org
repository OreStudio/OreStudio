* Notes

- *A roundtrip alone cannot see a dropped member.* The sampler fills only the
  members =wire_fields= names. With =owner= deleted from the catalog codec's
  list, the sample left =owner= at its default, the codec read the default
  back, and all 104 dq cases passed. Each generated test now asserts
  =names_every_member<T>(wire_left_out)= at compile time. Codegen counts the
  members the model marks =:no_wire:=. With the same deletion the build fails:
  "catalog has a member its wire shape does not name". For
  =iam.account_credential=, which has three =:no_wire:= columns, the count is 3.
- *A roundtrip cannot see a renamed member either.* The codec writes and reads
  under the same name, so a consistent rename roundtrips. Only a comparison
  with fixed bytes catches it. The proof task records this.
- *No pilot is possible.* =is_enabled= takes the most specific override, and a
  model's =ores.cpp.wire-codec.enabled: true= decides for every archetype under
  the facet. An archetype default cannot hold the test to one component, and a
  per-model opt-out on about 540 models is throwaway state. So this task
  generated every opted-in component, and the rollout task has nothing left
  for entities, junctions and field groups.
- *What the full build found.* Three gaps, each fixed here:
  - =scheduler::domain::cron_expression= states its own =text_form= outside
    =ores.utility=. A =text_form= may now state =sample_texts=, and the
    sampler reads them through =from_text=. The cron samples are
    ="30 6 1 * *"= and ="*/5 * * * 1-5"=.
  - The #4394 review fix refused =unsigned char=, which is =std::uint8_t=, and
    =assets::domain::image= holds a =std::vector<std::uint8_t>=. Only the plain
    character types are refused now.
  - A field group can hold entities, whose =wire_fields= are in their codec
    headers. The field-group test now includes them, computed by the same
    helper the entity test uses.
- No generated case found a codec defect. The proof task must still show that a
  runtime case can fail.
