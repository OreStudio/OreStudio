* Result

=ores_trading_structure_version_fn= returns a structure's internal version by
folding its legs rather than storing a counter beside them. A leg's version
moves when any of its components is written, because the component tables now
bump the trade's version, and the membership carries its own version, so
linking or unlinking a leg moves the deal too.

The external version stays on the agreement, which the authorisation and
agreement work owns.

This needed =:parent_entity: trade= and =:bump_parent_version: true= on the
seven children of the trade. Without it a component write did not move the
trade's version, so the fold would have missed exactly the case the acceptance
names. =trade_link= is left alone: it holds no facts, so its writes are not a
change to a trade's terms.
