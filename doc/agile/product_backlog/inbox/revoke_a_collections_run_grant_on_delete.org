#+description: Revoke a collection's run grant when the collection is deleted. A collection's run grant (feeds_run_as_their_owning_tenant, doc/knowledge/architecture/feed_execution_identity.org) stays standing after its collection is deleted, until a person with iam::run_grants:revoke ends it. The delete of a market data generation config should revoke the grant it holds, as reporting revokes a report definition's grant on unschedule or delete.
