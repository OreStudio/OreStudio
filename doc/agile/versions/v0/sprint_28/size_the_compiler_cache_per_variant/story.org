* Goal

The Linux builds keep a compiler cache that is as big as the build, inside the
10 GB repository allowance. The gcc debug build, which never finishes, stops.

* Decisions

- A cache smaller than its build is worth almost nothing, so a variant gets
  the whole of its need or no cache. The budgets, in MB, are clang debug 4000,
  clang release 1600, gcc release 1800 and 1600 free.
- The gcc debug build stops until the debug build gets smaller. Then it can
  have a cache again.
