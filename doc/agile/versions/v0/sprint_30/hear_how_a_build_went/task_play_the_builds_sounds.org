* Goal

=compass build= tells a person who is not watching it that it started, and how
it ended, by playing the desktop's own sounds. Green and red are different
sounds, so the outcome is heard and not read.

* Acceptance

- =compass build= plays =dialog-information= when it starts.
- It plays =complete= when the build succeeds and =dialog-error= when it fails
  or is interrupted.
- The player is spawned detached, so no build waits on a sound.
- A machine with no player, no theme file, or =ORES_BUILD_SOUND=0= builds in
  silence.

* Plan

- Name the three sounds once, as file names in the freedesktop theme, and map a
  finished build's outcome onto green or red.
- Choose the player from the ones a machine may have: =pw-play=, =paplay=,
  =canberra-gtk-play=, =ffplay=. =aplay= is left out because the theme is Ogg
  Vorbis and aplay plays raw WAV.
- Spawn the player detached with every stream dropped, so neither a missing
  player nor a slow one reaches the build.
- Let =ORES_BUILD_SOUND=0= in the environment or in =.env= turn them off, since
  a build on a headless machine has nobody to tell.

* Notes

- The sounds are the theme's, so nothing is added to the repository and the
  vocabulary is one the desktop already taught its owner. A build on a machine
  without the theme is silent rather than broken.
- The start sound plays once the build lock is held, so it means "the work is
  beginning" and not "this command was typed": a build that waits a long time
  for a slot stays silent until it starts.
- =--direct= builds are emacs script runs and play no sound: there is no
  compile to wait for.
- Verified by the suite and by playing the green sound by hand. The end-to-end
  proof is the next real build, heard from the shell that started it.

* Result

=compass build= plays =dialog-information= when it starts, =complete= when it
ends green and =dialog-error= when it ends red, chosen from the freedesktop
theme and played through the first of =pw-play=, =paplay=,
=canberra-gtk-play=, =ffplay= the machine has. Each is spawned detached with
every stream dropped, so no build waits on a sound, and =ORES_BUILD_SOUND=0= in
the environment or in =.env= silences them. The start sound plays once the build
lock is held, and =--direct= builds stay silent.

Fourteen cases in =test_build_sound.py= cover the choice, the theme file, the
player order, the opt-out from both places, and the detached spawn, including a
player that refuses to start. The whole compass suite passes (548 passed, 2
skipped), and the three sounds were played in build order through
=compass build_sound_command= and signed off by ear.
