* Result

Shipped:

- =start_market_feeds= needs =provision_party= as well as =publish_bundle=,
  so it binds every party the LEI import creates. A fresh =acme_demo=
  provision bound all five Acme parties to the 55 Bloomberg sources; before,
  only the system party was bound.
- The verification found a second bug, on main since =80dcac6037=: the feed
  ingest loop subscribed to an already-prefixed wildcard that =subscribe()=
  prefixed again, so no synthetic tick was stored in any environment. The
  loop subscribes to the relative wildcard, and a test that publishes a tick
  on the bus fails on the old subscription and passes on the fix.

After both fixes every Acme party stores Bloomberg FX ticks and IR curve
ticks.
