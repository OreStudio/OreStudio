Seeds the system tenant's own DQ tables for the taxonomy: one badge
definition per class with its colour, severity and css class; the
=asset_class= code domain; and one mapping per class from the domain to its
badge. The generated script replaces the rows that used to sit inside
=dq_badge_system_populate.sql='s single =DO= block, so the badge metadata has
one author.

The browser mirrors are the sibling =dq_artefact_populate= archetype, which
carries the same rows into the staging tables a tenant is published from.

variables and their semantics.
