#+created: 2026-09-27
#+updated: 2026-09-27

The template list the shell's =reports templates= menu asks for: the report
definitions a dataset bundle offers, in the order they should be presented.

It is an operation rather than an entity verb. A row is a projection over
=report_definition= scoped by a bundle, which the generated =report_definitions=
protocol cannot express: it pages the artefact table and knows nothing of the
=dataset= join or the =dataset_bundle_member= junction that decides membership,
and it has no display-order ordering. So the query stays hand-written beside
this model, and the model owns only the wire types.
