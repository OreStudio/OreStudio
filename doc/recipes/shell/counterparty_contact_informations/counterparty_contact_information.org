#+title: How do I run the counterparty_contact_informations commands from the shell?
#+description: Every command the counterparty_contact_informations submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:counterparty_contact_informations:

This file documents the counterparty_contact_informations resource at the shell, one section per command. Every command is a subcommand of =counterparty_contact_informations=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: 7E94EFBD-E969-5A72-81C4-F545731A36D6
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
counterparty_contact_informations list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =refdata.v1.counterparty_contact_informations.list=.

#+name: counterparty_contact_informations-list
#+begin_src ores-shell :tangle counterparty_contact_informations-list.ores :exports none
counterparty_contact_informations list --limit 1
#+end_src

** =add=
:PROPERTIES:
:ID: 636B5119-8CE7-5B20-8899-17B25E0E7DA8
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.

** =set=
:PROPERTIES:
:ID: 3C6F046C-CB75-588A-9717-47CF25DF3D33
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses.
