* Goal

Implement the classification tool against the settled dimension list and
run it end-to-end on =ores.refdata= only — the pilot component, chosen for
its size and variety. Deliberately try to break it: run it against entities
we already know the answer for (=currency= as the fully-regular reference
specimen; the 16 primary-key-heading legacy models as known-drifted) and
confirm the tool's output matches reality before trusting it on anything
else. Any dimension the tool gets wrong or can't compute here must be fixed
before rollout, not carried forward.

- The tool runs over every =ores.refdata= entity model and generated artefact
  and outputs a value for every settled dimension, no manual steps required.
- =currency= classifies as fully regular on every dimension the tool checks.
- All 16 known primary-key-heading entities are correctly flagged as legacy
  on the model-format dimension.
- At least a handful of other refdata entities are hand-verified line-by-line
  against the tool's output (pick a mix of domain and auxiliary types) with
  no discrepancies before the pilot is declared trusted.
- A refdata-scoped drift report is produced and reviewed.
