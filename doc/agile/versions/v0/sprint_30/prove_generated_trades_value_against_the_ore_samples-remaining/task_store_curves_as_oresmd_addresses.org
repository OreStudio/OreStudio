* Acceptance

- The exporter names every curve column through =ore_projection=, so a trade may hold an address in any of them.
- The bond insert trigger checks only a value that is an address, so an imported bond can hold its ORE curve name.
- The corpus roundtrip still loses nothing.
- An imported curve name becomes an address only in the market data task, when the series catalogue or market configuration can resolve it. An ORE curve name states no currency, instrument or quote, so an address cannot be built from it.

* Result

The exporter names every curve column of a bond and a credit trade through =ore_projection=, so a trade may hold an address in any of them. The bond insert trigger now checks only a value that is an address, so an imported bond can hold its ORE curve name. Tested in a rolled-back transaction on the database.

This task does not make imported curves into addresses. An ORE curve name states no currency, instrument or quote, so that step needs the series catalogue or a market configuration. It moved to the market data task.
