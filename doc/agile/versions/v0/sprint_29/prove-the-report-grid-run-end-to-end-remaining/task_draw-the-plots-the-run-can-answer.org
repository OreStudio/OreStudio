* Result

The results screen draws the two plots this run can answer.

Each book's share of the run draws as a donut, with every book's figure and its
share in the legend beside it, and a caption saying why that form. One book is
not plotted, because a whole with one part is not a shape.

The run's problems by scope draw as a donut whenever the run recorded any, and it
draws even when the run produced no rows, because the problems belong to the run
rather than to its result. On the failed run =e5e44605= the ring shows eighteen
problems: Report 1, Curve 7, Analytics 2 and Trade 8, each with its share.

The plots the prototype draws from the sensitivity analytic, Delta and Gamma
grouped and scattered, are not here: an NPV report runs no such analytic. They
belong to the report that does.
