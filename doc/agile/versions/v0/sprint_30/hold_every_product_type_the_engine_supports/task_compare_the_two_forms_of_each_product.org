* Goal

Each product ORE carries in both forms is booked as a twin pair on the same
terms, ORE values both, and a test compares the two values, so a difference
between the native and the scripted implementation is seen and explained.

* Acceptance

- the generator books, for each product with both forms, a native trade and a
  generic ScriptedTrade that state the same economic terms, linked as twins
- an ORE run values both trades of each pair
- a test compares each pair's values within a stated tolerance; a pair that
  differs is on a known list, asserted exactly, with the reason it differs
- a page or report shows each pair's two values and their difference
