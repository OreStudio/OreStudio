* Goal

Every commit on a branch, and its pull request, names the story, task and environment it belongs to, and compass-ng's commit_provenance check enforces it with no exemption, so blame can name who to tell when main breaks.

* Notes

- compass-85's draft exempted the record commits from =Environment=, because
  =compass_pr.py= wrote only the story and task. The product owner wants every
  commit to carry all three, so =_record_message= now adds the environment
  =pr create= already resolves (the task's =#+environment:=, then
  =ORES_ENV_NAME=), and the exemption is gone.
- The recipe already asked for =Environment:= on every commit; most sessions'
  commits carried it, and solid_dirac's commits in this sprint did not.
