* Plan

The history request states no subject of its own: the component that owns
an entity type answers on its own history subject, which
=history_subject_for= derives from the type. The forwarding step gains
=forward_on=, which takes the subject, and =forward= sends on the request's own
subject through it, so one implementation serves both.

The route lives in =ores.http.core=, beside the other cross-cutting routes. It
serves the 86 entity types the BFF served, held in one sorted table checked at
compile time: the classification lists, the versioned reference data records,
the synthetic resources and the records each history tab reads by name. An
unknown type is a 404 and a missing key a 400, as in the BFF.
