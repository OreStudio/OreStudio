* Result

The specification now states the list contract in full:

- *Order.* A column declares =:sortable: true= and the entity
  =:default_order:=. An empty field is the default order, a sortable field is
  honoured, and any other field is =invalid= with =order_not_supported=. The
  key, ascending, is the last tie-break.
- *Filter.* Equals members for the list filter column and relation columns;
  =<column>_one_of= members for the primary key and relation columns, at most
  1000 values, an empty list matching nothing, a longer list =invalid= with
  =filter_too_large=; a =search= member over =:searchable:= columns, a
  case-insensitive literal substring match.
- *HTTP.* =order=, =descending=, =<column>=, repeated =<column>_one_of= and
  =search= query parameters.
