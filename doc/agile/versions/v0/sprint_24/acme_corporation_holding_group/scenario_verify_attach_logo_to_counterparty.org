This scenario verifies [[id:21C9CA52-3515-4D99-9B95-1F5BA8A05DCD][Attach a logo/image to a counterparty]]: a counterparty
can now carry a logo via a nullable =image_id= soft-FK, edited through a
new logo picker on =CounterpartyDetailDialog= (Menu: Reference Data >
Counterparties). Runs against the *Acme Corporation* tenant (replacing
Barclays Plc as the system's reference/demo entity -- see
[[id:CB7351E9-8E7E-4BA4-9399-4EB22F6192D4][Commission Acme Corporation: a realistic holding-group test entity]]). Acme
Corporation is a party, not a counterparty -- it trades with real GLEIF
counterparties -- so provisioning instead attaches a demo logo to one
of those real, already-imported counterparties: =BARCLAYS PLC=
(short code =BRCLYS=), sourced from Wikimedia Commons ([[https://commons.wikimedia.org/wiki/File:Barclays-Logo.svg][File:Barclays-Logo.svg]],
CC0) -- so the first thing a tester sees is a *working example* with
no manual upload needed. The scenario then covers the full CRUD +
history + eventing sweep for the field on a second, freshly-created
counterparty -- create, read-back, update, delete, history, and a NATS
notification refreshing a second client. It then repeats a shorter
create/read-back/update round trip on =PartyDetailDialog=, whose logo
picker was added as a follow-on so the field is testable on both
dialogs. Pass means every step below completes with the stated
outcome and no unexpected error dialog appears.

*** Create a counterparty and set its logo

- Click Add to open a new =CounterpartyDetailDialog= in create mode.
- Fill in a short code (e.g. =ACMETEST=), full name (e.g. =Acme Test
  Counterparty=), party type, status, and business center; select any
  parent counterparty.
- In the *Logo* group box, click the flag/logo button and pick any
  image from the selector (the pre-populated Barclays logo, if
  offered, or any other available image).
- Confirm the button now shows the chosen icon and a "Logo changed
  (unsaved)" style before saving.
- Click Save, supply a change reason, and confirm the success
  notification appears and the row shows in the list.
