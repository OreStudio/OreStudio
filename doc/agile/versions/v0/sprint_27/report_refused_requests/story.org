* Goal

Make every client report a refusal as a refusal, naming the reason the server gave, so a permission problem is never mistaken for a malformed payload.

* Acceptance

- A request refused with X-Error: forbidden prints a message naming the refusal and the subject, and never mentions unpacking or decoding
- X-Error: unauthorized and bad_request are surfaced the same way, each with its own literal message
- X-Error: token_expired keeps its current re-authentication behaviour
- Tests pin each header value against a literal expected message

* Result

A refusal now reaches the caller as a refusal. The check lives in the NATS
decode helpers, so a caller that reads the =X-Error= header itself keeps
the reply it inspects, and only a caller that would decode the empty body
is stopped.
