The coded catalogue of convention kinds, one row per convention an ORE
conventions document can carry. A central =convention= row names its kind with
this code, and the kind selects the family whose parts the row carries.

The rows are ORE's own convention category names, upper-cased: the kind of
=tenor_basis_swap_convention= is =TENOR_BASIS_SWAP=. A kind that is modelled
beside this table in =ores.refdata= owns a family of parts; this table is the
closed set that says which kinds the central row may be.

Batch-loaded reference data, refreshed from ORE's =ore_types.xsd= alongside the
other coded refdata lookups.

** asset_class

:cpp_type: std::string

:END:

The asset class of the product model the kind serves: =interest-rates=, =fx=,
=inflation=, =credit=, =commodity= or =bond=. A screen groups the kinds by it, so
the grouping is data and not a table in the screen.

** ore_element
:PROPERTIES:
:type:     text
:cpp_type: std::optional<std::string>
:nullable: true
:END:

The element that writes the kind in ORE's conventions document, such as =Swap= or
=TenorBasisSwap=. Empty for a kind ORE Studio keeps that the document does not
carry, such as =TENOR=. With the terms of
=convention_kind_term=, it ties the kind to the ORE parameter contract.

#+begin_src cpp :name generator

#+end_src
