* Acceptance

- Simulation, sensitivity, SIMM calibration, historical return and Basel
  traffic light round trip end to end: entities, both mappers, and a round
  trip over every corpus file of the kind, or a fixture built from the
  schema where the corpus holds none.
- A report kind is a classification: the definition carries its kind by
  foreign key, and the kind selects the registered workflow and the
  parameter block a run of that kind reads.
- A run's engine input is packaged through the owning services' operations,
  whose handlers are code generated, and the store that wrote other
  components' tables is removed; the input travels through object storage
  rather than one inline message.
- An import writes a run's configuration in one transaction, and an export
  reproduces a run's configuration as of when the run started.
- The hand-written tables the census found carry entity models where a
  codegen shape covers them, and each component's SQL aggregate lists its
  generated entity files rather than holding them by hand.
- The values the entities flatten — the stress shift extras and the FX
  conventions' ORE ids — are held as typed rows and columns.
