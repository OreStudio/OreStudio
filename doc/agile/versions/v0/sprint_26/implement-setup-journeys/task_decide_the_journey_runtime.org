* Goal

The contract every journey is built to, written down once and
implemented once, so that the second journey is a list of steps and
nothing else.

Three questions have to be answered before the first journey can be
built, and none of them is answered today. What is a step definition:
which fields it carries, and which of those the server sees. How does
one page render the rail when the rail and the steps must not be able to
disagree. And how does a step reach a server subject, given that the
browser cannot name one.

The answers are signed off in
[[id:FC08DD66-DB25-4B4F-8A26-572A513393FF][the architecture audit]] and
recorded in the story's =* Decisions=: one hand-written BFF route per
step, the BFF as the browser's only HTTP surface, and only the
server-side workflow resumable. This task turns them into a page and
into code.

* Acceptance

- A knowledge page under =doc/knowledge/architecture/= defines a step
  definition, the rail, the rule for a step that cannot be returned
  past, the step-call contract, and what a step may not do. It obeys
  [[id:9AB395D6-0265-4DEB-BA95-04D24C8444AF][the knowledge document contract]].
- The rail is derived from the step list and nothing else, so the rail
  and the steps cannot disagree. A test proves it by building the rail
  from a list and asserting the two agree.
- A journey can inline another journey's steps, and the positions are
  found by name rather than by arithmetic, so adding a step to one
  journey cannot silently change another.
- The step-call contract is stated as a rule a route can be checked
  against, not as a description of the routes that happen to exist.
- [[id:3361CF92-89B0-481E-9E51-ACE2FEEF2FAA][Journey execution]] names the step and
  the human step, and its exists-or-missing table says what is actually
  there. The progress reads exist and are subscribed; the progress event's
  subject follows the BFF's convention while its payload does not match
  what the browser decodes; and retry does not exist at all.
- [[id:DD0C6CEB-A285-40F5-8A97-B39DA6953B20][The component specification]] links
  the page.
- =npm run typecheck= and =npm test= pass.

* Plan

1. *Write the contract page.* =doc/knowledge/architecture/journey_runtime.org=.
   It owns the client half of a journey: the step definition, the rail
   and the back rule, the step-call contract, the bootstrap gate, and
   what a step must not do. It links
   [[id:3361CF92-89B0-481E-9E51-ACE2FEEF2FAA][Journey execution]] for the server
   half rather than restating it.
2. *Land the rail model.* =packages/web/src/journeys/runtime.ts=. The
   step type is generic over its body, so the model carries no React
   dependency and its tests need no DOM. The rail, the back rule, the
   next position and the named lookup are pure functions.
3. *Test the model.* =packages/web/src/journeys/runtime.test.ts=. The
   cases that matter are the ones a second journey would break: the
   rail equals the step list in length and order, a final step blocks
   the return, an inlined journey's positions are found by name, and an
   unknown step id fails loudly rather than producing =undefined=.
4. *Add the vocabulary to [[id:3361CF92-89B0-481E-9E51-ACE2FEEF2FAA][Journey
   execution]]*: the step, the human step, and who owns a step's
   declared inputs.
5. *Correct that document's exists-or-missing table* against the code.
6. *Link the page* from
   [[id:DD0C6CEB-A285-40F5-8A97-B39DA6953B20][The component specification]].

The React component that renders a rail is /not/ here. It needs the
shared primitives, which the next task restores, and a contract that is
only provable through a rendered page would be a contract nobody can
read. The seam is the step type: this task owns it, the next renders it.

how the test-file typecheck gap was found, and it is filed as
[[id:A99BD090-BC0E-4736-8E2D-10F98F16F55B][a capture]] because the fix is

The rail model carries no rendering dependency, so its tests need no DOM
and no test environment. That is deliberate: the ordering rules are the
part that must be right, and requiring a renderer to check them would
have made them the part nobody checks.
