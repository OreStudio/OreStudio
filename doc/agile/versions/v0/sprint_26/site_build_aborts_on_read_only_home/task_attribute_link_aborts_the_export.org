* Acceptance

- Neither page writes the attribute in Markdown backticks.
- The site export resolves every link and reaches =Build succeeded=.

* Plan

Write the attribute as org verbatim, which is the markup the surrounding prose
already uses for C++ tokens. Backticks carry no meaning in org, so the exporter
saw the double brackets inside them as a link target.

* Notes

=[[no_unique_address]]= inside Markdown backticks is not a link, but org does not
read backticks, so the exporter treated the brackets as one and aborted:

#+begin_src text
Build failed: Org export aborted.  Unable to resolve link: "no_unique_address"
#+end_src

The failure is not sandbox-specific. It would break the site build anywhere, and
it was the second abort in the same run, after the package install.
