#+brief: The read of a pair's FX forward ladder.
#+filetags: :model:operation:marketdata:
#+created: 2026-11-09
#+updated: 2026-11-09

The read behind the FX forward ladder screen. A forward is computed from one spot
and the published funding curve of each currency, and is not stored, so the reply
names those inputs beside the rows. A refusal is a reply with =success= false and
a message that names what is missing, because a reader needs to know which input
to go and fix.

#+begin_src cpp :name comment
/**
 * @brief Raises, or applies, the publish of one pair's forward set for the caller's party. A call that names no approved request computes the set from the party's spot and published funding curves, raises a marketdata.fx_forward_publish request and stores the set as its candidate. A call that names the approved request publishes that candidate, unchanged. A set whose spot or curve is missing is refused, naming the input, and nothing is written.
 */
#+end_src
