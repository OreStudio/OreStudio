* Goal

The first run shows the public sources' terms step to every administrator, even one who is already signed in. The step offers one choice to accept every source's terms, or to decide each source in turn. Each source is a short row that expands to its terms, so the step stays readable with any number of sources.

Testing the step from a fresh system found four more faults on the screens a
new system reaches next, and the task took them on: a browser kept the old
build after a rebuild, the calibration screen mixed a run's answers with the
feeds' earlier states and drew its measures more plainly than the prototype,
and a system administrator met an access error on the subscriptions screen.

* Acceptance

- A signed-in first run resumes at the public sources step, not at the starting point
- The step offers accept all or decide one by one; each source collapses to one row and expands to its terms
- Each source's terms are a short link, such as 'ECB terms', that does not overlap the text beside it
- Nothing is sent until Continue, and Continue sends only what changed
- A reload, or a reopened browser, runs the build the server holds
- The calibration screen shows the feeds and a run on separate tabs, filters the feeds by vendor, and draws a feed's measures as the prototype does
- A system administrator opens the subscriptions screen without an error

* Plan

- Resume a signed-in first run at the sources step: =startStep= returned the starting point, so creating the administrator skipped the step.
- Hold the step's choices as a draft. =sourceChanges= turns the way and the decisions into the requests, and the journey's =run= sends them on Continue.
- Send the entry point with =no-store= and the hashed assets as immutable, through =@fastify/static='s =setHeaders=.
- Split the calibration page with the shared =useTabs=; read the vendor from the source name; read the series' fixings for the measures' sparkline.
- Skip the parties read in a system session, by the page's session mode.
