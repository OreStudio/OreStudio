* Acceptance

- The fresh smoke path provisions the deployment's secrets between the recreate
  and the start of the fleet, and fails loudly when the provisioning does.
- A recreate says, where the operator reads it, that the secrets are not
  provisioned and which command runs them.
- A vault invocation that exits non-zero and writes nothing names the log it left
  the reason in, instead of looking like an invocation that did nothing.


* Plan

The recreate stopped writing service passwords, and nothing downstream was told.
Three places learn it, and none of them change the design: the fresh smoke runs
=compass vault provision= after the recreate and before the start; the recreate
prints the command to run next; and the provisioning run reports a vault
invocation that fails silently, naming its log.

* Result

- =compass smoke ticks --fresh= runs =compass vault provision= between the
  recreate and the start, and stops with a clear line when the run fails.
- =compass db recreate= prints the command the operator runs next, so the step is
  not inferred from a pooler or a service fault.
- A vault invocation that exits non-zero and writes nothing now names the log it
  left the reason in, with its last lines.
- Proved end to end: the fresh smoke ran stop → recreate → provision → start,
  brought the fleet up, provisioned =acme_corporation= and read 22,693 ticks with
  every adapter accepting and none rejecting. The run passed.
