* Decisions

- *Coverage runs on the debug builds of both tiers.* The Nightly Build already
  collects coverage and memcheck on its debug jobs, and Continuous now collects
  coverage on its debug job. The same configuration is therefore measured on
  both tiers, and CDash carries a coverage sample every three hours instead of
  once a day.
- *Memcheck stays on the Nightly Build.* Valgrind is the heaviest cost in the
  suite and it needs the extra dev packages. Coverage alone is the part that
  belongs on every debug build.
- *The first Continuous run after this change starts cold.* The coverage flags
  enter the compile line, so sccache hashes the objects differently and the
  stored clang-debug entry no longer matches.

* Out of scope

- The memcheck pass, which stays on the Nightly Build alone.
- The cron interval. The debug job now runs longer than the three-hour
  interval, so the next interval must be derived from a measured run of the
  covered build rather than from the pre-coverage figures.
