* Acceptance

- compass env deploy takes several hosts and deploys them at the same time.
- Nothing a deploy writes on this machine is shared with a deploy to another host.

* Plan

Deploys to Newton, the laptop and Simba, started at the same time, failed. Every deploy saved the one image to the same tar file on this machine, and podman refused the second save. Every deploy also wrote the compute settings of its host to one shared file, so a deploy could send a host the replica count of another.

- An image is copied with the standard =podman image scp IMAGE HOST::=. It writes no staging file. The old save, compress and scp steps are gone.
- The compute settings and the certificates of a host are staged under =build/docker-stage/hosts/<host>/=, so no host's files are another's.
- =compass env deploy= takes several hosts. Each host runs as a child process of an ordinary single-host deploy. The output of each line is prefixed with the host. A summary names the hosts that failed, and the exit code is non-zero if any did.
- The line that podman prints for every layer is left out of a many-host run.

* Result
