* Goal

Move the NATS half of the forwarding step into ores.nats as a typed call that returns the decoded response or a NATS-level refusal, and the HTTP half into a new ores.http.nats part with one forward function. The record units, the typed route units and the feed key routes use it, and their per-unit copies go. ores.http.api stays free of NATS.

* Plan

The forwarding step has two halves, and each goes to the layer that owns it.

The NATS half goes in =ores.nats=. A typed call sends a canonical request on
its subject, waits the default timeout and decodes the reply. It answers the
decoded response or one refusal from a closed set:

| Refusal | What the service or the transport said |
|---------+----------------------------------------|
| =forbidden= | the reply's =X-Error= header is =forbidden= |
| =bad_request= | the header is =bad_request= |
| =unauthenticated= | the header is =unauthorized=, =token_expired= or =max_session_exceeded= |
| =session_expired= | the client could not renew the session |
| =unanswered= | the transport failed, or the header names a code the call does not know |
| =undecodable= | the reply is not the response type |

The header's meaning is a pure function of its text, so it is tested without
a server.

The HTTP half goes in a new =ores.http.nats= part, which links
=ores.http.api= and =ores.nats=. One =forward= function delegates the
caller's token, makes the typed call and maps each refusal to an HTTP status
and code through one table. =ores.http.api= keeps no dependency on NATS, so
an HTTP client of the API does not pull NATS in.

The record units, the typed route units and the feed key routes call
=forward=, and their own copies go in the same change. The typed units then
answer a refusal with the ={code, message}= body the browser reads, which the
switch-over needs.

* Result

The gateway forwards through one step. =ores.nats= keeps the NATS half it
already had, and the new =ores.http.nats= part holds the HTTP half: =forward=
and =respond=, which delegate the caller's token and state each failure as an
HTTP refusal through one table. The record units, the typed and operation route
units and the feed key reads call it, and their own copies are gone. The typed
units now answer every error with the ={code, message}= body the browser reads.
=ores.http.api= keeps no dependency on NATS. All nine =ores.http= suites pass.
