#+title: Check that every generated registrar is wired
#+description: The calibration policy, provider order and fallback registrars were generated but never called from the synthetic registrar, so no service answered their subjects; a gate should fail when a generated register_*_handlers or history provider has no caller.

This page is a [[id:671F18E4-E09C-4B3B-BD24-D33DF8AE38A6][capture]] in the *inbox* bucket of the product backlog — a pre-sprint idea, not yet pulled into a sprint as a story.

* What

Add a check to =./compass.sh check= that lists every generated =register_*_handlers= and =register_*_history_provider= function in a component. The check fails when no registrar of the service calls the function.

* Why

The synthetic component held registrars for the calibration policy, the provider order and the fallback, but =registrar.cpp= never called them. No service answered =synthetic.v1.calibration_policies.list=, so the calibration screen timed out after 30 seconds. The unit tests and the build did not find this. The codegen checklist names the wiring check, but only as a manual step.
