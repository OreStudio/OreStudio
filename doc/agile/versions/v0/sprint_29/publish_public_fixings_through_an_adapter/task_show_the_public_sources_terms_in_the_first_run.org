* Goal

A system administrator who sets up a new installation reads the terms of each public source the system loads quotes from, and accepts or declines each one, before any of its quotes are fetched.

* Acceptance

- The first-run journey has a step between the administrator and ready that lists each public provider of the catalogue: its name, what it gives, its terms page as a link, the credit it asks for and whether it allows storage.
- The administrator accepts or declines each provider. An acceptance records the terms version, the principal who accepted and when; a declined provider is not fetched.
- A provider whose terms change has a new version, and the system administrator is asked again before the adapter fetches it.
- The terms can be read and changed later from the provider's own screen, not only in the first run.
- Acceptance is set only by the accept operation, on the server: it computes the digest, takes the accepting account from the authenticated session and the time from the server clock. A provider write ignores acceptance fields that a client sends. (Added on 2026-10-28 from the review of #3992.)
