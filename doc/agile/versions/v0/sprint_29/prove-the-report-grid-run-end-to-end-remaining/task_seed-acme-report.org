A recreate followed by one provision gives a triggerable report, and the run's
inputs reached storage.

- *After a database recreate* the ACME tenant carries the report type and 78
  report definitions. A session acting for =Acme Corporation Plc= triggered
  "Audit Trail Summary" (definition =831711f4-d9f1-4f39-b5da-246e202fbc7e=),
  and instance =25922e99-e541-44ca-ab22-c6b7ddbc558a= walked pending, running
  and completed.
- *The chain's inputs exist where it expects them.* The run left
  =reporting/runs/25922e99-e541-44ca-ab22-c6b7ddbc558a/= holding =trades.msgpack=,
  =market_data.txt= and =fixings.txt=, and built
  =ore/packages/25922e99-.../ore_package.tar.gz=. The engine read that package
  and logged =Built Portfolio. Initial size = 8, size now 8, built 0 failed
  trades=.
