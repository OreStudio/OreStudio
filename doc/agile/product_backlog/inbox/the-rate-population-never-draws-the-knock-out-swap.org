#+description: The rate population never draws the knock-out swap. The rate planner cycles nine routed types, but a config draws only as many slots as its trades_per_book and each seeded rate config states eight, so slot 0 to 7 selects the first eight types and index 8 is never reached. A provisioned tenant books 24 rate trades over eight types, three each, and holds no knock-out swap at all: its knock-out fact table is empty. Either the config states nine slots or more, or the type is drawn by name rather than by position, so a population of any length states every type it routes.
