* Result

The ORE XML binding and record readers parse reals with
=ores::platform::numeric::parse_double=. They no longer call the floating-point
=std::from_chars=, which libc++ on Apple deletes. Three call sites changed:
two in =binding.cpp= and one in =record.cpp=. The integer =from_chars= calls
stay. The =ores.ore.core.tests= suite passes on Linux. Only the macOS job proves
the compile fix.
