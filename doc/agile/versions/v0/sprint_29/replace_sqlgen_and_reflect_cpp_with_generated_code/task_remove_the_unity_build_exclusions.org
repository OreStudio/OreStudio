* Acceptance

- Identical helpers defined in several files of a directory have one shared definition.
- Different helpers that shared a name are named for what each does.
- File-local loggers live in the class they log for.
- build/scripts/check_unity_collisions.py passes with an empty exclusion list, and the unity build and every suite pass.

* Plan

1. Classify each group the collision scan finds: identical definitions to
   share, different definitions under one name to rename.
2. Rename with clang-refactor, so a rename follows the compiler and not the
   text: every file but the first of a group names its helper after itself.
   A call inside a template body that depends on a template argument is not
   resolved by clang-refactor, and a script finishes those.
3. Move each shared group into one header per target, in the files' common
   directory, inline and in the helper's own namespace.
4. Empty the exclusion record and build the whole tree with =-k 0=. Apply
   the compiler's fully qualified suggestions where a merged unit made a
   relative name such as =messaging::= resolve elsewhere, and rename every
   redefinition it reports in the file that redefines it.
5. Repeat until the tree builds, then prune each shared header to the
   includes it compiles without.

* Notes

** Where this departs from the acceptance

- Renamed helpers are named for the file that owns them, such as
  =fx_instrument_projection_to_ore_date=, not for what each does. A name per
  owner is exact and mechanical over about 250 helpers; naming each for what
  it does is a reading of each one, left for the code that the generated
  codecs and statements replace.
- File-local loggers are renamed per file, such as =tenant_lookups_lg=, not
  moved into the class they log for. Many log for free functions, which have
  no class.

** What text identity got wrong

Two copies with identical text are not always the same helper. A logger
=lg()= reads its own file's =logger_name=, and a helper in =ores.ore= calls
its own file's =to_domain_date=. Sharing those changed which logger or which
conversion a file used, so they were renamed instead. =ores.ore/core/src= is
renamed throughout for that reason.

* Result

Every hand-written source is back in the unity build and the exclusion
record is empty. Identical helpers live once in 22 shared headers; other
clashing helpers, types and namespace aliases are renamed for the file that
owns them; relative names a merged unit made ambiguous are fully qualified.
The collision scan no longer reads a qualified member definition or a
parameter line as a file-local name, and two new tests pin that.
