The bundle publish verb: one request that asks for a bundle to be published and
one reply that reports what was dispatched.

It is an operation rather than an entity verb -- it names no row a caller
addresses by key, and it returns a dispatch count rather than a record -- so it
is declared here instead of being derived from an entity. The handler that
serves it stays hand-written beside this model, because it drives the
bundle-publish workflow and reads the publishable datasets.
