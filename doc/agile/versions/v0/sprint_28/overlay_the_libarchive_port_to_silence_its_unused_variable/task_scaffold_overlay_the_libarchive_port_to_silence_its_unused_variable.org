* Notes

The unused-variable check is unconditional. =vcpkg_cmake_configure= runs it
whenever a port manually specifies a variable that the project never read, and
only the per-call =MAYBE_UNUSED_VARIABLES= argument suppresses it. No
environment variable or toolchain setting turns it off globally, so the
portfile is the only place the fix can live.
