* Acceptance

- =result_metric= is a hypertable on the observation date, holding the run, the party, the family, the subject, the measure, the currency, the qualifiers, the value and the source of each figure.
- =result_cashflow= holds the child-row families with their typed keys, and no figure of theirs is flattened into a metric.
- A view serves the run, level and compare reads the screens make today, so no screen learns a family and the rollups are written once.
- The post-processor downloads the run's archive, calls the readers for the families the run wrote, and writes one bulk insert for each family.
- Nothing in reporting parses an ORE file, and =reporting.core= links =ores.ore.core= with the edge recorded in the core-link baseline.
- The node stops marshalling =npv.csv= into canonical rows.

* Plan

The metric table takes the families the metric reader serves, with the family
code as a column rather than a table of its own: sixty tables would be forty
identical shapes and a UNION for every cross-family read. The qualifiers the
corpus uses most — currency, scenario, factor, shift and the par flag — are
typed columns so they are indexed; the rest travel in one JSON object beside
them. The view over the metric table keeps the columns =report_result_row=
serves today, so the screen code does not change with the storage.

The post-processor reads the archive the node already uploads, runs the reader
for each family the run wrote, and writes each family in one insert. The node's
projection of =npv.csv= is deleted.

Every number this task claims about a tree, with the command that produced it
and the commit it was measured at. A number without both is not a measurement,
because a clean-up record describes a tree and trunk moves under a branch: a
consumer count, a gate's component count and a suite's size all change with no
code changing, and the reader of a bare number cannot tell which tree it came
from. Where the raw output matters, put it in an =evidence/= file beside the
task and name that file in the Command column.
