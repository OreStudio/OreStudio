* Goal

Every log line written while a request is handled names its correlation id, so
the lines of one request can be found together.

* Acceptance

- =log_handler_entry= opens a scoped Boost.Log attribute =correlation_id= for the
  handling, and the attribute is removed when the handling ends.
- The console, file and telemetry sinks print or export the attribute.
- An incoming id that is not 32 hex digits or a uuid is replaced; the log names
  the replacement, not the rejected value.
- A test writes two log lines inside one scope and finds the id on both.
