* Acceptance

- Configure labels every test with its component, the test name without
  its =.tests= or =.typecheck= suffix, and writes the components to
  =cdash_subprojects.txt= in the build directory.
- CTest.cmake reads that file into =CTEST_LABELS_FOR_SUBPROJECTS= after
  configure, and submits a =Project.xml= that declares each component as a
  CDash subproject.
- The case entries =expand_catch2_cases.py= makes keep the suite's
  labels, so each case joins its component's subproject.
- No test's =CMakeLists.txt= changes.

* Plan

Follow compass PR #88, with one difference. compass labels each test in its
registration helper. ORE has no shared helper: 104 test =CMakeLists.txt=
files each call =add_test=. So =projects/CMakeLists.txt= walks its
directories after the last =add_subdirectory=, and labels every test it
finds.
