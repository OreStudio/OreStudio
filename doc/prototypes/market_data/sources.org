* What it argues

Setting up where data comes from is not reading it. This screen holds the rows
that say where the values come from; Public rates holds the values.

The screen uses the words of the code, and these are the only words it uses.

#+ATTR_HTML: :class hug-leading
| Word | Meaning | Example |
|------+---------+---------|
| /Provider/ | Whoever owns the ids, the terms and the licence. A central bank, a treasury, or a data vendor. | =ecb= is a reference publisher; =bloomberg= is a data vendor |
| /Source/ | One adapter instance of a provider. It has a name, a kind and a default flag. A provider may have several. | =ecb-frankfurter= (live), =bloomberg-b= (test), =lseg-simulated= (simulated) |
| /Adapter/ | The runtime that meets the service at four messages. Its identity is the source name. | The process =ores.marketdata.official= hosting =ecb-frankfurter=; the simulator hosting =lseg-simulated= |
| /Adapter id/ | The name an adapter announces, serves and heartbeats under. It equals its source's name. | =ecb-frankfurter= |
| /Kind/ | How a source gets its values. The kind is data a person reads and no code branches on it. | =live=, =replay=, =test=, =simulated=, =derived= |
| /Route/ | A party's choice of one source for one provider. | System Party routes =ecb-frankfurter= for provider =ecb= |
| /Vendor instrument/ | An id scheme, an id and a field, in the vendor's own notation. | =iso4217= / =USD= / =rate=; or Bloomberg =EURUSD Curncy= / =PX_LAST= |
| /Item/ | The internal identity a vendor instrument maps to. | =FX-ECB-EUR-USD=, =IR-ECB-ESTR= |
| /Subscription/ | A party's entitlement to a provider. | System Party subscribes to provider =ecb= |

A test environment is a source of kind =test=. A data vendor is a provider of
kind =data_vendor=. The endpoint, the path, the poll interval and the backfill
window belong to the source; the credential reference belongs to the provider.

* What the screens must say

- A source belongs to one provider, and the provider owns the terms and the
  credential reference. The credential is not a column on the source.
- A provider may have several sources. One is the default and a new
  subscription routes to it. A party routes exactly one source for each
  provider.
- The transport a source runs with, its endpoint, path, poll interval and
  backfill window, is a command-line flag today. The prototype marks it *not
  persisted yet*, and the story moves it onto the record.
- The ECB has two sources: =ecb-frankfurter= serves FX, =ecb-ecb-data= serves
  IR. A party routes one, so the two classes cannot both reach it. The IR story
  settles whether a source serves every asset class or the route rule changes.
  The prototype draws this in the Routes tab rather than hiding it.

* What is fake

Every endpoint, kind, count, date and credential is invented. Secrets are masks
only; nothing is set or rotated. No request leaves the page.

* Verdict

The screen is the setup of market data, and Public rates is the reading of it.
A person who reads a rate follows a source's name here to see where it came from.
