* Result

*The descriptor table is current, and the wider drift is not stale output.*

The table was missing eight entries, a list and a versions-list for each of
the four instrument tables that landed without their row-level security and
their permissions. It is the same omission seen from the web side: the
tables reached the schema and the C++ and nothing in the browser knew they
were listable. =regenerate_list_request_descriptors.py= wrote them beside
the other instruments, and the check now reads 1284 requests and finds every
one agreeing with the C++ protocol.

*The component generator is not safe to run.* The check says 26 files differ
from their models and suggests regenerating. I ran it into a scratch tree and
read what it would write. It removes:
- =pugixml::pugixml= from the =ores.ore/core/tests= link, though
  =domain_script_library_projection_tests.cpp= includes =<pugixml.hpp>= and
  is built by that target, so the build breaks;
- the = 0= on =stale_seconds_ir= and =stale_seconds_fx=, leaving two
  members of a hand-written configuration struct with no value until the
  parser fills them;
- a party-scoped =market_fixing_repository::read_latest_for_series= that
  takes a tenant, a party and a set of series.

None of those is generated output that drifted. They are work added to
files the generator also owns, and the model does not describe them. Running
the generator would delete the work and pass the check. So the drift is a
model gap, one member at a time, and it needs the models changed rather than
the generator run.

*Gate.* =compass check --exclude-heavy= ran 11 checks and passed 10, and
=check_bff_list_requests.py= is one of them. The eleventh, =web=, hit its own
900 second limit: it opens with =npm ci=, a full reinstall, before it reaches
a single test. Run one at a time on the tree the check leaves behind, the
three things it stands for all pass:

- =prettier --check= on the regenerated table: all files use Prettier style.
- =npm run typecheck= across the workspaces: no error.
- The tests that read the table: =@ores/wire-protocol= 225 passed,
  =@ores/bff= 1301 passed.

*What is still red.* =component-drift= for the reason above, and
=money-decimal-columns= and =codegen-tests=, each of which needs a decision
about which side is right rather than a rerun.
