* Plan

Branch =feature/serve-the-moved-reference-data-reads=.

This task corrects the design note in one place. The note says the value set
reader lives in the reporting part, because the engine settings and pricing
engine routes read it too. These five routes are reference data area routes and
the reference data part already answers other convention routes, so a reader in
the reporting part would make the reference data part depend on reporting, which
already depends on =ores.refdata.api=. The reader therefore lives in
=ores.http.core=, and this task links it from the reference data part.

The five routes can be taken as soon as the first task has merged; they do not
wait on the engine settings or the pricing engines.

If the convention document routes prove as large as the machinery they need, this
task splits into one task for the convention documents and one for the curve
configurations.
