* Goal

Write a set of at least twenty real questions a person would ask, each with the pages that should answer it. Run them against the search and record how many find a right page in the first five, and which miss. The result decides whether the search needs more: better weights, near spellings with pg_trgm, or embeddings.

* Acceptance

- The question set and its expected pages are kept in the repository, so the measurement can be rerun.
- The share found in the first five is recorded, with every miss named.
- A rule is stated for when the result calls for more than keyword search.
