* Goal

Give the Linux build job =actions: write= so the sccache entry refreshes,
and remove the deprecated =std::getenv= calls that break the Windows clang
builds.

* Acceptance

- =continuous-linux.yml= grants the build job =contents: read= and
  =actions: write=.
- =ores.platform.tests= and =ores.ore.core.tests= build and pass locally.

* Plan

1. Add a =permissions:= block to the Linux build job.
2. Define =_CRT_SECURE_NO_WARNINGS= in the platform environment tests,
   as =real_environment_provider.cpp= does; the tests compare the
   provider against the C runtime, so they must call =std::getenv=.
3. Read =ORES_BOOTSTRAP_GOLDENS= through =environment::get_value= in the
   ORE coverage tests.

* Result

The Linux build job now has =contents: read= and =actions: write=, so the
sccache delete-then-save can replace the entry. The platform environment
tests define =_CRT_SECURE_NO_WARNINGS=; the ORE coverage tests read
=ORES_BOOTSTRAP_GOLDENS= through =environment::get_value=. Locally,
=ores.platform.tests= and =ores.ore.core.tests= build with no warnings,
and the =[environment]= (18 cases) and =[coverage]= (1 case) tests pass.
The cache refresh can only be confirmed on the first Linux run after merge.
