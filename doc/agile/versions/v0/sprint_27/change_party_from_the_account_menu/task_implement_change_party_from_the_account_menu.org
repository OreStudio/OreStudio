* Result

The account menu offers the other parties a person works in.

- The list is read when the menu opens and is drawn only for a person who works in more than one party. It leaves out the party the session acts for.
- Choosing one re-scopes the open session and reads every screen for that party again, so a screen never shows the old party's data under the new party's name.
- A failure is said in the menu. The Where I work page switches party through the same session action and gains the same re-read.
