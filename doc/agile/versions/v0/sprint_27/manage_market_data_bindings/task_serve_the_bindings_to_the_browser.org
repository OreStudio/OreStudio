* Goal

The record screen standard builds a screen from a record kind declared once: its resource, its write schema, its field table and its columns. The BFF has no record kind for feed bindings. Declare it, with the list searched by source name and series and filtered by kind, the fields Edit offers (the source name and the enabled flag), and the write checked at the boundary with a test that a bad row and a read only write are refused.
