* Goal

One hand-written type, =market_datum=, describes every ORE market datum: a
variant with one struct per ORE instrument type. Each field has a real type,
and the coordinate role is in the type, not in a table.

* Acceptance

- =market_datum= has one alternative for each of ORE's 45 instrument types.
- Currencies, ORE periods, dates, the ORE quote type, call/put, cap/floor and payer/receiver are types, not strings.
- A strike is a variant of absolute, ATM with its ATM type, moneyness and delta.
- Free-text names keep the case they arrived in.
- Every coordinate field has the type =coordinate<T>=, and =series_of(datum)= removes exactly those fields.
- No field is =std::optional= where its absence would mean a default. An optional ORE token has an explicit =none= value.
- Unit tests cover equality, =series_of= and every value type's text form.

* Plan

1. Derive the field list per type from the reference catalogue, not from the
   current models.
2. Write the value types first, then the structs, then =series_of=.
