* Notes

** Hand-written code

Telemetry has no generated repository: its one repository, in the database part, is hand-written, and it is ported by hand. Its six entities drop sqlgen's key wrappers and state their columns; every sqlgen session, select_from count, insert and delete goes through the query builder; the raw-SQL reads go through the query builder's raw helpers. The summary's counts are read as text into 64 bits, because the builder's count helper returns 32, and a failed summary count still leaves its figure at zero as sqlgen's did.

** What else

New repository tests cover the methods the suite did not: read_by_account, count_errors, delete_old_logs and the NATS server and stream samples. The hourly and daily stats read continuous aggregates that refresh on a schedule and stay untested.
