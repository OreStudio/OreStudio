* Decisions

- The codegen-standard contract is version==0 / change_reason_code=="system.test" (in-memory, never-persisted test fixture). The old version==1 / "system.new" expectations encoded pre-PR-#1698 hand-written generator behavior; the generators were aligned to the standard in PR #1698 and the test expectations lagged. Tests failing loudly caught the drift; no silent false-positive testing was happening.
- Closed as DONE: the fix was done elsewhere — the stale expectations were already fixed on main before this story was promoted (commits 90ad8693be, c113b851e, 123ca2bfa, d0458e500, 2026-07-17..2026-07-28). The story stands as the investigation record.
