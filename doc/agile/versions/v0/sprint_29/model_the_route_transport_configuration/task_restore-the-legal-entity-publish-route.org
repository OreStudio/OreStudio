* Result

The subject answers again and a fresh tenant provisions end to end: nine steps
of nine, 42,388 legal entities published from the LEI artefact, and the trades
generated as before.

The fault was one array entry. The publish-from-DQ handler is registered once
for a list of subjects, and the legal entities subject was not on the list, so
the workflow published the command and waited for a reply that no service could
give. Before the fix the same recipe failed at its first step, silent for
twenty minutes, and then declared the step dead.

The regression came in with the refdata regeneration this story carried. The
branch's copy of the model did not declare the operation, so regeneration
removed the hand-written registrar entry; the declaration landed on main before
this story merged, which put the struct, the SQL function and the workflow step
back while the registration stayed gone. The subject is now registered, and the
model still declares it, so a regeneration keeps both halves.
