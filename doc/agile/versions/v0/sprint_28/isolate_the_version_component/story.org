#+title: Story: Isolate the version stamp into its own component
#+description: The build's git hash is compiled into ores.utility.lib, a shared library that 179 targets link, so the stamp changes on every commit and relinks all of them. Work out how version is used, size the blast radius, and move the stamp into a small component that only the code that reports the version links.
