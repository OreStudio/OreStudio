* Acceptance

- The gate passes a job count to ctest
- The ctest time in the gate report is measured before and after

* Plan

The test preset in =CMakePresets.json= names no job count, and the gate's
=ctest= check passes none, so the gate ran the suites one at a time. Pass
=-j 4= through =compass test run= in the check's command. The suites that must
not overlap already say so: =ores.marketdata.core.tests= is =RUN_SERIAL= and
the two web suites share the =ores_web_dist= resource lock. Four is the job
count both full runs in this session used, and both passed.
