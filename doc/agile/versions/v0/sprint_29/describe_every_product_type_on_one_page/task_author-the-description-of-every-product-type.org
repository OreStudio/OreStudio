* Goal

Every product type states what it is in prose a person can read before booking it, and every statement names its source. The catalogue holds the one description, and no note or screen restates it.

* Acceptance

- All 121 rows carry a description and a source reference.
- The 13 types with no description anywhere are written: the four ForwardVolatilityAgreement codes, the commodity digital and average-price types, the commodity spread option, IntradayPowerForward, BondFutureOption, CreditDefaultSwapOption, SwaptionStraddle, CrossCurrencySwap and FxAverageForward.
- No description names a model, an engine or a pair.
- The six names that disagree today state one name each: CBO, Ascot, CapFloor, EuropeanOptionBarrier, Autocallable_01 and ForwardBond.
- A check fails when a row has no description or no source reference.

* Plan

The descriptions already exist, scattered: 103 of the 121 types are named by a
domain note that states a one-line description and the ORE guide file it was
written from. The work is to collect them into the catalogue, write the ones no
note names, and make an empty description impossible to seed.

- Add a `* Descriptions` table to the catalogue model: one row per code, with
  the prose, the document and the file inside it.
- Teach the loader to read it, and to refuse a catalogue code with no row, a
  row missing any of the three columns, and a row for a code the catalogue does
  not state.
- Emit the three columns in the seed.
- Write the eighteen types no note names, from the ORE example trades and the
  guide chapter that documents their structure.
- Prove it: the codegen suite, a recreated database whose 121 rows all carry a
  description and a source, and the catalogue's own page reading them.

* Notes

** 2026-11-02 — every type is described and sourced

One hundred and three of the descriptions are the domain notes', collected into
the catalogue: the note already stated the one sentence and the guide file, and
the catalogue is where a reader now finds them. The semicolon clause the notes
end on, "ORE's <name> product", is dropped, because the page states the code
beside the sentence and the tail said the name twice.

Eighteen types no note names. Their sentences are written here from the ORE
example trades under `external/ore/examples/Products/` and from the guide
chapter that documents their structure, and each names that chapter as its
source. Where a chapter documents several structures, the description says which
of them this type is.

The seed cannot carry an empty description again: codegen refuses a catalogue
code with no description row, a row missing its source, and a description of a
code the catalogue does not state. The suite states each of those as a test.

* Result

All 121 product types state what they are, in one sentence, and name the
document the sentence was written from.

The catalogue holds the prose in its `* Descriptions` table: one row per code,
with the description, the document and the file inside it. Codegen refuses a
catalogue code with no row, a row missing any of the three columns, and a row
for a code the catalogue does not state, so the seed cannot carry an empty
description again. Five tests state those rules, and one asserts that every type
in the catalogue is described and sourced.

One hundred and three descriptions are the domain notes', collected into the
catalogue; the tail each note ends on, "ORE's <name> product", is dropped because
the page states the code beside the sentence. Eighteen types no note names are
written from the ORE example trades and the guide chapter that documents their
structure, and each names that chapter.

The database recreates at =5469f5b0de= with 121 rows, all carrying a
description, a source and a source reference. The gates: 51 local checks, 77
pgTAP suites, and the codegen suite at 1846 tests. The C++ suites need the
build, which adds the nine roundtrip test files the regeneration created.

Two defects main carried were fixed on the way, because the gate renders every
component when the generator changes: the physical-space inventory and the list
request descriptors were stale, nine wire-codec roundtrip tests were never
committed, and the reporting element map still named the commodity curve table
the curve split replaced.
