* Goal

The CI build fails in
=projects/ores.iam/api/src/generators/run_grant_generator.cpp= with
=error: 'to_string' is not a member of 'boost::uuids'=. The
domain-entity synthetic-generator template emits a model's
=generator_expr= verbatim, but it never includes
=<boost/uuid/uuid_io.hpp>=, the header that declares
=boost::uuids::to_string=. Any entity whose =generator_expr= renders a
UUID as text therefore fails to compile. =run_grant= is the first such
entity. This hotfix emits the include when a =generator_expr= calls
=boost::uuids::to_string=, and regenerates the affected file.
