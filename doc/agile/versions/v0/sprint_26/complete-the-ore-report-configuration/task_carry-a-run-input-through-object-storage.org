* Notes

Raised in the review of PR #2647: the input travels inline, NATS refuses a
message over its 1 MB limit, and the Products example's curve configuration
alone is over 500 KB. The shell refuses an input over 900 KB with the reason
until this lands. The workflow request also carries the files, which this
removes.
