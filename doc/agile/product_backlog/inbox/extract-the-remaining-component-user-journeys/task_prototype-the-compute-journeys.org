* Result

The five compute journeys are written and walked. The grid had one journey,
the fleet survey, and nothing for the work it does; it now has five, one per
use case, each naming the charts it composes and the owner it serves.

A prototype covers all five screens, twenty charts hand-rolled as inline SVG
with no library and no build step, tabbed by the question each tab answers:
the load, one job, a failure, the capacity, and what the grid may run. Every
table pages by the Record screen standard, a job opens to its full detail, and
the lineage runs from the scheduled job through the report to the batch and its
results. A tenant variant narrows every row, every legend and every footnote,
and withholds the node logs, which are the installation's.

The design work behind it is recorded too: the three ownership classes in the
target-state tenancy pages, and the decision that reframed the whole exercise,
that the installation records what it did about its own operation rather than
reading across tenants, so the global view needs no policy exception.

The review found more than the build did, which is the point. It caught four
panels whose figures contradicted each other, a tenant leak in a legend, two
lineage errors, and a checker that passed 351 of 351 while all of it was wrong.
Eleven findings were accepted and fixed; one was declined, because the em-dash
rule it cited does not exist and the corpus uses them freely.

Verified: the documentation validator passes all 42 components; the prototype
inventory lists and publishes all 41; the RLS guard reports 10 widenings, all
listed, which is the baseline; the prototype's checker passes 457 of 457; and
the branch merges with main a3d65e6eb7 with no conflict.

Not verified: the prototype is mock data and reaches no server, and the
journeys have not been walked with the operator. The grid read fix and the
usage ledger are storied, not built, so nothing here changes the running
system.

Left behind: doc/knowledge/journeys/operations/wireframe_watch_the_compute_grid.puml
