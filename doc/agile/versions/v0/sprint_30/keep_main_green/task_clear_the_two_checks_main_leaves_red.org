* Result

* Result

=timescaledb_libraries= read every cluster's library directory even when it was
given one, so on a machine with the extension installed it returned the installed
version beside the one it was asked about, and the test that passes a temporary
directory failed. It now reads only the directory it is given, and falls back to
every installed cluster when it is given none, which is what its own docstring
said. The compass suite passes: 589 tests, 2 skipped.

The XML benchmark had no row after =0714120eac=, the commit that adopted
compass-ng v0.0.7 and changed the measured files, so the check failed on every
branch. The benchmark was rebuilt and run, and history.tsv carries 96 new rows
measured on clang 16 at -O3.

The gate is green: 25 of 25.
