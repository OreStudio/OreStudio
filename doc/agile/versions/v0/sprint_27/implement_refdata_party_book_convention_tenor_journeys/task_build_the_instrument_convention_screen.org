** What is not done

1. *Only the swap and the deposit are written.* The journey draws their terms in full and says the other 23 families are listed, not drawn. Their cards say so and the BFF refuses a write to them.
2. *The family-to-entity mapping is the BFF's.* The server has no list that maps a family to its entity. Task "Serve the convention family mapping, its term filter and term rules" is still open.
3. *The search filters the rows loaded here.* The server filters a convention list by id only, so the BFF returns up to 500 rows and the screen filters them.
4. *The server does not check a term against its list.* A term naming a value the list no longer holds is written, not refused. The screen offers only codes it has read from the lists.
5. *The history has no draft version and no revert.*
