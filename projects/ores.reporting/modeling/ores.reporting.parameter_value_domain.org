#+title: ores.reporting.parameter_value_domain
#+description: Codegen entity model for the reporting =parameter_value_domain= table. What a parameter value is, and what it refers to when it names something.
#+type: ores.codegen.entity
#+component: reporting
#+filetags: :model:entity:reporting:
#+brief: The kind of value a configuration parameter holds.
#+entity_singular: parameter_value_domain
#+entity_plural: parameter_value_domains
#+entity_title: Parameter Value Domain
#+created: 2026-09-27
#+updated: 2026-09-27

Every configuration parameter holds one value, and this says what that value
is: a currency, a date, a boolean, an integer, a tenor, a document reference,
or a list. Where the value names something in the model, =referenced_entity=
names the entity it points at, so the mapper knows what to write into the
document and a reader knows what the value means.

The entity is not called value_domain because that name is a knob in the
codegen meta-model; an entity using it resolves to a placeholder and the
generator writes files called unknown instead of failing.

* Columns

** code
:PROPERTIES:
:type:        text
:cpp_type:    std::string
:primary_key: true
:END:

The stable code for the domain, for example currency or tenor.

** name
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:END:

The human-readable name of the domain.

** storage_kind
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:END:

How a value in this domain is stored: text, numeric, integer, boolean,
date, uuid or list.

** referenced_entity
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:END:

The entity a value in this domain refers to, when it refers to one, for
example ores.refdata.currency. Empty when the value stands alone.
