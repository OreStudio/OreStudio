* What

A link is removed on one click with no reason asked. The link panel's Remove writes the removal at once: no confirmation, no change reason, no commentary, where RS-FEEDBACK-06 says every write carries a change reason and the currencies prototype drew a remove dialog that asks one. Seen on 2026-10-26 on the currency's Countries tab and the desk group's Members tab. Decide whether a link removal is a write that needs a reason, and if so give the shared LinkPanel the remove dialog.

* Why

RS-FEEDBACK-06 says every write carries a change reason, and the currencies prototype drew a remove dialog that asks one. Decide whether a link removal is a write that needs a reason; if it is, give the shared LinkPanel the remove dialog, and the desk group's members panel gains it too.
