#+title: ores.reporting.ore_parameter
#+description: Codegen entity model for the reporting =ore_parameter= table. The vocabulary of an ORE document: which leaves a schema accepts, and what each value means.
#+type: ores.codegen.entity
#+component: reporting
#+filetags: :model:entity:reporting:
#+brief: A parameter an ORE document accepts, and what its value is.
#+entity_singular: ore_parameter
#+entity_plural: ore_parameters
#+entity_title: Ore Parameter
#+created: 2026-09-27
#+updated: 2026-10-22

The vocabulary of ORE XML. A row documents one leaf of one ORE document: an
attribute or an element that holds a value. =schema_name= names the XML schema
of the document, for example =ore.xsd=, and =xpath= is the path to the leaf in
a document of that schema. The two together say which leaf this is.

ORE writes the parameters of =ore.xml= as a name and a value inside a block.
For them =scope= names the block (Setup, Markets, an analytic), =subtype=
narrows it, and =name= is the parameter, so the three give the same path as
=xpath=. =position= keeps the order the document wrote, because a document that
is not reproducible in order is not reproducible.

165 of the 218 parameter names observed in the shipped corpus belong to
exactly one analytic kind, which is why the name alone is not the key.

** id

Surrogate key for the ORE parameter.

** scope
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:END:

The block the parameter belongs to, for example Setup or Markets.

** subtype
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:END:

The kind within the block that accepts the parameter, for example the
analytic type. Empty when the block is the whole context.

** name
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:END:

The parameter name as ORE writes it.

** schema_name
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:END:

The XML schema the leaf belongs to, named by the file name of the schema, for example =ore.xsd=. A document is of this schema whatever its own file name is.

** xpath
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:END:

The XPath of the leaf in a document of the schema, for example /ORE/Setup/Parameter[@name='implyTodaysFixings']. The schema name and the XPath together say which leaf this is. For ore.xsd, scope, subtype and name give the same path.

** position
:PROPERTIES:
:type:     integer
:cpp_type: int
:nullable: false
:END:

The order the document writes the parameter in.

** ore_parameter_value_domain_code
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:END:

What a value of this parameter is.

** is_required
:PROPERTIES:
:type:     boolean
:cpp_type: bool
:nullable: false
:END:

Whether the document must carry the parameter.
