+#+brief: Propose and apply a change to a number-changing group of engine run settings.
+#+filetags: :model:operation:reporting:
+#+created: 2026-10-28
+#+updated: 2026-10-28

A number-changing group of engine run settings never changes in place. A write
to such a group is a proposal: the values are held against an approval request,
and the version in force keeps the rows a run reads until the request is signed
off. An operational group, such as execution, still lands directly through the
group's own entity operation.

The operations here are the proposal's own lifecycle. They are not entity
verbs, because a proposal is not a write of a part: raising one writes no part,
and the apply is the workflow step the kind names, not an operation a caller
takes.

The handler is hand-written beside this model, because each operation applies
the rules of the approval framework.

#+begin_src cpp :name comment
/**
 * @brief Holds a proposed change to a group in an approval request.
 *
 * A configuration that no report binds is a draft, and its groups change in
 * place, so a proposal here is refused and the caller writes the group
 * directly. A group that changes no numbers is refused the same way, because
 * the execution group is operational and lands directly.
 *
 * The proposal names the parts its group needs: the kind names one part for
 * each number-changing group, and the request takes the part of the group the
 * proposal writes.
 */
#+end_src
