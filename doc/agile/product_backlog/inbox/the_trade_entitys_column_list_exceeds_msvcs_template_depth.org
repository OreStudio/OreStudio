#+title: The trade entity's column list exceeds MSVC's template depth
#+description: windows-msvc-release-ninja fails to compile trade_entity.hpp:95 with C1202: recursive type or function dependency context too complex. The columns() chain there builds a column_list one binding at a time through operator|, and the trade entity is the widest of the generated entities at nineteen bindings. MSVC's instantiation depth is reached before the list is complete, so the whole entity and every library that includes it fails on that compiler alone; the Linux and Windows clang legs compile it. Splitting the chain, or carrying the bindings in a way that does not nest a template per column, would keep the entity within the limit.
