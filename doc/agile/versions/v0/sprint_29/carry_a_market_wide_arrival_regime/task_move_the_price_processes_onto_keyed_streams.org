* Goal

A run's price paths are a function of its seed: every price process draws from an rng_stream keyed for its series and the price purpose, and nothing in the price path reads random_device or a defaulted seed.

* Acceptance

- Every price process takes an rng_stream, and no constructor in the price path takes a defaulted seed.
- fx_spot_feed no longer reads random_device; two runs with one seed publish the same prices for a series.
- The process tests construct their streams from explicit keys.

* Plan

The change is made by two scripts, kept in =evidence/= so a reviewer can run
them again.

- =seed_codemod.py= moves the twelve price processes, =rate_tree= and
  =process_factory= from a seeded =std::mt19937= to a =math::rng_stream=: a
  =std::uint32_t seed = 42= parameter becomes a =math::rng_stream stream= with
  no default, a member engine becomes a stream, and a delegating constructor or
  a factory branch moves the stream it was given.
- =wrap_seeds.py= moves the tests. It reads clang's errors after a build with
  =-k 0=: a note that names an argument with no conversion to =rng_stream=
  gives the call and the argument, which the script wraps in
  =price_stream(...)=; a call that left the seed to its default is one
  argument short, and the script appends =price_stream(42)=, the seed the
  default gave. It runs until a round fixes nothing. The compiler decides
  which argument is the seed, not a pattern.
- =price_stream= in the tests keys a stream by an explicit seed.
- A feed's price stream is keyed by the run seed, the series key of its
  source name and the price purpose (=price_stream_for=), so its prices
  follow the run seed as its arrivals do. =fx_spot_feed= no longer reads
  =random_device=, and =ir_curve_feed= no longer uses a constant 42.
- The simulate and the preview dry runs keep the seed their request names,
  one more for each path, and key a stream from it.

* Result

Every random draw a run makes now comes from a keyed stream. The twelve price
processes, =rate_tree= and =process_factory= take a =math::rng_stream= and no
seed with a default; the change was made by =evidence/seed_codemod.py=, and
the tests were moved by =evidence/wrap_seeds.py=, which wraps the arguments
clang names. A feed's price stream is keyed by the run seed, its source name
and the price purpose, so one run seed draws the same prices for a series, and
another seed or another series does not; a test asserts all three. The FX
feed no longer reads =random_device=. On Acme every feed priced and published
after the change, with no failed tick.
