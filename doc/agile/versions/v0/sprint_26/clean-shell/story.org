* Result

Merged as PR #2275, with every applicable item of the Component Clean Standard
worked and recorded on the task. ores.shell joins COMPONENTS_UNDER_TEST and the
drift check passes with it listed; the whole tree builds, the codegen suite
passes and all fourteen of the component's suites pass with the fleet up.

The component is unusual in the programme in a way that shaped the whole pass. It
is a component of kind All with no model of its own beyond the component model,
and it is the render target of twelve other components' shell-command facets. So
most of the Entity and Protocol sections do not apply, and the largest
hand-written block in its tree is the shell surface of ores.trading entities,
which belongs to that component's own S01.

The pass found more than it confirmed, which is what the standard predicts: two
stale CMake lists, twelve stale part diagrams, six part overviews with no Diagram
section, four parts with no rendered image, a namespace brief describing a shell
that no longer exists, four tests asserting only a non-throw, and one red case
asserting a timestamp form the platform does not write.

The task records what it did not close: the trading dependency, the two generator
parser gaps, the CMake list check that no gate runs, and the V08 coverage list of
52 source files with no name-matched test.
