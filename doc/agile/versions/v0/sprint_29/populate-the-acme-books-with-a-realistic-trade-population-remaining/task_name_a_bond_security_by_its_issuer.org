* Result

A security's name now states its issuer. =security_id_for= takes the issuer
id and the digest covers it, so two issuers of one currency, anchor, term and
product hold two securities, and an issue id derived from the security no
longer collides. The planner draws the issuer before it names the security,
because the name needs it.

A case states the rule: two scopes whose issuer lists differ state different
securities for the same term and product.

* What could not be proved

The live proof did not run. Provisioning now stops earlier, in the curve
configuration bundle, because the ACME dataset states =ZeroInflation= for
=inflation_curve_config.inflation_type= and the refdata value set does not hold
it:

#+begin_example
Invalid value ZeroInflation for inflation_curve_config.inflation_type: the value
is not in set curve.inflation_type.
#+end_example

That is the inflation family's work in flight on main, not this change. Once it
lands, the two bond configs are the next thing to provision and read.
