* Result

Trace logging and the persistent FeedStatus::Error indicator shipped
as planned. The actual root cause -- fx_spot_subscription.cpp calling
rfl::json::read<T> directly instead of default_wire_codec().decode<T>(),
ignoring the negotiated wire format entirely -- was found and fixed
by commit 7fe8798452 ("[marketdata,qt] Fix fx_spot_subscription
hardcoded rfl::json, ignoring wire codec"), PR #1809, under
Task-ID 1FC899C9-48A9-416C-87D0-FF4BB54F0DB7 / Story-ID
1A815B1E-904E-460C-A2FB-31D9E3B392E2 (the NATS wire-format story),
merged the same day this diagnostics task was authored. Verified
2026-08-04: launched the Qt client against a live msgpack
environment, logged in as tenant_admin@acme_corporation, opened FX
Spot Monitor -- rows tick live, wire format resolves to msgpack, zero
"Failed to deserialise fx_spot_tick" warnings in the client log.
