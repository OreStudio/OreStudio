* Goal

An export describes one moment. Every family it reads is read at the same bitemporal instant, and the file it writes records that instant, so two exports of an unchanged environment are identical and an export taken during an import cannot mix two states.

* Acceptance

- An export takes one bitemporal instant before its first read and passes that instant to every family it reads.
- Paged reads go through the generated =as_of= path rather than each service choosing its own.
- The file an export writes records the instant it was taken at, so a reader can say what moment the export describes.
- A regression test takes an export, changes one family, and takes a second export. The first export is unchanged.

* Notes

- The instant belongs to the export, not to the family. A read per family that each takes its own instant describes a different moment per family, which is the defect this task exists to remove.
- =projects/ores.ore/service/src/messaging/run_configuration_operations.cpp= sets =as_of= to null when it asks for a family. That is the place to start.
