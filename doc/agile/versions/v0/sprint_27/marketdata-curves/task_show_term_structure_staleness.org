* Goal

Make a term structure's staleness visible whenever it is drawn, so a composite of several market states is never mistaken for one market state.

* Acceptance

- A read that returns a term structure's points also returns each point's
  instant and when it was recorded, so age is derivable without a second call
- A drawn term structure shows per-point age, the oldest point's age, and the
  spread between the oldest and the newest
- A curve stitched across market horizons is visibly different from one built
  from a single instant, without the reader asking
- A prototype settles the encoding, and the threshold at which the view warns
  rather than drawing silently is stated by a journey
