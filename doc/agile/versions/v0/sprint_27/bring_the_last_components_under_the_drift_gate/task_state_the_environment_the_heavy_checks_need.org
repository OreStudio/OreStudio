* Result

The environment is stated, not enforced, which is the half of the acceptance
this could carry honestly.

db needs no service connected to the database; ctest needs the NATS server up
and the database db has just rebuilt. compass services stop stops the server
along with the services, so the two cannot both be satisfied by it. Leaving the
target up instead makes db recreate --kill lose its race: it terminates the
service backends, they reconnect before the recount, and the check refuses on a
handful of live connections. The environment that works is NATS up with every
service stopped.

That is recorded on the local-checks page. The runner still neither states nor
enforces it, and that is deliberate here rather than overlooked: a change to
the runner cannot be verified without running the heavy tier, which this work
is not allowed to do. It is the first thing to fix when a build can be spent.
