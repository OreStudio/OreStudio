** Custom repository methods

The trade read path fetches the cbo tranches of many instruments at
once, and no generated read covers that: the generated reads address one key
group at a time. The batch read below is one statement over the instrument
set.

*** read_by_instruments_batch
:PROPERTIES:
:ID: F0060F18-ADEA-4B67-A6D3-0C494777EA91
:END:

Reads every current cbo tranche of the given instruments, in one statement. An empty input
reads nothing.

#+begin_src cpp :name implementation :implements F2EB1914-5E94-42CA-9C77-46BDB364BF9E
std::vector<domain::cbo_tranche>
cbo_tranche_repository::read_by_instruments_batch(
    const context& ctx, const std::vector<std::string>& trade_ids) {
    if (trade_ids.empty())
        return {};
    static constexpr auto max = db_timestamp::max();
    const auto tid = ctx.tenant_id().to_string();
    const auto query = query_builder::read<std::vector<cbo_tranche_entity>> |
                       query_builder::where("tenant_id"_c == tid &&
                             "trade_id"_c.in(trade_ids) && "valid_to"_c == max) |
                       query_builder::order_by("trade_id"_c, "sequence_number"_c);
    return query_builder::execute_read_query<cbo_tranche_entity,
                                             domain::cbo_tranche>(
        ctx,
        query,
        [](const auto& entities) { return cbo_tranche_mapper::map(entities); },
        lg(),
        "Reading cbo tranches for multiple instruments.");
}
#+end_src
