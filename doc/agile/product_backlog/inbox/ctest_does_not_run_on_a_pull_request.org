* What

Find out why a failing test reached main. Then decide whether a pull request needs a test gate.

The range bound repository test wrote rows with an empty =modified_by=. The store refused them, so the test failed on main. PR #3636 fixed it.

* Why

The workflows that build and run ctest (=continuous-*.yml= and =nightly-*.yml=) run on a schedule. They do not run on a pull request. The PR workflows check drift and lint only. A test can therefore fail on main with no check on the PR that added it. The cause is not confirmed. Check the scheduled runs first.
