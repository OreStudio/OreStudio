* Notes

- The first draft initialised the thread in the constructor's member-init list
  and read the stop source there. clang flags that under =-Werror= as an
  uninitialised field read, and the fix is to take the token and assign the
  thread in the body: the token is then a plain value and the initialisation
  order cannot be argued about.
- The macOS run of the previous fix (36704140032) succeeded, so the failure
  this task fixes is the one the deadline watch introduced afterwards.
