* Acceptance

- The pending table has the entity columns with the same foreign keys, checks and lookup validation, plus the request, line number, operation, version read and part.
- A model change reaches the pending table in the same regeneration and migration.
- The dry run runs the real service database layer in a savepoint, returns its refusals, publishes no event and sends no notification.
- The book is generated first and its pending table, propose, check, read and apply are tested.
