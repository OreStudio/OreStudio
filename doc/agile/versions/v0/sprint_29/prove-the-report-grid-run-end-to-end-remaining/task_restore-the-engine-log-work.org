* Result

The three commits are restored on today's tree, one for each thing the stranded
work did, and each one builds and passes its suite:

- =[ore] Read the engine's log in one place= brings =engine_log= and its suite
  into =ores.ore.core=.
- =[compute] Write the engine's log beside a run's rows= gives the claim a
  =logs_uri= and the node its fifth grant, and the wrapper uploads the canonical
  rows the parser produces.
- =[reporting] Load a run's log rows from the node= reads those rows through one
  reader, so the service never learns the engine's format.

Two faults were found while restoring and are fixed here. The claim's wording
still said four objects, and the log reader read a doubled quote as two field
boundaries, so a message that stated a quote lost it. The reader also had no
suite; it has six cases now.

Nothing remains on =feature/run-a-report-and-read-its-rows=.
