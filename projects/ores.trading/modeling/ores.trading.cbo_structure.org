The structure a CBO states inline: the scalars of its =CBOStructure=.

A CBO names its structure by its =StructureId=, which ORE looks up in its
reference data, or states it inline. An inline structure's tranches, basket
and payment schedule are rows of their own; this row keeps the scalars.

** Custom repository methods

The trade read path fetches the cbo structures of many instruments at
once, and no generated read covers that: the generated reads address one key
group at a time. The batch read below is one statement over the instrument
set.

*** read_by_instruments_batch
:PROPERTIES:
:ID: 154668DC-113E-47B7-89E1-F8CFE9240CA7
:END:

Reads every current cbo structure of the given instruments, in one statement. An empty input
reads nothing.

#+begin_src cpp :name implementation :implements F2EB1914-5E94-42CA-9C77-46BDB364BF9E
std::vector<domain::cbo_structure>
cbo_structure_repository::read_by_instruments_batch(
    const context& ctx, const std::vector<std::string>& trade_ids) {
    if (trade_ids.empty())
        return {};
    static constexpr auto max = db_timestamp::max();
    const auto tid = ctx.tenant_id().to_string();
    const auto query = query_builder::read<std::vector<cbo_structure_entity>> |
                       query_builder::where("tenant_id"_c == tid &&
                             "trade_id"_c.in(trade_ids) && "valid_to"_c == max) |
                       query_builder::order_by("trade_id"_c);
    return query_builder::execute_read_query<cbo_structure_entity,
                                             domain::cbo_structure>(
        ctx,
        query,
        [](const auto& entities) { return cbo_structure_mapper::map(entities); },
        lg(),
        "Reading cbo structures for multiple instruments.");
}
