* Goal

The prototype shows the five operations journeys as clickable screens: the running services, the compute grid, the message bus, the logs, and the versions and database fingerprint. It runs against a hand-written BFF route per step, uses only operations that exist today, and lives on a throwaway branch kept as the design record.
