* Summary

=ores.storage.service= is the process that lets a component reach storage over
the bus. It binds the operation set's subjects, authenticates the caller and
checks the operation's permission code before it acts, and calls
=ores.storage.core= to move the bytes.

* Inputs

- The bus endpoint and the service's own configuration.
- An authenticated request on one of the operation set's subjects.

* Outputs

- One reply per request, carrying the protocol's =result= and, where the
  operation returns data, the object's metadata or page.

* Entry points

- =src/main.cpp= — the process entry point.
- =include/ores.storage.service/messaging/registrar.hpp= — the handler registration.

* Dependencies

- [[id:9C11A981-EAA8-4AE2-AAEA-7FEE01982CE4][ores.storage.core]] — the implementation it serves.
- =ores.service= — the domain service runner every service shares.
- =ores.nats= — the transport.

** Run body

The store is the one the HTTP routes are given: two front doors onto the same
tree, which is what makes a put over the bus and a put over HTTP leave the
same object.

#+begin_src cpp :name service_app_run_body :implements 2CD994C9-83FF-4C41-8909-5AD2BF3DECCC
BOOST_LOG_SEV(lg(), info) << ores::utility::version::format_startup_message(
    "ores.storage.service", 0, 1);

ores::nats::service::client nats(cfg.nats);
nats.connect();

// The store is the one the HTTP routes are given: two front doors onto the
// same tree, which is what makes a put over the bus and a put over HTTP
// leave the same object.
ores::storage::filesystem::local_store store(cfg.storage_dir);

co_await ores::service::service::run(
    io_ctx,
    nats,
    make_context(cfg.database),
    "ores.storage.service",
    [store](auto& n, auto c, auto v) {
        return ores::storage::service::messaging::registrar::register_handlers(
            n, std::move(c), std::move(v), store);
    },
    [&nats](boost::asio::io_context& ioc) {
        auto hb = std::make_shared<ores::service::service::heartbeat_publisher>(
            std::string(service_name), std::string(service_version), nats);
        boost::asio::co_spawn(ioc, [hb]() { return hb->run(); }, boost::asio::detached);
    });
co_return;
#+end_src

** Config option member

The member the =--storage-dir= option fills. It must be the same directory the
HTTP storage routes are given, because the two interfaces serve the same
objects through the same store.
