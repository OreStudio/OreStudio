* Goal

Split from Declare each route's place in the catalogue, whose first PR declared every route's tool, area, entity and whether it writes. 116 hand-written routes take a body and none declares its type through the route builder's typed body declaration, so the catalogue cannot state their input schema. A lever reads each handler, following it into the functions it calls with the request, and declares the body type the handler reads, or no body where it reads none; it resolves 100 and leaves 8 for a person.

* Acceptance

- Every route that takes a body declares its typed body schema through the route builder, and one that takes none says so.
- The server refuses to start with a route whose method takes a body and that declares neither.
- The OpenAPI document carries every declared body's schema.

* Plan

(Implementation strategy. Written when work starts; key decisions
are distilled into the parent story's =* Decisions= at close, but the
plan itself stays — it is the historical record of what we did.)

- The two web templates declare their write routes' bodies, by the same
  sections their handlers read them under; the other templates already did.
- A lever reads each hand-written POST, PUT and PATCH handler, following it
  into the functions it calls with the request, and declares the type it
  reads, or =.no_body()= where it reads none.
- The router gains =.no_body()= and =.json_body()=, the latter for a body whose
  members depend on a family no one type fixes, and its start-up gate refuses
  a body route that declares neither a type, a stream nor that it takes none.
- The builder writes an example through a type's wire traits where it has
  them, else through the fields it states, because a route's own body type
  states its fields and has no traits.

* Result

Every ores.http route whose method carries a body states what it takes: a typed
body schema, a JSON object of no fixed shape, a stream, or none. The generated
web routes take theirs from their templates and the hand-written ones state
theirs, and the server refuses to start while one states nothing. The OpenAPI
document carries 511 of the 517 POST, PUT and PATCH operations' bodies; the six
without one read none. An agent's tool can therefore answer its input schema
from the catalogue.
