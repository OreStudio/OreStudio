* Goal

We import skills from two repositories that keep moving. Without a recorded origin we cannot tell an intentional divergence from an accidental one, and we cannot pull an upstream improvement. Define the contract: frontmatter keywords naming the upstream repository, the path within it, the commit we imported from, and the date; a body section stating how we diverged and why. Add a manifest document listing every imported skill. Add a compass check that reports which imports are behind their upstream. Both source repositories are MIT licensed, so settle how their licence ships alongside ours.
