* Acceptance

- The process enumeration is seeded, so a run names which process ran.
- A run has an identity and a state machine over its evolution.
- The state machine refuses a transition the process does not allow; a pgTAP test walks a run through its states.
- The run records the process it is a run of with an enforced foreign key, and no run exists without one.
