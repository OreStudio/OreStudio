* Goal

Write the document back from the same tables. The write direction need not
mirror the read direction; it has to be valid, cheap and lossless. Three rules
carry it: schema order, present fields only, and a decimal form that never
exponentiates.

* Acceptance

- Output validates against =input.xsd= for every document in the corpus.
- A decimal writes as fixed point at the column's scale and never as an
  exponent.
- Only text that needs escaping is escaped, decided by one scan.
- Reading the output yields the same values as reading the original.
