* Goal

Eight columns in the trading models hold JSON blobs where the domain should hold rows, and each is a place where the store cannot answer a question about the trade without parsing text.

* Acceptance


- Each of the eight columns is named, with its decision: rows, or kept with a reason.
- A column that becomes rows has no JSON left in the model, the store or the wire.
- The store answers a question about a trade from those rows, without parsing text.

* Result

All eight JSON columns in the trading models are rows: the five on the equity
swap and the equity accumulator through the basket constituents task, and the
three on the scripted instrument through the scripted variables task of the
valuation story. No trading table, domain type or wire message holds a trade
fact as JSON. The table in Decisions names each column and what it became.
