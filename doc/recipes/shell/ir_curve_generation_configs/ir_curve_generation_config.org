#+title: How do I run the ir_curve_generation_configs commands from the shell?
#+description: Every command the ir_curve_generation_configs submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross

This file documents the ir_curve_generation_configs resource at the shell, one section per command. Every command is a subcommand of =ir_curve_generation_configs=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: 5A760B5A-A39F-554B-B091-B71001CC69D5
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
ir_curve_generation_configs list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =synthetic.v1.ir_curve_generation_configs.list=.

#+begin_src ores-shell :tangle ir_curve_generation_configs-list.ores :exports none

** =set=
:PROPERTIES:
:ID: DBF70827-8526-5B06-9AFE-6D1CD901CBA7
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses.
