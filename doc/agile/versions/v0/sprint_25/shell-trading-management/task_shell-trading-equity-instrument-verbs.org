* Goal

ores.shell extends the trading command folder to the nine equity
instrument families, cloned from the fx-batch skeleton. Each unit
(equity_accumulator, equity_asian_option, equity_barrier_option,
equity_digital_option, equity_forward, equity_option,
equity_position, equity_swap, equity_variance_swap) declares the
entity-specific data: trading.v1 subject family, request and response
classes from the per-product protocol, save columns from the org
model, instrument_id key. The batch runs the live equity system test:
every unit round-trips add, list, history and delete through the shell
against the fleet, with each save verified at the DB layer and on the
changed-event stream. Any quirk a family exposes (position versus
instrument semantics, save columns the fx convention does not cover)
is resolved here and distilled back into the shared skeleton.
