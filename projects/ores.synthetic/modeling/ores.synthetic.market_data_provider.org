#+title: ores.synthetic.market_data_provider
#+description: Reference data table of the simulated market data providers a synthetic feed can stand for: data vendors such as Bloomberg and LSEG, exchanges such as CME and LSE, brokers, and reference sets such as the ORE examples.
#+type: ores.codegen.entity
#+component: synthetic
#+filetags: :model:entity:synthetic:
#+entity_singular: market_data_provider
#+entity_plural: market_data_providers
#+entity_title: Market Data Provider
#+brief: Simulated market data provider a synthetic collection stands for: a vendor, an exchange, a broker, or a reference set.
#+created: 2026-10-11
#+updated: 2026-10-11

A catalogue of the providers whose market data the synthetic feeds simulate.
A system-scope collection names the provider it stands for, so the installation
can run a simulated Bloomberg, LSEG or CME once and every tenant reads it
as that provider's data. Every collection names its provider, so every feed has
one. A reference set such as the ORE examples is a provider of its own.

Every provider here is simulated, and the synthetic screens show it without a
mark, because everything on them is synthetic. Every source name a provider's feed
publishes on starts =synthetic.<provider code>.=, so a simulated feed is never read
as the real one. A real provider integration, when one comes, belongs in market data
and not in this catalogue.

Scoped to =ores.synthetic= (not =ores.refdata=) because only synthetic
generation uses it today, following the =yield_curve_process_type=
precedent. Managed by the system tenant.

** code
:PROPERTIES:
:type:      text
:cpp_type:  std::string
:primary_key: true
:END:

Unique provider code: lower case letters, digits, underscores and hyphens,
starting with a letter. It is the provider segment of a source name.

Examples: 'ore', 'bloomberg', 'lseg', 'cme'.

under the system tenant, and every tenant reads them, which
=:system_tenant_visible: true= states on the repository. The row-level security
policy still decides which system rows a tenant sees and who may write them.
