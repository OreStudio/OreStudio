#+title: How do I run the day_count_fraction_types commands from the shell?
#+description: Every command the day_count_fraction_types submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:day_count_fraction_types:

This file documents the day_count_fraction_types resource at the shell, one section per command. Every command is a subcommand of =day_count_fraction_types=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

:PROPERTIES:
:ID: EF5560BB-2E67-532C-BF95-E8A5625E4ACE

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example

#+end_example

It is addressed at =refdata.v1.day_count_fraction_types.list=.

#+name: day_count_fraction_types-list
#+begin_src ores-shell :tangle day_count_fraction_types-list.ores :exports none

** =set=
:PROPERTIES:
:ID: 7513EB05-9F66-59B6-8262-F8D7A8185190
