The compute grid verbs live in the shell's =compute= menu. They talk
to the ~ores.compute~ service over NATS; the domain shapes and table
renderers come from ~ores.compute.api~.

* Question

How do I download a compute job input from the shell?

* Answer

Log in as the system super admin, then run =compute download-input= with the workunit id and a destination directory. The command fetches the batch input bundle the workunit references from compute storage and unpacks the tar.gz into the destination.

#+name: download-compute-job-input
#+begin_src ores-shell :exports none
connect $ORES_NATS_URL
login super_admin@localhost Secure-Password-123
compute download-input $WORKUNIT_ID $DEST_DIR
logout
exit
#+end_src

#+begin_src sh :noweb yes :results output :wrap example
./ores.shell ${log_args} ${connect_args} << 'EOF'
<<download-compute-job-input>>
EOF
#+end_src

The workunit id comes from =compute list-workunits=; find the batch
external reference first, then the workunit within it.
