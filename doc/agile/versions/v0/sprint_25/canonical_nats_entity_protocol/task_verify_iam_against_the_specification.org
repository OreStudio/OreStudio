* Goal

Every IAM entity works end to end through the web client against the canonical protocol: each operation its screens offer is exercised against a provisioned deployment, and every defect the sweep finds is fixed.

The shell half of this proof landed with the conversion
([[id:D9A4776C-AB42-4461-8F2F-AD077C20716E][Adopt the canonical protocol in ores.iam]]): all 124 generated IAM
commands have a generated recipe, and 123 of them answered the live fleet. The
one deliberate exception is =reset reset-system=, which the model declares
destructive. What is left is the UI, which is why the story scopes this task to
=ores.web=.

* Acceptance

- Every IAM entity the web client offers a screen for is exercised against a provisioned deployment, for each operation the screen provides.
- The BFF routes and the entity descriptors agree with the protocol each one consumes: no route or screen addresses a subject or a page the models do not declare.
- Any IAM entity the protocol covers and the web client does not is named, with the reason it is absent.
- Every defect the sweep finds is fixed, or recorded with the reason it is not.
- The sweep and its results are recorded in the task.
