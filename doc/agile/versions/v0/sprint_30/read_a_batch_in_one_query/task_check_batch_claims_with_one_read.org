* Acceptance

- The repository template's batch write makes one read per chunk of keys, not one per row.
- A claim that fails still refuses the whole batch, and the store writes nothing.
- The 1,000-row put benchmark is measured before and after on the same environment.
- The regenerated repositories build, their suites pass, and the drift gate on the repository address is clean.
