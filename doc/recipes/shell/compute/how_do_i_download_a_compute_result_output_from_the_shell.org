The compute grid verbs live in the shell's =compute= menu. They talk
to the ~ores.compute~ service over NATS; the domain shapes and table
renderers come from ~ores.compute.api~.

* Question

How do I download a compute result output from the shell?

* Answer

Log in as the system super admin, then run =compute download-output= with the result id and a destination directory. The command fetches the output bundle the node uploaded with the result from compute storage and unpacks the tar.gz into the destination.

#+name: download-compute-result-output
#+begin_src ores-shell :exports none
connect $ORES_NATS_URL
login super_admin@localhost Secure-Password-123
compute download-output $RESULT_ID $DEST_DIR
logout
exit
#+end_src

#+begin_src sh :noweb yes :results output :wrap example
./ores.shell ${log_args} ${connect_args} << 'EOF'
<<download-compute-result-output>>
EOF
#+end_src

The result id comes from =compute list-results=; find the batch
external reference first, then the result within it.
