The refdata product taxonomy seed: one =insert ... values= row per class
the catalogue's =taxonomy= list declares, in display order, carrying the
prose the model holds for it. The script is idempotent, as the hand-written
one was, and it used to be the copy the whole repository read.

The ={{^last}}= idiom emits the separating comma on every row but the last,
as the sibling SQL archetypes do. ={{description_sql}}= is the class's prose
already folded onto one line and quote-doubled, so a class whose text
carries an apostrophe cannot break the literal.

variables and their semantics.
