#+title: Task: State which form each product takes
#+description: ORE carries a product in one of three forms: a native trade class with its own element, a ScriptedTrade subclass with a fixed element of its own, or the generic ScriptedTrade with a library script. The catalogue does not yet say which form a type takes, so a reader cannot tell where a product's element lives.

* Goal

Every routed type states the form ORE reads it as, and a test proves the element our export writes is the element ORE's schema declares for that trade type, so a product whose form we model differently from ORE fails loudly.

* Acceptance

- the catalogue states, per type, whether ORE reads it natively, through a scripted class of its own, or through the generic ScriptedTrade
- for every routed type, the element the export writes is the one ORE's schema declares, checked by a test
- the generic ScriptedTrade and its library scripts stay supported as a route of their own, so both forms a product can take are available
