* Summary

=ores.storage.service= is the process that lets a component reach storage over
the bus. It binds the operation set's subjects, authenticates the caller and
checks the operation's permission code before it acts, and calls
=ores.storage.core= to move the bytes.

* Inputs

- The bus endpoint and the service's own configuration.
- An authenticated request on one of the operation set's subjects.

* Outputs

- One reply per request, carrying the protocol's =result= and, where the
  operation returns data, the object's metadata or page.

* Entry points

- =src/main.cpp= — the process entry point.
- =include/ores.storage.service/messaging/registrar.hpp= — the handler registration.
