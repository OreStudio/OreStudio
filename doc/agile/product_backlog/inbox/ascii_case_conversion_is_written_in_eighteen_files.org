* What

Eighteen source files outside the tests convert ASCII case themselves, with a
loop such as =c >= 'a' && c <= 'z' ? char(c - 'a' + 'A') : c= or with
=std::toupper= and =std::tolower=. The new oresmd URI codec adds two more
copies (=lower= and =upper=). Add one pair of ASCII helpers to =ores.utility=,
for example =to_upper_ascii= and =to_lower_ascii=, and replace the copies.

* Why

Each copy is a few lines, but the copies differ: some use the C locale
functions, which depend on the process locale and take an =int= that must be
cast from =unsigned char= first, and some use explicit ASCII ranges. Market
codes, ORE tokens and URI keys are ASCII by contract, so one locale-free helper
states that once. The PR 2522 review raised it.
