* Goal

Every route reads its body into one string, so the storage upload holds the whole
object in memory. A route needs a way to say its body is a stream, and the session
needs a read loop that hands the chunks on instead of collecting them.

* Acceptance

- A route states where its body goes, and the session reads it with a parser that
  holds one chunk at a time.
- The chunks reach the sink on the executor that owns the socket, so the socket is
  never touched from the handler's thread.
- The per-route limit and the ceiling apply unchanged, and a declared or chunked
  body past them is answered 413.
- A body that stops arriving is closed on the stream's deadline and its worker
  returns.
- A buffered route behaves exactly as it does today.
- A test streams more bytes than one chunk and reads back the same bytes.

* Plan

1. Add =domain::body_sink=: consume a chunk, finish the bytes, publish them to keep
   them, discard them otherwise.
2. Add =route::sink= as a factory, and a read loop in =http_session= that parses
   with =buffer_body=, hands each chunk to the sink, and reuses the limit and
   refusal path already there.
3. Give the handler the sink through =http_request=, so the existing handler
   signature and the generated route units are untouched.
4. Hold the chunk size in =http_server_options=, and let the session hold a guard
   that discards an unpublished sink.
5. Test the bytes, the limit, the stall, the destination's refusals and the
   buffered path.

* Notes

- One parser loop serves every route. It branches once, on whether a sink exists:
  the streamed route hands the chunk on, the buffered route appends it to a string.
- A body declared past the limit is refused before a sink exists, so nothing is
  taken and nothing is discarded. A body that runs past it mid-stream is taken in
  part and then discarded, which the chunked case covers.
- The stream applies its timeout to every read, so a stalled body is closed without
  the session setting a second deadline. That was measured: with the per-chunk arm
  removed the stall case still passes, and the arm was removed.
- =ores.trading='s generated batch header lost the bond members on =main=, so
  =ores.synthetic= does not compile and =ores.http.core= cannot be built without
  it. The header was restored from =b3a78b33ba^= for the build and the change was
  reverted; the fix is with the environment that owns the batch.
