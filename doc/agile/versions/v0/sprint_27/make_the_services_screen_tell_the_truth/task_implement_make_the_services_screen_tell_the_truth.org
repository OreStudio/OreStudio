* Result

The web service now publishes the heartbeat the other services publish, on telemetry.v1.ops.service_heartbeat, once at start and every fifteen seconds. It reports the name ores.web.service, a per-process instance id, an empty host and the release the project declares (0.0.27). The transport gained an optional publish, the client gained publishServiceHeartbeat, and a new heartbeat module in the BFF owns the timer. A failed publish logs once when it starts and once when it ends. The registry received the beat from the running service, which shows its NATS identity may publish on that subject. The wire-protocol, bff and web packages pass 168, 364 and 629 tests, and the format check is clean. I did not look at the services screen in a browser.
