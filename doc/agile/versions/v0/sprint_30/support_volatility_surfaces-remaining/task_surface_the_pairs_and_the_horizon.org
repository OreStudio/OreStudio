* Plan

What bounds the surface set today, measured on a freshly provisioned environment:

1. The catalogue. The system tenant holds ten blueprints, seeded by
   =projects/ores.seeder/datasets/fx_vol_surfaces/generate_sql.py= from a fixed =PAIRS= list of
   ten majors. Provisioning copies those ten into each party. Nothing else limits the count.
2. The quotes. The derived source's universe is its vendor inventory, seeded by
   =projects/ores.sql/populate/marketdata/marketdata_derived_catalogue_populate.sql= from the
   same ten pairs and eight expiries (1W to 2Y), so it publishes 10 x 8 x 5 = 400 quotes.
3. The horizon. A surface's grid expiry must be a tenor the forward ladder publishes a row for.
   The ladder's standard tenors end at 5Y, so 5Y is the ceiling today; beyond it the calibration
   refuses the expiry by name, which is the rule the previous task established.
4. The discounting. Not a constraint: the funding curves bootstrap pillars to 3M, 6M, 12M, 2Y,
   5Y, 10Y and 30Y, so a forward is priced at 10Y as readily as at 6M.
5. The forwards. Not a constraint either: 39 pairs already publish a forward set for every party.

Steps:

- Add 3Y, 7Y and 10Y to the ladder's standard tenors, so the grid can reach 10Y. 10Y is where the
  market convention stops (FX volatility is quoted to 10Y); the curve pillars reach 30Y, so the
  forward side is not what would stop a 30Y grid, the quote convention is.
- Extend the derived source's inventory to the same pairs and expiries.
- Extend the seeder's =PAIRS= to the 39 pairs that carry a ladder, each with its own convention's
  short-dated delta type, and its =EXPIRIES= to the ladder's list.
- Regenerate the dataset SQL, recreate the database, provision a tenant, and check that every
  party has a surface for every pair, with the 10Y grid expiry present and the fit converged.

Open question for the pairs whose convention switches delta type at 2Y (USD/JPY, EUR/CZK and the
rest): the blueprint states one delta type for its output strikes while the calibration resolves
the pair's convention per expiry. A grid that reaches past the switch states a strike type the
long expiry does not use. To be settled while implementing.
