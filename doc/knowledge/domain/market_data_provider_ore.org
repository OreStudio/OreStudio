* Summary

ORE, the Open Source Risk Engine, is a provider whose notation is open. An ORE quote key is a slash delimited string such as =FX/RATE/EUR/USD=, and each key has one value. The provider code is =ore=. Its sources are =ore-import=, which replays a market data file, and =ore-simulated=.

* Detail

** The id scheme

The scheme code is =ore_key=. A key has the form =TYPE/SUBTYPE/dim1/.../dimN=. The number and meaning of the dimensions depend on the type. The format is defined by ORE's open source code and by the =marketdata.csv= files in its Examples directory.

** The field

A key has one value, so the field is =value=.

** On the wire

An adapter of this provider sends the tick fields below. See [[id:97208391-AE4B-4032-9744-8F8B228FD567][The adapter subjects]] for the subject.

| Tick field | Example |
|------------+---------|
| id scheme | =ore_key= |
| external id | =FX/RATE/EUR/USD= |
| field | =value= |
| value | =1.0842= (decimal text) |

The ingress subject token for the id is =FX%2FRATE%2FEUR%2FUSD=. The service never decodes the token. It reads the id from the payload.

** The mapping

=ore_key= / =FX/RATE/EUR/USD= / =value= maps to =oresmd://fx/EUR?type=quote&instrument=fx_spot&quote=rate&ccy=USD=. This mapping is nearly mechanical, because the oresmd identity grew out of the ORE key. The import of an ORE market data file uses it, and the series it creates belong to the provider =ore=.

** Minted ids

None. Every ORE key is defined by ORE itself.

** What the simulator does

The source =ore-simulated= publishes ticks with =ore_key= for the keys of a market data file. It has the same shape as the simulated source of any other provider.
