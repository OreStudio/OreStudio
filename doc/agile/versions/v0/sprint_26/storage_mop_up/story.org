* Goal

Three leftovers the storage work surfaced are closed or accounted for.

The first is a provisioning gap that reads like a permission gap. A tenant admin
provisioned against a fresh database cannot use the raw shell surface, and the
obvious reading is that tenant roles lack =storage::objects:*=. They do not:
=TenantAdmin= holds the global =*= permission. The account simply has no role,
because =provision tenant= creates it and assigns none.

The second is the state a retired bucket leaves behind. The store creates a
bucket on first write and never collects one, so the protocol migration left
directories nothing reads.

The third turned out not to be a mop-up at all. The ORE import's trade saves
fail, and the cause is that no instrument can be saved through the trading
service: the write structs carry no audit and no handler stamps one. That is a
generated-surface change, and it belongs to the work that is regenerating that
surface.

* Decisions

- *Fix the provisioning, not the permission.* The temptation was to grant
  =storage::objects:*= to a tenant role. That would have widened access to a
  bucket with no per-tenant isolation to fix a bug that is not about access:
  =TenantAdmin= already holds =*=. The assignment is the defect.
- *A missing role fails loudly.* The handler logs at error level when it cannot
  find =TenantAdmin=, rather than returning success quietly, because an admin
  without a role holds no permissions and the journey then fails far from its
  cause.
- *The instrument audit is left to the trading regeneration.* Both candidate
  fixes are coherent, and one of them regenerates the whole instrument protocol
  surface, which another environment is regenerating now. Recorded with the
  choice still open.

* Out of scope

- The instrument-audit fix itself, for the reason above.
- Backfilling roles on tenants provisioned before this change. The task Result
  names the remedy.
- The credit-instrument tenor check the same import run hits. It refuses a CDS
  from the sample portfolio, which is a data question about that instrument.
