Directory for the engine package cache.

package and the rest wait for it.

** claim_poll_seconds
:PROPERTIES:
:cpp_type: std::uint32_t
:default_value: 5
:END:

Seconds between requests for work while the node is idle and hears no notice.

The service rings a doorbell when it queues work, so an idle node asks at once. The
poll is the fallback for a notice that was lost, and it is spread by jitter.

** telemetry_interval_seconds
:PROPERTIES:
:cpp_type: std::uint32_t
:default_value: 30
:END:

Interval in seconds between telemetry node-sample publishes.

Set to 0 to disable telemetry publishing entirely.

Base URL of the HTTP server for file transfers (e.g. http://localhost:8080).
