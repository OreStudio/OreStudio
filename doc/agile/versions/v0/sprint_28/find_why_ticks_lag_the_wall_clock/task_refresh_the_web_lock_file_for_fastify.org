* Result

The lock file of =projects/ores.web= now agrees with the package files. =npm install
--package-lock-only= changed three things and nothing else. Fastify goes from 5.12.5 to
5.12.6, with its new address and checksum. The entry of the bff package states fastify 5.12.6.
The range of vite in the lock file goes from =^8.3.4= to =8.3.4=, because =packages/web/package.json=
has pinned 8.3.4 since the Dependabot bump of vite. =npm ci --dry-run= reports no sync error. The
Linux release job of run 39959540017 failed at this step, and the local =web= check failed at it too.
