#+description: A structure that confirms as a whole is confirmed as one document, so its external version belongs to the deal. The structure table is immutable and holds no version, and its internal version is read from the legs. The model does not say where the deal's external version is stored or computed. A package does not need one, because each leg carries its own. Decide where the external version of a strategy, a typed structure and a dynamic structure lives, and add the read the structure page needs. The structure page prototype shows the external version of the deal, and says the table has no column for it.
