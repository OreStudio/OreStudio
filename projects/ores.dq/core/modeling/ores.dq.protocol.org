NATS messaging reference for [[id:D3A9F7C2-8B14-4E5D-A6C9-1F7E2B0D8C4A][ores.dq]]. All subjects use the
=dq.v1.>= namespace. See [[id:C9C24C99-F16C-45BE-A262-1C0F4502765E][ores.nats]] for transport details.

Each generated entity exposes the verbs =list=, =get=, =get_many=, =put=, =put_many=,
=delete=, and =delete_many=. Version history sits under the =<entity>_versions= prefix with
=list= and =get=. Read-only entities expose only =list=, =get=, and =get_many=. The entity
segment is the plural snake_case name, so a subject reads =dq.v1.<entity>.<verb>= or
=dq.v1.<entity>_versions.<verb>=.

Change notifications are published on =dq.v1.<entity>_events.<action>=, where the action is
=created=, =updated=, or =deleted=; see the Entity Change Events section.
