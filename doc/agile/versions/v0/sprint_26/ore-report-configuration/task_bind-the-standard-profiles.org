#+title: Task: Bind the standard profiles to the configuration entities that carry none
#+description: Solid Dirac's shell-surface census found that analytics' three stress-test entities render no shell unit because their models carry no :profile: at all. A repo-wide census found eight entity models authored from this environment with no profile binding, across analytics, refdata and reporting. Each one hand-authors a feature combination instead of naming it, so codegen cannot guarantee a known-good shape and no profile-enabled facet fires. Bind each entity to the catalogued profile its shape matches, drop the redundant per-feature declarations the profile now supplies, and regenerate. Do not touch the profile-less models owned by other environments; report them instead.
