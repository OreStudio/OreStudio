* Notes

- compass-85's v0.0.7 draft of =env_format.org= predated the pooler
  (7954155392, 3d29ef6c09), so it held 34 versions and no pooler or listener
  variables; =env generate= would have dropped them. compass-85 rebuilt it
  from main d81d470785 with versions 35 and 36 and re-ran its byte-identity
  proofs (=compass_v0.0.8_env/PROOF.md=): the same existing .env, from
  scratch (251 keys, secrets differ), and every option variant.
- Version 36 declares =ORES_TEST_LOG_ENABLED=, as the product owner decided.
  Regenerating a logging-enabled file now keeps it, where env_init.py dropped
  it.
- 2026-11-21, closed: compass-ng v0.0.9 lets a row's =when= compare, so the
  pooler-off rows are in the document. compass-85 proved it byte-identical to
  env_init.py with the pooler off, with PGPORT 5433 and with every option.
  On solid_dirac: pooler on regenerates with only the timestamp changed;
  pooler off writes all 18 database ports as 5432 and no listener lines. The
  pin moves to v0.0.9, which the document needs.
- Known gap (closed above), in compass: the document cannot express the pooler turned off,
  because a row's =when= only tests for empty. No environment or workflow sets
  =ORES_DB_POOLER_ENABLED=0= (all ten worktrees checked); compass-85 is adding
  a comparing =when= in v0.0.9.
- =current_version= keeps its name in env_init.py and now asks compass-ng, so
  compass_env_status.py, compass_db.py and the status test need no change.

* Result

=compass env configure= writes .env with compass-ng. Run on solid_dirac's
own .env (version 33): version 36, 252 variables; no variable removed and no
secret changed; the 93 added are versions 34 to 36 (pool settings, the
pooler and its listeners); each service's DB port moved to the pooler port,
as main's env_init.py would also do. =compass-ng env status= reports it
current. env_init.py is 587 lines, from 1126. The compass suite passes (559),
and the ratchet reports nothing new.
