* Summary

A prototype answers a question about layout or behaviour that a document
argues badly. It is throwaway: static files, mock data, no framework and no
backend. It exists so a design can be argued about with something concrete
in front of you.

This page is the index. Each entry opens the prototype, and names the page
that describes it.

* Adding a prototype

1. Put the static files under =doc/prototypes/<name>/=. Plain HTML, CSS and
   JavaScript. No build step.
2. Deploy them with one call to =ores-deploy-web-app= inside
   =ores-deploy-web-apps=, in =projects/ores.lisp/src/ores-build-site.el=.
3. Describe the prototype on a knowledge page beside this one.
4. Add a row to the table above.
