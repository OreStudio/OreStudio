* Decisions

- *Read the generated output, not the model.* =load_model= returns =columns=
  without the primary key and without the flag-derived members, and
  =** Table display= names those, so a rule stated over the model would fail on
  correct entities. The generated class is the authority on what a member is.
- *No baseline.* The tree the check lands on is clean, and the two defects it
  finds are small and local: a baseline would only hide the next one.
- *Every generated column reference names a column that exists.* Both rules are
  the same question asked of two surfaces, so they belong in one check rather
  than two.

* Out of scope

- The other free-text model sections. =** Checks= holds SQL expressions, so its
  columns are not separable from the expression the way an index's column list
  is; the database catches those on recreate.

Done. =check_generated_column_refs.py= is registered in the local check

Every acceptance criterion is met without a build: the check was run against
