* Result

A retention policy is data. The entity lives in the scheduler, which owns the
firing it rides on and already has the service and the screen it needs, following
the precedent that each component owns the policies it enforces.

The policy names the shape of its target rather than a table, so it survives a
table being replaced, and it carries the action, the period, the cadence and an
enabled flag. The SQL checks refuse an unknown kind, an unknown action and a
period of zero or less.

Regeneration produced the table, the domain type, the repository, the wire codec
and the presentation. One hand-written header needed an include it had always
relied on a neighbour for: the new entity changed the unity grouping, and the
missing =wire_traits= declaration surfaced.
