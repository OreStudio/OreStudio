* Enum brief

The `quote` query key for inflation instruments — the ORE TYPE. Inflation-only;
only meaningful when `type=quote`.

* Identifier brief

A fully-resolved oresmd identifier for an inflation instrument (asset_class=inflation).

* Requirement brief

A logical, possibly-partial oresmd requirement for an inflation instrument.
