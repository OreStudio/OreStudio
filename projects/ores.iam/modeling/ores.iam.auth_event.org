#+entity_title: Auth Event
#+brief: One authentication event: a login, a failed attempt, a logout, a token refresh, a rejected refresh, a tenant entered or left, or a signup; a TimescaleDB hypertable partitioned by event_time.
#+created: 2026-10-13
#+updated: 2026-10-13

One row per authentication event. The rows are append-only, so the model states
=:current_state:=: an event is a fact about an instant, and the bi-temporal pair
has no meaning on it.

The table is the audit log of who signed in and who failed to. Its =tenant_id=
is an ordinary text column and not the generated kind, because an event can
happen before a tenant is known, and it is then the system tenant's. The read in
=ores.iam.auth_event_operations= scopes on that column itself.

The table is internal: its protocol, handler and shell commands are the
hand-written operation model's, so only the data layer and the SQL schema are
generated here.

The table is isolated by tenant like the rest of IAM, by a policy in
=iam_rls_policies_create.sql=. An event that names no tenant is the system
tenant's. The hourly and daily continuous aggregates it once had are gone:
nothing read them, and TimescaleDB does not build a continuous aggregate over a
table with row-level security.

* Columns

** id
:PROPERTIES:
:type:            text
:cpp_type:        std::string
:primary_key:     true
:skip_uuid_check: true
:END:

The event's id, a uuid in its text form. It sits in the primary key beside the
partition column.

** event_time
:PROPERTIES:
:type:        timestamp with time zone
:cpp_type:    std::chrono::system_clock::time_point
:primary_key: true
:nullable:    false
:END:

When the event happened. The partition column.

** tenant_id
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:default:  ''
:END:

The tenant the event belongs to, in its text form. Empty when the event came
before a tenant was resolved, such as a failed login.

** account_id
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:default:  ''
:END:

The account the event is about, in its text form. Empty when unknown.

** event_type
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:END:

What happened: login_success, login_failure, logout, token_refresh,
max_session_exceeded, tenant_entered, tenant_left, signup_success or
signup_failure.

** username
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:default:  ''
:END:

The username the event names. Empty for an event with no resolved account.

** session_id
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:default:  ''
:END:

The session the event belongs to. Empty when no session was established.

** party_id
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:default:  ''
:END:

The party chosen at sign-in. Empty when none was.

** error_detail
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:default:  ''
:END:

Why a failure failed. Empty for a success.
