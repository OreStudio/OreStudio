* What

The publish bundle verb refuses a caller the bundle's level does not admit, so
no tenant can publish a world catalogue into itself through it. The publish
datasets verb is the second door: it names datasets and publishes them into the
caller's tenant, and a dataset row carries no level. A tenant administrator
holding =dq::datasets:write= can therefore publish the calendars, the countries
or the currencies into its own tenant and recreate the second copy the model
forbids.

* Why

The level was given to the bundle, which is the unit a person runs. It needs to
reach the dataset, because the dataset is the unit a dependency closure and a
direct publication name. The likely home is the dataset's artefact type, which
already names the target table and the subject, or a level column on
=ores_dq_datasets_tbl= that agrees with the bundles that carry it.

The rule a fix must keep: a dataset may belong to two bundles only when they
share a level, so the dataset's own level is well defined. A platform or world
dataset publishes only into the system tenant; a tenant dataset into the tenant
that asked.
