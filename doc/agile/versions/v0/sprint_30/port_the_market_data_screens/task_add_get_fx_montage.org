* Acceptance

- The response states base_currency, as_of and change_since.
- A pair whose base is on the quote side is included.
- A provider that does not quote a pair is absent from that pair.
- change_pct is measured from change_since and is absent when there is no
  price at it.
- day_high and day_low cover the same window and are absent when there is no
  window.
- Pairs are ordered by pair name.
