* Acceptance

- Each deleted script has a compass codec that gave the same verdict on main for at least one week of merges.
- The baseline files and their readers are deleted.
- local_checks.py lists only the gates compass does not cover.
- The compass repository's Retire legacy tooling targets table is updated for each removal.
- Exception reasons that name a retired baseline file or script name what stays instead.
- Until this task lands, a new accepted violation goes both into a compass exception and into the baseline its Python gate reads, so the fallback agrees.

* Plan

(Implementation strategy. Written when work starts; key decisions
are distilled into the parent story's =* Decisions= at close, but the
plan itself stays — it is the historical record of what we did.)

compass-85 sorted the scripts into four tiers, from ORE main at 732fc2ee34:

1. Deletable now: no caller outside the set. This branch.
2. Called only by a GitHub workflow: switch or remove the workflow first.
3. Still called by other code (=check_clean_standard.sh=, the CMake unity
   exclusions, generators feeding generators): move the caller first.
4. The Python generator and its 140 tests: after the =compass codegen= verbs
   forward to compass-ng and =env_init.py= and =systemd_generate.py= stop
   importing it.

Each tier is checked against compass-ng itself before it goes: a full
=compass-ng check= and =compass-ng diff= on the branch, because some scripts
are inputs to compass-ng rather than gates.
