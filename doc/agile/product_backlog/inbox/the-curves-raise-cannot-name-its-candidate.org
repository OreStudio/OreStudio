#+description: The raise page refuses a subject of another party, a missing candidate, a failed blocking check, a second open request and a candidate older than the live set. The curve has none: its bootstrap runs at the apply and a request whose inputs have not arrived is deferred, so a decider approves no version and the request names nothing checkable. Closing this moves the curve's compute before its raise, which changes the deferred path, or relaxes the page to say that a kind with no candidate answers no candidate checks.
