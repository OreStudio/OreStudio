Minting a storage capability. A capability is a signed, short-lived token
whose claims name the buckets, key prefixes and operations its holder may use.
It exists so a worker node reaches the objects of one assignment and nothing
else, and so the storage service answers an object-scoped question without a
permission lookup. [[id:F37D960D-9687-47DC-8737-605CA38D0CF2][Storage policy]]
states the rules.

The grants reuse [[id:4E0D934A-21D4-4609-8B7C-29F6D9A6A52D][the claims the token
carries]], so a caller builds the same row the verifier reads and no second
shape has to be kept in step.
