* Result

About 230 analytic parameter texts are deeper. Each one now says what the parameter decides, what its values do or what it changes in the results, when to change it, and an example where one helps. The median description grew from 193 to 289 characters, and the number of descriptions under 200 characters fell from 276 to 47.

The 47 that stay short are the parameters that ORE ignores or no longer reads. A longer text for them would be padding, so they say plainly that ORE ignores them.

The facts come from the ORE user guide, the example files and the ORE source at tag v1.8.17.0. Where the source did not settle a point, the text says less. A reviewer who knows ORE should still read the texts for the capital and margin analytics.
