* Notes

** Why it was wrong

=build_group= is handed to =ctest_start()=, which decides the CDash group
the build lands in. macOS and Windows were continuous when that value was
written, and renaming the workflows to nightly left it behind, so CDash
filed nightly platform builds under Continuous.

** The Site group is not a defect

=site-cdash.yml= passes =build_group=Site=, but to =CTestSite.cmake=, which
accepts it. =CTest.cmake= would reject it, and nothing passes Site to that
script.
