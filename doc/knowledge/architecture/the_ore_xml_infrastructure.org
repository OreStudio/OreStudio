* Summary

This is the index to the notes that describe how an ORE XML file reaches the
database and how it comes back. Each note states one idea and links to the
others; the diagrams are PlantUML beside the note.

The three layers:

- *Presentation*: an ORE document family is read by a *projection*, which binds
  the XML into a typed model and maps it to rows.
- *Identity and rule*: the mapping tables state which ORE element a row is, and
  the value sets state what values that element accepts.
- *Enforcement*: one database function per parameter family refuses a value no
  set states, and the write path calls it.
