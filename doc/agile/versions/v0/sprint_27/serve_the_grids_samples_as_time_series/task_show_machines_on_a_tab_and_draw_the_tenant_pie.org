* Result

The grid screen has a Machines tab, and the Overview holds the charts alone. The Usage tab draws a pie of the share of the results for each tenant, or each party for a tenant administrator, with the smallest groups folded into Others. The gap note about a node with no host row is gone, because the node table tags such a node. The note that the charts count one tenant stays, because the stats function still filters by one tenant and every grid sample is stored under the system tenant. The web suite passes (124 files, 1417 tests).
