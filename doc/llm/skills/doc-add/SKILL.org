* When to use this skill

Creating a document. Every type follows the same four beats — scaffold, fill,
wire, commit — so this is one skill and a table, and the table says what
differs per type.

This verb creates the artefact and nothing else. Picking up a unit of work is
=agile-start-task=: that one branches, stamps the journal, and moves state.

* How to use this skill

1. /Pick the type/. Unsure which document a thing is? Take the first match in
   the placement procedure in
   [[id:7D779BB3-BBEF-40D2-B6AC-E02BCA72AB85][Skill naming conventions]].
   Then find its row in the table below.

2. /Scaffold it/ with the row's command. Compass fills the frontmatter and
   generates the =:ID:=, so never hand-write either.

   #+begin_src sh :results verbatim
   ./projects/ores.compass/compass.sh add knowledge --slug my_topic --title "My topic"
   #+end_src

   The row's /Lands in/ column says where it goes. Where that column names a
   default, compass derives the parent from where you are, and =--parent-dir=
   overrides it.

3. /Fill every section/ the row names. A scaffold left with its placeholder
   prose is worse than no document: it reads as content and says nothing.
   Use the real generated =:ID:= values in any links you add.

4. /Wire the parent index/. A document nothing links to is invisible to
   search and to the graph, whatever its content. A story wires into the
   sprint's =* Stories= table, a task into its story's =* Tasks= table,
   knowledge into its topic index, a recipe into its topic page.

5. /Commit/ per [[id:F4B1A670-3B02-11F1-BCE2-4B06F4BBA5D9][commit conventions]], with the component
   bracket the type calls for: =[agile]= for a story or task, the bucket name
   for a capture, =[doc]= for the rest.

Some types are worth their own skill because their procedure genuinely
differs, not because their artefact does: writing a memory is mostly the
judgement of whether to write one at all
([[id:7357C672-A49F-4974-9399-A166F761D222][doc-add-memory]]), a recipe
carries a testable script ([[id:28AAF9A6-B1E4-402A-83BB-289090990FB8][doc-add-recipe]]),
and a skill has registers to parse and a bundle to rebuild
([[id:4B6536DF-56B6-A634-C7FB-FA3CF51E916D][skill-add]]).
