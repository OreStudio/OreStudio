Reference data table defining the closed price quotation set of a bond
option or total return swap. The set is the ORE =bondPriceType= simple
type under =external/ore/xsd/ore_types.xsd=.

The values are the ORE XSD spellings, so a stored value round-trips through the
ORE XML unchanged. No conversion is introduced here.
