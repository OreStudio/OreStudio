#+title: One spelling for an asset class code
#+description: The conventions screen groups by interest-rates; both the refdata and the badge catalogues store interest_rates. A hyphen and an underscore are two codes where there should be one. Find every place that derives a class code from a display name or a slug and make it read the catalogue.

* What

One asset class has three codes. The catalogues store =interest_rates=, the convention kinds store =interest-rates=, and the screens show *Interest Rate*. The same holds for the other classes. A reader that joins or filters on the wrong spelling finds nothing and reports no error, only an empty group.

Pick the canonical code, store it, and make every screen read the code from the catalogue rather than deriving one from a display name, a label or a route slug.

* Why

Found on 2026-10-31 while giving the trade blotter its class rail. The rail keys its groups on catalogue codes; the conventions screens key theirs on the hyphenated value in =refdata_convention_kinds_populate.sql=. No screen joins the two today, so nothing breaks. It breaks on the first filter that crosses them, and it breaks quietly.
