* Plan

=fl::offset= becomes =fl::spread_offset=. The field enum in
=ores.marketdata.api/datum/schema.hpp= declares =spread_offset= and no =offset=,
and =market_series_identity.hpp= records why: =offset= is a reserved word in
PostgreSQL and the identity column the generator writes takes the qualified
name. The JSON key the case assigns is a separate string and stays =offset=,
which is ORE's own spelling of the key.
