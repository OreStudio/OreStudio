The DSH sandbox grants write access to the shared bare repository =/mnt/development/OreStudio/ores.git=. Git commands work in every worktree without approval. All other paths outside the workspace stay read-only. The =write= and =edit= tools cannot write to =ores.git=; use git commands for changes there. A =read-only= session has no access.

*Why:* Git operations failed with 'Read-only file system' because the shared git directory sits outside the workspace, and the agent had to request an escalation for every fetch, branch and commit.

*How to apply:* Run git commands directly, with no sandbox escalation. Do not hand-edit anything under =ores.git=: the file tools cannot write there. Keep every other outside-workspace path read-only.
