* Goal

Make a repeated command registration fail a check, not the first shell a person
opens. The shell is how a tenant is provisioned, so a start-up break stops every
test that needs a tenant.

* Acceptance

- A check reports a unit an aggregator registers twice.
- A check reports a menu name two units build.

* Plan

2. Wire the check into the local checks, so a pull request runs it.
3. Prove it on the merge that broke the shell and on main, which is clean.

* Notes

=20a6ec0707= and =ef5800d37a= each wired the legal entity unit, from two
branches, and #4107 removed the second registration from main. The guard that
raised the error already lived in =shell_root_menu=, so the defect was known and
stated; what was missing was a reader of that statement before start-up.

The check skips a =tests= directory, because a test file registers a unit once
per test case, into a menu of its own.

* Result

Two rules now run on every pull request: a menu name is built by one unit, and
an aggregator names each unit once. The check reports the merge that broke the
shell and reports nothing on main.
