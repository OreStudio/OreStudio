This page is a [[id:671F18E4-E09C-4B3B-BD24-D33DF8AE38A6][capture]] in the *inbox* bucket of the product backlog — a pre-sprint idea, not yet pulled into a sprint as a story.

* What

Fourteen journey documents carry a Prototype section that names where the
accepted prototype lives:

: Source :: =projects/ores.web/packages/web/src/prototype/= on =main=; the hub at =/prototype= lists every prototype route

Both parts are stale. That directory no longer exists. The prototypes moved
to =doc/prototypes/=, one directory per prototype, with the hub at
=doc/prototypes/index.org= and no =/prototype= route.

* Why

The Prototype section is the design record's pointer to the artefact the
user accepted. A reader who follows it finds nothing, and cannot tell
whether the prototype was deleted or moved. The credentials and operations
journeys were written before the move and were not updated with it.

* Resolution

Fixed on 2026-10-08 by
[[id:4BC92424-C73B-4E74-ABEA-5F0A979AD91C][Group the prototypes and add the
Gemini reviews]]. Eleven journey documents named the moved tree; each now
names =doc/prototypes/<group>/<name>/index.html= and opens the built page. The
=Route= lines are gone, because no =/prototype= route exists, and a variant
that only the route carried is kept as =Accepted variant=. This capture is
done and can be closed.
