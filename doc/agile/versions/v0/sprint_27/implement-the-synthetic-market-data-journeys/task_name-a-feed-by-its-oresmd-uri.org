* Goal

An FX feed names the datum it simulates by its ORE key (fx_spot_generation_config.ore_key, e.g. FX/RATE/EUR/USD). The feed turns that key into an oresmd URI at run time (fx_spot_feed.cpp) and the market data ingest turns it back (tick_plan.cpp). ORE keys are an import format, not our identity: the feed should hold the oresmd URI (or the series identity the resolver takes), the web screen should show and pick it as the identity, and the ORE key should be derived for export only. This also lets the feed screen read the feed's stored ticks through the series reads (get_series_slice, get_series_evolution), which take the oresmd identity.
