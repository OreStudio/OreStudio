  =--source acme= run completed with no failed steps). The party
  =ACMCOR= (Acme Corporation Plc) carries a pre-populated
  =image_id= (=9cbca3dc-b351-4b4e-8cdf-3e77505f5582=) — verified via
  =compass sql -- -c "select short_code, full_name, image_id from
  ores_refdata_parties_tbl where image_id is not null;"= — and is the
  fixture this scenario uses for the pre-populated case.
- The build must include the fix under test: =setCounterparty()= /
  =setParty()= now call =updateFlagDisplay()= after loading the
  entity (=CounterpartyDetailDialog.cpp=, =PartyDetailDialog.cpp=).
  Confirm via =compass build ores.qt.exe=.
- Services must be running (=compass services start=) and the client
  launched against this scenario doc.
