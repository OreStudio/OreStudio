#+title: How do I add a compute batch from the shell?
#+description: Create a compute batch with an external reference and a job count from the shell; --smoke bounds the count to the grid smoke-test range (10 to 20 jobs).
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:compute:batch:
#+created: 2026-08-11
#+updated: 2026-08-11

The compute grid verbs live in the shell's =compute= menu. They talk
to the ~ores.compute~ service over NATS; the domain shapes and table
renderers come from ~ores.compute.api~.

* Question

How do I add a compute batch from the shell?

* Answer

Log in as the system super admin (principals are =username@hostname=),
then run =compute add-batch= with the batch external reference and the
number of jobs. The external reference is the script-friendly handle
you use to dispatch and watch the batch later.

#+name: add-compute-batch
#+begin_src ores-shell :exports none
connect $ORES_NATS_URL
login super_admin@localhost Secure-Password-123
compute add-batch $BATCH_REF 10 --smoke
logout
exit
#+end_src

#+begin_src sh :noweb yes :results output :wrap example
./ores.shell ${log_args} ${connect_args} << 'EOF'
<<add-compute-batch>>
EOF
#+end_src

The command prints the created batch id. The job count is session
knowledge: the batch row stores no count, so you pass it again at
=compute dispatch-batch=. The =--smoke= switch bounds the count to the
grid smoke-test range (10 to 20 jobs).
