* Result

Every operation that acts on an entity without being one of the eight moved to
={component}.v1.ops.{operation}=, named for the request message the model
already declares, which is the shape =reporting.v1.ops.trigger_report_instance=
and =variability.v1.ops.clear_bootstrap_mode= already follow. The three-segment
subjects that had no resource at all -- =workflow.v1.start=,
=marketdata.v1.tick=, =scheduler.v1.status= -- went with them.

The HTTP projection moved with the subjects, because a route is derived from
its subject: =/api/v1/iam/auth/login= is now =/api/v1/iam/ops/login=, and the
tangled =hurl= scripts and the shell scripts follow.
