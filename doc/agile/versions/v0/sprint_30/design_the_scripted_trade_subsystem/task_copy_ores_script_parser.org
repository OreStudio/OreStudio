* Goal

ores.trading.scripting holds ORE's script grammar, syntax tree, printer, static analysis and random syntax tree generator, copied with ORE's authorship, diffable against ORE's files and linking no QuantLib, and offers parse, inputs_of and print.

* Acceptance

- the sub-component sits below ores.trading.api and depends only on ores.utility, ores.platform and Boost Spirit; the component catalogue lists it
- every copied file keeps ORE's copyright header and names the ORE commit it was copied from, and a script diffs the copy against ORE's files at that commit
- parse returns ORE's error with its line and column, and every script of the library parses
- inputs_of agrees with the library's stored inputs for every script, and each difference is explained
