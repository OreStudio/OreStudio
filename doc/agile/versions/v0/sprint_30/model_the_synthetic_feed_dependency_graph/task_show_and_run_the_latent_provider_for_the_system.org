* Acceptance

- The system tenant sees Latent on the Provider tab and the dashboard; a tenant does not.
- Latent has a description in the synthetic provider list.
- Start and Stop of a provider with no source of its own stop and start its feeds as graph nodes, with one reason.
- Every neighbour on a Graph tab is a styled link: a feed to its page, a view to its surface's Graph tab, a source to its provider.
