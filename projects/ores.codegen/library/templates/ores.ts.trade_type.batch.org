The TypeScript twin of [[id:4c843ca3-122a-4fe0-875d-149bd5aea924][ores.cpp.trade_type.batch]]: one interface whose members
are the batch's arrays. Both read the same trade-type catalogue, so a member
added to one appears in the other.

Each member's element type is the interface =ores.ts.domain= emits for that
type, imported from the domain module beside it. Field names stay in the C++
spelling, because they are the JSON keys =rfl::json= writes.
