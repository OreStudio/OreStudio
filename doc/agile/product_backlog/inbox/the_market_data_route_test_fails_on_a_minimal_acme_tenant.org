* What

=marketdata_route_visibility_test.sql= picks the first tenant that people
set up and asserts that it holds market data routes and subscriptions. On a
database provisioned from =acme_minimal=, which subscribes no market data,
tests 8 and 10 fail. On an unprovisioned database the test skips them and
passes.

* Why

A test that passes or fails by which profile provisioned the database
does not test the routes' visibility. It should find a tenant that holds
routes, or skip when none does.
