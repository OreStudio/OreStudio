One view per family header that maps a date. Each view gives the deal grid the
same date columns, in the order the catalogue's =* Common dates= table lists
them, whatever name a product states a date under. A date the family does not
state reads as null.

The view joins the header to each table that states a date and to the table
that holds a shared date, on the tenant and the trade. It keeps the current
version of every row. It is =security_invoker=, so the tenant policy of each
table decides what the reading session sees.
