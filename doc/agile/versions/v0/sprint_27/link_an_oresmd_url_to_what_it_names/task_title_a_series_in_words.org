* Goal

Today the series page and the Evolution picker title a series with its raw identity, joined by slashes. The reader has to know the oresmd grammar to read it. The C++ schema table gets a title template for each instrument type and quote type, and the schema operation sends it. The web code fills the template and holds no instrument names.

* Result

The oresmd schema table has a title for each of the 45 instrument types and words for each of the 17 quote types. =describe_oresmd_schema= sends them as =title= on each instrument and =quote_titles= beside =quotes=. The web fills the braces from the series identity, so the AUD/USD spot series reads =AUD/USD spot rate=. An identity field the title does not name follows it as =name=value=. The series page, the Evolution picker, the Evolution notice and the Inspect dialog use the title, and a type the schema does not know keeps its raw identity. Checked in headless Chrome. A standalone program checked that every title names only fields of its own row. The Catch2 test for the same rule is built but was not run, because the test binary needs the database of this environment and an earlier full test run polluted it.
