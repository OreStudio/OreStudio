* Plan

The source is the =zettelkasten-luhmann= skill (daniloneto), a writing
assistant for a personal Markdown vault. It was read against
[[id:E3B70401-5142-4ACC-A61F-1BBF19F8470F][Zettelkasten]] and the corpus, and the
transferable parts were added to that page.

/Taken./ The thesis discipline, scoped to the pages that argue; the filing
decision and the four relations (contradicts, completes, exemplifies, answers);
the improbable neighbour; the anti-patterns.

/Not taken, and why./ The vault layout, templates, YAML frontmatter and fixed
English section headings describe a Markdown vault; this graph is =.org= files
addressable by UUID, and its mechanical conventions already exist. Fleeting and
daily notes have a counterpart in the capture backlog. "Never file
automatically" mostly does not apply: we automate only the mechanical back-link
a structure note needs, and never the semantic choice — which is the rule the
page now states, so the boundary is explicit rather than implied.

* Notes

The source skill's core is the cognitive half of Zettelkasten — a note is a
contestable claim, and the choice of where it is filed is the thought. This
graph already carries the structural half well: UUID addresses, a link graph,
argued structure notes, and checks that every ordered page links back. The page
had no statement of the cognitive half, so an agent writing a page had no rule
for whether it must argue, no vocabulary for the relation it joins, and no list
of what not to do. Those three gaps are what the change closes.
