#+description: Codegen operation model for the configuration documents refdata owns: save, get and delete a curve configuration document, and save and get the conventions.

#+brief: Refdata's ORE configuration documents as operations.
#+filetags: :model:operation:refdata:
#+created: 2026-10-04
#+updated: 2026-10-04

The configuration documents refdata owns, as operations: the curve
configuration and the conventions. Another service reaches them only through
these, never through refdata's tables. The handler stamps the session's party
on every row it stores.
