#+title: Cap C++ compilation builds at -j2
#+description: Use -j2 for C++ compilation; Emacs-only cmake targets need no cap
#+type: memory
#+memory_subtype: feedback
#+level: cross
#+filetags: :memory:feedback:
#+created: 2026-06-11
#+updated: 2026-11-11

Cap C++ compilation with a small -j through compass build <target>, never by calling make, ninja or cmake --build directly (see [[id:877BF897-FE27-4F45-8293-E207D23AC1F7][Never run builds with cmake directly]]). Never use -j $(nproc). Non-compilation doc targets (compass build --direct skills/site, or the equivalent cmake deploy_skills target) run directly without a -j cap.

*Why:* Machine crashed on full-tree make all -j$(nproc): Qt/shared-library link steps are memory-heavy. Emacs-only targets don't compile C++ so they carry no risk.

*How to apply:* For C++ compilation: always -j2. For compass build --direct skills, the cmake deploy_skills target, etc: run directly, no -j flag.
