* Summary

Seventeen ORE XML documents configure a report run. They carry 605 schema types,
which resolve to 265 entities, 178 embedded value types and 162 excluded
classes. Ten of the seventeen belong to a component that already models them or
should; seven have no model anywhere.

The inventory is extracted from the schemas rather than read by hand, and the
extractor is in the repository, so a schema change is a rerun.

The rule throughout: an entity is a root, a block that holds children, or a
keyed configuration node; a value type is a leaf carrying one scalar payload
with label attributes. Excluded means an anonymous container or inline companion
(43 in =curveconfig.xsd=, 2 in =conventions.xsd=), the =xs:any= wildcard in
=simmcalibration.xsd=, or the market-data subtree of =simulation.xsd=.
265 + 178 + 162 = 605.

** What is out of scope, and why

Market data, trades and observed data are excluded by the brief: =todaysmarket.xml=,
=portfolio.xml=, =instruments.xsd=, =scriptlibrary.xml=, =collateralbalance.xml=
and =intradaypowerloaddata.xsd=. They account for 271 further schema types, which
the extractor can render on request but which are not configuration.

The exclusion that is easy to miss is inside an in-scope document:
=simulation.xml= declares the market-data overrides the simulation market is
built from, under =market= and =market_*=, plus the curve algebra that reshapes
them. That is 116 classes — most of the document — and it is market data.

** Regenerating the inventory and the diagrams

#+begin_src sh
# The complete inventory and the class diagram of everything in scope.
python3 build/scripts/xsd_to_uml.py --format both --out-dir .audit/ore-taxonomy

# The entity-to-owner mapping, one row per modelled class.
python3 build/scripts/xsd_to_uml.py --format mapping --out-dir .audit/ore-taxonomy

# One document on its own, entities and blocks only.
python3 build/scripts/xsd_to_uml.py --entities-only --xsd sensitivity \
    --out-dir .audit/ore-taxonomy --out-name sensitivity.puml
#+end_src

The diagrams committed beside this page were produced by those commands and
rendered with =plantuml -tpng=. The extractor reads =external/ore/xsd= and needs
nothing else.
