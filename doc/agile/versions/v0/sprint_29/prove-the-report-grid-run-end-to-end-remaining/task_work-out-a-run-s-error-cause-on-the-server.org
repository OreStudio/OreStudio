#+title: Task: Work out a run's error cause on the server
#+description: The run page decided what an error was about by reading the engine's message in TypeScript: it took the curve name out of IndexCurve(...), matched trades to curves by substring, truncated sentences and chose a label per scope. The shell could not do any of it without a second copy, which is how the duplication showed.

The engine states a trade's curve only inside the message it writes, and the reporting service is where that format belongs. It now reads the cause once, where the log is read, stores it on the row, and both clients render it. The page's parsing is gone: it groups by the row's cause. The pricing date stays unrendered until the instance records it, which the earlier task's result already lists as remaining work.

* Result

The reporting service works out what each error is about, and both clients
render it.

=engine_log_error= carries a =cause=, worked out where the engine's log is read.
A curve's cause is its name, taken from the =curveId= the engine states; a
trade's is the curve its message names; an analytic's is its type; a
configuration's is its configuration type. Only the trade case reads the
message, and it does so in one place, with the engine's format written down in
a comment beside it.

The error event model gained =cause=, nullable, with its SQL, repository, entity
and TypeScript regenerated. The recorder stores it, and a failure the run
records for itself stores nothing, because it has no cause.

=ores.web= no longer reads the engine's words: =curveNameOf=, =asOfDateOf=,
=labelOf=, =firstSentenceOf= and the substring matching that attached trades to
curves are gone, and the page groups by the row's cause. The "priced at" line
went with them, because the date is a fact of the run that the instance does not
record yet; the earlier task's result already carries that.

Proven on a triggered run, instance =b83c3eb5=: the shell returned rows with
"cause":"Yield/GBP/GBP1D" and no parsing, and the page rendered the same four
curves, thirty-three errors and seventeen distinct reasons.
