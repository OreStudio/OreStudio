* Acceptance

- The MessagePack double reader accepts integer frames; a string or a boolean is still refused.
- Simulate and convert on the Price behaviour tab succeed against the deployed services.

* Plan

Testing GJR-GARCH on the Price behaviour tab showed every simulate and convert
request refused with "Not a number". The web encoder has one number type and packs
1.0 as the integer 1; the hand-written MessagePack reader accepted only a float
frame for a double. Accept integer frames in the reader, as the JSON reader does.
