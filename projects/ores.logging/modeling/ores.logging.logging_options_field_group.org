** include_pid
:PROPERTIES:
:cpp_type: bool
:default_value: false
:END:

If true, includes the process ID in the log filename.

When enabled, the filename is modified to include the PID before the
extension. For example: "app.log" becomes "app.12345.log".

** replica_index
:PROPERTIES:
:cpp_type: std::optional<int>
:END:

If set, embeds the replica index in the log filename before the
extension (and before the PID if include_pid is also set).

For example: "app.log" with replica_index=0 becomes "app.0.log".

** tag
:PROPERTIES:
:cpp_type: std::string
:END:

Tag to filter the logging. If supplied, only messages with this
tag will be logged.
