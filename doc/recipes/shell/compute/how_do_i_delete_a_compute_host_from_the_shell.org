#+title: How do I delete a compute host from the shell?
#+description: Remove a compute host row by id; the command refuses to delete a host that is online.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:compute:hosts:
#+created: 2026-08-11
#+updated: 2026-08-11

The compute grid verbs live in the shell's =compute= menu. They talk
to the ~ores.compute~ service over NATS; the domain shapes and table
renderers come from ~ores.compute.api~.

* Question

How do I delete a compute host from the shell?

* Answer

Log in as the system super admin, then run =compute delete-host= with the host id to remove the host row. The command refuses to delete a host that is online (it heartbeated within the 300 second (5 minute) heartbeat timeout); stop its wrapper first. An offline host row is removed.

#+name: delete-compute-host
#+begin_src ores-shell :exports none
connect $ORES_NATS_URL
login super_admin@localhost Secure-Password-123
compute delete-host $HOST_ID
logout
exit
#+end_src

#+begin_src sh :noweb yes :results output :wrap example
./ores.shell ${log_args} ${connect_args} << 'EOF'
<<delete-compute-host>>
EOF
#+end_src

The row is closed temporally: the current version gets a =valid_to=
stamp instead of being removed, so the grid history stays intact.
