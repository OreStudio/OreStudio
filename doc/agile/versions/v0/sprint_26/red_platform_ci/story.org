* Goal

Bring the Linux and Windows continuous builds on main back to green.

- Linux: the debug jobs hit GitHub's 6-hour job limit. The sccache hit
  rate is 0% for debug and 24-34% for release. The =Delete sccache entry=
  step fails with HTTP 403, because the repository's default token is
  read-only. The old entry stays, every save then fails with "Unable to
  reserve cache", and every =sccache-linux-*= entry dates from 2026-10-01.
- Windows clang: =environment_environment_tests.cpp= calls =std::getenv=,
  which clang-cl reports as deprecated; warnings are errors.
  =xml_example_coverage_tests.cpp= has the same call.
