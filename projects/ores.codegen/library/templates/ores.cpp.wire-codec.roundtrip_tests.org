The test file for one type's wire codec. It fills a value with
=ores::utility::codec::sample=, writes it, reads it back, and requires the
value it read to equal the value it wrote. It does this in JSON and in
MessagePack, for the sample and for the default value.

The sample sets every member away from its default, so a codec that drops a
member, writes it under the wrong name or reads it back as another value fails
here. The default value catches the opposite fault: a codec that cannot read
back an empty string, a nil id or the epoch.

See the [[id:C4E8A91F-3B7D-4F2E-85A6-1D9C7E3B2F4A][Template variable reference]] for the complete list of available
variables and their semantics.

* Mustache incantations

An entity and a junction go through =wire_traits=, which is the generated
translation unit the facet's =codec_impl= writes. A field group has no traits
of its own, because it crosses the wire only inside the entity that holds it,
so its test calls the struct codec directly on the group's =wire_fields=.

The sample fills only the members =wire_fields= names, so a roundtrip alone
cannot see a member the list leaves out: the sample leaves it at its default and
the codec reads the default back. A =static_assert= closes that gap. It compares
the struct's member count with the list's length, less ={{wire_left_out}}=, the
members the model marks =:no_wire:= on purpose.

Every case name and helper starts with the type's name. A component's test
files link into one binary and build as one unity unit, so without the prefix
two types in the same component declare each name twice.
