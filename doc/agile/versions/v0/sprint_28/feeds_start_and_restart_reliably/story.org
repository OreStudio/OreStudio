* Acceptance

- A restart with marketdata not yet running starts every auto-start feed once marketdata answers.
- A provision starts the system feeds without a restart.
- A person's Start of a feed creates the binding of the person's party.
- Reporting creates its run grant through the shared client call.
- Every feed group shows the documented behaviour across a stop and a start of the services.

* Decisions

- The =enabled= and =auto_start= flags stay the only stored form of the running set. A Start or a Stop by a person does not survive a restart.
- A restore tries again for every feed that fails, except a feed whose series another feed holds.
- A provision calls the restore as an operation, once, and never fails because of it.

* Out of scope

- Revoking a run grant when its collection is deleted. The delete is generated code that has no IAM call. Capture: revoke_a_collections_run_grant_on_delete.
- A check that the consenting person's party matches the collection's party.
