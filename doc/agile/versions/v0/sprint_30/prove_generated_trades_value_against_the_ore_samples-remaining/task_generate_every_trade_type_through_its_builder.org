* Acceptance

- =convention_lookup= answers what each family's builder asks: the CDS convention for credit, the equity and commodity underlyings for theirs. Moved here from [[id:4435202D-6074-47F6-8BEB-85E25CF70BEF][Look up an oresmd identifier's conventions and project it for ORE]].
- Each family's planner draws its values and calls the builders; its =construct_*= functions and =*_terms= structs are deleted.
- Each family's entries leave the recorded trades' known lists, its recorded files change in the same commit, and the lists end empty or with a stated reason per entry.
- A tagged test runs the ORE engine on each recorded portfolio, with ORE's example configuration, and fails on an error ORE raises reading or building a trade, unless a known list asserted exactly names it; a Trade error caused by missing market data is counted apart. Moved here from [[id:63FF92C8-3E18-49BB-93FA-B0862B5FD4B2][Test that every generated trade builds in ORE]].
- A run of the Acme reports after provisioning records no Trade errors, only market data errors.
- The roundtrip tests read every ORE sample trade of each generated type, write it back, and fail on any element ORE needs that we drop or rename.
- Tests catch the FxOption style and FxSwap far leg defects that the first Acme run found.

* Notes

** From the review of PR #4474

Points the review raised on the recorded-trades test and the writer, left
for this task because it edits both:

- =state_reason= in the writer skips a row with none of the three audit
  shapes without a word; end it with a =static_assert= so a new row type
  that fits none fails to compile.
- =known_refusals()= mixes writer refusals with the three bond types the
  in-memory path cannot join; split the test-only ones into a list of their
  own, so the case's name says what it asserts.
- =sample_requirements()= should =REQUIRE= the corpus directory, for a
  clear failure when =external/ore= is missing.
- The recorded files compare as exact text; check line endings
  (=.gitattributes= for =tests/data=) and number formatting on the Windows
  build.
