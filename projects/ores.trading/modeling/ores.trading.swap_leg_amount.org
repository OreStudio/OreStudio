One numbered amount of a swap leg: a notional the leg pays on, dated from
the day it applies. A leg whose notional amortises or accretes states one row
per step; a leg with a single notional states one row.

ORE states the notionals as a list on =legData/Notionals= and the dated
variation as =legData/Amortizations=. Both describe the same column, so both
land here: the import reads whichever the document states, and the export
writes the list back. The leg itself carries no notional, because a single
column cannot hold a schedule.

The row is a child of the leg rather than an entity with a life of its own:
=swap_leg= names the trade and the ordinal, and this row adds its own ordinal
within that leg.

** Custom repository methods

The trade read path fetches the notionals of many instruments' legs at once,
and no generated read covers that: the generated reads address one key group
at a time. The batch read below is one statement over the instrument set.

*** read_by_instruments_batch
:PROPERTIES:
:ID: 4C0BC117-F9DE-48AB-988E-CE8540B2DBA0
:END:

Reads every current notional of the given instruments' legs, ordered by
instrument, leg and sequence, in one statement. An empty input reads nothing.

#+begin_src cpp :name implementation :implements F2EB1914-5E94-42CA-9C77-46BDB364BF9E
std::vector<domain::swap_leg_amount>
swap_leg_amount_repository::read_by_instruments_batch(
    context ctx, const std::vector<std::string>& trade_ids) {
    if (trade_ids.empty())
        return {};
    static const auto max(make_timestamp(MAX_TIMESTAMP, lg()));
    const auto tid = ctx.tenant_id().to_string();
    const auto query = sqlgen::read<std::vector<swap_leg_amount_entity>> |
                       where("tenant_id"_c == tid &&
                             "trade_id"_c.in(trade_ids) && "valid_to"_c == max.value()) |
                       order_by("trade_id"_c, "leg_number"_c, "sequence_number"_c);
    return execute_read_query<swap_leg_amount_entity, domain::swap_leg_amount>(
        ctx,
        query,
        [](const auto& entities) { return swap_leg_amount_mapper::map(entities); },
        lg(),
        "Reading swap leg amounts for multiple instruments.");
}
