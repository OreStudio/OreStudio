The immutable identity of a deal assembled from several trades. It holds
what never changes for the deal's life: the party, the counterparty, the
kind of binding, the template it was shaped by, and its parent when it is
itself a leg of a larger deal.

It is the anchor of the composition ladder. The legs are not owned
children: a trade points at the structure that holds it, so the same trade
can be unlinked from one deal and linked to another without being
rewritten. The economics live on the legs, and the structure's internal
version is read from them rather than stored beside them.

A structure nests one level at most, because a deal inside a deal inside a
deal has no confirmation to hang on. The insert trigger enforces it.

* Insert trigger

#+begin_src sql :name one_level_of_nesting :implements d4e8e136-828d-440a-ba59-82ba2b9d3e2e
    -- Structures nest one level at most. A structure that has a parent is a
    -- leg of a larger deal, and a leg carries no legs of its own: the
    -- confirmation hangs on the deal the customer sees, and there is no
    -- second deal above it to confirm.
    if NEW.parent_structure_id is not null and exists (
        select 1 from ores_trading_structures_tbl
        where tenant_id = NEW.tenant_id
          and id = NEW.parent_structure_id
          and parent_structure_id is not null
    ) then
        raise exception 'Invalid parent_structure_id: %. The parent is itself a leg, and structures nest one level at most.',
            NEW.parent_structure_id
            using errcode = '23514';
    end if;

    -- A structure is not its own parent.
    if NEW.parent_structure_id = NEW.id then
        raise exception 'Invalid parent_structure_id: %. A structure cannot be its own parent.',
            NEW.parent_structure_id
            using errcode = '23514';
    end if;
#+end_src

** Custom repository methods

** Naming a structure

A structure is grouped before anybody can book a leg into it, so the grouping
is where it needs a name: every write gives a structure that has no internal
reference one. The service names it after the repository writes the row.

#+begin_src cpp :name service_includes :implements A7D3F1E2-8C5B-4A2F-B9E0-3D6C1A8F4B2E
#include "ores.trading.api/domain/structure_identifier.hpp"
#include "ores.trading.core/repository/structure_identifier_repository.hpp"
#+end_src

#+begin_src cpp :name naming_helpers :implements ED2E71EE-7410-4696-A732-C09D67DCA1E9

/**
 * @brief The prefix a deal reference carries for a kind of structure.
 *
 * The desk reads a reference and knows what it is looking at, so the prefix is
 * the kind's and not a house-wide one. An unknown kind takes the structure
 * prefix rather than no prefix at all: a reference is what makes a deal
 * addressable, and a missing one is worse than an approximate one.
 */
std::string reference_prefix(const std::string& kind) {
    if (kind == "Package")
        return "PKG";
    if (kind == "Strategy")
        return "STR";
    if (kind == "Typed")
        return "TYP";
    if (kind == "Dynamic")
        return "DYN";
    return "STR";
}

/**
 * @brief Names a structure that has no reference yet.
 *
 * A structure is grouped before anybody can book a leg into it, so the grouping
 * is where it needs a name. The value is derived from the structure's own id,
 * which is unique already, so two structures cannot collide and no counter has
 * to be kept.
 *
 * This runs on every write and not only on a creation. The structure and its
 * identifier are two statements, so a run cut between them would otherwise
 * leave a deal that no later write ever names again.
 */
void name_structure(const ores::database::context& ctx, const domain::structure& value) {
    repository::structure_identifier_repository identifiers;
    const auto named =
        identifiers.read_latest(ctx, boost::uuids::to_string(value.id), std::string("Internal"));
    if (!named.empty())
        return;

    domain::structure_identifier identifier;
    identifier.tenant_id = value.tenant_id;
    identifier.structure_id = value.id;
    identifier.id_type = "Internal";
    identifier.id_value =
        reference_prefix(value.kind) + "-" + boost::uuids::to_string(value.id).substr(0, 8);
    identifier.modified_by = value.modified_by;
    identifier.performed_by = value.performed_by;
    identifier.change_reason_code = value.change_reason_code;
    identifier.change_commentary = value.change_commentary;
    identifier.recorded_at = value.recorded_at;

    // The claim is the identifier's own: a structure's claim speaks about the
    // structure, and a version on it would mean nothing here.
    identifiers.write(
        ctx, identifier, {ores::utility::domain::precondition_kind::must_not_exist, std::nullopt});
}
