This page is a [[id:671F18E4-E09C-4B3B-BD24-D33DF8AE38A6][capture]] in the *inbox* bucket of the product backlog — a pre-sprint idea, not yet pulled into a sprint as a story.

* What

Parallelise the heavy checks and skip the work they do not need: set a test
parallel level for =ctest=, run the pgTAP suites concurrently, and let
=db recreate= no-op when the schema fingerprint already matches the tree.

* Why

The heavy tier is the gate's ceiling. =build= is about ninety minutes on
one workstation, and =db recreate=, =ctest= and =pgtap= follow it on every
run that selects the =sql=, =cpp= or =services= class. =ctest= and =pgtap=
declare no parallel level, and =db recreate= rebuilds the schema
unconditionally even though =context_factory= already computes a
fingerprint saying the database matches the code.
