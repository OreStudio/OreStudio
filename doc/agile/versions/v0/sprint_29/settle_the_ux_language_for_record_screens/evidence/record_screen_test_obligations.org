#+title: The tests the record screen specification requires
#+description: The obligations propagated from record-screen-behaviour.allium, derived by hand because the Allium CLI is not installed, for the harness story to take.

The Allium CLI is not installed in this environment, so =allium plan= could not
produce the obligation list. This table derives it by hand from the test
generation taxonomy, one row per construct of
=doc/llm/specs/record-screen-behaviour.allium=. The third story, Check every
record screen against the UX language, takes each row as a test of its harness.
A row that needs a seam the code lacks says so.

Forty four obligations. Thirteen need a second browser or a second account,
two need a controllable clock, and one is an open question for the owner. The rest
need nothing the running environment lacks. Row 39, the open question, stands
last on purpose: it is a decision, not a test.
