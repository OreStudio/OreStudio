* Acceptance

- A derivation method is data: its code, its version, its name, the assumptions it rests on, what it fits and what it does not, and the knowledge page that owns the subject.
- A stored value states the method and the version that wrote it, and a page reads the note for that pair, never for the latest version of the method.
- The note is shown beside the value wherever a derived set appears, and the generated market data says how the set was initialised as part of the same note.
- A method with no note cannot write a value: the write is refused, or the seed that declares the method fails to install. A value whose method has no note is a value nobody can read the limits of.
- The note is short enough to read on the page and links to the durable page for the rest, so the page states the limits and the knowledge page states the method.

* Notes

- The method and version are already stamped on a published series: the FX derived quotes carry a derivation kind and a method version, and the surface publish carries its own. The note is the human half of that stamp and is versioned with it.
- The notes differ by class and by method, and they are the place a limitation is stated: the FX note says the level is a realised volatility times an authored risk-premium multiplier and the shape is a Gram-Charlier shrunk to a prior, and the interest rate note says the projection is a one-factor Gaussian average and the smile is first-order with no curvature.
- A note is not a knowledge page and does not replace one. It is the short statement a person reads at the point of use; the page that owns the method is cited from it.
