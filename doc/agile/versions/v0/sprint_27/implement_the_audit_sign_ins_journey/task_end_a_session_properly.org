* Result


Logout ended its session row with zeroed byte counters, so a sign-out erased
what the session had moved. It now reads the row and carries the counters
through.

A tenant administrator can end another account's session with
=iam.v1.ops.end_session=, behind its own =iam::sessions:end= rather than the
=iam::*= wildcard. The tenant comes from the caller's own session and the
sessions table carries row-level security, so another tenant's session is not
there to end; a session that has already ended is refused in the reply.
