* Acceptance

- No code searches for an ORE element name or attribute spelling.
- The as-of date is read and set through the run document projection.
- The latest market data date comes from the market data reader.
- Tests cover a document whose marker sits in a comment, and one that writes its attributes in another order.

* Plan

Both facts the handler needs are operations the codec can state, so they become
operations on the two readers rather than searches inside the handler:

- =run_document_projection::as_of_date= reads the document and maps it, so the
  parameter is found by name and the projection decides what an as-of date is.
  =with_as_of_date= maps the document, sets the date, and writes it back through
  the projection, which is also how the export built it.
- =market::latest_market_data_date= reads the body with the market data parser
  and takes the last date it states, so a comment, a second date spelling or a
  repeated key are the parser's business.

The handler keeps what it alone knows: that a run prices at the data's last date
when the data ends before the date the run asked for.

The tests live with the owners: a document that mentions the parameter in a
comment, one that spells its attributes another way, one that states no date,
and a body with comments, mixed date spellings and a line the parser refuses.

* Result

The package handler states a date change as a document change and asks the codec
for the facts it needs. Its three text helpers are gone: no code outside the
projection searches for an ORE element name or attribute spelling.

=as_of_date= and =with_as_of_date= are operations on the run document
projection, and =latest_market_data_date= is an operation on the market data
parser. The rewrite goes through the same =reverse= the export used, so a
document that prices at the data's date keeps every parameter the model states
and invents none.

The handler keeps one rule of its own, which is about runs and not about ORE: a
run whose gathered data ends before the date it asked for prices at the data's
last date, and says so.
