* Summary

Generates =tests/test_suite.hpp= for every component's test target. It
defines =test_suite=, the logger name every test file in the target uses, once
for the target. It consumes the component model and takes the name from the
component's full name, the same name the test main gives the test module.

The constant used to be defined in each test file's anonymous namespace. A
unity build merges several test files into one translation unit, so those
copies collided. One definition in a shared header cannot collide, and it
keeps every file of a target on the same logger name.
