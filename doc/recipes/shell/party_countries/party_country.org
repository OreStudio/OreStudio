#+title: How do I run the party_countries commands from the shell?
#+description: Every command the party_countries submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:party_countries:

This file documents the party_countries resource at the shell, one section per command. Every command is a subcommand of =party_countries=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: C9C964E8-66D1-58BF-A093-EE1C533E700F
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
party_countries list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =refdata.v1.party_countries.list=.

#+name: party_countries-list
#+begin_src ores-shell :tangle party_countries-list.ores :exports none
party_countries list --limit 1
#+end_src

** =get=
:PROPERTIES:
:ID: 074972B4-F636-50CF-9A25-4B2D128015FB
:END:

Reads the one row its key addresses. A key states every identifying column, so a partial key is refused rather than answered with an arbitrary row.


The command is shaped like this:

#+begin_example

#+end_example

It is addressed at =refdata.v1.party_countries.get=.

** =add=
:PROPERTIES:
:ID: 0F39B561-AC64-58A3-AABA-1D90E6421C9D
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.


The command is shaped like this:

#+begin_example
party_countries add <party_id> <country_alpha2_code> <reason> <commentary>
#+end_example

It is addressed at =refdata.v1.party_countries.put=.

** =set=
:PROPERTIES:
:ID: 3FE23534-40BB-5975-BDF5-4A289B7A9A5F
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved. Passing --version makes the write conditional on the version the caller last read.


The command is shaped like this:
