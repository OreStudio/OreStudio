* Goal

Prove the compute role of ~compass env deploy~ (PR #1937) live,
end-to-end, against a real serving environment:

- Deploy ~ores.compute.wrapper~ to a remote box with ~compass env
  deploy <host> --role compute~. The wrapper joins the serving
  environment's compute core over NATS: it registers as a compute node
  of that environment, receives work, and reports results.
- Register the remote host in the serving environment's ~compute.hosts~
  table. The host IDs come from the ~ORES_GRID_NODE_*_HOST_ID~ ids in
  the environment's generated ~.env~; keep them in sync with ~compass
  db recreate~ (~env_init.py~).
- Fix any ergonomics gaps the live run exposes: registration flow,
  docs, or the deploy command itself.
