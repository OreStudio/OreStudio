* Decisions

The remainder is carried in [[id:6FF11957-0CCE-4B12-BDE5-7AD2BE882000][Bring the role screens to the standard]].

- A list a record page only reads, such as a tenant's parties, is a
  =RecordTable= in a tab: the shared list without its header.
- List filters are part of the list's source and live in the address as
  =f.<id>=; a toggle filter shows records a kind hides by default.
- A classification list is read whole once and paged in the browser, as the
  standard's classification list exception now says.
- The shared delete and revert dialogs take the write, so a kind with its own
  write API, such as classifications, uses the same dialogs.
