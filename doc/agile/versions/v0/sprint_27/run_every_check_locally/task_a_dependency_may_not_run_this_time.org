* Result

The dependency check compared a check's `after` names against the selection
rather than the catalogue, so a narrow selection that picked site-page without
component-drift read the dependency as a typo and raised. The runner crashed
before running anything, and every documentation-only change would have hit it.

A dependency names a check; whether that check runs in this selection is a
separate question, and its absence is satisfied rather than wrong. The lookup
is now the catalogue.

Found because the docs-only branch for the risk report config record crashed on
its first static run. A regression test pins the selection that broke it.
