* Result

The =pattern= document type exists and its scaffold works through
=compass add pattern=. The template has a two-to-four sentence blurb and the
thirteen required sections: also known as, context, problem, forces, solution,
failure handling, pitfalls, security, resulting context, in ORE Studio, related
patterns, sources and see also. =--pattern-group= takes one of six groups and is
required.

The hub, [[id:EA249899-6611-407F-A43A-B37019EBD1A7][Patterns]], lives in
=doc/knowledge/patterns/=. It states the three rules of the language, reads the
six groups in order with each group's question, and lists the planned patterns
with their sources. A pattern becomes a link when its page exists. The knowledge
index links the hub.
