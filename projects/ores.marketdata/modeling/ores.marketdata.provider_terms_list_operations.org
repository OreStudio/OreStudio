#+title: ores.marketdata.provider_terms_list_operations
#+description: Codegen operation model for accepting the terms of several providers in one request, each as the single accept would.
#+type: ores.codegen.operation
#+component: marketdata
#+subcomponent: api
#+entity_singular: provider_terms_list_operations
#+namespace: ores::marketdata::messaging
#+brief: Accepting the terms of several providers at once.
#+filetags: :model:operation:marketdata:
#+created: 2026-11-01
#+updated: 2026-11-01

A system that is set up, or a person who reads every public source's terms in one
screen, accepts them in one request. Each provider goes through the same checks as
the single accept in [[id:7E2B91D4-3C58-4F0A-8D61-2A9E5B7C4F13][ores.marketdata.provider_terms_operations]], and one refusal
does not stop the others. The request carries a list of providers, which the shell's
token form cannot fill, so this model renders no shell command; the shell accepts
all public terms with a command of its own.
