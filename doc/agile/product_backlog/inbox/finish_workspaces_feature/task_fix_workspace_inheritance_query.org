* Goal

Make single-parent workspace inheritance actually work. Today, every
=has_workspace_id= entity filters with an exact-match predicate
(=workspace_id == wid=); a workspace with a parent sees none of the
parent's data. Upgrade =cpp_domain_type_repository.cpp.mustache= to
generate the resolution-order query
(=workspace_id = ANY(:resolution_order)= with =DISTINCT ON=
deduplication, closest workspace wins) that
=projects/ores.workspace/core/modeling/multi_workspace.org= already
documents as the target design, and thread the resolution-order array
through the C++ context/service layer to the repository call.

- =has_workspace_id= list/find queries use
  =workspace_id = ANY(:resolution_order)= with =DISTINCT ON=
  deduplication instead of exact match.

  reaches every regenerated repository call.
- Manually verified: a child workspace with no local rows for an
  entity correctly sees its parent's (or Live's) rows.
