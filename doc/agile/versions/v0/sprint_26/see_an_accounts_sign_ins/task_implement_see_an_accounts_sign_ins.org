* Goal

* Result

The journeys describe an account's sign-ins and name the system administrator.

- [[id:99ABD4E6-A69E-4D3F-902D-A69EBE2A565F][See who has access]] names the
  system administrator as a second actor over the system tenant, reached from
  the system tenant's *People* tab, and adds a step: opening an account shows
  its type, its sign-in state and its sessions, newest first. It records the
  missing read (an account filter and a start-time order on
  =iam.v1.sessions.list=) and that a session's end is not recorded, and closes
  the gap about secrets on the account read.
- [[id:22AC8DD8-A440-4330-9992-47A5E9985473][Audit sign-ins]] names the same
  second actor and points the per-account question at the account page.
