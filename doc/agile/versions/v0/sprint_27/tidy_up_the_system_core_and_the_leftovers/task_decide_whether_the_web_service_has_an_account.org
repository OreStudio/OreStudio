* Goal

The web service either has an identity of its own, declared and provisioned
like every other service's, or it has none and carries no picture.

* Acceptance

- The registry entry, the environment, the database roles, the IAM accounts
  and the avatars all agree on the answer.
- If the service needs an identity, it is declared the way =ores.http.server='s
  is and reaches the bus as itself.
- If it does not, =ores_web_service.svg= and the image published from it are
  gone, and the record states how the BFF reaches the services instead.
- Either way, something fails when the next change makes the five disagree.
