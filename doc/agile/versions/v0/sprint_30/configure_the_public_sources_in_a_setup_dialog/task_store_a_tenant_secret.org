* Goal

A value that a service needs and a person supplies, such as the key of a public source, is stored against the tenant, is written once and is read only by name. The browser learns that a value is stored, never the value.

* Acceptance

- A secret is stored for a tenant under a name, and read back by that name.
- No read path returns the value to a browser; a screen can ask whether it is stored.
- The value is encrypted at rest with a key that is not held in the database, and the rows are scoped to their tenant as every other tenant table is.
