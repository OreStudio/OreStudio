* Result

The seven operation models that still fell back to reflect-cpp, and the four
diff types the history messages carry, have generated wire codecs with
roundtrip tests; the history api is a compiled library for it. The generator
finds another component's include root and codec header from the files that
exist, and refuses a type with no header, and an entity codec header includes
its members' codec headers, so a shape is visible wherever its type is
encoded. The build passes.
