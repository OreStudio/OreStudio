* Acceptance

- The feed configuration is generated from the blueprint dataset's pairs and ladder, not listed again.
- Each pair's starting ATM level is its spot process's volatility, so a surface and the spot it
  is struck against start from one level. (Revised: the first draft seeded the levels from the
  derived source by rank; see the Plan.)
- The pairs whose spot the latent run quotes have a surface at every expiry of their
  blueprint's ladder; the crosses are the task "Quote cross surfaces consistent with their legs".

* Plan

- *What was there.* The latent surface feed's code exists (the generator, the emitter, the
  feed kind), but no dataset configured it: the seven feeds in the database were test rows in
  test tenants, written by the test user. The system tenant quoted no latent surface.
- *The route.* The synthetic feeds dataset already publishes FX spot and IR curve feeds in one
  transaction, and its publish function names a third asset class as "a third loop added
  here". The four surface tables gain artefact tables from their models, and the publish gains
  that loop: contributors, feeds, expiries and the links, each published row taking its
  artefact's id so a second publish writes new versions of the same rows.
- *Nothing listed again.* The dataset rows are read from what is already published: the pairs
  are the blueprint pairs the Bloomberg feeds quote a spot for, the ladder is the blueprint
  pillars' expiries, and the script runs after the refdata layer that stages them.
- *The starting level.* A surface starts at its pair's spot volatility, read from the spot
  mixture's primary component (its per-tick stdev is the annual vol over 3970.9). The derived
  source's realised volatility was the first draft's seed; the spot's own level keeps the latent
  surface consistent with the spot it is struck against, and leaves the derived source as a
  candidate to retire.
- *What the run showed.* The crosses have no latent spot (the run quotes USD pairs only), and
  the feed quotes every pair in one borrowed convention: both are new tasks. A surface runs
  only on demand, and its contributors have no vendor ids yet, so it starts with the next task,
  which quotes through the vendors.
