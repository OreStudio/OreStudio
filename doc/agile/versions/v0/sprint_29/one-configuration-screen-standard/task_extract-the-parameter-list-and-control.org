* Result

Delivered and signed off. A ControlModel union states the control a value needs, two mappers fill it from the pricing value set and from the engine settings row, and ParameterControl and ParameterRow are shared by both screens. No BFF, API or stored data changed, and no existing assertion changed.

The scenario [[file:scenario_verify-the-parameter-controls-on-both-screens.org][Verify the parameter controls on both screens]] passed on the provisioned environment, and the suites pass: 145 tests across pricing, engine settings and parameters.

The edit lifecycle was deliberately not extracted. The pricing screen saves the whole document and the engine settings screen saves one group, so a shared hook would reconcile two save shapes rather than extract one. The control and the row are the part the screens genuinely share.
