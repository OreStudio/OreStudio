* Summary

This structure note orders the pages on agents, programs a language model
drives, that act for a person through =ores.http=. The cluster answers one
question in order: how an agent can do what a person may do without becoming a
second way in. Read it as: the path an agent's call takes, the consent it acts
under, how it is named on each call, how it reaches ORE and finds what to
call, and what happens to what it does.

* Reading order

** The path

[[id:3B1D40EA-121F-4F53-A612-FF13DCE1A0BB][The path of an agent's call through ORE]] — start here. It argues that an agent has one door and borrows a
person's access, and it draws every part that the pages below describe.

** The consent and the name

[[id:A7E2942C-66AD-449C-B80B-CA789EBC34FA][Agent grants]] — the person's consent, which an agent cannot act without. Read
it before the token, because the token is what the grant becomes on a call.

[[id:1162906F-BB72-486E-9A11-30D567C65F3E][The agent in a token: subject and actor]] — the person as subject and the agent as actor. Everything that
follows decides on one or the other.

** The way in

[[id:5E479832-A0B2-4BC6-B008-BAD505F4E145][The MCP transport in ores.http]] — the MCP endpoint, written in =ores.http=.

[[id:4C382E8F-9449-4012-A09F-76291373E6F7][The operation catalogue for agents]] — how an agent finds an operation among more than a thousand,
in five tools.

** What happens to what it does

[[id:2D36D474-2CF9-4498-AF49-818CEF080B98][The record of an agent's actions]] — every call recorded as the agent's, for its person.

[[id:381D87BB-4E2D-47BA-8853-6132CF900305][Six-eyes approval of an agent's writes]] — every write held for its person and then a second approver. Read
it after the record, because a held write is shown to the person through it.

* What this cluster excludes

How a person signs in and what their roles grant belongs to [[id:AF46793A-FF6C-4066-A059-279CE9936420][Identity and Access]]; this
cluster begins where a person consents to an agent. The approval framework
itself belongs to the [[id:E21DFC83-9F3F-45BE-AD3F-48262126DFAC][Four-eyes framework]] and its pages; this cluster adds one condition
to it. The knowledge an agent answers from belongs to compass, not to ORE.
