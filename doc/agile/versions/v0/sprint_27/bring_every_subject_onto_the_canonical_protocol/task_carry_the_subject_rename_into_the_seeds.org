* Result

The rename reaches every subject the tree writes, not only the ones a model
declares.

50 =target_subject= values in =dq_artefact_types_populate.sql=, 74 subject
tokens across 22 files including the registrars' subscriptions and dq's six
internal orchestration subjects, and the six =subject_to_fn= helpers that turn
a subject back into a SQL function name -- every one of which still looked for
a =.publish-from-dq= suffix the migration had removed.

The identity workflow's two hand-written subjects moved to the reserved
namespace: =workflow.v1.ops.identity_step= and
=workflow.v1.ops.identity_compensate=.

The classifier now checks the verb before the event branch, so a resource
named =*_events= reads as a request: =trading.v1.lifecycle_events.delete_many=.

Verified end to end at =030d2d1e51=: a recreated database plus the ACME
Corporation bring-up completes all eight steps, =attach_photos= included, and
publishes both vendored ORE packages. 1262 codegen tests pass.

Out of scope, captured: the gate still reads only model declarations, and the
widened scan found fourteen more subjects no model declares.
