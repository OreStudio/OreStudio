* Goal

The pricing engine data is curated in data files, not in Python literals. Every
curated fact carries a reason, a source, a curator and a date. The generators read
the files and write the same SQL as before.

* Acceptance

- The authored texts, the name fixes, the typo fixes, the product types and the
  global parameters live in =curation/*.json= under the seeder dataset.
- Every entry carries a =reason=, a =source=, a =source_ref=, a =curator= and a
  =date=. The loader rejects an entry that lacks one, whose source is not one of the
  four categories, or whose value is empty.
- The generators read the curation. No priced text remains in a Python literal.
- The generated SQL is unchanged.
- =generate_ore_parameters_dataset.py --check= passes.
- The methodology names the files and the gates that are live.

* Plan

1. Read the literals and assign each to one concern: a type, a name, a text fix, a
   setting text, a model, an engine, a template or a global parameter.
2. Generate the JSON from the literals, so no value is retyped by hand.
3. Add =curation/__init__.py=, which loads the files and checks the provenance.
4. Rewire the extractor, the vocabulary generator and the parameter rows.
5. Delete =descriptions.py=.
6. Regenerate both datasets and prove the SQL is byte-identical.

The instrument of a type was in the generated types SQL, because the generator read
its own previous output. It moves to =types.json=, so the generator reads one source.

=documentation= is optional on any type. Only the four types the guide does not
describe use it today, but a curated text for a guide type needs no new field.

* Result

The curation is data. Eight JSON files under =curation/= hold the 296 curated facts,
each with a reason, a source, a source reference, a curator and a date. The loader
rejects an entry that lacks one or names a category outside the four. The
extractor, the vocabulary generator and the parameter rows read the files, and
=descriptions.py= is gone.

The generated SQL did not move: 108 types, 194 pairs, 834 settings, 25 models,
74 engines, 19 templates and 1674 ore parameter rows. That is the proof that the
files say what the literals said.

The review changed the shape of the provenance. A single =source= string became a
category plus a reference, because 104 type entries claimed the guide as their
source while their values came from the seeded table. All 108 now say =seed= and
name the file.

The release floor is still measured, not curated, and the methodology says so.
Two checks fail on =main= before this branch, the ER diagram and the
=analytics.quant= file list. Neither is in this change.
