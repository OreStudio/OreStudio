States the type's members as a list of =ores::utility::codec::field=, and
defines the four wire functions over it.

The list is the whole of the encoding: =object::write_json= writes an object
whose keys are the fields' names in the order the list states them, and
=object::read_json= reads each one back by name. A field's own form is the
carrier's for its member's type, so a string, a number, a truth value, an
instance, a decimal and a uuid need nothing here.

See the [[id:C4E8A91F-3B7D-4F2E-85A6-1D9C7E3B2F4A][Template variable reference]] for the complete list of available
variables and their semantics.
