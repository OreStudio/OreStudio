* Goal

A reader can always say what price a run began at and why. Today a run's start record lives only in the memory of the running feed and is lost when it stops. Each start of a feed is stored once as a feed start record: when it started, who or what started it, the kind of start (release, resume, re-anchor, or first start of an unreleased feed), the initial price in the pair's market convention, its source (the fixing and its item, the last stored spot and its time, or the configured level), and the calibration and version the run uses. The feed's History tab reads these records with the feed's versions, so a restart is an entry with its initial price.

* Acceptance

- Each start of a feed stores one start record, with its kind, initial price, source, starter and calibration.
- A restart shows in the feed's History tab as an entry naming the price it resumed from and the spot's time.
- The feed's Calibration tab reads the current run's start from the stored record, so it survives the service that started it.
