The curve a segment builds on, as ORE's =ReferenceCurve=. A zero spread
segment adds its spreads to it, a bond yield shifted segment shifts it and a
yield plus default segment adds its default curves to it. ORE requires it on
all three, so every segment of those elements has this part.

A segment holds at most one row of this part, so the generated table adds the
unique index on the live rows of =(tenant_id, curve_segment_id)=.
