* Result

Every package the image needs exists in the Ubuntu 26.04 archive, so the
recipe holds no external repository: the toolchain PPA, apt.llvm.org, the
GitHub CLI repository, the PGDG repository and the three downloaded archives
are gone. The image is smaller and states less.

The tree itself has not yet compiled on the new image; the workflow builds the
image and checks the tools, not the code.
