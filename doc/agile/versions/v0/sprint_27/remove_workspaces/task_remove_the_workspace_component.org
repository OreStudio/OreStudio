* Result

=ores.workspace= is gone, with every trace of it. The component tree, the
shell adapter part and its recipes, the SQL schema and its functions, the
grants, the RLS policies, the Live workspace seed, the workspace service
user, account, role and permissions, the generated web protocol, the nav
label and the =live_workspace_id= sentinel are all deleted. Every derived
artefact is regenerated: 121 files deleted, and the component file lists,
the shell recipe inventory and the ER diagram follow.

Acceptance met on the counts. The measure script reports zero tables with
a workspace_id, zero models or profiles setting the feature, zero
component files, zero shell part files and zero callers. The only
remaining hits are the frozen DSH-kanban fixtures and the trading part,
which the trade shape story owns. The owner chose to merge without the
local check gate, so the build, ctest and the database recreation were not
re-run for this task.
