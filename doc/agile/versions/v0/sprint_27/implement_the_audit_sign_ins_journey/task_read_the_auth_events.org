* Result


=iam.v1.auth_events.list= reads the caller's tenant's events, newest first,
filtered by account, period and event type. The table carries no row-level
security, so =auth_event_repository::read_events= scopes on =tenant_id=
itself through one parameterised statement: an empty filter does not filter.
The handler requires =iam::auth_events:read=, which the seed adds and grants
to =HttpService= for the BFF path.

The operation model renders the protocol, the BFF route and the shell
command; the three static gates stay green (subject conformance, protocol
twin coverage, handler permissions). =ores.iam.core.tests= passes 240 of 252,
and the 12 failures are the mTLS-NATS eventing tests this environment cannot
run, not this read.
