* Acceptance

- A book belongs to the same sandbox as its parent portfolio, or both to none; a book in a sandbox is virtual.
- A virtual book has no ledger reference and is not a sweep target.
- A sandbox's books are read and written only by those who may see the sandbox.

* Plan

- A book carries the sandbox it belongs to, optional and fixed, as a
  portfolio does. A book is virtual exactly when it has one, so no separate
  flag can disagree with the tree.
- The book trigger keeps a book in its parent portfolio's sandbox, or both
  in none, and refuses a write into an archived sandbox.
- A check gives a virtual book no ledger reference and refuses it as a
  sweep target.
- The sandbox isolation policy that portfolios carry applies to books too.
