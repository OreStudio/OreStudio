* Decisions

- Release joins the Nightly Build rather than Continuous. The rebalance
  exists to keep the continuous compiler-cache working set inside the 10 GB
  repository cap, and a third variant there works against it.
- Coverage and memcheck follow the buildtype. They are added to the nightly
  arguments only when the build is debug.
- The four configurations are the coverage target: gcc and clang, debug and
  release. Anything less leaves a configuration that nothing compiles.

* Out of scope

- Moving valgrind's installation off the release jobs. It is one package
  step and does not change what the job builds.
