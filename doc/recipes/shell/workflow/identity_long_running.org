The long-running configuration of the [[id:25ED321D-A489-449C-BF60-15F1A1B3DBE7][identity workflow]]. The =ores-shell= block
below is tangled into the runnable script library as =identity_long_running.ores=.

* Question

How do I watch a workflow while it is running?

* Answer

Each step waits before it reports, so the instance sits at =in_progress= long enough to poll. Run =workflow wait= in one shell and =workflow_steps by-workflow-id= in another to see the steps advance.

#+name: identity-long-running
#+begin_src ores-shell :exports none
workflow start identity_workflow '{"steps":[{"name":"one","delay_seconds":5},{"name":"two","delay_seconds":5}]}' --instance-id 10000000-0000-4000-8000-000000000006
workflow wait 10000000-0000-4000-8000-000000000006 --timeout 60 --expect-state completed
#+end_src

=workflow wait= fails unless the instance reaches the state named, so this
script fails when the path it covers does nothing.
