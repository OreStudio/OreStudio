#+title: How do I run the fra_conventions commands from the shell?
#+description: Every command the fra_conventions submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:fra_conventions:

This file documents the fra_conventions resource at the shell, one section per command. Every command is a subcommand of =fra_conventions=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: 69F455FC-5B28-52B5-AD5D-F2EDD7766484
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
fra_conventions list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =refdata.v1.fra_conventions.list=.

#+name: fra_conventions-list
#+begin_src ores-shell :tangle fra_conventions-list.ores :exports none
fra_conventions list --limit 1
#+end_src

** =get=
:PROPERTIES:
:ID: 0FD7B9D4-ABB4-5291-AC41-6F80D904BD52
:END:

Reads the one row its key addresses. A key states every identifying column, so a partial key is refused rather than answered with an arbitrary row.


The command is shaped like this:

#+begin_example
fra_conventions get <id>
#+end_example

It is addressed at =refdata.v1.fra_conventions.get=.

#+name: fra_conventions-get
#+begin_src ores-shell :tangle fra_conventions-get.ores :exports none
fra_conventions get __none__
#+end_src

** =add=
:PROPERTIES:
:ID: 3AB21C6F-1CA4-5A80-9EE8-4324D674EBFF
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.


The command is shaped like this:

#+begin_example
fra_conventions add <id> <index> <reason> <commentary>
#+end_example

It is addressed at =refdata.v1.fra_conventions.put=.

#+name: fra_conventions-add
#+begin_src ores-shell :tangle fra_conventions-add.ores :exports none
fra_conventions add __none__ __none__ system.new_record generated_script
#+end_src

** =set=
:PROPERTIES:
:ID: 4300FBB8-86CA-525D-8E34-4C672C27B6E4
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved. Passing --version makes the write conditional on the version the caller last read.


The command is shaped like this:

#+begin_example
fra_conventions set <id> <index> <reason> <commentary> [--version <n>]
#+end_example

It is addressed at =refdata.v1.fra_conventions.put=.

#+name: fra_conventions-set
#+begin_src ores-shell :tangle fra_conventions-set.ores :exports none
fra_conventions set __none__ __none__ system.new_record generated_script
#+end_src
