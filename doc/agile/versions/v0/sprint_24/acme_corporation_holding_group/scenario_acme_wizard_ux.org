* Before you start

- The database must be *genuinely fresh and un-provisioned* -- nobody
  has run =provision system= or =bootstrap= against it via the shell.
  If in doubt, ask the environment owner to run =compass db recreate
  -y -k= and *not* follow it with any shell provisioning script -- the
  whole point of this scenario is to exercise the wizard-driven path
  from a cold, bootstrap-mode system, not a pre-seeded one.
- Launch the client fresh (not reused from an earlier session):
  =compass client start --colour <colour> --open-scenario
  doc/agile/versions/v0/sprint_24/acme_corporation_holding_group/scenario_acme_wizard_ux.org=
- Take a screenshot at the end of every step, and use the Notes field
  in the step-detail panel to record anything that doesn't match what
  the checklist says to expect -- exact wording, an extra/missing
  page, anything.
- Nothing below assumes prior knowledge of what the wizards look
  like: where the checklist isn't yet confirmed by a real run, it
  says so and asks you to record what you actually see instead of
  asserting a specific expected result.
