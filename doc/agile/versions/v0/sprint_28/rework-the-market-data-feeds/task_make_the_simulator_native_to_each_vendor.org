* Result

The simulator is native to each vendor. The catalogue holds one simulated source for each of three providers, named for the provider and an instance: =bloomberg-a=, =lseg-a= and =demo-a=. No name, subject or id says that a source is simulated or names ORE, and the source =ore-simulated= is gone. The service starts one adapter for each source of the catalogue whose kind is simulated, and each adapter serves the system collections of its provider and publishes that provider's own ids.

The notation of each provider is an independent class of =ores.marketdata=: =bloomberg_notation=, =lseg_notation= and =demo_notation=. A notation reads a vendor id into a neutral description of the quote and writes it back, and refuses what it could not read back. The readers are Boost.Spirit.X3 grammars. The classes know nothing of the catalogue, NATS or the simulator, and the simulator only asks =notation_of(provider)= for the id of a generator. The roundtrip is proved by a corpus of 545 lines of ids and descriptions, a grid over every ordered pair of twelve currencies on every side, a test that damages each character of every valid id, and a test that reads every installed vendor instrument of the three providers and writes it back as itself.

The provider =ore= no longer has a simulated source. It keeps =ore-import= and =ore-derived=. The 2016 ORE samples dataset is removed. The uniform demo is a set of fixed levels for the provider =demo=. The Acme profile routes its parties to =bloomberg-a=. A market clock (=system_market_clock= and =fixed_market_clock=) gives the start date of a feed whose config names none, and the build context gives every feed the same clock instance.

Left for other tasks:
- Rate curves have no vendor tickers, so curve generators stay on the old path. The task =Write the vendor tickers of the curve pillars= carries it.
- The Bloomberg dataset still starts 13 pairs from the fixed 2026-05-05 vintage. The task =Calibrate the synthetic ticks from free public sources= replaces it and makes the clock decide the date.
- The LSEG and Bloomberg rows marked =to confirm= on the inventory page still need a person with a login.
- ICE and Tradeweb have no notation and no simulated source.
- The adapters are built from the catalogue at start-up. A source added later needs a restart.
