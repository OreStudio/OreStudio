* Acceptance

- A codegen facet generates a route unit per entity, with a header, an implementation and a test, from the entity's model.
- The generated route speaks the canonical NATS protocol and carries the caller's session, so the service's own permission check governs access.
- Every route that needs a session is behind one by construction, declared in the model rather than by hand at the call site.
- The hand-written route file for ores.assets is deleted, and its endpoints still answer.
