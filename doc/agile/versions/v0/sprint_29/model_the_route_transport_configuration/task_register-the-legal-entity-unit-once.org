* Result

The registrar calls the unit once, in its alphabetical place among the leg and
local jurisdiction commands. The stray call beside the counterparty commands is
gone.

Before: the shell refused to start with "Two shell command units register the
name 'legal_entities'", so no environment could be provisioned or driven from
the shell. After: the shell starts and resolves the address — `legal_entities
list` answers that the caller is not logged in, which is the command's own
refusal and not the menu's.

Both calls arrived in the same session's legal entity wiring, one from
[[commit ef5800d37a]] and one from [[commit 20a6ec0707]]; neither noticed the
other because the file is generated in alphabetical order and the second landed
out of sequence.
