Reference data is classified by short code lists: types, statuses, kinds, and
the vocabularies ORE documents write. These lists have no goal of their own, so
this group is the exception the extraction standard allows: one plain list
screen, with its edit form and history, serves every list. The person chooses
the list by topic.
