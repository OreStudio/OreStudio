* Notes

The extractor was never the problem. =curve_terms.json= holds PillarChoice,
DuplicatePillarPolicy, Priority and MinDistance for every kind, with the type and
default the ORE source states; the walk on 2026-10-30 suggests otherwise only
because a term without a text is not written as a row. The guide explains the four
once, in the simple segment's prose, and never lists them as items, so the
extraction has no item to attach the words to. That is what curation exists for,
and the same route landed ProjectionCurve.

The default the extractor read is what the screen shows: LastRelevantDate for the
pillar choice, KeepLast for the duplicate policy, 0 and 1 for the priority and the
minimum distance.
