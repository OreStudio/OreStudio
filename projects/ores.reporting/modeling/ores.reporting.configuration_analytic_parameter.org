One =Parameter= element inside one =Analytic= of the run document that a configuration describes: the value, and the definition that says what it means. A row is keyed to a definition in =ore_parameter= whose =scope= is the analytic and whose =subtype= is the analytic type code, so adding a parameter is a lookup row and never a column.

* Artefact columns

The definition of a parameter has an id that differs between databases, so a dataset cannot stage it. A staged parameter names the parameter instead, and the analytic type comes from the staged analytic that the row points at. =ores_dq_publish_configuration_document_fn= resolves the pair to the definition of the target database.
