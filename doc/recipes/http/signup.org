Create a new account (when self-registration is enabled).

#+begin_src verb :wrap src json
post /auth/signup
Accept: application/json
Content-Type: application/json

{
    "username": "newuser100",
    "email": "newuser@example.com",
    "password": "MyP@ssword456"
}
#+end_src

#+RESULTS:
#+begin_src json
HTTP/1.1 403 Forbidden
Content-Type: application/json
Content-Length: 37
Server: ores-http-server-v1
Access-Control-Allow-Origin: *

{
  "error": "User signups are disabled"
}
#+end_src

The account this call creates, the tenant it lands in, the party and role it
receives, and the switch that refuses it are
[[id:84706C3E-D48D-4A4B-967A-4AADB3CF44B2][registration and onboarding defaults]].
The path the call takes, and the codes it answers with once they exist, are
[[id:504863AB-C45A-47E8-BB77-AADCB620A305][the entry journeys]].
