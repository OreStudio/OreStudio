* What

Each hand-written, screen and operation route of =ores.http= states the
permission its service checks, read from the handler it reaches, so the MCP
tools filter it as they filter the generated entity routes.

* Why

The generated entity routes state their permission by the rule their handlers
apply. The rest, 739 of the 1,153 operations the server serves, state none: screen routes name the entity in the
singular, the operation routes are IAM's and no model property carries a
permission, and the hand-written ones forward to one or more services. Some
check a permission only for another's record, such as revoking a grant that is
not one's own, so one permission per route does not describe them; the
declaration may need to name that condition.
