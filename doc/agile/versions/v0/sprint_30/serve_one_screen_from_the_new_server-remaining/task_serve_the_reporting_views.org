* Goal

Serve these composed views from ores.reporting: a report configuration, an ORE schema's contents, the cuts, the hand take, the kinds of cut, the lookups a cut kind names and the report health. Each view states its name, schema, owner, computation and cache policy, as the route inventory records them. The route stays the same as the route the screen calls now. This task depends on the resources of the part that owns the data.
