* Plan

The prototype answers the four placements the journey's judgement left open, and
nothing else. It is a static page under =doc/prototypes/parties/approval-matrix/=
with the query string as its state, so every state has an address a reviewer
opens: the party's tab with no set, with an empty set, with a set, and with a
refused save; the book's panel that follows its party, that narrows it, and that
is refused from a stale page.

The tokens are the application's, copied from the web app's stylesheet. The
controls move between states and write nothing, because the prototype answers
what the screen looks like. The refusal is the page's own words: the server does
not carry the party's set yet, and the journey filed that as a capture, as it did
the operation that would answer the set a book may carry.

The design note beside the prototype cites the rule each part follows, lists the
states with their addresses, and states what is fake.
