* Goal

ores.http serves MCP's Streamable HTTP transport at /mcp: POST, GET and DELETE, sessions by Mcp-Session-Id, JSON-RPC through ORE's codec, and the methods initialize, notifications/initialized, ping, tools/list and tools/call, written in ores.http with boost.taar as the reference. A request authenticates with an agent's key, and a missing or invalid one is answered with 401.

* Acceptance

- /mcp answers POST, GET and DELETE as the Streamable HTTP transport specifies, with sessions by Mcp-Session-Id.
- initialize, ping, tools/list and tools/call work, and the official MCP conformance runner passes for what is implemented.
- A request without a valid agent key is refused with 401.

* Plan

(Implementation strategy. Written when work starts; key decisions
are distilled into the parent story's =* Decisions= at close, but the
plan itself stays — it is the historical record of what we did.)

- The transport lives in =ores.http.api/mcp=: a =tool_provider= interface, a
  =session_registry= that binds each =Mcp-Session-Id= to the person and agent
  that opened it, and an =endpoint= that reads JSON-RPC through ORE's
  =json_document=.
- The route's own authentication exchanges the agent's key; the endpoint then
  refuses a token whose =act= names no agent, so a person's session cannot use
  it.
- GET answers 405, which the transport permits of a server that sends nothing
  unasked; a stream waits for a capability that needs one.
- The routes declare =transport()=: the gateway would otherwise hold every MCP
  POST as an agent's write. Each tool's call is judged as its own route in
  [[id:24864EC2-233C-4943-B381-3AD69DE2DAB0][Browse, search and call operations through five tools]].
- One tool, =list_areas=, is served now so that =tools/call= is proven end to
  end; the other four arrive with that task.
- The conformance runner sends no header, so it runs through a localhost proxy
  that adds the agent's key.

* Result

ores.http serves MCP's Streamable HTTP transport at =/mcp= to an LLM agent's
key: =initialize=, =notifications/initialized=, =ping=, =tools/list= and
=tools/call= over POST, sessions by =Mcp-Session-Id= bound to their agent,
DELETE to end one and 405 to GET. A request without a valid agent key is
refused with 401, a foreign origin with 403. The official conformance runner
passes every scenario for what is implemented, and =list_areas= answers the
sixteen published areas through =tools/call=.
