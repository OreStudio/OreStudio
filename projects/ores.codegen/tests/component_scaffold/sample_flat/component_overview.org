* Summary

Test fixture for the component-scaffold verifier. Represents a flat component
(no api/core/service subdivision) — equivalent in shape to =ores.nats=,
=ores.storage=, or =ores.service=.

Codegen running =--address ores.cpp= against this overview always produces:
- =CMakeLists.txt= at the component root
- =src/CMakeLists.txt= / =tests/CMakeLists.txt= / =modeling/CMakeLists.txt=
- =include/<full_name>/export.hpp=
- =tests/main.cpp=

While the overview carries =:ores.cpp.scaffold.enabled: true= it also
produces the first-generation scaffold, which a component deletes once its
first real model lands:
- =include/<full_name>/<full_name>.hpp=
- =include/<full_name>/domain/stub.hpp= and =src/domain/stub.cpp=
- =tests/stub_tests.cpp=
