The C++ projection of the catalogue's mapping. =asset_class_for_authority=
takes the authority text a datum or an index names.

An authority the mapping leaves empty -- =correlation= and =generic= -- is
simply absent from the function, so it answers =std::nullopt= for it.
=asset_class_codes= carries the taxonomy's own codes, in display order, so a
test-data generator that must emit a code the catalogue holds reads it rather
than restating the list.

The header is written into =ores.marketdata.api=, beside the datum model
whose authorities it maps. The build already links =ores.refdata.api= into
=ores.marketdata.core=, so the dependency direction is unchanged.
