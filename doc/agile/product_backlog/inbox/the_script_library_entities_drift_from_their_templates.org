This page is a [[id:671F18E4-E09C-4B3B-BD24-D33DF8AE38A6][capture]] in the *inbox* bucket of the product backlog — a pre-sprint idea, not yet pulled into a sprint as a story.

* What

Regenerate the trading component and commit the 21 script library files it
rewrites. The files are the create scripts of the script, variant, input,
result, calibration, calibration strike and coarsening tables, their event
headers and their repositories. The rendered repositories gain a claim-rows
filter that keeps only the caller's own rows when a write checks its claim.

* Why

The component-drift check covers every file of a component when a branch
changes that component's model. A branch that changes the trading catalogue
then fails the check on files it did not touch. The repository change also
matters by itself: without the filter, a claim can take the system tenant's
row in place of the caller's, and the store refuses a write the caller may
make.
