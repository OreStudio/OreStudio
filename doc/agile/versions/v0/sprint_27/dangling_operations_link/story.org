* Decisions

- The link is dropped rather than repointed. =ores.iam.operations= was
  withdrawn deliberately (it duplicated the census migration, spelled the
  operations with a hyphen, and invented a second shell menu), so no model
  declares the credential's writes today. The sentence still carries the
  claim, =iam.v1.ops.*=, and can link again when a model owns them.
- The prose is emitted, not documentation-only. The same paragraph appears in
  the domain header, the SQL create and the ER diagram, so the edit is a
  codegen change and all three are regenerated with it.
- The link is not repointed at the census story. Durable documents linking
  into agile content is already an advisory with 242 instances; adding one
  more to carry a pointer that will be stale once the migration lands would
  make the page worse, not better.
