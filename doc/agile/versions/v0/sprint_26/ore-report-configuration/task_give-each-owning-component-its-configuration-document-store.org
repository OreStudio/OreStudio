* Acceptance

- refdata owns the curve configuration and conventions document types and stores; analytics owns pricing engines and today's market; reporting owns the run document, its configuration rows and bindings.
- The ores.ore mappers produce and consume the owners' document types.
- The corpus round trips in ores.ore exercise every owner's store, and each owner tests the rules ORE does not drive: the run document's refusals and bindings in reporting, the world and party conventions rule in refdata.
- ores.ore.core's run store calls the owners' services instead of their repositories; [[id:2355DF78-E4AC-404E-8053-B8AE464538D6][Package the run input through the owners' operations]] removes it.

* Result

Each configuration document's type and store now live with the component that
owns its tables, and =ores.ore= maps ORE XML to and from those types.

- Types: =refdata::domain::curve_configuration_document=, =conventions_document=
  (with =fx_convention=), =analytics::domain::pricing_engines_document=,
  =todays_market_document= and =reporting::domain::run_document= (with
  =run_analytic= and =run_parameter=). The =mapped_*= structs in =ores.ore= are
  gone; the conventions mapper reports its unmodelled categories through its
  own function, since they are not stored data.
- Stores: =curve_configuration_document_service= and
  =conventions_document_service= in refdata, which owns the world and party
  conventions rule; =pricing_engines_document_service= and
  =todays_market_document_service= in analytics; =run_document_service= in
  reporting, which also creates the configuration rows and their bindings.
- =assign_party= and the document read helpers moved to =ores.database=, so the
  owners stamp parties without depending on =ores.ore=.
- =ores.ore.core='s =document_store= is deleted. Its =run_store= calls the
  owners' services; it remains only until [[id:2355DF78-E4AC-404E-8053-B8AE464538D6][Package the run input through the owners' operations]]
  puts the package step on the owners' NATS operations.

The corpus round trips in =ores.ore= exercise every store; reporting and refdata
test the rules ORE does not drive. ctest 90/90 after a database recreate.
