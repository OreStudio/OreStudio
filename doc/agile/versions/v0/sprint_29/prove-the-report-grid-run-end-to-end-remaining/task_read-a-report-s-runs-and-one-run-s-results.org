* Result

A report now keeps its definition first and puts its runs beside it, and a
result is only ever read on the run that produced it.

The report page has two tabs. *Definition* is the record, and it is the tab that
opens. *Runs* lists the report's runs newest first with the state each reached,
when it started and finished, and the date it priced at. Each row offers two
things: *Details*, the run's own page, and *Results*, the same page with the
figures open.

A run's page carries two tabs. *Run* states the report the run came from, its
kind, its state, its times, the date it priced at with the note explaining a
substituted date, what the run said when it finished, the output archive's key
with a download, and the way to the run's errors. *Results* is the figures: the
trade count, the total of each currency, then one row per trade.

The run that shows it is =9ff0e92e-f21d-4137-bb24-ad4956fa99f0=, on the NPV
definition of ACME Corporation HK Ltd. Its Run tab says =Report execution
completed.= and names =reporting/runs/9ff0e92e-.../output.tar.gz=. Its Results
tab shows eight bond trades and a total NPV of =31,607,092.99= HKD.

The earlier task put results on the definition's own page, which read figures
without the run that produced them and hid the definition behind them. This task
replaces that.
