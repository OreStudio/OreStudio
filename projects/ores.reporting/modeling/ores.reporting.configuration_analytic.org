One row per =Analytic= element in the run document that a configuration describes: which analytic to run, in what order, and whether it is on. A report definition binds a shared configuration, and the configuration owns its analytics, so reports that run the same analytics share one set of rows. The parameters of an analytic are rows of =configuration_analytic_parameter=.
