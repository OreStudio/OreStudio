* Goal

MCP's authorization specifies OAuth 2.1, with the server publishing protected resource metadata and the client obtaining a token from an authorization server. ORE issues its own sessions and tokens. Decide how an outside MCP client signs in as a person: ORE as the authorization server, a token the person issues in ores.web, or another way, with the options considered and a recommendation. Decide early, because it shapes the MCP session store and how a call is recorded as made over MCP, for that person.
