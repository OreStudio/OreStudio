#+title: ores.marketdata.series_identity_shape_entry
#+description: One identity field an identity shape requires or forbids, stated as data so the writer can refuse a row that misses one.
#+type: ores.codegen.entity

#+filetags: :model:entity:marketdata:
#+entity_singular: series_identity_shape_entry
#+entity_plural: series_identity_shape_entries

#+brief: One field of an identity shape, and whether the shape requires it or forbids it.
#+created: 2026-11-19
#+updated: 2026-11-19

An entry of an identity shape, one row per field the shape speaks about.

The shape it belongs to is named by its code, and the shape holds the family:
the asset class, the series subclass and the index family. The entry says what
the family makes of one field: =required= means a row of this family that
leaves it empty is not an identity, =forbidden= means the field says nothing
about this family and a row that fills it states something untrue. A field a
shape does not mention is neither: the family does not use it, and the writer
leaves it as the URI parse left it.

The writer that projects an identity row from an oresmd URI reads the shapes
and their entries together, and refuses a row that misses a required field or
carries a forbidden one, naming the family and the field.

* Columns

** id
:PROPERTIES:
:type:        uuid
:cpp_type:    boost::uuids::uuid
:primary_key: true
:END:

UUID that names this entry. An entry is one field of one shape, so the pair of
=shape_code= and =field= is unique among the current rows, by the declared index
below. A surrogate key names the row by one value, so its history reads as any
other record's.

** shape_code
:PROPERTIES:
:type:        text
:cpp_type:    std::string
:nullable:    false
:END:

The code of the identity shape the entry belongs to, such as
=ir.index_fixing.ibor=.

#+begin_src cpp :name generator
std::string("ir.index_fixing.ibor")
#+end_src

** field
:PROPERTIES:
:type:        text
:cpp_type:    std::string
:nullable:    false
:END:

The identity column the row speaks about, named as =market_series_identity=
holds it: =ccy=, =unit_ccy=, =index=, =instrument_type=.

A name that is no column of that table is a statement nobody can act on, so
=build/scripts/check_marketdata_identity_columns.py= checks every seeded row
against the table's columns at build time.

#+begin_src cpp :name generator
std::string("ccy")
#+end_src
