#+title: ores.refdata.conventions_import_operations
#+description: Codegen operation model for the conventions import: begin a staging session, stage one family, and commit the staged families.

#+brief: Begin, stage and commit a conventions import.
#+filetags: :model:operation:refdata:
#+created: 2026-10-18
#+updated: 2026-10-18

The operations a caller takes to import a conventions bundle. The bundle is
too large for one message, so the caller begins an import, stages one family
per message, and then commits. Every staged family reaches the live
conventions tables only on the commit, in one transaction.

A repeated begin with a known id answers the import that already exists, so a
retried begin opens no second session. A repeated stage of the same import,
family and sequence is refused. A commit applies only a staging import.
