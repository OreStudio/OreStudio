FxWorstOfBasketSwap	ORE's class runs a script of its own, not the library one. The library script reads one fixing of the floating index on each fixing date where the class compounds an overnight index over the period, and the twin pays the initial fixed amount on the first period date where the class pays it on the first pay date. The two differ by a few percent.
