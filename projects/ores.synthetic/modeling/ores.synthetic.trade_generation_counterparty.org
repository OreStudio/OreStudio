#+created: 2026-10-15
#+updated: 2026-10-15

One counterparty a trade generation config faces. The counterparty scope of
a configuration is a set, so it is a repeating field set and lives here, one
row per counterparty, rather than a column on the config.

The row is what makes the population reviewable. A party holds thousands of
counterparties and only a handful of tradeable links, and a trade against a
counterparty outside the tradeable set inserts cleanly and is wrong. The
scope states the intended set, and the generator draws from it rather than
from the whole counterparty table.

Counterparty-scope rows belong to a parent config through =config_id=, the
same one-config-many-children shape =gmm_component= uses for its parent
=fx_spot_generation_config=.
