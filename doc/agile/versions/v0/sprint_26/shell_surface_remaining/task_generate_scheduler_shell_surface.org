* Goal

Every shell command scheduler answers is produced by a generated unit, or the model states why it renders none. The component has no shell part, and job_definition already states that reason in its Physical space. The task completes the record for scheduling_operations and audits the hand-written scheduler_commands unit, which registers six verbs.
