* Goal

Claude Code runs one model per session, so we cannot copy pstack's multi-model rigor. The Council substitutes persona diversity for model diversity, which is a good substitute where the value is framing and a poor one where the value is independent error detection, because eighteen personas over one model share that model's blind spots. Bind the Council to the convening function for design forks and contested judgements, and at the same time make the architecture's other half real: route error detection to the checkers that genuinely do not share the session model's priors, which are the compiler, the test suite, the schema validators, CI and the review bot. Record the verdict on the task, never as a silent change to the code.
