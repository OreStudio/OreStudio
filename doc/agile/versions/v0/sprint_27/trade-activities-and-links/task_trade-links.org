* Acceptance

- trade_link joins two trades with enforced foreign keys and a type from trade_link_type, and records the trade activity stamp that made it.
- A link a process created carries that run as well, once the run model lands; the column is nullable until then.
- trade_link_type names the from and to roles and the economic effect, seeded from the link catalogue (novation, exercise, roll and the rest).
- Nothing in the tree carries a successor trade id.
