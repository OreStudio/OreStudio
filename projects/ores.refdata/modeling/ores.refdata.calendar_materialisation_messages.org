The on-demand calendar materialisation command.

The command extends a calendar's materialised =calendar_dates= up to a
year. It is a command, not a row: it carries no payload type and no
entity backs it, so both messages are message-only.

#+begin_src cpp :name comment
/**
 * @brief On-demand "regenerate up to <year>" command for calendar_dates.
 *
 * Extends (never rewrites below the existing watermark) a single
 * calendar's materialised calendar_dates, or every calendar's, up to
 * end_year. No cron job triggers this -- it is user- or save-action-
 * triggered only.
 */
#+end_src
