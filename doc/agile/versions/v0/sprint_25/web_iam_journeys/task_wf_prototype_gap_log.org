* Goal

Question: when a prototype exposes a modeling error or a missing
server-side operation, where does that finding go, and in what shape?
Decide the artefact -- a gaps document beside the map, the ticket's own
Result, or a product-backlog capture -- and the fields each entry
carries, so a route, a message or a field the server does not yet
provide is not lost. The inventory already names the first entries: no
forgot-password operation, no account activate or deactivate, no way
for an administrator to end another account's session, and session
statistics with no NATS subject. Not blocked by anything.
