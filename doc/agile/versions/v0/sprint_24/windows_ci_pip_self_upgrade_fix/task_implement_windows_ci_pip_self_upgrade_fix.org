* Result

compass.sh now upgrades pip via `"$VENV_BIN/python3" -m pip install
--upgrade pip -q` instead of invoking `"$VENV_BIN/pip"` directly --
on Windows, pip.exe cannot overwrite its own running binary and
fails with "ERROR: To modify pip, please run the following
command...", exactly the failure seen in the Windows CI run
(job 90156725928). Verified locally (Linux) by clearing the venv's
requirements stamp and re-running compass.sh; Windows verification
deferred to CI on this PR.
