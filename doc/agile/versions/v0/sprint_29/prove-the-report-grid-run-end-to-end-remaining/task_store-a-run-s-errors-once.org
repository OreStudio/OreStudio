* Result

A redelivery of the step that reads a run's output no longer stores the same
reasons twice. The recorder asks the run whether it already holds errors and
returns before writing when it does. The guard covers the run-level failure row
as well.

An engine scope the vocabulary does not name no longer costs the whole batch.
The rows the vocabulary does name are stored, and the scope that could not be
placed is said on the run as a report-scope warning naming it, so the loss is
visible on the screen rather than only in a log.

Proven by the reporting suites: a batch with one known and one unknown scope
stores two rows, the curve and the warning, and recording the same errors twice
stores one.
