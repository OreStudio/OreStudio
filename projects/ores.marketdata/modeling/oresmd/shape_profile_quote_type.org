* Quote types

The class carries no currency, no tenor and no metric key: the entity is the
profile and the coordinate is the date, the second of the day and the period the
profile is sampled on. ORE writes the metric as the second segment, so the one
metric is its own quote type here -- the `metric` query key is one of the IR-only
keys every other class rejects.

| shape_factor | SHAPE_PROFILE | shape_profile | SHAPE_FACTOR | composite       | no_ccy          | SHAPE_PROFILE/SHAPE_FACTOR/PROFILE/DATE/SECOND/PERIOD, plus the DST flag the corpus writes as a seventh segment. | date,second,period,dst | date,second,period,dst |

* Enum brief

The `quote` query key for shape profiles. Shape-profile-only; only meaningful
when `type=quote`.

* Identifier brief

A fully-resolved oresmd identifier for a shape profile (asset_class=shape_profile).

* Requirement brief

A logical, possibly-partial oresmd requirement for a shape profile.

* Coordinates

The coordinate dimensions this asset class's keys carry, and the kind of
value each holds. A key that also appears in the Fields table above must
declare the same cpp_type; every key a =* Quote types= row lists is either
declared here or a field above, and absence means identity.

| query_key | cpp_type | value_kind | notes |
|-----------+----------+------------+-------|
| date | std::optional<std::string> | string | The date the shape factor is quoted for. |
| second | std::optional<std::string> | string | The second of the day within the period. |
| period | std::optional<std::string> | enum | The period the second is counted in. |
| dst | std::optional<std::string> | enum | The daylight-saving flag the corpus appends. |
