* Acceptance

- The extractor reads a class's base from any file in the checkout, so a class declared in a header and defined in a source keeps its inheritance.
- The six leaves a yield curve segment inherits are recorded under each of the twelve segment kinds.
- The regenerated contract carries them, and a query counts the segment leaves before and after.
- The dataset and value-set checks pass, and the artefact is the generator's.

* Plan

One map, collected before anything is built. `classes()` read `class X : public Y`
from each file and looked the base up in that file's map, so a class declared in
`yieldcurveconfig.hpp` and defined in `yieldcurveconfig.cpp` kept no base and every
leaf it inherits was lost. The base map is now filled from every file the
extractor reads before any class is built.

The leaves that come back are the ones the base reads: `Type`, `Conventions`,
`PillarChoice`, `DuplicatePillarPolicy`, `Priority` and `MinDistance`, under each
of the twelve kinds.

* Notes

- *What the unresolved blocks say.* Walking the base adds 25 blocks the extractor
  cannot resolve, almost all a segment's `Quotes`: a quote list is a collection of
  `Quote` elements, not a leaf, so the extractor records it as a block with no
  parser rather than inventing a leaf for it. That is the honest answer, and it is
  why the count moved.
- *The screen follows the contract.* The page reads these leaves by path, so a
  segment's conventions and pillar choice stop drawing as gaps once the contract
  carrying them is published; no screen change was needed.

* Result

A segment's inherited leaves reach the contract. The extractor now reads a class's
base from every file it reads, so the six leaves `YieldCurveSegment::fromXML`
reads — `Type`, `Conventions`, `PillarChoice`, `DuplicatePillarPolicy`, `Priority`
and `MinDistance` — are recorded under each of the twelve segment kinds.

Measured on the regenerated tree: 434 terms became 480, the artefact's curve rows
went from 253 to 265, its segment rows from 26 to 38, and `Conventions` went from
no row at all to twelve. The dataset and value-set checks pass, and the artefact
and the value sets are the generators'.

What it does not fix: a segment's `Quotes` is a collection of quote elements, and
the extractor records it as a block it cannot resolve rather than as leaves —
which is why the unresolved count rose from 8 to 32.
