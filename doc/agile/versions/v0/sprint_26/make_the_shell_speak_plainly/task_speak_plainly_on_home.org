* Result

Home and the shell speak plainly.

- *One read for the home.* =GET /api/overview= answers the counts (in
  service, on evaluation, setting up), the tenants needing attention (a failed
  setup leads to its run, a suspension to the tenant), the first five tenants
  with their setups, and the five newest setups named by tenant. Every count
  is a list read that asks for its total, so the counts are the registry's own;
  the system tenant and test tenants are left out as the roster leaves them out.
  A failed run read empties the activity and says so. The wire-protocol package
  gains the shape, a tenant read by id, and a read of the newest runs.
- *Menus, not journey cards.* Each mode's menu lists real screens and marks
  the open one: Home and Tenants; Home, Parties, Rescue access and Sign-ins;
  Home.
- *Three homes.* The system administrator's follows the prototype: the health
  card with a plain verdict, recent activity, needs attention and the first
  tenants, with the status colours the badge catalogue already holds. The
  tenant administrator's offers the tenant's screens as tiles; the prototype's
  live figures are left out, because counting locked accounts or failed
  sign-ins would need every page of those reads, and a first-page count would
  be wrong in a large tenant. The party user's says where they work and marks
  the areas this release does not have.
- *Words.* Every user-facing journey string is gone in English, French and
  Portuguese, and the roster names its own add button.
- *Tests:* 4 BFF cases for the overview (counts by filter, never the system or
  test tenants, the runs unavailable, refused outside system administration);
  the home tests rewritten, including that no mode's home names a journey; the
  route table and roster tests moved to the new words. BFF 129, web 232, wire
  protocol 68, all passing; typecheck and prettier clean.
- *Not read live.* The deployment holds the operator's own administrator, whose
  password this session does not have; the live read is left to the story's
  final deployment.
