#+title: Cap the rows a generated list may return
#+description: The generated list applies the caller's limit and no ceiling of its own, so a client that states none, or a large one, pulls every row the filter matches. The result rows are one such list: the BFF asks for 20,000 rows of one run, and any other client with the read permission could ask for every row of the tenant. A page cap in codegen, or a required filter for a table whose key is a run rather than a row, is the decision this captures.
