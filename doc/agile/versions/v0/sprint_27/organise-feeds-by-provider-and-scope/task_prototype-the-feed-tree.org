* Notes

- From the Qt window the prototype keeps: the running, stopped or partial state
  with its count on every node; one folder-scoped request to start or stop a
  subtree; and the two-flag pair. It leaves the editing, the mixture and the
  live chart to the feed pages.
- The variants are the tree and node panel of the Qt window (=a=), a single
  tree table (=b=), and drill-down columns that load a page of children at a
  time (=c=). Only =c= does not render a large folder whole.

* Result

Shipped: the prototype as one flow under a Synthetic folder card of Market
data. The first version's three layouts were reviewed: the columns became the
Feed overview, which stops at the feed kind; the tree became the Feed tree,
whose feeds open their existing pages with a breadcrumb back through the tree;
the tree table was dropped. The menu structure page is amended for a folder
inside an area, a folder page that holds cards only, the Synthetic addresses,
and the feed page's trail through the tree. Build the feed browser builds it.
