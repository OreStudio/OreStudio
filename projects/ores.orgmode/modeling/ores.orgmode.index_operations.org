=ores.orgmode.service= rebuilds the knowledge index when it starts and after
each publish of the knowledge pages. This operation rebuilds it on demand, from
the pages already loaded. A rebuild replaces the whole index in one
transaction, so running it again gives the same index.

The index is the whole deployment's, not a tenant's, so the operation needs
the installation permission =installation::knowledge_index:rebuild=, which a
tenant administrator's =*= does not cover.
