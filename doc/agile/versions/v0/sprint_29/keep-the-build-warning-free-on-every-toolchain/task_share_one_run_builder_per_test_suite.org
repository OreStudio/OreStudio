* Result

Each suite builds a run from one definition. The reporting tests call
=a_run_stamp(priced_at)= from =run_stamp_fixture.hpp=, and the marketdata
tests call =a_market_state_run(as_of)= from =market_state_run_fixture.hpp=;
each copy differed only in its date, which is now the parameter. The
marketdata copy an earlier fix renamed to =a_stored_run= is gone. The
fixtures stay in their components' tests rather than in =ores.testing=,
because the types they build live in the two components' cores, which the
shared testing library does not link. The gate passes 20 of 20, the unity
collision check among them.

The duplicates reached main because the PR that added the second reporting
copy, #4381, merged without the local gate ("compass check not run, per the
operator").
