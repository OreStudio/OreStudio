* Notes

Bound to [[id:5D3A6D13-73E0-41A5-9E08-0C8C11BD609E][Artefact staging only]] (alongside its shape profile): this
artefact type's own row in =ores_dq_artefact_types_tbl=
(=lei_relationships=) has =target_table=/=target_subject= both null --
explicitly terminal, not published anywhere. GLEIF LEI
corporate-hierarchy data is queried directly from the artefact table;
a same-component main table would be an orphan nobody designed for.

Qt UI deliberately disabled (see Physical space below): same rationale
as =lei_entity= -- the generated read-only Explorer list window
queried the (correctly nonexistent) main table and errored on open.
