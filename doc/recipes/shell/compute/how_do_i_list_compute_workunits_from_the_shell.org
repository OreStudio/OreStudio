#+title: How do I list compute workunits from the shell?
#+description: List the workunits of the compute grid as a table, optionally filtered to one batch by external reference.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:compute:workunits:
#+created: 2026-08-11

The compute grid verbs live in the shell's =compute= menu. They talk
to the ~ores.compute~ service over NATS; the domain shapes and table
renderers come from ~ores.compute.api~.

* Question

How do I list compute workunits from the shell?

* Answer

Log in as the system super admin, then run =compute list-workunits= to print every workunit as a table: id, batch id, app version id, input uri, priority, target redundancy, modified by, recorded at. Pass =--batch= with the batch external reference to filter to one batch.

#+name: list-compute-workunits
#+begin_src ores-shell :exports none
connect $ORES_NATS_URL
login super_admin@localhost Secure-Password-123
compute list-workunits
logout
exit
#+end_src

#+begin_src sh :noweb yes :results output :wrap example
./ores.shell ${log_args} ${connect_args} << 'EOF'
<<list-compute-workunits>>
EOF
#+end_src

Pass =--batch= with the batch external reference to filter to one
batch.
