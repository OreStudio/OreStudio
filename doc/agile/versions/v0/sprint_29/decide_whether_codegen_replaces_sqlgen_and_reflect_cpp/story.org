* Goal

A decision, with measurements, on whether the generator emits raw SQL, MessagePack and JSON code for every entity in place of sqlgen and reflect-cpp, and if so the plan to move.

* Acceptance

- Measured: read and write speed, allocations, build time and binary size of
  generated raw code against sqlgen and reflect-cpp, for a few representative
  entities, with the commands and commits that produced each number.
- Listed: every sqlgen and reflect-cpp feature the platform uses, and how
  generated code covers each one.
- Decided: keep, replace, or replace in part, with the reasons and, if
  replacing, the order of the move.
