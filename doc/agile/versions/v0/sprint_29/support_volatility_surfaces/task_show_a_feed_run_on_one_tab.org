* Result

A feed's /Run/ tab replaces the /This run/ and /Variance/ tabs. It holds four
cards in the calibration page's style: the start level in market convention, with
the fixing, provider, orientation, date and item; the fixing window as tiles,
each marked as setting the spread or recorded only; the daily variance as a table
of Alpha (α), Gamma (γ), Beta (β) and persistence; and the calibration the run
used, whose id links to the feed's calibration page. When the config names a newer
calibration, the card names both and says a restart runs it. The card and tile
components moved to =ui/Card.tsx= so both screens draw the same block.

The same pass fixed the calibration page: the GARCH names kept their Greek
letters, which the uppercase caption had turned into capitals, and an authored
calibration no longer claims its starts disagree.
