#+title: View a report's runs from its definition screen
#+description: The report definition screen says what a report is configured to run, but not what it has actually run. There is no way to walk from a definition to its runs, so a person who has just changed a definition cannot see whether the next run behaved, and a person investigating a failure starts from the grid's job list instead of from the report.

Add a Runs tab to the report definition screen. It lists the definition's recent report runs, newest first, with the state, the party, when it started and finished, and how many errors and warnings each recorded. A row opens the run page, and the Errors tab of that page carries the reasons.
