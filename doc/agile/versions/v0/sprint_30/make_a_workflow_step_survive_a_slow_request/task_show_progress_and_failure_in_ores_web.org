* Goal

A person watching a run in the browser sees the current progress line on the step's rail while it works, and a failure names the work that failed and why.

* Acceptance

- A step in progress shows its latest progress line on the rail.
- A failed step shows the work that failed and the reason, translated where a translation exists.
- A run that retried shows the attempts it took.
- The polling stops when the run reaches a terminal state, as it does today.
