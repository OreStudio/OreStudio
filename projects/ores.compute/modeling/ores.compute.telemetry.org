The grid telemetry surface: one request and reply for the dashboard
summary, and one fire-and-forget publish from a wrapper node reporting
what it has done since the last sample.

These are operations rather than entity verbs, so they are declared here
instead of being derived from an entity. The grid summary is computed, not
stored, and the node sample arrives from outside the service, so neither
is a row a caller addresses by key.

The handler that serves them stays hand-written beside this model, because
it reads the newest stored samples and calls the grid-stats function.

* Physical space

The shell commands are switched off. The grid summary reaches a person through
the hand-written =compute grid-stats= command, which sends
=get_grid_stats_request=, composes it with the host listing, and can watch the
grid while a batch runs. A generated unit would send the same request and print
the reply, so it would be a second command for one read.

 * draws a value: a gap is not a measurement of zero. Only nodes with a sample in
 * the range are listed.

#+end_src

** get_grid_usage_request
:PROPERTIES:
:subject: compute.v1.ops.get_grid_usage
:response: get_grid_usage_response

#+begin_src cpp :name comment
/**
 * @brief Asks who uses the grid, with the work counted by group.
 *
 * It carries no fields, because the caller's session decides the scope and the
 * grouping. A session in the system tenant reads the work of every tenant and
 * gets one group for each tenant. Any other session reads its own tenant, and
 * only the parties it acts for, and gets one group for each party.
 */
#+end_src

** get_grid_usage_response
:PROPERTIES:
:END:

#+begin_src cpp :name comment
/**
 * @brief The work of the grid counted by group, as columns.
 *
 * Group i is described by keys[i] and by entry i of every other column. The
 * group is a tenant when group_kind is "tenant" and a party when it is
 * "party". A key that is empty stands for work with no party, which predates
 * the party scope. The share of a group is its entry in a column divided by the
 * sum of that column, which the caller computes.
 */
#+end_src
