#+title: How do I run the fx_spot_generation_configs commands from the shell?
#+description: Every command the fx_spot_generation_configs submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:fx_spot_generation_configs:

This file documents the fx_spot_generation_configs resource at the shell, one section per command. Every command is a subcommand of =fx_spot_generation_configs=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

:PROPERTIES:
:ID: 6A693030-069C-5873-B786-9C771B063E99

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
fx_spot_generation_configs list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =synthetic.v1.fx_spot_generation_configs.list=.

** =set=
:PROPERTIES:
:ID: A52CEBCC-7846-5E40-8AC3-B6CA5C0AAA17
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses.
