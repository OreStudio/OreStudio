* Result

Every audit account cell now reads the username on its first line with the
account UUID beneath it in small monospaced type: the active sessions, the
session statistics, the failed attempts and the auth events. The page builds
one id-to-username map from =api.accounts()=; an unknown id or a failed
accounts read falls back to the UUID alone rather than an empty cell.

The failed-attempts panel keeps every =ores_iam_login_info_tbl= row, because
the row is per-account login state and not an event: both account-creation
paths insert it, and =account_operations_service::login()= refuses without it.
The zero sentinels now read as such instead of lying: =1970-01-01 00:00:00Z=
renders as *Never signed in* and =0.0.0.0= as *Never*, in all three locales.
Rows order most-failed first, then accounts that have signed in, then the
never-used ones.

=Audit= also gains a card on =PartyHome=, which offered none, so a
party-scoped administrator reaches the screen the same way a tenant
administrator does. =SystemHome= offers no cards at all, so it was left alone.
