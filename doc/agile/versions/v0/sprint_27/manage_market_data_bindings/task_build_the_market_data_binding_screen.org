* Goal

The screen follows the prototype. It lists the bindings with their source, the series behind each and the last tick, and lets a person bind, rebind, enable, disable, start and stop for synthetic data. Real data stays a shown and unsupported case. The task is split into server and web tasks once the prototype is signed off.
