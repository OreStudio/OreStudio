* Goal

A report is ready to run only when its four configuration documents exist. Acme crafts them itself. This task decides their content per party, from the report design in the sprint 27 investigation of which reports each party runs, and writes the design down with its justification before any publishing is built.

* Acceptance

- A design page states, for each party, which pricing engines, today's market, curve configuration and conventions documents it holds, what each contains, and why.
- The design names every static input the reports need beyond those four documents, or states that there is none.
- The design is independent of ORE import data and says how it differs from the ORE samples it is inspired by.
