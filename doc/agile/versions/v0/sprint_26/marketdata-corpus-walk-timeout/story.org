* Result

The corpus walk's per-file check was quadratic: it read every series in a
growing tenant, one query each, after every file. One query per file on the
source tag replaces it, and the check now compares (key, value) pairs. The
suite runs in 367 s locally where it took 1,570 s, with the same assertions.
The import's own per-series lookups remain, captured for follow-up.
