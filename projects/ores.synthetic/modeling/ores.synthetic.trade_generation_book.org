#+created: 2026-10-15
#+updated: 2026-10-15

One book a trade generation config books into. The book scope of a
configuration is a set, so it is a repeating field set and lives here, one
row per book, rather than a column on the config: a party holds up to twenty
books and the population spreads across them.

The row references a real book of the config's own party. The trade booking
trigger refuses a book that belongs to another party, so a row naming one
would write no trade. The generator resolves the reference rather than
inventing it, and that resolution is what fails loudly when the reference is
missing.

Book-scope rows belong to a parent config through =config_id=, the same
one-config-many-children shape =gmm_component= uses for its parent
=fx_spot_generation_config=.
