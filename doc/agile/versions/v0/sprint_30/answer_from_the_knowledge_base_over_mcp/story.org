* Goal

An agent connected to ores.http over MCP is asked "what is volatility". It
finds ORE's own pages on volatility, answers from them, and gives a link to each
page it used, which opens as a page of ores.web.

This joins two stories and starts when both are done:
[[id:05FE6068-3CBD-4B93-B6AE-47A5689F1FCB][Search the knowledge base from ores.web]] and
[[id:008127D7-B897-4CF7-854B-6DDFB89AC7F4][Serve ORE's API to LLM agents over MCP]]. The analysis is in
[[id:3237D7CF-8EBA-4B9B-9B54-7135A4A7AA4A][How the assistant answers from the knowledge base]].

* Acceptance

- MCP offers the knowledge search and the page reads as tools, and the pages as
  MCP resources, through the knowledge service.
- A section given to a model is written as Markdown, with its page's title, its
  heading path and the ores.web address of its page at its anchor.
- Asked a question the knowledge base covers, an MCP client answers from the
  pages and links each page it used.
- The set of questions from the knowledge story is run through an MCP client,
  and how often its answer cites the right page is recorded.
