The header the dispatch unit and every per-family unit include. It states one
apply function and one payload-read function per convention family, taking and
returning only strings, so including it instantiates the serialisation of no
family. The definitions live in the per-family units that the
[[id:390E401F-EF5C-4E3F-BB18-48A00D37CAA9][ores.cpp.convention-family]] facet renders.
