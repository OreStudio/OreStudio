Reference data table defining the closed activity category set used by
=ores.trading.activity_type=. The rows are the categories the trading
activity seed (projects/ores.sql/populate/trading/trading_activity_types_populate.sql)
already uses, so the set is the component's own rather than an external standard.

The values are the ORE XSD spellings, so a stored value round-trips through the
ORE XML unchanged. No conversion is introduced here.
