The class declaration for one entity's shell command unit. The unit owns
one submenu of the component's root menu and one =process_*= handler for
each of the four CRUD verbs.

Two substitutions place the output, and both come from ={component}=, the
short component name without the product prefix. The part directory is
=ores.shell.<component>=, so a =trading= entity writes into
=projects/ores.shell/trading/=. The include path keeps the shared
=ores.shell/= prefix the other parts use, so a unit moves between the
adapter parts without an edit to any =#include=.

See the [[id:C4E8A91F-3B7D-4F2E-85A6-1D9C7E3B2F4A][Template variable reference]] for the complete list of available
variables and their semantics.
