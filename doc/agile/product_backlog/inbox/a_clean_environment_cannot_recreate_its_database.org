#+description: Environment format 39 removed the service passwords, but compass db recreate still demands them, so a fresh checkout cannot build a database and the fleet has nothing to authenticate against until provisioning runs.

This page is a [[id:671F18E4-E09C-4B3B-BD24-D33DF8AE38A6][capture]] in the *inbox* bucket of the product backlog — a pre-sprint idea, not yet pulled into a sprint as a story.

* What

At environment format 39 the environment file carries no service password: each
service resolves its own from the vault before it opens a pool. =compass db
recreate= still requires one per service, so it refuses a clean v39 file, and a
database it did build would set each service role's password from a value the
file no longer carries. A fresh checkout therefore cannot build a database, and
the fleet it starts has nothing to authenticate against until =compass vault
provision= has run.

* Why

=cmd_recreate= appends =ORES_{service}_DB_PASSWORD= to its list of required
variables for every service the registry holds, and passes each one to
=create/iam/service_users_create.sql=, which runs =alter user ... with password=.
Both halves were written when the file carried the value. Environment format 39
removed the value and left both halves alone, so the pair now states a bootstrap
step that no longer exists.

The order a cold start needs is unchanged and still correct: a database exists
first, then provisioning writes each role's password, then the fleet starts and
each service resolves its own. What is missing is the first step's agreement with
that order: =recreate= either creates each service role without a password and
leaves it to provisioning, or it invents one, which is the duplication
provisioning exists to end.

solid dirac reported this on 2026-11-28 and recovered their environment by
restoring the previous file and declaring it version 39. The fleet runs, but
against a database built before the change, so that environment cannot recreate
until this is settled. It blocks every clean-environment request on main, which
is why it is written down rather than carried privately.
