#+title: Task: Settle the redelivery bound
#+description: The streams keep a message for a day, but a push consumer redelivers at most MaxDeliver times, currently ten, with the default AckWait of thirty seconds, so a service down for more than a few minutes exhausts its attempts and the command is lost anyway. That is a narrower promise than the durable subscription pattern now implies. Decide whether to widen the bound, make it explicit per stream, or state the real window, and make the documents say what the system actually does.
