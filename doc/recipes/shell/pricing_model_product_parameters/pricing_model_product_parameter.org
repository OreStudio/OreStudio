#+title: How do I run the pricing_model_product_parameters commands from the shell?
#+description: Every command the pricing_model_product_parameters submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:pricing_model_product_parameters:

This file documents the pricing_model_product_parameters resource at the shell, one section per command. Every command is a subcommand of =pricing_model_product_parameters=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: 2E9B88A6-F671-5813-A801-79B1CEB66CCF
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
pricing_model_product_parameters list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =analytics.v1.pricing_model_product_parameters.list=.

#+name: pricing_model_product_parameters-list
#+begin_src ores-shell :tangle pricing_model_product_parameters-list.ores :exports none
pricing_model_product_parameters list --limit 1
#+end_src

:PROPERTIES:
:ID: CB980F4B-6ADC-55D0-AEAB-AF2EA6FECDDB

** =add=
:PROPERTIES:
:ID: 86610F86-6090-5B22-99C4-901D54B562CC
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.


The command is shaped like this:

#+begin_example
pricing_model_product_parameters add <pricing_model_config_id> <pricing_model_product_id> <parameter_scope> <parameter_name> <parameter_value> <reason> <commentary>
#+end_example

It is addressed at =analytics.v1.pricing_model_product_parameters.put=.

** =set=
:PROPERTIES:
:ID: 2BC90B43-A9EB-516C-807A-F7C75F954AE8
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved. Passing --version makes the write conditional on the version the caller last read.


The command is shaped like this:
