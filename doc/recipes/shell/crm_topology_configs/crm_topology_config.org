#+title: How do I run the crm_topology_configs commands from the shell?
#+description: Every command the crm_topology_configs submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:crm_topology_configs:

This file documents the crm_topology_configs resource at the shell, one section per command. Every command is a subcommand of =crm_topology_configs=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: 849C74B2-D973-5BE7-84C3-D6DC88C13CA9
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
crm_topology_configs list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =refdata.v1.crm_topology_configs.list=.

#+name: crm_topology_configs-list
#+begin_src ores-shell :tangle crm_topology_configs-list.ores :exports none
crm_topology_configs list --limit 1
#+end_src

:PROPERTIES:
:ID: 4AE0DAF5-B4FF-5822-A155-51505F96ACDA

** =add=
:PROPERTIES:
:ID: 5C1E1A2C-F17C-5974-BB35-195FF7C742E0
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.


The command is shaped like this:

#+begin_example
crm_topology_configs add <id> <name> <pivot_currency_code> <enabled> <reason> <commentary>
#+end_example

It is addressed at =refdata.v1.crm_topology_configs.put=.

#+name: crm_topology_configs-add
#+begin_src ores-shell :tangle crm_topology_configs-add.ores :exports none
crm_topology_configs add 00000000-0000-0000-0000-000000000000 __none__ __none__ false system.new_record generated_script
#+end_src

** =set=
:PROPERTIES:
:ID: 585E1277-8D63-5B6C-B88F-CA8E2E104D67
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved. Passing --version makes the write conditional on the version the caller last read.


The command is shaped like this:

#+begin_example
crm_topology_configs set <id> <name> <pivot_currency_code> <enabled> <reason> <commentary> [--version <n>]
#+end_example

It is addressed at =refdata.v1.crm_topology_configs.put=.
