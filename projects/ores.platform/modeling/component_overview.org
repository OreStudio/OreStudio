* Summary

=ores.platform= is the single home for platform-specific code in ORE
Studio. It wraps the operating-system facilities that every other
component would otherwise reach for directly, so that no other component
carries a =_WIN32=, =__linux__= or =__APPLE__= conditional, and no other
component includes a raw OS header. A component that needs a platform
concern calls this component; when the concern has no home here yet, the
abstraction is added here first and only then used.

The component holds no ORE Studio dependency. Its dependencies are the
C++ standard library and Boost: =Boost::process= supplies the current
process id, and =Boost::exception= supplies the exception hierarchy the
filesystem facet throws. That independence is what makes it usable from
every layer, from the foundation libraries up to the services and the
shell, without a risk of a dependency cycle.

The component is model-free. It owns no entity, no NATS subject and no
protocol header, so none of its types is generated and none appears on
the wire. Everything it exposes is hand-written.

The time facet is the busiest surface by a wide margin:
=ores.platform/time/datetime.hpp= is included by several hundred files
across the tree, which is why its format policy matters beyond this
component. Timestamps are stored and transmitted as UTC, in ISO 8601
with a =Z= suffix; local time is used for display only.

* Facets

- =environment/= — process environment variables, read through an
  injectable =environment_provider= so that a caller can substitute an
  in-memory map for the real environment under test. The facet ships
  =fake_environment_provider= for that purpose, and =environment=
  routes every call through the installed provider.
- =filesystem/= — reading and writing file content, deleting a list of
  files, and the =file_not_found= and =io_error= exceptions the facet
  raises.
- =net/= — machine identity: the hostname, the primary non-loopback
  hardware address in both colon-separated and raw-byte form, and the
  stable machine identifier derived from the two.
- =process/= — the current process id, the path and build time of the
  running binary, and the signal set a service treats as a request for
  a graceful shutdown.
- =time/= — the time conversion and formatting surface. =datetime=
  owns the ISO 8601 and database string formats, =time_utils= owns the
  cross-platform =gmtime=, =localtime= and =timegm= wrappers plus the
  calendar-date conversions, and =relative_time_formatter= renders
  human-readable relative times such as "yesterday" and "in 3 days".

* Inputs

- Operating-system environment variables.
- Filesystem paths for file read and write operations.
- System network interfaces, for the hardware identity.
- The executable's own filesystem metadata, for its build time.
- =time_t= and =std::chrono= time points supplied by callers.

* Outputs

- Type-converted environment variable values, with the absent and the
  unparseable case both distinguishable from a real value.
- File content, and the exceptions raised when a file or directory
  cannot be read.
- The hostname, the primary MAC address, a stable hex machine
  identifier, and the current process id.
- Cross-platform =time_t= to UTC and local =tm= conversions, ISO 8601
  and database timestamp strings, calendar dates, and relative-time
  display strings.
- The running binary's path and build time.

* Entry points

- =include/ores.platform/environment/= — =environment=,
  =environment_provider=, =fake_environment_provider=,
  =real_environment_provider=.
- =include/ores.platform/filesystem/= — =file=, =file_not_found=,
  =io_error=.
- =include/ores.platform/net/= — =get_hostname=,
  =get_primary_mac_address=, =get_primary_mac_address_bytes=,
  =derive_machine_id=, =derive_machine_id_hash=.
- =include/ores.platform/process/= — =current_pid=,
  =executable_path=, =executable_build_time=, =shutdown_signals=.
- =include/ores.platform/time/= — =datetime=, =time_utils=,
  =relative_time_formatter=, =k_timestamp_format=.

* Dependencies

- The C++ standard library.
- =Boost::process= — the current process id.
- =Boost::exception= — the exception hierarchy the filesystem facet
  throws.

No ORE Studio component is a dependency of this one.
