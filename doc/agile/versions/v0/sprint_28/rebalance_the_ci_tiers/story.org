- macOS builds on macos-15, not the retiring macos-14.

* Decisions

- Continuous CI keeps linux-clang debug and release only. They were the
  only jobs that finished well inside the six-hour limit: 2h46m and
  2h54m on the last green run. The gcc jobs ran about 4h10m, and macOS
  4h40m to 5h40m.
- Continuous Linux runs every three hours, the tightest interval that
  does not queue a run behind its predecessor. The relevance-guard makes
  that a ceiling rather than a promise.
- macOS and Windows move to the nightly tier. macOS moves to =macos-15=
  because GitHub retires =macos-14= on 2026-11-02.
- Shrinking the matrix to two variants also fits their sccache inside
  GitHub's 10 GB repository cap, so a run can finish and reach its
  =Save sccache= step.

* Out of scope

- Coverage and packaging still run on the continuous clang jobs.
- The Windows run time is unmeasured. Its last run reported success with
  the build matrix skipped, so its cadence rests on an inherited figure.
