* Result

Delivered. The story is wired into Sprint 26 with four tasks, and the target
architecture is written as
[[id:01083101-A83A-4294-81A4-DDF3192CEB14][Report Processing]], a
knowledge page rather than a story document, because the target outlives the
story. That page replaced an earlier single document, written under the same
task, whose subject was the run's modes rather than the pipeline.

The story was framed as "integrate scheduling, reporting and compute". The
design found that the integration already exists along one path — the shell
can drive a batch to completion — and fails along the path the story needs,
because the reporting to compute handoff publishes on a subject no wrapper
subscribes to, leaves the workunit's fields empty, and hands over a URI in the
wrong shape. That work is the ACME smoke-test story's and this one waits on
it, recorded on the story so the dependency is visible rather than implicit.

Four tasks carry the rest: design, the execution mode together with
role-addressed step results, demo mode end to end, and full mode. The fourth
is deliberately deferred.
