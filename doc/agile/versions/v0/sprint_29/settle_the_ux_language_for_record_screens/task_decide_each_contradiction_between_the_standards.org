with the proposal each carries. Where the code already follows one page, that

record the decisions on the story.

* Result

Every contradiction the audit found has a decision on the page that now rules,
dated 2026-10-25, and the losing page points at it. A save does not reload the
page; a save with no field change is allowed; changed rows are found by
comparing pages; Edit and the version stand on the thing they belong to; the
dialog is titled Edit and the title of what it changes; the classification list
stays the one list read whole; a journey is a design document and a rail is a
wizard; labels are sentence case; the verbs live once; the breadcrumb's shape
belongs to Menu structure. The checklist offers no choice. The story records
the decisions.
