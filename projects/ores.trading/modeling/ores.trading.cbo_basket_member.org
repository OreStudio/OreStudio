** Custom repository methods

The trade read path fetches the cbo basket members of many instruments at
once, and no generated read covers that: the generated reads address one key
group at a time. The batch read below is one statement over the instrument
set.

*** read_by_instruments_batch
:PROPERTIES:
:ID: EA1705F5-D2F0-45F7-B6A1-1DA931188A81
:END:

Reads every current cbo basket member of the given instruments, in one statement. An empty input
reads nothing.

#+begin_src cpp :name implementation :implements F2EB1914-5E94-42CA-9C77-46BDB364BF9E
std::vector<domain::cbo_basket_member>
cbo_basket_member_repository::read_by_instruments_batch(
    const context& ctx, const std::vector<std::string>& trade_ids) {
    if (trade_ids.empty())
        return {};
    static constexpr auto max = db_timestamp::max();
    const auto tid = ctx.tenant_id().to_string();
    const auto query = query_builder::read<std::vector<cbo_basket_member_entity>> |
                       query_builder::where("tenant_id"_c == tid &&
                             "trade_id"_c.in(trade_ids) && "valid_to"_c == max) |
                       query_builder::order_by("trade_id"_c, "sequence_number"_c);
    return query_builder::execute_read_query<cbo_basket_member_entity,
                                             domain::cbo_basket_member>(
        ctx,
        query,
        [](const auto& entities) { return cbo_basket_member_mapper::map(entities); },
        lg(),
        "Reading cbo basket members for multiple instruments.");
}
