* Goal

Write a set of at least twenty real questions a person would ask about ORE,
each with the documents that should answer it. Run them through the ores.http
search route, which compass answers, and record how many find a right
document in the first five, and which miss. Ranking is compass's: the misses
go to compass as evidence, and the result decides whether ORE's documents
need better titles, descriptions or tags, or compass's search needs more.

* Acceptance

- The question set and its expected documents are kept in the repository, so
  the measurement can be rerun.
- The share found in the first five is recorded, with every miss named.
- The misses that are compass's ranking are reported to compass, and those
  that are ORE's documents are fixed or recorded.
