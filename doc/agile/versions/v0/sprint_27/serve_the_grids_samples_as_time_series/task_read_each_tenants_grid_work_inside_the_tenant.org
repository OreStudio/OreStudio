* Acceptance

- The policies batches_system_read_policy, workunits_system_read_policy and results_system_read_policy are removed, and so are their entries in the guard's exception list.
- The grid summary function counts only the tenant it is given.
- The usage read serves one tenant, grouped by party, and a system session reads its own tenant only.
- The operator's usage is built by entering each tenant and reading it there, and a tenant that cannot be read is shown as unavailable.
- The data read across tenants page states the rule and no exception.
