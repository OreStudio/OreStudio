* Decisions

- Add to the existing page rather than start a new one. The page already
  carries the method, its implementation here, and structure notes; the craft
  of composing a note is the same topic, and a second page would either
  duplicate it or need a hub neither would earn.
- The thesis discipline is scoped, not universal. Most pages here are
  definitions and catalogues, where a topic title is correct; the discipline
  binds the pages that argue. The source skill has no such distinction,
  because a personal vault has no reference corpus.
- The four relations are documentation, not a checked field. They describe the
  prose annotation a See also link already carries, so no schema change and no
  gate is introduced for them.
