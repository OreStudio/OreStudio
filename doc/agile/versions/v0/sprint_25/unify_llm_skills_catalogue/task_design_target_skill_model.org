* Acceptance

- The naming conventions document carries the compass- prefix rule, the six regulatory functions, and the =principle-= and =method-= segments.
- =#+level:= is mandatory on every skill, and the level-to-scope table from the architecture is recorded.
- The verb register gains every verb the ported methods need, each with its decision-log entry.
- The terminology table lands in the glossary, naming the retired synonyms and the two traps: spec means an Allium spec, persona means a Council member.
- The reference-only-skills rule is amended to exempt the citation function, with the reasoning recorded.
- The placement procedure from the architecture is reproduced where an author will meet it.

* Plan

The architecture already states the model, so this task moved statements
into the two documents that bind an author, and changed nothing about the
model itself.

The naming conventions document takes the =compass-= prefix, the five name
shapes, the =principle-= and =method-= second segments, a table mapping each
name shape to the regulatory function it offers, the =act-= and =export-=
verbs, the level register with its advisory and binding strengths, and the
placement procedure. The glossary takes the terminology register, because
terminology governs every document and the skills cluster is only one reader.

Policy binds where an author meets it, so =skill-add= carries the same rules
in its own steps: the naming step now states the prefix and the segments and
routes an unsure author to the placement procedure, and a new step makes
=#+level:= a filled-in field rather than a rule stated elsewhere.

* Notes

Three things the sources disagreed on, resolved in favour of the later
document and recorded in the decision log.

The acceptance says six regulatory functions. There are seven: /recording/
was added when the framework was respecified as a regulator, after this task
was written. The naming document carries all seven.

The design's terminology table renders the role a session adopts as
/function/, which now collides with /regulatory function/. The architecture
resolves it to /System/, and the glossary follows the architecture. The
glossary's =Agent= entry defined an agent as a subprocess forked by an
orchestrator, which is what the architecture calls a /delegate/; it now
carries the general definition, and =Session= and =Delegate= are separate
entries.

=#+level:= is mandatory from now on, and 52 of the 83 existing skills do not
carry it yet. Tagging them is its own task in this story, which is where the
sweep belongs; this task lands the rule and the register the sweep reads
from.

* Result
