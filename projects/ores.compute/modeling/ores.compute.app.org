Represents the high-level definition of an engine that can be executed on
grid nodes (e.g., ORE_STUDIO, LLAMA_CPP, LEDGER). The BOINC equivalent of 'app'.

The platform seeds shared compute apps under the system tenant (the
canonical apps every tenant runs). =:system_tenant_visible: true= makes the
generated repository read own-tenant OR system-tenant rows on every read
path, so tenant-scoped queries still see the platform apps. Mutations stay
own-tenant scoped.
