A typed sub-configuration owned by a =market_data_generation_config=. Describes
how to synthesise the tick stream for a single FX spot rate: which ORE market
key it produces, the starting price, the tick cadence, and the price process.
The price process is a Gaussian Mixture Model whose components are held
separately as =gmm_component= rows. Scoped to a tenant and a party.

** auto_start
:PROPERTIES:
:type:          boolean
:cpp_type:      bool
:nullable:      false
:default_value: false
:END:

Whether this config starts automatically when the service comes up,
as opposed to manual-start-only. Orthogonal to =enabled=: a config can
be =enabled=true, auto_start=false= (valid, manually startable, but
never auto-started -- e.g. a legacy/alternate-index variant living
alongside a currency's primary config so the two never silently fight
over the same published qualifier at boot). Starting a feed --
whether auto-start-at-boot or a manual Start -- is rejected outright
if another feed is already running for the same oresmd_uri; nothing
auto-disables the running one, so switching requires an explicit Stop
then Start.

** arrival_mode
:PROPERTIES:
:type:          text
:cpp_type:      std::string
:nullable:      false
:default_value: "periodic"
:default:       'periodic'
:sortable:      true
:searchable:    true
:END:

How the feed's ticks arrive. "periodic" gives equal gaps, "poisson" gives
exponential gaps and "hawkes" gives gaps that cluster. The long-run mean rate is
=ticks_per_hour= in every mode, so switching mode changes only how the same load
is spread in time.

#+begin_src cpp :name generator
std::string("periodic")
#+end_src

** branching_ratio
:PROPERTIES:
:type:          double precision
:cpp_type:      double
:nullable:      false
:default_value: 0.0
:default:       0.0
:END:

For "hawkes": how much one tick raises the rate of the next, as the expected
number of further ticks. At least zero and strictly below one; one or more has no
stationary rate and is refused. Ignored by the other modes.

#+begin_src cpp :name generator
0.0
#+end_src

** decay
:PROPERTIES:
:type:          double precision
:cpp_type:      double
:nullable:      false
:default_value: 1.0
:default:       1.0
:END:

For "hawkes": how fast a burst fades, in units of one over a second, so a value
means the same thing at any tick rate. Finite and strictly positive. Ignored by
the other modes.

#+begin_src cpp :name generator
1.0
#+end_src

** sensitivity
:PROPERTIES:
:type:          double precision
:cpp_type:      double
:nullable:      false
:default_value: 1.0
:default:       1.0
:END:

How strongly the market-wide arrival factor moves this row, where one is the
average series and a value below one makes it calmer than the market. Finite and
strictly positive. It does nothing until the market factor lands; a value of one
leaves today's behaviour unchanged.
