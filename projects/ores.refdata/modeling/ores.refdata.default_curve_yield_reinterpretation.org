The yield curve a default curve of type =YieldCurve= reads as survival
probabilities, as ORE's =ReinterpretedYieldCurve=. Only that construction reads
it, and ORE requires it there.

A default curve configuration holds at most one row of this part, so the generated table
adds the unique index on the live rows of =(tenant_id, default_curve_configuration_id)=.
