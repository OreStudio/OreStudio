* Goal

The import path formats a full JSON record for every entity it maps, at a
level that is not enabled. It is the largest single cost in the importer today
and it has nothing to do with XML, so it stands on its own.

* Acceptance

- A trace line that is off costs nothing: no formatting, no allocation.
- The importer's time per record falls by the share the formatting held.
- No log line changes at a level that is enabled.
