* Result

The session context that every connection acquisition writes is now one
statement instead of six, and the market data ingest pays about ten
transactions per stored tick where it paid about fifty. The measurement
is in the task's Result.

The remaining ingest cost is not in this story. The ingest still opens
one transaction per tick and stores one row per tick; batching the ticks
of a single instant into one transaction is captured for later, as is the
ingest that goes silent when the synthetic producer restarts.
