#+title: Account Contact Informations shell commands
#+description: Every command the account_contact_informations submenu answers, with the script each one exports into the shell's script library.
#+type: recipe

This file documents the account_contact_informations resource at the shell, one section per command. Every command is a subcommand of =account_contact_informations=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

#+end_example

** =add=
:PROPERTIES:
:ID: EA93F955-C6E6-5A9B-8922-4C8E6AA74FA3
