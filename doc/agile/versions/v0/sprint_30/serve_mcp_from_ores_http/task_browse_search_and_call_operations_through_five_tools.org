* Goal

tools/list answers five tools, whatever the catalogue holds: list_areas, list_entities, list_operations, find_operations by BM25 over names, areas, entities, summaries and descriptions, and call_operation. Every list shows only what the person may call, and only reads when the grant is read only. Every answer is short. A call without arguments, or with wrong ones, answers the operation's input schema and an example. A held write answers the approval request it raised.

* Acceptance

- tools/list answers the five tools whatever the catalogue holds.
- Each list answers tens of lines at most, filtered to the person's permissions and the grant's scope.
- call_operation runs a read and answers its result cut to a size a model can read; for a write it answers the approval request it raised.
- A call with missing or wrong arguments answers the input schema and an example.
