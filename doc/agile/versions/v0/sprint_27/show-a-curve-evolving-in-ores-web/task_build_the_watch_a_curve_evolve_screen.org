* Acceptance

- The screen reads the evolution through the BFF route and draws instants by nodes.
- It shows node status, value age, and provenance on request.
- A hole and a refusal each read as what they are.

* Plan

Add the contract schemas for the evolution and snapshot replies, a small api module that
posts to the two BFF routes, and a pure view module that turns the replies into a matrix
and a "now" table. Draw them in one page at =/market-data/evolution=: a form for the
object and the range, the matrix with each node's change, and the now table with age and,
on request, source. Open the page from the home's market data tile for a person who holds
=marketdata::curve_snapshots:read=. Catalogue every message in three languages.

* Result

A person who may read curves opens ores.web, follows the Market data tile on the home,
names an object by its typed identity and a range of days, and reads two things. The
matrix has a row per node and a column per instant, with each node's change over the
range (persistent, added, dropped, intermittent or never quoted). A missing value is a
hole drawn as a dash, never a zero. The now table gives each node's current value and its
age, and when the person asks, the source of each value with the recipe behind a derived
one and the author of a manual one. A server warning about stale values is shown, and a
refused read is shown as the server's reason.

The page is =market/EvolutionPage.tsx=. The matrix and now rows come from pure functions in
=evolutionView.ts=, which have their own tests. The home tile moves from Upcoming to Active
for a holder of =marketdata::curve_snapshots:read=; a person without it still sees it as
coming. All messages exist in English, French and Portuguese.

*What was not done.* The screen has not been looked at in a running stack. It is tested
with rendered markup and canned data, not with a browser, a live BFF or a database. The
object is named by typing its identity, because no read lists the series yet. A series
list route and a picker are the next improvement, and the story's Notes name them.
