#+title: ores.synthetic.feed_overview
#+description: Codegen operation model for reading a folder's children with the feed counts and the run state under each.
#+type: ores.codegen.operation
#+component: synthetic
#+subcomponent: api
#+entity_singular: feed_overview
#+namespace: ores::synthetic::messaging
#+brief: A folder's children with the feeds and the running feeds under each, and a page of the feeds in a folder.
#+filetags: :model:operation:synthetic:
#+created: 2026-10-13
#+updated: 2026-10-13

The reads behind the feed overview and the feed tree. A screen asks for the children of
one folder, or for the roots, and gets each child with the feeds under it, split into FX
spots and IR curves, and how many of them run. The service counts in the database and
takes the running feeds from the controller, so no screen reads the feeds to count them.
Nothing is stored.
