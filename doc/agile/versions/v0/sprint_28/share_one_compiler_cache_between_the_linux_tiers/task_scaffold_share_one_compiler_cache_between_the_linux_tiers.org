* Notes

The step difference is not a build difference: the hand-written names differ
("Ccache for gh actions" against "Setup ccache", "get-cmake" against "Get latest
CMake") for the same actions. The one genuine extra is Continuous's Boost header
check, which runs before the build and cannot change a compile line.
