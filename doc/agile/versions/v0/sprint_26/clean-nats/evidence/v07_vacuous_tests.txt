# V07: no vacuous test in ores.nats
# Run 2026-09-26. A test is vacuous when it passes although its subject
# does nothing: a bare length, a non-throw, a truthiness, or one production
# run compared with another.

## Finding

No test is vacuous. Every case asserts a literal expected value or a
specific parse outcome, and each REQUIRE_NOTHROW sits above an assertion on
the value the call produced (the parsed url, the empty cert path an
unrelated app's variable must leave alone). A subject that did nothing
fails the paired assertion.
