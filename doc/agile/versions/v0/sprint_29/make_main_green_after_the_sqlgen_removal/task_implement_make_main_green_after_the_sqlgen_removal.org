* Result

Every check of =compass check= passes: 73 of 73, the last four after the
fleet was stopped for the database recreate. The full site builds. Fixed, by
what failed on main:

- *SQL schema validation* (Continuous Linux, Nightly Build). Five tables had
  no row-level security: the two sensitivity lookups now read their own and
  the system tenant's rows, the structure identifiers are tenant-scoped, and
  a run's result rows are party-scoped like the run. The result rows'
  hypertable shape and the tenant-scoped curve publish are recorded as
  intended in the ignore file.
- *macOS build.* The libpq codec's time point bounds overflowed on a clock
  that counts microseconds, and the never instant decoded to a date in 9999
  there. Both bounds now stay inside the arithmetic, with a test that runs
  without a database.
- *Windows build.* =getenv= is deprecated in the CRT and a per-file define
  does not survive a unity batch: the environment provider uses =_dupenv_s=,
  tests read through it, and the time zone test skips on Windows. MSVC's
  reflect-cpp errors are out of scope.
- *Equity underlying.* The merge left out its event registrar, shell
  commands, permission seeds, scripts and recipe inventory, and its publish
  function's place in the write ratchet.
- *Codegen drift and sweep.* The composite instrument's write observation sat
  under Messages and produced invalid TypeScript; the paste-block check could
  not see a namespace opened by a chain; the structure service carried
  hand-written naming code a regeneration deleted, now model paste blocks
  through three new service template hooks; the result row lacked its domain
  includes; the marketdata test libraries, the snapshot protocol, the list
  request table, the facet inventory and the ER diagrams were stale.
- *TypeScript and shell script drift.* Prettier and a re-tangle.
- *Product website.* Three captures closed their property drawer with =:END=,
  which hid their ids.
- *Gate checks.* The pgTAP fixtures now state a trade origin and accept a
  product-wide parameter's XPath; the convention terms generator reads through
  field groups; a basket constituent's initial price is an exact decimal; the
  XML benchmark is recorded.

Not fixed here: the workflow engine's recovery errors on a database ctest has
used, tracked in the capture "Workflow recovery fails on test tenants left by
ctest".
