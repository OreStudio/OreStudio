* Goal

A Claude Code skill and companion runbook exist for evaluating the health of any entity: the
skill looks up coverage from the Entity Coverage Matrix (retired 2026-09-03), walks through
standard functional verification steps (load, edit, save, events, history), and produces a
concise gap report.
This replaces ad-hoc manual investigation with a repeatable, automated procedure.
