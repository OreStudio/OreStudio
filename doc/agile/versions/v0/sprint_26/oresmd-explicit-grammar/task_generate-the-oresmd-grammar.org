* Acceptance

- No query key is silently defaulted: the parser materialises a grammar default and the writer emits it, so model, metric and quote are always present where the grammar defines them.
- No coordinate is a comma-joined string: point is gone from the identifier, the parser and the writer.
- ATM is a delta and not a strike.
- The generated parser and projection tests use the new spelling, and the old point= forms are rejected by the parser.
- doc/knowledge/domain/market_data_urn.org describes the grammar that ships.
