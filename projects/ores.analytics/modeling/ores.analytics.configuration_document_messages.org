#+title: ores.analytics.configuration_document_messages
#+description: Codegen operation model for the configuration documents analytics owns: save, get and delete pricing engines and today's market documents.
#+type: ores.codegen.operation
#+component: analytics
#+subcomponent: api
#+entity_singular: configuration_document
#+namespace: ores::analytics::messaging
#+brief: Analytics' ORE configuration documents as operations.
#+filetags: :model:operation:analytics:
#+created: 2026-10-04
#+updated: 2026-10-04

The configuration documents analytics owns, as operations: pricing engines
and today's market. Another service reaches them only through these, never
through analytics' tables. The handler stamps the session's party on every row
it stores.
