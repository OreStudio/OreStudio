* Result

A security's name now states its issuer. =security_id_for= takes the issuer
id and the digest covers it, so two issuers of one currency, anchor, term and
product hold two securities, and an issue id derived from the security no
longer collides. The planner draws the issuer before it names the security,
because the name needs it.

A case states the rule: two scopes whose issuer lists differ state different
securities for the same term and product.

* The live proof

Recreated the database and provisioned ACME on main plus this change. Every step
completes, including =generate_trades=, for the first time since the population
work began:
