** Gaps found in this task

1. No refdata junction checks its ends. The inserts of =currency_calendar=,
   =currency_country=, =currency_currency_group=,
   =currency_pair_convention_calendar= and the three =party_*= junctions check
   the tenant only, so a row can name a record that does not exist. The
   junctions keep closed versions, but no operation reads them.
2. Closing a desk group leaves its membership rows open.
3. Memberships cannot be read by group; the filter takes currency codes only.
4. A pair and its convention are written in two operations, and the pair code
   is not checked against its legs on the server.
5. The pair list cannot be filtered by currency or classification.
6. The =business_day_convention= note on the currency pair convention model
   names a trading table; the insert validates against the refdata list.
