* What

Give each convention kind a generated list filter on its term columns, and decide how a list reports the number of distinct term sets it holds.

* Why

The generated filter of every convention list takes =id_one_of= and nothing else. A person who looks for the document that states a set of terms reads every page. The swap kind holds 320 documents that state 201 term sets, so the cost is real and the check for a duplicate before authoring is a person reading rows. Three journeys already record the gap. The 26 tables have different columns, so the filter must be generated for each kind and not shared.
