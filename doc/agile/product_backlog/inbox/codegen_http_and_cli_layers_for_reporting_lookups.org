* What

The reporting entities ore_file, ore_file_category and ore_file_version were
generated through every layer the codegen has a profile for: SQL, domain,
repository, service, protocol, handlers, history, shell commands and wire types.
The HTTP endpoints and the CLI commands have no codegen profile, so the three
entities have no HTTP or CLI surface.

* Why

The entity skill counts an entity done only when every layer exists, and it
says a layer without a profile is a gap to close with a profile, never by hand.
Writing the two layers by hand for these entities would leave code the next
regeneration cannot reproduce.
