The per-dataset publish verb: one request that names the datasets to publish and
one reply that reports what was dispatched.

It is the sibling of [[id:1166DC86-77A8-4E93-A3D9-E35E40550A01][ores.dq.publish_bundle]], and an operation for the same
reasons: it addresses no row by key and returns a dispatch count rather than a
record. Both verbs build the same bundle-publish workflow request, so they also
share one hand-written handler, =ores.dq.core/messaging/publish_handler.hpp=.

The datasets are dispatched individually rather than as a bundle member list, so
the request carries dataset identifiers and no bundle code. =mode= is a string
for the same reason the bundle verb's is: the publication mode is a hand-written
enum with no model, so a generated TypeScript twin cannot import it.
