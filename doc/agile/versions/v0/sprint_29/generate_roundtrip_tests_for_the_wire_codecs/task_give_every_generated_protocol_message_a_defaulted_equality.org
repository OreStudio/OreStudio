* Acceptance

- The protocol templates emit =friend bool operator==(const T&, const T&) = default;= on every message.
- Every opted-in component builds. A nested type without equality gets one, or is named in the task.
- pytest pins the emitted operator.

* Plan

1. Emit =friend bool operator==(const T&, const T&) = default;= after the
   members of every message, in the four message sections of
   =ores.cpp.protocol.protocol_header= (entity, junction, operation, family).
2. Regenerate every protocol header.
3. A defaulted equality is deleted, not refused, when a member has no
   equality, so find the gaps with a scratch check: one translation unit per
   api part that asserts =std::equality_comparable= for every message.
4. Give each blocking type a defaulted equality, in its template when it is
   generated.

* Notes

- The six blocking types were =result=, =order=, =change_intent= and
  =precondition= (with =field_failure= under =result=) in
  =ores.utility/domain/protocol.hpp=, =trade_envelope_data= (with
  =trade_envelope_field=), and the generated =instrument_batch=, whose
  equality goes in the =ores.cpp.trade_type.batch= archetype.
- Clang warns =-Wdefaulted-function-deleted= on a deleted defaulted equality,
  and the build uses =-Werror=. A new message member without equality
  therefore fails the build, which keeps the property.
- The drift check also found four inbox and scheduler codec files that main
  had not regenerated after a codegen change added enum includes. They are
  regenerated here.
- Four suites failed in the full run, none from this change. The marketdata
  feed and synthetic announce cases compete with the running services, and
  pass with them stopped. The security case needs =ORES_TEST_PASSWORD_FAST=,
  which a direct run does not set. =ores.trading.core.digest.tests= is a stale
  binary from 2026-10-17: a regeneration dropped its directory from the build.
  Captured as [[file:../../../../product_backlog/inbox/build_the_trade_digest_tests_again.org][Build the trade digest tests again]].
