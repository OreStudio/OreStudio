* Result

Implemented =quadratic_gaussian_process=: a short-rate engine with quadratic
yield terms, =r = delta_0 + delta^T X + X^T Gamma X= over Gaussian
Ornstein-Uhlenbeck factors. =discount_factor()= prices bonds with the
exponential-quadratic recursion, completing the square over the per-tick
shock with Eigen (matrix inverse, determinant and positive-semidefinite
checks). At Gamma == 0 the recursion reduces to the affine process's
exactly, verified bit-for-bit. 9 Catch2 tests covering Gamma == 0 exact
equivalence with =affine_term_structure_process=, the zero-sigma
deterministic path, a brute-force Monte Carlo cross-check of the recursion
(300k paths, no systematic bias), first-tick moments against closed forms,
positivity with PSD Gamma, discount monotonicity, seed determinism and
validation. Registered in =component_files.cmake=.

All 368 =ores.analytics.quant= tests pass on Linux. Not yet wired into
=process_factory= (deferred to PR 2: system infra wiring).
