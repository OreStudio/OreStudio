Creating and revoking a run grant. The run grant table is readable through its
generated entity protocol and writable only here, because each write needs a
check no row write can express: the grantor must hold the whole role in the
party, and only the grantor or an administrator may revoke.
[[id:78B82824-0BBB-4442-A9FA-E1F265DF57BD][Run grants and run tokens]] states the
rules.

** create_run_grant_request
:PROPERTIES:
:subject: iam.v1.run_grants.create
:response: create_run_grant_response
:END:

#+begin_src cpp :name comment
/**
 * @brief Records a person's consent that runs of one resource act for them.
 *
 * Sent on behalf of the person, with their token. The grant's tenant and
 * party are the session's, and its grantor is the session's account. Refused
 * when the session acts for no party, or when the person does not hold every
 * permission of the role. A second create for the same resource returns the
 * active grant, and re-activates a revoked one.
 */
#+end_src
