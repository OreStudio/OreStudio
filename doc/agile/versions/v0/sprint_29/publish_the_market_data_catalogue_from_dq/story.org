* Goal

The ACME bundle publishes the catalogue a working system needs: publishers, suppliers, sessions, feeds, scopes, routes and schedules. Adapters are referenced by code and no secret is carried.

* Acceptance

- The datasets publish in dependency order and a tenant is provisioned from them.
- Adapters are validated by code and version; the bundle does not create them.
- Secrets are references only.
- A provisioned tenant reaches serving feeds with no manual row.

* Decisions

- Adapters are release data, seeded by the installation.
- Suppliers, sessions, feeds, scopes, routes and schedules come from DQ.
- Endpoints may differ per environment; the bundle carries the demo ones and references the rest.
