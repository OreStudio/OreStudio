* Decisions

- A table that holds links is a junction model with =:history: true=. The generated table gains =version=, =modified_by= and =performed_by= in place of =assigned_by= and =assigned_at=. The wire names are unchanged.
- Reads that join a generated table to others, such as the permissions an account holds, stay hand-written in a repository of their own. The generated repository reads the table and nothing else.
- A TimescaleDB log table is an entity model with =:hypertable:= and only the data layer and the SQL schema enabled. What the generator does not state, such as a continuous aggregate, is an SQL paste block in the model, with its drop as a second block.
- The recorders and counts that the generated reads cannot express stay hand-written beside the generated repository, under a name that says what they are: =auth_event_log= and =run_token_issue_log=.
