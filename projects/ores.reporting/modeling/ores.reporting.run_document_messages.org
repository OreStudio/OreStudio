#+title: ores.reporting.run_document_messages
#+description: Codegen operation model for a report definition's run document and its configuration bindings: save, bind, get and delete.
#+type: ores.codegen.operation

#+subcomponent: api

#+brief: A report definition's run document as operations.
#+filetags: :model:operation:reporting:
#+created: 2026-10-04
#+updated: 2026-10-04

A report definition's run document and its configuration bindings, as
operations. The ORE service imports a run through these and the owning
components' document operations, and exports it the same way; it never touches
reporting's tables. A session acting for a party may only act on a definition
its party owns.
