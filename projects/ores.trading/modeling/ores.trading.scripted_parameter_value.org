One value of a scripted trade's list parameter, keyed to the parameter and
the value's ordinal.

A parameter whose value is a list, such as a basket's underlyings or a
vector of weights, states each value in turn, so each is a row.

** Custom repository methods

The trade read path fetches the scripted parameter values of many instruments at
once, and no generated read covers that: the generated reads address one key
group at a time. The batch read below is one statement over the instrument
set.

*** read_by_instruments_batch
:PROPERTIES:
:ID: 291718E8-F6EE-4400-9D84-1A3E3A0C9306
:END:

Reads every current scripted parameter value of the given instruments, in one statement. An empty input
reads nothing.

#+begin_src cpp :name implementation :implements F2EB1914-5E94-42CA-9C77-46BDB364BF9E
std::vector<domain::scripted_parameter_value>
scripted_parameter_value_repository::read_by_instruments_batch(
    const context& ctx, const std::vector<std::string>& trade_ids) {
    if (trade_ids.empty())
        return {};
    static constexpr auto max = db_timestamp::max();
    const auto tid = ctx.tenant_id().to_string();
    const auto query = query_builder::read<std::vector<scripted_parameter_value_entity>> |
                       query_builder::where("tenant_id"_c == tid &&
                             "trade_id"_c.in(trade_ids) && "valid_to"_c == max) |
                       query_builder::order_by("trade_id"_c, "parameter_sequence_number"_c, "sequence_number"_c);
    return query_builder::execute_read_query<scripted_parameter_value_entity,
                                             domain::scripted_parameter_value>(
        ctx,
        query,
        [](const auto& entities) { return scripted_parameter_value_mapper::map(entities); },
        lg(),
        "Reading scripted parameter values for multiple instruments.");
}
