* Goal

Add a dependency-free HTML/CSS/JS image carousel to the site homepage
(=index.org=), replacing the old static hero image + standalone
version screenshot with a single carousel whose first slide is the
hero (splash image + title/subhead/CTA) and whose remaining slides
are a hand-curated set of ORE Studio screenshots with captions,
showcasing the breadth of functionality (market data, org structure,
quant/analytics, data governance, trade capture, reference data).

* Acceptance

- Carousel replaces the old hero section + standalone version
  screenshot at the top of =index.org=, with the hero merged into the
  carousel's first slide.
- 6 hand-curated feature screenshots follow, each with a caption.
- Dependency-free (no CDN/external JS library) vanilla JS controller:
  auto-advance, pause on hover/focus, prev/next buttons, dot nav.
- Regular slides never stretch (=object-fit: contain=, safe for any
  native image resolution); the hero slide crops rather than
  stretches (=object-fit: cover=).
- =compass site serve= actually serves =.js= files (site build had no
  publish rule for them before this task).
