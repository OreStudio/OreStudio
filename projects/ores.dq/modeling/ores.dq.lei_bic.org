* Notes

Bound to [[id:5D3A6D13-73E0-41A5-9E08-0C8C11BD609E][Artefact staging only]] (alongside its shape profile): this
artefact type's own row in =ores_dq_artefact_types_tbl= (=lei_bic=) has
=target_table=/=target_subject= both null -- explicitly terminal, not published
anywhere. GLEIF LEI-to-BIC data is queried directly from the artefact table; a
same-component main table would be an orphan nobody designed for.

The table was hand-written SQL with no model until
[[id:6632B4F0-7005-4A55-BB69-96161952C2EF][Settle the owner of the DQ-only models]] modelled it
beside =lei_entity= and =lei_relationship=, whose GLEIF dataset it belongs to.
