* Goal

The system can fit a volatility surface to its quotes. A pure engine beside the curve engine in =projects/ores.analytics/quant= takes the weighted ATM, risk reversal and butterfly quotes of each expiry, the forward to each expiry and the pair's conventions as inputs. It fits SSVI with gamma = 1/2, samples the fitted surface on an output grid, and checks the result for arbitrage. It reads no database and calls no service, so unit tests prove it. SSVI is the only smile model in this task. See [[id:53D14F31-EE32-493E-BBEB-140AA4906BE4][Constructing a volatility surface: from quotes to a published set]].

* Acceptance

- Quotes generated from known SSVI parameters are fitted back to those parameters within a tolerance the tests state.
- The engine returns the ATM total variance of each expiry, the skew, the curvature, the sampled grid and the error of each pillar.
- Each strike label resolves to a strike through the given forward and the delta and ATM conventions.
- A butterfly quoted as a broker strangle enters the fit as the price of the strangle at its own strikes, and gives a different surface from the same number read as a smile butterfly.
- Between expiries the engine interpolates in total variance.
- The result reports calendar spread arbitrage and butterfly arbitrage, using the SSVI conditions on the parameters, and tests show each violation detected.
- A pillar whose error exceeds the tolerance is reported by name.
- An expiry without the pillars SSVI needs is refused, and the error names the expiry and the missing pillars.
