A curve configuration is stored one family table per section, and each column of
those tables holds one leaf of the ORE document. This table names that leaf, so
the store can check a value against the set the leaf accepts without holding a
copy of the projection in a trigger body.

The rows are generated from the same projection and schema that draw the page's
columns, so the map and the screen cannot disagree.
