* Goal

pstack's most valuable structural idea is that one skill is sticky: entered once, it stays on across turns, matching each request to a method and staying quiet when none applies. Without it every method is something an agent must remember to reach for, and the one it forgets is the one it needed. Build our version. It declares the session function, which attenuates the catalogue by level; matches the request to a method and copies that method's phases into the todo list verbatim before reasoning about the task; reads the principles index at task start; routes to actions and recipes as phases fire, and to deliberation at a fork the evidence cannot settle. The verbatim copy is the part that carries the value and the part most easily lost, because the known failure mode is an agent reading a method and then writing a bespoke plan that quietly drops its named phases.

* Acceptance

- The mode is sticky across turns and can be opted out of at any time.
- Entering it declares the session function and attenuates the catalogue accordingly.
- A matched method's phases are copied into the todo list verbatim, before any task-specific reasoning.
- A phase deliberately skipped stays in the list with a stated reason; silent skipping is refused.
- The principles index is read at task start.
- The name is recorded in the naming decision log as a bare-noun register extension, with the rejected alternative noted.
- The mode is exercised on real work end to end before the task closes.
- Blocking, from the council review: the matching predicate is specified before the mode ships — the rule that maps a request to a method, the arbitration rule when two methods match, and the null case when none does.
- The mode can decline. It states when the heavy path is not worth its cost and falls through to the plain action skills.
- The request shape is documented: goal, then a finish condition naming a result rather than an effort, then the behaviour that must not change.
- The mode and its delegate function share one definition. The mode spawns that function, never a generic agent, so the discipline survives the delegation boundary.
- An existing delegate is resumed rather than a sibling spawned alongside it.
