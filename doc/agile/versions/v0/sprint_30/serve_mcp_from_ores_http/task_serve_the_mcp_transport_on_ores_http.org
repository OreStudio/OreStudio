* Goal

ores.http serves MCP's Streamable HTTP transport at /mcp: POST, GET and DELETE, sessions by Mcp-Session-Id, JSON-RPC through ORE's codec, and the methods initialize, notifications/initialized, ping, tools/list and tools/call, written in ores.http with boost.taar as the reference. A request authenticates with an agent's key, and a missing or invalid one is answered with 401.
