* Goal

tools/list answers five tools, whatever the catalogue holds: list_areas, list_entities, list_operations, find_operations by BM25 over names, areas, entities, summaries and descriptions, and call_operation. Every list shows only what the person may call, and only reads when the grant is read only. Every answer is short. A call without arguments, or with wrong ones, answers the operation's input schema and an example. A held write answers the approval request it raised.

* Plan

(Implementation strategy. Written when work starts; key decisions
are distilled into the parent story's =* Decisions= at close, but the
plan itself stays — it is the historical record of what we did.)

- =operation_catalogue= is a snapshot of the router's routes once every route
  is registered, without the transports and the routes that stream a body. It
  keeps each route's tool, area, entity, summary, parameters, body schema and
  handler, and a BM25 index over its words.
- Search adds to BM25 the share of a tool's own name the words cover, weighted
  2: plain BM25 ranked =list_currency_currency_groups= above =list_currencies=
  for "list currencies", because the longer name repeats a word asked for.
- =call_operation= takes the path the agent's direct call takes: a write is
  refused to a grant that only reads, offered to the six-eyes holder, and every
  call is recorded against the route it reached. The route's handler runs with
  the caller's claims and exchanged token.
- An operation's input schema names its path and query parameters and its
  body; the body's =$defs= move to the root, where its references point.
- The lists filter by the grant's scope, reads alone for a grant that only
  reads. Filtering by the person's permissions needs each route to state the
  permission its service checks, which no route does: matching a route's
  entity to a permission resource found none for 267 of 1146 operations. That
  is the task [[id:83CA0DEA-C89F-426B-B5B3-5D84DD0711CA][Declare the permission each route needs]].
- A coroutine takes its arguments view by value: a reference to a temporary
  view dangled in the first tests.

* Result

=tools/list= answers five tools whatever the catalogue holds. =list_areas=,
=list_entities= and =list_operations= walk the catalogue a short page at a
time, and =find_operations= ranks the five best operations by BM25 with the
tool's name weighted. =call_operation= runs an operation as the agent's own
call would: a read answers its result cut to 8,000 characters, a write is
held for the person and answers the request it raised, and a call without its
arguments answers their schema and an example. Every call is recorded against
the route it reached. The lists filter by the grant's scope; the filter by the
person's permissions is its own task.
