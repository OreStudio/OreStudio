* Goal

The code knows the schema it was built for and the database records the schema it was built from, as a fingerprint of the SQL scripts. Every service and test run compares the two at startup, logs both, and refuses to start when they differ, with a message that names the fix: compass db recreate.

* Acceptance

- A service started against a database built from other SQL logs the expected and actual fingerprints and exits with a dedicated exit code and an unmistakable message.
- A service started against a matching database logs both fingerprints and starts.
- compass services start, compass db status and compass bearings report whether the database is in sync with the checkout.
