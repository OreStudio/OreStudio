* Acceptance

- A design document states, for each of the four parties, which reports it runs and why, from its role, its jurisdiction and its place in the group, with the alternative rejected.
- Provisioning gives each party only the reports in the design, and each party's report definitions carry the configuration they need with a base currency that matches the party.
- Each party has a realistic portfolio tree, root portfolio and currencies, and each report scope names portfolios that exist for that party.
- The seeds the task touches carry no comment that states a count, and the task records what a clean provision did not prove.
