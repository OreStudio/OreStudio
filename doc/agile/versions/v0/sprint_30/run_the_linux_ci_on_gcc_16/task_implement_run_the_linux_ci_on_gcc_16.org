* Acceptance

- =versions.env= states =GCC_MAJOR=16.
- The Dockerfile installs =g++-16= and points =gcc=/=g++= at it.
- =build.sh --print-ref= names =gcc16= and a new hash.

* Plan

1. Find where the compiler version is stated.
2. Check that the version is obtainable on the current base image before
   changing anything.
3. Change the two files the image is built from, and check the tag moves.
4. Leave the base image alone unless the compiler forces it.

* Result

The image now installs GCC 16 from the Ubuntu toolchain PPA and points gcc and
g++ at it. The base image stays on 24.04, because moving it would move the
PostgreSQL and LLVM repositories too.

The image is built by the CI Image workflow when this lands, which is also its
first real test: this worktree has no container engine.
