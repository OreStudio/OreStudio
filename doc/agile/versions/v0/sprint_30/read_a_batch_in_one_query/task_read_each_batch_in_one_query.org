- The service template reads the current rows of each batch path with one query.
- A put-many still refuses the whole batch when one row fails its precondition, and writes nothing.
- The regenerated services build and pass their suites, and the codegen drift gate is clean.
- A 1,000-row put of market observations is measured before and after, with the command, on the same environment.
