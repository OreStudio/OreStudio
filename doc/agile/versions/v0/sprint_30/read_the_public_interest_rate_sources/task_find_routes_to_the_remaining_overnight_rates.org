* Goal

The system reads the public overnight rate of as many of the 28 currencies as their publishers allow. The survey in [[id:3F9D6EAE-9FB8-4A0D-9BAF-1EA3EA93AB4F][the calibration sources note]] found a usable source for four currencies: USD, EUR, GBP and CAD. This task reads the route and the terms of each other currency, and adds an adapter task for each source that is usable.

* Acceptance

- AUD has a route that a script can read, or the note records why none exists. The RBA server refused a script with 403.
- NZD has its terms and its route read. The RBNZ server refused a script with 403 on both.
- The Bank of Japan's call rate is not loaded until the task's owner asks the Bank's Public Relations Department whether this use is commercial, and writes its answer into [[id:3F9D6EAE-9FB8-4A0D-9BAF-1EA3EA93AB4F][the calibration sources note]].
- Each of the other twenty currencies has its route and its terms read, and its Usable column filled.
- Each usable source has its own adapter task in [[id:6E93FD89-3443-4BED-8E2F-9295E773BFB7][Read the public interest rate sources]]. An existing adapter reads the source only when the API and the format are the same.
- The index questions of PLN and TWD are answered, or passed to the task that replaces ceased or misnamed feeds.

* Plan

- Probe one candidate route for each currency with a script, and keep the status, the size and the first bytes as evidence.
- Read each publisher's terms: its own page where a script can read it, a search where the page is rendered by script. A term that a search reports from a third party is recorded as not read.
- Fill the Route, Terms and Usable columns of the survey in the calibration sources note, with the date read.
- Add one adapter task for each usable source. The routes differ in API and format, so none reuses an existing fetcher.

* Result

The survey in the calibration sources note now records the route, the terms and whether each currency is usable, read and probed on 2026-11-10.

- AUD: the RBA's table F1 answered a script three times; the RBA's terms allow commercial use with "Source: RBA [year]". Usable.
- NZD: the RBNZ still refused a script with 403, on the table and on the copyright page. Open.
- JPY: the owner judged on 2026-11-09 that this use is not commercial, and the note records that decision and that the Bank was not asked. The BoJ API serves the call rate from 1990. Usable.
- The other twenty: BRL, NOK and SEK are usable with open routes; MXN, CLP, SGD and CZK with a free registered key. CNY and HKD need a licence from CFETS and the TMA. DKK has usable terms and no route found. COP, INR, KRW, TRY and ZAR are open.
- PLN and TWD, with CNH, HUF and ILS, are passed to [[id:4B5701D6-16C6-445B-BDD4-C60050FED95C][Replace the synthetic feeds of ceased or misnamed indices]], which already names them.

Nine adapter tasks are added to the story: the RBA, the Bank of Japan, the Banco Central do Brasil, Norges Bank, the Riksbank, Banco de Mexico, the Banco Central de Chile, the MAS and the Czech National Bank. Each names its route, its credit, and what it must settle first: a key, a series code, or an item that the catalogue lacks, as for SWESTR and the TIIE de Fondeo.
