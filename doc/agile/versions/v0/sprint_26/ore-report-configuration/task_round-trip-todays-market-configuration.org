#+title: Task: Round trip today's market configuration
#+description: todaysmarket*.xml end to end: the market configuration sets a report's valuation reads, with each set's yield curve, discount curve, fx, equity, commodity, correlation and volatility specifications, the calendar, the sensitivity and report currency settings, and the ibor fallback and pricing engine binds. Neither the entity model nor a mapper exists, and the corpus holds 98 files under the TodaysMarket root, so nothing of this kind round trips. Model the entities in the component that owns the concept, write both mappers, and prove the round trip with the harness over every file in the corpus.
