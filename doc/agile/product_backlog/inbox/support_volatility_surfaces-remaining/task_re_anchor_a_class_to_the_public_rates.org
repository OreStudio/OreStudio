* Goal

A running synthetic market follows its own path after release and drifts from the real rates; bringing it back is a decision, not a side effect. An operator's Re-anchor on the Calibration screen writes each of a class's feed levels from its latest fixing, as a new version of the config with the operator's reason, and restarts the feeds from those levels without resuming from their last stored spots. The history shows each level before and after. Nothing else writes the level of a released class from a fixing.

* Acceptance

- Re-anchoring a class writes each feed's level from its latest fixing and restarts the feed from it, not from its last stored spot.
- The re-anchor is a version of each feed's config with who, when, the reason and the level before and after, and shows in the feed's history.
- The daily calibration of a released class leaves the level alone; only a restart, from the last stored spot, or a re-anchor writes it.
