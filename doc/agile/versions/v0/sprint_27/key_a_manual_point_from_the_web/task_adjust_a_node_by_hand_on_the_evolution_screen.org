* Result

A person who holds =marketdata::market_observations:write= sees an Actions column in the Now table. Each node has an Adjust button that opens a form for the value, a change reason and a commentary. A node that shows as manual also has a Clear button. After a write the screen reads the object again. Such a person always gets the source column, so manual nodes are marked and show who keyed them. The catalogues have the new words in English, French and Portuguese, and the language parity test passes. The permission also has its plain-words entry.

Static-markup tests cover what the panel offers with and without the write permission and that Clear shows only on manual nodes. The form itself opens on a click and is not covered by a test. I did not use the screen in a browser.

Decisions:
- The screen decides only what to offer. The server checks the write again.
- Reasons come from the shared =useReason('amend')= list used by the other screens.
