* Plan

Assets needs no code change, so the task maps and proves rather than edits. Map
each of the three models to the unit it renders and record the verbs each menu
carries. Prove the two negatives: no hand-written unit registers an assets menu
and no hand-written unit extends a generated assets menu. Run the component's
shell suite as the evidence that the three units compile and pass.

* Notes

Assets is the first of the seven with no gap at all: three models, three units,
and nothing hand-written beside them. There is nothing to retire and nothing to
sign off.

=assets_commands.cpp= is hand-written and registers no command of its own. It
calls the three generated units' =register_commands= in turn.
[[id:E38360B6-99FF-4AF0-937F-58F31BD573F5][Shell facet]] records the same gap
for every component: the aggregator needs a component-scoped archetype and a
render-time list of the component's opted-in entities. That is a generator
change, and it is recorded here rather than made here.
