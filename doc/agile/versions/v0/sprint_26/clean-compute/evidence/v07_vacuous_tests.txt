## Finding

No test is vacuous. Every non-empty, truthiness or non-throw assertion is
a guard that sits beside an assertion of a literal expected value in the
same case: the archiver case that checks a non-zero file size also reads
the extracted files back and compares their bytes, and each domain
serialisation case that checks a non-empty string also searches it for the
field value it wrote. A subject that did nothing fails the paired
assertion, which is what the item asks.

The generated eventing cases assert the same way: each waits for a
notification that names the row it wrote and then round-trips the row
through the service, so a chain that published nothing fails.
