* Goal

Read every XML document in the repository with the scanner on every check, and
fail the build on any rejection. The corpus is the only evidence that the
subset the scanner accepts is the subset the project holds, and today nothing
stops a scanner change from narrowing it quietly.

* Acceptance

- One check fails when any XML document in the repository is rejected.
- The check covers =external/ore=, =external/fpml=, =external/fix=,
  =assets/test_data= and =doc/agile=, which is 3,971 documents and 44.8 MB.
- A rejection names the file, the line, the column and the reason.
- The check runs in the local check suite, not in a one-off script.
