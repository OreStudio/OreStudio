* Goal

No request, session or database context carries a workspace. The X-Workspace-Id and X-Workspace-Resolution headers are gone from every client and service.

* Acceptance

- ores.database context has no workspace_id or resolution chain.
- ores.nats has no x_workspace_id or x_workspace_resolution header and nats_client has no with_workspace_id or with_workspace_resolution.
- ores.service request_context reads no workspace header, and its tests no longer set one.
- The ores.web wire-protocol client sends no workspace header and exports no WorkspaceContext or LIVE_WORKSPACE_ID.
- The build is green, and ctest and the ores.web tests pass.
