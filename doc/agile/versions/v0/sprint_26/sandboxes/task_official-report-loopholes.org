* Acceptance

- A risk report configuration whose scope holds sandbox inputs cannot belong to an official definition.
- The books an official report resolves exclude every book reached through a sandbox portfolio.
- The pgTAP test covers the sandbox portfolio path and checks its fixture.

* Plan

The review of PR 2561 found two paths around the official report rules,
and the PR was merged on green with them taken here.

- A risk report configuration could move from a definition that is not
  official to an official one with sandbox data in its scope. The
  configuration's insert trigger now refuses that, through a new helper
  that answers whether one configuration's scope holds sandbox inputs; the
  definition check reuses it.
- The resolver filtered virtual books but not other books reached through a
  sandbox portfolio. Its portfolio path now skips sandbox portfolios for an
  official report.
- The test asserts its fixture and covers scoping a sandbox portfolio.
