* Goal

No table, domain type, repository or generated TypeScript type carries a workspace_id. Every entity that had one keeps the same rows and behaviour, because every row was already in the Live workspace.

* Acceptance

- No model sets has_workspace_id and no profile a model binds defaults it true; the 24 models that bound workspace-scoped-lookup bind simple-lookup. The unbound profile goes with the codegen feature.
- No create script under projects/ores.sql/create declares a workspace_id column outside the workspace schema.
- Hand-written workspace code in the four components is gone, including report_definition's read_latest_with_resolution and the refdata workspace inheritance test.
- Regeneration is byte-identical, the build is green, and ctest and the codegen tests pass.

* Plan

The workspace column comes from the generator, so the change is to the
models and profiles, as in the trading task (PR #2620).

- The 24 refdata conventions move from =workspace-scoped-lookup= to
  =simple-lookup=, which differs only in =has_workspace_id=.
- =fk-scoped-child= sets =has_workspace_id= false. It carries book,
  portfolio, three analytics configs and =report_instance=.
- The four models that set the flag themselves drop it. =report_definition=
  then agrees with =uuid-identified-lookup=, so its =KNOWN_MODEL_DRIFT=
  entry goes.
- Regenerate refdata, reporting, analytics-cpp and marketdata. Each was at
  zero drift before the change.
- Hand-written code: the marketdata tick subject loses its workspace
  segment (=marketdata.v1.tick.<tenant>.<party>.<key>=), the ingest loop
  stops keying its stats on the workspace, the reporting test fixture stops
  inserting one, and the refdata workspace inheritance test is deleted.
- The request context, the codegen feature and ores.workspace stay for
  their own tasks.

* Result

No entity outside ores.workspace carries a workspace. The 24 refdata
conventions bind =simple-lookup=, =fk-scoped-child= no longer sets the
flag, and the four models that set it drop it. Regeneration removed the
column from 32 tables, their domain types, repositories, generators and
generated TypeScript, and the hand-written resolution read of
=report_definition=, which came from a pasted model block. The marketdata
tick subject is =marketdata.v1.tick.<tenant>.<party>.<key>=. The refdata
workspace inheritance test is deleted. The request context, the codegen
feature and ores.workspace remain for their own tasks.
