** storage_dir
:PROPERTIES:
:cpp_type: std::string
:default_value: "/var/ores/http-server/storage"
:END:

Root directory for object storage (all buckets live under this path).

Each bucket maps to a subdirectory of this root. The server names no
bucket of its own: it creates one on the first write to it, so the
callers' bucket and key protocol decides what appears here.

** web_session_name
:PROPERTIES:
:cpp_type: std::string
:default_value: "ores_web_session"
:END:

The name the session cookie is issued under.

Carries this deployment's environment, so two deployments on one host cannot
overwrite each other's session. Over TLS the server adds the =__Host-= prefix a
Secure cookie requires.

** web_session_path
:PROPERTIES:
:cpp_type: std::string
:default_value: "/"
:END:

The path the session cookie is scoped to.

A screen served under a prefix keeps its own session, so the cookie's path is
that prefix. Without it two sessions of one deployment, one from this server and
one from the BFF, would be stored under the same name and overwrite each other.

** web_dir
:PROPERTIES:
:cpp_type: std::string
:default_value: "/var/ores/http-server/web"
:END:

The built browser bundle this server answers for, when there is one.

The directory a build wrote: =index.html=, the =assets/= it names, and the
prebuilt copies beside them. Empty means the server serves no bundle, and a
directory that is not there is logged and skipped rather than served empty.

** site_config
:PROPERTIES:
:cpp_type: std::string
:END:

The site configuration the served client reads, the BFF's =environments.json=.

Empty reads the file =ORES_WEB_SITE_CONFIG= names. Without one, the server
answers no site routes and logs why.

** site_env
:PROPERTIES:
:cpp_type: std::string
:END:

The environment of the site configuration this server serves.

Empty chooses it as the BFF does: =ORES_WEB_ENV=, the checkout's
=ORES_ENV_NAME=, the file's active environment, then its first.

** http_base_url
:PROPERTIES:
:cpp_type: std::string
:END:

Override for the HTTP base URL advertised via NATS service discovery.

If empty, defaults to "http://localhost:{server.port}".
