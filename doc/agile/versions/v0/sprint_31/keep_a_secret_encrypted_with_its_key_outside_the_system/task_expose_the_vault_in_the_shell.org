- The vault's own suites and the shell composition's suite still pass.

* Plan

Two lines of composition, not a feature: the component was complete and
unreachable. The shell's application target gains =ores.shell.vault.lib=, and the
repl's =setup_menus= includes the two command headers and registers both menus
beside the other components'.

The proof is the binary's own help listing, run as a scripted session so it needs
no person and no login: the menus appear in the root list. The vault suites and the
shell application's suite cover the rest.
