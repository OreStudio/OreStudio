#+title: The minimal Acme tenant lacks reference data some example trades need
#+description: On a tenant provisioned from acme_minimal, an ORE example bond is refused for its reference curve BENCHMARK-EUR, and an FX worst-of basket swap's constituents are refused because the FX catalogue does not hold TR20H-USD-CAD. The minimal profile should publish the reference data the ORE examples name, or the import should say what to provision.

This page is a [[id:671F18E4-E09C-4B3B-BD24-D33DF8AE38A6][capture]] in the *inbox* bucket of the product backlog — a pre-sprint idea, not yet pulled into a sprint as a story.

* What

On a tenant provisioned from =acme_minimal=, two ORE example trades are
refused for reference data the profile does not publish. The formula based
bond in =Exotic_Formula_Based_Coupon.xml= names the reference curve
=BENCHMARK-EUR=, which no curve series of the tenant holds. The FX worst-of
basket swap in =Exotic_FXWorstOfBasketSwap.xml= names =TR20H-USD-CAD=, which
the FX catalogue does not hold, so its constituents are refused.

* Why

The minimal profile exists to roundtrip the ORE examples quickly. The
profile should publish what they name, or the import should say what to
provision rather than refuse the rows.
