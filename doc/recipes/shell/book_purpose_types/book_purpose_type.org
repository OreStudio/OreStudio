#+title: How do I run the book_purpose_types commands from the shell?
#+description: Every command the book_purpose_types submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:book_purpose_types:

This file documents the book_purpose_types resource at the shell, one section per command. Every command is a subcommand of =book_purpose_types=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: DF7D9705-BFF2-55CF-ACDF-90CEFF6EBF6A
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
book_purpose_types list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =refdata.v1.book_purpose_types.list=.

#+name: book_purpose_types-list
#+begin_src ores-shell :tangle book_purpose_types-list.ores :exports none
book_purpose_types list --limit 1
#+end_src

** =get=
:PROPERTIES:
:ID: 886942DE-E78C-5ECC-AD89-3642961D6E48
:END:

Reads the one row its key addresses. A key states every identifying column, so a partial key is refused rather than answered with an arbitrary row.


The command is shaped like this:

#+begin_example

It is addressed at =refdata.v1.book_purpose_types.get=.

#+name: book_purpose_types-get
#+begin_src ores-shell :tangle book_purpose_types-get.ores :exports none
book_purpose_types get __none__
#+end_src

** =add=
:PROPERTIES:
:ID: CB8AC35E-C30C-592E-B547-E785D94ACFF3
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.


The command is shaped like this:

#+begin_example
book_purpose_types add <code> <name> <description> <display_order> <reason> <commentary>
#+end_example

It is addressed at =refdata.v1.book_purpose_types.put=.

#+name: book_purpose_types-add
#+begin_src ores-shell :tangle book_purpose_types-add.ores :exports none
book_purpose_types add __none__ __none__ __none__ 0 system.new_record generated_script
#+end_src

** =set=
:PROPERTIES:
:ID: 9B76FCE7-F6CF-52F0-9F90-9AC6D7C51A14
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved. Passing --version makes the write conditional on the version the caller last read.


The command is shaped like this:

#+begin_example
book_purpose_types set <code> <name> <description> <display_order> <reason> <commentary> [--version <n>]
#+end_example

It is addressed at =refdata.v1.book_purpose_types.put=.

#+name: book_purpose_types-set
#+begin_src ores-shell :tangle book_purpose_types-set.ores :exports none
book_purpose_types set __none__ __none__ __none__ 0 system.new_record generated_script
#+end_src
