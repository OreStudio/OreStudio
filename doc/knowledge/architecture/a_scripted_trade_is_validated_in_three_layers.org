#+title: A scripted trade is validated in three layers
#+description: The editor's grammar while one types, ORE's grammar on the server at booking, and ORE's build of the trade at valuation: what each layer decides and what it cannot.

* Summary

A scripted trade is checked three times, each by the layer that can decide
it. The editor's grammar flags errors while a person types, as a convenience.
ORE's grammar on the server decides whether the script parses and whether the
trade states its inputs, and refuses the booking if not. ORE's build of the trade
decides whether ORE can price it: the types against the script, the product
tag's engine, and the market data. No layer stands in for another.

* Detail

| Layer | Runs in | Decides | Cannot decide |
|-------+---------+---------+---------------|
| editor | =ores.web=, a tree-sitter grammar | where a token or a statement is wrong, as one types | anything; it is not ORE's grammar ([[id:8CF94EFE-4699-4F7D-B59B-E695AFD723CA][The editor's grammar is tested against ORE's parser]]) |
| server | the booking API, with =ores.trading.scripting= | that the script parses as ORE parses it, and that the variables are the script's inputs by name and type ([[id:8FD7BD95-AAEC-4CF9-A9F4-D609A9DEFBD8][ORE's grammar is the one authority on whether a script parses]]) | whether ORE can price it |
| engine | an ORE run | that ORE builds and prices the trade | nothing earlier: it runs after the booking |

** Why three

The editor must answer as fast as a person types, so it cannot call the server
on every key. The server must answer at booking, in the time a booking takes,
so it cannot run ORE. Only ORE can say whether the market and the pricing
configuration let it price the trade. Each layer is authoritative for what it
decides and silent on the rest.

** Validating before booking

The booking API's =validate_script= runs the server layer without booking,
so the editor offers a check button, and the shell validates a file
([[id:B01292A4-0394-40E8-A0B4-2DBA3F46C052][The shell parses a script without a login]]). A test build in ORE, the engine layer before booking, is a
separate and slower request, for a person who wants it.

** Where today's code differs

The server layer checks a library script's variables against its mined inputs,
but parses nothing, and no editor exists.
