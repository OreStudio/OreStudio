* Goal

Eliminate every =file(GLOB_RECURSE ...)= source-discovery call from the
build (165 CMakeLists.txt files across ~96 components at task start),
replacing it with an explicit, checked-in list of files -- the
idiomatic CMake approach per Kitware's own guidance, rather than
mitigating the stale-configure problem with =CONFIGURE_DEPENDS= (already
landed separately, and explicitly out of scope for this story to redo).

Since these CMakeLists.txt files are themselves codegen-templated
boilerplate rather than hand-maintained one-offs, hand-editing 165
files is both impractical and error-prone. Instead: write a small,
idempotent generator script that computes the explicit list from the
filesystem and rewrites the =file(GLOB_RECURSE ...)= block in place,
run it across every component (one commit per component so each is
independently reviewable and revertable), and update the codegen
archetype templates so newly scaffolded components start with
explicit lists rather than regressing back to GLOB.

* Plan

(Implementation strategy. Written when work starts; key decisions
are distilled into the parent story's =* Decisions= at close, but the
plan itself stays — it is the historical record of what we did.)

1. Write =regenerate_cmake_sources.py=: regex-match each
   =file(GLOB_RECURSE ...)= call (with its optional seeding
   =set(<var> "")=), resolve its base directory (either
   =${CMAKE_CURRENT_SOURCE_DIR}= itself, or a component-root variable
   of the form =set(VAR ${CMAKE_CURRENT_SOURCE_DIR}/..)= found earlier
   in the same file -- the only two shapes this codebase uses), walk
   the filesystem for matching files, and replace the call with an
   explicit, sorted =set(<var> ...)= block. =--check= mode reports drift
   without writing, for CI.
2. Validate on two representative components first (a plain library,
   =ores.diff=, and a Qt AUTOMOC component with both =.cpp= and =.hpp=
   globs, =ores.qt/synthetic=) -- build both targets to confirm the
   explicit lists behave identically to the GLOB they replace.
3. Run the script across every remaining component, one component
   (=src= + =tests= CMakeLists.txt together) per commit.
4. Update the codegen archetype =.org= templates
   (=ores.cmake.component.*.org=) to stop emitting GLOB.
5. Add a recipe documenting the new convention.
6. Full =compass build= + =ctest= at the end; fix any straggler.
