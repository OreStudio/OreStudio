* Acceptance

- Compression, allocation, merge, roll, sweep and bulk book move detail tables exist, each keyed by the process run with an enforced foreign key.
- The process named by a run states which detail table, if any, a run of that process carries; a pgTAP test refuses a detail row of the wrong process.
- No detail table is keyed by a trade activity: the activity is the stamp on an amendment, and the run is the parent here.
