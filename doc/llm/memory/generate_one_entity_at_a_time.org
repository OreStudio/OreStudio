#+title: Generate one entity at a time, through an address
#+description: Run codegen per entity with --address rather than per component or with --all, so a narrow change produces a narrow diff.
#+type: memory
#+memory_subtype: feedback
#+level: cross
#+filetags: :codegen:drift:hygiene:memory:feedback:
#+created: 2026-09-19
#+updated: 2026-09-19

Regenerate codegen output one entity at a time, always through an explicit --address, using compass codegen entity generate <entity> --address <facet> (--diff first to preview). Never run a whole-component regeneration or --all to check one model.

*Why:* A whole-tree or whole-component run materializes output for every model the facet admits, so one narrow change produces hundreds of files, most of them unrelated. The TypeScript facet widening showed this: a plain check_component_drift.py --all regenerated TypeScript for every drift-free component and aborted on four entities whose response carries ores::utility::domain::hierarchy_node, a gap that has nothing to do with the change under test.

*How to apply:* Preview with --diff, confirm the paths named are the ones the change should touch, then write. Keep check_component_drift.py for verification, and constrain it with --address when a tree-wide proof is needed (--all --address ores.cpp regenerates C++ only and leaves the TypeScript alone).

When a model is being drafted rather than migrated, use the reporting mode: check_component_drift.py --dry-run generates into a temporary root and reports what would change or be created, writing nothing into the repository. Never run the in-place check to find out what a draft would do. It regenerates the whole drift-free set, and a drafted model sitting in a modeling directory makes it write that entity's output over hand-written files. A safe check must not have to move a file out of the way first: on 2026-09-19 an in-place --all run while a drafted login_info model was in projects/ores.iam/modeling/ overwrote sixteen hand-written files and created thirteen more, all of which had to be restored by hand.
