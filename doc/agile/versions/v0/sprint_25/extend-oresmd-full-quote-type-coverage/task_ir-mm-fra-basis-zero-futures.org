* Goal

Extend the existing =ir_market_data_identifier= to represent the 11 ORE
IR quote types not yet covered by oresmd — every TYPE/METRIC pair the
catalogue documents for interest rates beyond the original two
(=IR_SWAP/RATE= and =DISCOUNT/RATE=). The consumer-facing change is a
new =quote= query parameter (the ORE TYPE) plus an extended =metric=
enum (the ORE METRIC), both IR-only and only meaningful when
=type=quote=.

* Plan

Added the =ir_quote_type= enum (=oresmd_enums.hpp=), extended =metric=,
and added =quote_type= as an =std::optional= field on both
=ir_market_data_identifier= and =ir_market_data_requirement=. The new
=quote= query parameter is parsed in =oresmd_parser= (gated: IR-only,
rejected when =type≠quote=), serialised in =to_uri=, and wired through
=oresmd_resolver=. The quote-key projection (=oresmd_projections=)
dispatches on =ir_quote_type= + =metric= to construct the correct ORE
key — =ir_swap= uses the =2D= settlement-lag convention, =discount= uses
the =curve_id= format (=USD3M=), =cc_basis_swap=/=cc_fix_float_swap=/
=bma_swap= omit =index= from the qualifier, and every other type
includes =INDEX/TENOR= in the qualifier. =default_metric()= supplies the
metric when the caller omits it (=quote=mm= → =rate=, etc.).

* Result

Delivered full IR quote-type representation in =oresmd=, meeting every
Acceptance bullet:

- =ir_quote_type= (12 values) + extended =metric= (5 values) replace the
  old =par_rate=/=discount_factor= conflation with a clean two-dimensional
  design: =quote= carries the ORE TYPE, =metric= carries the ORE METRIC,
  and =metric= defaults from =quote= when absent.
- =quote_key_ir= dispatches correctly for all 12 TYPEs, including the
  format variants: =ir_swap='s =2D= settlement-lag convention,
  =discount='s =curve_id= qualifier, and the no-index qualifier for
  =cc_basis_swap=/=cc_fix_float_swap=/=bma_swap=.
- 108 test cases, 214 assertions, all passing — 26 new tests covering
  every TYPE/METRIC pair's projection, round-trip, default-metric, and
  validation; the remaining 82 tests (85 original minus 4 backward-compat
  removed plus 1 new validation) all pass with the test suite's own
  mechanical migration to the new =quote= parameter.
- No new component, no dependency changes — everything lives inside
  =ores.marketdata= exactly as the original =oresmd= library task
  established.
