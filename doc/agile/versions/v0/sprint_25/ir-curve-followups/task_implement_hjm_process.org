* Result

Implemented =heath_jarrow_morton_process=: a forward-curve engine whose state
is a discretized forward-rate curve at fixed relative tenors. The
no-arbitrage drift is the public =hjm_no_arbitrage_drift= free function (the
trapezoid of the cumulative volatility); =next()= advances every tenor,
=current()= is the front (short) rate and =discount_factor()= integrates the
current curve by trapezoid with flat extension past the last tenor. 10
Catch2 tests covering frozen rates at =sigma == 0= reproducing the initial
curve exactly, the drift formula against hand-computed vectors, the
discounted-bond martingale property (statistical), Hull-White equivalence
under exponential volatility (statistical), discount monotonicity, seed
determinism and validation. Registered in =component_files.cmake=.

All 368 =ores.analytics.quant= tests pass on Linux. Not yet wired into
=process_factory= (deferred to PR 2: system infra wiring).
