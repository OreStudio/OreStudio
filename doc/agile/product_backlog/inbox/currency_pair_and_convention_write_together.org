This page is a [[id:671F18E4-E09C-4B3B-BD24-D33DF8AE38A6][capture]] in the *inbox* bucket of the product backlog — a pre-sprint idea, not yet pulled into a sprint as a story.

* What

A pair and its convention are written by two operations; if the second fails the pair exists without the convention it must have one of. The pair insert validates the legs and the classification but not that the pair code is =BASE/QUOTE=, that the legs differ, or that they are in base-precedence order. The pair list filter takes pair codes only. The convention model's note names a trading table for =business_day_convention=, while the insert validates against the refdata list. Add one operation that writes both, derive or check the pair code on the server, add currency and classification filters, and correct the model note.

* Why

Found while writing the currency pair journey; each item is a gap the screen has to work around.
