* Goal

A family with no shape row is projected unguarded, by design, so the catalogue can grow family by family. Nothing says when it should have grown: a new family is written unguarded until someone thinks to state it. A check reads the families the stored identities use, by asset class, series subclass and index family, and names each one no shape row states. Raised by the review of PR #4821.

* Notes

The projector already counts what this task asks about: =backfill_result::unstated= is
incremented for every series whose family no shape states, and the backfill response
does not carry it. The check is therefore mostly a reader, and it is taken after
[[id:15A60BBE-102B-40BA-8F6A-83E2FB92E96B][Report what the shape guard refuses]] rather
than beside it.

What the count says at =67803175ce=, which shapes the deliberate-gap list: the system
tenant holds 330 identities in 5 families and every one of them is stated, so the check
passes on today's data. The 66 unstated families in use are a test tenant's fixtures --
the synthetic series generator writes a faker URI and a drawn subclass -- so the list
is not a catalogue gap but a fixture gap, and the answer may be to fix the generator
instead of listing 66 entries. That is
[[id:474E8968-C7B4-4740-839F-9328B93A5FEA][Generate a series that is an identity]].
