* Acceptance

- =import_service=, =ore_export_service=, =feed_ingest_loop=, =curve_republish_service=, =curve_pillar_reader= and =series_classifier= use the new codecs.
- The export writes each key from the stored datum URI. =market_observations.key= is gone.
- A row cannot hold two identities. An FX pair the import reverses is reported, and the row holds the corrected pair only.
- The corpus import test compares each value with the value under the same key.
- The corpus selection includes the =MD_*= and =FD_*= files, and the tests share one tokeniser with production.
- The database recreates, the whole corpus imports, and an export of the import equals the input after canonical spellings.
- Every developer knows to recreate their database: the PR body names the step (=compass db recreate -y -k=, then re-import), and the sprint journal records the date the cut-over merged.

* Plan

Cut over one consumer at a time behind the same tests. Recreate the database
and re-import; write no migration.
