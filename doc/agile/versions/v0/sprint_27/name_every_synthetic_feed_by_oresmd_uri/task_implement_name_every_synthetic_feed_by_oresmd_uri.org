* Goal

A synthetic FX spot feed states the series it produces as an oresmd URI, the same reference the market data store, the feed bindings and the screens use. Today it states an ORE key (ore_key, such as FX/RATE/EUR/USD), so a reader has to translate between two names for one series.

* Acceptance

- The synthetic FX spot feed model carries an oresmd reference where it carries ore_key, and the generator derives it from the currency pair.
- The feed publishes under that reference, and a feed binding finds it with no translation.
- The data already stored is migrated, and no row keeps the old ORE key.
- The docs and the screens that show the feed use the new name.
