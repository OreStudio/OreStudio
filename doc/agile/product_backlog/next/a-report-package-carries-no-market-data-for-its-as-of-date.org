#+description: A report run failed with 'Failed to build market: There are no quotes available for date October 23rd, 2026'. * What

The market data a run's package carries must cover the date the run prices at.
When it does not, the engine refuses every analytic with one message, and the
report fails for a reason that has nothing to do with the report.

* Why

"Board Risk Dashboard" was triggered on 2026-10-25 against a freshly
provisioned database. ORE named its three analytics and failed all of them with
the same line:

#+begin_example
Failed to build market: There are no quotes available for date October 23rd, 2026
#+end_example

The as-of date and the gathered vintage disagree. Either the run should price at
the date the data has, or the gather should select data for the date the run
asks for. Right now neither happens, and every pricing report fails the same
way.
