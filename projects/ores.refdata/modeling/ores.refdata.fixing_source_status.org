Reference data table of the states of a fixing source. A ceased source,
such as LIBOR, keeps its row, because historical trades and fixings still name
it.

| Code | Meaning |
|------+---------|
| =active= | the source publishes a value on each of its fixing days |
| =ceased= | the source no longer publishes; its history stays |

See [[id:5AF9CEEF-A878-443A-8C32-C6E9F6C26FC9][Fixing sources for option cuts and non-deliverable currencies]].
