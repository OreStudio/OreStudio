* Acceptance

- convention_lookup answers what each FX builder asks.
- The FX planner draws values and calls the builders; its construct_* functions and *_terms structs are deleted.
- The FX entries leave the recorded trades' known lists, and the recorded files change in the same commit.
- The ORE engine test reads and builds every booked FX type.
- The roundtrip tests read every ORE sample trade of each booked FX type and write back every element ORE needs.

* Plan

- One builder per booked FX type. The four single and double barrier products
  share a template, as do the four digital and touch products; the generic
  barrier has its own builder, as it observes an underlying on a schedule.
- A trade names its pair by an oresmd FX index, built from the fixing source
  and the two currencies. The ORE projection's mappers write it as ORE spells
  an index or an underlying, and read it back the same way. No builder or
  planner spells an ORE name. The user asked for this on 2026-11-11.
- A test reads every recorded generated trade back and writes it again, so a
  name spelled outside the mappers fails it.

* Result

Every booked FX type has a builder in =fx_builders.hpp=. The builders state
the option style, the barriers, the underlyings, the observation schedules
and the range bounds as the shared rows ORE's samples need. The planner draws
the pair's FX index as an oresmd index with the source TR20H, which ORE's
samples use; the market data task gives the source a home. The FX
constructors and the plan's =fx_terms= are deleted.

ORE now reads and builds every booked FX type; the 13 FX lines leave the known
errors and 25 entries leave the known missing paths.

The TaRF went around the mappers: its reader read the underlying name as an
index and its writer wrote the index name where ORE wants an underlying name.
Both now use the underlying mappers, and a projection test that pinned the old
behaviour now expects an address. The new round-trip test found that the
variance swap reader dropped LongShort; it now reads it. The round-trip test
holds a known list of the equity and commodity differences, which their family
tasks remove.
