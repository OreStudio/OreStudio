* Goal

AONIA, the RBA's interbank overnight cash rate, is stored as fixings in the system tenant, with its history, read from statistical table F1 (=www.rba.gov.au/statistics/tables/csv/f1-data.csv=, series =FIRMMCRID=). The adapter is specialised: it reads the RBA alone, and it supplies only its fetcher to the shared half of the official adapter.

* Acceptance

- The adapter reads the RBA alone, and it does not copy the announce, the demand, the backfill or the publish code.
- The RBA is a supplier in the catalogue, the series =FIRMMCRID= maps to the AUD-AONIA item, and a session and a feed scoped to that item are seeded in the system tenant.
- A fresh environment stores the AONIA history as fixings within minutes of provisioning, and the log names the source and the count it stored.
- Each fixing is the decimal of the published percent, with the credit "Source: RBA" and the year.
- Unit tests parse a recorded F1 file, and a malformed answer gives an error, not a fixing.

* Plan

- =rba_fetcher= reads a series of an RBA statistical table. Its key is =<table>.<series>=, such as =f1.FIRMMCRID=, and it gets =/statistics/tables/csv/<table>-data.csv=.
- The RBA publishes each table as one file with its whole history, so each read gets the file and keeps the days of the window. The file of F1 is about 300 KB.
- =parse_rba_table= finds the =Series ID= row, takes the column of the series, and reads each later row. A row can stop before the last columns, so a missing cell is skipped as an empty one.
- The BoE fetcher and this one both write dates with an English month name. The parser moves into =published_text= as =date_of_month_name=, with the separator as an argument.
- The HTTP client's user agent becomes =OREStudio (+https://github.com/OreStudio/OreStudio)=. The RBA refuses =ORE Studio= and =OREStudio= with a 403, and accepts this one. The agent has no version, so a release does not change it.

* Notes

- The user agent change was checked against each publisher with one request each. All answered 200 except the Riksbank, which answered =403 Out of call volume quota= to both the old and the new agent. [[id:931A6249-B689-496F-B666-A3CACB0A0494][Register a Riksbank API key]] records it.
- The RBA writes a row for a day before it publishes the day's rate, with the rate cell missing. The parser skips such a row, so the next poll stores the rate.
