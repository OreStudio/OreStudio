* Result

The market is the installation's, and only the system tenant sets it now, as
only the system tenant starts a system feed. A tenant administrator's pin from
the shell is refused as forbidden, and the Market regime tab shows a tenant the
market read-only, with a line saying the system administrator sets it, while a
system session keeps the switch. The gap came with the task that first put the
switch on the feeds screen, which checked the permission to run feeds and not
the tenant.
