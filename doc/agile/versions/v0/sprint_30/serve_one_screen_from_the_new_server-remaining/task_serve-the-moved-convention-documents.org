Serve GET /api/conventions/:family/documents/:id and PUT /api/conventions/:family/documents/:id/terms. A convention document is one family's record, found by the family the address names, with the terms the screen reads off its held form; the write takes the terms the form states and saves them against the version it read.

* Acceptance

- The C++ server answers GET /api/conventions/:family/documents/:id and PUT /api/conventions/:family/documents/:id/terms at the BFF's member names and status codes.
- The document states its family, its kind, the party that holds it and its terms, each term with the value it holds and the values it may hold.
- The write takes the version the screen read and refuses a stale one as a conflict, as the BFF did.
- A family the address names that the registry does not hold is a 404 that names it.
- A test proves each refusal; the happy paths need a live estate and this task does not prove them.
- Each route names its C++ equivalent in the inventory.
