* Goal

The dq FSM migration deleted fsm_protocol.hpp and with it the machine-scoped state lookup, without moving its consumers. ores.workflow.core and ores.trading.core no longer compile on main, and ores.reporting.core asks for states through a request type that no longer exists. Every consumer reads FSM states through the generated surface and the deleted header is referenced by nothing.

- ores.workflow.core, ores.reporting.core and ores.trading.core build from this branch, and no source includes the deleted fsm_protocol.hpp.
