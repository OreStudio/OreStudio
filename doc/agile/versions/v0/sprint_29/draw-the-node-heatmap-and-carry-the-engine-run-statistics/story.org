* Acceptance

- The grid screen draws the node load heatmap and the node state ribbon from the node series, grouped by machine.
- The wrapper measures the engine run time and peak memory and sends them with the result.
- The result records its run statistics and a grouped read aggregates them per workunit and batch.
- A node sample carries the engine run time and peak memory of its jobs, and each host has a cost rate so the grid screens open to a tenant administrator.
