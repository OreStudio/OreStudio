One trade type a trade generation config books. A config books the trade
types of its asset class; when it states rows here it books only those, in the
order the planner of the class cycles them. A config with no row books every
type of its class.

A party prices only some of the products of a class. The Acme holding company,
for one, prices FX forwards and no FX option, so its FX config states
=FxForward= here rather than taking the sixteen FX types the planner knows.

The rows belong to a parent config through =config_id=, the same shape
[[id:2E13AC47-E3F0-4485-AA4D-BC6E9CD1980B][Trade Generation Book]] uses for the book scope.
