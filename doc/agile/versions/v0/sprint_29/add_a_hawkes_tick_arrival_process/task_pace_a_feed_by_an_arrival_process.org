* Acceptance

- The feeds build their clock from ores.analytics.quant and keep no clock code of their own.
- Periodic mode behaves as it does today.
- The config, the Qt editor and the web editor carry the mode, the branching ratio and the decay, and refuse a branching ratio of one or more.
- The sensitivity travels with them, so the market regime has a place to read it from.

* Plan

The feeds already build their clock from =ores.analytics.quant= and keep no
clock code, and a periodic process reproduces their behaviour. What is missing is
the choice: the mode and its numbers live nowhere, so every feed is periodic.

The unit of configuration is one row.

- =fx_spot_generation_config= is keyed by (config, base currency, quote
  currency), so every pair gets its own row.
- =ir_curve_generation_config= is one row per currency and index, so every curve
  gets its own row.
- The two are separate entities, so FX and IR never share a regime.

That is the granularity the design needs: a major pair, an emerging pair and an
IR curve tick at different rates and cluster differently, and each already
carries its own =ticks_per_hour=. The arrival parameters join it as three
columns, and each feed builds its own process from its own row.

1. Add =arrival_mode=, =branching_ratio=, =decay= and =sensitivity= to both config entities,
   with defaults that keep today's behaviour (periodic, zero, a positive decay).
2. Regenerate the C++ and TS domain types and protocols, the SQL create scripts,
   the ER diagrams and the component diagrams.
3. Build the process from the row in both feeds, replacing the hard-coded
   =\"periodic\"=; the factory already converts the rate and refuses a bad mode.
4. Carry the three fields through the Qt editor and the web editor, and refuse a
   branching ratio of one or more in both, beside the rate rule they already
   have.
5. Seed one clustering regime on a liquid pair and leave the rest periodic, so a
   smoke run proves two regimes can coexist.
6. Test: a feed built from a Hawkes row owns a Hawkes process; a row with a
   branching ratio of one is refused before the feed starts; periodic rows are
   unchanged.
