The class declaration for one entity's HTTP route unit. The unit owns one
route per derived verb, and exposes the one entry point a hand-written
per-component aggregator calls to install them.

Two substitutions place the output, and both come from ={component}=, the
short component name without the product prefix. The part directory is
=ores.http.<component>=, so a =trading= entity writes into
=projects/ores.http/trading/=. The include path keeps the shared
=ores.http/= prefix the part's own include root uses, so a unit moves between
the adapter parts without an edit to any =#include=.

The header names no protocol type. The canonical request and response are
used only inside the handler bodies, so the header stays a declaration of the
surface the aggregator sees and the protocol include lands in the source
beside the code that names it.
