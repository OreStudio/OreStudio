* Goal

The rate engine holds current state and answers rate() and rates() for now. A volatility derivation needs ten years of daily levels. Step the same engine day by day through a publisher's fixing series, reading every pair after each day, and return the levels as a history. The streaming path is untouched: this is a second way to drive the same engine, not a second engine.
