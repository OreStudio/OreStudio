* Result

A model change reached the server and stopped there. structure_id and is_leg
were added to the trade summary model, the C++ and SQL generated from it were
regenerated, and the TypeScript the wire protocol generates was not, so the
committed client type described a trade summary the server no longer returns.

Regenerating the trading component moves two files: the domain type gains the
two members, and the protocol shape gains them with the filter operators the
model declares for them. The drift gate for trading-cpp now reports no change,
and the web package typechecks against the wider type.
