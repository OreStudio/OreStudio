The bodies behind the declarations of the sibling
=ores.cpp.shell-command.command_aggregator_header= archetype: the unit
includes and one =register_commands= call per unit.

The list arrives as =shell_aggregator.units=, injected by the generator
at render time from the component's opted-in entity models and the local
units its shell overview declares. Each entry names one unit -- its header
stem and its class name. Every unit reads the root menu and the session,
because the generated =list= verb spells paging as flags. The generator
sorts the entries by unit name, so
the calls are stable from one render to the next and a new unit lands in
its alphabetical place rather than at the end.
