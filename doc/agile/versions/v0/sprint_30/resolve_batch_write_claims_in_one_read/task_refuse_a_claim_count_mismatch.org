* Goal

A generated write(rows, claims) whose two lists differ in size is refused before it reads or writes.

* Acceptance

- Every generated write(rows, claims), entity and junction, throws std::invalid_argument when the sizes differ, before any read or write.
- A repository test proves the refusal and that nothing is written.

* Plan

- In the repository template, check the size of the claims against the rows at
  the top of the entity and the junction =write(rows, claims)=, before any read
  or write, and throw =std::invalid_argument= on a mismatch.
- Regenerate every repository, and test one entity and one junction batch.
