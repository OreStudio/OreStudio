* Result

The system administrator's home has three tabs, held in the address: Dashboard, Active modules and Upcoming modules. The Dashboard has four panels: Tenants, Services, Grid and Message queue. Every panel has the same three parts: a title that leads to its screen, one line of status, and the figures behind it. Every panel says Everything is running when nothing needs the person, and says how many need attention, in the same words, when something does. A panel with nothing to report says so, and a panel still loading says it is loading. The Tenants panel holds the tenant figures, the recent setups, the tenants that need attention and the first tenants. The sentence that says how many tenants the deployment runs is gone, and so is the Tenants heading with its lead sentence above the table. The Services panel uses the installation figures that the services screen opens with. The Grid panel states nodes online, idle nodes, active batches and failed results. The Message queue panel states connections, slow consumers, streams and messages stored. The Active modules tab holds the four cards and the Upcoming modules tab the three journeys with no screen. The system home moved into its own file. The web package passes 650 tests and the format check. I did not look at the home in a browser.
