* Goal

One report definition runs end to end from the scheduler through the
workflow to the compute grid and back, with report pre- and
post-processing, the orchestration contract, the substituted and live
proofs, and a measured baseline. The design, the documentation and the
run configuration shipped with the source story; this story is the
implementation. The target state is written as
[[id:01083101-A83A-4294-81A4-DDF3192CEB14][Report Processing]].

* Acceptance

- A run with both ends substituted executes the real scheduler, the
  real workflow, the real grid and the real storage, and records that
  it was substituted.
- A run with neither end substituted reads live trades and market data,
  and records the engine's results.
- Report processing has a measured baseline, and the reporting handlers
  use the engine's idempotency check.
