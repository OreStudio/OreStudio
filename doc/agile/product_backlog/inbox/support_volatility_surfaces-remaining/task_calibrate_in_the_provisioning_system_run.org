* Goal

A fresh installation provisioned with a demonstration profile has calibrated, running feeds without a click. The system run gains a system-scoped step after system_provision that starts synthetic_calibration_workflow, as start_tenant_setup starts the tenant run, and a release step a profile orders. The Acme profile orders the release; a production profile does not, and leaves it to an operator. The tenant run does not wait for calibration.
