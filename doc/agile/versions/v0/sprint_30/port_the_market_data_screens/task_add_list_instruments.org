* Acceptance

- marketdata.v1.ops.list_instruments answers one entry per instrument, never
  one per node.
- A curve is one entry, a surface is one entry and a pair is one entry with
  no axes.
- No two instruments of one kind share a name within the party.
- Only the caller's party's instruments are returned; an empty party_id
  resolves to the session's party.
- Every axes.values array is in the order a plot can draw without sorting.
- Every source carries as_of, age_seconds and the server's stale verdict.
- The answer pages with offset and limit, and states total and truncated.
