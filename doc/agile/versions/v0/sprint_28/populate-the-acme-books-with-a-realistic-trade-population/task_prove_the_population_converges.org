* Result

The population converges. A second run of the generation wrote nothing and
moved nothing.

Baseline: services stopped, =compass db recreate -y -k=, =compass services
restart=, then one provision with =bootstrap setup … --profile acme_demo=.
The tenant reached =active= about four minutes later.

One provision produced 32 trades, every one at version 5, so
=sum(version)= is 160 over 160 rows; 32 bond instruments at 8 per party
over the four parties; and 32 Internal identifiers.

The second run used the same step the profile runs:

    synthetic generate-trades --config c5359a84… --config 27dcb076… \
        --config 01ad8f0a… --config 34f07898…

Each of the four configs reported =planned 8, wrote 0, already present 8=,
and every one of the 32 trade lines read ="version 5 (already present)"=.
Planned 32, wrote 0, already present 32.

After the run the counts are identical: 32 trades, =sum(version)= 160, max
version 5, 160 rows in total, 32 bond instruments, 32 identifiers. No trade
duplicated and no trade's version advanced.

Nothing in the acceptance was missed.
