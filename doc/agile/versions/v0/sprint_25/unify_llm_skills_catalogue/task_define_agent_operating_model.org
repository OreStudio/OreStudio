* Goal

The purpose of this framework is that the mode can be started on an agent and left to run. That case is the least specified part of it. Settle and implement the operating model: the five fields that configure an agent, which are function, level, environment, finish condition and authority, with the model inherited rather than routed; isolation through a worktree per parallel writer, including the two resources a worktree does not protect, the shared git stash stack and any remote; and the four things an unattended run needs that an attended one does not, which are a finish condition the agent can check itself, an authority grant made explicitly in advance and narrowly, a decision trail that makes the result reconstructable, and liveness, failure and resumption behaviour. Delegation is for context, parallelism and isolation only; it is never for a second opinion, because every delegate runs the same model as its parent.

* Acceptance

- The five configuration fields are implemented, and an agent cannot be started without a function, a level, an environment and a finish condition.
- Authority is granted explicitly and narrowly in the request that starts a run; an agent that reaches the edge of its authority stops and says so rather than widening its own grant.
- Be autonomous is not treated as an authority grant; it permits reversible work only.
- Every parallel writer has its own worktree and environment, provisioned through compass.
- The shared git stash stack and any remote are handled explicitly rather than left to a delegate to improvise.
- A run leaves a decision trail sufficient to reconstruct it, preferring evidence a reviewer can re-run over claims in prose.
- A supervisor can distinguish a working agent from a stuck one without interrupting it.
- A run can be paused at an atomic boundary and resumed later by a different agent from its trail and branch.
- An agent at a genuine dead end stops and explains rather than retrying a failing approach.
- The model is inherited from the spawning session and never routed per role.
- One real unattended run completes end to end before the task closes.
