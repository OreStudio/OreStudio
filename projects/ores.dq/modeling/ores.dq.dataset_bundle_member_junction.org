Junction table linking bundles to their constituent datasets. Uses codes
for loose coupling - allows declaring membership for datasets that may not
yet exist in the system.

Examples:
- Bundle "slovaris" contains "slovaris.countries", "slovaris.currencies", etc.
- Bundle "base" contains "iso.countries", "iso.currencies", all FpML datasets

** Handler: list

Plain, unfiltered list of all dataset bundle members (no soft-FK
filter). No generic junction template mechanism currently produces
this shape (junctions only generate =list_by_<side>= operations, gated
by =:list_by:=), so it is captured here as a hand-written paste block
until/unless a second junction needs the same shape.

#+begin_src cpp :name protocol_extra :implements 5C3C5DBB-684A-4947-9A35-25D33ED7A222
