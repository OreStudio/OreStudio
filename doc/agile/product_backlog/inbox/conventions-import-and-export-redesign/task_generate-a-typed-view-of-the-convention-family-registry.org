* Goal

A caller that works on every convention family visits each family with its own generated value type and protocol messages. Today the registry is a table of strings, so only refdata's generated apply can dispatch on it, and ores.ore falls back to untyped values.

* Acceptance

- Codegen emits, from the same models as the registry, a visitor over every convention family that hands the caller the family's value type and its list and stage messages.
- A static assertion or test checks that the typed view and the string registry name the same families in the same order.
- Adding a convention family needs no hand edit to the typed view.
