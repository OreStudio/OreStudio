* Steps

** Log in as tenant admin for Acme Corporation

- Launch the Qt client: =compass client start=
- Log in as =tenant_admin@acme_corporation= / =Secure-Password-123=
- Select *ACME CORPORATION PLC* from the tenant picker
- Confirm the main window opens with the menu bar visible

** Open Pricing Engine Types and verify list

- Navigate to /Analytics → Pricing Engine Types/
- Confirm the list window opens with existing system records (Swap, EuropeanSwaption, BermudanSwaption, CMS, CapFloor)
- Verify pagination controls are visible and functional
- Verify the toolbar has Add, Edit, Delete, and History buttons

** Add a new pricing engine type

- Click *Add* in the Pricing Engine Types toolbar
- Enter Code: =TestType=
- Enter Description: =Test pricing engine type for regression=
- Leave Instrument Type Code blank
- Click *Save*
- Confirm the new row appears in the list with Code =TestType=

** Edit the pricing engine type

- Select the =TestType= row in the list
- Click *Edit*
- Change Description to =Updated test pricing engine type=
- Click *Save*
- Confirm the list refreshes and shows the updated description

** View pricing engine type history

- Select the =TestType= row
- Click *History*
- Confirm the history dialog opens showing at least 2 versions (create + edit)
- Close the history dialog

** Delete the pricing engine type

- Select the =TestType= row
- Click *Delete*
- Confirm the deletion prompt appears
- Confirm deletion
- Verify the =TestType= row is removed from the list

** Open Pricing Model Configs and create a config

- Navigate to /Analytics → Pricing Model Configurations/
- Confirm the list window opens
- Click *Add*
- Enter Name: =TestConfig=
- Enter Variant: =standard=
- Enter Description: =Test configuration for regression=
- Click *Save*
- Confirm the new config appears in the list

** Find config by name

- In the Pricing Model Configs list, locate the row with Name =TestConfig=
- Select the row and click *Edit*
- Confirm the detail dialog shows Name =TestConfig=, Variant =standard=
- Close the dialog without saving

** Add a pricing model product to the config

- Navigate to /Analytics → Pricing Model Products/
- Confirm the list window opens
- Click *Add*
- Select the config created above in the Pricing Engine Configuration dropdown
- Select Pricing Engine Type =Swap=
- Enter Model: =DiscountedCashflows=
- Enter Engine: =DiscountingSwapEngine=
- Click *Save*
- Confirm the new product appears in the list

** Add a pricing model product parameter

- Navigate to /Analytics → Pricing Model Product Parameters/
- Confirm the list window opens
- Click *Add*
- Select the config created above in the Configuration dropdown
- Leave Product blank (global parameter)
- Set Scope to =global=
- Enter Parameter Name: =Calibration=
- Enter Parameter Value: =Bootstrap=
- Click *Save*
- Confirm the new parameter appears in the list

** Delete test data and verify cleanup

- In Pricing Model Product Parameters, select the test parameter and click *Delete*
- Confirm deletion
- In Pricing Model Products, select the test product and click *Delete*
- Confirm deletion
- In Pricing Model Configs, select =TestConfig= and click *Delete*
- Confirm deletion
- In Pricing Engine Types, verify no leftover test data remains
