* Goal

A curve segment's element is its type, not a value of one of its columns. Each element's settings live in their own part, and a segment row holds the element and its shared terms.

* Acceptance

- No segment row carries a column that the element its segment_type names cannot use.
- The twelve elements' settings are parts, and a part exists only for the elements that have it.
- The curve recipe's read, the ORE projection and the fixtures state the segment and its parts as separate arrays.
