* Goal

Give the reviewer evidence of what a change does. The person runs the same report with configuration A and with configuration B, and the screen shows the difference in the results and explains it: which products moved, by how much, and which model, engine or setting change explains each move. The reviewer reads this beside the difference of the configurations before approving. This needs a run that can take a chosen configuration version, a way to compare two runs of one report, and a link from a moved result to the configuration change behind it.

* Acceptance

- A person can run one report against two configuration versions and read both runs side by side.
- The screen lists the products whose result moved, with the size of the move.
- Each move names the configuration change that explains it, or says that no change explains it.
- The proposal for sign-off carries this evidence.
- The task says which operations exist today and which are missing, including the operation that says which configuration version a run used.
