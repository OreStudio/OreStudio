* What

=floating_index_code= on a swap leg holds the index its leg type names: a
floating index, a CMS swap index such as =USD-CMS-30Y=, an inflation index,
a commodity or a formula. The trigger checked it against the floating index
table alone and refused every CMS, inflation, commodity and formula leg, so
the check was dropped. A floating leg's index is now checked by nothing.

* Why

A mistyped floating index is a defect the database caught and no longer
does. The check should return keyed by the leg type, each kind against the
table that holds it, or the column should split by kind.
