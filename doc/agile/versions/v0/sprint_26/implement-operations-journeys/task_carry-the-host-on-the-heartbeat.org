* Goal

Every service heartbeat carries the service name, the instance id and the
release, and no host. The compute side is the mirror: each node sample
carries the host id, and no instance id. Nothing joins an instance to the
machine it runs on, or a compute wrapper to its node
([[id:A1D7FC12-4105-41F7-8885-CCE07120034C][The service heartbeat carries no host]]).
This task adds =host_id= to =service_heartbeat_message= and stores it on
=service_sample= beside =instance_id=, so the grid's wrapper panel and the
services roster can name the machine behind an instance.
