* Goal

Every shell command storage answers is produced by a generated unit, or is recorded as a hand-craft with a reason. The generated objects operation unit and the hand-written storage menu both offer put, get, delete and list, over different transports and different input shapes, so one of the two has to be the surface and the other needs a reason to exist.
