* Acceptance

- The store lists a sprint with its stories, their tasks and progress, and the backlog buckets.
- It reads only the work tree the BFF runs in.

* Plan

Port the field rules of =ores.dsh_kanban/lib/agile.js= to a TypeScript model that reads text. Put a file store behind an interface, and test it on a temporary tree and on the real tree.

* Notes

The store gives the sprints, one sprint's board and the four backlog buckets. It leaves three things to later tasks. The doc route reads any doc by id, in the serve task. The work tree and the current story need git, in the work trees task. The charts need the history of each sprint, in the charts task.

A test found that a story file that is a link was read. The store uses =lstat=, so a link is never a file.

* Result

The BFF has =FileAgileStore= behind =AgileStore=. It lists sprints newest first, builds a board with the columns, counts, filters and progress of the old contract, and lists the backlog buckets. It reads only regular files and real directories, and a sprint name must match =sprint_N=. 620 BFF tests pass.
