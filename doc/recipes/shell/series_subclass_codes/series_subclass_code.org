#+title: How do I run the series_subclass_codes commands from the shell?
#+description: Every command the series_subclass_codes submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:series_subclass_codes:

This file documents the series_subclass_codes resource at the shell, one section per command. Every command is a subcommand of =series_subclass_codes=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: 73E79027-DA12-5843-9955-4C4E9E0B3714
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
series_subclass_codes list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =refdata.v1.series_subclass_codes.list=.

#+name: series_subclass_codes-list
#+begin_src ores-shell :tangle series_subclass_codes-list.ores :exports none
series_subclass_codes list --limit 1
#+end_src

** =get=
:PROPERTIES:
:ID: 7C8B8553-6D35-5640-AAA3-907163312C96

#+end_src

** =add=
:PROPERTIES:
:ID: 9870728A-8AA2-5730-A1D1-120FE2874FDB
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.


The command is shaped like this:

#+begin_example
series_subclass_codes add <code> <name> <description> <display_order> <reason> <commentary>
#+end_example

It is addressed at =refdata.v1.series_subclass_codes.put=.

#+name: series_subclass_codes-add
#+begin_src ores-shell :tangle series_subclass_codes-add.ores :exports none
series_subclass_codes add __none__ __none__ __none__ 0 system.new_record generated_script
#+end_src

** =set=
:PROPERTIES:
:ID: 693FE4C1-EFD0-5208-9590-7136231AECFA
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved. Passing --version makes the write conditional on the version the caller last read.


The command is shaped like this:

#+begin_example
series_subclass_codes set <code> <name> <description> <display_order> <reason> <commentary> [--version <n>]
#+end_example

It is addressed at =refdata.v1.series_subclass_codes.put=.

#+name: series_subclass_codes-set

#+end_src
