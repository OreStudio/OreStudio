* Enum brief

The `quote` query key for equity instruments — the ORE TYPE. Equity-only;
only meaningful when `type=quote`.

* Identifier brief

A fully-resolved oresmd identifier for an equity/index instrument (asset_class=equity).

`ccy` is required here (unlike IR, where `entity` already is the currency) since an
equity's `entity` is a ticker -- the quote currency is independent information.

* Requirement brief

A logical, possibly-partial oresmd requirement for an equity/index instrument.
