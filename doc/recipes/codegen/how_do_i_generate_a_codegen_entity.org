#+title: How do I generate a codegen entity?
#+description: Run ./compass.sh generate --scope on the entity model to write the outputs that model feeds, and only those whose content changed.

* Question

How do I regenerate all codegen output for an entity?

* Answer

Edit the entity's model under its component's =modeling/= directory, then run
=generate= scoped to that model, from the project root:

#+begin_src sh
./compass.sh generate --scope projects/ores.refdata/modeling/ores.refdata.country.org
#+end_src

=--scope= limits the run to the outputs of the units that read the file, and
to what they feed. compass-ng writes only the outputs whose content differs,
so an unchanged file keeps its timestamp. Every layer the model's type and its
=:ores.*.enabled:= overrides admit is covered in one run: the SQL schema and
populate scripts, the C++ domain, repository, service, protocol, handler and
eventing files, and the CMake lists.

Preview first, which writes nothing:

#+begin_src sh
./compass.sh diff --scope projects/ores.refdata/modeling/ores.refdata.country.org
#+end_src

Without =--scope=, =generate= covers the whole tree. A warm run with no change
takes a few seconds, so after a template change or a change that reaches
several models, run it unscoped.

* Script

=./compass.sh generate= and =./compass.sh diff= forward to compass-ng through
=cmd_compass_ng= in [[proj:projects/ores.compass/src/compass.py][=compass.py=]]; its =codegen= codec renders the templates
of [[proj:projects/ores.codegen/library/templates][=projects/ores.codegen/library/templates=]].

* Tested by

Run the scoped =diff= on a current model: it reports 0 to write and the count
of outputs the model feeds (98 for =ores.refdata.country.org=).
