* Result

** Outcome

Each catalogue entity has a list and a single read that the service serves:
publisher, supplier, adapter, session and feed. A test calls both for each
entity, so a read cannot quietly disappear.

The five read permissions are seeded, and the Viewer role holds all five, so
the Connectivity screen can read the catalogue without a write grant. A pgtap
suite states the permissions, the Viewer grants and the rows a screen reads.

The generated reads already existed; this task proves them and closes the
permission gap for suppliers, adapters and sessions.
