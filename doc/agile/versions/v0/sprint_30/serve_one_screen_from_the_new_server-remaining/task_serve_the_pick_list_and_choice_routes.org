* Plan

The four pick lists read reference data lists only, so they live in the
refdata part as one hand-written unit: a shared reader that pages through any
list, and one table per form that names each control and its list.

On 2026-11-11 the two choice routes moved out of this task. They read the
analytics and reporting protocols, and neither area has an HTTP part yet, so
each belongs with its area: the sensitivity templates' choices with
[[id:3727E9F4-3FE9-4B8A-A067-5F7AB6504CE0][Serve the sensitivity templates]], and the report form's choices
with [[id:504FD469-B1A1-4480-9694-34724AD2F2A5][the reporting part's resources]].
