* Goal

Make the money gate able to see the shapes the FX review found. The check reads
the models and classifies each column by name, so three deviations pass it: a
continuous quantity whose name reads as money, a money value read through a
binary float, and money typed text. Both of its baselines are a single blank
line, so the gate asserts nothing for this family in either direction.

* Acceptance

- A column whose name reads as money but whose economics are continuous is checked as continuous, and the exclusion list is not the only thing that hides it.
- A money column typed =text= is reported.
- The check is not extended to read the ORE binding unless that is the chosen mechanism; if it is, the check names what it reads.
- Both baselines are seeded with the offenders that remain, so the debt is visible and cannot grow.
- The exact-numbers page stops restating the baselines in prose, as its own rule asks.
- A pytest case covers each new direction, including one that the old check missed.

* Plan

1. Reproduce the three blind spots with the family's own columns.
2. Decide the mechanism for each, and write it into the check with a test.
3. Run the check over the whole tree, seed the baselines, and read the new entries.
4. Correct =exact_numbers_and_economic_change.org= so it points at the baselines rather than repeating a count.
