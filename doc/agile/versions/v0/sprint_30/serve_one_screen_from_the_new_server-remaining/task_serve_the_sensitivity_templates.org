* Plan

The analytics area had no C++ part, so the first step is the part itself:
=ores.http.analytics=, an adapter of the gateway, copied from the plan
[[id:3A61E5E2-CBD2-47D5-B70C-F656C214937C][How do I add an adapter part to ores.http?]] states. Its
=CMakeLists.txt= files are hand-authored, codegen writes only its two file
lists, and the part holds one hand-written unit rather than generated ones: the
templates are read as a page with two lookups joined beside each row, which is a
composed answer and not a collection.

The unit answers the seven routes at the BFF's addresses and in its shapes. The
two lookups are read from the tables that hold them rather than restated here, so
a method or an asset class added to a table reaches the form without a change to
the part, and the rule the methods table states - a method that needs no class
states none - is applied before a write reaches the store, so the refusal names
which of the two is wrong.

The writes carry the preconditions the screen reads: a create states a key the
table does not hold, and a correction and a removal state the version the screen
read, so a key written meanwhile is refused rather than replaced. A removal
answers the row it removed, whose versions stay behind it.

The keys' history is read through the gateway's one history step, so this part
does not derive a subject of its own.

* Result

The templates are served. The gateway has an eleventh adapter part,
=ores.http.analytics=, and it answers the whole family at the BFF's addresses: the
page, the two lookups, one key, its history, and the three writes. The analytics
area is the seventh the gateway serves whole, and 295 of the BFF's 333 routes are
now paired.

What is proved: the part builds and the server links it, its six cases pass, the
local gate is green, and the inventory regenerates to itself with every one of the
seven routes paired. What is not proved: no route of this part was read against a
live service, so the page, the lookups and the writes rest on their tests and on
the shape the inventory states, and the store's own refusals were not exercised.
