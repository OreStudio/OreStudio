* Acceptance

- The list covers every instrument that the current feeds simulate.
- Every id follows the vendor's notation, and each minted id has a deviation note.
- The list is checked against the external identifiers survey.

* Plan

(Implementation strategy. Written when work starts; key decisions
are distilled into the parent story's =* Decisions= at close, but the
plan itself stays — it is the historical record of what we did.)

1. List what the current feeds simulate: 26 FX spot pairs and a short-rate curve for 28 currencies.
2. Write the FX pairs once, in a generator, and derive from that list both the rows the bundle installs and the table of the inventory page, so the two cannot differ.
3. Write each id in the vendor's notation. Mint none. Mark the rows of markets with a non-deliverable variant for a check against the vendor.
4. State what is not inventoried: the rate curves, ICE and Tradeweb, and why.
5. Check the notation against the identifier survey, and add the page to the architecture hub.

* Result

The catalogue now installs the 26 FX spot pairs that the simulated feeds quote, in the notation of Bloomberg, LSEG and ORE: 78 vendor instruments and 78 mappings that map the three providers to the same oresmd items. No id is minted. The new populate script derives the id of each vendor instrument from its identity, so a second run writes the same rows. The inventory page lists the rows, says how each id is written, and marks the 6 pairs of currencies with a non-deliverable variant (INR, KRW, TWD, BRL, CLP, COP) as =to confirm=, which is 12 vendor instruments of Bloomberg and LSEG. The notation agrees with the examples of the identifier survey. The SQL schema check, the populate reference check and the documentation checks pass.

Left for later work, and stated on the page:
- A person with access to the Bloomberg and LSEG screens must confirm the rows marked =to confirm= and the rows marked =standard=. The public documents do not define the notation, so the list is a reviewed proposal and not a verified list.
- The short-rate curves of 28 currencies have no rows. A curve tick from a vendor adapter is dropped as =unmapped= until the pillar ids are written down.
- ICE and Tradeweb have no rows, because the feeds simulate nothing in their asset classes and their notation is not public.
- The populate script did not run against a database, because the worktree =.env= is at version 32.
