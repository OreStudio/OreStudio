ORE's =parametricSmileConfigParameters= is an unbounded sequence of
=Parameter=, each a name, an optional initial value and whether it is fitted.
A list is a part of its own keyed by the smile, and the order the document
writes is a column, because the export restores that order and nothing else
carries it.
