#+title: Check: wide types
#+description: No C++ class, struct or union holds more than fifteen data members, save the types its Ceilings table records, whose ceilings only come down.
#+type: check

This page defines a =check= that compass runs over ORE Studio. Its =* Definition=
is what compass runs; the rest says why.

* Rule

No class, struct or union of ORE Studio's C++ declares more than fifteen
non-static data members. A type over fifteen is listed in =* Ceilings= with
the count it has; it may shrink, and its row comes down with it, but it may
not grow, and no new type joins the list.

* Why

A type with many fields usually holds several concepts at once. Grouping the
fields that belong together into types of their own keeps each type small
enough to read, to test and to change, and lets code that needs one group
take that group alone. The ceiling of fifteen is a judgement, not a measured
limit: it is what the product owner set.

The check is a warning: it shows the wide types, and the ones that grow, but
fails no gate. The table is the list to work down.

This check is about design, not the compiler. MSVC's C1202 limit is the
=Keep MSVC within its template limits= story's subject, in the compass
repository.
