* Result

ores.web.typecheck and ores.web.tests share the ctest resource lock
ores_web_dist, so ctest never runs them together. The cause was in the
Continuous Linux linux-clang-release log of run 37097859492: the typecheck
started at 05:45:47 and ran 27 seconds, rebuilding the wire package's dist
with tsc --build --force, and the tests started at 05:45:50 and failed at
05:45:55 with 18 BFF suites reading an import as undefined. The BFF suites
import that dist.

Proof: ctest -R ores.web -j 2 now starts the tests only after the typecheck
passes, and both pass.
