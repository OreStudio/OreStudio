* Acceptance

- No note, seed, journey or screen describes a vintage as the source of an
  initial price; the notes point at the fixing items instead.
- A new FX or IR config starts on the fixing path, and a fixed level is
  reachable only as a stated fallback for a pair no source covers.
- A search of the tree for =vintage= finds only historical records and the
  backlog investigation on backdated data, never a current path.
- The story's decision states that vintage is decommissioned.

* Plan

"Vintage" has two senses in the tree. A reference dataset is named by its
date, =marketdata.reference_vintage_2016_02_05=; that name stays. The retired
sense is =price_source='vintage'=, an initial price read from a stored
observation; its code is already gone, so the notes, the seeds and the
defaults follow.

- Seed the FX calibration policy (ECB, IMF, Bank of Canada, CBRT; 90 days;
  inverse allowed; keep the fixed level) and stop seeding per-feed fixing
  items, so every seeded feed derives its candidates.
- Start a new FX feed on =fixing=; =fixed= is the fallback for a pair no
  public source fixes. An IR curve keeps its stated initial rate, since no
  public source fixes a short rate.
- Remove the dead =SyntheticFeedRun= role and the synthetic service's run
  grant exchange, which existed to read a vintage price.
- Rewrite every current note, journey, wireframe and seed comment that
  describes a vintage as an initial price.

* Result

The vintage path is closed. The FX calibration policy is seeded and no feed
is seeded with items of its own; a new FX feed starts on the fixing path, and
the fixed level is the stated fallback. The notes, journeys, wireframes and
seed comments describe the fixing path, and the dead run role and grant are
gone. A search for =vintage= finds the reference dataset names, the dated
history, real company names in the LEI seeds, and the backlog investigation
on backdated data, never a current way to start a feed.
