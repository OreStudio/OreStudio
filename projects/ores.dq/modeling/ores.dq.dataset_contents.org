The dataset contents verb: one request that names a dataset and, when it names a
table too, one page of that table's rows.

A dataset names one artefact type, and the type names a table or a family of them,
so the dataset alone does not say which tables hold its rows. The answer carries
the tables first and the rows second, because no screen knows a family's shape in
advance and every family carries its own columns.

It is an operation rather than an entity verb because the answer is a shape no
table holds: a table's rows, with the columns that table states. The handler that
serves it stays hand-written beside this model.
