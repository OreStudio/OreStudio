* Result

The Development area has a Board tab, built to the accepted variant A. It shows the sprint line with a sprint picker held in the address (=?sprint=sprint_N=), the day of the sprint clamped to the sprint, four tiles, a search box and epic filters, a column for each state with a card for each story, and the story detail with its fields, pull request links and expandable tasks. A link in the detail opens the story or task doc on the existing doc page. The board reads =/api/agile/board= and =/api/agile/sprints=. The English, French and Portuguese text is in the catalogue, and the French and Portuguese is my translation, which needs a speaker. The tests cover the filter, column and day rules, the tab and the detail as markup. I did not drive the tab in a browser, and the current-story mark waits for the work tree task.
