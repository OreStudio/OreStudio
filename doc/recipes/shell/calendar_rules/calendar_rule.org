#+title: How do I run the calendar_rules commands from the shell?
#+description: Every command the calendar_rules submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:calendar_rules:

This file documents the calendar_rules resource at the shell, one section per command. Every command is a subcommand of =calendar_rules=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: 10012B00-0F1E-5524-8250-3C57AEF9B58E
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
calendar_rules list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =refdata.v1.calendar_rules.list=.

#+name: calendar_rules-list
#+begin_src ores-shell :tangle calendar_rules-list.ores :exports none
calendar_rules list --limit 1
#+end_src

:ID: D4DB0EF8-14E7-5888-96BA-7D3D970C0A85

** =add=
:PROPERTIES:
:ID: D88BD5E3-B875-5AC5-89B3-AD69B27514A9
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.


The command is shaped like this:

#+begin_example
calendar_rules add <id> <calendar_code> <kind> <month> <day> <weekday> <occurrence> <day_offset> <shift> <effective_from> <effective_to> <reason> <commentary>
#+end_example

It is addressed at =refdata.v1.calendar_rules.put=.

#+begin_src ores-shell :tangle calendar_rules-add.ores :exports none
calendar_rules add 00000000-0000-0000-0000-000000000000 __none__ __none__ __none__ __none__ __none__ __none__ __none__ __none__ __none__ __none__ system.new_record generated_script

** =set=
:PROPERTIES:
:ID: 7D7A5648-12C4-57C1-862B-9344C6A52AB2
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved. Passing --version makes the write conditional on the version the caller last read.
