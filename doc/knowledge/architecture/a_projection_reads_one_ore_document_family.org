* Summary

A *projection* is the code that knows one ORE document family: its elements,
its vocabulary, and the rows it becomes. The tree has three:

| Document | Root element | Projection |
|----------+--------------+------------|
| The pricing engines | =<PricingEngines>= | =pricing_engines_import= |
| The curve configuration | =<CurveConfiguration>= | =curve_configuration_projection= |
| The run document | =<ORE>= | =run_document_projection= |

A projection reads a document into a typed record, maps that record to rows, and
is the only code that knows the document's shape. It does not decide what a
value *means*: it passes the value through, and the value set decides.

An example, from =pricingengine.xml=:

#+begin_src xml
<PricingEngines>
  <Product type="Swap">
    <Model>DiscountedCashflows</Model>
    <Engine>DiscountingSwapEngine</Engine>
    <ModelParameters/>
    <EngineParameters>
      <Parameter name="EnforceMonotoneVariance">true</Parameter>
    </EngineParameters>
  </Product>
</PricingEngines>
#+end_src

The projection turns =Product@type=, =Model= and =Engine= into the product row,
and each =Parameter@name= into a settings row keyed by =(scope, name)=. What
=true= may be, and what values =Scheme= may take, is not the projection's
question.
