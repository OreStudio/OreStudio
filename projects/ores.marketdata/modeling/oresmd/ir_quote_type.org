* Enum brief

The `quote` query key of an oresmd URI, IR-only and only meaningful when
`type=quote`: the ORE quote TYPE (e.g. MM, FRA, IR_SWAP) — the first segment of ORE's
TYPE/METRIC/... quote key, independent of the METRIC column carried by the `metric`
query key.

* Identifier brief

A fully-resolved oresmd identifier for an interest-rate instrument (asset_class=ir).

Only `ccy` and `type` are unconditionally mandatory; every other field is optional
because which fields are meaningful depends on `type` (a fixing/curve needs
`index`/`tenor`/`role` but no `point`; a quote needs `point` and, for `type=quote`
specifically, `metric`) -- see "Tenor vs. point, and the par-rate/discount-factor
ambiguity" in the design doc.

* Requirement brief

A logical, possibly-partial oresmd requirement for an interest-rate instrument.

* Type-gated keys

Query keys that are only meaningful when =type=quote=; the parser rejects them
otherwise ("'<key>' is only meaningful when type=quote").

=quote= is not here. A quote type names a volatility surface as well as a quote
-- CAPFLOOR arrives as =type=vol= with =quote=capfloor= -- so the check that
guards it lives in the parser, which accepts it for =quote= and =vol= alike and
refuses it for everything else.

* Notes

IR has the most complex qualifier shape variants:
- =includes_index_2d=: qualifier is CCY/2D/TENOR (ir_swap only — the 2D is settlement lag)
- =curve_id=: qualifier is CCY/CURVE_ID where CURVE_ID = CCY+TENOR stripped (discount only)
- =includes_index=: qualifier is CCY/INDEX/TENOR (mm, zero, mm_future, oi_future)
- =two_tenors=: qualifier is FIRST_TENOR/SECOND_TENOR/CCY (basis_swap only --
  a single-currency basis swap quotes two index tenors against one currency,
  so the key carries both tenors and no index and no role. The registry's own
  shape table calls the pair long_tenor/short_tenor; this model names them by
  position, because the corpus does not say which of the two is the longer
  and the registry's labels are not corroborated anywhere else.)
- =cross_currency=: qualifier is CCY1/TENOR1/CCY2/TENOR2 (cc_basis_swap and
  cc_fix_float_swap -- two currencies and two index tenors, with the maturity
  after them; the entity path segment carries the first currency)
- =capfloor_vol=: the key after the metric is CCY/MATURITY/FLOAT_TENOR/SHIFT/
  STRIP/STRIKE, so the currency is the entity and the surface coordinate is
  everything after it. The two flag slots are what the market data catalogue
  calls the shift and strip flags; they are =0= on almost every corpus line and
  =1/1= on the rest. The same shape serves RATE_NVOL and RATE_LNVOL, which
  differ only in the metric -- normal vol against log-normal.
- =no_index=: qualifier is CCY/START (BMA, and the fra families -- no index
  dimension; FRA's second segment is its start tenor and IMM_FRA's is its IMM date)

=type=vol= handled separately via =volatility_surface_point= struct.
=type=fixing= produces index_name and curve_key via separate projection paths.
