One ORE =todaysmarket.xml= document, held as the thing the collections and the
configurations hang off. The document itself carries no market data: it is an
ordered set of collections, each entry naming a curve by reference, plus named
configurations that select one collection of each kind by the collection's id.

The entries live on =todays_market_entry=, the configurations on
=todays_market_configuration=, and the references a configuration makes on
=todays_market_configuration_binding=. This row is only the identity of the
document, so that a tenant may hold more than one and a report may choose
between them.

The reporting configuration this document is registered as. A run names its
today's market file in its setup; the reporting configuration is what joins
that name to these rows. Nullable because a document can be imported before it
is registered: the mapper reads and writes content and does not invent a
header, the caller supplies one.
