The class declaration for one operation model's HTTP route unit.

The facet's entity archetypes render a fixed CRUD set. This archetype renders
what the model *declares*: one handler per message that carries a =:subject:=
and a =:response:=, because the subject is what the route forwards to and the
response is what it returns. A message with no response answers with nothing
to carry, and a payload struct has no subject at all, so neither becomes a
route.

The model type is the only difference from the entity archetypes, and it is
stated here rather than inherited so the entity archetypes keep rendering
entities. Nothing else about the facet changes: the opt-in, the part the unit
lands in and the aggregator that calls =register_routes= are the same.
