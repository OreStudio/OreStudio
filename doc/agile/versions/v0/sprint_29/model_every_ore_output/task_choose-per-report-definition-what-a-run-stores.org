* Acceptance

- The report definition carries the set of output families its runs store, and a new definition stores every family.
- The post-processor and the marketdata ingest parse only the families the definition names, and log the families they skip.
- The raw output files stay in the object store whatever the definition says.
- The setting is visible and editable wherever a report definition is edited.
- A run with a family turned off stores no rows for that family, and a test proves it.

* Plan

The definition names the families its runs *skip*, not the ones they store, so
an empty list stores everything and a family the catalogue gains later is stored
without anyone editing a definition.

1. A =family_selection= in the =ores.ore= catalogue: the skipped codes, parsed
   once from a comma-separated list, refusing a code the catalogue does not name.
2. =skipped_families= on =report_definition=, text, default empty.
3. The trigger refuses an unknown code, as it refuses an unknown
   post-processing, and copies the list into the run's request, so a run stores
   what its definition said when it started.
4. Post-processing passes the selection to the reporting reader and to
   =store_market_state=; each skips the family, does not fetch its file, and
   names it in the log.
5. The web report page shows and edits the list; the shell command gains the
   argument through the codegen.

* Result

A report definition now names the output families its runs skip, in
=skipped_families=, empty by default, so a new definition stores every family and
a family the catalogue gains later is stored without an edit. The trigger
refuses a family the catalogue does not name and copies the list into the run, so
a run stores what its definition said when it started. Post-processing and the
market state store skip those families, do not fetch their files, and log each
one; the files stay in the object store. The web report page and the shell
command show and edit the list. A run of Group Consolidated Exposure that skips
=saccr= stored its 36 npv figures and no saccr rows. Every acceptance bullet is
met.
