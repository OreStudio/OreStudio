* Notes

The defect came in with =d1f8da3523=, which wanted a republish of a convention
to be a skip rather than a duplicate key. It appended =on conflict do nothing=
to the insert the function executes, and wrote a block comment between the two
adjacent literals. PostgreSQL joins two constants separated only by whitespace;
a comment is not whitespace, so the second literal became an argument. Nothing
ran the function between the merge and this discovery: =setup_schema.sql= failed
at the file, so =compass db recreate -y -k= aborted with exit 3.

The guard lives in =check_sql_hygiene.py=, which already scans the SQL tree for
a comment that breaks a recreation. It now also scans inside dollar-quoted
function bodies, because a body is SQL the server runs.
