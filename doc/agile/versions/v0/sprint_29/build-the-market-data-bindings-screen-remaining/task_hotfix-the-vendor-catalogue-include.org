* Result

=ores.marketdata.core/datum/oresmd_uri_codec.hpp= no longer exists: the ORE
metadata codec moved into the marketdata api component. =tools/vendor_catalogue=
still included the old path, so the target and everything after it in the build
failed with

#+begin_example
fatal error: 'ores.marketdata.core/datum/oresmd_uri_codec.hpp' file not found
#+end_example

The include now names =ores.marketdata.api/datum/oresmd_uri_codec.hpp=. The
target builds, and the file is brought to clang-format because the format gate
refused the pillar quote initialiser it inherited.

Verified: =./compass.sh build ores.marketdata.vendor-catalogue= exits 0;
=./compass.sh check --only format= passes.
