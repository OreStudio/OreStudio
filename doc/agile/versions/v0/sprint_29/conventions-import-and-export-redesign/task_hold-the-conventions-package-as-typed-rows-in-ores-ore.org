* Goal

Inside the ORE file boundary, the conventions package holds each family's rows as their own value types. The design allows a transient typed form there. The mapper, the tenor basis swap and cross currency joins, and the diff work on values, and nothing encodes a row to JSON only to decode it in the same process.
