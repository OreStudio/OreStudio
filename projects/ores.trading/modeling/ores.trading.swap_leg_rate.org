One numbered rate or spread of a swap leg, dated from the day it applies. A
leg whose rate steps states one row per step; a leg with a single rate states
one row.

ORE states a fixed leg's rate as a list on =legData/FixedLegData/Rates= and a
floating leg's spread as a list on =legData/FloatingLegData/Spreads=. Both are
a list of values that vary over the leg's life, so both land here and
=rate_role= says which arm stated the row. The leg itself carries no rate and
no spread, because a single column cannot hold a schedule.

=rate_role= is data, not a table: the closed set is =fixed= and =spread=, and
the schema states it.

The row is a child of the leg rather than an entity with a life of its own:
=swap_leg= names the trade and the ordinal, and this row adds its role and its
own ordinal within that leg.

** Custom repository methods

The trade read path fetches the rates of many instruments' legs at once, and
no generated read covers that: the generated reads address one key group at a
time. The batch read below is one statement over the instrument set.

*** read_by_instruments_batch
:PROPERTIES:
:ID: 64AE2796-F132-404C-AA06-9F0C8D335C9E
:END:

Reads every current rate of the given instruments' legs, ordered by
instrument, leg, role and sequence, in one statement. An empty input reads
nothing.

#+begin_src cpp :name implementation :implements F2EB1914-5E94-42CA-9C77-46BDB364BF9E
std::vector<domain::swap_leg_rate>
swap_leg_rate_repository::read_by_instruments_batch(
    context ctx, const std::vector<std::string>& trade_ids) {
    if (trade_ids.empty())
        return {};
    static const auto max(make_timestamp(MAX_TIMESTAMP, lg()));
    const auto tid = ctx.tenant_id().to_string();
    const auto query = sqlgen::read<std::vector<swap_leg_rate_entity>> |
                       where("tenant_id"_c == tid &&
                             "trade_id"_c.in(trade_ids) && "valid_to"_c == max.value()) |
                       order_by("trade_id"_c, "leg_number"_c, "rate_role"_c, "sequence_number"_c);
    return execute_read_query<swap_leg_rate_entity, domain::swap_leg_rate>(
        ctx,
        query,
        [](const auto& entities) { return swap_leg_rate_mapper::map(entities); },
        lg(),
        "Reading swap leg rates for multiple instruments.");
}
