This page is a [[id:671F18E4-E09C-4B3B-BD24-D33DF8AE38A6][capture]] in the *next* bucket of the product backlog — a pre-sprint idea, not yet pulled into a sprint as a story.

* What

Replace the native select in the shared web controls or drop the UDP rule. UI design principles says never use a native form element for styled UI, and the shared Select in ui/Primitives.tsx is a native select element that every classification, choice and record field of the record dialog draws. Found by the audit of the UX standards.

* Why

The audit of the UX standards compared the pages with each other and with
the shared code, and found this as work rather than as a rule to decide. It is
filed so the story Settle the UX language for record screens, or the pipeline,
picks it up with the audit's reasoning behind it.
