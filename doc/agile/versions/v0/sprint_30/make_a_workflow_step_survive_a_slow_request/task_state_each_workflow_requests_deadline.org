* Goal

Every request a provisioning step makes either takes the shared default deliberately or states its own deadline. A request whose work outlives the default states a longer one, with the reason in the code beside it, so a slow calibration no longer fails against a deadline set for a read.

* Acceptance

- The audit names every request a provisioning step makes, the work it does and the deadline it should state.
- A request whose work is a write or a fit states its own deadline, sized to a loaded p99 rather than a round number.
- A request that keeps the shared default says so deliberately, beside its call site.
- The stated exception is stated in one place, not repeated as a number at each call site.
