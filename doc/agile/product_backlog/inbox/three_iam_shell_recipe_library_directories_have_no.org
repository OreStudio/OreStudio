#+title: Three iam shell recipe library directories have no committed…
#+description: Three iam shell recipe library directories have no committed scripts on main.

doc/recipes/shell/seed_profiles, seed_profile_parameters and seed_profile_steps each carry a tracked recipe document, and projects/ores.shell/scripts/library/ carries none of the three directories at all. Tangling the recipes -- compass build --direct tangle_shell_scripts -- materialises them as untracked files, so the recipe and its runnable script are out of step in the tree: the /Commands/ sections of those recipes document scripts a caller does not have.

This is the same shape as the recipe drift that nothing gates, from the other side. The tangle writes the scripts, and nothing commits them, because the shell script drift workflow compares the tangled output against the tree in a way that did not fail on the three missing directories when main was last green.

Found while running the tangle for ores.dq, whose own library directories are committed. Recorded rather than fixed here because the recipes are ores.iams, and the fix is to commit the three directories after tangling, or to remove the recipe documents if the surfaces were retired.
