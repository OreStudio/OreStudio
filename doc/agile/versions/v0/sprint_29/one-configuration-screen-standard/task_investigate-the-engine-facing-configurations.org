* Notes

The record is [[id:146461B4-C00E-4FA7-A01D-DEFBC862BC73][Investigation: the two engine-facing configurations]].

The two-line answer: the pricing engine configuration chooses and configures
the valuation method for each product type, and the engine run settings decide
how the engine prepares the inputs and runs the job for every product at once.
The run document joins them: its =Setup= block is the engine run settings, and
it names the pricing engine document through =pricingEnginesFile=.
