* Result

A fresh system tenant holds the EURUSD_SSVI blueprint with 40 pillars and 40 pillar sources, for the system party. Every pillar source names the one fx_option series the derived source writes, and every pillar has a derived vendor instrument. The output series is an fx_vol_surface series that starts OBSERVED and that the calibration claims on its first run.

=refdata_fx_vol_surface_blueprint_seed_test.sql= proves the first four acceptance items on a recreated database.

The fifth acceptance item, stored derived quotes after the feed runs, was not run live, to avoid a full build and a service run. The test shows the feed publishes each pillar's quote, and the Calibrate task reads those quotes for real, so it fails there if they are absent.
