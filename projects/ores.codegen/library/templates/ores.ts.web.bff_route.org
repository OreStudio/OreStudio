One entity's BFF route descriptor, as a TypeScript data module: the
collection the route listens on, the path parameter that carries the
natural key, the wire field that key lives in, the array fields a batch
delete and a list response use, and the subjects the requests travel on.
The generic factory reads the descriptor and registers the five routes, so
an entity adds no handler of its own.

The module holds values and one value import. There is no function in it,
which is what makes it safe to generate: nothing here is behaviour that a
template would have to be taught to reproduce.

The subjects are not written here. They are imported from the entity's
own generated protocol module, which is rendered from the same model, so
the descriptor and the wire shape cannot disagree about a subject name.
The projection names the messages =org_loader.entity_protocol_messages=
derives -- the list request after the plural, the save, delete and history
requests after the singular -- by reading the enriched entity's derived
message list, so a rename in the derivation moves the descriptor with it.

The delete and history requests are keyed by the entity's primary key, and
the path segment is the natural key. The projection states those members
only when the primary key *is* the natural key: otherwise the factory
would send the natural key's value in a primary-key field, and the service
would match no row or fail to decode the message. The route is withheld
rather than registered, so a caller gets the not-found answer instead of a
success that changed nothing.

The optional members are gated on the presence of the subject, not on the
=has_get=/=has_remove=/=has_history= literal: pystache reads the string
=false= as truthy, so a section on the literal would emit the member it
means to omit. The literals are still projected for a consumer that wants
them. No domain entity derives a single-record get, so =get= is absent
today; a current-state entity derives no history pair, so =history= is
absent for it.

A junction is deliberately not served: its delete request names one array
per side, and the generic factory sends a single key, so a junction route
would silently drop half its key. The archetype admits =domain_entity=
only, and junction routes stay hand-written until the factory states the
pair.
