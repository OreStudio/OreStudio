* Acceptance

- The curve analytics asks for a currency first, and the curve picker lists that currency's curves only.
- The curve beside lists the same currency's curves by default, the curve the chosen one discounts off first.
- Other currencies are offered only behind an explicit choice, and only their funding curves, beside a funding curve.
- A cross-currency pair states what it shows, the rate differential, instead of the funding and projection lesson.

* Plan

Both pickers listed every curve of every currency in one flat list.

1. Give each curve option its currency, from its bootstrap config.
2. State the rules in one module, =curveChoice=: the currencies, a currency's
   curves with its funding curve first, the curves that may stand beside the
   chosen one, and the two pairs the screen explains.
3. Ask for a currency first, then a curve of it; offer the same currency's
   curves beside it, the one it discounts off first; offer other currencies'
   overnight curves only on request and only beside an overnight curve. An
   address that names any other pair draws one curve.
4. Explain a cross-currency pair with its own panel: the rate differential,
   forward points and carry.

is the same currency's, the curve it discounts off first. Another currency is
offered only on request and only beside an overnight curve, and only its
overnight curves; such a pair has its own panel, which says the gap is the rate
differential, the source of forward points and of carry. All four acceptance
