The roles an =iam.role_grant= approval request asks for, one row each. A row is
identified by the request and the role. When the request is approved, IAM
grants each role the account does not already hold, and records that it
applied it.

* Columns

** applied_at
:PROPERTIES:
:type:     timestamp with time zone
:cpp_type: std::optional<std::chrono::system_clock::time_point>
:nullable: true
:END:

When IAM applied the role after the request was approved, or null until it
has. Applying is done once: a role the account already held is marked applied
without a grant, and a role taken away after it was applied is not granted
again, because the request is still approved but no longer unapplied.
