* Goal

One command enumerates every subject the tree declares and fails on any that is not {component}.v1.{resource}.{verb} with a verb from the closed set of eight, so the rule is enforced instead of remembered.

* Acceptance

- A script enumerates every subject from the models and reports each one that is not {component}.v1.{resource}.{verb} or {component}.v1.{resource}_events.{action}, with a verb from the closed set of eight.
- It reads the models rather than the generated headers, so the defect is named at its source.
- Accepted exceptions live in one file beside their reason, and the file is the only place an exception may be recorded.
- The script is wired into the same place the other codegen checks run, and it fails the build on a new violation.
- Codegen suite test holds the gate against a model with a bad subject and against one with a good subject.
