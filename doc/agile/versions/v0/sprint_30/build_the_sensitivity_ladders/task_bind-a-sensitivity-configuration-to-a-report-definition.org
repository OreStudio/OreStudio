* Acceptance

- A report definition binds a configuration of type sensitivity, and the binding is readable by the pre-processing phase.
- The risk report configuration of a sensitivity report sets sensitivityConfigFile and marketConfigFile, and the seeds of every party that runs a sensitivity report set both.
- A run of a sensitivity report names the bound document in its generated ore.xml and the engine reads it.
- The gate that proves a report runs end to end still passes.
