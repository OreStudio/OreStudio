* Acceptance

- The kind iam.reporting_line is seeded with the named-decider rule, a required comment on refusal, and a deadline.
- A detail entity, generated from a model, holds request id, account, proposed manager and the previous manager, and is readable by the people it concerns.
- Every member holds the permission to propose, so the decide permission is not the gate for this kind.
