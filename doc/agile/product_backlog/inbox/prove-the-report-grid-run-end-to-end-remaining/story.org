* Acceptance

- The ACME definition triggers from the shell, the instance travels pending, running and completed through the FSM guard, and the compute results are retrieved.
- The run is reproducible from a freshly recreated database, and every report ACME is seeded with has the risk report configuration its run needs.
- The run's portfolio input is ORE-readable at the path the run document names, and the engine proceeds past Build Portfolio.
- A job whose engine reports an error and writes no analytics is recorded as a failed result, and a stored assignment whose result is gone is not replayed.
