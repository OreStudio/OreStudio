#+title: How do I run the rounding_types commands from the shell?
#+description: Every command the rounding_types submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:rounding_types:

This file documents the rounding_types resource at the shell, one section per command. Every command is a subcommand of =rounding_types=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: 24E5B595-5221-5C1F-8C56-AF71DA915C3F
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
rounding_types list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =refdata.v1.rounding_types.list=.

#+name: rounding_types-list
#+begin_src ores-shell :tangle rounding_types-list.ores :exports none
rounding_types list --limit 1
#+end_src

** =get=
:PROPERTIES:
:ID: D4BA1B1F-7410-5A0A-AC01-108416D64861
:END:

Reads the one row its key addresses. A key states every identifying column, so a partial key is refused rather than answered with an arbitrary row.


The command is shaped like this:

#+begin_example
rounding_types get <code>
#+end_example

It is addressed at =refdata.v1.rounding_types.get=.

#+name: rounding_types-get
#+begin_src ores-shell :tangle rounding_types-get.ores :exports none
rounding_types get __none__
#+end_src

** =add=
:PROPERTIES:
:ID: A0C39D48-3F8E-5FCE-9A61-85DFC4AD03C3
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.


The command is shaped like this:

#+begin_example
rounding_types add <code> <name> <description> <display_order> <reason> <commentary>
#+end_example

It is addressed at =refdata.v1.rounding_types.put=.

#+name: rounding_types-add
#+begin_src ores-shell :tangle rounding_types-add.ores :exports none
rounding_types add __none__ __none__ __none__ 0 system.new_record generated_script
#+end_src

** =set=
:PROPERTIES:
:ID: 048FB7E5-FCCC-5A0B-B79B-57391531A3A9
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved. Passing --version makes the write conditional on the version the caller last read.


The command is shaped like this:

#+begin_example
rounding_types set <code> <name> <description> <display_order> <reason> <commentary> [--version <n>]
#+end_example

It is addressed at =refdata.v1.rounding_types.put=.

#+name: rounding_types-set
#+begin_src ores-shell :tangle rounding_types-set.ores :exports none
rounding_types set __none__ __none__ __none__ 0 system.new_record generated_script
#+end_src
