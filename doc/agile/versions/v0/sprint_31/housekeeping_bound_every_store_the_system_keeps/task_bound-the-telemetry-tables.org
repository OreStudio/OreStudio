* Goal

A telemetry table has the same bound as every other store: a row in the catalogue, a policy the sweep applies on the installation's own licence, and a screen that states what it last removed.

* Acceptance

- The catalogue names every chunked telemetry table, with its time column, its measure and its default period
- The sweep drops the telemetry chunks past the period on the Apache licence, as it does for the report tables
- A test proves a chunk past the period is dropped and a chunk inside it is kept
- The housekeeping screens state the telemetry stores beside the rest, with their sizes
