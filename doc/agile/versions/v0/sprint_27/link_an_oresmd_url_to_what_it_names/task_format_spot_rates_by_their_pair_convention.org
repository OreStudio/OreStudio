* Goal

The series page shows a spot rate as the stored text trimmed to seven significant digits. The currency pair conventions already hold decimal_places for each pair: 2 for a JPY quote and 4 for the rest. The page reads the convention of the pair and formats the chart axis and the table with it. A series that is not an FX spot keeps its present format. The page keeps asking for the latest observations by count, as now.

* Acceptance

- The series page formats an FX spot series with the decimal_places of its pair's convention, in the chart axis and in the table.
- A pair with no convention, and a series that is not an FX spot, keep the present format.
- The convention is read through the refdata store and a failed read leaves the present format, with no error banner.
- A pure function formats a value for a number of places, and has tests for rounding and for places 2 and 4.

* Result

The series page shows an FX spot rate with the =decimal_places= of its pair's convention, read from the =currency-pair-conventions= resource through the refdata store, quietly. The chart axis and the table use it: AUD/USD shows four places and USD/JPY two. A pair with no convention, a failed read and a series that is not an FX spot rate keep the plain seven-digit format. The page still reads by count only. A time window was left out on purpose. Checked in headless Chrome against real data.
