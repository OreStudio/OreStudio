* Goal

Skills and recipes restate each other today. pr-merge the skill and the merge-a-PR recipe both carry the command. Under the architecture the recipe holds the command, tested and runnable by a human, and the skill holds the judgement: when to reach for it, what must hold first, what to do when the guard rails refuse. Sweep the execution function and enforce that split. Where a skill carries a command with no recipe behind it, write the recipe. This is also what makes the sequencing function work, because a method step that needs an effector reaches for a recipe rather than improvising a shell command inline, and the next method inherits it.
