* Decisions

- The library directory follows the server's own version number, not
  =pg_config=. A client installation can name a different major from the
  server serving the database, and following the client turned a database
  that records the installed extension into a false "no library on disk".
  =pg_config= survives only as the fallback for a host whose server cannot be
  asked.
- One pull request carries the scaffold and the fix. The story documents would
  otherwise need a scaffold PR of their own before the fix could land, and a
  two-line tooling fix does not earn that ceremony.
