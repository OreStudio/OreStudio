* Result

A run's book and counterparty levels can be stated against an earlier run of the
same report.

A *Compare to* control offers the report's completed runs and no comparison by
default. The chosen run sits in the address as =?baseline=, so a refresh keeps it
and a colleague can be sent the comparison. Each row then states the change and
the change as a share of the earlier figure, the totals line states the change
against the run, and a row only the earlier run had is kept and marked as gone
rather than dropped.

The comparison is refused when the run named is a run of another report, and it
is offered only at the aggregate levels: a trade is read on its own.

The two runs on record are =c2a86671= against =71d08bde=, on the NPV definition
of ACME Corporation HK Ltd. Both priced the same data, so the book states
=33,709,129.46= HKD either side of the comparison and a change of =0.00=: the
control is proven, not the arithmetic.
