* Goal

Every equity, FX and commodity script in ORE's library that has no element of its own is booked as a generic ScriptedTrade through the scripted builder, from a recipe stated as data, and ORE reads and builds it.

* Acceptance

- each such script has a recipe: a value rule per input, held as data, not as code per script
- the generated population holds one trade of each such script
- the ORE engine test reads and builds each, with no error of the trade kind
- a test fails when a library script is neither generated nor named as a script with an element of its own
