* Summary

A *fixing* is the value of a market rate observed at an agreed time from an
agreed source, on which a contract settles or decides. This structure note
gathers the notes on fixings: what a fixing is, where it comes from, which
products need it, how it is taken through a controlled process, how it is
stored and shown, and what it does to value and P&L. It ends with the data
model the notes imply and how far ORE Studio holds it.
