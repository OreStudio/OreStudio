ORE applies a shift to a market point in one of three ways, which its schema
fixes as the =shiftType= enumeration in =ore_types.xsd=: =Relative=,
=Absolute= and =EqualTo=. Stress and sensitivity scenarios both use it.

The shift type is a seeded lookup, seeded for the system tenant and read by
every tenant, so a shift that names a type ORE does not have is refused.
