* What

=service::process_factory::make_process= and =domain::validate_process_parameters= take the process type as a string, such as "geometric" or "ornstein_uhlenbeck", and an unknown value falls back to the geometric process. Quant should take its own enum, and the component that stores the process type should read its code into that enum, as reference data does for its conventions.

* Why

Quant holds its own types and knows no stored spelling, so its engines are tested alone and a bad code is refused where a row is read. A silent fallback turns a typo in a stored feed into a different process. Found while moving the stored codes out of quant in the task Keep quant free of stored codes.
