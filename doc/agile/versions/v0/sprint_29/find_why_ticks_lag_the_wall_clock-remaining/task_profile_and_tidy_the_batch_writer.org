* Goal

A batch of 1,205 ticks, about 12,000 rows, took 5.5 seconds, where step 0 gives about 8,300 rows per second inside the database. Find where the time goes: the row building, the string conversion of sqlgen insert, the shape check, the manual point check, or keep_last_per_key. Fix the largest cost.

* Acceptance

- A profile that names where the time of a batch goes.
- The client path costs less than twice the database for the same rows.
- The process function is split into plan, build rows, store and after-commit, and the series URI is computed once.
- The log of a failing source shows the first failure and counts the rest.
- Tests cover a batch of several ticks and tenants, the split of a failing batch, the cache clear on a failed row, and a queue overflow.
