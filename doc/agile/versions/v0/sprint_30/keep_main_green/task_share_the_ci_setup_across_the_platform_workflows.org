* Result

* Result

The census and the shape are recorded in the capture
[[id:B06E240E-D25A-4E31-B602-7259279F2B20][Share the CI setup across the
platform workflows]], which is in the backlog for a phase to pick up.

Four findings are worth carrying forward:

- 48% of the lines inside run blocks repeat another workflow's block, and the
  four build workflows are 58% of all the YAML in the repository.
- Ten steps of each build job are the same on every platform; what differs is a
  named, short list per operating system.
- The logic that is already shared — the test run, the split, the submit —
  lives in =CTest.cmake= and =build/scripts/expand_catch2_cases.py=, not in
  YAML, which is why today's splitting fix reached every leg at once.
- A composite action is the unit for a step group and a reusable workflow is the
  unit for a leg, because a leg is a job and a step group is not.

The phases, in order: =install-compass=, then the NATS, database and environment
composites, then =save-sccache=, then =build-leg.yml=, then the guard and the
package attachment.
