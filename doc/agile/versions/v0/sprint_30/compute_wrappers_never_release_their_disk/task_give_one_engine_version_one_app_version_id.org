* Goal

One engine version gets one app version ID. The ID is derived from the
engine's identity, for example a name-based UUID (version 5) of the app name
and the engine version, or a hash of the package archive. A wrapper then finds
its unpacked package after a database recreate and does not download it again.
The wrapper also removes the =.tar.gz= after it unpacks it.

* Acceptance

- Two database recreates seed the same app version ID for the same engine.
- After a recreate, a wrapper runs a job without a new package download.
- A changed engine gets a new ID, so a wrapper never runs a stale package.
- No =.tar.gz= stays in =packages/= after a package is unpacked.
- Decide what removes the copies that other IDs left behind. When the task
  starts, make this testable, for example: after the change, the number of
  package folders equals the number of distinct engine versions.
