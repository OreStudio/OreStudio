- Each route names its same-address C++ route in the inventory.

* Plan

Serve the tenancy screens' catalogues at the BFF's addresses in
=tenancy_catalogue_routes=: the tenant statuses and types, each painted with
the badge its code names, and the legal entities a tenant may start from. The
statuses keep the service's order and the types their display order, as the
BFF sorted them; a code no badge names is painted with none. The badges and
the legal entities are the dq service's, so =ores.http.iam= takes =ores.dq.api=.

The other 18 tenancy routes move to [[id:6B079A05-65D0-41B0-A725-8AD9DA84D5BE][Serve the remaining tenancy routes]].
