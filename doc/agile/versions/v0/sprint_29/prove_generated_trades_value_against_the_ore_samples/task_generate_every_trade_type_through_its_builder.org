* Acceptance

- Each family's planner draws its values and calls the builders; its =construct_*= functions and =*_terms= structs are deleted.
- Each family's entries leave the recorded trades' known lists, its recorded files change in the same commit, and the lists end empty or with a stated reason per entry.
- A tagged test runs the ORE engine on each recorded portfolio, with ORE's example configuration, and fails on an error ORE raises reading or building a trade, unless a known list asserted exactly names it; a Trade error caused by missing market data is counted apart. Moved here from [[id:63FF92C8-3E18-49BB-93FA-B0862B5FD4B2][Test that every generated trade builds in ORE]].
- A run of the Acme reports after provisioning records no Trade errors, only market data errors.
