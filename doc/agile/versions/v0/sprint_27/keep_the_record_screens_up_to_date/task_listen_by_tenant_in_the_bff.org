* Result

Built and tested (=change-events.test.ts=, 14 tests; wire-protocol 40).

- The transport hands the envelope's tenant and party to =subscribeToEvents=.
- The registry keeps one subscription per entity. =mayHear= decides, for each
  session, whether an event is its own tenant's or the system tenant's, and for a
  member whether it is a party they work in. An event with no tenant is told to
  nobody. An administrator hears every party of the tenant.
- The party list is read when an event arrives, so a switch of party counts.
- Assumption to check live: an administrator session (tenant or system mode) sees
  every party of its tenant. If row security limits an administrator by party,
  =everyParty= must follow it.
