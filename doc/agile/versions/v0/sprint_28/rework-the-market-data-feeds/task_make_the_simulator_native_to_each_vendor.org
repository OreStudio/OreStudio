* Goal

The simulator looks like the vendor to everything downstream: a Bloomberg generator sends Bloomberg ids, an LSEG generator sends RICs, and no name, subject or id says that the source is simulated or names ORE.

* Acceptance

- Each simulated source has a neutral name of the form provider-letter, such as bloomberg-a, and its kind shows only in the kind column and as a badge.
- A table turns a currency pair into the id of each provider (bbg_ticker with PX_LAST, ric with BID), and the generators publish those ids. Bloomberg is first and LSEG second.
- The source ore-simulated, the adapter id ore-simulated and the Acme step arguments that name it are gone. The Acme parties route to a Bloomberg source.
- The ore_samples_2016 dataset is removed and the uniform_demo dataset is kept with fixed levels.
- Rate curves are listed as not served until a vendor ticker per pillar is written down.
