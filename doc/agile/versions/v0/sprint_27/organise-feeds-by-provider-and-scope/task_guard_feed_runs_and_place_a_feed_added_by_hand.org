* Acceptance

- Every verb that starts or stops a feed checks synthetic::feeds:run, and the screen draws the buttons only for a person who holds it
- A client reads the message of an invalid argument and a fixed sentence for any other failure
- A feed added with no folder is placed under its collection, and the missing folders are made

* Plan

- A new permission, =synthetic::feeds:run=, in the IAM catalogue. Every verb that starts or stops a feed checks it with the read of the configs it touches: one feed, a folder, a selection. The one-feed stop checked nothing before. The wildcard =synthetic::*= and the admin roles cover it.
- =client_message= decides what a client reads about a failure: the message of an invalid argument, which is written for the caller, and a fixed sentence for anything else. The five older handlers and the simulate path use it, and the log keeps the cause.
- A trigger after the generated insert trigger places a feed that names no folder in the instrument type folder of its kind under its collection, and makes the folders that are missing. The publish function already named the same folders. The Add feed form starts with the collection the person is looking at.
