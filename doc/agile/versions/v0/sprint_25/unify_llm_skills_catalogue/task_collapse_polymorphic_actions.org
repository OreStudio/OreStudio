* Goal

The catalogue is an N-by-M table written out by hand. Seven add skills are one verb over seven artefact types; six show skills are one verb over six. Embark's lesson is that actions register against the type, not against a source command, so a verb that behaves uniformly becomes one skill plus a type table. Do this before the imports land, or we will port cells we are about to delete. The test is whether the procedure differs, not whether the artefact differs: agile-close-task earns its own skill because closing a task is genuinely its own procedure; doc-show and agile-show-sprint do not.

* Acceptance

- Every verb in the register is classified as uniform or type-specific, with the reason.
- Uniform verbs are collapsed into one polymorphic skill each, driven by a type table rather than by prose.
- The type table is generated from the document types rather than hand-maintained.
- Type-specific skills that survive state why their procedure differs.
- Retired skills go through skill-delete so incoming links are re-pointed and deployed copies purged.
- The catalogue count before and after is recorded.
