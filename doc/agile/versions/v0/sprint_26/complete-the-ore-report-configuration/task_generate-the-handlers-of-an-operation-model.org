* Acceptance

- An operation in an operation model names the service method it calls, the permission it checks and whether it requires a party, and codegen generates the handler that authorises, decodes, calls and replies.
- The registrar subscribing every operation is generated.
- The configuration document handlers in refdata, analytics and reporting, and the calendar materialisation handler, are generated and their hand-written copies deleted.

* Notes

Raised on 2026-10-05 by the operator during the review of PR #2639: the
configuration document operations generate their protocol from operation
models, but their handlers and registrars are hand-written, as every operation
handler is today, because the handler and registrar templates serve entity
models only. The PR went in as it was; this task removes the hand-written
handlers.
