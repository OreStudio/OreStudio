* Goal

A closed window ends its session. The grace period carries a reload, a network loss and a brief sleep. The sign-out is the one the Sign out button makes, so IAM records the end and the person shows as offline.

* Acceptance

- A session with no heartbeat for the grace period is ended through the same path as Sign out.
- A session that resumes its heartbeat inside the grace period is not touched.
- The browser session no longer lives eight hours past a closed window, and a reload keeps working.
- The end is recorded with its reason: window closed.
