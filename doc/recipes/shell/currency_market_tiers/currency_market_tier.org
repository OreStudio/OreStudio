#+title: How do I run the currency_market_tiers commands from the shell?
#+description: Every command the currency_market_tiers submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:currency_market_tiers:

This file documents the currency_market_tiers resource at the shell, one section per command. Every command is a subcommand of =currency_market_tiers=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: 8073A2FB-7643-5058-8918-9A076040521C
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
currency_market_tiers list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =refdata.v1.currency_market_tiers.list=.

#+name: currency_market_tiers-list
#+begin_src ores-shell :tangle currency_market_tiers-list.ores :exports none
currency_market_tiers list --limit 1
#+end_src

:ID: 2BCB242B-042D-50C8-A1CD-5036D7C630EA

#+end_src

** =add=
:PROPERTIES:
:ID: 1E538B73-B3B6-5533-AE2E-AEF3F83EBBA2
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.


The command is shaped like this:

#+begin_example
currency_market_tiers add <code> <name> <description> <display_order> <reason> <commentary>
#+end_example

It is addressed at =refdata.v1.currency_market_tiers.put=.

#+name: currency_market_tiers-add
#+begin_src ores-shell :tangle currency_market_tiers-add.ores :exports none
currency_market_tiers add __none__ __none__ __none__ 0 system.new_record generated_script
#+end_src

** =set=
:PROPERTIES:
:ID: F4328B0C-C6D0-512F-AD20-CAAA971CD7D3
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved. Passing --version makes the write conditional on the version the caller last read.


The command is shaped like this:

#+begin_example
currency_market_tiers set <code> <name> <description> <display_order> <reason> <commentary> [--version <n>]
#+end_example

It is addressed at =refdata.v1.currency_market_tiers.put=.

#+name: currency_market_tiers-set
#+begin_src ores-shell :tangle currency_market_tiers-set.ores :exports none

#+end_src
