** What

=ir_curve_bootstrap_pillar.start_tenor_code= and =end_tenor_code= are
undeclared soft references to =refdata_tenors=. The only database check
validates =curve_role_code=, so a typo in a tenor code saves and then throws at
bootstrap time inside =curve_republish_resolver=, where the end tenor doubles as
the quote point id.

** Why the shape check does not cover it

The import task made a curve's declared shape check its own term values against
=refdata_tenors=, but that check runs when a shape is declared, from the points a
build produced. It does not read the pillar a person saved. A typo in a pillar's
tenor code still saves and still throws later, so this is its own task.
