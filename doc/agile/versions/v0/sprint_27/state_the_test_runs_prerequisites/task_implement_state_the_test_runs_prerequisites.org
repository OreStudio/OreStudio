* Result

=compass test run= probes the broker's port before taking the build lock and
refuses with the fix when nothing listens. The probe is an =ss= listen check,
not a TCP connect: the server requires client certificates, so a plain
connect is refused before it can report the port. =--cdash= skips it, because
that form builds first.

The memory =check_the_test_environment_before_believing_a_failure= records all
three prerequisites, what each failure looks like, and the fix each one has:
the broker, a build that matches the database's schema fingerprint, and free
PostgreSQL connection slots.

Verified: the compass test folder passes (325 passed, 1 skipped), including
two new cases for the preflight, and the full suite is green at 9707 of 9707
tests in 92 suites with the fleet up.
