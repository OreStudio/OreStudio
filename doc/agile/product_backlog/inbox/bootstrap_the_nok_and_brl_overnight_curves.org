#+title: Bootstrap the NOK and BRL overnight curves
#+description: The curve bootstrap does not implement ACT/ACT.ISMA (NOK-NOWA) or BUS/252 (BRL-CDI), so neither currency has an overnight curve config, and the stored NOWA fixings are read by no curve.

This page is a [[id:671F18E4-E09C-4B3B-BD24-D33DF8AE38A6][capture]] in the *inbox* bucket of the product backlog — a pre-sprint idea, not yet pulled into a sprint as a story.

* What

Seed an overnight curve config for NOK and for BRL. The bootstrap engine must first implement the day count that each index convention states: ACT/ACT.ISMA for =NOK-NOWA= and BUS/252 for =BRL-CDI=.

* Why

The synthetic feed quotes both currencies, but the overnight curve configs skip them, because the bootstrap engine does not implement these two day counts. Norges Bank's NOWA is now stored as fixings in the system tenant, so its fixings wait only on the curve. BRL waits also on the terms of the CDI.
