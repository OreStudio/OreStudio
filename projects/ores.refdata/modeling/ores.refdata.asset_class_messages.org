The asset class catalogue protocol messages.

=asset_class_info= is a joined shape: the =asset_class_code= entity holds
the code, name and description, and the coding scheme lives beside it.
The rows are read by a hand-written repository, so the shape is a message
payload and not an entity -- there is no table that carries
=coding_scheme_code=.
