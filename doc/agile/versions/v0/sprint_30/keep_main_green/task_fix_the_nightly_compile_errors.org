* Plan

The nightly run 43163241266 (Linux), 43190100783 (macOS) and 43178285478
(Windows) on 2026-11-12 stopped at these errors:

1. gcc, =-Wsubobject-linkage=: the generated web record routes keep a
   =key_of= lambda in the =handle_delete= coroutine frame. The template now
   emits a =<unit>_key_of= function in the anonymous namespace; 16 route files
   are regenerated.
2. macOS: =step_workers::run= takes =std::move_only_function=, which Apple's
   libc++ does not have. =run= is now a template over the step.
3. MSVC C4459: in =calendar_screen_routes.cpp= the local =last= hides
   =std::chrono::last=. The locals are now =year_start= and =year_end=.
4. clang-cl: =std::getenv= is deprecated. =application.cpp= now reads the
   site environment through =ores::platform::environment=.

Each job stops at its first failing file, so more errors can follow. The new
=ORES_WARNINGS_AS_ERRORS= option sets =-Werror= and =/WX=. It is off on every
build until all platforms build clean of warnings; then it goes back on.
A CTest script can still set it with =warnings_as_errors=1=.

* Notes

Second round, 2026-11-12, from every failed run on main:

- Codegen drift: =ores.platform.lib= was added to the generated server
  =CMakeLists.txt= by hand; it now comes from the component model.
- Agent component and CPU evaluation: 157 of 305 backend contract sources had
  changed, many through the flat field list. The codec probe passed 23
  operations and 45 cases. The export change below touched ten of the
  sources again, so the evidence is recorded at the branch head
  =2629842861=.
- Unity batch measurement (run 43216466419): smaller batches and the
  non-unity build found two missing includes, in
  =dataset_dependency_json_io.cpp= and the =role_product_type= junction model.
  The duplicate =seed_person= in =curve_publish_fixture.hpp= was already
  inline on main. Batch 16 hit the workflow's 30 min step limit.
- Nightly Linux debug: the coverage link failed in the CI image, which has no
  =libclang_rt.profile=. =install_llvm.sh= now installs
  =libclang-rt-19-dev=, and image =...-320bbcb1308a= is published.
- Nightly Windows clang: =windows.h= defines =near= as an empty macro, which
  broke a test helper of that name.
- Nightly macOS: three suites fail because an exception thrown in one library
  is not caught as its type in another. The import macro was empty outside
  Windows, so each library held a hidden =type_info=, and libc++ compares
  them by address. The export template now imports with
  =BOOST_SYMBOL_VISIBLE=. Not yet run on macOS.
- CDash: the fork alexhock/OreStudio runs the scheduled workflows on three-day
  old code and submitted rows with 16 failed shell suites. The CTest scripts
  now submit only from =OreStudio/OreStudio=.
