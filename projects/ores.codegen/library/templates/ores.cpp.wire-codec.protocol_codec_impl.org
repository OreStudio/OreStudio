Defines the four functions of each =wire_traits= specialisation the protocol
header declares, one message at a time.

The shapes are stated beside the structs in the protocol header, so nothing here
repeats a member list: each definition is the object form of the message, and
the members' own carriers do the rest. A message that holds a domain type or
another message recurses into that type's codec, which is why the protocol
header carries the field lists rather than this unit, and why this unit includes
the entity's own domain codec: that is the header those field lists are
declared in. The envelope's own shapes come from the utility package, which
states them beside the structs the same way.

See the [[id:C4E8A91F-3B7D-4F2E-85A6-1D9C7E3B2F4A][Template variable reference]] for the complete list of available
variables and their semantics.
