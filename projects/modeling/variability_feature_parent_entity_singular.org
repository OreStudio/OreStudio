* Effect

Only meaningful with =has_explorer_api=. Names another entity as this one's parent; adds =openAddWithParent(boost::uuids::uuid parent<Pascal>Id)= and prefills that field when the add dialog opens nested under a parent explorer node.

* Structural consequence

Yes — adds a method to the controller; assumes a =parent_<entity>_id= uuid column already exists on the domain entity.
