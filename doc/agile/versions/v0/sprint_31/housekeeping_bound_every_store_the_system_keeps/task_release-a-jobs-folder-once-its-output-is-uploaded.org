* Goal

A compute node deletes a job's working folder as soon as its output and log are uploaded, so the node keeps only the folders of jobs that failed before upload.

* Acceptance

- The job folder is removed on the success path, after the output and the log have been uploaded
- A job that fails before its upload keeps its folder, which is then the only evidence of the failure
- The removal is recorded in the log, so a later reader can tell that it happened and why the folder is gone
- A measured run shows a node's job directory stops growing with the number of completed jobs
