* Summary

A curve, an FX forward set and an FX volatility surface are each derived from market quotes, and each becomes the set the system prices from in the same way. A compute writes a candidate. The maker raises a publish naming it. A second person decides, or a stated rule closes the request. The trader applies the approval, which publishes the set, supersedes the set it replaces and tells its readers. A published set is later withdrawn through a request of its own. A reader always takes the newest published set at or before its as-of.

This page orders the cluster. Read it top to bottom when changing how a derived object is published; read one page when changing one step. Every page states the target, in the present tense.
