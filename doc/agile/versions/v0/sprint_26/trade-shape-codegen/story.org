* Acceptance

- An entity can be declared immutable (non-temporal), and other entities reference it with real foreign keys.
- A model can pin a copied fact with a composite foreign key to its source.
- Check lists of trade-type codes and the trade-type to table routing are generated from one catalogue.
- Key and context field groups nest, and every generated struct stays within nine effective fields.
- The derived authorisation status and the blotter's common-date view are generated.
