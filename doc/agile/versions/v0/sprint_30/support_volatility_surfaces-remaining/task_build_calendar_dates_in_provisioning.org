* Goal

A freshly provisioned tenant has correct business days. Provisioning loads the holiday rules of every published calendar and builds its dates, so no one has to run Rebuild and a value date never falls on a holiday.

* Acceptance

- Provisioning Acme on a fresh database leaves TARGET, UnitedStates.Settlement and Japan built with their holidays.
- 2026-12-25 reads as closed in TARGET and UnitedStates.Settlement, and the unit tests compare each calendar with QuantLib for at least one year.
- EUR/USD on 2026-11-09 has a spot date of 2026-11-12, because 2026-11-11 is a US holiday.
- A second provisioning run writes no duplicate dates.
