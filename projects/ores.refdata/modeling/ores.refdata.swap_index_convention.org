A named swap index, which ORE describes by pointing at the swap convention it
follows rather than by restating that convention's fields. Corresponds to the
<SwapIndex> element in ORE conventions.xml. The id field is the natural key
(ORE <Id> element).

** conventions
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:END:

The =swap_convention= this index follows, by its id. ORE names a convention here
rather than repeating its fields, so an index is a reference and not a copy.

#+begin_src cpp :name generator
std::string("EUR-6M-SWAP-CONVENTIONS")
#+end_src

:PROPERTIES:
:type:     text
:cpp_type: std::optional<std::string>
:nullable: true

Calendar the index's fixings are read on (e.g. 'TARGET'). ORE leaves it out when
the index fixes on the convention's own calendar.

#+end_src

** oresmd_uri
:PROPERTIES:
:type:     text
:cpp_type: std::optional<std::string>
:nullable: true
:END:

The oresmd URI of the index this convention defines: the named swap index
itself, as a fixing URI in the swap family. Classification: fixing — the
convention defines the index; =conventions= points at the swap convention
it follows and is not market data.

The column holds the address as a value, so refdata depends on the oresmd
format as a contract only and never on the marketdata library or its tables.
Nullable, because no convention is required to state its address yet.

std::nullopt
#+end_src
