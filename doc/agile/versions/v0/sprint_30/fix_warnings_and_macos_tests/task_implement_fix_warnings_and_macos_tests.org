* Result

The two macOS failures have one cause: the exception a test catches is thrown
in the library, and the library hides its symbols, so libc++ cannot match the
catch. Exporting =repository_exception= and the two domain exceptions fixes it.
The same defect would hit a service that catches =db_connection_exception=, so
that fix covers both.

Three warnings are gone and each was checked by recompiling the file with
=-Werror=. Two more warning families remain and need a GCC 13 or an MSVC build
to work on; the story records them as out of scope rather than guessing.
