One row per constituent of an equity worst-of basket, keyed to the trade
and the constituent's ordinal within the document.

The basket is a list. A list is rows of a child table rather than an
encoded string, so the constituents live here and not in the
=basket_json= column that used to hold them. The column is retired with
this table.

The ORE document states the basket as an unbounded list of =Underlying=
elements carrying a =Name=, and the list order is the document's order.
The ordinal is what identifies a row and preserves that order, so a
round trip re-emits the constituents as the document held them.

The trade is the key. A constituent is reached through the trade that
owns it and by nothing else, so the pair of =trade_id= and
=sequence_number= is the primary key.

The activity that wrote this version.

** sequence_number
:PROPERTIES:
:type:        integer
:cpp_type:    int
:primary_key: true
:END:

Ordinal of this constituent within the document's list, counting from one.

The schema declares the list unbounded and a document's order is the order
it stated, so the ordinal is what identifies a row and preserves that
order.

** underlying_name
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:END:

Name of the equity underlying this constituent names.

The ORE document states it in the =Underlying/Name= element; the column
refuses an empty name.

** weight
:PROPERTIES:
:type:           double precision
:cpp_type:       std::optional<double>
:nullable:       true
:END:

The member's weight in the basket, when the document states one.

A weight is a continuous quantity and not money, so it is a binary float, as
the position underlying's weight is. The column is nullable because a basket
that names its members without weighting them is a valid basket, and an
absent weight must stay null rather than become a zero the document never
wrote.

** initial_price
:PROPERTIES:
:type:           double precision
:cpp_type:       std::optional<double>
:nullable:       true
:END:

The price the constituent opened at, when the document states one.

ORE states =InitialPrices= as a list that runs beside the basket, one entry per
underlying, so the price is a fact about the constituent and not about the
trade. It was held as JSON text on the facts until the basket became rows.

A price is a continuous quantity, so it is a binary float as the weight is.
