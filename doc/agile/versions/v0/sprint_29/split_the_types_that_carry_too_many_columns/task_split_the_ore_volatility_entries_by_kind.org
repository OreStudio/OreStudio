* Goal

Each of the five volatility entries holds one kind of entry, and the block that only exists for one kind is a type of its own. Cap floor and swaption share one proxy part, so the same split is made once and used twice.

* Acceptance

- Every one of the five types ends with at most one block per entry, and no column is meaningful only for a value another column selects.
- The proxy block is one part type that cap floor and swaption both carry, not two copies.
- The ORE export and import of a volatility entry writes one typed array per part, and the bytes the reader sees stay what the ORE file states.
- No compiler flag, unity exclusion or field-group reshuffle is added.
