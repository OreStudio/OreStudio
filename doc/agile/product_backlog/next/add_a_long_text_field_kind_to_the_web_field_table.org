* What

Add a long text field kind to the web field table. The record screen standard says long text is a text area, but the FieldSpec kinds have no long text kind, so only the commentary is a text area and no field table can ask for one. Party contact and calendar rule fields need it. Found by the audit of the UX standards.

* Why

The audit of the UX standards compared the pages with each other and with
the shared code, and found this as work rather than as a rule to decide. It is
filed so the story Settle the UX language for record screens, or the pipeline,
picks it up with the audit's reasoning behind it.
