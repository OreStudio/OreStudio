#+title: How do I preview entity codegen changes as a diff?
#+description: Run ./compass.sh diff --scope on the entity model to see, as a unified diff, what generate would change; nothing is written.
#+type: recipe
#+level: cross
#+filetags: :codegen:compass:entity:diff:recipe:
#+created: 2026-06-26
#+updated: 2026-11-22

Useful when a template has changed and you want to audit the impact on a
specific entity before committing any regenerated files. See
[[id:08FBD248-257A-A474-DD43-DB08949978F1][ores.codegen]] for background on the physical-space graph and templates.

* Question

How do I see what would change if I regenerated an entity without writing
to disk?

* Answer

Run =diff= scoped to the entity's model:

#+begin_src sh
./compass.sh diff --scope projects/ores.refdata/modeling/ores.refdata.country.org
#+end_src

It prints a unified diff of every output the model feeds that =generate= would
change, and writes nothing. It exits 0 when nothing would change and 1 when
something would. =--scope= also takes a template, to audit what a template
change does to the tree:

#+begin_src sh
./compass.sh diff --scope projects/ores.codegen/library/templates/sql_schema_domain_entity_create.mustache
#+end_src

=--files= lists every changed file in place of counts by codec and template,
and =--skip-stale= leaves out the files already stale at =HEAD=, so the diff
is your change's own.

* Script

=./compass.sh generate= and =./compass.sh diff= forward to compass-ng through
=cmd_compass_ng= in [[proj:projects/ores.compass/src/compass.py][=compass.py=]]; its =codegen= codec renders the templates
of [[proj:projects/ores.codegen/library/templates][=projects/ores.codegen/library/templates=]].

* Tested by

Change one property of a model, run the scoped =diff=, and verify that it
shows the change in that model's outputs only.
