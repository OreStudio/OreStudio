* Decisions

* Out of scope

- Plots on the tenant dashboard. The tenant side keeps no history on the server.
- A permission only the operator holds. Tenants and the installation cards stay drawn by session mode until the server has one.
- Translated strings for the Rescue access screen.

* Result

The tenant administrator's home has the system home's shape: a header with one status, three tabs, and a dashboard of panels that say what needs the person in the same words. The dashboard refreshes every 15 seconds and colours its figures.

Every person gets the same menu. An area is drawn when the person holds a read one of its screens needs, and a card is drawn when the person holds the read of its screen. The knowledge page menu_structure defines the rule, and the UX structure note ux_hub lists the UX pages. Operations is drawn for everyone, with Sign-ins, Roles and Rescue access under their areas and a breadcrumb on each screen.
