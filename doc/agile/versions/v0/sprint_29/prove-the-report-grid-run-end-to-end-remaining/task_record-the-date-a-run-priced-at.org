* Result

A run says which date it priced at, and why it moved.

The report instance gained =priced_at= and =price_note=, both nullable, with
their SQL, repository, domain and TypeScript regenerated. A =record_run_pricing=
operation carries the two from the package handler to the reporting service,
which writes them on the instance. The package handler sends it with the run's
own token, so the write is the run's and row-level security scopes it, and it
does not touch the database itself. A moved date says the run asked for one date
and the gathered data ends at the other. A date that did not move says nothing.
The page shows one line on the Run tab when the date is there.

Proven on instance =c09ebaf1=: =priced_at= 2026-05-05 and =price_note= "The run
asked for 2026-10-23 and the gathered market data ends at 2026-05-05, so the run
priced at the data's date.", read back both from SQL and from
=report_instances get=. The run completed, because it was a package run, whose
last step is packaging.

The reporting and shell suites pass, the web typecheck is clean, and the new
service and page tests cover the write and the line.
