A person opens ores.web, names a curve or a surface, and watches it evolve as an aligned matrix of instants by nodes, with each node's change, staleness and provenance.

* Acceptance

- The BFF exposes the identity, snapshot, slice and evolution reads, each behind the permission the server checks.
- A person reaches the evolution screen from the market data area and reads the aligned matrix for a named object.
- The screen shows each node's status, the age of each value and, on request, where each value came from.
- A hole is shown as a hole and a refused request is shown as a reason.
