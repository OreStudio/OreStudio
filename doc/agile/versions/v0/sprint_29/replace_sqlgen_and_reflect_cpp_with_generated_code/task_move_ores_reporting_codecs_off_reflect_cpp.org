* Plan

- Opt the 47 reporting models into the wire codec and regenerate.
- Move the hand-written sites with a codemod: =rfl::json::read= to
  =json::try_read=, =rfl::json::write= to =json::write=, and the reflect-cpp

  message through a try/catch.
- Give the hand-written trigger payload, engine settings request and report
  definition template wire fields.
- Move the reads that ore and compute left waiting on reporting's codec.
- Prove every domain type, every operation message and the template against
  reflect-cpp.
