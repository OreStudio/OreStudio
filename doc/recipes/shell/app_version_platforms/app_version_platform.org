#+title: How do I run the app_version_platforms commands from the shell?
#+description: Every command the app_version_platforms submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:app_version_platforms:

This file documents the app_version_platforms resource at the shell, one section per command. Every command is a subcommand of =app_version_platforms=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: A39BC507-0E03-531B-AD67-39CB3484FAE6
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
app_version_platforms list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =compute.v1.app_version_platforms.list=.

#+name: app_version_platforms-list
#+begin_src ores-shell :tangle app_version_platforms-list.ores :exports none
app_version_platforms list --limit 1
#+end_src

** =add=
:PROPERTIES:
:ID: A19AAFA7-F89E-56E2-8095-041EF458DB45
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.


The command is shaped like this:

#+begin_example
app_version_platforms add <app_version_id> <platform_id> <package_uri> <sha256> <reason> <commentary>
#+end_example

** =set=
:PROPERTIES:
:ID: D9F6402D-67B2-5056-94D6-7B7AE593AA34
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved. Passing --version makes the write conditional on the version the caller last read.
