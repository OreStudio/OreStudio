#+brief: Propose and preview changes to books.
#+filetags: :model:operation:refdata:
#+created: 2026-10-10
#+updated: 2026-10-10

The operations a person takes to propose a change to a book instead of writing
it. A line is a pending book change: the book's own columns, the operation (put
or delete) and the version the person read. The preview runs the real write for
each line in a transaction it never commits and answers each line's refusal and
the parts the policy names. The raise previews, then holds the lines in an
approval request.

The handler is hand-written beside this model, because each operation applies
the rules of the four-eyes framework.
