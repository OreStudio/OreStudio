* Acceptance

- compass build prints the start time after the parallel jobs line
- compass build prints the finish time, the outcome and the elapsed time when the build ends
- Both lines are in the build log

* Decisions

- Stamp the cmake path only. It is the output a person reads to see when a
  build ran; the =--direct= emacs path is short and has its own log.
- Write the finish line in =finally=, so a failed or interrupted build also
  states when it ended.

* Out of scope

- Stamps on the =--direct= emacs path.
