This page is a [[id:671F18E4-E09C-4B3B-BD24-D33DF8AE38A6][capture]] in the *inbox* bucket of the product backlog — a pre-sprint idea, not yet pulled into a sprint as a story.

* What

The seeded roles give =TenantAdmin= every permission and give =Operations= read, write and delete on currencies and the currency junctions only. Operations holds no read on countries, calendars, currency groups, rounding types, monetary natures or market tiers, so it can change a currency but cannot see the values the currency screen must pick from. No role maintains calendars, classification lists, currency pairs or desk groups. Decide whether to widen Operations or to add a reference data role.

* Why

The reference data screens hide their actions from anyone without the write permissions, so today only a tenant administrator can maintain reference data.
