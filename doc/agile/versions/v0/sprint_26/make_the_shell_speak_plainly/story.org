* Decisions

- *The words come from the person, not the design.* No screen says journey,
  and no screen asks anyone to enter or leave a tenant. A tenant opens like
  any record.
- *A tenant is read inside it for one read.* The BFF enters the tenant, reads
  and leaves for each tab read; the tenant token never reaches the browser's
  session. The session's own tenant, the system tenant for a system
  administrator, is read as the session.
- *Images ride the page's visit.* A page reads the pictures and flags it names
  in the same visit and the BFF keeps them, so a page costs one entry.
- *The system tenant is shown but never removed.* The roster lists it; the
  web does not offer its removal and the table's check refuses it.
- *Removal is the generic delete.* It closes the row and keeps the data; sign-in
  and token refresh then refuse the tenant, so access ends within one access
  lifetime.
