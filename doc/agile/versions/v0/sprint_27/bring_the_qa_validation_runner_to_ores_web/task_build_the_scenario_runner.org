* Goal

A tester works through a scenario one step at a time, marks each step, writes notes and saves. A finished scenario reopens to be read, and a retest starts it again.

* Acceptance

- The runner shows the scenario header, a progress bar, the current step with its instructions, Pass, Fail and Clear, and a note.
- A Pass moves to the next step and a Fail stays on it. Marking steps never closes the scenario.
- Save writes the run through the BFF. It closes the scenario only when no step is pending.
- A done scenario opens read-only, and Retest asks for confirmation before it clears the steps.
- A multi-client scenario shows each step's client.
- Screen tests cover the Fail-then-note flow, the last Pass, a partial save, a closed scenario and a retest.
