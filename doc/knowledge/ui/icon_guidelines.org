ORE Studio's icon catalogue lives here as a single visual-language
reference. Pick an icon by its semantic category, then match the
variant (Regular for default / Filled for active) to the UI state.
UI skills drive icon selection from this catalogue; for the broader
UI design context see [[id:6743F6E3-578C-4E4B-9DD6-D5A0DF6734C8][UI design principles]]. Return to [[id:7474935C-95D1-3034-B833-83DCD9FB3A09][Knowledge]].

*The live icon assets are 68 SVG files in
=projects/ores.web/packages/web/src/assets/icons/=. Every icon link below
resolves in this tree. The file name is =ic_fluent_{concept}_{size}_regular.svg=;
the set carries the Regular variant only. An entry whose file is absent says
=None in the asset set=.*

* Icon System Overview

ORE Studio uses *Microsoft Fluent UI System Icons*. All icons follow the naming
convention:

#+begin_example
ic_fluent_{concept}_{size}_{variant}.svg
#+end_example

** Variants

- *Regular*: Outline style, used for default/passive states and secondary
  actions.
- *Filled*: Solid style, used for active states, emphasis, and primary actions.

** Sizes

- *16px*: Compact UI, inline with text, dense tables.
- *20px*: Standard UI elements, buttons, navigation.
- *32px*: Headers, emphasis areas.
- *48px*: Large feature icons, onboarding, empty states.

** Usage Principles

1. *Consistency*: Use the same icon for the same concept throughout the app.
2. *Clarity over decoration*: If removing an icon loses no meaning, remove it.
3. *Paired variants*: Use regular for default, filled for hover/active/selected.
4. *Adequate spacing*: Give icons room to breathe, minimum 4px from text.

* Adding New Icons

When adding a new icon to ORE Studio, follow these steps. The artwork lives in
=projects/ores.web/packages/web/src/assets/icons/=, and the live set carries the
regular variant. Steps 3 to 6 name files and functions of the former Qt client,
which is not in the tree.

** Step 1: Locate Icons in Source Repositories

ORE Studio uses one icon set:

- *Fluent UI System Icons*: ~/Development/fluentui-system-icons-main/assets/

Search for a semantically appropriate icon. The live set carries the regular
variant. Only =clock= is 16px and only =password_reset= is 48px; every other
file is 20px.

Example search:
#+begin_example
find ~/Development/fluentui-system-icons-main/assets -name "*upload*20*regular*"
#+end_example

** Step 2: Copy Icons to Project

Copy the icon into the live asset directory:

#+begin_example
cp ".../Arrow Upload/SVG/ic_fluent_arrow_upload_20_regular.svg" \
   projects/ores.web/packages/web/src/assets/icons/
#+end_example

** Step 3: Update Resource File

There is no resource file. The Qt resource file that used to list the icons went
with the ores.qt tree, and the web set is a flat directory of SVG files. The
file itself is the registration.

** Step 4: Add Enum Entry

Add the new icon to the =Icon= enum in =IconUtils.hpp=:

#+begin_src cpp
enum class Icon {
    // ... existing entries (alphabetically sorted)
    PlugDisconnected,
    Publish,       // <- New entry
    Question,
    // ...
};
#+end_src

** Step 5: Add Icon Mapping

Add the mapping in =IconUtils.cpp= in the =getIconDef()= function:

#+begin_src cpp
case Icon::Publish: return {"ic_fluent_arrow_upload_20", "upload-square.svg"};
#+end_src

The mapping format is:
- First string: Fluent UI icon base name (without =_regular.svg= / =_filled.svg=)
- Second string: Solar icon filename
- Optional third parameter: =true= to force filled/bold variant

** Step 6: Use the Icon

Use the new icon in code:

#+begin_src cpp
action->setIcon(IconUtils::createRecoloredIcon(
    Icon::Publish, IconUtils::DefaultIconColor));
#+end_src

** Step 7: Document the Icon

Update this skill document:
1. Add the icon to the appropriate category in the Icon Inventory section
2. Add an entry to the Quick Reference Table
