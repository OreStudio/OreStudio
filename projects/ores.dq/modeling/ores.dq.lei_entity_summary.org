#+brief: Summarises active LEI entities by country, one row per legal entity.
#+filetags: :model:operation:dq:
#+created: 2026-09-27
#+updated: 2026-09-27

The summary read the shell's =lei= menu asks for: the root legal entities of a
country, one row each, with the fields a person recognises them by.

It is an operation rather than an entity verb. The row is a projection over
=lei_entity= that deduplicates on the LEI and drops every entity another entity
consolidates, which is a query shape and not a page over a table, and it returns
a summary record rather than the entity.

No handler is generated for an operation, so the handler that serves these
subjects is hand-written beside this model:
=core/include/ores.dq.core/messaging/lei_entity_summary_handler.hpp=, wired in
=core/src/messaging/registrar.cpp=. The SQL functions it calls keep the
deduplication and the consolidation filter in the database:
=ores_dq_lei_entities_distinct_countries_fn= and
=ores_dq_lei_entities_summary_by_country_fn= answer the shell's country browser,
and =ores_dq_lei_entities_search_fn= matches a name or an LEI for the search a
starting point opens on, stating how many parties importing the match's
hierarchy would create.
