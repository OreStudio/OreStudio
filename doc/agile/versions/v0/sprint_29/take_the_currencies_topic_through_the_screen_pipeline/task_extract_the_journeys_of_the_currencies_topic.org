The three journeys of the currencies topic are judged on their pages. Add or
correct a currency is a CRUD variation of the standard record screen with
three link tabs; its ORE export is the one own action and waits on the server,
and the Qt import of one file is proposed dropped for the ORE import area. Set

derived key, drawn today by a dialog of the screen's own against RS-WRITE-31,

CRUD variation with a members link panel. No step keeps state across a reply,
so no workflow is needed. Nine gaps link to their captures; one is done since
the journey was written. The owner signed off the judgement on 2026-10-25 and
turned the two decisions into one standard: every kind with an ORE document

three operations per document, recorded as the Import and Export section of
the record screen standard; currencies build the first pair.
