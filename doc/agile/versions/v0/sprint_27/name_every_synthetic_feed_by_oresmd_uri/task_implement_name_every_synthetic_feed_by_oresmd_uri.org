* Goal

A synthetic FX spot feed states the series it produces as an oresmd URI, the same reference the market data store, the feed bindings and the screens use. Today it states an ORE key (ore_key, such as FX/RATE/EUR/USD), so a reader has to translate between two names for one series.

* Result

A synthetic feed names the series it publishes. The FX spot feed holds its quote URI in place of the ORE key. A feed reports series_uris(), and two feeds conflict when their series overlap. The IR curve feed builds its pillar series from the currency, the pillar start and the index tenor, and the bootstrap config states the same index tenor. The market data URI page now says that a curve is a series.

Checked on a recreated database after the merge with main: synthetic api (55 cases), core (42) and service (56); shell synthetic (170); marketdata core (196). All pass.

Follow-up: the republish subject still uses the ORE key. The task Name the republish subject by the oresmd URI tracks it.
