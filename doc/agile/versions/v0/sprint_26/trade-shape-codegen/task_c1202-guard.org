count its top-level members, to size the set of exceptions.

* Result

Abandoned before any code was written. The nine-member rule it set out to
enforce does not hold:

- 220 of the 287 reflected structs the models generate have more than
  nine members, up to 59, and the Windows build compiles them.
- The C1202 that fails main today is in =instrument_payload.cpp=, on
  =bond_instrument_data=, a hand-written carrier. reflect-cpp writes it as
  a tagged variant alternative and builds one literal over every field
  name reachable from it.

A cap on generated structs would need 220 recorded exceptions and would
still not see the failing type. Instead:

- The decomposition section of Data-Oriented Design now states what the
  limit counts, with these measurements.
- The field group doc template no longer cites the nine-member figure.
- Section 16 of the trade shape investigation carries a dated note that
  supersedes it.
- The story's acceptance line now asks for the measured rule, not the
  guard.
- [[id:7878D057-5504-4117-98DF-6CEA9BB5D6B9][MSVC fails C1202 on the bond export carrier]] files the Windows
  break, which no sprint-26 story owned.
