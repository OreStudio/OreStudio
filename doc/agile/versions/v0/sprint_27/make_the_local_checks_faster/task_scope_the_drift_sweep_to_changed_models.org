* Goal

=drift-sweep= renders only the components whose models this branch changed,
and keeps the whole-catalogue render for a change that can reach every
component.

* Acceptance

- A branch that changed one component's models renders only that component.
- A branch that changed the generator or a template renders every catalogue component.

* Plan

The sweep judges the files the branch touched, and a touched generated file
is produced by the component whose models it came from, so the modeling
directory is the right key -- the same rule =component-drift= uses. Reuse
=_touched_components= with the catalogue list rather than the registry,
because the sweep exists for the components the registry does not cover, and
keep the fallback: the generator, its templates and the registry decide
every component's output, and a diff with no model in it cannot attribute a
stray generated file to a component.

* Measurements

Every number this task claims about a tree, with the command that produced it
