* Notes

- Rescue access stays in Organisation. It unlocks one person's account, which is a write on an account. Sign-ins only reads sessions, and it is the audit of how the installation is used. Both the code and the page already agreed, so no screen or card moves. This is a decision I made from the two screens; if you want it in Operations, it is a change of one table row and one card list.
- Market data is its own area, and the point was out of date. The page said it had no web screens. It has two, FX price feeds and Watch a curve evolve, and the menu already draws the area. The page now says why: the data changes by the minute, and a person who looks for a curve does not look in reference data.
- The Trades point was never a decision. It states what is not built. It is now a section called Not built yet.
