* Result

Wrote =doc/knowledge/domain/book_types_and_their_controls.org=. It separates the
official book (maps to the ledger, created by Finance through the multi-party
process) from the virtual book (a trader creates it in a sandbox, no approval),
records what the existing notes establish, and records the decisions on seven
acts they left open. It shows which parts Acme has accounts for and files
"Add the missing book-control actors to Acme".

The decisions: a change to a live book is decided by the function that owns the
field; a move, a rights grant and a new official portfolio are decided by
Operations; a special-purpose book adds no approver; the screen's new book is the
desk's request that starts the opening process; sandboxes are not gated.
