* Decisions

- CDash dynamic analysis flags the NATS C library's one-time global
  init (=nats_openLib=) blocks as still reachable because CTest.cmake
  passes =--show-reachable=yes=. The blocks are not leaks: the library
  keeps them for the process lifetime and frees them only in
  =nats_library_cleanup()=, which the client layer must not call
  (global teardown is unsafe while other subsystems may still use
  NATS).
- Treatment: narrow suppressions anchored on the library init, not
  code changes; no RAII primitive for the library-global init —
  connection-level RAII already exists in =client::disconnect()=.
