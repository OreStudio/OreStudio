* Acceptance

- A branch that changed one component's models regenerates only that component.
- A branch that changed the generator or a template still regenerates every component.

* Plan

A component's models are its source of truth, so select on its modeling
directory in the branch diff. Widening is the safety valve: the generator,
its templates and the registry decide every component's output, so a change
under =projects/ores.codegen/= renders them all; a diff with no model in it
renders them all too, because a stray generated file cannot be attributed to
a component and a wrong guess would hide the drift the check exists to find.
The in-place regeneration and whole-tree diff are unchanged once the set is
chosen.

* Result

The check regenerates the components the branch's models belong to, and
falls back to the whole registry for a codegen, template or modelless
change. The gate runs it with =--base {base}=; the in-place regeneration and
whole-tree diff are unchanged.
