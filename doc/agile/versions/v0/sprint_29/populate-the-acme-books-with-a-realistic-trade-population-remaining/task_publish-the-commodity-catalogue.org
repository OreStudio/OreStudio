* Result

The commodity catalogue publishes during provisioning, and a provisioning run
over the ACME tenant now leaves six commodities in the catalogue it books in.
The equity catalogue publishes beside it, eleven underlyings, which is the
check that the mechanism is the same one.

Two registrations were missing, and only two: the publish operation itself
already existed, because the commodity catalogue was written when publish
operations were hand written, and what it never had was the artefact type that
names the function and the bundle membership that makes the profile reach it.

| Registration | Before | After |
|--------------+--------+-------|
| publish operation | present | present |
| artefact type | absent | =commodities= |
| bundle membership | absent | =base= |

The lesson from the equity family held: a seeded catalogue is not a published
catalogue, and the three registrations are what publish it. It is worth saying
that this gap existed while the commodity population task was recorded as done,
because that task was proved in code and never through a provisioning run. The
proof that matters is the run.
