* Result

=auth_event= is generated from =ores.iam.auth_event.org=, a hypertable entity in the same shape as the compute samples.

- The table, entity, mapper, domain type and repository come from the model. The schema is the one the hand-written script made: the same columns, the same two indexes and the same retention.
- The hourly and daily aggregates, with their retention, are an SQL paste block in the model, and their drop is a second paste block, so the generated drop script removes them before the table.
- The recorders and the filtered read stay hand-written, renamed =auth_event_log=, because the generated reads do not express them. The recorder writes through the generated repository.
- The table still carries no row-level security. That finding is in its own capture.
