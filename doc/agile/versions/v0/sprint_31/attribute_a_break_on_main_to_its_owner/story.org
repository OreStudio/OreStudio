* Acceptance

- A skill states the procedure and the report shape, and a recipe holds the
  commands that attribute the break and prove it.
- The owner is an environment, read from the commit's trailers and the fleet,
  and the disposition says whether to fix inline or hand it back.
- A session that reads the skill reports the same four parts in the same order
  whoever writes it.

* Decisions

The report's owner is an environment rather than a person. The environment
holds the branch, the task and the session that made the change, so it is the
one thing that can act on the report; the person and the agent are named beside
it because a reader wants to know who to talk to.

=blame= is not a verb of the naming register, and it is also the checker's own
command, which the conventions forbid naming a skill after. The skill is
=compass-code-investigate-trunk-break= and the word survives only in the recipe
title, which names the question rather than the skill.
