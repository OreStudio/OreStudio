#+description: The CMake archetype emits a Qt-era comment into every component's source list. Template projects/ores.codegen/library/templates/ores.cmake.component.files_src.org line 54 writes '# Headers must be listed for AUTOMOC to find Q_OBJECT declarations.' above set(HEADERS ...). AUTOMOC is never enabled anywhere in ORE Studio's own build and the Qt client is gone, so the comment is a Qt remnant in a shared template and ~85 checked-in component_files.cmake files carry it. Commit 86306c9494 introduced it with the archetype. Removing it is a one-line edit to the org template plus a re-tangle with 'compass build --direct tangle_codegen_templates', but it makes every regenerated component_files.cmake stale again, so it must be sequenced against the repo-wide generated-marker sweep. Found while working the Clean ores.fpml story; it belongs to the Remove the legacy Qt remnants story.
