#+title: Stop the test suites writing into the developer database
#+description: ORES_TEST_DB_DATABASE carries the same name as ORES_DB_DATABASE, so every ctest run writes its fixtures into the developer's own environment database. A gate run replaced the provisioned ACME data: the report instances the proof recorded disappeared, the live tenants went from one to 52, and the definitions the run used were gone. Tests need their own database name, created and dropped with the run.
