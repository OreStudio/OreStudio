#+brief: What a report error is about, named in the engine's own vocabulary.
#+entity_singular: report_error_scope
#+entity_plural: report_error_scopes
#+entity_title: Report Error Scope
#+created: 2026-10-16
#+updated: 2026-10-16

The vocabulary a report error's scope is drawn from. The engine that computes a
report states the scope of every error it emits, in its structured log, as a
=group=. The codes here are those group names verbatim, so the model adds no
classification of its own: the engine says =Trade= and the row says =Trade=.

| Code | Where an error of this scope appears |
|---|---|
| =Trade= | On the one trade the error names. A trade that would not build is one of these, and a run that reports sixteen of them reported sixteen trades that would not build. |
| =Analytics= | On the one analytic the error names, or on the trade the analytic could not build. Which of the two is stated by the error row's subject, not by the scope. |
| =Curve= | On the one curve the error names, a curve that would not build while the market was assembled. |
| =Configuration= | On the input the error names, which belongs to no one trade. |
| =Report= | Nowhere below the run: the error is about the run itself. This is the one code the engine does not emit. It is here because a run can also fail for a reason no engine saw, such as a workflow step that never reached it, and a reader wants one table. |

=Report= is the only code this model states rather than copies. Every other code
is a string the engine writes, and a code the engine writes that is not a row
here is a vocabulary the engine has grown: the row is refused, loudly, rather
than stored with a scope no reader can place.

* SQL

** Flags
:PROPERTIES:
:tablename: ores_reporting_report_error_scopes_tbl
:END:

The table's row-level security is stated by hand in
=reporting_rls_policies_create.sql= rather than generated, because the scope
vocabulary is seeded for the system tenant and has to be readable by every
tenant that reads a report. A generated tenant-only policy shows a tenant its
own rows and nothing else, so every tenant would find the vocabulary empty.
