The C++ projection of the catalogue's digest section. =read_instrument_components=
hands the append callback every row of the trade's instrument that makes up its
economic shape, in the order the catalogue lists them, and
=read_shared_components= hands it the rows every instrument shares. The switch has one case
per routed instrument table and no default, so a table the catalogue routes and
does not list fails the build rather than reading as empty.
