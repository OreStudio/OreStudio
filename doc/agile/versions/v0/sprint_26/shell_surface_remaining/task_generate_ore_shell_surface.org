* Notes

The =ore= menu is the ORE document round trip: upload a package, import it, and
export a portfolio. It lives in the trading shell part because the round trip
writes trading entities, not because this component owns the menu.

Two of the three verbs compose more than one step. =ore import= uploads the
package and then sends =ore_import_request=; =ore upload= moves a file and sends
nothing. =ore export= sends the trading protocol's portfolio export, which belongs
to another component's model.

So there is nothing here for a generated unit in this component to supersede. The
=ore_import= operation renders no unit because the component has no shell part, and
the menu that reaches it does more than send the request.
