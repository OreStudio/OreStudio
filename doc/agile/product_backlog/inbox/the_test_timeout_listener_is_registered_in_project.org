#+description: The test timeout listener is registered in projects/ores.http/client/tests/main.cpp by hand; the test-main template states only the logging and database lifecycle listeners, so the drift check flags the file. A listener that kills a test after 60 seconds is a whole-suite policy, so it belongs in the template behind a per-component opt-in (a property such as :test_timeout_listener: true on the component model) rather than in one generated file. The hotfix that cleared main dropped the hand edit, so the http client suite has no per-test timeout today.
