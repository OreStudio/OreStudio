* Goal

The feed's configuration names one approved calibration in place of its own alpha, gamma, beta and window. Choosing a calibration is a new config version, so the feed's history shows when each came into use. At start the feed reads the calibration it names and fits nothing; a feed whose calibration is no longer approved does not start and says why. The run's start record names the calibration and its version.
