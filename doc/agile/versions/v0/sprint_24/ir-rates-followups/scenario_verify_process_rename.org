  =IrCurveEditor= detail dialog.

  "Cox-Ingersoll-Ross" (a spelled-out label), not the raw code
  =COX_INGERSOLL_ROSS= or the old =CIR=.

  formula description (dr = κ(θ−r)dt + σ√r dW ...).
