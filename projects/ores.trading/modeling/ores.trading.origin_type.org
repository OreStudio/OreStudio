Reference data table holding the systems a trade can come from: =ux= (a
person at a screen), =api= (an external caller through the API),
=ore_import= (the ORE XML import) and =synthetic= (the trade population
generator).

The set is closed and the C++ enum =domain::origin= holds the same values.
A code with no enum value cannot be read back, so the table is immutable:
it is seeded once and never changes at run time. Because it is immutable,
the trade anchor references it with a database foreign key rather than a
trigger check. The table has no tenant: the set is the same for every
tenant.

Origin is provenance and not economics. The same trade imported twice is
one trade, so origin stays out of the economic digest.
