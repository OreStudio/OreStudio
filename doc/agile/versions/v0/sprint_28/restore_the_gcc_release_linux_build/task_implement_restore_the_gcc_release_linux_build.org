* Notes

** What the rebalance dropped

Continuous Linux went from four configurations to two, clang debug and
release, and the gcc pair moved to the Nightly Build. That matrix carried
debug alone, so =linux-gcc-release= stopped being built anywhere, and
nothing reported it to CDash because nothing ran it.

** Why release joins the nightly rather than continuous

The rebalance exists to keep the continuous compiler-cache working set
small enough for the 10 GB repository cap. A third variant in continuous
works against that. The nightly has room and already holds the gcc debug
job.

** Coverage and memcheck follow the buildtype

The nightly added =code_coverage=1,with_memcheck=1= unconditionally. Both
belong on a debug build, and neither is meaningful on an optimised release
binary, so they are now added only when the buildtype is debug.
