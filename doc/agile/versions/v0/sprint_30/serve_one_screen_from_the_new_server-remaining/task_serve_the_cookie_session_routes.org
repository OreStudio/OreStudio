* Goal

Serve the cookie session, the party switches, sign-up, the password policy and
the password change at the BFF's own addresses and shapes, so the browser signs
in to the C++ server as it does to the BFF. Sign-up and the policy are read
before a session exists, sign-up is rate limited per address, and a password
change updates the session the browser holds, so all eight are the session's
work.
