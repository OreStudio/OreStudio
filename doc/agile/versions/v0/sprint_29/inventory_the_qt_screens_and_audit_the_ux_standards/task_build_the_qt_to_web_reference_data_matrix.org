* Goal

One table answers, for each of the 61 Qt reference data entities, which web screen covers it (a dedicated record screen, the classification screen, the convention screen or none), which fields and child records the web lacks, and which Qt behaviours the web dropped on purpose. The name match of the first pass is replaced by a reading of the Qt sources.

* Acceptance

- Every Qt reference data entity has a row that names its Qt parts and the web screen that covers it or states that none does.
- Each row lists the fields, child records and actions the web lacks, read from the Qt .ui and .cpp sources and the web field tables, not inferred from names.
- The matrix lives as a knowledge page under doc/knowledge/ui and the UX hub links it.
- A Qt behaviour the web drops on purpose is marked as such with the standard section that drops it.
