The tests of the gate a system-owned entity's handler puts on its writes. Every
tenant shares the rows, and the handler writes them in the system tenant's
context, so the store's tenant policy cannot refuse a tenant's write. The
handler's gate is the only barrier, and these tests prove it for every write
operation the entity has.

Each case drives the handler over real NATS on test subjects, with a token the
test mints. The body is one byte no wire format decodes, so no case writes a
row. A session of the test tenant is denied before the body is read. A session
of the system tenant passes the gate and is refused at the decode step, which
proves the gate let it through without changing the system tenant's rows.

The unit renders only for a model that states =:system_tenant_validation:=.
The output path names ={system_owned_entity}=, which resolves only for such a
model.
