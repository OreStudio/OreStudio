* Result

Add or correct a currency runs in ores.web against the real server: a currency
list with labels and a filter, and a currency page with its fields, its
countries, calendars and desk groups as link panels, and its history. The
screens read and write through a new registry of refdata record resources
(wire-protocol) and generic, allow-listed BFF routes; one field table per
resource drives the edit form, the details and the revert. The ORE export is
stated on the screen as missing, per the journey. Checked on the real server:
every resource read, a stale write refused, a correction diffed in the
history.
