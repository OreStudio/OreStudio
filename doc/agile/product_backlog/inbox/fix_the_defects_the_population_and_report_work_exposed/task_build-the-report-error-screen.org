* Goal

A person opening a report run sees its errors, placed against what each one is about, so a trade-scoped error appears on that trade and a report-scoped error on the run.

* Acceptance

- The screen lists a run's errors with scope, severity and message.
- An error that names a subject is reachable from that subject.
- A run that carries errors is distinguishable from a clean one without opening it.
- The screen holds only the permission it needs, and is checked against a run that has errors.
