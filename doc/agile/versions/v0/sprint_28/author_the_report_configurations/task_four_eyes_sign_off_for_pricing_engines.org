* Goal

Build the sign-off that the sign-off journey and prototype draw. Each role that model risk names approves each change to an official pricing engine configuration before a report can run with it, and the person who proposed a change cannot sign it off. This is the implementation, and it starts after the main configuration UI is implemented. The journey and the prototype are in the task Govern the pricing engine configurations.

* Acceptance

- The server holds a proposal, a decision and a status, and a policy that names the roles.
- The server refuses an approval from the person who proposed the change, and from a person with no role for the row.
- A proposal never replaces the rows that a run reads. Making it official changes the version in force in one step.
- A run records the version of the configuration it used.
- A direct write to an approved version is refused.
- The screens follow the sign-off prototype.
