* Result

The 27 avatars in =external/avatars= are recoloured from =#212121= to
=#e3e3e6=, the theme's ink, and the seed regenerates from them. The running
environment's images were updated in place and the BFF image cache cleared, so
the Accounts list and the Root Tenant People tab draw legible avatars. One
environment quirk worth recording: =/api/images/:id= is served =immutable=
for a year, so a browser that fetched an avatar before the in-place update
keeps it until its site data is cleared. A provision creates fresh image ids,
so the durable fix does not meet that cache.
