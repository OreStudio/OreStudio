* Acceptance

- The participation table is keyed by process run and trade, carries a role from a reference list, and references both with enforced foreign keys.
- The roles distinguish an input from an output, because a run reads trades it does not change.
- A single-trade run writes one participant; a pgTAP test covers a run over several trades.
- No row of this table references a trade activity: the activity is the stamp on an amendment, and the run is the parent here.
