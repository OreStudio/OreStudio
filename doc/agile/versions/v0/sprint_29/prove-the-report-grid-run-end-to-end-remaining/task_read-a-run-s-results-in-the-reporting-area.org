* Acceptance

- The report page carries Definition, Runs and Results tabs.
- The Runs tab lists the report's runs newest first with their state.
- The Results tab reads npv.csv from the latest run's output archive and shows the figures first, then the rows.
- A run with no output, or an output that holds no npv.csv, says so rather than drawing an empty table.
- The parsing is tested against a file shaped the way the engine writes it.
