* Goal

A family with no shape row is projected unguarded, by design, so the catalogue can grow family by family. Nothing says when it should have grown: a new family is written unguarded until someone thinks to state it. A check reads the families the stored identities use, by asset class, series subclass and index family, and names each one no shape row states. Raised by the review of PR #4821.

* Acceptance

- A pgTAP suite or a local check names every family in use that no shape row states, and fails when there is one.
- A family that is unguarded on purpose is listed as such, with its reason, so the check passes on a deliberate gap.
