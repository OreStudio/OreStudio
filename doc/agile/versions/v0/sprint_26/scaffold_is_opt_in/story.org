* Decisions

- *First-generation scaffolding is opt-in, and the opt-in is one line.* The
  facet is `#+default: disabled`; a component asks for it with
  `:ores.cpp.scaffold.enabled: true`, which the overview scaffold writes for
  a new component and which the first real model retires.
- *The address states the lifetime.* The scaffold used to sit in
  `ores.cpp.component`, so "first-generation only" was a convention nobody
  could see. A facet of its own makes it structural.
- *A component's umbrella header is scaffolding too.* The same run showed it
  recreated for a component that had deleted it; it moved with the stubs.
