* Goal

Lay the domain knowledge of grouping trades on one foundation. A trade
set is the primitive, a trade group is the set a run of a process
creates, a structure is the set that is also a product, and a link is
neither. Write that down once, with the taxonomy, so that batching, the
processes and the reports are built on a stated model rather than an
assumed one.

* Acceptance

- The grouping vocabulary is stated once, in one place: trade set, trade group, structure and link.
- A taxonomy diagram shows how the groupings relate to each other and to the constructs above them.
- Each document names what it excludes, so batching, the processes and the reports keep their own homes.

* Plan

Settle the shape with the owner before writing, then write in reading
order: the primitive, the two rules that hang off it, the set an
operation creates, and the hub that orders them. Redraw the taxonomy as
a diagram beside the notes. Then sweep the pages that carried the old
set/group vocabulary, so one model is stated in one place and nothing
contradicts it.
