* Goal

A connection carries no tenant or party between transactions: each transaction sets its own context locally, so any connection serves any tenant.

* Acceptance

- Tenant, party, visible parties, actor and service are set with =set_config(..., true)= at the start of each transaction, in the round trip of its first statement.
- A test reuses one connection for two tenants and shows the second transaction sees none of the first tenant's context or rows.
- Nothing is set when a connection opens; UTC is a default of the role.
