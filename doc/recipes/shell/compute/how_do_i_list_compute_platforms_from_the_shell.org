#+title: How do I list compute platforms from the shell?
#+description: List the compute platform triplets (id, code, display name, OS, CPU arch) from the shell as a table.

The compute grid verbs live in the shell's =compute= menu. They talk to
the ~ores.compute~ service over NATS; the domain shapes and table
renderers come from ~ores.compute.api~.

* Question

How do I list compute platforms from the shell?

* Answer

Log in as the system super admin (principals are
=username@hostname=), then =compute list-platforms=: the shell prints
the platform triplets as a table — id, code, display name, OS, CPU
arch. The table is empty until a platform exists (e.g. after =compute
publish-package=).

#+name: list-compute-platforms
#+begin_src ores-shell :exports none
connect $ORES_NATS_URL
login super_admin@localhost Secure-Password-123
compute list-platforms
logout
exit
#+end_src

#+begin_src sh :noweb yes :results output :wrap example
./ores.shell ${log_args} ${connect_args} << 'EOF'
<<list-compute-platforms>>
EOF
#+end_src
