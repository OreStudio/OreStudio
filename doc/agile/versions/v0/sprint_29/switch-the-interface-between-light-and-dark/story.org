#+title: Story: Switch the interface between light and dark, and choose the language from the header
#+description: The interface has one palette, a dark one, because a terminal is read for long sessions; a person who needs a light screen has no way to ask for one. The language is chosen from a select inside the account menu, which is where a person looks for their own pages and not for a setting about reading. Give the header two controls with the icons the icon set already uses for them: one that switches the palette and says which one it will switch to, and one that opens the three languages.
