One =StressTest= element of an ORE stress document. The id attribute is the
scenario's name, which is what a run's analytic refers to; the corpus holds
twenty-six distinct names across forty-six uses, so a name is shared between
documents.

What a scenario actually does lives in its shift blocks -- DiscountCurves,
FxSpots, SwaptionVolatilities and fifteen more -- and each is modelled as it
lands. This row holds the scenario itself: its name, the library it belongs to
and the date it is applied at.
