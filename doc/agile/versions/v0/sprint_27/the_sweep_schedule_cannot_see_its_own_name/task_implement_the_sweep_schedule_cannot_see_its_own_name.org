* Acceptance

- The job lookup captures what its predicate reads.

* Plan

=try_register_once()= recognises the job it registered last time by comparing
each definition's name to =described_.job_name=. The predicate is a lambda with
an empty capture list, so =described_= is out of reach: clang refuses the
implicit capture of =this= and then refuses the =find_if= whose predicate
concept is unsatisfied. Both errors are the one cause.

Hold the name in a local and capture that. The alternative, =[this]=, captures
the whole object for a predicate that reads one string, and the job name is what
the comment above the lookup already says the match is by.

Nothing else in the file is affected: this is its only lambda, and every other
use of =described_= and =svc_nats_= is in a member function body.
