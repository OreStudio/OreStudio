* Result

Implemented =black_derman_toy_process=: a recombining binomial tree short-rate
engine with time-varying volatility. The tree is fitted once at construction
by forward state-price calibration, reproducing the input discount curve
exactly, with flat continuation of the last fitted level beyond the input
curve. =next()= walks the tree with p = 0.5; =discount_factor()= propagates
state prices through the generic =rate_tree= utility. 17 Catch2 tests
covering exact curve reproduction at =sigma == 0=, implied bond prices
agreeing with the fitted curve, tree-walk recombination, discount
monotonicity, dt scaling of the level spacing, seed determinism and
validation. Registered in =component_files.cmake=.

All 368 =ores.analytics.quant= tests pass on Linux. Not yet wired into
=process_factory= (deferred to PR 2: system infra wiring).
