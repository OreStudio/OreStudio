ORE writes the netting sets a credit simulation covers as a comma separated
list of codes inside one =NettingSetIds= element, which is a list stored as
text. A list is rows, so each code is a row here, keyed to the configuration
and carrying its position so the order is reproduced on export.

The codes name netting sets that the trading component owns; no netting set
entity exists yet, so the code is held as text until one does.
