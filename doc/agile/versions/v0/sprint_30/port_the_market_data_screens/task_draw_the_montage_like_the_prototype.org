* Result

The provider set, the Today column and the day's marked ends are merged in
#4759. The provider set travels in the address and is asked of the server as a
set; each row draws its own freshest provider's day, sharing the open pair's
read; and the panel states and marks the day it draws, not the row's figures.

The review's one real defect was the chip set: filtering to a provider emptied
the control down to it, so the others could not be put back. That is fixed, and
the claim in the PR body that said otherwise was wrong and is corrected. The
review's sharpest point led to the panel separating two provenances: the path's
own numbers, and the table's, which are the server's pair answer.

Two costs are recorded rather than hidden. Each row's shape is one series read,
which wants a server or bulk read; and the pair's stated high, low and change
come from whichever provider the store returned last, which wants the read to
fold the window across the pair.
