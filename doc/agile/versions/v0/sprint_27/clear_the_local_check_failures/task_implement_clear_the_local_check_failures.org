* Plan

The tangle is the source of truth. =./compass.sh build --direct
tangle_shell_scripts= regenerates every script under
=projects/ores.shell/scripts/library/= from =doc/recipes/shell/=, and on main
it leaves twelve changes, which are the whole defect:

- Six tracked scripts differ from their recipe. =report_operations
  submit-compute= and =prepare-ore-package= gained two arguments;
  =report_instances add=, =set= and =put-many= had two arguments reorder;
  =account_operations save-account= lost one.
- Six scripts are missing altogether. The =account_credential= recipe landed
  in =f8289850b5= without its tangled output, so =account_credentials list=,
  =get=, =get-many=, =by-account-id=, =version= and =versions= exist as
  recipes and not as scripts.

Nothing is hand-edited: the change is the tangle output, committed.

* Notes

=git diff --exit-code= cannot see a file that was never added, so before the
untracked-files step was added to =shell-script-drift.yml= the missing
=account_credentials= scripts were invisible to the gate. The local
classification has no rule for =projects/ores.shell/scripts/library/**= either,
so it falls to the =unknown= class and runs every check; both are worth a
follow-up.
