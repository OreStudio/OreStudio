* Acceptance

- A netting_set_identifier entity holds identifiers of a netting set under a party id scheme, generated across SQL, C++, protocol and shell.
- Within a tenant an ORE name is the alias of one netting set only.
- Build, ctest, pgTAP and the local check set pass.

* Plan

Follow the counterparty pattern exactly. A netting set keeps its own code, the
name the tenant gives it, and answers to ORE ids through identifiers.

- Add =ores.refdata.netting_set_identifier=, copied from
  =ores.refdata.counterparty_identifier=: (netting_set_id, id_scheme,
  id_value, description), schemes from =party_id_schemes=, and the partial
  unique index =ore_alias= on (tenant_id, id_scheme, id_value) where the
  scheme is ORE.
- Leave out the composite versioning flags the counterparty identifier
  carries. A netting set is not a composite entity: its CSA does not bump its
  version either, and the netting set table has no touch function.
- The generator picks ORE or INTERNAL, the two schemes with no cardinality
  limit that name things inside one system.
- Wire the SQL create and drop lists, the permissions, the core registrar, the
  history provider and the shell commands.

* Notes

- The service compiles the event registrars of netting agreements, netting
  sets and now netting set identifiers, but =event_registrar.cpp= calls none of
  them, so no change event of the three reaches NATS. The identifier follows
  its parent here. Wiring all three is a follow-up.
- An ORE id is unique per tenant, not per party. Two parties of one tenant
  cannot both import a set named =CPTY_A=. The counterparty aliases have the
  same scope.

* Result

A netting set now answers to ORE ids through =netting_set_identifier=, as a
counterparty does through =counterparty_identifier=. Within a tenant an ORE id
names one netting set, and a set may hold several ids. The entity is
generated across SQL, C++, protocol, shell and the web wire protocol, with
seeded permissions. pgTAP covers the alias rule, the shared values of other
schemes, a new version of an alias, and the rejected set and scheme.
