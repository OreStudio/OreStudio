This page documents a [[id:31C868B9-306E-4282-BA8C-07E647021B34][task]] in the [[id:12DAAEC7-2E9D-4487-80E5-E690737071B3][Make the oresmd URI grammar explicit and typed]] story. It captures the goal, current status, acceptance, and any notes or results.

* Goal

The oresmd grammar is declared in its models rather than in the generated
parser. Each of the thirteen quote-type models states, for every query key, its
role (identity or coordinate), its value kind and its order; and it states, per
quote type, which coordinate keys that type carries. The =point= bag is removed.

No generated C++ changes in this unit. The point of the unit is that the next
unit can generate the parser, the writer and the series identity from a
declaration a reviewer can read, instead of from a hand-written visitor.

The findings and the target grammar are recorded in
[[id:1C9EE1D4-651E-49D9-927C-F4891FF1ACEB][The oresmd URI grammar: silent defaults and the untyped coordinate]].

* Acceptance

- Every dimension a =point==-bearing URI carries is a declared query key, with a
  role, a value kind and an order.
- Every query key of every quote type has =role= of =identity= or =coordinate=.
- The four volatility families with no quote type of their own gain one:
  =swaption= for IR, and an =option= member for FX, equity and commodity.
- A codegen test walks every =point==-bearing URI in the model test tables and
  fails while any is not expressible as declared keys. It passes at the end of
  this unit and its check is the record's evidence.
- The generated C++ is unchanged by this unit, and every existing test still
  passes.

* Plan

1. Read the census in the investigation: every quote type, its
   =point_semantics=, its =qualifier_shape=, and every =point==-bearing URI in
   the model test tables.
2. Add the =Coordinates= table to each of the thirteen =*.org= models under
   =projects/ores.marketdata/modeling/oresmd/=.
3. Add =role= to every row of each model's =Fields= table and mark the =point=
   rows for removal.
4. Add the four missing quote types.
5. Add the codegen check, and record its before and after counts in
   =* Measurements=.
