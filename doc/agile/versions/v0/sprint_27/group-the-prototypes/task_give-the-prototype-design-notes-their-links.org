* Result

Nine design notes carry the table: three under access, and one each under
books, classifications, entry, profile and tenancy. Each names the
prototype, the Gemini review where one exists, and the group page the
note answers to. Three notes link a review: =access=, =profile= and
=tenancy/navigation=. The other six say =none=.

It is an org table rather than the export block the earlier attempt used.
The earlier version was raw HTML with inline styles, which no org buffer
renders and no link check reads; this one is the same table in the org
file and on the site, and its links are org links, so =org-links= covers
them. The styling it gives up was the reason the block existed, and the
group page already carries the register for anyone who wants the styled
view.

Nothing changed in a prototype page or a review page, which stay
byte-identical to what their author wrote. Only the notes changed.
