* Acceptance

- The rule is in the Summary and in its own section, with the two reasons a
  read may be open: a self read, or a read a member needs before holding any
  role that grants it.
- The allow-list names each open subject, what it answers, and why.
- The planned self read for contact information is listed, so task 2 can open
  it.
- The page says where the code is today, so a reader does not mistake the rule
  for the current state.
- Every subject on the list exists in the generated protocol.
