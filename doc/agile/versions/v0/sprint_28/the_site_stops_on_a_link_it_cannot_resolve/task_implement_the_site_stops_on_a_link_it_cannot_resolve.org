* Plan

The id belongs to =doc/knowledge/journeys/reporting/journey_look_back_over_a_reports_history.org=
and is written there in lower case. Two of the six references typed it in upper
case:

#+begin_example
doc/knowledge/journeys/conventions/journey_change_the_convention_for_one_kind.org:313
doc/knowledge/journeys/reporting/journey_change_what_a_report_runs.org:436
#+end_example

Change both to the lower-case spelling. Nothing else refers to the upper-case
form, so no alias is needed.

The page gates could not have caught it, which is why it reached main:

- =site-page= publishes only the pages a change touches, so a broken link in an
  untouched page never gets exported by it. The full build is a different
  target, =deploy_site=, and it sits outside =compass check=.
- =org-links= checks links, but not whether an =id:= link matches a defined id
  by case.
