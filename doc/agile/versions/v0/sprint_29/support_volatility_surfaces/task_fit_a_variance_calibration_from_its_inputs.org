* Goal

Fitting reads only a stored input, never the live fixings, so the same input always gives the same fit. The result is stored as a proposed calibration that names its input, the method version and every number a reviewer needs to judge it: the parameters, persistence, long-run and starting variance, likelihood, the starts tried and whether they agreed, and why a fit was refused.

* Acceptance

- synthetic.v1 operation fit_variance_calibration for an input id, permission-checked, returning the proposed calibration.
- A refused fit (too few returns, a fit at the stationarity bound, no convergence) is stored as a rejected calibration with the reason, so the attempt is in history.
- Fitting one input twice gives the same parameters; the tests reuse the QuantLib-derived GJR-GARCH cases and add one per refusal.

* Notes

The schema does not tie =persistence= to =alpha=, =gamma= and =beta=, because
=p_minus= is not stored (review of the records task, PR 4426). This task owns the
equality: the fit writes =persistence= as =alpha + gamma p_minus + beta= from the
mixture it fitted under, and a test checks it on every stored fit.

* Result

The same run fits each captured input with =fit_variance=, which reads only the
points, so the same input gives the same fit; an applied run stores the result as
a proposed calibration, or a rejected one with its reason, named by its input and
the method version, and never rewrites one that exists. The fit states its
evidence: the shape, the persistence computed under the feed's daily =p_minus=
(tested equal to =alpha + gamma p_minus + beta=), the long-run and starting
variance, the likelihood, the starts tried and whether they agreed, which the
analytics fit now reports.

Measured on the same run: 25 proposed and 3 rejected (241, 247 and 248 returns
against the minimum of 250). Several proposed fits sit at a boundary with
disagreeing starts, such as NZD/USD, USD/TRY and EUR/JPY: a year of data identifies
the shape weakly, which is what the review is for. The analytics tests show the
starts agree on a well identified series and disagree on thirty returns of near
white noise; the synthetic tests cover recovery, determinism, rejection and the
inverted sign.
