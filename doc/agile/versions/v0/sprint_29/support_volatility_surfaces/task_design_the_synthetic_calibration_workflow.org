* Result

The story's Decisions record the design in four entries: calibration runs as a
workflow after the public rates are loaded; a fit within the class policy's
rules is approved by the policy; one review verb serves a person and the policy,
with no apply workflow; and the synthetic feeds start only when their class is
released. A flow diagram beside the story shows the provisioning runs, the
calibration workflow and the release.

The design is built by six tasks, in this order: approve a fit within the class
policy's rules; load the public rates as a workflow step; run the synthetic
calibration workflow; release the synthetic feeds after calibration (the earlier
task to start the feeds after calibration, rewritten); calibrate in the
provisioning system run; and recalibrate on a schedule.

The evidence is the provisioning run of 2026-11-03 (26 Bloomberg fixing feeds started from 16:09:57,
IMF fixings stored at 16:10:03) and a preview of the FX class on the same day (13
of 24 proposed fits pass the proposed rules).
