* Goal

A person who asks for a run gets one, whether or not the report has ever been
scheduled. The report holds its consent to run, and admission creates that
consent from the person asking when it does not yet exist. Every later trigger,
on demand or scheduled, reuses it.

This is the half of [[id:822CEF08-980C-4548-9C7B-04CFF433CEFB][the trigger
story]] that gives a run its authority. Without it a run that no schedule
produced cannot act, which is why building a report's ORE packages fails today.
