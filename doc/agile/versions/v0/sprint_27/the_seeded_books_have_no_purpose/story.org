* Goal

=compass db recreate= dies in populate on every checkout of =main=:

#+begin_example
psql:populate/testdata/testdata_books_artefact_populate.sql:225:
ERROR: null value in column "book_purpose_type" of relation
"ores_dq_books_artefact_tbl" violates not-null constraint
#+end_example

The book gained two not-null columns, =book_purpose_type= and
=ledger_feed_type=, and the generated artefact DDL gives neither a
default. All five book seeds -- the testdata set and the four ACME sets --
insert the older column list, so the first row of the first one fails.
Populate aborts, =ores_database_info_tbl= is never stamped, and every
service then refuses to start with "the database schema does not match
this build (none)". No database can be created from =main=.

The fix belongs in the model, not in the five seeds. The model already
states both defaults in the columns' own prose: a book that plays no
specialised role trades, and a book with no ledger connection has no
feed. The artefact column list simply failed to mirror them, the way
=is_sweepable= on the same table already mirrors its own =false=.
