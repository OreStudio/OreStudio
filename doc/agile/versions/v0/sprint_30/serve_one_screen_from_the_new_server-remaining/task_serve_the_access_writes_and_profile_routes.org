* Plan

Serve the people screens' account reads and the default party at the BFF's
addresses: =GET /api/accounts=, =GET /api/accounts/:username= and
=POST /api/me/default-party=. An account is stated as the screens read it by
one shared writer, =account_view=: camelCase, an unknown account type read as
a person, and the nil identifier on a reference read as null, as the BFF's
=mapAccount= did. One account named by the caller's own username is read by
the self read, which needs no account permission.

The access screens' shapes move into one header, =access_screen_shapes=, which
every access route reads and writes: the unity build check found two units of
the part each defining =wire_fields= for its own shapes, and the shapes are one
vocabulary.

The other 20 routes move to [[id:0BA78447-4EB6-4655-87EA-5CF45B0581A9][Serve the access profiles, contacts, locks and role writes]].
