* Acceptance

- The read returns the inputs the generator read, the latent state, each vendor's view and the quotes that were delivered, and it ends there: no calibration and no party.
- The read returns the chain as nodes and edges. A node carries its kind, its state, its as-of and the series it holds; an edge carries what it flows, the as-of of what flows and the lag between the two, so a stale input reads on the edge.
- The read returns the axes the quote set declares -- their names, their labels and the model a fit would use -- and the page draws from that description and from nothing else.
- The subject is whatever the quote set's coordinates name, and the read refuses a subject the store does not know rather than answering an empty chain.
- A subject whose chain is broken returns the node that failed and the input it lacked, and the edge it should have carried is absent rather than empty.

* Notes

- The read is the seam the page depends on: a page that cannot draw a new class without a change is a read that did not state the axes.
