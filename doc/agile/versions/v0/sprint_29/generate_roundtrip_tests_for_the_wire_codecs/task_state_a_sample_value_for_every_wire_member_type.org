* Goal

=ores::utility::codec::sample<T>= makes a value, with every member away from its default, for every type an opted-in model's codec writes.

* Acceptance

- The sampler covers every member type in the protocol survey, which counts the members of the generated protocol headers.
- Each sample differs from the type's default and from the member's modelled default.
- Nested types that state =wire_fields= resolve by recursion, across components.
- No sample is NaN or a computed value, because a defaulted equality compares a =double= exactly and NaN never equals itself.
- A type outside the rules fails to compile.
- Catch2 tests in =ores.utility.tests= cover every member kind, the second sample, two distinct vector elements, and an exact JSON and MessagePack roundtrip.

* Plan

The story first put a sample table in codegen Python. On a second look the
codec headers state each type's =wire_fields= in public view, so a C++ sampler
can walk the same list the codec walks. The plan:

1. Add =ores.utility/codec/sample.hpp=. Dispatch in the codec's own order: a
   struct with =wire_fields=, an enumeration, the scalars, the text-form
   types, then the wrappers.
2. Give each type two samples, so a member whose default equals the first can
   take the second.
3. Test it in =ores.utility.tests= against a probe struct with one member of
   each kind the survey found, and roundtrip the probe through both formats.

* Notes

- The vector test caught a real defect in the first version. The struct
  sampler ignored =which=, so both samples of a struct were equal, and a vector
  of structs held two equal elements. A vector codec that wrote the first
  element twice would have passed. The second sample now differs from the
  first in every member.
- The survey lists =std::optional<std::optional<T>>= on 18 members. The probe
  holds one, and it roundtrips in both formats.
- The time point sample has microseconds, and it roundtrips exactly in both
  formats. No precision is lost.
- The survey grew from 35,801 members at 17019adff8 to 36,524 at f9ee9f6f5d,
  because main added models.

* Result

=ores::utility::codec::sample<T>= in =ores.utility/codec/sample.hpp= makes a
non-default value for every member type the protocol survey found. It recurses
through =wire_fields=, so nested types in other components need nothing more.
A type outside its rules fails to compile. Four Catch2 cases in
=codec_sample_tests.cpp= prove the values differ from their defaults, the
second sample is taken when needed, vector elements differ, and a probe with
one member of each kind roundtrips exactly through JSON and MessagePack. The
generated test archetype can now call =sample<T>(0)= for each type.
