* Notes

- Plan from compass-85's v0.0.7 bundle, in five PRs: this one (pin, grants,
  exports, check inventory), then service integrity, commit provenance, the
  .env generation, and retiring verify.py. The product owner decided:
  ores.ore.service's role gets ore::* permissions; the agent prototype's
  essentials list gets an exception row; commit provenance is on, with
  Environment on every commit; ORES_TEST_LOG_ENABLED is declared as a new env
  format version.
- v0.0.7's full check on main: 1 codegen/drift (the grants file), 1662
  exported_types/unexported_hidden_function, and the 2 known warnings.
- Grants: the regenerated file holds exactly main's grant statements, compared
  as sorted sets. The view loop moved into the template; the approvals mode
  and notification grants moved into the registry with their reasons as
  comments.
- Exports: the templates follow the junction branch of the history provider
  template, which already included =ores.<part>/export.hpp= and wrote
  =ORES_<PART>_EXPORT=. The regenerate wrote 1702 files. Every export header
  the new includes name exists (14), and every macro used is defined there.
  The twelve hand-written declarations were marked and clang-formatted.
- compass reported, in the first pass of a three-pass generate, that it
  deleted the view loop comment the template now holds; the final file keeps
  it. Sent to compass-85 as a compass issue.
