* Result

The book level reads as a tree.

A portfolio nests under its parent portfolio, and its figure is its own books
plus the portfolios under it, so each level can be checked against the level
above and below. Each row states its depth and the screen indents it. A book in
no portfolio, or in one whose name was not read, stands at the top rather than
under a guess.

On run =c2a86671= the level draws four rows: *Global Portfolio* over *Banking
Book* over *Liquidity Buffer Portfolio* over *Liquidity Buffer Bonds*, each at
=33,709,129.46= HKD over the same eight trades, which is what one book under one
chain of portfolios should say.

The totals line states the run's own trade count rather than the sum of the rows,
because a tree's rows state the same trades once per level above them.
