- The story records which component owns todaysmarketcalibration_cashflows.

* Plan

The three files are what the engine loaded, written back: a date, the thing the
value is for, and the value, with a payment date for a dividend. The suite corpus
holds no sample of them; the notebook examples do, so the generator reads those
three families from the notebooks and nothing else from there, because the
notebooks also copy families the suites state.

The acceptance named the observation and fixing tables. They are the wrong home:
the observations a run reads come from this store, so the run's copy written back
would duplicate them, and a new version would replace the stored provenance with
the run's. The values land in =ores_marketdata_market_input_values_tbl=, scoped to
the run, as the scenario and calibration values are.

1. The generator reads marketdata, fixings and dividends from the notebooks, with
   family-scoped keys, because a cashflow family states =fixingDate= as a column.
2. =read_market_inputs= in =ores.ore= and the corpus gate, which now also reads
   every family's own sample, wherever it lives.
3. The three families are market state, so =store_market_state= reads and stores
   them, and reporting leaves them alone.
4. =todaysmarketcalibration_cashflows= stays in reporting: it is a cashflow keyed
   by market object, pillar, leg and number, and the cashflow table and reader
   already hold it; marketdata would need a second cashflow table of the same
   shape.

* Result

The quotes, fixings and dividends a run read are catalogued, read by
=read_market_inputs= and stored by marketdata in
=ores_marketdata_market_input_values_tbl=, one row for each line, keyed by result,
file and line. They are not observations: the observations a run reads come from
this store, so the run's copy is kept beside them, scoped to the run. The three
families' samples come from the notebook examples, and the corpus gate now reads
every family's own sample. =todaysmarketcalibration_cashflows= stays in reporting,
as the Plan says. A run of Group Consolidated Exposure stored the two FX quotes it
read.
