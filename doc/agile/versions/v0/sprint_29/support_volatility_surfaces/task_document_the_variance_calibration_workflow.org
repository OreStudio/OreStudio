* Goal

The knowledge base describes the target workflow: a calibration run captures its inputs under the class policy and stores them, a fit reads one stored input and is stored as a proposed calibration, a person approves or rejects it, and a feed runs only an approved calibration it names. Every stage is versioned and shown in history.
