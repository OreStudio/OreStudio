* Goal

The platform has one report type, risk, and one report workflow, which runs the engine. System Health, Audit Trail Summary, MIFID II Transaction Reporting, CFTC Swap Data Reporting and HKMA Trade Repository do not compute an analytic. They monitor the platform, summarise changes or report trades to a repository. They currently carry a stand-in analytic, portfolio details, so that their run document is not empty. Give them a report type, a workflow and the inputs they really need, and remove the stand-in.

* Acceptance

- A report type and a workflow exist for the reports that do not run the engine, and each of the five reports uses one.
- The five reports no longer require the ORE configuration documents, and their configurations no longer carry the stand-in analytic.
- Data Quality Completeness and FX Spot Rates are decided separately: either they keep an engine analytic with a reason, or they move to the new type.

* Plan

1. For each of System Health, Audit Trail Summary, MIFID II Transaction Reporting, CFTC Swap Data Reporting and HKMA Trade Repository, state its input, its output and its destination.
2. Decide the report types and the workflow for them. The report type seed states that a type no workflow can run is not seeded, so the workflow comes with the type.
3. Move the five reports to the new types and remove the stand-in analytic from their configurations.
4. Decide Data Quality Completeness and FX Spot Rates.
