The warning configuration of the [[id:0442FD13-1833-427F-B6CA-C4B5877C452B][identity workflow]]. The =ores-shell= block
below is tangled into the runnable script library as =identity_with_warnings.ores=.

* Question

How do I tell a clean run from a lossy one?

* Answer

The second step reports =warn=, so the engine marks it =completed_with_warnings= and keeps the log entries the handler recorded. The instance still completes: a warning is not a failure, and only the step log says the run was lossy.

#+name: identity-with-warnings
#+begin_src ores-shell :exports none
workflow start identity_workflow '{"steps":[{"name":"one"},{"name":"two","behaviour":"warn"}]}' --instance-id 10000000-0000-4000-8000-000000000003
workflow wait 10000000-0000-4000-8000-000000000003 --timeout 60 --expect-state completed
#+end_src

=workflow wait= fails unless the instance reaches the state named, so this
script fails when the path it covers does nothing.
