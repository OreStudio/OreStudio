* Goal

A record detail can carry a hint, and it shows as a native title on the label. A native title does not show on touch screens, and the label cannot take focus. Add a shared tooltip that opens on hover and on focus, with aria-describedby, and use it for every hint.

* Result

Merged as [[https://github.com/OreStudio/OreStudio/pull/3496][#3496]].

- =ui/Tooltip.tsx= holds one shared tooltip. It opens on hover, on keyboard
  focus and on tap, and it wires =aria-describedby= from the label to the hint.
- =revealAfter= is a pure function over the reveal state. A test covers when
  the hint stays open and when it closes.
- The record screen hints use the tooltip. The native =title= attribute is gone.
