#+title: How do I list compute results from the shell?
#+description: List the submitted compute results as a table with outcome and host, optionally filtered to one batch by external reference.

The compute grid verbs live in the shell's =compute= menu. They talk
to the ~ores.compute~ service over NATS; the domain shapes and table
renderers come from ~ores.compute.api~.

* Question

How do I list compute results from the shell?

* Answer

Log in as the system super admin, then run =compute list-results= to print every submitted result as a table: id, workunit id, host id, server state, outcome, output uri, error message, received at, modified by, recorded at. Pass =--batch= with the batch external reference to filter to one batch.

#+name: list-compute-results
#+begin_src ores-shell :exports none
connect $ORES_NATS_URL
login super_admin@localhost Secure-Password-123
compute list-results
logout
exit
#+end_src

#+begin_src sh :noweb yes :results output :wrap example
./ores.shell ${log_args} ${connect_args} << 'EOF'
<<list-compute-results>>
EOF
#+end_src

Pass =--batch= with the batch external reference to filter to one
batch.
