#+title: The ACME bring-up fails booking a trade for a missing origin
#+description: A fresh recreate followed by smoke ticks --start-services --leave-running runs the eight acme_demo steps and aborts at the eighth: generate_trades fails with 'Invalid origin: <NULL>. No active origin type found with this code' raised by ores_trading_trades_insert_fn at line 14. The origin type table has four rows, so the vocabulary exists; the trade being booked carries a null origin code, which the insert function refuses. The consequence is that a recreated database never finishes provisioning: the tenant is left bootstrapping, step 7 subscribe_market_data had already completed and step 8 is the last one, so nothing downstream runs.
