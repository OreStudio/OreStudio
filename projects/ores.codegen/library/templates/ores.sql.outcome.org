* Summary

One template: the message functions and the raiser the entity triggers
call, rendered from the outcome catalogue. =outcome_catalogue= profile.

* The ores.sql.outcome facet

The SQL projection of the /outcome catalogue/ model: each =store= outcome
becomes a function that composes its sentence, and one raiser maps the code to
its SQLSTATE. A trigger states the code and the field name and nothing else, so
the wording and the SQLSTATE exist once.
