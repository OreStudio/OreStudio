* Result

All eleven headers generate from org models. The full build passes, and
=compass codegen regenerate --component iam --address ores.cpp.protocol=
leaves all sixteen headers in the directory byte-identical.

Three deviations from byte identity, all intended and recorded in the
commit body: the generator's banner on every header; one blank line after
the include guard in =session_protocol.hpp= and
=session_samples_protocol.hpp=; and six end-of-line field comments in
=bootstrap_protocol.hpp= rendered as leading blocks, which is the comment
form the project requires.

The codegen suite reports 222 passed and one failure,
=test_a_colliding_earlier_column_does_not_hide_a_later_real_one=. That
failure predates this work and is not related to it: it expects a
=domain::asset_class= row that =projects/modeling/cpp_custom_types.org=
does not hold.
