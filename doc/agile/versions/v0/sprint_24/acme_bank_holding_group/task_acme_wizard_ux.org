  sample holding group)" vs "Manual setup".

  pages entirely, going straight to Execute.

  =provision_acme_tenant_command= (no bundle publish, no synthetic

  (clears bootstrap flag) same as the manual path.

  in the prior task; no shell changes needed here.

- Discovered =ores.shell='s =--source acme= wiring already landed in
  the prior task (PR #1678); this task's remaining scope is
  ores.qt-only.
- Add =DataSourceMode::acme= to =TenantProvisioningWizard=.

  bundle publish, synthetic generation, and party association

  association for Acme).
- =TenantApplyAndSummaryPage=: Acme-specific summary text instead of
  the bundle-name summary.
