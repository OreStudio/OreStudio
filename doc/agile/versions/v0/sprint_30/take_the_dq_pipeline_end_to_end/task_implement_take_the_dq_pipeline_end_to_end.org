* Acceptance

- Inventories of the seeded datasets, the publish functions and the direct-insert
  tables, each with the file it was read from.
- The runtime publish path traced through the bundle workflow, the handler and
  the dataset dependency edges.
- A numbered list of defects, each with evidence.
- A proposed model for blank database to usable database, with the level of
  every dataset.

* Plan

1. Read what documents publishing, and say what the documentation claims.
2. Inventory the three flows: direct insert, DQ seed plus publish, runtime publish.
3. Test each dataset against the requirement that it is published at the right
   level.
4. Write the defects and the proposed model.
