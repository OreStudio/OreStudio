* Goal

The series page says no URI, an error, loading, a fixing, an unknown type, a series that is not listed, a series with an axis, or the values. The choice is a chain of conditions in the component, and the page has no render test because there is no DOM test library. A pure function that takes the query results and returns the state can be tested for each case.
