* Summary

The secrets an installation keeps for its own use, the consumers that may receive
them, and the record of who asked for what.

1 prototype answers to this group. It is a static page under =doc/prototypes/=,
opens with no build and no session, and reads mock data only. The table below
opens it and says what it argues.

[[file:../index.org][Prototypes]] is the top page and the only inventory.

* Adding a prototype

Create =doc/prototypes/vault/<name>/= with an =index.html=, and a
=prototype.css= and =prototype.js= when it needs them. Open the page with
the links table every prototype carries, and leave its review row at
=none=. Add a row to the table above, with the design note beside the
prototype when there is one. Stop there: the site build finds every
prototype under this tree, so no build file names it.
