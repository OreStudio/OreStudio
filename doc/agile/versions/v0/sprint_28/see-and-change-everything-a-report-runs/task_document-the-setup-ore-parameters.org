* Result

The 70 Setup, Logging and Markets parameters that are not engine settings have a label, a help line, a description, a default, a format and the release that introduced them. The texts come from the ORE user guide and the ORE source at tag v1.8.17.0. Nine names are in example files and no release reads them, and the text says so. =useAnalytics= is no longer read since 1.8.9.1. A generator writes the seed, and the gate =block-parameters-seed= compares the seed with the texts. The pgTAP key test now derives the XPath of a Logging and a Markets parameter.

The text of =buildFailedTrades= said No by default. The ORE application sets that default, and the library defaults to Yes. The text and the prototype now say both.
