#+description: The :has_batch_read: flag is inert. Twenty trading instrument models set it, and template_variables.org documents it as 'Repository exposes a batch read method', but no generator source and no template reads it. The batch read read_latest(context, <primary key vectors>) is declared in cpp_domain_type_repository.hpp.mustache and implemented in cpp_domain_type_repository.cpp.mustache unconditionally, with no guard. So the flag changes nothing, and it reads as if it did. Either delete the flag from the models and from template_variables.org, or give it a consumer. Found while scoping the composite family get and put in the atomise-the-convention pilot.
