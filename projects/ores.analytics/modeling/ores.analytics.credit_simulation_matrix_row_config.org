ORE lays a transition matrix out on a fixed rating scale: every document in
the corpus is 8x8 and names the same eight ratings in the same order. Because
the scale is a property of the domain rather than data a user enters, it is
encoded in the type rather than seeded as rows: one row per source rating,
with one probability column per target rating. A matrix is therefore eight
rows, and a row reads the way the matrix is written in the document.
