#+title: How do I run the crm_driver_pairs commands from the shell?
#+description: Every command the crm_driver_pairs submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:crm_driver_pairs:

This file documents the crm_driver_pairs resource at the shell, one section per command. Every command is a subcommand of =crm_driver_pairs=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: 2EE0F956-4491-5E00-A12C-C3B4D404DAC0
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
crm_driver_pairs list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =refdata.v1.crm_driver_pairs.list=.

#+name: crm_driver_pairs-list
#+begin_src ores-shell :tangle crm_driver_pairs-list.ores :exports none
crm_driver_pairs list --limit 1
#+end_src

** =get=
:PROPERTIES:
:ID: 01660170-D3A3-5306-AA9F-2E36855AE8E8
:END:

Reads the one row its key addresses. A key states every identifying column, so a partial key is refused rather than answered with an arbitrary row.


The command is shaped like this:

#+begin_example

** =add=
:PROPERTIES:
:ID: 1BC8D537-008B-554D-985D-3B184073DF49
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.


The command is shaped like this:

#+begin_example
crm_driver_pairs add <id> <config_id> <base_currency_code> <quote_currency_code> <enabled> <reason> <commentary>
#+end_example

It is addressed at =refdata.v1.crm_driver_pairs.put=.

#+name: crm_driver_pairs-add
#+begin_src ores-shell :tangle crm_driver_pairs-add.ores :exports none
crm_driver_pairs add 00000000-0000-0000-0000-000000000000 00000000-0000-0000-0000-000000000000 __none__ __none__ false system.new_record generated_script
#+end_src

** =set=
:PROPERTIES:
:ID: 4807C47D-A9D7-5FF0-A31A-AF9F687480EF
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved. Passing --version makes the write conditional on the version the caller last read.


The command is shaped like this:

#+begin_example
crm_driver_pairs set <id> <config_id> <base_currency_code> <quote_currency_code> <enabled> <reason> <commentary> [--version <n>]
#+end_example

It is addressed at =refdata.v1.crm_driver_pairs.put=.
