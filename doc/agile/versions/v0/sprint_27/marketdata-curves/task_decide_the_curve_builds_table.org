* Result

*Decision: no =curve_builds= table. The table that the journeys do earn is a publication record, and it waits for the publish operation.*

*What the evidence says.* Six journeys name a missing object: ask for a
publish, decide a publish, publish the approved set, withdraw or replace a
published curve, see who changed a curve, and watch a curve evolve. They name the same three gaps.
Nothing marks a candidate set, nothing marks a curve published, and nothing links
an approval request to a curve. Each journey asks for a *published state*
(=published_at=, =published_by=, the as-of published), a =superseded_by= link
and a detail keyed by the approval request. None of the six asks for a *build*
as a thing with its own state. The bootstrap, check, adjust and blueprint
journeys run on the series, the points and the annex, and none lists a
build header as missing.

*Why a build header adds nothing.* A build is the points one derivation wrote at
one reference date. The annex already carries the three facts that name it:
=derivation_config_id=, =derivation_config_version= and =source_as_of=. The
series and the reference date complete the key. A reader groups on that key.
The group has no state, so it needs no row.

*Why the published state cannot sit on the series or the points.* A series has
many publishes, withdrawals and replacements over time, and the trail must show
each one with an actor. One column on the series holds only the latest. A column
on the points writes to the hot hypertable for a cold fact. So the state needs
its own small bitemporal record.

*What that record is.* A publication, not a build: series, reference date,
state (candidate, published, withdrawn, superseded), =published_by=,
=published_at=, =superseded_by= and =request_id=. Its columns come from
journeys 9 to 12 and are listed in the story's decision. It is not added in
this story, because no approval kind, no publish operation and no consumer
exists to give the columns a test. A table with no reader repeats the mistake
sprint 25 made.

*Acceptance.* The decision carries its evidence (Measurements). The table is
not needed as a build, so the record says what carries the build record: the
annex plus the series and the reference date. The publication record is named
for the story that adds the publish operation.
