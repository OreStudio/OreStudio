One barrier of a product, keyed to the trade, the list that states it and
the barrier's ordinal in that list.

ORE states a barrier as a =BarrierData= block: a type, a style, a list of
levels and an optional rebate. Fifteen products state one, some state a
list of them, and a generic barrier option also states a transatlantic
barrier. Every one of them is a row here, so a product with one barrier
holds one row, a product with several holds several, and the type, style
and rebate belong to each barrier rather than to the product.

The levels are =instrument_barrier_level= rows: a single barrier states
one level and a double barrier states two.

** Custom repository methods

The trade read path fetches the instrument barriers of many instruments at
once, and no generated read covers that: the generated reads address one key
group at a time. The batch read below is one statement over the instrument
set.

*** read_by_instruments_batch
:PROPERTIES:
:ID: 46E1F8DD-2C20-44F5-A110-4A77EA0DD522
:END:

Reads every current instrument barrier of the given instruments, in one statement. An empty input
reads nothing.

#+begin_src cpp :name implementation :implements F2EB1914-5E94-42CA-9C77-46BDB364BF9E
std::vector<domain::instrument_barrier>
instrument_barrier_repository::read_by_instruments_batch(
    context ctx, const std::vector<std::string>& trade_ids) {
    if (trade_ids.empty())
        return {};
    static constexpr auto max = db_timestamp::max();
    const auto tid = ctx.tenant_id().to_string();
    const auto query = query_builder::read<std::vector<instrument_barrier_entity>> |
                       query_builder::where("tenant_id"_c == tid &&
                             "trade_id"_c.in(trade_ids) && "valid_to"_c == max) |
                       query_builder::order_by("trade_id"_c, "barrier_role"_c, "sequence_number"_c);
    return query_builder::execute_read_query<instrument_barrier_entity,
                                             domain::instrument_barrier>(
        ctx,
        query,
        [](const auto& entities) { return instrument_barrier_mapper::map(entities); },
        lg(),
        "Reading instrument barriers for multiple instruments.");
}
