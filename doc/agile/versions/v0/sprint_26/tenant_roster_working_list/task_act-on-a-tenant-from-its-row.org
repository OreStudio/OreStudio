* Acceptance

- Each roster row has an actions menu.
- *Resume setup* opens the tenant's provisioning run when that run is
  unfinished or failed, and is not offered otherwise.
- *Open* and *Retire or reset* are shown as not built yet, the way the shell
  marks a journey the tree has not built, rather than hidden or broken. *Open*
  is wired when [[id:45E4EB0A-73ED-4361-920F-8928AAE2D9AB][Show one tenant]]
  lands; *Retire or reset* waits for the capture
  [[id:8B276277-A49D-4813-A017-C0529C798DBB][Build the retire or reset tenant journey]].
- Every new behaviour is proved by a test, and the screen was read against the
  running deployment.

* Plan

Decision, 2026-10-02, the product owner's: build the menu now with *Resume
setup* working, and *Open* and *Retire or reset* marked as not built; wire
*Open* when the detail task lands. The retire or reset backend is mostly
missing (no suspend, terminate or purge subject), so it is a capture rather
than part of this task.

1. A menu per row, built from a =details= element so it opens without
   script and renders in the static web tests.
2. *Resume setup* links to =/tenants/runs/:id= when the run is not completed.
3. *Open* and *Retire or reset* render disabled with the shell's
   "Not built yet" words.
4. Tests for each item's state, then a live read.

* Result

Each roster row ends in an actions menu, built from a =details= element.
*Resume setup* links to =/tenants/runs/:id= when the tenant's run is not
completed, and is absent for a completed run or a tenant with none. *Open* and
*Retire or reset* show with =aria-disabled= and the shell's "Not built yet"
words. The summary carries the label "Actions for /name/" for screen readers.
The words are in English, French and Portuguese, and the journey
[[id:F14135EC-F136-4D93-B8A6-D4386FF20684][See the tenants]] names the menu.

Three new web tests prove the item states: 216 of 216 web tests pass and the
typecheck is clean. The rebuilt bundle served by the running deployment
carries the menu. The live roster holds no tenant with an unfinished run, so
the live read shows only the two not-built items; the *Resume setup* branch is
proved by the tests alone.
