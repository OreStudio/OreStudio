#+title: ores.refdata.configuration_document_messages
#+description: Codegen operation model for the configuration documents refdata owns: save, get and delete a curve configuration document. The FX convention projection stays here for the ORE boundary.
#+type: ores.codegen.operation
#+component: refdata
#+subcomponent: api
#+entity_singular: configuration_document
#+namespace: ores::refdata::messaging
#+brief: Refdata's ORE configuration documents as operations.
#+filetags: :model:operation:refdata:
#+created: 2026-10-04
#+updated: 2026-10-04

The configuration documents refdata owns, as operations: the curve
configuration. Another service reaches it only through these, never through
refdata's tables. The handler stamps the session's party on every row it
stores.

The FX convention stays in this model because the ORE boundary projects it
from a currency pair, that pair's convention and its calendars. It is not a
message, and no family of conventions has a type here.
