The fail-fast configuration of the [[id:0442FD13-1833-427F-B6CA-C4B5877C452B][identity workflow]]. The =ores-shell= block
below is tangled into the runnable script library as =identity_fail_fast.ores=.

* Question

How do I run a workflow whose only step fails?

* Answer

The single step reports =fail= and declares no compensation, so there is nothing to unwind. The engine moves the instance through =compensating= and settles it at =compensated=, which =--expect-state= asserts.

#+name: identity-fail-fast
#+begin_src ores-shell :exports none
workflow start identity_workflow '{"steps":[{"name":"boom","behaviour":"fail"}]}' --instance-id 10000000-0000-4000-8000-000000000004
workflow wait 10000000-0000-4000-8000-000000000004 --timeout 60 --expect-state compensated
#+end_src

=workflow wait= fails unless the instance reaches the state named, so this
script fails when the path it covers does nothing.
