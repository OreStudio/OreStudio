* Goal

A person who watches the compute grid sees the load of the whole grid, including the jobs of every tenant, and can follow a report run from its trigger to its compute result. Today the fleet row of the system tenant counts the work of every tenant through an interim change to ores_compute_grid_stats_fn. The installation ledger that the journey Watch the grid names replaces that change.

* Acceptance

- The system tenant reads the load, the queue and the outcomes of all tenants from the installation ledger, not from a function that reads across tenants.
- A tenant administrator sees the hosts of the grid and the tenant's own jobs on the same screen.
- A report run shows in the grid as a batch with its workunit, host and result, linked to the report instance.
- The interim change in ores_compute_grid_stats_fn is removed.
