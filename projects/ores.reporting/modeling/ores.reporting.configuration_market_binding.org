One =Parameter= of the =Markets= block in a run document: a market role, and the market configuration the run binds to it. The block belongs to the configuration that describes the run, so reports that share a configuration share its market roles. The role is a free string in ORE's schema, and the value names a configuration set built in =todaysmarket.xml=, which =ores.analytics= owns. This table holds the binding, not the configuration it names.
