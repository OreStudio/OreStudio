* Result

Twenty-one design notes now sit beside the market data prototypes, one per
prototype, following =doc/prototypes/entry/registration-door.org=. Each opens
with the links table, then argues the prototype: the question it answers, its
variants, its states, what is fake, where the code lives, the verdict and what
it leaves open. The variants and states are the prototype's own — read from the
query parameters its script switches on, and named with its words — so the note
describes the page that is there rather than one imagined for it.

The group page's first cell links each note. Before this, a reader who followed
a prototype from the table landed on the prototype itself and never saw the
argument, which lived in the cell beside it.

The convention said a note was optional: "A design note, where one exists" and
"To keep a design note". That wording is what let the largest group in the tree
go entirely without one, and nothing checked for it. The top page now says every
prototype has a note and the row links it; the check that refuses a prototype
without one belongs to the follow-up task, along with the eighteen prototypes in
the other eight groups that still have none.
