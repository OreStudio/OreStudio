* Acceptance

- One constructor per routed commodity code, fixing the trade type code.
- Twelve shape terms structs, and no terms struct carries a column another shape states.
- The writer selects a constructor and no longer copies the bag field by field.
- A provisioning run books the same commodity population as before, and the suites are green.

* Plan

Twelve shapes, ten terms structs and twenty-five constructors: a terms struct
per distinct set of columns, a constructor per routed code, each stamping its
own trade type. Products that state identical columns share terms and still
get their own constructor, because the table cannot tell them apart.

The writer keeps the choice of constructor, because something has to read the
recorded trade type, and loses the field-by-field copy.

* Result

Every routed commodity code is constructed by a function that names it. The
writer no longer copies the bag into the row: it builds the terms its shape
states, calls the constructor, and stamps the audit columns.

The product code is the only thing several of these products can state. Seven
codes share the option shape and three share the basket option shape, so their
rows differ by =trade_type_code= alone; the table has no column that would
distinguish a rainbow option from a basket option, and no child table for a
basket's members. That is recorded as the family's next problem rather than
worked around.

* What the population proves, and what it does not

The claim that a run books the same population is true and vacuous: the ACME
profile seeds no commodity generation config and the tenant has no commodity
book, so the commodity arm is never reached. Measured at =c81da34a1e=: zero
commodity rows and zero commodity configs.

So the evidence for this change is the suites, measured on this branch at
=8322b1eb19=: =ores.trading.api.tests= at 462 assertions in 124 test cases
and =ores.synthetic.core.tests= at 1733 assertions in 78 -- twenty-five
constructors each
asserting the trade type it stamps, the vocabulary refusals, and a zero
quantity refused on every shape -- plus the writer's dispatch, which the
compiler proves total over the type strings it handles. A provisioning run
cannot prove it until commodities have a book and a config, which is its own
task.
