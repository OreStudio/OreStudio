* Notes

Both templates now write the include only when the model has no generated wire
codec. The cache needed it because the reflector's decode needs it for uuid
members, and an entity with a generated codec never reaches the reflector.

=compass codegen regenerate --all= on the two facets also rewrote three refdata
eventing tests that drift from their models on main
(=base_correlation_config=, =inflation_cap_floor_volatility_config=,
=yield_volatility_config=). They keep main's body and lose only the include, so
this change does not carry that drift. The drift has its own inbox capture.

The two failing suites, =ores.marketdata.core.tests= and =ores.web.tests=, fail
on main for causes with their own captures.
