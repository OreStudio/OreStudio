Each entry says what the codec or check is for, the rules it reports under, and where it is defined: a check document of this repository, linked, or compass itself. The page is generated by compass's check_inventory codec from the codecs, the check documents and the configuration of every run. Edit those and run compass generate, never the page; compass check reports the page when it no longer says what runs.
