* Goal

A new system fetches public fixings as soon as it is set up: the administrator accepts every public source's terms in one step in the first run, and the shell's bootstrap setup accepts them by default.

* Acceptance

- marketdata.v1.ops accepts a list of provider codes with the versions read and answers, per provider, accepted or refused with the reason; each acceptance records the digest, the session's account and the server's time, as the single accept does.
- The first-run public sources step has an accept-all tick box that accepts every listed provider at the version shown; a provider can still be declined on its own card.
- bootstrap setup accepts every public provider's terms after it signs in as the administrator and prints one line per provider; --no-accept-terms skips it.
- A shell command accepts all public terms on a system already set up.
- No seed or profile step writes an acceptance.

* Notes

- Why: the adapter fetches no public provider until its terms are accepted
  (since 10-28). Nothing in setup accepts them, so after a database recreate
  every feed kept its fixed level until someone accepted the terms on the
  Public rates page. The earlier tests had accepted them by hand.
- The acceptance stays with the signed-in system administrator rather than a
  tenant provisioning step: terms belong to the system, and the record must
  name a real account.
