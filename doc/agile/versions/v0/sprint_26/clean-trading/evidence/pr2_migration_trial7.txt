PR 2, the seventh migration trial: the handler migrates clean

Measured 2026-09-26, branch feature/sync-trading-drift, on the tree the
first regeneration produced.

What the sixth trial left
-------------------------
It reached six errors in three groups: four over-rewritten response
checks for the four families with no model, one enum-to-text conversion
that did not fire, and one protocol gap that became decision D8.

The enum arm
------------
The codemod's expansion tested

    elif "domain::" in types.get(field, "") and "string" not in wire_type:

That is the inverse of the intent. For the one member it had to convert,
trade_write.product_type, the wire type is std::string, so the test was
false and no conversion was emitted. The corrected test reads

    elif "domain::" in types.get(field, "") and "string" in wire_type:

and emits ores::trading::domain::to_string(...). The condition now fires
exactly when a domain member that names an enumeration reaches a wire
member that is text, which is the shape the generator's reader mirrors.

D8 applied
----------
The handler records the external identifier at the save site:

    result.saved_trade_external_ids.push_back(ext_id);

and the rollback builds one removal per identifier:

    ores::trading::messaging::delete_many_trades_request del_req;
    for (const auto& saved_id : req.saved_trade_external_ids) {
        ores::trading::messaging::trade_removal removal;
        removal.key.external_id = saved_id;
        del_req.removals.push_back(std::move(removal));
    }

The field carries a key and not a uuid, so the ores.ore model renames it
from saved_trade_ids to saved_trade_external_ids, with a comment stating
which key it holds. Regenerated output:

    projects/ores.codegen/venv/bin/python \
        projects/ores.codegen/scripts/check_component_drift.py --component ore

The generated C++ and TypeScript follow the model, and the two
occurrences in the hand-drawn projects/ores.ore/api/modeling/ores.ore.api.puml
are corrected by hand. No trading model and no trading protocol change.
