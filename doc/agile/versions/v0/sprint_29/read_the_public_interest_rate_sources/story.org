* Goal

The ECB Data Portal, FRED, the Bank of England and the US Treasury deliver their rates and curves as end-of-day feeds, so the synthetic IR feeds have a public seed.

* Acceptance

- Each supplier has an adapter, a session and its feeds.
- Rates are one value a day and curves are pillared items, catalogued and mapped.
- Values arrive as durable fixings and a feed can start from the latest one.

* Decisions

- One session per supplier; the supplier and the publisher coincide for the direct APIs.
- The service is end_of_day for all four at first.
- A curve is a set of pillared items, not one item with an array.
