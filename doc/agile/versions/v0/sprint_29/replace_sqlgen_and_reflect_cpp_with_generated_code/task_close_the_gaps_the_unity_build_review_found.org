* Acceptance

- =check_unity_collisions.py= groups sources by target, not by directory, so
  two files of one target in different directories are checked together.
- The exclusion the collision check picks for a group stays the same when a
  new file sorts before the others.
- =--record= reads relative paths in a compiler log as well as absolute ones.
- =check_unique_type_names.py= reads every namespace of a header, nested and
  sibling, and covers the test headers (=tests/*.hpp=).
- Both scripts have a unit test fixture.
- =cmake_minimum_required= is 3.18 or newer, or the exclusions say why not.
- =compass lint= lints every file when git is not available, instead of
  crashing.
- The own-or-system RLS template comment reads: every session reads its own
  rows and the system tenant's rows.
