* Result

The refusal, the parameter reader, the trims, the code and reason checks and the
outcome mapping live once in =ores.http.api/net/record_routes=, exported from
the shared library, with eight test cases of their own. The 26 refdata record
units call them, and keep only the call, the rows and the bodies. The api and
refdata suites pass, including the 175 web route cases.
