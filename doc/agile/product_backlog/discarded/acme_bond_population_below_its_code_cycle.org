* What

A fresh Acme setup on main ed926fbead ends generate_trades with warnings: "The population of
1000 trades gives 'bond' 40 trades, and its 4 configs state at least one trade per code it
cycles, which is 44. A total of 1100 is the smallest that holds them." The population knobs, or
the bond share of them, should grow with the bond codes the planner cycles, so a fresh setup
ends green again.

* Why

The bond planner's code cycle grew when the bond future option and its kin joined the
catalogue, but the default population did not. The step still writes the trades, so the tenant
is usable; the warning is a false alarm on every fresh setup, which hides a real one. Found on
the ladder task's provisioning run; the trade population belongs to the story "Hold every
product type the engine supports".
