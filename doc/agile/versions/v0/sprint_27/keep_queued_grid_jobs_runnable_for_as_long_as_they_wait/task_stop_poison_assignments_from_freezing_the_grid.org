* Goal

A late, repeated or stale assignment costs one cheap report and rewrites nothing. This task holds the two changes of the claim design that stay right in every design: a node skips an assignment whose storage token has ended, and the submit never rewrites a retired or a done result.

* Acceptance

- A wrapper does not start an assignment whose storage token has ended. It reports one client error with a message that names the cause, and takes the next assignment.
- A node that cannot read the expiry starts the job and lets the storage service decide.
- A submit for a retired result changes nothing, and the reply says it succeeded.
- A second submit for a done result changes nothing, and the reply says it succeeded.
- The decisions are unit tests that need no database.
