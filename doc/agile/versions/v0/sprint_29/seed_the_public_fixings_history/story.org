* Goal

Every environment holds years of daily public fixings without fetching them from the publishers' API. A static DQ snapshot carries the history and the adapter fills only the gap from the latest stored fixing to today. The calibrations that need depth, the GARCH fit of FX spot and the derived FX volatility quotes of [[id:3D2A2BD4-4126-4E54-9046-A9E00966D898][Support volatility surfaces]], read it; without it they work from the adapter's shorter window, with their priors dominating and weak butterflies.

* Acceptance

- Every environment loads years of daily fixings for each catalogued provider and pair from a static DQ snapshot.
- The public sources adapter fetches only the days from the latest stored fixing to today.
- Each provider in the snapshot allows redistribution; any other stays adapter-only.
