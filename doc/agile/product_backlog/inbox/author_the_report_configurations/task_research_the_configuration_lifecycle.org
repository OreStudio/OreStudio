* Goal

Decide how a configuration moves from an edit to a version in force. Settled so far: a configuration has one open working copy. A person saves many versions of it, then proposes the working copy for review as one whole version. A reviewer approves or rejects the whole version. The version in force stays in force until the approval. Open: who may hold the working copy, what a saved version is called, how a rejected version returns, how a new version reaches the reports that bind the configuration, whether a version can be withdrawn, and how this fits the other four configuration types. The output is a design note and a revised journey, not code.
