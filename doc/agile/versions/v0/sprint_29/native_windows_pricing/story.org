* Acceptance

- Build ORE 1.8.17.0 from the pinned OreStudio Engine revision and bundle ore.exe, runtime DLLs and an x64-windows manifest.
- Demonstrate native worker pricing and preserve existing Linux packages.
- Verify current-main account and credential preservation with strict schema matching, documenting untested upgrade paths.

* Decisions

- Use the existing OreStudio/Engine fork at the same revision as the bundled Linux engine; no engine source changes or additional fork.
- Keep the package contract common across platforms and add the Windows package beside the Linux packages.
- Run unchanged Unix SQL through an explicit container adapter on Windows; keep shared SQL and password verification identical to upstream.
- Keep the upstream Windows CRLF seed failure outside this PR, as requested by the owner.

* Out of scope

- Migrating the older installed database to the current-main schema.
- Fixing the upstream Windows nightly database seed line-ending failure.
- Claiming completion of the full application or fleet validation gate.
