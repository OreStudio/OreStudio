* Acceptance

- Preview returns every proposed write with its part and any refusal, and writes nothing.
- Raise runs each write in a rolled-back savepoint and returns its refusal before anyone waits.
- The last approval applies every line in one transaction, and a stale line fails the whole request into apply_failed with a reason.
- Apply converges after a missed event or a service restart.
