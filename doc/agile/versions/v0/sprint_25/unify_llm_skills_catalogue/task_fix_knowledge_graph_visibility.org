* Goal

The knowledge index carries eight id references that do not resolve, and all eight target files exist on disk. They are the entire external knowledge cluster: QuantLib, the Open Source Risk Engine, FpML, coding schemes, standing settlement instructions, PostgreSQL row-level security, and shared-library symbol visibility. That cluster is invisible to compass search and to graph traversal, so an agent asking what we know about QuantLib is told nothing while the page sits there. Diagnose the cause, which is either a stale index or a subtree the indexer never walks, fix it, then add the invariant to the audit channel so nobody has to notice by hand again. Domain grounding cannot become an obligation until the graph it reads from is trustworthy.
