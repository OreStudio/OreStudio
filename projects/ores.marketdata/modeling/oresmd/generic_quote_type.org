* No quote types

This class carries no quote type, and therefore no quote key, so no
=* Quote types= table follows and no =quote_type= field is generated.

ORE resolves the =GENERIC-= prefix in its own parser. The name is the whole of the
index's identity: a generic index is whatever its producer called it, the corpus
carries no other key for either series, and ORE has no market-data key for one. The
corpus carries two of them, on fixing rows only: =GENERIC-JuniorNote= in
=Legacy/Example_46/Input/fixings.txt= and =GENERIC-PortfolioBasket#1= in
=Products/Input/fixings.csv=.

** The =GENERIC-MD/= sibling is a market-data key, not an index name

=GENERIC-MD/<TYPE>/<METRIC>/...= is the market-data key form that an oresmd URI
replaces, and =Products/Input/fixings.csv= puts two of them in a fixing column:
=GENERIC-MD/EQUITY_OPTION/PRICE/RIC:.SPX/USD/2025-10-03/3300/C= and its 3400
sibling, which are SPX call prices rather than fixings. An index name carries no
slash, because the slash is the key grammar's own separator, so the index-name
projection refuses any name that has one and these two stay out of the fixing
space.

* Enum brief

* Identifier brief

A fully-resolved oresmd identifier for a generic index (asset_class=generic).

=name= is the index name ORE writes after the =GENERIC-= prefix, upper-cased the
way every other class's entity field is. The character set is ORE's, not this
URI's: =PortfolioBasket#1= carries a =#=, which the URI writes percent-encoded
and the parser decodes, so the name survives the trip through a URI unchanged.

=name_spelling= is the token as the corpus wrote it, kept beside the upper-cased
name when the two differ. Neither corpus name arrives upper-cased
(=GENERIC-JuniorNote=, =GENERIC-PortfolioBasket#1=), so this field is what lets
the projection write the index name back in the case ORE wrote it. It follows
=source_spelling=: the identifier holds the normalised token, and the name keeps
the spelling that arrived.

* Requirement brief

A logical, possibly-partial oresmd requirement for a generic index.
