* Summary

=ores.shell.storage= is the adapter part that projects object storage onto the
shell's REPL. It holds the command unit generated from
[[id:D469834F-DB7C-4486-B43F-CBD984744C36][ores.storage.objects]], so the verbs
are the operation model's verbs and not a hand-written parallel surface.

The unit is the raw one: every verb takes a bucket, a key and a local path, so a
caller that only wants bytes somewhere does not have to learn a domain verb.
The consumer verbs that wrap storage belatedly, such as the compute package
publisher, live with their own domains.

* Inputs

- The operation model the unit is generated from, and the live session.

* Outputs

- A =storage= submenu whose verbs reach the object operation set.

* Entry points

- =include/ores.shell/app/commands/storage/objects_operations_commands.hpp= —
  the =storage= submenu, generated from the operation model.
- =src/app/commands/storage/objects_operations_commands.cpp= — the generated
  unit; =application='s =storage_commands= aggregator is the hand-written list
  that calls it.
