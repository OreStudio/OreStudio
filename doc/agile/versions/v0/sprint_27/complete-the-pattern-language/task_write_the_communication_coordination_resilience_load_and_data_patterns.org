* Result

Fifteen pattern pages are written, with sixteen diagrams: Request-Reply, Claim
Check and Competing Consumers in communication; Saga, Process Manager and
Idempotent Receiver in coordination; Timeout, Retry and Bulkhead in resilience;
Queue-Based Load Leveling, Throttling and Fair Share in load; Database per
Service and Cache-Aside in data; and Log Aggregation in observability. Every
hub row links its page.

Eighteen use pages now name their patterns, generated from the same table: the
workflow engine pages, the three workflow pages, the reporting design, the IAM
run grants page, the compute, storage, scheduler and service anatomy pages, the
memory on table ownership and the telemetry logs journey. The workflow pages'
plain-text placeholders for the coordination patterns are now links.

Circuit Breaker was dropped: the hub lists a pattern only when ORE Studio uses it
or a design has chosen it, and neither holds. Cache-Aside records that the
entity-mirror caches are a different technique, filled from change events.
