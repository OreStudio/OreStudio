* What

Move the Journey screen anatomy section of UX Language to the Journey runtime page. UX Language says a journey is one screen with a rail of steps, while the entity screen specification says a journey is a design document and a screen is never a journey copied step by step, with a wizard as the exception. The owner's pipeline decision follows the entity specification, so the rail belongs with the runtime and is named a wizard. Found by the audit of the UX standards.
