* Acceptance

- The threshold is configuration per instrument kind, with hedgr's fx and ir
  values as the starting point.
- Every value block carries as_of, age_seconds and stale.
- age_seconds is max(0, server_now - as_of) in whole seconds.
- stale is the server's verdict and no client recomputes it.

* Notes

- The call-site half is in: the catalogue, the ladder, the montage and the
  surface all ask =staleness_policy=, and no read carries a literal hour.
- The threshold is still one number for the whole service. It cannot move into
  the options struct as it stands: =run_host_async= parses the configuration and
  constructs the service in one call, so an option would be inert. The variable
  is the honest interim.
- A publication with no instant is stale: the read asks =is_stale= with no
  instant, which the policy answers with stale.
