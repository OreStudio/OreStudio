* Goal

A person reads the IR calibration coverage at a glance: one line per curve with its role, tenor, discount curve, publish time and state, and the class policy in one compact card; and the state each row shows is what the calibration found.

* Acceptance

- The coverage table has one row per curve; the currency and its source show once per currency.
- The window shows only for a feed that overrides the policy.
- The class policy is a compact card: window, inverse rule, fallback, and the source order as numbered chips.
- The IR feeds reach the calibration, so a currency with a feed and a published curve is not shown as having no feed.
