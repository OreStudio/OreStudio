#+created: 2026-09-22
#+updated: 2026-09-22

Every field that changed between two versions, in the order the engine found
them. It is never stored: it is a member of a history version and reaches a
client inside a history response.

* Flags
:PROPERTIES:
:schema:          public
:product:         ores
:component:       diff
:no_primary_key:  true
:profile:         table-less-record
:END:

=No primary key=: a result is a value the engine returns, not a row anything
addresses. Saying so is what tells the loader this is a record that is carried
rather than stored.

The profile supplies =:no_audit_columns:=, which keeps the version column, the
audit tail and the transaction timestamp off the struct.

* C++

** Flags
:PROPERTIES:
:no_subcomponent: true
:END:

=No sub-component=: =ores.diff= keeps its headers at its own include root, so
there is no directory between the component and =domain/= for this model to
name.

** Domain includes

#+begin_src cpp :name includes
#include "ores.diff/domain/diff_entry.hpp"
#include <vector>
#+end_src

* Columns

** entries
:PROPERTIES:
:type:     text
:cpp_type: std::vector<ores::diff::domain::diff_entry>
:END:

One entry per changed, added or removed field, in the order the engine found
them. Empty when the two versions are identical, which is how a caller tells
"nothing changed" from "nothing compared".
