One row per determination period of a worst-of basket swap, keyed to the
trade and the period's ordinal within the document.

ORE states the same worst-of basket swap on equities, FX and commodities, and
nothing in a period belongs to one of them, so the families share this table.

The levels are a list. A list is rows of a child table rather than an encoded
string, so the periods live here and not in the =knock_out_levels_json= and
=fixed_trigger_levels_json= columns that used to hold them. Both columns are
retired with this table.

The ORE document states =KnockOutLevels= and =FixedTriggerLevels= as two
unbounded lists that run beside the determination schedule, one entry per
date. They are therefore per period and not per constituent, which is why
they are not rows of a basket constituent: a basket of two underlyings
over four dates states two names and four levels.

The trade is the key. A period is reached through the trade that owns it and
by nothing else, so the pair of =trade_id= and =sequence_number= is the
primary key.

** Custom repository methods

The trade read path fetches the periods of many worst-of basket swaps at once
when it assembles the export payload, and no generated read covers that:
=read_latest(context, ids)= filters on the child's own key and
=read_latest_by_trade_id= reads one instrument at a time. The batch read
below is one statement over the instrument set.

*** read_by_instruments_batch
:PROPERTIES:
:ID: 8F1C3D42-6B5A-4E79-9C08-D1E2F3A4B5C6
:END:

Reads every current period of the given instruments, ordered by instrument
and ordinal, in one statement. An empty input reads nothing.

#+begin_src cpp :name implementation :implements F2EB1914-5E94-42CA-9C77-46BDB364BF9E
std::vector<domain::basket_swap_period>
basket_swap_period_repository::read_by_instruments_batch(
    context ctx, const std::vector<std::string>& trade_ids) {
    if (trade_ids.empty())
        return {};
    static constexpr auto max = db_timestamp::max();
    const auto tid = ctx.tenant_id().to_string();
    const auto query = query_builder::read<std::vector<basket_swap_period_entity>> |
                       query_builder::where("tenant_id"_c == tid && "trade_id"_c.in(trade_ids) &&
                                            "valid_to"_c == max) |
                       query_builder::order_by("trade_id"_c, "sequence_number"_c);
    return query_builder::execute_read_query<basket_swap_period_entity,
                                             domain::basket_swap_period>(
        ctx,
        query,
        [](const auto& entities) { return basket_swap_period_mapper::map(entities); },
        lg(),
        "Reading basket swap periods for multiple instruments.");
}
