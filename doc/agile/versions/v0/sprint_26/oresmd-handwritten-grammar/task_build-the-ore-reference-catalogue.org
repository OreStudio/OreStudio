* Goal

A checked-in fixture states, for every ORE key form and every distinct corpus
key, the fields ORE's own =parseMarketDatum= assigns. The new codec is tested
against it. Without it, every round trip compares text with text, and a token
in the wrong field passes.

* Acceptance

- An offline harness, linked against the local =libOREData.so=, reads each key and writes the instrument type, the quote type and every field the =MarketDatum= subclass exposes.
- The input holds every form documented in =OREData/ored/marketdata/marketdatumparser.cpp=, with at least one key per form, plus every distinct key in the corpus market payloads.
- The input also holds keys that ORE rejects, each with ORE's error.
- The fixture, the input list and the harness source are checked in. A recipe states how to rebuild the fixture against a new ORE release.
- The ORE version the fixture came from is recorded in the fixture.
- Before the old grammar is retired, a test over the catalogue measures it through the stored URI path and records the baseline the review reported: 4,269 corpus keys whose URI the parser rejects and 7,254 that do not read back. The review's figures then come from a test in the tree, not from a throwaway probe.

* Notes

Why not boost serialization: ORE gives every datum class a boost =serialize=
member, but instantiates it for binary archives only, writes no field names, and
skips fields (=CdsQuote= omits its doc clause and running spread). The harness
calls the inspectors instead; =generate_dump.py= reads them from
=marketdatum.hpp=, so a class ORE adds is dumped without editing the harness.

The as-of date matters: ORE refuses a dated forward or option whose expiry falls
before it, so a 2025 as-of refused 39,251 corpus keys. The harness uses
QuantLib's earliest date. ORE still turns an equity forward or dividend given as
a tenor into a date relative to it.

Corrections to the review this catalogue makes possible:

- Five of the 40 hand-written sample keys in the review are keys ORE refuses
  (=PAYER= is not a protection side, in two keys; =UNIT= is not a time unit; an IR swap
  cannot mix a period start with a date end, and the calendar spread option
  takes =RATE_NVOL= only). The figure "oresmd names 17 of 40 documented forms"
  is superseded by this catalogue's 89 of 122.
- ORE's names for the segments oresmd calls =settle= (IR swap and MM) and
  =shift= / =strip= (cap/floor) are =fwdStart=, and =atm= / =relative=. The
  extra swaption segment oresmd reads as an index is ORE's free-text
  =quoteTag=, and the seventh basis swap segment is an identifier ORE ignores.
  The typed model should take ORE's meanings.
