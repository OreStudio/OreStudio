A sensitivity template key spells how its products are priced, in one of the five
forms ORE defines: =Analytical=, =Semianalytical=, =FD=, =MC= and =Trade=. The key
carries the token -- =IR_FD= -- and a person reads the name beside it.

The method decides whether a template has an asset class at all. Four of the five
are a way of pricing a class of product, so a template that states one states the
class too. =Trade= is the exception: a trade-level template is the one ORE defines
without a class, because the sensitivities come from the trade itself rather than
from shifting a class of market data. =needs_asset_class= states that, and the
screen reads it rather than repeating the exception.

The methods are seeded for the system tenant and read by every tenant, so a
template that names a method ORE does not have is refused.

** needs_asset_class
:PROPERTIES:
:type:         boolean
:cpp_type:     bool
:nullable:     false
:default:      true
:END:

Whether a template that states this method also states an asset class.

Four of the five methods price a class of product, so their templates state the
class. The trade-level method is the one ORE defines without a class, so it is the
one row that states false.

#+begin_src cpp :name generator
[&r]{ return r.code != std::string("Trade"); }()
#+end_src
