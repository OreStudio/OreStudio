* Goal

Three kinds of codegen drift exist and only one is enforced. Template drift is guarded in CI by template-drift.yml. Artefact drift, where a generated file was hand-edited, is detected by check_component_drift.py, which works and which no workflow invokes; worse, the nightly-includes workflow raises pull requests whose body tells the reader that hand-edited generated output would fail that check. That claim is false today. Model drift, where an entity's features no longer match the profile it is bound to, has no checker at all. These checks are the genuinely independent verification the architecture argues we should route to first: mechanical, falsifiable and indifferent to how convincing an agent's reasoning was. Two of the three are routed nowhere.
