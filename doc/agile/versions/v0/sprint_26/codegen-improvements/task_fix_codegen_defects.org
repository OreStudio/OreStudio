* Acceptance

- Each defect is recorded with the command or recipe that shows it, and with the file and line of its cause.
- Each fix changes a template, a loader or a script, and not the generated output.
- Each fix carries a regression test that fails before the fix and passes after it.
- The affected components are regenerated, and the drift gate passes with each of them listed.

* Plan

Work the defects in the order the clean-up passes find them. Each one is one
unit: record it in the register below with the evidence that shows it, fix it
at the source, add the regression test, regenerate the affected components,
run the drift gate, and commit.

The branch accumulates the fixes and is rebased onto main as needed. Nothing
merges until every component is clean, so a fix that would change generated
output across components does not have to land early to be correct.

* Notes

*Finding.* A scaffold artefact is emitted once and is then unreachable: the
facet is disabled, the opt-in line is gone, and the drift gate covers
regeneration, which never produces it. A stale one therefore lives forever
with nothing to correct or detect it. Adding the opt-in back and running
=compass codegen generate --address ores.cpp.scaffold= regenerates the
umbrella header correctly, but it also emits three placeholder files
(=domain/stub.hpp=, =src/domain/stub.cpp=, =tests/stub_tests.cpp=) that must
then be deleted, which is why the repair is not something to run routinely.

*Open decision.* Two repairs, with different outcomes:

- Refresh the comment from the model's =#+description=, by regenerating. The
  text becomes "Domain types and NATS protocol schemas for the analytics
  component." The stale prose ("generators, messaging protocols and
  eventing...") exists nowhere in the tree and would be dropped.
- Rewrap the existing comment, joining its prose into one line so
  clang-format lays it out at 100 with prefixes. The text stays as it is,
  stale though it is.

Either way the class-level gap stays open until a scaffold artefact has a
regeneration and a gate.
