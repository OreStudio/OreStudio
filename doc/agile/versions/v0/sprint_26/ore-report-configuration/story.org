* Goal

A report definition's configuration is a set of strongly typed entities rather than a flat row of switches, and every entity in the ORE configuration vocabulary is identified, owned, and reachable from the definition.

* Acceptance

- Every entity in the seventeen ORE configuration documents is identified and mapped to an owning component.
- A report definition reaches its configuration through typed entities and foreign keys, never through a flat table of switches or an XML or JSON blob.
- A new kind of report adds a workflow and a parameter block, not a column on the report definition.
