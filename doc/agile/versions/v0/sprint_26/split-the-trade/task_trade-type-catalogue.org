* Goal

One catalogue decides where every trade type lives: the instrument tables' trade_type checks and the export handler's routing are generated from it, and no table lists codes by hand.

* Acceptance

- The trade-type catalogue is a table in the trade type model, and its seed script is generated from it.
- Each instrument table's trade_type check is generated from the codes the catalogue routes to it; the lists are disjoint.
- The export handler routes a trade to its instrument table through generated code, not hand-written conditions.
- Where routing and tables disagree today, the catalogue settles it, following where the ORE importer writes each type.
- Build, ctest, pgTAP and the local check set pass.

* Plan

- A new model type, =ores.codegen.trade_type_catalogue=, following the
  asset class catalogue: =ores.trading.trade_type_catalogue= holds one row per
  trade type with its seed columns and the instrument entity that holds it.
  Two archetypes render the trade types seed and =trade_type_routing.hpp=
  (=instrument_table= and =instrument_table_for=).
- An instrument model states =:routed_by:= and =:routed_column:=; the
  generator adds the check listing the codes routed to it. The 29 instrument
  models drop their hand-written lists; the risk participation table has no
  trade type column, so it is routed but not checked.
- The export handler buckets trades by =instrument_table_for= instead of
  hand-written conditions on product type and code.
- The wide trade's 121-code list becomes a check against the trade type
  catalogue, as the anchor's is.
- Where today's routing and tables disagreed, the catalogue follows where the
  ORE importer writes each type: =EquityOutperformanceOption= joins the equity
  option table's list; =EquityOptionPosition= is routed to the equity position
  table; =TotalReturnSwap= and =ContractForDifference= are routed to, and
  accepted by, the composite table; =BondFutureOption= and
  =EuropeanOptionBarrier=, which nothing imports, are routed nowhere. The ten
  tables that accepted all 121 codes now accept only their own.
