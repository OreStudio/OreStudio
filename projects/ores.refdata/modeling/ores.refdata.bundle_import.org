A bundle is applied in one =unit_of_work=, and the messages that
carry it cannot hold the whole bundle: a message carrying every family is the
aggregate that fails on MSVC. The import is the row the staging messages hang
off instead. It records that a bundle is being staged, who owns it, how many
families were promised, and when an abandoned session stops waiting.

The caller mints =id=, so a repeated begin with a known id returns the import
that already exists rather than opening a second one. The service stamps
=party_id=, =state= and =expires_at= from the session it runs in.

Nothing in this table is visible to a reader of the live tables
until a commit applies the staged rows.

* Columns

** id
:PROPERTIES:
:type:        uuid
:cpp_type:    boost::uuids::uuid
:primary_key: true
:nullable:    false
:END:

The import's identity. The caller supplies it, so a retried begin names the
same import rather than opening a second one.

** party_id
:PROPERTIES:
:type:         uuid
:cpp_type:     boost::uuids::uuid
:nullable:     false
:server_owned: true
:END:

The party the staged bundle belongs to. The service stamps it from the
session, so a caller never states it. Row level security confines the import
to that party.

** source
:PROPERTIES:
:type:     text
:cpp_type: std::optional<std::string>
:nullable: true
:END:

A short description of where the bundle came from, such as the file name the
caller loaded it from. Nullable, because a caller that imports from a stream
has no name to give.

#+begin_src cpp :name generator
std::nullopt
#+end_src

** state
:PROPERTIES:
:type:                text
:cpp_type:            std::string
:nullable:            false
:default:             'staging'
:no_generator_suffix: true
:END:

Where the import stands. A begun import is =staging= and a commit that applied
every family marks it =applied=. Those are the two states the service writes.
The column permits =failed= and =expired=, and nothing sets either yet, so a
failed commit leaves its import =staging= for a retry.

#+begin_src cpp :name generator
std::string("staging")
#+end_src

** families_expected
:PROPERTIES:
:type:     integer
:cpp_type: std::optional<int>
:nullable: true
:END:

How many families the caller promised in the begin. Nullable, because a
caller that does not know the count states none. Nothing reads it yet, so a
commit accepts a bundle that carries fewer families than were promised.

#+begin_src cpp :name generator
std::nullopt
#+end_src

** expires_at
:PROPERTIES:
:type:     timestamp with time zone
:cpp_type: std::chrono::system_clock::time_point
:nullable: false
:END:

When an uncommitted import stops waiting. A sweep would mark the row =expired=
and release its staged items after this instant, and no sweep exists yet, so a
staging import waits indefinitely.
