#+title: How do I run the regulatory_book_types commands from the shell?
#+description: Every command the regulatory_book_types submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:regulatory_book_types:

This file documents the regulatory_book_types resource at the shell, one section per command. Every command is a subcommand of =regulatory_book_types=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: A037799F-9FC4-52FE-B69E-D376F3848FB3
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
regulatory_book_types list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =refdata.v1.regulatory_book_types.list=.

#+name: regulatory_book_types-list
#+begin_src ores-shell :tangle regulatory_book_types-list.ores :exports none
regulatory_book_types list --limit 1
#+end_src

** =get=
:PROPERTIES:
:ID: E506360B-EBE5-5CA5-982D-DD790B5CF184
:END:

Reads the one row its key addresses. A key states every identifying column, so a partial key is refused rather than answered with an arbitrary row.


The command is shaped like this:

It is addressed at =refdata.v1.regulatory_book_types.get=.

#+name: regulatory_book_types-get
#+begin_src ores-shell :tangle regulatory_book_types-get.ores :exports none
regulatory_book_types get __none__
#+end_src

** =add=
:PROPERTIES:
:ID: FEADFB92-4E85-504B-9599-DB849EE40D0F
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.


The command is shaped like this:

#+begin_example
regulatory_book_types add <code> <name> <description> <display_order> <reason> <commentary>
#+end_example

It is addressed at =refdata.v1.regulatory_book_types.put=.

#+name: regulatory_book_types-add
#+begin_src ores-shell :tangle regulatory_book_types-add.ores :exports none
regulatory_book_types add __none__ __none__ __none__ 0 system.new_record generated_script
#+end_src

** =set=
:PROPERTIES:
:ID: 86517CF1-3153-5C8A-B5C1-7D92FC92C931
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved. Passing --version makes the write conditional on the version the caller last read.


The command is shaped like this:

#+begin_example
regulatory_book_types set <code> <name> <description> <display_order> <reason> <commentary> [--version <n>]
#+end_example

It is addressed at =refdata.v1.regulatory_book_types.put=.

#+name: regulatory_book_types-set
#+begin_src ores-shell :tangle regulatory_book_types-set.ores :exports none
regulatory_book_types set __none__ __none__ __none__ 0 system.new_record generated_script
#+end_src
