* Decisions

The remainder is carried in [[id:4880D5CD-A7EE-4B30-87FA-A9C7F3633DD9][Move the lookup artefact tables and settle the remaining DQ artefact models]].

- *A moved table keeps its shape.* The owning model states the old staging
  columns in an =* Artefact columns= section, so a move changes no populate
  or publish function. A table takes the name its owning model gives it, as
  the provider table did.
- *The staging shim gate stays.* No dq shim copies another component's
  entity now, but codegen still drops the shell unit of one that would, and a
  fixture tests it.
- *A staging table states its own checks.* The =* Artefact columns= section
  takes an expression table, and the artefact template renders it, so a
  hand-written table with constraints moves without losing them.
- *A table whose owner has no model waits for the model.* =ip2country= moves
  once its geo store is modelled, and =lei_bic= moves with the other GLEIF
  tables.
