The detail row of one =marketdata.fx_vol_surface_publish= approval request: the
calibrated candidate the request authorises, the checks of that candidate, and
the record of the act once the surface is published.

A surface is derived data and belongs to its blueprint's party. The subject is the
blueprint and the as-of, which name one calibration record. The raise copies that
record's checks here, so the person who decides reads the fit they approve: whether
it converged, its largest pillar error, how many pillars are beyond the tolerance,
and how many arbitrage conditions it breaks. The apply publishes that calibration
and no later one: a calibration rerun after the raise is a new version, and the
apply refuses a version the request did not name.

A blueprint's output series holds one live surface. The apply ends every live set
of the series in the same act, as a curve publish does, so the superseded set and
its successor both stay in the history. =published_at= and =published_by= are the
publication record, empty while the request waits. =request_id= is the natural
key, so a request authorises one publish.

Reads every record of one series that was published and has not ended, newest
first. The publish gate asks here before it stamps the successor: one live set is
what a reader is promised, so a series that holds more than one is a set that
never ended, and the apply ends them all.

#+begin_src cpp :name implementation :implements F2EB1914-5E94-42CA-9C77-46BDB364BF9E
std::vector<domain::fx_vol_surface_publish>
fx_vol_surface_publish_repository::read_live_for_series(const context& ctx,
                                               const boost::uuids::uuid& series_id) {
    BOOST_LOG_SEV(lg(), debug) << "Reading the live sets of series: " << series_id;
    static constexpr auto max = db_timestamp::max();
    const auto tid = ctx.tenant_id().to_string();
    const auto sid = boost::uuids::to_string(series_id);
    const auto query = query_builder::read<std::vector<fx_vol_surface_publish_entity>> |
                       query_builder::where("tenant_id"_c == tid && "output_series_id"_c == sid &&
                             "valid_to"_c == max);

    auto rows = query_builder::execute_read_query<fx_vol_surface_publish_entity, domain::fx_vol_surface_publish>(
        ctx,
        query,
        [](const auto& entities) { return fx_vol_surface_publish_mapper::map(entities); },
        lg(),
        "Reading the live sets of a series.");

    // A set is live when it was published and nothing ended it: a record with no
    // instant is a request that still waits, and one that carries an end is a set
    // a reader no longer prices from.
    rows.erase(std::remove_if(rows.begin(),
                              rows.end(),
                              [](const auto& r) {
                                  return !r.published_at.has_value() ||
                                         r.superseded_at.has_value();
                              }),
               rows.end());
    std::sort(rows.begin(), rows.end(), [](const auto& a, const auto& b) {
        return *a.published_at > *b.published_at;
    });
    return rows;
}
