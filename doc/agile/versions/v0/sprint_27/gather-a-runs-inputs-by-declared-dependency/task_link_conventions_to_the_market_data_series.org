* Goal

An instrument convention names the market data it depends on as free text (for example fra_convention.index = 'EUR-EURIBOR-6M'), so the reference cannot be validated and cannot be joined to the market series that answers it. Add one nullable oresmd URI column to every convention kind, and record what each kind's address is (an identifier, a requirement, or a fixing) and why. Every convention kind states a market data need, so no kind is excluded: the first cut's test, "does this convention reference a market data series?", was wrong, and its thirteen exclusions are retracted (see the PR body).

* Notes

- 2026-10-09: the first cut added the column to 13 of the 26 kinds and excluded 13 on the test "does this convention reference a market data series?". That test is wrong. The product owner ruled that every convention kind needs an oresmd URI, since a URI need not be an identity; a fixing is a first-class oresmd subject, and a requirement is a legitimate less-specified address. The exclusions are retracted and every kind now carries the column.
