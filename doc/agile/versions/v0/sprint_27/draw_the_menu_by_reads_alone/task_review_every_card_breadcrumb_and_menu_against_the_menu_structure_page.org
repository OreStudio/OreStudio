* Result

Every difference between the web menu, cards and trails and the menu structure page is listed in the task, and each is fixed in the code or the page, except the one the story's first task covers.

- The menu and Home put Market data before Requests, as the page does, and a test holds the two in step.
- Market data's cards are in the one card registry and its trails start at Home and link the area.
- The tenant screens that had no trail, or a trail without Home, have one.
- The page now names the Development area and the card words of Operations.
- The screen is Staff for everyone, and the four pages of a person's own (My profile, My access, Security, Where I work) have a breadcrumb of Home then the page. Every routed screen except Home has a trail.

Evidence: the whole web package passes (104 files, 1144 tests), the typecheck is clean and Prettier is clean.

Not done here: the installation read (the story's first task) and a test that walks every screen (the story's last task).
