- Both plugins' check-manifest.mjs passes.

* Plan

=check-manifest.mjs= reads the product version from =CMakeLists.txt= and fails
when =package.json= disagrees. =CMakeLists.txt= declares =OreStudio VERSION
0.0.27=; both plugins declared =0.0.25=. Set each =package.json= version to
=0.0.27=. The check is deliberate, not incidental: a plugin ships with the
product and is upgraded with it, and a missed bump installs cleanly and looks
fine.
