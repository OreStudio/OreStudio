* Goal

A ten year expiry needs 2520 returns. The derived source should quote the expiries its sample reaches and leave the rest unquoted, naming them, instead of quoting a fixed ladder and leaving a hole that voids the surface downstream. The reach is computed per pair per party from the sample it holds.

* Acceptance

- The reach of a pair is computed from the returns its party holds, not from a constant.
- The source quotes only the expiries it reaches and names the ones it does not.
- A pair whose sample is doubled never reports a shorter horizon.

* Plan

- *What was already true.* The derivation already reads each expiry's level over a window of
  =max(21, years x 252)= returns, and an expiry past the sample fails inside
  =realised_volatility= with "the sample is shorter than the window". So the reach was already
  the sample's, but implicit: it surfaced as one error per expiry, and nothing named it.
- *The rule, once.* =fx_derivation_window= is the one rule for how many returns an expiry
  needs; =derive_fx_quotes= and =derive_grid= read it, so the reach the source reports and the
  window its quotes are read over cannot disagree.
- *The reach.* =derived_fx_reach_of= splits a pair's ladder into the expiries its returns cover
  and the ones they do not, each with what it needs. The live refresh derives only the reached
  ones and names the rest in one line, such as "USDCLP reaches 7Y with 2345 returns; 10Y needs
  2520". The history path keeps =derive_grid=, which judges each day by the returns up to it.
- *The property.* A test walks samples from 0 to 3000 returns and checks that doubling one
  never reaches less, and reaches the same expiries first.

* Result

A pair's reach is the expiries its returns cover, read through =fx_derivation_window=, the one
rule the quotes' windows are read by too. The live source derives only those and names the rest
in one line, with what each needs; a doubled sample never reaches less. Every pair the catalogue
holds today reaches 10Y, so the 2275 quotes are unchanged; the reach is what lets a shorter pair
such as USD/CLP join the catalogue, once the calibration fits the expiries it has.
