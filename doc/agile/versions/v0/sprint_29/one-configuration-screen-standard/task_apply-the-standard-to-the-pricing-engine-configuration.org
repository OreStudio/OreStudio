* Acceptance

- The record page has Details, Products, Parameters, Used by and History, in that order.
- Every model, engine, pair and parameter description comes from the documentation contract, not from a screen literal.
- Used by lists the reports that bind the configuration and states the reach rule.
- History is the shared timeline, with Revert.
- The product and parameter dialogs show the documentation, without and with the schema panel under the Simple and Advanced switch.
- The page states the other configurations the same report binds, with links.
- The import follows the standard: the parse on the server, the findings, the difference and the review.
