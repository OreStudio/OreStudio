* Goal

ores.orgmode is a single library at the component's root. Make it a compound component, as ores.marketdata and ores.analytics are: move the existing parser into ores.orgmode.parser, with ores.shell and the tests on the new includes, and scaffold ores.orgmode.api, ores.orgmode.core and ores.orgmode.service through the codegen so the next tasks have somewhere to go.
