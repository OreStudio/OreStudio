* Result

A list marks the rows that differ when the same page is read again: the key was not there, or the row's content is not what it was. ores.qt compares =recorded_at= with the last reload time, which crosses the server's clock and the browser's, so the web compares the row against the same page read before and uses no clock. Moving to another page, searching or sorting marks nothing. A marked row gets a gold left edge and pulses three times (=row-changed=), and the mark goes after four seconds. The list keeps its scroll position because it only re-reads. =RecordTable= does this for every refdata list, the people, parties and tenants lists. The staff list and the hierarchy are not tables of =RecordTable= and are not marked yet. Five unit tests cover the comparison.
