* Acceptance

- The ACME definition triggers from the shell, the instance travels pending, running and completed through the FSM guard, and the compute results are retrieved.
- The run is reproducible from a freshly recreated database, and every report ACME is seeded with has the risk report configuration its run needs.
- The run's portfolio input is ORE-readable at the path the run document names, and the engine proceeds past Build Portfolio.
- A job whose engine reports an error and writes no analytics is recorded as a failed result, and a stored assignment whose result is gone is not replayed.

- 2026-10-24: The proof runs on this environment's five local wrapper hosts.
  The LAN hosts belong to other environments and were one and two releases
  behind main, so a run there would prove a different tree. The version table is
  recorded on [[id:063E3B7C-EAEB-403F-93E5-C4384570BCF2][Prove the run end to end and keep it repeatable]].
- 2026-10-24: The acceptance bullet about a failed job was not true when the run
  was first made. The engine's bookkeeping files counted as analytics, so a
  failed analytic was recorded as Success. The verdict now reads the engine's
  own =Error in ORE analytics= line, and the same broken package fails as it
  should.
- 2026-10-24: Seven of the run's eight bonds have no reference data the engine
  can build, so they price nothing. The chain is correct and the run is honest
  about its output; the gap belongs to the instrument export, not to this story.
- 2026-10-24: The acceptance bullet about a stored assignment whose result is
  gone is already met by an earlier decision, not by this run. Sprint 28 retired
  the assignments stream and the wrapper claims work from the ledger, so no
  assignment outlives a recreate. That task was abandoned for the same reason.
- 2026-10-24: The proof rides with a test-harness fix. Local test runs share the
  NATS server with a running fleet, so the suites now use a =<prefix>.tests=
  namespace and a fleet cannot answer their announces. The streams that
  namespace creates are not purged yet; that is captured in
  [[id:4FABC503-2218-42FA-9086-1E94A367A638][Purge the streams a test run creates]].
