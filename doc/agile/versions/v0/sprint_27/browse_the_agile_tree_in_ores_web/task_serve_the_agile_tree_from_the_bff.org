* Result

The BFF serves the agile tree behind the session check: =GET /api/agile/sprints=, =/api/agile/board= (newest sprint, or =?sprint=sprint_N=), =/api/agile/backlog= and =/api/agile/docs/:id=. The doc route serves sprints, stories, tasks and captures only, and reads through the scenario store's id index, so no id names a path. A sprint name that is not =sprint_N= answers 400. With no doc root the routes answer 404. The contracts package has the schemas, and 8 route tests parse every answer with them.
