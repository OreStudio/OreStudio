* Goal

Every market series a publish creates can be found by the resolver and listed by the picker as soon as the publish completes, without anyone running a backfill by hand.

* Acceptance

- One function projects the identities a tenant's series lack, and the backfill command and the publish handler both call it.
- When a publish from the data quality area inserts or updates series, the handler projects the identities before it reports the step complete.
- A test shows a series with no identity row gets one, a projected series is left alone, and a second call writes nothing.
- A fresh environment's picker lists the seeded series for each party with no manual backfill.

* Decisions

* Out of scope

- The one system-tenant series that a SQL populate script seeds. It lives in the system tenant and no screen lists it.
- Making the SQL publish function project the identity itself. It cannot run the codec, and the codec must stay the only reader of the grammar.
