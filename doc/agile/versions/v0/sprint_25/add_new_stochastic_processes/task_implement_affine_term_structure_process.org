* Result

Implemented =affine_term_structure_process=: an N-factor Gaussian affine
short-rate engine, =r = delta_0 + delta^T X= with correlated
Ornstein-Uhlenbeck factors via Eigen. =discount_factor()= runs the affine
bond-price recursion per tick with the exact per-tick factor covariance
(sigma_dt, the affine special case of the quadratic recursion). The
existing one-factor Vasicek/Hull-White and two-factor Gaussian engines
reduce to it exactly, verified test-by-test at 1e-12. 11 Catch2 tests
covering exact equivalence with =vasicek_process=, =hull_white_process= and
=two_factor_gaussian_process=, sigma == 0 flat-curve reproduction across a
dt sweep, correlated two-factor bond price against the G2 closed form,
three-factor sanity, zero factors, seed determinism and validation. CIR is
documented in the header as a future square-root-factor extension.
Registered in =component_files.cmake=.

All 368 =ores.analytics.quant= tests pass on Linux. Not yet wired into
=process_factory= (deferred to PR 2: system infra wiring).
