* Goal

A person books or changes a generic ScriptedTrade on a screen of its own: they pick a library script, fill a form the screen draws from the script's inputs, and see the script's code read-only; a custom inline script is an advanced mode with a code editor.

* Acceptance

- picking a library script lays out one typed field per input, with arrays as editable lists and events as dates
- the form refuses a value its input's rule refuses, and saving checks the variables against the script as the builder does
- the script's code shows read-only beside the form
- an inline script is edited in a code editor, its inputs are read from it, and the form follows them
- a trade of each form the generator books opens, edits and saves through the screen
