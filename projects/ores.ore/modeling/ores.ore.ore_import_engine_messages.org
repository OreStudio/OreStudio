#+description: Codegen operation model for the messages the workflow engine exchanges with the ORE import saga: the execute command, its stored result and the rollback compensation.

#+brief: The ORE import saga's execute, result and rollback messages.
#+filetags: :model:operation:ore:
#+created: 2026-09-26
#+updated: 2026-09-26

The engine-facing half of the ORE import protocol. The workflow engine
publishes the execute command when the workflow starts and the rollback
command when compensation is triggered; the handler in =ores.ore.service=
answers each by calling publish_step_completion, so neither command has a
response type of its own.

The result is not sent over the wire. It travels as the step's response_json,
which is why it carries the saved entity identifiers the rollback needs.
