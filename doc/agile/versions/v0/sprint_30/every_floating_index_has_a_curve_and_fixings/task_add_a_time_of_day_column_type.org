* Goal

Give the codegen a time-of-day column type. The PostgreSQL column is time without time zone, with the zone in its own IANA column; the C++ domain member is ores::platform::time::time_of_day, std::chrono::seconds since midnight with a defaulted comparison, converted to and from std::chrono::hh_mm_ss. Every template that handles a date column handles a time column the same way.

* Plan

The work has two halves.

1. The runtime half, which needs no codegen change:
   - =ores::platform::time::time_of_day=: seconds since midnight, in the
     range 00:00:00 to 23:59:59. The constructor refuses a value out of
     range. Comparison is defaulted.
   - =datetime::to_iso8601_time= and =from_iso8601_time=: the text form
     "HH:MM:SS". The parser also reads "HH:MM" and refuses fractions of a
     second.
   - =text_form<time_of_day>=, which JSON and msgpack use for the leaf.
   - The PostgreSQL binding =codec<time_of_day>=: OID 1083, array OID 1183,
     binary microseconds since midnight. The decoder refuses a value with a
     fraction of a second.
   - =query_builder= filter value, the faker sampler and the digest's
     canonical form.
2. The template half, which waits on compass v0.0.13: an =is_time= branch
   beside every =is_date= branch in the entity, generator, repository,
   history field mapper and service templates.

* Notes

compass-ng v0.0.12 derives the type flags from =:type:= only. A model
property such as =:is_date: true= has no effect, and an unknown type leaves
the generated TypeScript type empty, so prettier fails. No workaround
exists before v0.0.13.

* Result

A model column of =:type: time= is a PostgreSQL =time= and a
=ores::platform::time::time_of_day= in C++, seconds since midnight in one day.
compass v0.0.13 binds the column as text, so the repository record holds
"HH:MM:SS" and the mapper converts it with =datetime::from_iso8601_time= and
=to_iso8601_time=. The generator draws a time of day, the shell reads one as an
"HH:MM:SS" token, and the table printer streams one as "HH:MM:SS". JSON and
msgpack carry it through =text_form=, and the binary PostgreSQL codec binds it
as a query parameter.

Acceptance:
- A =:type: time= column generates a =time= column and a =time_of_day= member,
  and round-trips through the repository
  (=a_fixing_source_reads_back_its_publication_time=, 16:00:00 and 23:59:59),
  the wire codec and JSON (the generated codec round trips of =fixing_source=
  and =cut_code=) and the table. Met.
- The fixing source and cut code models use it for their times. Met.

The template branches cover the entity, the mapper, the generator and the
shell token. The history field mapper has no time branch, because compass sets
no =render_is_time= flag yet; how the history view shows a time column is not
checked.
