* Summary

=ores.workspace.core= persists workspaces and serves them over NATS. It holds
the generated repository, service and command handler for the workspace entity,
together with the generated history provider, presentation mapper and
sub-registrar.

The two workspace operations that are not entity verbs have hand-written
handlers beside the operation model that declares their subjects: the ancestry
resolution chain calls a set-returning SQL function, and the trade scope writes
a whitelist table no entity model describes. The component's registrar composes
all of them, and the generated event registrar wires the entity's change
pipeline.

* Inputs

- An =ores::database::context= per request: connection pool, tenant and actor.
- NATS command messages on the workspace subjects.

* Outputs

- Version rows in =ores_workspaces_tbl= and scope rows in
  =ores_workspace_trade_scope_tbl=.
- A NATS reply to every workspace subject.
- Workspace history, served through the generic history provider.

* Entry points

- =ores::workspace::messaging::registrar::register_handlers= — the one call the
  service application makes.
- =ores::workspace::repository::workspace_repository= — the generated CRUD set
  plus the resolution and trade-scope methods.
- =ores::workspace::service::workspace_service= — the generated service.
