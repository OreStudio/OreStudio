* Goal

A DSH plugin, specific to this repository, that shows the agile work item for the current work tree in an interactive panel inside the DSH Web session. The panel keeps the existing agile dashboard's look and answers one question at a glance: which sprint, story, and task is this tree on right now.

- The plugin loads into the DSH web profile and renders in a live session.
- The panel names the current sprint, story, and task, derived from the work tree rather than typed by hand.
- The panel is interactive and uses DSH client UI primitives rather than a separate web server.
