* Summary

This structure note orders the pages on LLM agents: programs a large language
model drives, through the loop of tool calls that [[id:0D919421-2B73-4322-9F79-9FDA38A67EA1][Large language models]] describes,
such as Claude Code or a small local model's agent, that act for a person
through =ores.http=. The cluster answers one
question in order: how an agent can do what a person may do without becoming a
second way in. Read it as: the path an agent's call takes, the consent it acts
under, how it is named on each call, how it reaches ORE and finds what to
call, and what happens to what it does.

* Reading order

[[id:3B1D40EA-121F-4F53-A612-FF13DCE1A0BB][Routing of LLM agent calls through ores.http]] — start here. It argues that an agent has one door and borrows a

[[id:1162906F-BB72-486E-9A11-30D567C65F3E][Delegation tokens for LLM agents: subject and actor claims]] — the person as subject and the agent as actor. Everything that
follows decides on one or the other.

[[id:1679B2CE-05C2-4CFF-9A4B-47EC721CB10A][Withholding of administrative permissions from LLM agents]] — what no role can delegate, and the three places that
keep it so. Read it after the token, because the exchange is the first of

[[id:4DCD0684-F6AE-4E84-BB9D-2AE2DAFDB667][Sessions of LLM agents]] — an agent's calls as sessions of their own, shown apart

** What happens to what it does

[[id:2D36D474-2CF9-4498-AF49-818CEF080B98][Auditing of LLM agent actions]] — every call recorded as the agent's, for its person.

* What this cluster excludes

How a person signs in and what their roles grant belongs to [[id:AF46793A-FF6C-4066-A059-279CE9936420][Identity and Access]]; this
cluster begins where a person consents to an agent. The approval framework
itself belongs to the [[id:E21DFC83-9F3F-45BE-AD3F-48262126DFAC][Four-eyes framework]] and its pages; this cluster adds one condition
to it. The knowledge an agent answers from belongs to compass, not to ORE.
Two uses of LLMs meet in this project and must not be confused. LLMs that
build and maintain ORE Studio, through Claude Code, skills and compass, are a
development practice, described in [[id:3B7C30A5-A421-4EEF-ADA8-C20D4AB54BB6][ORE Studio as an LLM-first system]]. The agents of this cluster are a
production feature: they use the running ORE Studio for a person, with no more
access than that person, and nothing here applies to how ORE Studio is
developed.
