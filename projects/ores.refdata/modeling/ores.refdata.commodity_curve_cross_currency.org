How a cross currency commodity curve is built from a price curve in another
currency, as ORE's =BasePriceCurve=, =BaseYieldCurve= and =YieldCurve=. Only
that construction reads them, and ORE requires all three for it.

A commodity curve holds at most one row of this part, so the generated table
adds the unique index on the live rows of =(tenant_id, curve_definition_id)=.
