* Result

Two captures are in the inbox of the product backlog, and the inbox index lists them. The first
states the duplicate and exact pins of the web workspaces: 29 of 38 declarations are exact, four
dependencies repeat, and zod at 4.6.6 in one package and 4.6.5 in the others crashed the bff
typecheck out of memory. The second states how a stale lock file reaches main: the bump pull
requests had no checks, the TypeScript gate runs only on a push to main, and fastify 5.12.6 stopped
a Linux build at npm ci. Each capture gives the direction of a fix and leaves the choice to the
story that picks it up. The zod pins themselves are fixed on PR 3684.
