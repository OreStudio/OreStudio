#+description: Try distcc on host newton (Debian on WSL) to shorten how long each build holds a host build slot. Builds queue on the two host slots, the abstract AF_UNIX names @ores-build-slot-a and @ores-build-slot-b, across about ten worktrees, and a wait can last an hour while the compile takes minutes. ccache already hits 87.7 percent of compiles, so distcc only helps on misses, which are the costly files after a regenerated header. Conditions: newton needs the same clang as this host (Debian clang 21.1.8); plain distcc ships large preprocessed sources, and pump mode needs the same vcpkg tree and paths on newton; linking, preprocessing and all tests stay local; compass ties a slot to -j6, so a higher -j for the remote part needs new slot accounting so this host is not overloaded. Check the network path from WSL. Measure first: compare slot hold time for one build with and without distcc. Separately, the old slot-b lock file named bright_faraday since 2026-10-10 with a dead pid (200392). The abstract-socket lock cannot go stale because the kernel frees the name when the holder exits, and `compass build --status` reports the live holder plus, for a free slot, the last holder this checkout recorded; check that before adding tooling.
