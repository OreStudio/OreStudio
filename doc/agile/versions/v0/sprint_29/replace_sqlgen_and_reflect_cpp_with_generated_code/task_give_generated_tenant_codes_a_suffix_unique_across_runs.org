* Result

The tenant generator's code and hostname carry eight hex digits of a uuid,
as the seed profile generator already does with a whole uuid, so they no
longer depend on a per-process index alone. The code keeps its index too,
which the generator template declares in any case. ores.iam.core and
ores.iam.api pass twice in a row on the same database.
