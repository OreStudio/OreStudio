* Result

Delivered in PR #2644 for the currency, desk group and currency pair screens.
The models mark their searchable and sortable columns, the generated lists
search and order on the server, and one shared =RecordList= pages through them
with the full =Pager= (First, Previous, Next, Last, page size, Load all), the
search, the sortable headers, the column menu and the states. A record page
reads its one record by key. Checked live: 168 currencies page and order by
name and by code; a search for "dol" finds 25; a pair search orders by code;
an unknown key answers 404.

The holiday calendar screen moves onto the same parts in PR #2646, and the
classification screens with the conformance task.
