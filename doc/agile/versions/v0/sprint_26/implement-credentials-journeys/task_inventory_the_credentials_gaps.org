* Goal

Give the group one page that says, for every credentials step, whether the
operation exists, what carries it, whether the browser can reach it and what
permission it needs. The per-screen findings the prototypes recorded mix three
different problems — a missing subject, a missing route and a handler that
answers with nothing — and each has a different owner and cost. The build tasks
are sized from this page.

The answer does not depend on which variant the product owner picks, because no
variant changes what the server serves, so this work could proceed while the
prototypes are under review.

* Plan

1. Count the routes on both HTTP surfaces: the BFF, which the browser reaches,
   and =ores.http=, which it does not.
2. List the subjects from the generated protocol, so the census does not inherit
   a design document's claim.
3. Check the permission each operation needs against the handler's guard, and
   against the catalogue that grants it.
4. Read the handlers the journeys' subjects reach, to separate a handler that
   answers with no rows from one that answers.
5. Write the per-journey tables, the gap counts and the recommendations.
6. File the defect the census found.

* Notes

- The census was run twice: once against the BFF alone, which concluded that
  nothing serves the credentials data, and once against both surfaces, which is
  the record. The first pass is kept in the investigation's =* Paths taken=,
  because the mistake is the reusable part: an =ores.http= route is not a
  browser read.
- The permission column checks the handler's guard, not the catalogue. The two
  disagree twice: =sessions:delete= is required and never granted, and
  =sessions:read= is granted and never required.

The defect: =list_sessions=, =get_session= and =get_many_sessions= check no
permission, while the account reads check =iam::accounts:read= and the
login-record reads check =iam::login_info:read=. The catalogue grants
=iam::sessions:read= for exactly this purpose. Filed as
[[id:89CD5129-06AA-448A-BED1-78F829ABC952][The session read handlers skip the permission check the catalogue grants]].
