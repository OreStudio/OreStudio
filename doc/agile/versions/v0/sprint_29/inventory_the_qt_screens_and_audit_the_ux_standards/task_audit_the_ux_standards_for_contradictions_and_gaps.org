* Acceptance

- Every contradiction between the pages is listed with both sections and the screens that follow each side today.
- Every open form layout question is listed with the Qt dialogs that show the need.
- The audit says which rules are checkable by a machine, which need a person, and what a rule needs so a check can name it.
- The audit judges whether Allium fits the behaviour rules and names the rules it would cover.
- The audit is a knowledge page under doc/knowledge/ui, and the second story links it.

* Plan

Read the five pages in full and compare every normative sentence across them.
Where two pages disagree, read the shared code to say which side the screens
follow today, so each contradiction comes with a proposal the second story can
accept or change. Use the matrix script's record of the Qt dialogs' tabs and
group boxes as the evidence for the form layout questions. Judge the checklist
as an instrument, size the identifier work by counting bullets and headings,
and say which rules a machine can check and which Allium can state.
