* Goal

Give the forward publish the set shape curves and surfaces now use: the pair is
the second half of the natural key, one request names a party's pairs, and the
step raises once.

* Acceptance

- One request authorises a party's forward pairs, and a decider answers it once.
- A publish still names the request and one pair, and is refused when the request
  does not name that pair.
- The published forward sets a reader sees do not change shape: one row per pair,
  sharing the request id of the set they belong to.
- A person's publish of one pair is a set of one, so there is one raise path.

* Plan

=ores_marketdata_fx_forward_publishes_tbl= still keys on =request_id= alone, and
=fx_forward_publish_service.cpp= reads a request's subject with
=read_latest_by_request=. The work is the four slices of
[[id:C756C87B-2284-4BCB-AAEC-F2EA4F2F6D6F][Approve a set of surfaces in one
request]]: the pair becomes the second half of the natural key; the read becomes
=read_latest_by_request_and_pair=; a set raise writes the request and its pairs in
one transaction; the forwards step raises once and publishes each pair under it.

This is tracked rather than assumed because the set path is not complete for every
kind until it is done, and because #4913's review asked for it to be written down
before the shape is described as finished.
