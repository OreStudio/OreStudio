* Goal

Rename the per-entry curve configuration tables so each name says it holds configuration: yield_curve becomes yield_curve_config, fx_volatility becomes fx_volatility_config, and so on. curve_definition, the header row other documents refer to, keeps its name.

* Acceptance

- Every per-entry curve configuration table, and its C++ type, repository, protocol, shell commands and permissions, carries the _config suffix.
- curve_definition, the child tables and the tables whose names already say configuration keep their names.
- Every corpus curveconfig.xml still round trips, in memory and through the database.
- A migration takes a database that holds the old tables to the new names.
