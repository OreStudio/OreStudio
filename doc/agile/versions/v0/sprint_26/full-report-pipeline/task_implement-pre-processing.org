* Goal

Produce the ORE engine's input from a definition's scope: bulk scope reads on trading and market data, mapping to the engine's documents through ore's mappers in-process, streaming, and an archive addressed by a digest of its inputs so that concurrent runs over the same scope share one generation.

* Acceptance

- Trading and market data each expose a scope-limited bulk read, and pre-processing reads nothing else.
- The artifact is addressed by a digest of its inputs and a repeated request over the same inputs is a lookup.
- Peak memory is bounded and does not grow with the size of the input.
- The archive contains Input/ore.xml and the files it names, so the grid can run it.
