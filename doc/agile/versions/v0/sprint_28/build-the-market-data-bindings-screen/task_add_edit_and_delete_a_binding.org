* Goal

Add and Edit are one dialog of the record standard. Add states the new record reason and opens the new binding's page. Edit offers the source name and the enabled flag with the help the prototype shows, asks for a change reason and a commentary, warns when the series changes, and refuses a source whose series a running feed holds. Delete names the binding, says that the series, its observations and the binding's history stay, and returns to the list.

- Only the roles the prototype shows may add, edit and delete.
