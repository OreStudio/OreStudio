One row per name a credit basket states, keyed to the trade and the name's
ordinal within the document.

The ORE schema states a basket as an unbounded list of =Name= elements, each
carrying an issuer, a credit curve, an optional notional, an optional weight
and an optional currency, and a few more that this table does not hold yet.
The list order is the document's order and the ordinal preserves it, so the
export re-emits the names as the document held them.

An index credit default swap and a synthetic CDO state a basket. A product
that states none writes no rows.

The notional is a money value, so the column holds an exact numeric. The
weight is a continuous quantity, so the column holds a binary float. The
document may state neither, and then the column is null rather than a zero the
document never wrote.

The trade row carries the party. The name rows are family-owned and ride the
trade's scope.

** Custom repository methods

The trade read path fetches the names of many credit baskets at
once when it assembles the export payload, and no generated read covers
that: =read_latest(context, ids)= filters on the child's own key and
=read_latest_by_trade_id= reads one instrument at a time. The batch
read below is one statement over the instrument set, which is what the
generated stack cannot express.

*** read_by_instruments_batch
:PROPERTIES:
:ID: 36596969-5526-46F8-8DC9-14A9D567142D
:END:

Reads every current name of the given instruments, ordered by
instrument and ordinal, in one statement. An empty input reads nothing.

#+begin_src cpp :name implementation :implements F2EB1914-5E94-42CA-9C77-46BDB364BF9E
std::vector<domain::credit_basket_constituent>
credit_basket_constituent_repository::read_by_instruments_batch(
    context ctx, const std::vector<std::string>& trade_ids) {
    if (trade_ids.empty())
        return {};
    static const auto max(make_timestamp(MAX_TIMESTAMP, lg()));
    const auto tid = ctx.tenant_id().to_string();
    const auto query = query_builder::read<std::vector<credit_basket_constituent_entity>> |
                       query_builder::where("tenant_id"_c == tid && "trade_id"_c.in(trade_ids) &&
                             "valid_to"_c == max.value()) |
                       query_builder::order_by("trade_id"_c, "sequence_number"_c);
    return query_builder::execute_read_query<credit_basket_constituent_entity,
                              domain::credit_basket_constituent>(
        ctx,
        query,
        [](const auto& entities) { return credit_basket_constituent_mapper::map(entities); },
        lg(),
        "Reading credit basket constituents for multiple instruments.");
}
