* Notes

The component has no shell part, so the reason a unit cannot render is structural
rather than a decision about each operation. What each operation adds is who reads
it:

- =logs= serves the UI and the log pipeline. It carries both a query and an ingest
  publish, and neither is a REPL session's business.
- =nats_samples= answers the operations dashboard, which is where a person meets
  NATS server and stream samples.
- =service_samples= carries the heartbeat every service writes, and the samples the
  dashboard reads.

None of the three has a hand-written command anywhere in the shell, so there was
nothing to retire and nothing to compare.
