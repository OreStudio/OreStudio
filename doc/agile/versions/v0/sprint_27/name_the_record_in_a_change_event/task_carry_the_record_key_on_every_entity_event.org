* Goal

The typed entity event already carries the key of the changed row, and so does the NATS payload. Prove it for every entity, and make a key that cannot be read visible. The generated =from_notification= leaves the key empty without a word when it cannot read it, and a screen would read an empty key as /many/. No codegen change is expected beyond a log line.
