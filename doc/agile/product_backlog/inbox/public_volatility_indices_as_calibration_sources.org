#+title: Use the free public volatility indices as calibration source…
#+description: Use the free public volatility indices as calibration sources for the vol surfaces of other asset classes. FX has no free implied vol source (checked 2026-11-03 in the task Document the volatility surface architecture), but some asset classes have a published index. FRED carries Cboe indices such as VIX (VIXCLS, equity), and Cboe also publishes indices for oil, gold, emerging markets and longer equity horizons; check which FRED carries today and which are discontinued. Each FRED Cboe series is marked Copyrighted: Citation Required, and its storage terms are unread, so read Cboe's and FRED's terms before any fetcher stores a value. The ICE BofA indices on FRED, MOVE among them, forbid reproduction without ICE's written permission and keep only three years of observations, so they are out. An index is a single implied vol level, so at best it sets the ATM level of one tenor; the shape still comes from the derived calibration source. A fetcher for FRED needs an API key, which the public sources adapter keeps under its secrets.
