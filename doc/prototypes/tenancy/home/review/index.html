Home screen prototype — Gemini review

Gemini drew the system administrator's home as a dashboard of four panels: tenants, services, the compute grid and the message queue. It is kept as a record of the alternative, not as the agreed design. Every value on it is mock data, and some of the facts it states are invented: the processor load of the grid, the scheduler status and the broker name have no source in anything the installation records today.
