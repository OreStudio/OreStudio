* Purpose

Models a market-convention reference table: a small, named set of
records identified by a human-meaningful text code (e.g.
=EUR-CDS-CONVENTIONS=), scoped to both tenant and workspace since
convention sets are typically curated per trading desk/workspace
rather than shared tenant-wide. Discovered as a genuine recurring
combination while surveying =ores.refdata= for this profile catalogue
pilot — 8 entities (=cds_convention=, =deposit_convention=,
=fra_convention=, =ibor_index_convention=, =ois_convention=,
=overnight_index_convention=, =swap_convention=, =zero_convention=)
share this exact configuration independently, which is the bar this
catalogue sets for naming a profile rather than leaving it as
unremarked repetition.

* Reference entity

[[id:558BC028-D6EF-473C-96E7-8518D6302472][cds_convention]] — settlement lag, premium schedule, and accrual rules
for a vanilla CDS, keyed by a text convention identifier.
