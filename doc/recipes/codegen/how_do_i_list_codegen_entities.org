#+title: How do I list codegen entities?
#+description: Entity models are org files under each component modeling directory; list them by their #+type line with compass doc find or git grep.
#+type: recipe
#+level: cross
#+filetags: :codegen:compass:entity:recipe:
#+created: 2026-06-26
#+updated: 2026-11-22

Entities are defined as org-mode model files under each component's
=modeling/= directory and discovered via [[id:08FBD248-257A-A474-DD43-DB08949978F1][ores.codegen]]'s manifest.

* Question

How do I list all codegen entities by metatype?

* Answer

Each entity is an org model file under its component's =modeling/= directory,
and its =#+type:= line names its metatype. List the entities of one metatype:

#+begin_src sh
git grep -l '^#+type: ores.codegen.entity' -- 'projects/*/modeling/*.org'
git grep -l '^#+type: ores.codegen.junction' -- 'projects/*/modeling/*.org'
#+end_src

Count every metatype:

#+begin_src sh
git grep -h '^#+type:' -- 'projects/*/modeling/*.org' | sort | uniq -c | sort -rn
#+end_src

Each model carries an org-roam =:ID:=, so =./compass.sh show <id-prefix>=
opens it.

* Script

=git grep= over the model files. compass-ng's =codegen= codec reads the same
files when it generates.

* Tested by

Run the count command and verify that =ores.codegen.entity= and
=ores.codegen.junction= appear with non-zero counts.
