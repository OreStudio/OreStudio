#+updated: 2026-11-21

The rate index families an [[id:8B840E8D-2763-4A1F-8BC2-6C9E354DB673][ir_curve_generation_config]] can name,
one row per family, and the tenors each one admits. An overnight family, such
as =sonia=, names no tenor. A term family, such as =euribor=, names one, and
the curve then projects that tenor's rate and discounts off the overnight
curve of its currency. A family can be both: =hibor= is an overnight index
for CNH and a term index for HKD. A dated tenor, such as SOFR's =FOMC=, is
neither: it names a curve whose pillars fall on meeting dates.

This replaces the two lists the curve config's checks and the DQ publish
function wrote out by hand, so a new family is a seed row rather than four
edits. Scoped to =ores.synthetic=, as the yield curve process types are,
because synthetic IR curve generation is its only consumer. Managed by the
system tenant.
