* Goal

A reader sees how every number of a run came to be. The This run tab states the start in plain text, the level first in market convention, then the fixing it came from and whether it was inverted, then the calibration the run used. The Calibration tab lists the pair's inputs and calibrations with their states, and opens each one: an input shows its points, a calibration shows its evidence and review history. Each record links to the next one in the chain, run to calibration to input to fixings, and back to the feeds that use a calibration. A person with the permissions captures, fits, approves and rejects from this tab.
