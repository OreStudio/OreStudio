#+title: How do I run the crm_enabled_derived_pairs commands from the shell?
#+description: Every command the crm_enabled_derived_pairs submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:crm_enabled_derived_pairs:

This file documents the crm_enabled_derived_pairs resource at the shell, one section per command. Every command is a subcommand of =crm_enabled_derived_pairs=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: 9765CDEB-897C-5CE7-8A65-D91ECAB61809
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
crm_enabled_derived_pairs list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =refdata.v1.crm_enabled_derived_pairs.list=.

#+name: crm_enabled_derived_pairs-list
#+begin_src ores-shell :tangle crm_enabled_derived_pairs-list.ores :exports none
crm_enabled_derived_pairs list --limit 1
#+end_src

** =add=
:PROPERTIES:
:ID: E1DAE7AB-2F7F-5C16-9B29-2AA55FABE290
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.


The command is shaped like this:

#+begin_example
crm_enabled_derived_pairs add <id> <config_id> <base_currency_code> <quote_currency_code> <enabled> <reason> <commentary>
#+end_example

It is addressed at =refdata.v1.crm_enabled_derived_pairs.put=.

#+begin_src ores-shell :tangle crm_enabled_derived_pairs-add.ores :exports none
crm_enabled_derived_pairs add 00000000-0000-0000-0000-000000000000 00000000-0000-0000-0000-000000000000 __none__ __none__ false system.new_record generated_script
#+end_src

** =set=
:PROPERTIES:
:ID: 202CCAD5-2147-5E4D-898E-CC61C4E86B84
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved. Passing --version makes the write conditional on the version the caller last read.


The command is shaped like this:

#+begin_example
