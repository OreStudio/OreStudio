* Goal

- a RapidCheck property test with Catch2 generates instruments of every supported type, writes them as ORE XML, reads them back and requires equality
- a Mull run over the projection files, outside the normal build, lists the mutations no test notices, and each one is killed by a new test or recorded with its reason
- the run is documented as a recipe so it can be repeated
