One entity's or junction's domain interface, as a TypeScript module. It
mirrors [[id:E9A47FBA-7799-4D6B-AD1A-144B2F740F0F][ores.cpp.protocol.protocol_header]]'s
companion domain class ([[id:543F3A6F-C359-4075-8A53-9E48F766DCE6][ores.cpp.domain.class_header]]): the same fields, in the
same order, from the same model. The protocol facet's
=ores::<component>::domain::<entity>= projection names this interface, so
the payloads reference it instead of restating the entity.

The derivations are the request's own, held in the enriched
=domain_entity= dict: the prelude's flags (=has_audit_columns=,
=has_tenant_id=), the member lists
(=primary_key.columns=, =natural_keys=, =columns=) and the audit tail
(=has_audit_group=). Each field's =ts_type= is stamped by the loader's
=org_loader._ts_domain_type=. A field with no projection carries no
=ts_type=, and =org_loader._reject_silent_entity_domain_ts_gap= refuses the
entity rather than let the template emit =<member>: ;=. That guard reads no
=:ores.*.enabled:= property: mapping the type in =_ts_domain_type= is the
fix, or the model records why the member has no wire shape a TypeScript
client can read.

A junction renders from the enriched =junction= dict and follows the
C++ junction block exactly: =version=, =tenant_id= when the model sets
=has_tenant_id=, the =left= and =right= columns, the junction's own
=columns=, then the audit tail. The C++ block declares that tail as
plain members with no =has_audit_columns= branch, so the interface
states it unconditionally. The interface name is =name_pascal=, derived
in =core.generate_from_model=; =left=, =right= and each column carry the
=ts_type= it stamps. =org_loader._reject_silent_junction_ts_gap= refuses
a junction with a member that has no projection, so a member never
vanishes from the interface silently.

A composed struct (=domain_groups=, =has_identity_group=,
=has_audit_group=) names its group member's own interface, so the module
imports each group it composes. The =ores.ts.domain= facet admits
=field_group= models, so the group's own interface is emitted beside the
entity's; a group the entity's own component declares imports from
=./<group>.js=, and one from another component from
=../../<component>/domain/<group>.js=.

See the [[id:C4E8A91F-3B7D-4F2E-85A6-1D9C7E3B2F4A][Template variable reference]] for the complete list of available
variables and their semantics.
