* Plan

1. Generate an instrument batch: one typed array per concrete instrument
   entity and one per child entity. The trade-type routing generator already
   knows every instrument table and emits the include list, so it is the hook.
2. Replace =trade_export_item.instrument= with the batch on
   =export_portfolio_response=, and add the generated append and lookup
   helpers.
3. The producer appends each decoded variant arm into the batch; the exporter
   looks the instrument up by trade id and rebuilds the in-memory variant, so
   its existing dispatch is unchanged.
4. Delete =instrument_payload=, its codec, the leaf-name registry and the
   wrapper structs.
5. Update =messaging_export_portfolio_codec_tests.cpp= and
   =xml_exporter_tests.cpp=, and run the ORE mapper round-trip suite, which is
   the byte-level check that the export still rebuilds its documents.

The layout is fixed by the constraint in the deprecated page: it must be flat
at the leaf level, because a nested =std::variant= cannot be encoded either.
