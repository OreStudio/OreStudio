* Acceptance

- The system tenant sees Latent on the Provider tab and the dashboard; a tenant does not.
- Latent has a description in the synthetic provider list.
- Start and Stop of a provider with no source of its own stop and start its feeds as graph nodes, with one reason.
- Every neighbour on a Graph tab is a styled link: a feed to its page, a view to its surface's Graph tab, a source to its provider.

* Plan

Fixes the owner found testing the merged story, each live-checked as it
landed, in one PR.

1. The tabs hid a provider their catalogue lacks; that catalogue is the
   synthetic provider list, which held no =latent=, so the system tenant lost
   it too. Hide the system's own providers by the session's tenant instead.
2. Seed =latent= in the synthetic provider list, so it has a description.
3. A provider with no source of its own cannot hand-start its feeds: stop and
   start them as graph nodes, with one reason.
4. Style the Graph tab's links, and link views and sources too.
