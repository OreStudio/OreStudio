One figure a run produced, at one subject and one observation date, with the
qualifiers that say what the figure is about. Every family whose row is keys,
qualifiers and figures lands here, and =family= says which family it came from.

The row is written once, with the run, and never edited; a correction is a new
run. A figure the engine stated as its null string is not here at all, because
there is nothing to store. The =subject_id= is the engine's own identifier, such
as a trade id or a netting set id, so it is text and not a uuid.

** family
:PROPERTIES:
:type:         text
:cpp_type:     std::string
:natural_key:  true
:filterable:   true
:END:

The family the figure came from, as the catalogue names it: npv, curves, xva. It
is what tells a reader which reader produced the row.

** subject_type
:PROPERTIES:
:type:         text
:cpp_type:     std::string
:natural_key:  true
:END:

The kind of record the figure is about: trade, netting_set, portfolio, or row
when the family states no record.

** subject_id
:PROPERTIES:
:type:         text
:cpp_type:     std::string
:natural_key:  true
:filterable:   true
:END:

The engine's own identifier for that record, such as a trade id. It is text
because the engine names its records with strings, not with uuids.

** as_of
:PROPERTIES:
:type:         timestamp with time zone
:cpp_type:     std::chrono::system_clock::time_point
:natural_key:  true
:END:

The observation date the figure belongs to: the run's priced date when the file
states none, and the row's own date or time step when it does.

** measure
:PROPERTIES:
:type:         text
:cpp_type:     std::string
:natural_key:  true
:filterable:   true
:END:

The engine's name for the figure: a heading such as NPV, and also a curve or a
risk factor, because a configuration-driven family states each figure as a
column.

** currency
:PROPERTIES:
:type:         text
:cpp_type:     std::string

The currency the figure is stated in, empty when it states none.

** scenario
:PROPERTIES:
:type:         text

:END:

The scenario the figure was produced under, when the row states one. It is typed

** factor
:PROPERTIES:
:type:         text

:nullable:     true

The risk factor the figure is a sensitivity to, when the row states one.

** shift

The size of the shift the figure was produced at, when the row states one.

** qualifiers

** source

The family and the row the reader read, for provenance.

** Bitemporal natural keys

A run's figures are its own. The insert trigger closes the current row of the
same key, and the key names the run, so posting one run never closes another
run's rows.
