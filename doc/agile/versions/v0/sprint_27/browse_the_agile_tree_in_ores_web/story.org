* Decisions

- The module extends the Development area of the QA runner story. It is a regular module and needs no developer tools.
- The BFF reads the agile tree of the work tree it runs in, behind an interface, as the scenario store does. It never calls compass and never merges work trees. The =ores.dsh_kanban= contract is the source for the fields, the state vocabulary and the rules, and it stays in git history after the project goes.
- The browser never names a path. A doc is read by id.
- Parity means the board, the card detail, the backlog, the charts and the work tree strip. The task that retires the two projects waits for all of them.
- The prototype comes first, and the person accepts it before the board is built.

* Out of scope

- Writing agile docs from the browser. Compass stays the only way they change.
- The across work trees story view the contract specifies and defers.
- A tester role and assignment, which are story 3.
