* Goal

Ticket type: grilling (human in the loop).

A strategy is the first rung of the composition taxonomy: a small fixed set
of named shapes with invariants that hold by construction. Strategy mode
fixes the leg set and refuses a structure that breaks those invariants.

Decide which strategies the prototype carries, and what each one's invariant
actually is. The source document names Risk Reversal, Butterfly, Straddle,
Strangle, FX Swap and Vega Spread. The prototype needs enough to show the
mode, not the whole set.

Also decide how the screen reports a broken invariant. An amend that touches
only reference data must pass with the invariants intact.
