* Goal

The ores.cpp.shell-command facet is on by default, so a model no longer opts in one file at a time. The facet node carries #+default: disabled, eight variability profiles fix it true, and many models repeat the opt-in in their properties drawer. This task flips the default, removes the now-redundant profile rows and drawer entries, and proves the generated surface is unchanged.
