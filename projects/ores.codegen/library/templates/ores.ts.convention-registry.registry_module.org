Every convention family the conventions document carries, as a TypeScript
constant: the family key, the entity model that serves it, the protocol subject
stem, whether the family's table is party-scoped, and how the document writes
it. The rows and their order are those of the C++ registry header, because both
come from one derivation.

The module lives beside the generated domain interfaces and is committed, as
they are, so a regeneration cannot delete a file the web layer imports. It
names no C++ type. The field names are camelCase, because the module is not a
wire shape.

The output path is literal because the facet renders from a /component/ model.

See the [[id:C4E8A91F-3B7D-4F2E-85A6-1D9C7E3B2F4A][Template variable reference]] for the complete list of available
variables and their semantics.
