* Goal

The citation function holds rules an agent cites rather than runs. Port the pstack principles the audit adopted, each as its own loadable skill so a method can cite it by name. Several need adaptation rather than copying: type-system-discipline is written for TypeScript and must be recast for C++; never-block-on-the-human argues against confirmation in a way that conflicts with our own conventions on irreversible actions and unrequested pull requests, so it must be reconciled explicitly rather than imported as written. Each principle carries its upstream attribution and a divergence note.

* Acceptance

- Every adopted principle is a loadable skill named after its rule.
- Principles written for another language or host are adapted, and the adaptation is recorded as a divergence.
- never-block-on-the-human is reconciled against our conventions on irreversible actions and unrequested pull requests, and the resolution is recorded.
- An index lists the principles by group so a method can read the set at task start.
- Every ported principle carries its upstream repository, path and commit.
- Each candidate principle is tested against the encode-as-a-check rule before it is ported: a principle that can be expressed as a lint, a metadata flag, a runtime check or a script is written that way instead, and the citation function holds only what genuinely cannot be checked.
- The principles that were encoded as checks rather than ported are listed, with what checks them.
