* Acceptance

- continuous-linux.yml passes code_coverage=1 when the build type is debug.
- The Continuous debug job still fits inside the 320-minute step cap.

* Plan

Pass =code_coverage=1= to the CTest script when the matrix build type is
=debug=, in the same style that =nightly-linux.yml= already uses for coverage
and memcheck. Leave the release build and the memcheck flag alone.

=CTest.cmake= does the rest: it selects =gcov= or =llvm-cov= from the compiler,
appends =-DWITH_PROFILING=On= to the configure arguments, and calls
=ctest_coverage= before =ctest_submit=, so the results land on the track named
by =ctest_start(${build_group})=, which is =Continuous= for this workflow.

* Notes

The coverage flags enter every compile line, so the stored clang-debug sccache
entry stops matching and the first run after this change compiles from cold.
The step cap and the cache guard already handle that case: the save runs under
=always()= and keeps whatever the run built.

The debug job now runs longer than the three-hour cron interval. The interval
needs a measured covered run before it can be re-derived.
