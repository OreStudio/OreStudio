* Goal

A tree-sitter grammar for ORE's script language highlights and flags errors in ores.web's editor, and a differential test holds it to ORE's parser on every library script and on scripts ORE's random syntax tree generator writes.

- the corpus is every library script and a stated number of generated scripts
