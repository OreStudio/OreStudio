* Notes

One verb is retired and five stay, and the rule that separates them is worth
stating because it recurs across the story's components. A hand-written read goes
when a generated unit sends the same request and the hand-written one adds only a
filter over a field the model already carries. It stays when it presents a shape
or a request no model states.

=synthetic list configs= is the retired one. It sends
=list_market_data_generation_configs_request=, the generated
=market_data_generation_configs list= sends the same request, and its =--scope=
flag filters the returned rows on =c.scope=, a field the config model carries.
Nothing else was in it.

The five that stay:

- =synthetic list folders= composes the parent/child tree and resolves a folder by
  exact name, display path, slug or slugged path. The generated =folders list=
  returns rows.
- =synthetic list feeds= reports the feeds running in the service, which is
  process state and not a table.
- =synthetic start= and =synthetic stop= act on running feeds, resolving a folder
  subtree or one feed by id, ore key or source name.
- =synthetic validate-vintage= checks vintage availability for a feed.

None of the five has a model that could state it, so no generated unit
supersedes them.

Removing the configs read also removed the three helpers only it used:
=scope_label=, =binding_mode_label= and =parse_scope=. The folder-tree helpers
stay, because =start= and =stop= resolve a folder token with them.

* Result

Synthetic's nine models all render a unit, and its hand-written menu now carries
five verbs instead of six. =synthetic list configs= is gone: the generated
=market_data_generation_configs list= sends the same request, and the only thing
the hand-written verb added was a filter on =c.scope=, a field the model already
carries. A caller who wants one scope reads the generated list and filters it.

The other five verbs are signed off with their reasons. One composes a folder
tree, one reports service state, two control running feeds and one validates
vintage availability. No model states any of them, so no generated unit can
supersede them.

The suite passes 432 assertions in 153 cases, and the shell still registers its
227 menus with no collision.
