* Goal

Record for each BFF route the C++ route that answers it, or state that none does. Extend the inventory check so that a pairing to a missing route fails the gate, and print the coverage per area from the pairing.

* Acceptance

- Each of the BFF routes has a pairing or an explicit gap.
- The check fails when a pairing names a route that does not exist.
- The coverage per area is computed from the inventory.
- The local gate is green.

* Plan

Keep the pairs as data in =build/scripts/route_pairing.py=. Pair a route only when the C++ route clearly does the same thing, and leave a route that uses a different key as a gap. Compute the coverage from the pairs and write it to the inventory. Make the inventory check fail on a pair to a missing route and on a coverage section that does not match the pairs.

* Result

=build/scripts/route_pairing.py= records 40 pairs. The inventory prints each of the 323 BFF routes with its C++ route or "none", and prints the coverage per area. The =route-inventory= check fails on a pair that names a missing route and on a coverage section that does not match the pairs. Four mutations and =test_route_pairing.py= show this behaviour. The local gate is green.

A pair records the mapping and does not prove it. The port tasks prove each route against the answer the BFF gives. This task also classifies =POST /api/curves/fx-forward-ladder=, because main failed the check without that classification.
