#+title: How do I run the images commands from the shell?
#+description: Every command the images submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:images:

This file documents the images resource at the shell, one section per command. Every command is a subcommand of =images=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: B7DFAD26-5AA6-5EC6-ACC4-1E3A6BC17F3B
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
images list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =assets.v1.images.list=.

#+name: images-list
#+begin_src ores-shell :tangle images-list.ores :exports none
images list --limit 1
#+end_src

** =get=
:PROPERTIES:
:ID: 4FCB98F6-20A3-5C2B-ACAA-729F4736F4C1
:END:

Reads the one row its key addresses. A key states every identifying column, so a partial key is refused rather than answered with an arbitrary row.


The command is shaped like this:

#+begin_example
images get <code>
#+end_example

It is addressed at =assets.v1.images.get=.

#+name: images-get
#+begin_src ores-shell :tangle images-get.ores :exports none
images get __none__
#+end_src

** =add=
:PROPERTIES:
:ID: 6A4A9E23-42AA-52E4-A3DE-60203DB0E675
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.


The command is shaped like this:

#+begin_example
images add <code> <description> <mime_type> <data> <reason> <commentary>
#+end_example

It is addressed at =assets.v1.images.put=.

#+name: images-add
#+begin_src ores-shell :tangle images-add.ores :exports none
images add __none__ __none__ __none__ __none__ system.new_record generated_script
#+end_src

** =set=
:PROPERTIES:
:ID: BB09BF39-CB13-5BD4-B680-08002FE106F6
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved. Passing --version makes the write conditional on the version the caller last read.


The command is shaped like this:

#+begin_example
images set <id> <code> <description> <mime_type> <data> <reason> <commentary> [--version <n>]
#+end_example

It is addressed at =assets.v1.images.put=.

#+name: images-set
#+begin_src ores-shell :tangle images-set.ores :exports none
images set 00000000-0000-0000-0000-000000000000 __none__ __none__ __none__ __none__ system.new_record generated_script
#+end_src
