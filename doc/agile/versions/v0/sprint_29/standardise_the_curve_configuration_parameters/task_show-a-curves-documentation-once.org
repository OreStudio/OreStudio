* Notes

- *One sentence, two places.* The contract gives a curve leaf a =help= and a
  =description= that are the same guide line, so the row's hint and the
  documentation panel printed it twice. The hint is gone: a row that is read and
  not changed states its label and its value, and the documentation is read where
  it is collapsed, which is what the
  [[id:852207A6-6785-43E6-A5D6-2D5C2C374101][ORE element and leaf screen standard]] states for a leaf in read mode.
  The engine settings and conventions screens already draw it this way, so this
  page was the odd one out.
