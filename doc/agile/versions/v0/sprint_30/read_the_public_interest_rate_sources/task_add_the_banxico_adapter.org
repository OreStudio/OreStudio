* Goal

The overnight TIIE de Fondeo is stored as fixings in the system tenant, with its history, read from Banco de Mexico through the SIE API, =www.banxico.org.mx/SieAPIRest/service/v1/series/SF331451=, in JSON, with a free token. The adapter is specialised: it reads Banco de Mexico alone, and it supplies only its fetcher to the shared half of the official adapter.

* Acceptance

- The adapter reads Banco de Mexico alone, and it does not copy the announce, the demand, the backfill or the publish code.
- Banco de Mexico is a supplier in the catalogue, its series maps to the MXN overnight item that this task catalogues, and a session and a feed scoped to that item are seeded in the system tenant.
- A fresh environment stores the history as fixings within minutes of provisioning, and the log names the source and the count it stored.
- Each fixing is the decimal of the published percent, with the credit the source and Banco de Mexico's URL.
- The depth of the history is measured and written into the calibration sources note.
- Unit tests parse a recorded response, and a malformed response gives an error, not a fixing.
