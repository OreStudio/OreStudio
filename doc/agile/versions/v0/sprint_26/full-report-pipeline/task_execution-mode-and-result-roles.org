* Goal

Give the report definition a run configuration, carry it into the workflow start message, and make the workflow build the phase list that configuration names. * Acceptance

- A definition's run configuration selects the phases that run, and a run is reproducible from the database alone.
- No step consumer reads an earlier result by index; a missing result fails loudly instead of yielding an empty field.
- A definition whose configuration executes every phase still runs the existing chain unchanged.
