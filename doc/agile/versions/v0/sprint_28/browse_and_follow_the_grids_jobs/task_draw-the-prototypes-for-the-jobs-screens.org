* Notes

The Jobs tab prototype was compared with the story's acceptance on 2026-10-22.
It lacked an outcome filter and a link to the job page. It drew a dashed run
statistics block, the wrong tabs and a failed workunit with no canonical
result, and it kept its state in memory. All six are fixed. The job page and
the app version page are new. The app version model has no release note, so the
page draws one and the task Store a release note with the app version adds the
column.

Opened in headless Chrome on 2026-10-22: the three prototypes render for every
role, state and variant checked. The owner reviewed the three prototypes on
2026-10-22 and approved them.
