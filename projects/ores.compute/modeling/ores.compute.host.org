compute grid. Tracks hardware capabilities, heartbeat, and accumulated credit.

** Custom repository methods

*** Client model DisplayName data

The =DisplayName= column shows the whimsical =display_name= when set,
falling back to a short-ID (first 8 hex chars of the external_id) for
hosts registered before display names existed. The per-row tooltip
reveals the full external_id. This is wired through the
=tooltip_field= and =data_paste= per-column knobs on the Qt columns
table above; the data-paste body is pasted verbatim into the generated
=data()= case for the column (see the ores.cpp.qt meta-model for the
knob contract).

#+begin_src cpp :name display_name_data :implements B7A4E9F2-6C3D-4E8F-9A1B-5C7D2E8F4A6B
            if (!host.display_name.empty())
                return QString::fromStdString(host.display_name);
            // Short-ID fallback: first 8 hex chars of the UUID.
            return QString::fromStdString(host.external_id).left(8);
#+end_src
