* Acceptance

- The mapper reads and writes every field the modelled categories carry, so no element is dropped.
- Each convention category the corpus uses has an entity in ores.refdata and a mapper in both directions.
- The conventions kind is registered with the round-trip harness and all seventy-two corpus files round trip.
- The mapper reports any category it does not model, and a test asserts that it reports none.

* Plan

1. Make the skip countable before changing anything. The mapper dropped
   seventeen categories in silence, which is why seventy-two files went
   unmeasured: nothing could say which categories the documents use. It now
   fills =mapped_conventions::unmodelled= and warns per category.
2. Measure which categories the corpus needs, and which files use only modelled
   categories. The probes are hidden tests, because the kind does not round trip
   and a test that passes while a document loses a category is worse than a
   measurement a person reads.
3. Fix the modelled categories first, because they are the cheap half and they
   are why nine files fail for a reason unrelated to the unmodelled categories.
4. Then model the fourteen categories, most used first, each with a refdata
   entity, both mappers, and its own round trip.
5. State the two normalisations the mapper performs on purpose in the kind's
   comparison, and only once the categories are modelled, because until then the
   kind cannot pass whatever the comparison says.

* Notes

- The cheapest work is not the unmodelled categories. Nine files carry no
  unmodelled category and still fail, on two causes: =<IndexBased>= is dropped,
  and a boolean and a day counter come back in ORE's enum spelling rather than
  the document's.
- =<IndexBased>= is a mapper line on Deposit, whose column already exists, and a
  new column on Zero, which has none although ORE writes an index-based zero
  convention.
- =true= against =True=, and =A365= against =A365F=, are the mapper's deliberate
  normalisation of booleans and enum aliases to canonical codes. Both carry the
  same information, so the comparison may state them. A dropped element carries
  less information than the document, so it may not.
- The mapper now warns once per unmodelled category on every import, which will
  be noisy for the corpus until the categories land. That noise is the point:
  the skip was invisible for as long as it was silent.
