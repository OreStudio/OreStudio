developer on the same release builds with the same compiler and sees the same

* Decisions

- No external repository is used. The 26.04 archive carries clang 21.1.8, GCC
  16, cmake 4.2.3, ninja 1.13.2, node 22.22.1, gh 2.46 and both PostgreSQL 18
  and its TimescaleDB package, so the PPA, apt.llvm.org, the GitHub CLI
  repository, the PGDG repository and three downloaded archives all go.
- The cmake, ninja and node pins go with them. Those tools are no longer chosen
  by the file, so the file no longer states a version it does not set.
- Overriding a package stays an option, and versions.env says so, but only for
  a tool the image ships too old to build the project. Nothing in 26.04 is.

* Out of scope

- macOS and Windows, which already track the latest: the macOS job runs on
  =macos-26= and selects Xcode 26, and the Windows job runs on
  =windows-latest= with the MSVC that image carries.
