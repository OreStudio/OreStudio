* What

Two declarations name the =ores.http= gateway from the browser side, and
nothing uses either:

- =projects/ores.web/packages/contracts/src/site.ts:56= declares
  =httpBaseUrl= on the site description.
- =projects/ores.web/packages/wire-protocol/src/client.ts:430= declares
  =discoverHttpBaseUrl()=, and no file calls it.

* Why

The BFF is the browser's only HTTP surface. =ores.http= serves callers
outside the browser, so a browser-side discovery path is a decision nobody
made. A declared-but-unused path is worse than an absent one: it reads as
the supported way to reach the gateway, and the next person adds a call
through it.

The signed-off architecture decision is to remove both rather than
document them. It is a code change, so it belongs with the implementation
work that follows the architecture task, not in a documentation change.
