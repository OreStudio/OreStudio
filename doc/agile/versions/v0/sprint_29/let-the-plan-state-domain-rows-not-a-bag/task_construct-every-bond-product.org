* Result

Abandoned, because the measurement changed the task. Nine of the ten routed
bond codes are never drawn: the planner states one product, =Bond=, for every
slot. Measured on a recreated database at =0f0533fc7a=, the bond instrument
table holds 24 rows and all 24 are =Bond=; the family's own fact rows are
empty, because the writer fills only the instrument header.

Constructing nine products nothing draws would have been dead code with a
test attached, and constructing the tenth would have fixed a trade type the
planner already hardcodes. So the work is not a constructor's: the population
has to draw the products before a constructor can state them.
