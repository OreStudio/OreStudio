#+title: Nobody reminds a decider that a request is about to lapse
#+description: The role request now carries a fortnight's deadline and closes itself as expired, so a queue cannot rot. The other half of the same gap in the Ask for more access journey is a reminder: an administrator who has not answered is told before the request runs out, rather than finding out afterwards that it did. The journey names both candidates together -- 'There is no deadline and no reminder' -- and the deadline is built. A reminder is a notification raised on a schedule rather than on a change, so it needs the sweep to look ahead as well as behind: every open request whose expires_at falls inside the reminder window, told to the kind's deciders, with some mark on the request so the same reminder is not sent twice. Decide whether that is worth the second piece of state, or whether the waiting notification and the queue are enough.
