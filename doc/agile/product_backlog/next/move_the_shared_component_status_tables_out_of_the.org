* What

Move the shared component status tables out of the UX standards into a generated report. The record screen standard says Recency is missing while the entity screen specification says useChangedRows exists; a status table inside a standard drifts the day the code moves. The standard should state the rule only. Found by the audit of the UX standards.

* Why

The audit of the UX standards compared the pages with each other and with
the shared code, and found this as work rather than as a rule to decide. It is
filed so the story Settle the UX language for record screens, or the pipeline,
picks it up with the audit's reasoning behind it.
