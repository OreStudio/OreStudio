* Acceptance

- S01: =feed_binding=, =market_observation=, =market_fixing= and the asset-class junction have generated shell command units and tests.
- S02: each has a generated recipe, and the recipe inventory lists them.
- V04: every marketdata shell command runs against the live fleet, and the run log is on the task. Any command that cannot run is recorded with its reason.

* Plan

Bind the models to the shell surface, regenerate, then run the recipes.

1. Opt =feed_binding=, =market_fixing= and =market_observation= into
   =ores.cpp.shell-command= in their property drawers. Their profiles,
   =readonly-timeseries= and none, do not turn the facet on.
2. Give the junction a list read. Codegen withholds every messaging facet, the
   protocol and the shell unit from a junction that declares no =list_by= side,
   so =market_series_id= gets =:list_by: true=.
3. Regenerate marketdata at the =ores= address, wire the new registrar and the
   four shell units into their hand-written aggregators, and seed the two
   permissions the junction's handler checks.
4. Regenerate the cmake lists, the recipe inventory and the script library,
   then run every marketdata script against the live fleet.

* Notes

** The live run

Each of the 73 marketdata scripts ran in its own =ores.shell --load=
invocation, logged in as the ACME tenant administrator, because the shell
stops at the first failing command. The full table is
=evidence/marketdata_shell_commands_run.txt=.

- 32 =ok=: the command reached its service and decoded. That includes the three
  =marketdata import= scripts, whose hand-written command prints counts rather
  than an outcome.
- 19 =missing=: the sentinel key addresses no row.
- 18 =failed=: each is the database refusing a sentinel, never a fault. The
  nil UUID breaks the =id= check on =set= and =put-many=; =__none__= is not a
  series subclass; the lineage sentinel is not JSON; the junction's nil series
  is no series.
- 4 =aborted=: the =crm_rates_*= scripts. No shell menu answers =crm= since
  commit =ee4e739a65= deleted the hand-written CRM commands, so these cannot
  run. Recorded as
  [[id:393E5F62-88E9-4EB5-841C-1DDF071F1394][The CRM shell recipes call a command that no longer exists]].


Today only =market_series=, =observation_lineage= and
=series_classification_rule= have shell commands. See [[id:6D60C52C-26B9-416B-A453-478EE5CA33C5][the 2026-10-02 review]], section 4.
