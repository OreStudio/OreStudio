* Decisions

- *The template owns the include, not the model.* Commit =06936a44da= states the
  rule: an include a template's files need sits behind a context flag computed
  from the branch that spells its symbol. The domain class template emits a
  =std::chrono= member, so it emits =<chrono>=; the 244 models that declared it
  by hand were standing in for a missing gate.
- *Delete the declarations the template now covers.* Leaving them emits the
  include twice. One that still needs it keeps it: an entity with no audit
  columns that declares a chrono column of its own is outside the gate.
- *Put the gate where the branch is.* =domain_entity= emits the member under
  =has_audit_columns=, so its include is gated on the same flag; =junction=
  emits it unconditionally, so its include is unconditional.

* Out of scope

- The protocol headers' own includes. 354 of the 360 that name =std::chrono= on
  =main= declare no =<chrono>= and reach it through the domain header they
  include. That is a separate question about the operation template and is
  unchanged here.
