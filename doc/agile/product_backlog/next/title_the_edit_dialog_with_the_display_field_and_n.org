* What

Title the Edit dialog with the display field and not the key. RS-WRITE-20, decided 2026-10-25, says the dialog is titled Edit followed by the title of the page, the display field. The harness baseline finds the currency dialog titled Edit AED where the page is UAE Dirham, and 11 classification row dialogs titled by the code where the page title is the name. 12 dialogs; the 10 that pass are lists whose code is their name.

* Why

The harness measured every record screen before the screen pipeline changed
any, so each topic starts from a known gap and the sign off has a before and an
after. This is one of the four rules the baseline found broken.
