* What

=projects/ores.sql/populate/scheduler/scheduler_populate.sql= seeds a job
that scrapes MQ queue statistics every minute, and
=projects/ores.sql/populate/trading/trading_sample_data_populate.sql= books a
swap and a novation as demonstration data. No root script includes either one,
so no database has ever run them. The scheduler file arrived with the move from
pgmq to the scheduler (=11168b35ba=).

The trading file is settled: it booked wide trades, so it was deleted with the
wide trade. The scheduler file is the one decision left.

* Why

Each file is either a feature someone expected and does not have, or dead
code. Wiring the scheduler job changes what runs on every database; wiring the
sample trades adds them to every database. The wiring check now names both as
deliberate exceptions until this is decided.
