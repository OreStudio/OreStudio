The settings of a default curve bootstrapped from CDS instruments, as ORE's
=StartDate=, =RunningSpread=, =IndexTerm=, =ImplyDefaultFromMarket= and
=PriceIsUpfront=. Only the CDS spread, hazard rate, price, conventional spread
and null constructions read them, and each is optional, so a configuration has
this part only when its document states one of them.

A default curve configuration holds at most one row of this part, so the generated table
adds the unique index on the live rows of =(tenant_id, default_curve_configuration_id)=.
