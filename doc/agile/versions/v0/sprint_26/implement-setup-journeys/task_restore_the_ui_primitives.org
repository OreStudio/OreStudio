- The primitives, the password field, the password policy and its test, and the brand artwork are restored from =e47043269f^= and pass the checks of the TypeScript Clean Standard.

- The step parts are ported from =prototype/first-run-journey= with the simulation removed: no stub, no canned profile data and no artificial failure switch remain.
