* What

=ores_iam_auth_events_tbl= has a =tenant_id= column and no row-level security
policy, so a session in one tenant can read another tenant's authentication
events. =validation_ignore.txt= suppresses =RLS_001= for it with the reason
"the entire log is accessible to tenant admins", and suppresses =RLS_002= saying
"the whole log is tenant-scoped". Without a policy the log is not
tenant-scoped at all.

* Why

Authentication events name accounts, sessions and source addresses. Either the
table needs a tenant isolation policy, or the reason in the ignore file must
say why every tenant may read every other tenant's events. The current reason
contradicts the table.
