* Goal

Ticket type: research (agent-driven, no human needed).

What can the compute grid already do for a one-off valuation? The booking
screen must capture an initial NPV, and the candidate mechanism is to
dispatch a valuation run and read the result. That decision cannot be taken
until the current capability is known.

Establish what =ores.compute= offers today: what a run configuration and a
computation definition require, how an input token resolves to a versioned
market data snapshot, whether a single trade or structure can be valued on
demand, and what a completed result carries.
