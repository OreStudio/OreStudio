* Goal

The generic Related tab from entity_specification.org section 9 and gaps.org item 24: one declaration per relationship produces a read-only table with Add and Delete, shown on the parent's detail screen. It serves an account's contact information, an account's parties, an account's roles and a role's permissions, so none of them gets a table of its own. Adding or removing a related record carries an audit reason, which the Qt client did not do.
