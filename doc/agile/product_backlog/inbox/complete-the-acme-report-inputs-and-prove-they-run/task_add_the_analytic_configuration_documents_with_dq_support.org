* Goal

Several analytics read a configuration document that has no entity model, no store or no DQ support. The simulation document has 18 entities and the sensitivity document 58 in the ORE schemas. The stress test and the credit simulation have models but no document store, and the historical return, Basel traffic light and SIMM calibration documents have nothing. Add what is missing for each, add the DQ staging and the publish for each, craft the ACME documents for the reports that read them, and bind them. This task takes over the work of the backlog story Complete the ORE report configuration.

* Acceptance

- Each of the seven documents has entity models, a document store, mappers that round trip the ORE samples, and a service operation to read and write it.
- Each document has DQ staging generated from its entities, an artefact type, a publish function on the shared document publish, and a dataset for each ACME party that declares its dependencies.
- The reports that read a document bind one: the exposure and capital reports bind the simulation, the sensitivity reports and FRTB bind the sensitivity document, Stressed VaR binds the historical return document, and P&L Attribution binds the simulation and the sensitivity documents.
- The readiness check lists no report as blocked on a missing analytic document.

* Plan

1. For each document (simulation, sensitivity, stress test, historical return, Basel traffic light, SIMM calibration, credit simulation), record what exists: model, store, mapper, round trip test.
2. Move the open tasks of the backlog story "Complete the ORE report configuration" into this work, or close them in its favour.
3. Add the missing entity models and document stores, with mappers that round trip the ORE samples.
4. Add the DQ staging, artefact type and publish function for each, on the shared document publish.
5. Craft the ACME documents for the reports that read them and register a dataset for each party with its dependencies.
6. Bind the documents in the bindings of the definitions, and update the readiness check.
