* Acceptance

- A manual point value is validated as the estate's decimals define a number.
- The manual point suite pins that +0.09 is accepted and stored as stated.

* Plan

The service validated with a private =is_number= that refused a leading
plus, while =decimal= — the estate's one definition of a number, used by
=ore_key_codec::is_number= and by =strike_label::parse= — accepts it. Read
the refusal as an accident of the =std::from_chars= the gate used to call
rather than as a rule, because the service accepts =0.090=, another
non-canonical spelling. Validate with =decimal::parse=, the same call the
key codec makes, and correct the test rather than the grammar.
