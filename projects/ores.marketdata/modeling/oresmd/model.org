This manifest file acts as the single entry point for =compass codegen entity
generate <name>= — when loaded, it scans the directory for all sibling
=*_quote_type.org= files, merges their data, and feeds them to the
=ores.cpp.oresmd= facet's archetypes.

* Spec files

The =variant_order= column controls the struct/variant ordering in the header
output files (fx-first), which differs from this table's manifest order (ir-first,
used for the enum output file). The =parse_order= column controls the ordering of
the =parse_*()=/=resolve_*()= function definitions (correlation/inflation/commodity
interleaved as in the hand-crafted files), which differs from both.
