#+description: The economic digest folds an instrument's option, premium, exercise fee and payment date rows, and never reads the option's exercise prices, although read_option_exercise_prices_by_trade_ids exists and the table is economic. A change to an exercise price therefore leaves the trade's economic digest and external version alone. Declaring the digest shape in the trade-type catalogue (the Shared components table) made the omission visible. Add instrument_option_exercise_price to the table with its reader, and add a digest test that changes an exercise price. Listing it changes what the digest covers, so every stored digest changes once.
