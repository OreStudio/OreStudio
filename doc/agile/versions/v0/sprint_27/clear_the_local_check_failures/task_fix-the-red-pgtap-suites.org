* Goal

Running the local gate with the heavy tier on main reports pgtap red: ten of the thirty-two suites fail, and the story that cleared the gate's other failures left this one behind. Eight suites write trades, trade activities and structures without the audit columns their generated tables now require, so every insert dies on the not-null constraint and the suites that write a trade first report zero tests run. One suite reads a party's contacts without setting the party context that the table's own restrictive row level security policy demands, so it sees no row and reports the primary mark missing. One suite calls the LEI counterparty publish twice and the second call hits a temp table the function creates and never drops.
