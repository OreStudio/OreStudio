** What is not done

1. The parent party is a free-text id, because the pick lists carry no party list. A picker is a small follow-up.
2. A membership has no history, which is task 75FC1047. The screen shows the open memberships and the party history is the only trail, as the journey document says.
3. A history revert loads the older party fields into the review. It does not restore the identifiers or the contacts of that version.
4. The unit level rule is checked in the browser and by the server. The browser check cannot see a type the server's rule treats differently.
5. The confirm is several calls. A refusal part way leaves the earlier calls written, and the refusal names the step.
