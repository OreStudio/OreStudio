* Goal

=ores::testing::scoped_environment_override=
(=projects/ores.testing/include/ores.testing/scoped_environment_override.hpp=)
takes a list of key prefixes as well as a list of keys. It removes every
variable whose name starts with a prefix, and restores each one when it goes
out of scope. Each of the 13 =config_parser_tests.cpp= files strips its own
service's prefix (=ORES_<SVC>_SERVICE_=) and =ORES_NATS_=, so a test of a
default asserts the default.
