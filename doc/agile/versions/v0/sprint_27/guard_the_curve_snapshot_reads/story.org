** What

=curve_snapshot_handler= checked no permission and no curve-snapshot read code
was seeded in =iam_permissions_populate.sql=, so any authenticated caller could
read every tenant's curve points. The republish and compute handlers did check
=marketdata::curve_bootstrap:republish= and =:compute=, so this was an oversight
on the read side.

** Resolution

The defect was closed before the capture was promoted.
=projects/ores.marketdata/service/include/ores.marketdata.service/messaging/curve_snapshot_handler.hpp=
checks =marketdata::curve_snapshots:read= at =:81-85= and =:121-125=, and
=projects/ores.sql/populate/iam/iam_permissions_populate.sql:1519= seeds it. The
story is closed on that evidence and carries no tasks, because no work was left
to do when it was promoted.
