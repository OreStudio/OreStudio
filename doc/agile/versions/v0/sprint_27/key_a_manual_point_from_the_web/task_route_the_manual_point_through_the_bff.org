* Result

=POST /api/curves/manual-point= and =POST /api/curves/manual-point/clear= forward to the two operations. The body schemas are strict. A key needs at least one coordinate, a value, a reason code and a non-empty commentary. The server's refusal reaches the browser as 422 with its own words, and a missing permission is 403. Six new tests in =curves.test.ts= cover the forward, the 422, the 403, the structural refusals that never reach the server, and the clear.

The BFF typechecks and its 25 curve tests pass. Not run against the real stack.
