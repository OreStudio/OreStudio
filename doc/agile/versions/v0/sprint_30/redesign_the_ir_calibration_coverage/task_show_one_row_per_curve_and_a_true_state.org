* Acceptance

- The coverage table has one row per curve; the currency and its source show once per currency.
- The window shows only for a feed that overrides the policy.
- The class policy is a compact card: window, inverse rule, fallback, and the source order as numbered chips.
- The IR feeds reach the calibration, so a currency with a feed and a published curve is not shown as having no feed.

* Plan

The screen stacked every curve of a currency in one cell, repeated each curve's
publish time beside a column that held it again, repeated the policy's window on
every row, and said no feed on every row.

1. Find why every row said no feed. The coverage read each currency's feed from
   the calibration of the class. The calibrate handler takes the FX spot kind
   and reads each built input as an FX spot input, so it answers
   =interest_rates= with no feed. The route test passed because it fed the
   calibration an IR feed the service never returns. A first fix that set the
   IR candidate's asset class was dropped: that path never reaches the
   calibration.
2. Read the IR feed facts where they live: the IR generation config says
   whether the feed starts from a fixing, and the running feed's recorded start
   says from which provider, or why it kept its level.
3. Give each curve its own gap from its own publish.
4. Lay the table out one row per curve, the currency and its feed spanning the
   currency's rows; draw the policy as a card.

* Result

The IR calibration coverage is one row per curve: its role, its tenor, the curve
it discounts off, its publish and its own state, with the currency and its feed
named once beside the currency's curves. The class policy is a card with the
window, the inverse rule and the fallback, and the source order as numbered
chips.

All four acceptance points are met, the second by removing the window outright:
an IR config holds no window of its own, so there is no override to show. The
states are true: before, every one of the 28 currencies said no feed; now 10 are
covered, 16 state the reason their run recorded for keeping a fixed level, and 2
have no curve config.
