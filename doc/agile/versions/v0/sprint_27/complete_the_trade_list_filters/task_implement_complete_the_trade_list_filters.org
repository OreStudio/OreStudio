* Acceptance

- An enum column (=counterparty_scope=) declares =:filterable: true=, and the generated member, repository condition and TypeScript type work, with a repository test.
- An invalid enum value gives the same error as other invalid filters.
- A child model declares =:list_by: true= on =trade_id=, and the generated =list_by_trade_id= read works, with a repository test.
- The result states whether the generator supports a view-backed read-only entity, and which instant a view over versioned tables answers.
