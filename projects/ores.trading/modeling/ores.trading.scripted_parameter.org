One named parameter of a scripted trade, keyed to the trade and the
parameter's ordinal.

ORE reads every scripted trade as a script and a set of named parameters of
five kinds: event, number, index, currency and day counter
(=scriptedtrade.cpp=). A generic trade states them under
=ScriptedTradeData/Data= as =<Number><Name/><Value/></Number>=; a named
product such as =MovingMaxYYIISData= states each as an element named after
the variable, typed by its =type= attribute. Either way a parameter is a
name, a type and a value, and the value is a scalar, a list, or for an
event a schedule or a schedule derived from another event. The list is
finite, so every scripted product is these rows.

A list value is =scripted_parameter_value= rows, and an event's schedule is
rows of the shared schedule tables under the owner =scripted= and the
parameter's ordinal.

** Custom repository methods

The trade read path fetches the scripted parameters of many instruments at
once, and no generated read covers that: the generated reads address one key
group at a time. The batch read below is one statement over the instrument
set.

*** read_by_instruments_batch
:PROPERTIES:
:ID: 62499BCF-B42D-475A-B0EB-26FA4FC780CA
:END:

Reads every current scripted parameter of the given instruments, in one statement. An empty input
reads nothing.

#+begin_src cpp :name implementation :implements F2EB1914-5E94-42CA-9C77-46BDB364BF9E
std::vector<domain::scripted_parameter>
scripted_parameter_repository::read_by_instruments_batch(
    const context& ctx, const std::vector<std::string>& trade_ids) {
    if (trade_ids.empty())
        return {};
    static constexpr auto max = db_timestamp::max();
    const auto tid = ctx.tenant_id().to_string();
    const auto query = query_builder::read<std::vector<scripted_parameter_entity>> |
                       query_builder::where("tenant_id"_c == tid &&
                             "trade_id"_c.in(trade_ids) && "valid_to"_c == max) |
                       query_builder::order_by("trade_id"_c, "sequence_number"_c);
    return query_builder::execute_read_query<scripted_parameter_entity,
                                             domain::scripted_parameter>(
        ctx,
        query,
        [](const auto& entities) { return scripted_parameter_mapper::map(entities); },
        lg(),
        "Reading scripted parameters for multiple instruments.");
}
