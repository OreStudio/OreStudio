None: every synthetic repository is generated.

** What else

The pq template opened two namespaces with helpers of the same names, and a synthetic unity batch saw both, so the calls were ambiguous. The template now qualifies the query builder helpers, and dq, analytics and inbox are regenerated with it. The regenerate also brought the trade generation config shell recipe up to date with structures_per_book, which main had added without regenerating it.
