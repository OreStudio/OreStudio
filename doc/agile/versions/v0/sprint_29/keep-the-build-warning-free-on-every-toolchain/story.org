- *The MSVC unity build runs out of template context.* =tenor_basis_swap_pay_receive_entity.hpp='s
  =columns()= spells its 23 bindings as a =|=-chained expression, and
  =std::tuple_cat= over them exhausts MSVC's template context inside
  =unity_60_cxx= of =ores.refdata.core=. Unity batches 16 sources because
  =7f2c4f037a= turned it on (2026-10-27), so the batch is the unit MSVC runs
  out on. Either the binding expression wants a flatter shape or the batch wants
  to be smaller; both are a decision about generated code and build cost rather
  than a typo, and a Windows runner is the only place to check the answer.
