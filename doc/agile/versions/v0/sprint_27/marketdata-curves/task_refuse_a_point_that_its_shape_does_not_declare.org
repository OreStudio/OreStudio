* Goal

The shape tables say what a composite object comprises, but nothing enforces it: a point whose coordinate the shape does not list is still written, so the shape and the points can disagree and the disagreement is silent. Refuse such a point at write time, wherever a point is written, so the two cannot drift. Then let an import declare the shape of the series it carries, so an observed or imported structure has a shape without a build to write one.

* Acceptance

- A point whose coordinate is not a declared axis value of its series is refused, and the refusal names the series, the coordinate and the value.
- The refusal holds for every writer of a point, not only the one that was changed, or the task says which writer it does not cover and why.
- A point for a series that declares no shape is written as it is today, so no existing series stops accepting points.
- An import declares the shape of the series it carries, from the declaration rather than from the points, and a series it does not declare keeps whatever shape it had.
- A series whose declared shape gains a value accepts points at that value without any further change.
