* Acceptance

- The trade model, the five trade field groups and the three envelope models are deleted with every file they generated.
- The wide-trade SQL functions, trading_sample_data_populate and trade_trades_test are gone; the drop scripts and grants no longer name the wide tables.
- The tenant purge deletes instrument rows and the anchor's components before the anchor, through the sanctioned immutability path.
- The round trip stays at in-scope lost 0 with every envelope as stated; build, ctest, pgTAP and the local check set pass.

* Plan

- List every file the nine models generate with =codegen generate
  --dry-run=, delete those files and the models, and regenerate the trade
  component so the shared command table drops them.
- Remove the hand-written wiring: the SQL create and drop includes, the
  wide trade's row-level security, its one SQL function
  (=ores_trading_get_trade_ids_by_books_fn=, which nothing called), the
  envelope readers in =parent_scoped_queries=, the registrars, the event
  mappings and the envelope permission seeds.
- The envelope reader keeps only the booked path, which reads the anchor's
  components.
- Delete the tests of deleted behaviour: the envelope reader test against
  the old tables, the wide trade domain test and generator cases, the
  wide trade pgTAP test, and the never-wired sample trades populate.
- Retire the trading-record profile, whose only binding was the wide
  trade, and repoint the knowledge docs at the anchor and its components.
- Make the tenant purge delete every tenant-scoped trading table in a loop
  that retries a table still referenced by an enforced foreign key, with
  the immutable purge switch on for the anchor. The old purge deleted the
  components and the anchor only, and left every instrument row behind.
- Leave the anchor's name for the next task, which renames it to =trade=.
