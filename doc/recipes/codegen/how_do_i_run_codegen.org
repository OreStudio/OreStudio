* Question

How do I run the ORE Studio C++ code generator?

* Answer

** Everything that changed (preferred)

compass-ng regenerates every output whose model, template or other input
changed, writes nothing else, and formats C++ and TypeScript as the committed
tree is formatted. A warm run with no change takes a few seconds. Preview with
diff, which writes nothing, then write with generate:

#+begin_src sh
./compass.sh diff
./compass.sh generate
#+end_src

A new model file needs no step of its own: =generate= finds it and writes its
outputs.

** The older entry points

=./compass.sh codegen generate=, =codegen regenerate=, =codegen entity
generate= and =projects/ores.codegen/codegen.sh generate|regenerate= all run
=compass-ng generate= now, and with =--dry-run= or =--diff= they run
=compass-ng diff=. Their =--model=, =--address=, =--component= and =--entity=
arguments no longer narrow the run. The Python generator rewrote every file it
rendered, so a regenerate of one template touched thousands of files; these
entry points no longer reach it.

The read-only entity reports stay:

#+begin_src sh
./compass.sh codegen entity list
./compass.sh codegen entity show country
./compass.sh codegen entity archetypes --entity country
#+end_src

* Script

=./compass.sh generate= and =diff= forward to compass-ng through =cmd_compass_ng=
in [[proj:projects/ores.compass/src/compass.py][=compass.py=]]. =cmd_codegen= in the same file forwards the older verbs,
and [[proj:projects/ores.compass/src/compass_codegen_entity.py][=compass_codegen_entity.py=]] holds the entity reports.

* Tested by

Run =./compass.sh codegen regenerate --component refdata --address ores.cpp
--dry-run= and verify it runs =compass-ng diff=.
