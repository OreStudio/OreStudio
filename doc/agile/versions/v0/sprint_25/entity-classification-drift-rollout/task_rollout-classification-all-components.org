- The tool runs successfully over every remaining component and produces a
  single combined drift report with per-component breakdowns and totals.
- Any component-specific wrinkle the tool doesn't handle (new artefact kind,
  different tenancy pattern, etc.) is resolved, not skipped or silently
  scored as N/A.
- Each of the 14 ad hoc "Fix =<component>= entity model drift" tasks is
  either closed as covered, or re-scoped with the report's concrete findings
  replacing its original guess.
- =entity_coverage_matrix.org=, =entity_evaluation_checklist.org=, and
  =entity_catalogue.org= are deleted; anything from them still useful is
  captured in the tool/report or its documentation first.
