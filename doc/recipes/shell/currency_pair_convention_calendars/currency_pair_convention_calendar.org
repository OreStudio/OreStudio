#+title: How do I run the currency_pair_convention_calendars commands from the shell?
#+description: Every command the currency_pair_convention_calendars submenu answers, with the script each one exports into the shell's script library.
#+type: recipe

This file documents the currency_pair_convention_calendars resource at the shell, one section per command. Every command is a subcommand of =currency_pair_convention_calendars=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: F4472163-2815-5F65-A703-03EDEC90310E
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
currency_pair_convention_calendars list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =refdata.v1.currency_pair_convention_calendars.list=.

#+name: currency_pair_convention_calendars-list
#+begin_src ores-shell :tangle currency_pair_convention_calendars-list.ores :exports none
currency_pair_convention_calendars list --limit 1
#+end_src

** =add=
:PROPERTIES:
:ID: 733AC46B-2963-5E69-A8E4-281BDD21D58E
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.


The command is shaped like this:

#+begin_example
currency_pair_convention_calendars add <pair_code> <calendar_code> <reason> <commentary>
#+end_example

It is addressed at =refdata.v1.currency_pair_convention_calendars.put=.

#+name: currency_pair_convention_calendars-add
#+begin_src ores-shell :tangle currency_pair_convention_calendars-add.ores :exports none
currency_pair_convention_calendars add __none__ __none__ system.new_record generated_script
#+end_src

** =set=
:PROPERTIES:
:ID: 8609B8F6-8F78-5DB4-8B09-336B30CDB0B4
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved. Passing --version makes the write conditional on the version the caller last read.


The command is shaped like this:
