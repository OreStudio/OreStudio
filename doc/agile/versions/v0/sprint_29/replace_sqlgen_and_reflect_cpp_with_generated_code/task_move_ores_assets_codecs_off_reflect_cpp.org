* Notes

** The dq publish command is shared

=publish_from_dq_command= and =publish_from_dq_result= are read and written by
the publish handler of six components: assets, dq, synthetic, reporting,
refdata and iam. Their model was not opted into the codec with dq's, so this
task opts it in. The other five handlers keep reflect-cpp until their own
component tasks move them; the generated codec does not change what
reflect-cpp writes for them.

The api library still links =ores.rfl.pch=; [[id:7A1D09B8-B3F2-4E02-9669-3C2F6CC2C6EC][Remove reflect-cpp]] replaces it.
