* What

Deleting a currency leaves its links behind. The currency's rows in currency_countries, currency_calendars and currency_currency_groups stay when the currency is deleted, so a currency re-created with the same code opens with the old links already in place. Seen on 2026-10-26 by the currencies scenario: ZZS deleted and added again showed TARGET and Scandies linked before the step added them. The calendar's business days show the same shape (captured apart). The delete of a currency should close its links, or the remove dialog should say what stays.

* Why

The delete of a currency should close its links, or the delete dialog should say what stays. A currency re-created with the same code inherits links nobody chose for it, and the scenario runner had to skip links it found already there.
