** A service test that depends on the environment

=the adapter announces again until the service answers= starts an adapter and
expects no answer for 300 ms. This environment runs its own
=ores.marketdata.service=, whose adapter supervisor subscribes to the announce
subject and answers, so the case fails here on every run. The marketdata
service still decodes with reflect-cpp and the codec writes the bytes
reflect-cpp wrote, so the answer does not depend on this change; this is
inferred, not proven by running main's binary.

* Result

ores.synthetic encodes and decodes without reflect-cpp. Its 26 models use the
generated codec, its dq publish handler reads and writes through it, and no
synthetic source outside the tests includes reflect-cpp. The bytes match
reflect-cpp's.
