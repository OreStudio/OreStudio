* Summary

=ores.variability= holds the platform's typed runtime configuration as a
single bitemporal table of named settings. A setting is named by a dotted
string such as =system.bootstrap_mode=, carries a type and a value, and is
scoped to a tenant and a party. Components read settings in process and are
told when one changes, so a configuration change takes effect without a
restart; the shell and other clients read and write the same settings over
NATS.
