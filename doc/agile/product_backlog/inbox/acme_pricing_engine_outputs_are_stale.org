This page is a [[id:671F18E4-E09C-4B3B-BD24-D33DF8AE38A6][capture]] in the *inbox* bucket of the product backlog — a pre-sprint idea, not yet pulled into a sprint as a story.

* What

Regenerate the Acme pricing engine outputs and commit them, so a run of =generate_configuration_data.py= changes only what its author meant to change.

On 2026-11-11 the run for PR #4600 rewrote =pricing_model_product_parameters.json= and the four =acme_*_pricing_engines_artefact_populate.sql= scripts (812 insertions, 224 deletions), adding settings such as =FxCalibration Bootstrap=. Those settings come from =../ore_pricing_engines/pricing_vocabulary.json=, which is newer on main than the committed outputs. The PR left those files out.

* Why

Every later change to the Acme configuration generator meets the same unrelated diff, and must either carry it unreviewed or restore it by hand. The live Acme pricing engines also lack the settings the vocabulary now says ORE needs.
