* Goal

The Windows CI build breaks at
projects/ores.database/src/service/postgres_listener_service.cpp:27
with C1083: cannot open include file 'unistd.h'. PR #1998 introduced
the POSIX-only include together with ::getpid() to name the listener's
dedicated connection. The fix restores the Windows build by adding
ores.platform::process::current_pid() — a cross-platform wrapper over
boost::process::v2::current_pid() — and migrating every getpid call
site to it, retiring the ad-hoc #ifdef patterns.
