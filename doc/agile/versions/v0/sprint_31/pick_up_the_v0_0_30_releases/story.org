* Decisions

** 2026-11-24 — the database stays on PostgreSQL 18 for this release

The 19 move was proven end to end on a throwaway cluster: =initdb= on 19.0, the
whole =compass db recreate=, 853 tables against 18's 855 with the difference being
pgTAP's own two, and both required extensions present. It stops there because
TimescaleDB has no package for 19 in any of the three places it could come from:
the Debian forky archive, PGDG's forky and trixie suites (both stop at
=postgresql-18-timescaledb=), and TimescaleDB's own packagecloud repository, whose
forky index is empty.

Without it the create scripts guard each hypertable and keep plain tables, so
nothing breaks. The loss is hypertables, compression and retention on the
market-data and session tables, which is a heavier cost for the fleet than being
one major version behind. The move becomes its own work when the package lands,
and the tables convert in place then.
