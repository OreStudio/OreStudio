#+description: pricingengine*.xml end to end: the engine definitions a report's valuation selects, each naming the model and engine it binds and the parameters it carries. The corpus holds 125 files under the PricingEngines root and nothing of this kind round trips. Write both mappers and prove the round trip with the harness over every file in the corpus.
