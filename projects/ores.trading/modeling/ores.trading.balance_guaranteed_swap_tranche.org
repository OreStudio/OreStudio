One row per tranche a balance guaranteed swap states, keyed to the
instrument and the tranche's ordinal.

The ORE schema states the tranches as a list under the swap's =Tranches= block.
A tranche names its security, its seniority and an optional description, and it
holds a list of dated notionals that live in
=balance_guaranteed_swap_tranche_notional=. The block's schedule is not here: it
is a schedule of the shared kind, so it lands in =instrument_schedule= under the
owner role =tranches=.

** Custom repository methods

The trade read path fetches the tranches of many instruments at once
when it assembles the export payload, and no generated read covers that.
The batch read below is one statement over the instrument set.

*** read_by_instruments_batch
:PROPERTIES:
:ID: ba78d3e3-a76d-4f7b-aceb-98bed959816e
:END:

Reads every current balance guaranteed swap tranche of the given instruments, ordered by
instrument and ordinal, in one statement. An empty input reads nothing.

#+begin_src cpp :name implementation :implements F2EB1914-5E94-42CA-9C77-46BDB364BF9E
std::vector<domain::balance_guaranteed_swap_tranche>
balance_guaranteed_swap_tranche_repository::read_by_instruments_batch(
    context ctx, const std::vector<std::string>& trade_ids) {
    if (trade_ids.empty())
        return {};
    static const auto max(make_timestamp(MAX_TIMESTAMP, lg()));
    const auto tid = ctx.tenant_id().to_string();
    const auto query = sqlgen::read<std::vector<balance_guaranteed_swap_tranche_entity>> |
                       where("tenant_id"_c == tid && "trade_id"_c.in(trade_ids) &&
                             "valid_to"_c == max.value()) |
                       order_by("trade_id"_c, "sequence_number"_c);
    return execute_read_query<balance_guaranteed_swap_tranche_entity, domain::balance_guaranteed_swap_tranche>(
        ctx,
        query,
        [](const auto& entities) { return balance_guaranteed_swap_tranche_mapper::map(entities); },
        lg(),
        "Reading balance guaranteed swap tranches for multiple instruments.");
}
