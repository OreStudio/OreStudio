#+title: How do I run the currency_pairs commands from the shell?
#+description: Every command the currency_pairs submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:currency_pairs:

This file documents the currency_pairs resource at the shell, one section per command. Every command is a subcommand of =currency_pairs=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: 6F5EA669-5FD6-5D8C-A7FE-A1233E27D482
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
currency_pairs list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =refdata.v1.currency_pairs.list=.

#+name: currency_pairs-list
#+begin_src ores-shell :tangle currency_pairs-list.ores :exports none
currency_pairs list --limit 1
#+end_src

** =get=
:PROPERTIES:
:ID: 0D6A370D-C909-5ED4-A201-7628A674DD64
:END:

Reads the one row its key addresses. A key states every identifying column, so a partial key is refused rather than answered with an arbitrary row.


The command is shaped like this:

#+begin_example
currency_pairs get <pair_code>
#+end_example

It is addressed at =refdata.v1.currency_pairs.get=.

#+name: currency_pairs-get
#+begin_src ores-shell :tangle currency_pairs-get.ores :exports none
currency_pairs get __none__
#+end_src

** =add=
:PROPERTIES:
:ID: BEC0D025-8259-50F4-86F9-003F2283AF53
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.


The command is shaped like this:

#+begin_example
currency_pairs add <pair_code> <base_currency> <quote_currency> <classification> <reason> <commentary>
#+end_example

It is addressed at =refdata.v1.currency_pairs.put=.

#+name: currency_pairs-add
#+begin_src ores-shell :tangle currency_pairs-add.ores :exports none
currency_pairs add __none__ __none__ __none__ __none__ system.new_record generated_script
#+end_src

** =set=
:PROPERTIES:
:ID: 1AC64939-8954-546C-9411-E9FD7CC4E5E5
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved. Passing --version makes the write conditional on the version the caller last read.


The command is shaped like this:

#+begin_example
currency_pairs set <pair_code> <base_currency> <quote_currency> <classification> <reason> <commentary> [--version <n>]
#+end_example

It is addressed at =refdata.v1.currency_pairs.put=.

#+name: currency_pairs-set
#+begin_src ores-shell :tangle currency_pairs-set.ores :exports none
currency_pairs set __none__ __none__ __none__ __none__ system.new_record generated_script
#+end_src
