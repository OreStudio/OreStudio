#+title: Swap points and interest rate differentials are two views of one number
#+description: Swap points imply a rate differential and the reverse, so a system can key one and derive the other.
#+type: knowledge
#+level: cross
#+filetags: :domain:finance:fx:fx_forward:

* Summary

Swap points and an interest rate differential determine each other through parity. Brokers derive the bid and ask interest rates of a currency from swap points quoted by banks. A system can hold either one and derive the other.

* Detail

*Open question.* Should ORE Studio let a user key swap points, derive them only, or configure this by pair? It derives them today.
