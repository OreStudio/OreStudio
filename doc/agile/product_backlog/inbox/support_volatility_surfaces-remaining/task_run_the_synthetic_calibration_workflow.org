* Goal

Calibrating the synthetic feeds is one workflow a person can follow step by step. synthetic_calibration_workflow runs in the system tenant: load_public_rates, then calibrate_feeds as an applied run, then approve_within_policy, then tell_reviewer, which sends the inbox a message naming the fits that wait. The policy is stop, and each step is idempotent, so the engine's retry resumes a failed run. An operator starts it from the Calibration screen, and another run can start it as a step.
