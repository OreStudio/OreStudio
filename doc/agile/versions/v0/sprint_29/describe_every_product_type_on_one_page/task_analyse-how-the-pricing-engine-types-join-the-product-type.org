* Acceptance

- Every one of the 108 pricing engine types appears in the mapping with a product type code or a stated reason for having none.
- The 57 types with no trade type are classified as product, configuration or building block, with the evidence for each.
- The join shape is decided and written down: a junction keyed by both codes where one product type takes several engines, a column where it takes only one.
- The hand-written prose of the 108 is given one home, and the investigation says which.
