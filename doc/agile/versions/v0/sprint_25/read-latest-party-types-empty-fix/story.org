* Goal

Fix bitemporal read_latest queries returning empty results in non-UTC sessions.

The C++ constant MAX_TIMESTAMP was misaligned with the database function
ores_utility_infinity_timestamp_fn(), causing WHERE clauses to drop their
valid_to filter in non-UTC sessions due to PostgreSQL plan-time folding
of IMMUTABLE functions.

* Result

Fixed by syncing the C++ constant MAX_TIMESTAMP from "9999-12-31 23:59:59"
to "9999-12-31 23:59:59+00" to match ores_utility_infinity_timestamp_fn()
in the database. The timezone-aware literal remains timezone-independent
and prevents PostgreSQL's plan-time folding optimization from dropping the
valid_to filter in non-UTC sessions.
