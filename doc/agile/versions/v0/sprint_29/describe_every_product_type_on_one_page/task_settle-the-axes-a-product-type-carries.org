* Goal

A product type says what a desk needs in one row, and no second classification is invented for it. The eight values of product_type_t map onto the axes with no loss, and each axis has one code set, one spelling and one owner.

* Acceptance

- The page records each axis, its code set, its spelling and the entity that owns it.
- All eight product_type_t values map onto the axes, including composite and scripted, and the routing family the instrument table needs is named.
- rates, interest_rates, swap and InterestRate resolve to one spelling, and the mapping is recorded.
- has_options and has_extension keep a stated meaning, or are replaced by something that states it.
