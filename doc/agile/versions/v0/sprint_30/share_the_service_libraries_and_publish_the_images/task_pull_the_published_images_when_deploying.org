* Result

compass env deploy <host> --pull fetches the published images on the host and
tags each one under the local name remote-run.sh resolves, so the remote side
of a pull deploy and a transfer deploy are the same script. --registry
defaults to ghcr.io/orestudio; --image-tag selects a moving tag such as main,
and without it the deploy pulls the version-commit tag this checkout would
publish. A pull deploy skips the local image check, and the compute wrapper is
published so the compute role can pull too.

Verified on pauli: the generated pull script ran through ssh with
docker.io/library/alpine (pull, then the two local tags), and the test images
were removed afterwards. The full ghcr.io path needs the nightly to publish
first.
