#+title: ores.marketdata.adapter_operations
#+description: Codegen operation model for the four messages an adapter and the market data service exchange: announce, demand, tick and heartbeat.
#+type: ores.codegen.operation

#+brief: The announce, demand, tick and heartbeat messages of the adapter contract.
#+filetags: :model:operation:marketdata:
#+created: 2026-10-23
#+updated: 2026-10-23

An adapter and the market data service meet at four messages: announce, demand, tick and
heartbeat. This model declares the four, and the vendor id and the rejected id they share.
The messages carry no subject here, because the subjects hold an adapter id and a vendor id.
=ores.marketdata.api/domain/adapter_subjects.hpp= builds them.

No message names a tenant, a party, an oresmd URI or a source kind. The service applies the
mapping and the routes. The adapter knows only the ids of its provider.

/**
 * @brief One value a provider publishes: an id scheme, an external id and a field.

** adapter_announce_request

What an adapter tells the service when it starts.

#+begin_src cpp :name comment
/**
 * @brief An adapter announces itself, its provider and its universe.
 *
 * The universe is the set of ids the adapter can serve. The service checks it
 * against the catalogue of the provider and never takes it as the catalogue.
 */
#+end_src

*** adapter_id
:PROPERTIES:
:cpp_type: std::string
:END:

The opaque id of the adapter. No code parses it.

*** adapter_code
:PROPERTIES:
:cpp_type: std::string
:END:

The code of the adapter module that sent the announce, as the catalogue spells it. It is
what makes an adapter installed: the service lists a module as installed from the first
announce it answers, so an installation that never runs a module never claims it.

*** module_version
:PROPERTIES:
:cpp_type: std::string
:END:

The version of the module that sent the announce.

*** provider_code
:PROPERTIES:
:cpp_type: std::string
:END:

The code of the provider whose ids the adapter publishes.

*** universe
:PROPERTIES:
:cpp_type: std::vector<vendor_id>
:END:

The ids the adapter can serve.
