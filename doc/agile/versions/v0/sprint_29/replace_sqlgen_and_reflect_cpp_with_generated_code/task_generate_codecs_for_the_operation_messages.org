* Goal

No operation model states the wire-codec facet, so every message an operation declares still travels through reflect-cpp, in every component. The operation and family sections of the protocol template state the shape and the codec specialisations the entity section states, and a codec translation unit defines them.

- An operation or family model that enables the wire-codec facet writes each message's shape, its codec declarations and its codec translation unit.
- The trading operation messages use the generated codec, and the export blob is written with it.
- A test proves an operation message's generated bytes equal reflect-cpp's, in both formats.
