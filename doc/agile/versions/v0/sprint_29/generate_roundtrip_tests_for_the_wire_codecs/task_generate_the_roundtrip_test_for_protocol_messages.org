* Acceptance

- Entity, junction, operation and family messages are covered.
- The pilot component builds and its generated tests pass.

* Plan

- A new archetype, =ores.cpp.wire-codec.protocol_roundtrip_tests=, writes one
  test file per protocol header, beside the entity roundtrip tests. It follows
  the protocol codec unit section by section: entity, junction, operation and
  family, with operations and families only where the codec is generated.
- One case per message, named by its qualified type. There are 590 headers
  with about 13,500 messages, so four cases per message would be about 54,000
  cases. The case calls =ores::testing::check_wire_roundtrip=, which states
  the member-count guard and the four checks once, so the generated files
  declare no names and build as unity units without clashes.
- The tests include the same codec headers as the codec unit, and the envelope
  shapes in =ores.utility/domain/protocol_codec.hpp=. The dq pilot failed to
  compile without that header: =result=, =order=, =precondition= and
  =change_intent= had no sample.

* Result

The archetype =ores.cpp.wire-codec.protocol_roundtrip_tests= writes 590 test
files across 18 components, one per protocol header, with one case per message.
Each case calls =ores::testing::check_wire_roundtrip=, which requires the
sample and the default value to roundtrip in JSON and in MessagePack, and the
message's =wire_fields= to name every member. All 14,515 cases pass.

The full build found one gap: =mint_storage_capability_request= holds a vector
of =ores::security::jwt::storage_grant=, which had no equality. It now has a
defaulted one. The branch also emits the entity roundtrip tests of nine refdata
models that reached main after the entity task.

The first full run failed 33 cases in three suites. 32 read tables that the
database did not have, because it predated models from main; they pass after
=compass db recreate=. One was a timed wait in the marketdata service ingest
loop under =-j 4= load; it passes when the suite runs alone. Neither touches
this change.
