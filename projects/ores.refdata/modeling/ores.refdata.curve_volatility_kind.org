An ORE volatility entry writes either one bare kind element, or a
=VolatilityConfig= element holding up to one of each of seven kinds in an
=xs:all=. Each kind is its own complex type, and every one of the seven repeats
the same four terms: =QuoteType=, =VolatilityType=, =ExerciseType= and
=Calendar=. Each also carries a =priority= attribute, because an entry may hold
several alternatives and ORE builds the first that succeeds.

This row is that kind: which kind it is, where it sits in the order, and the four
terms. They are columns of this row rather than of each kind's part, because the
row is what makes them appear once: seven kinds sharing four columns is a group,
seven kinds each having their own four is a union. The kind's own fields live in
the kind's part, one table each, as =curve_volatility_strike_surface= does for
=StrikeSurface=.

The kind is the discriminator, and it is a row rather than a column because an
entry holds several of them.
