* Goal

One call proposes a change. It refuses a proposal that would make a loop, that names the person as their own manager, or that repeats one already waiting, and it tells the proposed manager.

* Acceptance

- propose_reporting_line raises an iam.reporting_line request naming the proposed manager as decider, and records the detail.
- A loop, a self-report and a second open proposal for the same person are refused with a message.
- If recording fails the request is withdrawn, so the queue never holds a proposal that names nothing.
- The proposed manager gets a notification linking to the request.
