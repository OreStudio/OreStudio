* Acceptance

- Every dataset whose rows are resolved against the system tenant is a member
  of =system_core=, and the sweep that establishes this names how each one was
  found rather than listing the tables it happened to look at.
- The ER diagram image matches the diagram source, and the drift gate covers
  both so they cannot part again.
- The web service either carries an identity of its own or carries no picture:
  a published avatar nothing references is not an answer.
- The fpml dataset-dependency file is produced by its generator, and
  regenerating it changes nothing.
