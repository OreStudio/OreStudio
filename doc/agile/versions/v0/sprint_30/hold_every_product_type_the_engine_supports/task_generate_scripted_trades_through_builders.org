* Acceptance

- convention_lookup answers what each scripted builder asks.
- One scripted builder takes a library script and typed variables, checks them
  against the script's inputs as the script library task holds them, and builds
  every generic ScriptedTrade; the class-read types (DoubleDigitalOption,
  PerformanceOption_01, Autocallable_01) each have a builder of their own.
- The scripted planner draws values and calls the builders; its construct_* functions and *_terms structs are deleted.
- The generator books Autocallable_01.
- The scripted entries leave the recorded trades' known lists, and the recorded files change in the same commit.
- The ORE engine test reads and builds every booked scripted type.
- The roundtrip tests read every ORE sample trade of each booked scripted type and write back every element ORE needs.
