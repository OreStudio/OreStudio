* Goal

A person inspecting a curve reads what the market quoted at the previous close and how far the curve has moved, from the server, without a second screen and without the browser deciding which set was current.

* Acceptance

- The analytics request states an optional compare-at instant; empty means no comparison and the answer states none.
- The answer states, for each pillar, the prior zero rate and the change in basis points, read from the party's published set at or before the compare-at instant.
- A compare-at instant with no published set leaves the prior fields absent and says so, rather than showing a zero.
- The curve inspector draws the prior and the change when the answer carries them, and the columns are absent when it does not.
- Both sides are tested: the read against a published fixture, and the screen against an answer.

* Result

The read compares: a request states an instant, and the answer carries the party's
published set that was current then — published by then, its as-of at or before it,
not withdrawn — with each pillar's prior zero rate and the change in basis points.

The screen draws the prior and the change columns when the answer carries them, and
says no set was current when the instant found none, rather than drawing a zero. The
query is keyed by the comparison so changing the date refetches.

Five cases hold the read (29 assertions across the analytics suite, including the
absent branch), and nine hold the screen. The live probe of the route was refused
upstream ("bad_request") and is not yet explained: the request names a bootstrap
configuration and an as-of later than the server's clock, so the refusal is likely
one of those two rather than the comparison.
