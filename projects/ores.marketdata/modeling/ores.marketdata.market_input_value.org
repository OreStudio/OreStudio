The market a run read, one value at a time. The engine writes back the quotes,
the fixings and the dividends it loaded, so a run states what it priced against.
Each of those values is a row here, scoped to the run.

These are not observations: the observations a run reads come from this store,
so writing the run's copy back as an observation would duplicate it and replace
its provenance with the run's. A row here says what one run saw.

** Bitemporal natural keys

A run's inputs are its own. The key is where the engine stated the value: the
result, the file and the line. The insert trigger closes the current
row of the same key, and the key names the run, so one run never closes another
run's values.
