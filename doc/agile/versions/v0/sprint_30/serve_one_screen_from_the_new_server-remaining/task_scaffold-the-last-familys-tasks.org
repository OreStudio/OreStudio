Twenty-four routes, of which twenty-three are in the fifty the area counts and
one, the pricing engines' vocabulary, is a route the screen calls that the
inventory states as not an API.

Two facts about the split a reader of the design note should know.

**The value set reader does not live in the reporting part.** The design note
says it does. The five routes the story's Acceptance moves here are reference
data area routes, and the reference data part already answers
=/api/conventions/{family}=. The reporting part already links
=ores.refdata.api=, so a reference data part that read value sets through the
reporting part would close a cycle between two part libraries. The reader goes
in =ores.http.core=, beside the history and change route helpers, and the
reference data part links that.

**The pricing engines' vocabulary is a route the screen calls.** The inventory
states it as not an API, in no area, and it is not in the fifty. The editor
requests it at =packages/web/src/api/pricingEngines.ts=, so the screen breaks
without it when the BFF goes. This is the shape of =choices=, which this story
served and paired as a not-an-API route for the same reason.
