#+title: ores.reporting.configuration
#+description: Codegen entity model for the reporting =configuration= table. A named, reusable configuration a report binds.
#+type: ores.codegen.entity
#+component: reporting
#+filetags: :model:entity:reporting:
#+brief: A named, reusable configuration a report can bind.
#+entity_singular: configuration
#+entity_plural: configurations
#+entity_title: Configuration
#+created: 2026-09-27
#+updated: 2026-09-27

The name is ours; the detail lives with the component named by
=owning_component=. A report binds a configuration through
=report_configuration=, so several reports share one configuration without
copying it, and the kind of configuration it is comes from
=configuration_type= by foreign key rather than from a text code.

** id
:PROPERTIES:

Surrogate key for the configuration.

** name
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:END:

The name of the configuration. It is ours, not ORE's, and it is what a
report refers to.

** configuration_type_code
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:END:

The kind of configuration this is.

** owning_component
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:END:

The component that owns the detail of this configuration, for example
analytics or refdata. Reporting references it rather than copying it.
