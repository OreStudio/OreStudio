* Plan

1. Register each reference kind with the round-trip harness and measure it
   before changing anything, because the mappers were written for import and
   nothing had ever compared their output with their input.
2. State a normalisation in the kind's comparison only when the two documents
   carry the same information, and only as narrowly as the normalisation is.
3. For a kind whose difference is a lost field, fix the model rather than the
   comparison, and record the fix if it is larger than this task.

* Notes

- The harness is hidden for the two kinds that do not pass, because their
  failures are losses rather than comparisons that need stating, and a test
  that asserts a loss is green is worse than a measurement a person reads.
- *Currencies.* ORE's =CurrencyType= has no home on the refdata currency.
  =monetary_nature= is a different axis and the translation into it is not
  invertible, since =Major= and =Minor= both become =fiat=. The fix is a column
  carrying ORE's type, seeded as a lookup, mapped one to one.
- *Conventions.* The mapper models nine categories and skips the rest silently,
  which its own header says. The corpus needs at least the Zero convention's
  =TenorBased= and the categories the header names. The mapper must also stop
  skipping silently, because a silent skip is why 72 files went unmeasured.
- *Calendar adjustments.* The one normalisation is that an empty date list may
  be written as an empty element or omitted. A list with dates is compared date
  by date, so the rule cannot hide a dropped date.
