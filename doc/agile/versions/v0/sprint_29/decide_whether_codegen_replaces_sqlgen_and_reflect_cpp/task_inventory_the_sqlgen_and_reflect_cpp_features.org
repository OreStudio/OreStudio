* Goal

A complete list of the sqlgen and reflect-cpp features the platform uses, in
generated and hand-written code, with what generated code over native APIs
must provide to replace each one.

* Acceptance

- Every sqlgen construct and every reflect-cpp construct in use is listed, with
  its count and whether its uses are generated or hand-written.
- Every type the libraries encode for us is listed: UUIDs, timestamps, exact
  decimals, optional values, enums, nested vectors, polymorphic messages.
- Each entry names what replaces it, or why it stays.

* Notes

- Writes go through =execute_write_query= in =ores.database=, which issues one
  =sqlgen::insert= for each row, inside a unit of work for a batch.
- The NATS wire codec chooses JSON or MessagePack at run time, both through
  reflect-cpp templates instantiated for each message type.
- Most of the use is generated, so a change to the templates changes most of it.
