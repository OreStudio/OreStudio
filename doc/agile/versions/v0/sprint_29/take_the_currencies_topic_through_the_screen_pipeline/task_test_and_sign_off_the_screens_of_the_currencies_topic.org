* Plan

Follow step 4 of the screen pipeline runbook on a fresh database. Recreate the
database and provision Acme, write the test scenario over the three lists, a
record of each kind, create, links, the stale amend, history and revert, the
export and the import of a change, a desk group's members, a pair with its
convention, delete and the reader, and drive it with a script, one function
per step, so the run is repeatable and its log is the evidence. Run the
harness on each screen alone, fold the run into a sheet per screen with
=screen_sign_off.py=, fill the person's lines from the scenario and its
screenshots, and record the verdict. File every gap the walk finds as a
capture, or fix it when it is the screen's and small. The sign off that
closes the topic is the owner's walk, so the task waits on it.
