* Result

* Result

Every leg now splits its results. The expansion step used to sit inside the
branch that runs =ctest_test=, so the memcheck legs submitted one entry per
suite: =linux-clang-debug-ninja= reports 112 entries where =linux-clang-release=
reports 30,457 cases.

The script needed no change. It reads the suite's command line for the path its
Catch2 results were written to, and a valgrind command line carries that path
like any other. Two rules still hold the suite-level entry where the cases
cannot account for it, which is what a valgrind defect on an otherwise passing
suite looks like.

Verified locally: a hand-built memcheck entry expands into its six cases, and
the same entry with the suite failed and every case passing stays one entry.
The CMake configure is clean.
