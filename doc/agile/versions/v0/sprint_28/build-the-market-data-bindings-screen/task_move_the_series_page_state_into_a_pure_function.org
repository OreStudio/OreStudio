* Goal

The series page says no URI, an error, loading, a fixing, an unknown type, a series that is not listed, a series with an axis, or the values. The choice is a chain of conditions in the component, and the page has no render test because there is no DOM test library. A pure function that takes the query results and returns the state can be tested for each case.

* Acceptance

- A pure function returns the state of the page from the results of its queries.
- Each of the states has a test.

* Plan

The page reads three things: the parts of the URL in the address, the codec's
schema, and the series the party can see. The choice among the situations is a
function of those three answers and of the address, and of nothing else.

1. =market/seriesState.ts= holds the choice beside the page, the way
   =market/evolutionView.ts= holds the Evolution page's rules. It exports
   =SeriesPageState=, a tagged union with one kind for each situation the page
   draws, and =seriesPageState=, which takes the answers and returns one kind.
2. The answers are a plain union of =answer=, =error= and =waiting=, not
   TanStack query objects, so the rule holds no hook and no framework type.
   =SeriesPage.tsx= maps each query to that union in one small adapter.
3. The function keeps the order the component held: no URI, then the first
   failed read, then waiting, then the parse verdict, then the series the
   address names. It is a move, so the same address draws the same words.
4. The component is a switch over the state, and the state carries the series
   the situation needs. The Evolution link target is built from the address,
   which is where it came from before.
5. =seriesState.test.ts= states the reads for each situation and the whole
   state it must return, as a literal.

* Result
Merged as [[https://github.com/OreStudio/OreStudio/pull/3509][#3509]].

- =market/seriesState.ts= holds =SeriesPageState=, a tagged union with a kind for
  each situation the page draws, and =seriesPageState=, which takes the answers
  of the reads and the address and returns one kind.
- The reads arrive as a plain union of =answer=, =error= and =waiting=. The rule
  holds no hook and no framework type.
- =SeriesPage.tsx= is a switch over the state. What a person sees for a given
  address did not change.
- =seriesState.test.ts= states a case for each of the nine situations, each with
  the whole expected state as a literal. 18 tests, and the file passes.
- Limitation. No render test of the page. The workspaces hold =react-dom/server=
  and no DOM library, so the switch is covered by the typecheck and the state
  tests only.
