Unit plan, written at start on 2026-09-07. The canonical method is the
codegen-fix-drift skill (steps 1-8); the byproduct-sweep and two-mode
drift rules of the regen-byproduct-hygiene memory are in force

  Notes); survey every model file, classify by metatype, compute

  7-8).* The history-provider families materialized by the baseline

  deliberately unwired); then the registry entry and the =--all= run.
