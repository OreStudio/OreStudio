* Result

A tenant opens in place.

- *A scoped read in the client.* =OresClient.readInsideTenant(tenantId, read)=
  enters the tenant, hands =read= a caller that carries the tenant's token, and
  leaves in a =finally=, whatever the read did. The token is never put on the
  session, so a call the session makes meanwhile keeps its own token; a tenant
  session is not refreshed, so a read that outlives it fails.
- *Two routes.* =GET /api/tenants/:code/parties= and
  =GET /api/tenants/:code/people= read inside the tenant, for system
  administration only; an unknown code or the system tenant is no tenant, and
  the server's refusal of the entry is a 403.
- *The tenant's screen* has Overview, Parties and People tabs, kept in the
  address, and a quiet *View only* label; the *Act in this tenant* button is
  gone.
- *Removed with its callers:* the session-level enter and leave routes, the
  client's entered tenant and its error, the session's acting-in state, the
  read-only request hook, the shell's banner, the session provider's enter
  and leave, and the home page's read-only flag.
- *Words.* The parties page's "On another page" said something the parent
  read by id made false; a parent left unnamed is now one the session cannot
  see, and says so, in all three languages.
- *Journey.* =journey_act_inside_a_tenant.org= describes the tabs, the read
  per request and the audit record each read leaves.
- *Tests:* 5 client cases for the scoped read (tenant token on the read and
  the exit, the session's own token kept and used by a concurrent call, a
  refused entry, an exit after a failed read, no refresh on a lapsed tenant
  session); 6 BFF cases for the routes; the tenant page's tabs; the old
  tenant-session and banner tests removed with what they tested. BFF 128, web
  230, wire protocol 68, all passing; typecheck and prettier clean.
- *Not read live*, for the reason task 1 gives; the story's final deployment
  reads it.
