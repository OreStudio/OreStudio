* Goal

* Result

Wrote the [[id:2BF7F03F-6BF4-45FF-8E26-4D3B4E2D943D][Record screen standard]]
in =doc/knowledge/ui=. It keeps the scope of the retired Qt-derived entity
specification: words, what a record kind declares, layers, addresses, the list
(header, search, table, server paging, states, recency), the record page (tabs,
fields, last changed), writes (form, create, amend, delete, read-only), history,
related records (links and parts), icons and cells, feedback, access, safety,
naming, exceptions, and the steps to build a screen. It speaks of record
screens, not entities: a journey decides which records, and the standard decides
how each record screen looks and behaves.

Each rule names its shared component, with a status, and the standard lists
where each of today's screens differs. The UX language page no longer tells a
journey step to draw its own table, the retired specification points to the new
page, the knowledge index lists it, and a memory makes record screens follow it.
The two follow-up tasks hold the conformance work, server paging first.
