Two structural facts the rest of the task turns on:

1. **There is no root model.** Every other composite keeps its models and its
   root `component_overview.org` in `projects/ores.<component>/modeling/`, and
   sets `#+subcomponent:` on each model to route the output into a part. This
   component has no `projects/ores.telemetry/modeling/` directory at all: only
   the three part directories. M10 and H05 both ask for the component's own
   overview, and the catalogue's `modeling_dir` needs a directory to point at,
   so the task creates one.

2. **The messaging reference is prose, and it is thin.** It documents one of
   the six subjects the component owns (`telemetry.v1.logs.list`) and links to
   the component overview. It is not a model and nothing generates from it.
