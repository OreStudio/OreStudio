* Result

The system administrator's home now has an Installation section between the tenant health figures and the cards. It shows the same six figures as the services screen, from the same hook and component: services running of those expected, lost, missing, errors and warnings in the last hour, and the newest release. Each figure leads to the services or logs screen. The section does not appear for a tenant administrator or a member. The tenant health figures stay. The web package passes 643 tests and the format check. I did not look at the home in a browser.
