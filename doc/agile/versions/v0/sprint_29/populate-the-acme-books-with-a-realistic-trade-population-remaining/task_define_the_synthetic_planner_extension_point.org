* Acceptance

- A planner is a pure function of the generation config and returns a plan.
- One writer sends any plan through the shared booking client.
- The bond planner uses the interface, and the old bond-specific writer is deleted.
- A test adds a second asset class planner with no change to the writer or to booking.
- A second run of any planner books nothing.
