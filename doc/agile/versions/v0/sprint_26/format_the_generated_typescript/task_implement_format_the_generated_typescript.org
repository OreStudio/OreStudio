* Goal

The TypeScript render emits a tree that no formatter owns, so the format check named in package.json has never passed and never run: there is no prettier configuration in the repository at all. The C++ render already runs clang-format over its output as a second step, and the drift gate depends on that, so the generated C++ is byte-identical to clang-format output. The TypeScript facets need the same second step, a committed style, and a workflow that runs the check.

* Acceptance

- A prettier configuration is committed and states the house style: 4-space indentation, single quotes, 100 columns, with JSON, Markdown and CSS at 2 spaces because that is their convention.
- The TypeScript render runs prettier over its own output, as the C++ render runs clang-format, so the generator and the drift gate agree byte for byte and no generated file is hand-formatted.
- package-lock.json is excluded, because npm owns the file.
- The generated tree and the hand-written tree both pass prettier --check.
- The TypeScript workflow runs the format check, and the codegen-drift workflow installs the same pinned prettier the workspace declares, because the drift gate reads every generated file as drifted without it.
- The TypeScript Clean Standard records what changed against its first audit, with the numbers re-measured at the commit that lands this.
