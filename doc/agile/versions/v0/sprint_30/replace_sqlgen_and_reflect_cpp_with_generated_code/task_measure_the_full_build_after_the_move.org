* Result

Not done, because of environmental contention. The measurement needs a quiet
machine, and the machine is too busy during the day: other environments held
the load between 5 and 60 while the runs were attempted. Two attempts gave no
usable number. The first was served by the compiler cache, because
=CMakeLists.txt= reads =ORES_COMPILER_CACHE= from =.env= and overrides a command
line setting. The second was stopped.

The migration was required in any case, so its value does not depend on this
number. The shorter total build time therefore stays unmeasured.
