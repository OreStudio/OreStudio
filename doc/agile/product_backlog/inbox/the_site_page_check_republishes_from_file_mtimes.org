This page is a [[id:671F18E4-E09C-4B3B-BD24-D33DF8AE38A6][capture]] in the *inbox* bucket of the product backlog — a pre-sprint idea, not yet pulled into a sprint as a story.

* What

Drive =compass site page= from the branch diff instead of from file
mtimes. =compass site page FILE...= and =--no-index= already exist; the
check calls it bare, so it rescans the org-id map over 8185 files and
republishes every page whose source mtime beats its published HTML.

* Why

Measured at 770fc62e23: 114.9s warm, and a cold worktree published 1487
pages and hit the check's 900s timeout. A fresh checkout gives every source
a new mtime, so the whole corpus reads as changed whatever the branch
touched. Passing the branch's changed =.org= files cuts this to seconds,
and the same diff says whether a page was added or renamed, which decides
whether the org-id rescan can be skipped with =--no-index=.
