The account_history protocol messages.

=account_version= is a payload, not a domain entity: no =account_version=
table exists and the codegen has no version facet, so the type that a
versioned account history carries is declared here, beside the messages
that use it, and rendered to C++ and TypeScript from this one source.
Its =data= member is the generated account entity, so the account's own
shape stays owned by =ores.iam.account=.
