#+description: The system has a system clock that the feeds check. The clock drives which date a feed reads. A feed that needs the daily rates of a date looks them up in a table of daily rates. If the date is in the table the feed reuses it. If not, the feed fetches the rates once, stores them in the table, and then reuses them. So a public source is asked for one date only once, however many feeds, restarts or services need it. The same clock can later be set to another date, so a replay or a test runs on the rates of that date.
