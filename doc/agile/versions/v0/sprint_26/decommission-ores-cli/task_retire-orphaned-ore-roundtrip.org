* Result

Closed unstarted. The premise was wrong. The directory-level round trip
is the only way to drive the whole import and export pipeline over the
real ORE corpus in one pass, and round-trip coverage that reads
=external/ore/examples= is wanted. Retiring it would have removed that
capability rather than replaced it.

The work moves to [[id:5864A5C1-0F16-45BA-9F5B-26727E148127][Cover the ORE directory round trip with a test over external/ore data]],
which gives the method a caller and a fidelity assertion instead of
deleting it.
