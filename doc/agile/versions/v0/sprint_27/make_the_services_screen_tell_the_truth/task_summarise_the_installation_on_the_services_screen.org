* Result

The Operations services screen now opens with an installation overview: services running of those expected, lost, missing, errors and warnings in a chosen range, and the newest release with how many services run an older one. The roster gives the service figures. The logs read gives the error and warning totals, as a read with a page size of one, so no backend changed. Each figure leads to the services or logs screen. A failed logs read leaves the roster figures standing and shows a dash for the counts. The code sits in one hook and one component, InstallationHealth, which the home will reuse. The web package passes 638 tests and the format check. I did not look at the screen in a browser.
