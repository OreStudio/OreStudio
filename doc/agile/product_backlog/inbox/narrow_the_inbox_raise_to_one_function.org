#+title: Narrow the inbox raise to one security-definer function
#+description: Gated services write five inbox tables to raise a request. Give them EXECUTE on one inbox function instead, so the inbox owns the write rules and the grant surface shrinks. The call still runs in the caller's transaction, so the request and the held change still commit together. Refdata and trading both use the wide grants today (service_registry.org). Found while checking whether the trading raise crosses an owner.
