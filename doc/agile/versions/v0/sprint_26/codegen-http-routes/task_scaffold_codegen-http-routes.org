* Result

The gateway's routes generate from the components' models. The codegen facet
=ores.cpp.http-route= projects an entity or an operation model onto a route
unit, as three entity archetypes (header, implementation, test) and three
operation archetypes, tangled into six mustache templates. A message opts in
with =:http_route: true=; absence means the gateway does not expose it, so an
unmarked message and =:http_route: false= are the same refusal.

Three components landed, each as its own generated part beside a
hand-written aggregator, and each with its hand-written route file deleted
rather than kept in parallel:

| Part | Model source | Generated routes |
|------+--------------+------------------|
| =ores.http.assets= | image, tag, image_tag | 29 |
| =ores.http.refdata= | currency | 10 |
| =ores.http.iam= | account, role, permission, session, login_info, and the operation groups | 53 |

The deleted files are =core/.../routes/{assets,iam,risk}_routes.{hpp,cpp}=;
=risk_routes= was a misnomer for the refdata currency group.

The gateway is a protocol gateway. A generated route builds the canonical
request, sends it over NATS and maps the reply to an HTTP response, so it
depends on the target's wire protocol and not on its service library. The
server no longer links =ores.assets.core.lib=, =ores.refdata.core.lib= or
=ores.iam.core.lib=; it links the three generated parts. With the
hand-written storage, variability and information routes, the gateway serves
99 endpoints; 92 of them are generated.

Security is one declaration and one enforcement point. The template emits
=.auth_required()= or =.auth_optional()= from the model. =build()= and
=add_route()= throw =std::logic_error= when a route states neither, so a
route cannot be public by omission, and
=projects/ores.codegen/scripts/check_route_auth_declarations.py= fails the
build if any registered route is silent. The route forwards the caller's
bearer token, so the service's own permission check governs the real caller.

The route template builds each route once into a local named after the route
(={{identifier}}_built=) and passes that value to both =add_route()= and
=register_route()=.

The storage client takes its caller's bearer token as a required parameter,
and every in-repo caller passes one.

- The trade and market series export handlers carry the reporting service's

  still receive 401.
- A trailing ={key}= GET shadows the versions path beneath it.
