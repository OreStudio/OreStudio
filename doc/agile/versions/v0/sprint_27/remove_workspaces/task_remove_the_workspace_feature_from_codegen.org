* Acceptance

- No template, loader, profile, scaffolding option or test names has_workspace_id; the feature document is deleted and the variability docs no longer list it.
- The workspace-scoped-lookup profile, which no model binds after the column task, is deleted.
- Regeneration of every component under the drift gate is byte-identical.
- The codegen tests pass.

* Plan

Every model renders with the flag false, so each ={{#has_workspace_id}}=
section is already empty and each ={{^has_workspace_id}}= body already
renders. Deleting the positive sections and unwrapping the inverse
markers therefore leaves every generated byte unchanged. A script strips
the sections from the tangle sources, the loader entry is removed so no
model or profile can set the flag, and =check_component_drift.py= proves
the regeneration is byte-identical.
