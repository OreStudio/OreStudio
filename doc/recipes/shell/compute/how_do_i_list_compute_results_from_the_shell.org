#+title: How do I list compute results from the shell?
#+description: List the submitted compute results as a table with outcome and host, or list the results of one workunit by workunit id.

#+level: cross

#+created: 2026-08-11

The compute entity verbs live in their own shell menus, one per entity
(=apps=, =app_versions=, =platforms=, =batches=, =hosts=, =workunits=,
=results=). They talk to the ~ores.compute~ service over NATS; the
domain shapes and table renderers come from ~ores.compute.api~.

* Question

How do I list compute results from the shell?

* Answer

Log in as the system super admin, then run =results list= to print every submitted result as a table: id, workunit id, host id, server state, outcome, output uri, error message, received at, modified by, recorded at. To list the results of one workunit, pass its id to =results by-workunit-id=.

#+name: list-compute-results
#+begin_src ores-shell :exports none
connect $ORES_NATS_URL
login super_admin@localhost Secure-Password-123
results list
logout
exit
#+end_src

#+begin_src sh :noweb yes :results output :wrap example
./ores.shell ${log_args} ${connect_args} << 'EOF'
<<list-compute-results>>
EOF
#+end_src

A batch's results are reached through its workunits: =batches get
<external_ref>= prints the batch id, =workunits by-batch-id= lists its
workunits, and =results by-workunit-id= lists each workunit's results.
