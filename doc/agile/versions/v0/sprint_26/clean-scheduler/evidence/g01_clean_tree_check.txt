1. The component's own gate, in its writing mode.

    check_component_drift.py --component scheduler-cpp

    INFO Regeneration complete.
    No drift: regenerated output matches the checked-in tree.
    exit 0

    This mode regenerates the component in place and then diffs the working
    tree, so it is the authoritative form. It requires a clean tree: while one
    documentation edit was uncommitted it failed on that file and reported
    "generated output does not match what's checked in". The script runs
    `git diff` with no path filter, so it sees every uncommitted file, not only
    the component's. That is recorded in the task as a defect in the tool, and
    it is why this check is recorded as run at a committed revision.
