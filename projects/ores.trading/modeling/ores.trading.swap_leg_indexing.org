One indexing of a swap leg, keyed to the leg and the indexing's ordinal.

ORE states a leg's indexings on =LegData/Indexings= as a list of =Indexing=
blocks. An indexing scales the leg's notional by an index: an FX index turns
a notional in one currency into another, and an equity index turns a share
count into a notional. Each block names the index, the quantity, the initial
fixing, the fixing terms and, optionally, a valuation schedule.

The valuation schedule is a schedule like any other, so it lands in the
shared schedule rows under the leg, with the schedule role
=indexing_<n>_valuation=, where =n= is this row's ordinal.

The row is a child of the leg rather than an entity with a life of its own:
=swap_leg= names the trade and the ordinal, and this row adds its own ordinal
within that leg.

** Custom repository methods

The trade read path fetches the indexings of many instruments' legs at
once, and no generated read covers that: the generated reads address one key
group at a time. The batch read below is one statement over the instrument
set.

*** read_by_instruments_batch
:PROPERTIES:
:ID: E0221434-5E4E-456F-9730-FE46B3E4FBCD
:END:

Reads every current indexing of the given instruments' legs,
ordered by instrument, leg and sequence, in one statement. An empty input
reads nothing.

#+begin_src cpp :name implementation :implements F2EB1914-5E94-42CA-9C77-46BDB364BF9E
std::vector<domain::swap_leg_indexing>
swap_leg_indexing_repository::read_by_instruments_batch(
    context ctx, const std::vector<std::string>& trade_ids) {
    if (trade_ids.empty())
        return {};
    static constexpr auto max = db_timestamp::max();
    const auto tid = ctx.tenant_id().to_string();
    const auto query = query_builder::read<std::vector<swap_leg_indexing_entity>> |
                       query_builder::where("tenant_id"_c == tid &&
                             "trade_id"_c.in(trade_ids) && "valid_to"_c == max) |
                       query_builder::order_by("trade_id"_c, "leg_number"_c, "sequence_number"_c);
    return query_builder::execute_read_query<swap_leg_indexing_entity,
                                             domain::swap_leg_indexing>(
        ctx,
        query,
        [](const auto& entities) { return swap_leg_indexing_mapper::map(entities); },
        lg(),
        "Reading swap leg indexings for multiple instruments.");
}
