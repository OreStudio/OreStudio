* Goal

Fix the two defects that took the machine down, the NATS message leak and the
shared-heat runaway, and the two marketdata usage defects they hid: usage rows
stamped with an account that does not exist, and terminated tenants kept in
demand, routing and usage.

* Acceptance

- A test fails on each defect before its fix and passes after.
- marketdata memory stays flat with the feed running, calm and pinned =active=.
- The stored tick rate follows the configured rate times the regime multiplier.
- Usage rows are stored, and no write names a terminated tenant.

* Plan

1. Cap every fleet unit's memory (PR #3873, merged) so a leak kills one service
   in its own cgroup instead of the machine.
2. Reproduce on a fresh database with Acme provisioned, sampling marketdata
   memory and the =INGEST STATUS= counters every 30 seconds.
3. Find the retained objects with =gcore= and a string count of the heap: about
   11,300 copies of each Bloomberg ticker beside its ingress subject, which led
   to =on_msg= in =ores.nats=.
4. Fix the leak with owning handles, test first, and confirm the live curve.
5. Fix the heat runaway found by a parallel investigation: enrol each feed's
   mean rate and share the heat out, test first.
6. Fix the usage identity and the terminated-tenant reads that the leak's noise
   had hidden.
7. Re-measure calm and pinned =active= on the final build, then run the gate.

* Result

Fixed. Every core NATS message is now freed through =msg_handle=, and the cnats
objects the client and the JetStream admin create are owned by handles, with
=ensure_result= for status checks. Each synthetic feed enrols its mean rate and
takes its share of the shared heat, so the heat is bounded for any feed count.
marketdata writes usage as its service account and leaves terminated tenants out
of demand, routing and usage, and one failed interval no longer stops the rest.

On the live fleet, marketdata memory is flat, the tick rate is 38 rows a second
calm and about 148 pinned =active=, and the whole fleet uses 5.6 to 7.1 percent
of one core. See =* Measurements=.
