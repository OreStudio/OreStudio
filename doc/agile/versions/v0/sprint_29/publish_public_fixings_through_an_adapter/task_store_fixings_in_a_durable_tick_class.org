* Acceptance

- A class policy keyed by instrument type says whether a class is durable; the FX fixing is durable and every other class keeps today's rules.
- A durable tick skips the age gate; a backfill sent oldest first for each vendor id passes the order rule.
- Durable ticks go to their own points table, of the shape of the ticks table, with no retention policy.
- A test sends a fixing a day old and a ten-day backfill through the ingest and reads them all back; a live quote of the same age is still dropped.
- A durable tick whose vendor id and vendor time are already stored is skipped, so a backfill that overlaps the store after a restart adds no row; a test shows it.
