Reference data table defining the closed barrier set. The set is the ORE
=barrierType= simple type under =external/ore/xsd/instruments.xsd=.

The values are the ORE XSD spellings, so a stored value round-trips through the
ORE XML unchanged. No conversion is introduced here.
