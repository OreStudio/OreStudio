* Goal

The generator books CompositeTrade, ContractForDifference, TotalReturnSwap,
EquityOutperformanceOption and SyntheticCDO through their builders, and a test
holds the coverage as the catalogue's supported types, so a type added without a
generator fails.

* Acceptance

- each of the five types has a builder, and the generator books one trade of
  each; a container embeds trades of types the generator already books
- the ORE engine test reads and builds each, with no error of the trade kind
- every booked type is built by its builder, and a type with no builder fails
  loudly
- a test asserts the generated types equal the catalogue's supported types, so
  adding a type without a generator fails
