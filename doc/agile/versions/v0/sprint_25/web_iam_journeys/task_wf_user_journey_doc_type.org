Two conventions settled while building it:

1. Journeys are grouped by /logical topic/, never by component. A component is
   an implementation concept; a journey is grouped by what the person is doing.
   The groups live under =doc/knowledge/journeys/<group>/=.
2. A PlantUML =salt= diagram must not carry a =title= directive — the
   combination fails to render. The org =#+caption:= supplies the title.
