* Acceptance

- next() equals next(1.0): the same seed gives the same prices as before, and the existing tests pass unchanged.
- The sum of the steps over a fixed span has the same variance whatever the number of ticks in it.
- A process that cannot take a variable step throws for an elapsed other than one, and validation refuses a non-periodic mode for it.

* Plan

A tick is the arrival process's unit, so a step of two ticks is a step of twice
the time. The value process needs to hear that number, and the two callers that
have one need a way to say it.

1. The interface gains =next(elapsed_ticks)= and =supports_variable_step()=. The
   default answers one tick with =next()= and refuses anything else, so a
   process with no time-scaled law says so instead of guessing.
2. The geometric and arithmetic mixtures scale the mean with the elapsed time
   and the spread with its square root: the variance of a return over a fixed
   span must not depend on how the span is cut. At one tick the draw is exactly
   the old draw, so the same seed gives the same prices.
3. The Ornstein-Uhlenbeck transition is already exact for any step, so the
   elapsed time replaces the tick length in the same closed form.
4. The clock hands its body the gap it waited, and each feed turns that gap into
   ticks. A feed whose arrival gives ticks of different lengths is refused at
   construction when its process cannot step by elapsed time, so the pairing
   cannot be built wrong.
5. Tests: one tick equals the old step on the same seed; the spread over a span
   survives a different cut; a process with no time-scaled law refuses; the
   compatibility rule allows periodic for both kinds and a non-periodic mode
   only for a process that can step.

* Result

A value process now takes a step measured in nominal ticks, and one tick is
still exactly the old step: the same seed gives the same prices, and the
existing tests pass unchanged.

The mixtures scale the mean with the time and the spread with its square root,
so a year of returns has the same variance whether it arrives in many small
steps or few large ones — the test measures that on 400 paths. The
Ornstein-Uhlenbeck process needed only its elapsed time in place of the tick
length, because its transition was already exact.

The clock hands its body the gap it waited, which is the seam that makes an
irregular arrival usable: a Hawkes feed steps the price by the time that passed,
not by one nominal tick. A feed that pairs a non-periodic arrival with a
process that cannot step is refused at construction.
