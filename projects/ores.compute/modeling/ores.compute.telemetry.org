The grid telemetry surface: one request and reply for the dashboard
summary, and one fire-and-forget publish from a wrapper node reporting
what it has done since the last sample.

These are operations rather than entity verbs, so they are declared here
instead of being derived from an entity. The grid summary is computed, not
stored, and the node sample arrives from outside the service, so neither
is a row a caller addresses by key.

The handler that serves them stays hand-written beside this model, because
it reads the newest stored samples and calls the grid-stats function.
