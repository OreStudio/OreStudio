The root of an ORE stress document: =StressTesting= in =stresstest.xml=, which
holds the scenarios a run may apply and the one setting that governs how they
are applied. Twenty documents ship, holding forty-six scenarios between them.

Each row is one document. The scenarios hang off it, because a scenario is only
meaningful inside the library that names it.
