This page is a [[id:671F18E4-E09C-4B3B-BD24-D33DF8AE38A6][capture]] in the *inbox* bucket of the product backlog — a pre-sprint idea, not yet pulled into a sprint as a story.

* What

The trade type catalogue states, for every product type, the form ORE reads it
as, the table that holds it, its builder, its generator and whether the engine
can carry it. A page of the UI shows that answer to a person, from the
catalogue as the server serves it.

* Why

A person choosing how to book a product, or checking what ORE Studio can hold,
has to read the catalogue's org file today. The work was a task of
[[id:0CAC2F0E-69EC-4497-8587-4E0A6593BC7D][Hold every product type the engine supports]], which was abandoned for the
scripted trade redesign; it is kept here so it is not lost.
