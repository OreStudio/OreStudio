* Goal

The level of a synthetic price comes from a public source that anyone can check, as close to today as the source allows, and a reader sees the time of retrieval on the screen.

* Acceptance

- A generator config carries a calibration entry: a source code (ecb.eurofxref, fed.h10, ust.par_yield or an overnight rate), an as-of date and a window for the volatility.
- A retrieval step, separate from the simulator, reads the latest value of each source, stores it with the time of retrieval and the as-of date, and keeps the last value when the source cannot be reached.
- The feed screen shows the time of retrieval and the as-of date. A pair that no source covers keeps a fixed level and says so.
- The terms of each source are read from the official page, the credit or notice each one asks for is kept, and a value changed after retrieval is marked as derived.
- The 2016 ORE vintage calibrates no generator.
