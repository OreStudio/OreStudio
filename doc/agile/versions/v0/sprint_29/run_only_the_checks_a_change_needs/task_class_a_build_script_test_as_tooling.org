* Acceptance

- The tests of build/scripts live in build/scripts/tests and a tooling check runs them
- A change to one of them selects no codegen check
- Every moved test still passes

* Plan

Move the tests that load only =build/scripts= code from
=projects/ores.codegen/tests/= to =build/scripts/tests/=, beside the code they
test. That path is already in the =tooling= class, so the path rules need no
exception. A new =build-script-tests= check runs the folder with the codegen
venv's python, as =codegen-tests= ran them. Each test finds the repository root
with =parents[3]=, which is the same from both folders.

Nineteen tests moved: every test that names =build/scripts= and loads no codegen
module. Live references to the old paths move with them; sprint records keep
the paths they had when they were written.
