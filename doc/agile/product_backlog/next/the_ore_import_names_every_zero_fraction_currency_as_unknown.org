* What

The ORE import names every zero fraction currency as a value with no row. The importer's validate_currency refuses a fractions per unit of zero, which the yen, the won and eleven other seeded currencies carry, so every preview of a currency configuration lists thirteen currencies under values with no row with Fractions per unit must be positive, though the import then writes them as they are. Seen on 2026-10-26 by the currencies scenario. Either a zero is valid for a currency with no minor unit and the check goes, or the seed should carry one as ORE's own files do.

* Why

Every preview of a currency configuration lists thirteen currencies under values with no row with Fractions per unit must be positive, though the import then writes them as they are, so the notice is noise on every import. Either a zero is valid for a currency with no minor unit and the check goes, or the seed should carry one as ORE's own files do.
