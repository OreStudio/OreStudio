* Goal

A reader sees how every number of a run came to be. The This run tab states the start in plain text, the level first in market convention, then the fixing it came from and whether it was inverted, then the calibration the run used. The Calibration tab lists the pair's inputs and calibrations with their states, and opens each one: an input shows its points, a calibration shows its evidence and review history. Each record links to the next one in the chain, run to calibration to input to fixings, and back to the feeds that use a calibration. A person with the permissions captures, fits, approves and rejects from this tab.

* Result

The Calibration screen shows each feed's variance in a column: the calibration it
runs, its state and persistence, and a mark when the run fitted a new one to
review. A feed's calibration page has a Variance tab with two cards: the
calibration the feed runs, read as stored with its input, and this run's fit, with
its shape, persistence, starting ratio, starts and whether they agreed, returns,
window, item, provider, orientation and ids, and approve and reject with a
required reason. A preview reports a stored fit as stored, with its id, so the
screen reviews it; a refused review is a conflict with the service's reason. The
class list shows a start level in the pair's market convention, an inverted
fixing beside it. On the feed screen, the This run tab replaces the notice over
every tab and states the level first, then the fixing, the window and the daily
variance with its calibration and version; the Variance tab shows the shape the
running feed carries and opens its calibration.

The flow is documented in
[[id:5B561453-D754-466E-9234-5360AC611F02][Calibrating a synthetic feed: from fixings to a reviewed run]],
with four PlantUML diagrams (the run, the states, an approval, the audit chain);
the GARCH note and the calibration sources note link to it.

Measured on the environment: the preview reports a current calibration for all 51
feeds; the audit passes 9 of 9.
The web suite passes 2445 tests and more, the BFF 1256 and more, the synthetic
suites and the doc checks pass.
