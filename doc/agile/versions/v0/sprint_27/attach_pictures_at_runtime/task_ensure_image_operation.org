* Acceptance

- =assets.v1.images.ensure= returns an existing tenant image with the
  code, or copies the system-tenant template through the real save path
  and returns the new id.
- It is idempotent and needs no workflow context.
- =copy_template_image=, the party-logo attach and the counterparty-logo
  map all call it; no copy logic remains duplicated.
