*Bullet 3.* The story's earlier decision made the URI the point's only identity. That
is a choice, and the bullet asks for more: a coordinate that is queryable and
joinable. The new task decides it from a consumer. It does not assume a column set.

*Bullet 8.* "What it was built from, by which recipe" is the derivation config, its
version and the source as-of. The lineage annex holds all three. The wire struct
leaves them out. The new task adds them and decides the evolution read.

*What this audit did not do.* It did not rerun the tests of the met bullets. It relies
on each task's own record. Bullets 15 and 16 are read from the models and the story,
not from a test.
