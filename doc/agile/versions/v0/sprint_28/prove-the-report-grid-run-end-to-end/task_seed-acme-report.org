* Goal

The story needs a report type, a definition owned by an ACME party, and the input the run consumes, all reproducible from a freshly recreated database. The existing fixture is owned by the system party because a business-party-owned definition is invisible to a session scoped elsewhere, so the ACME definition needs a session that can see ACME.
