* Goal

The grid wrapper moves every package, input, output and log through the storage
routes, and the upload now writes a part file and renames it. Nothing has run the
wrapper against it: the measurement proves the session's cost, and the sink's tests
prove the file protocol, but the path a real transfer takes is unproven.
