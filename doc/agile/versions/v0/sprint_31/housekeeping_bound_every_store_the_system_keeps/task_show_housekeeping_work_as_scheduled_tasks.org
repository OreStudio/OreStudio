* Goal

Every housekeeping sweep is a scheduler job with its own definition, so a person can see from the system what housekeeping is running, when it last ran and what it freed, and can enable or disable it.

* Acceptance

- Each sweep registers a scheduler job definition, and its firings create the job instances the scheduler already records
- The task screens list the housekeeping jobs beside every other job, with the last run, its outcome and what it freed
- A person can enable, disable and change the cadence of a housekeeping job from those screens
- A disabled policy is visible as disabled rather than absent
