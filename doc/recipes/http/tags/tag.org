#+title: How do I call the tags endpoints over HTTP?
#+description: Every endpoint the tags resource answers over HTTP, with the request each one exports into the gateway's recipe library.
#+type: recipe
#+level: cross
#+filetags: :recipe:http:tags:

This file documents the tags resource over HTTP, one section per endpoint. Every section exports its own Hurl file into =projects/ores.http/scripts/library/=. Running a file sends that one request, so a failure names the endpoint it came from.

* Endpoints

** =GET /api/v1/assets/tags=
:PROPERTIES:
:ID: ACAEA6BB-EBE4-5EEA-ABA3-B764243B9F13
:END:

List tags. It needs a session.

It forwards to =assets.v1.tags.list=.

The request is:

#+begin_example
GET /api/v1/assets/tags
#+end_example

#+name: tags-list
#+begin_src hurl :tangle tags-list.hurl :exports none
GET {{base_url}}/api/v1/assets/tags
Accept: application/json
Authorization: Bearer {{token}}
HTTP 200
#+end_src
