* Goal

ORE's script library arrives as a world dataset whose methodology extracts, corrects, parses and derives the inputs of every script with ORE Studio's parser; a tenant's own script is parsed when it is published; and a scripted trade records the version of the script it was booked on, or its inline text, so it revalues on the payoff it was booked with.

* Acceptance

- the library is a dataset of the Open Source Risk Engine catalogue
- its methodology records the ORE commit and each correction
- its rows are staged in the artefact tables of the script, variant, input, result and calibration entities, which opt in through their models, whose descriptions then state that the rows are derived by the dataset's methodology
- the trading service's publish function writes the staged rows into the system tenant, and the dataset is a member of the =world= bundle
- a check verifies that the staged rows are what the generator makes of ORE's distribution
- the populate scripts that load the library and correct it today are retired; the corrections are steps of the methodology, under the same exactly-once rule
- the shell's =script parse=, =script check=, =script inputs= and =script print= run with no session and no server, and =script check= prints each diagnostic as FILE:LINE:COLUMN: severity: message [code] and exits with a non-zero status on any error
- the generator parses every script with =script check= and fails on a script that does not parse, with its line and column
- the staged inputs are those =script inputs= derives, which corrects Accumulator02's ObservationPeriodEndDates from a Number list to an Event list, and a test verifies they equal inputs_of for every script
- a republished dataset writes a new version only of the scripts whose rows changed
- a tenant's script is parsed when the tenant publishes it and refused with the same diagnostics; a name the world library holds draws a warning, and the tenant's script is the one its bookings resolve the name to
- a scripted trade records its library script's name, holding tenant and version, or its inline text and a hash of it
- a run writes the library from the versions its trades name
