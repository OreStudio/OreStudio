* Acceptance

- A report definition states whether it is official; existing definitions are official.
- An official definition's scope cannot name a sandbox portfolio or a virtual book, and a definition cannot become official while its scope does.
- The books an official report resolves never include a virtual book.

* Plan

- Row-level security already hides a sandbox's portfolios and books from a
  session with no actor, so a system process sees none. That is not
  enough: the book resolver runs as the table owner, which bypasses
  row-level security, so the rule has to live in reporting itself.
- =report_definition= gains =is_official=, defaulting to true, so every
  existing definition stays official.
- The two scope tables refuse a virtual book or a sandbox portfolio when
  the configuration's definition is official.
- A definition cannot become official while one of its configurations
  scopes a sandbox input.
- The resolver drops virtual books from an official report's set, as a
  last line of defence for data written before these checks.
- A pgTAP test covers the rules the test user can reach.
