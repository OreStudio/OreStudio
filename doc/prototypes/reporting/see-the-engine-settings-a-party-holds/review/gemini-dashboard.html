Imply today's fixings Changes the numbers Decides what the run does about the fixing of the valuation date.
ore.xml > Setup > implyTodaysFixings No When No, valuation date fixing is loaded from historical fixings file.

Comprehensive Documentation

Decides what the valuation run does regarding the fixing of the valuation date. When set to No, the fixing for the valuation date is loaded from the fixing file like any earlier fixing. When set to Yes, that fixing is not loaded, and the pricing engine implies it directly from the discount/forward curves. Use Yes when the run prices off hypothetical market data (e.g., scenario analysis or stress testing), as real market fixings would mismatch hypothetical curves.

Include today's cash flows Changes the numbers Includes or excludes cash flows occurring on the valuation date itself.
ore.xml > Setup > includeTodaysCashFlows No Excludes cash flows payable today from NPV calculation.

Comprehensive Documentation

Determines whether cash flows scheduled on the valuation date are included in trade NPV pricing. When set to No, today's cash flows are assumed already settled. When set to Yes, they are discounted and added to the portfolio present value.
