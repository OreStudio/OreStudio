* Acceptance

- A quote's value is read from the element that holds it, not from a column named after an ORE child element.
- A segment's quotes are drawn under that segment, in the order the document writes them.
- A composite quote's rate and spread show, and so does the list a quote belongs to.
- A quote leaf the contract does not document keeps its name and counts as a gap.
