* What

On 2026-11-11 the Acme provisioning failed at its last step, =generate_trades=: "The RiskParticipationAgreement builder refuses the drawn underlying.index: oresmd://ir/EUR?type=fixing&index=ibor&name=EURIBOR&tenor=12M: more than one swap convention names it: EUR-12M-SWAP-CONVENTIONS and EUR-EURIBOR-12M-SWAP." The convention lookup refuses an index that two swap conventions name, and the curated conventions hold two for EURIBOR 12M. Either the lookup prefers one, or the data keeps one, or the generator draws only indices with one convention.

* Why

A provisioning run that fails at its last step leaves the tenant without its trades and the auto-approval switch on, because =end_auto_approval= never runs. The draw is random, so the failure comes and goes. The run was on a branch based before #4565, which rebuilt rates trades through their builders, so check main first.
