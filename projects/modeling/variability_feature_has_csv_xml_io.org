* Effect

Retired with the Qt client. It turned on CSV and XML import and export in the
generated client model and in the MDI window's import dialog, and it paired
with the =csv_export_class=, =xml_export_class= and =xml_import_class=
properties that named hand-written helper classes. Those dialogs and
properties are gone, so setting or clearing this literal no longer changes
generated behaviour. It stays accepted on entity orgs and on the profiles
below as documentation only.

* Structural consequence

Yes — adds import/export methods to the generated client model and MDI window.
