* Result

Six identity patterns are written, each with a sequence diagram and its
sources: RFC 7519, 6749, 6750, 7517, 7009 and 8693, the OpenID Grant Management
draft, microservices.io, Microsoft's On-Behalf-Of flow, Spring Cloud Gateway,
Newman and Madden. The pitfalls record the failures ORE Studio has met: the
empty result of a service identity reading party data, the RS256 mismatch at the
edge, the impersonation token that expired during a poll, and the token minted
before the service's subjects existed.

The composite, Scheduled Work Acting as a Tenant, states what the combination
adds: no token in durable state, one cache key per run, and a lapse that
suspends the schedule. The hub's identity group links all six.
