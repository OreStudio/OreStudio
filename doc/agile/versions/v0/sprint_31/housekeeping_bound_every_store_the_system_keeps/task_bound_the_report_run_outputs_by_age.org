* Goal

A run's cashflows, metrics and text values are removed once the run is older than the stated retention period, so the store's size follows the runs a person still compares rather than every run ever made.

* Acceptance

- A retention period is stated for the run output tables, with the reason for the period recorded
- Chunks past the period are dropped by the engine where it runs a job, and by the executor where it does not
- A run inside the period still reads its rows
