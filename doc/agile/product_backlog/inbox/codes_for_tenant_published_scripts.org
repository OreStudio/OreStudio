This page is a [[id:671F18E4-E09C-4B3B-BD24-D33DF8AE38A6][capture]] in the *inbox* bucket of the product backlog — a pre-sprint idea, not yet pulled into a sprint as a story.

* What

Give a tenant's own published script the codes of its coded inputs, as the
library's scripts have them: a row of =script_input_code= for each number a
coded input reads and the name it stands for.

* Why

The codes of the library's scripts are read from the library's comments by
the script library generator, which a tenant's publish does not run: the
publish derives a script's inputs from its code with the parser, and a comment
is not data the publish reads. A tenant's coded input therefore has no codes,
and a form offers a bare number for it. The publish could read the codes from
the script's comment, as the generator does, or take them as a field of the
publish request.
