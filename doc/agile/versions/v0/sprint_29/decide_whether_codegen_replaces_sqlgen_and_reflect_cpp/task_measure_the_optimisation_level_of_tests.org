* Notes

- The test files spend little time in the optimiser; their cost is parsing and
  instantiation. =-O0= saves 11% of their compile CPU at no cost to the test run,
  which waits on the database. Tests are about an eighth of the files, so this is
  about 1.4% of the total build: worth taking, and it makes tests easier to
  debug, but it is a small lever.

* Result

Compiling =ores.dq.core.tests= at =-O0= saves 11% of its compile CPU, and the
tests run in the same time, because they wait on the database. Tests are about
an eighth of the files, so this saves about 1.4% of the total build. It is worth
taking, and it makes the tests easier to debug, but it is a small lever.
