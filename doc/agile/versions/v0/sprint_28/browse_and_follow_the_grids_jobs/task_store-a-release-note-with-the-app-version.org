* Goal

An app version holds a release note as text, written by the same call that publishes its package, and the generated read returns it.

* Acceptance

- The app_version entity has a release_note text column, and the generated table, protocol and wire type carry it.
- compute publish-package takes the note from a file and stores it with the version.
- A republish without a note keeps the stored note.
- The glossary and the app_version model page name the field.
