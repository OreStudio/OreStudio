* Goal

Every component reads and writes the database through generated statements on a thin libpq layer, and encodes its messages through generated JSON and MessagePack codecs. sqlgen and reflect-cpp are no longer dependencies, and the full build is faster.

- Every component builds as a unity build.

- Every suite passes.
- The full build without ccache is measured against the baseline.

* Decisions

- *The order of the move.* The tasks table is in this order, and each task's
  goal names its step. The reasons for each step are in [[id:937333B6-3A64-40A9-B53F-719CF81BB964][Write the decision and the order of the move]].
  1. Build every component as a unity build. It is the largest lever on build
     time and waits on nothing else.
  2. Build the libpq layer in =ores.database=.
  3. Generate repositories on the layer: the templates move with =ores.dq=,
     then each other component moves in its own task.
  4. Remove sqlgen.
  5. Write codecs, once, for the twelve types with a custom encoding.
  6. Generate codecs and switch the wire codec: the templates move with
     =ores.dq=, then each other component moves in its own task.
  7. Remove reflect-cpp.
  Last, measure the full build after the move.
- *Two independent tracks after step 1.* Steps 2 to 4 (the database) and steps
  5 to 7 (the codecs) do not depend on each other. Within a track, a
  component's task starts only after its template task.
- *Every step leaves the system working.* Each task ends with the suites green
  and the tree building as a unity build. No task leaves a component half on
  the old library and half on the new one.
- *The wire format does not change.* A generated codec must match reflect-cpp's
  bytes in both formats before reflect-cpp goes. The test that proves it lives
  as long as both exist.
- *No libpqxx.* It lacks pipeline mode, needs a clang triplet, and compiles
  twice as slowly as libpq.
- *Generated code stays unity-safe.* Every file-local name in a generated file
  carries its entity's name.

* Out of scope

- Binary result formats and binary COPY. Text is enough for the control
  plane; the data path decides for ticks.
- A faster ISO 8601 timestamp conversion. It helps both codecs, and it has its
  own capture.
- The data path's connections, unit of work and typed statements. That story
  builds them; this story's libpq layer is what they run on.
