* Notes

The first end-to-end run since the vendor-native move found two defects. The synthetic service crashed at start with =permission denied for table ores_marketdata_market_data_sources_tbl=, so nothing ticked. After that fix 13 of 26 generators still refused to start. The publish cast the observation date with =::timestamptz=, which is midnight in the session time zone (Europe/London). The vintage lookup compares UTC dates. February vintages matched. The 2026-05-05 vintage falls in BST, so it did not.

What still does not tick: curves have no adapter path, an environment provisioned before the move has no routes until it is provisioned again, and the old start_feed control plane is still in the tree but nothing starts it.
