* Acceptance

- A read over the bus answers the preview of a named bundle: per dataset, the
  staged count and the action a publish at that mode would take — insert, update
  or skip — from =ores_dq_bundle_preview_fn=, so the preview and the publish read
  the same function.
- A per-dataset preview answers one dataset the same way.
- The dataset publish verb carries a level, so a tenant cannot publish a world
  dataset into itself.
- A bundle or dataset that names no level, or names nothing that exists, is
  refused with a reason.
- A test reads the preview of a seeded bundle and asserts the per-dataset actions.

design draws them on one screen: the coverage list's step 4 reads what a whole
bundle would write, and a dataset's page reads what that dataset would write. The

path calls it for its own purposes; no subject serves either.
