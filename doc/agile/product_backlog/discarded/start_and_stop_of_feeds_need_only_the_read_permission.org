This page is a [[id:671F18E4-E09C-4B3B-BD24-D33DF8AE38A6][capture]] in the *inbox* bucket of the product backlog — a pre-sprint idea, not yet pulled into a sprint as a story.

* What

The folder verbs and the selection verbs (=start_feeds_under_folder=, =stop_feeds_under_folder=, =start_selected_feeds=, =stop_selected_feeds=) check the read of every registered kind's feed configs. They start and stop producers, which changes what the platform publishes. A person who may only read feeds can start and stop them through the service. The web draws the buttons only for a person who may write, so the screen hides what the service allows. Check the write permission of the kinds a request touches, in the one function the verbs share.

* Why

The review of PR #3239 found it. The check matches the folder verbs that came first, so the gap is older than the selection verbs.

* Resolved

Done, not discarded. The permission =synthetic::feeds:run= guards every verb that starts or stops a feed, and the screen draws the buttons only for a person who holds it.
