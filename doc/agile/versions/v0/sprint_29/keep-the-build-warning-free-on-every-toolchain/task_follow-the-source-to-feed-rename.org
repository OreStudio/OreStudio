* Plan

Only the two BFF routes import the deleted module; the rest of the web surface
reaches the catalogue through them, so the change stays inside the BFF and its
two tests.

The renamed row is not a rename of a field: the feed carries =publisher_code=
in place of =provider_code=, and a =service= where the source carried a =kind=.
The reply keeps the shape each screen already takes, so the screens do not move,
and the mapping is stated where it happens: a source's kind is now the feed's
service, which is the only fact of that shape the feed has.
