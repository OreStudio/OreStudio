* Result

The Gemini review is filed at doc/prototypes/tenancy/home/review with an index and a banner on its one screen, beside the Home screen prototype it reviews. The Tenancy group page links it from the Home row, and the design note says what it argues, what the built screen took and what it left. The prototype inventory check passes: 51 prototypes, 5 reviews.

The built home took four things: one status for the whole installation at the top, boxed metric tiles, two columns so the four panels weigh the same, and a footer on each panel that says when it was read or which release it is. It left the processor load of the grid, the scheduler status, the broker name and the claim about clusters, because nothing records them. The message queue panel draws a throughput curve from the server samples it already reads, as the difference of the message counter over the seconds between two samples, so the figure is real. The web package passes 662 tests and the format check. I did not look at the home in a browser.
