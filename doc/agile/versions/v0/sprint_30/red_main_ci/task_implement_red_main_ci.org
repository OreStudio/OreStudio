* Result

The three fixes are in and each was proven against the signal that failed:

- GCC: the original file reproduces the exact CI error under
  =g++ -fsyntax-only=; the fixed file exits 0 with the same flags.
- Windows: the multiprecision type that =billing.cpp= now uses on clang-cl
  gives identical results to =__int128= for both expressions, so the link fix
  does not change the charge.
- Web: the BFF suite goes from 1276 passed and 1 failed to 1277 passed, and
  the package typechecks.

The local check gate was not run: the fixes are three small edits and the
gate's heavy half would recreate the development database. CI is the first
full build of these changes.
