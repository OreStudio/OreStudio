#+description: Codegen operation model for the approval-gated publish of a party's FX forward set and the read of a published one.

#+brief: The publish and read of a party's FX forward sets.
#+filetags: :model:operation:marketdata:
#+created: 2026-11-09
#+updated: 2026-11-09

The publish and the read behind the FX forward ladder screen. A forward set is a
party's published record: the publish computes it from the party's own spot and
published funding curves, and a person approves it as they would an IR curve. The
read returns the published set and names every input beside the rows, with how its
request was decided. No operation computes a forward for display. A refusal is a
reply with =success= false and a message that names what is missing, because a
reader needs to know which input to go and fix.

#+begin_src cpp :name comment
/**
 * @brief Raises, or applies, the publish of one pair's forward set for the caller's party. A call that names no approved request computes the set from the party's spot and published funding curves, raises a marketdata.fx_forward_publish request and stores the set as its candidate. A call that names the approved request publishes that candidate, unchanged. A set whose spot or curve is missing is refused, naming the input, and nothing is written.
 */
#+end_src
