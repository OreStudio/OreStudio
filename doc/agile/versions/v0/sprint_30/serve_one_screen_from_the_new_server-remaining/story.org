* Acceptance

- [ ] Every resource route the BFF answers has a C++ equivalent, area by area, merged as
      it lands.
- [ ] Every composed view is answered by the server that owns it, with its name, its
      schema, its owner, its computation and its cache policy.
- [ ] A generated list route carries what the BFF's lists carry: the page, the order,
      the search and the filter's own members.
- [ ] The coverage is counted from the route inventory, not claimed.
- [ ] The local gate is green on every pull request.
