* Acceptance

- The entity protocol specification states when an entity is a read model over several entities, and that a screen filters through it, not through joins in the client.
- The specification defines the enum filter member, the _from and _to range members with the end-of-day rule, and the by-parent read.
- The specification states which instant a read model answers when its parts version on their own timelines.
- The entity screen specification and the modeling standard point to it, and each rule has an example from the trade list.
