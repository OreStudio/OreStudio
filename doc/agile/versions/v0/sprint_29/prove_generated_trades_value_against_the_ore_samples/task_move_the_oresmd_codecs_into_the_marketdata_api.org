* Acceptance

- =oresmd_uri_codec= and =ore_index_codec= are in =ores.marketdata.api= and the core keeps no copy; their callers are moved and their tests pass.
- =market_reference= is a variant of the address kinds the grammar has (an index, a datum or series), obtained only by parsing, with its canonical text from the codec's writer.
- A test parses and writes an address of each kind and refuses a malformed one with the codec's reason.

* Notes

- The move was scripted (moves with git, renames the export macro and guards,
  rewrites the includes): 15 files moved, includes rewritten in 43.
- In the API the moved sources share a unity group with the API's own datum
  sources. Five helpers collided: =upper=, =lower= and =all_digits= were the
  same and are shared in =shared_helpers.hpp=; the index codec's =split= (on
  =-=) and =is_period= (by the term parser) were not, and are renamed
  =split_on_dash= and =is_period_term=.
- The codec tests stay in the core suite: their catalogue helper reads ORE's
  catalogue files and the core's URI service test shares it.
- Two feed ingest loop tests in =ores.marketdata.service.tests= fail while
  the environment's own marketdata, official and synthetic services run:
  those write ticks to the same database and subjects. With the three
  stopped, the suite passes. A test that counts rows in a shared database is
  fragile; worth a capture.

* Result

The oresmd URI codec and the ORE index and key codecs are in
=ores.marketdata.api=, with Boost.URL, and the core keeps no copy, so any
component can parse and write an address without the core. =market_reference=
is the one form a market reference takes in code: an index or a datum, got by
parsing or from its index or datum, spelt by the codec's writer and compared
by that spelling. Its tests parse a fixing and a quote address, refuse
malformed ones with the codec's own reason, and show a reference made from
an index equals the one its address parses to. All acceptance criteria are
met; the suites of every component that includes the codecs pass.
