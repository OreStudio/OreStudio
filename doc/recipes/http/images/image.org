#+title: How do I call the images endpoints over HTTP?
#+description: Every endpoint the images resource answers over HTTP, with the request each one exports into the gateway's recipe library.
#+type: recipe
#+level: cross
#+filetags: :recipe:http:images:

This file documents the images resource over HTTP, one section per endpoint. Every section exports its own Hurl file into =projects/ores.http/scripts/library/=. Running a file sends that one request, so a failure names the endpoint it came from.

* Endpoints

** =GET /api/v1/assets/images=
:PROPERTIES:
:ID: B7DFAD26-5AA6-5EC6-ACC4-1E3A6BC17F3B
:END:

List images. It needs a session.

It forwards to =assets.v1.images.list=.

The request is:

#+begin_example
GET /api/v1/assets/images
#+end_example

#+name: images-list
#+begin_src hurl :tangle images-list.hurl :exports none
GET {{base_url}}/api/v1/assets/images
Accept: application/json
Authorization: Bearer {{token}}
HTTP 200
#+end_src
