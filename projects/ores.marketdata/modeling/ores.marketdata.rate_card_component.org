A rate card belongs to a source. It is the set of components that apply to the source in a period. Each
component has a driver, which says what the vendor counts, and a charge for one unit of it. A rating step
applies the components to the usage events of a period and gives the bill of the source.

A simulated source carries a card of its own with illustrative charges, or published ones where they
exist. The model is the same for every source, so a simulated source gives a shadow bill with the same
lines as a live one. The system tenant owns the cards, because the platform owns the vendor contracts.
