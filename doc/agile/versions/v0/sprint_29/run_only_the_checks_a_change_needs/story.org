* Goal

A gate run that costs what the change reaches: the heavy checks run only when production code changed, ctest runs only the suites whose binaries compile a changed file, and the suites run in parallel. When the gate cannot decide what a change reaches, it runs everything.

* Acceptance

- A change whose compiled files reach only test binaries skips the db, ticks-smoke and step-consumers checks
- ctest runs only the suites whose binaries compile a changed file, and runs every suite when the dependency lookup cannot decide
- The gate runs ctest in parallel
- The gate time for a test-only change is measured before and after
