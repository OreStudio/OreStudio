* Notes

- The Windows link cannot be reproduced on Linux or macOS: there the same
  macro is a visibility attribute that costs nothing, and the construction is
  satisfied by the inline definition every consumer already has.
- The scan resolves includes transitively from each translation unit of the
  sublibrary: a header included by another header that a unit includes is
  compiled by that unit, which is what makes a header-only type safe.
- The failed symbol was an implicitly-declared default constructor, which is
  the class of member clang-cl imports but a library never emits on its own.
  An aggregate used with brace initialisation, by contrast, never names it --
  which is why only two of the six declarations produced a link error.
