Reference data naming the kinds of configuration a report can bind: the ORE
run itself, a stress library, a sensitivity analysis, a simulation, a SIMM
calibration, a credit simulation, a historical return set, a Basel traffic
light set, and the curve and reference documents.

This is a seeded vocabulary, not free text. A discriminator stored as a bare
code cannot be constrained, counted or joined, which is why every
configuration carries one of these rows by foreign key. Adding a kind is a
row here plus a workflow, never a column on the report definition.
