#+title: ores.marketdata.fx_vol_quote_fit_operations
#+description: Codegen operation model for reading quoted FX volatility surfaces as smiles by delta: an SSVI fit of each source's ATM, risk reversals and butterflies in the pair's convention, which writes nothing.
#+type: ores.codegen.operation
#+component: marketdata
#+subcomponent: api
#+entity_singular: fx_vol_quote_fit_operation
#+namespace: ores::marketdata::messaging
#+brief: The fit of quoted FX volatility surfaces to smiles by delta, for display.
#+filetags: :model:operation:marketdata:
#+created: 2026-11-20
#+updated: 2026-11-20

A vendor quotes an FX volatility surface as an ATM volatility, risk reversals
and butterflies at each expiry. A difference between two vendors' risk
reversals is a difference in skew, not in a volatility, so a screen that
compares them reads each source as a smile by delta. The conversion depends on
the pair's delta convention, its ATM convention and a smile fitted to the
strangles, which only the server knows: the service fits SSVI to each source's
quotes on the party's published forward set and answers the volatility at the
deltas of the smile. There is no shell command, because the sources are a list
of quotes, which a command line does not carry.
