* Goal

Everything that reads or waits on time in the arrival path does it through one clock interface. Production uses the steady clock; a test advances a manual clock and asserts exact event times without sleeping.

* Acceptance

- The interface offers now() and an interruptible wait_until(t).
- A test of the manual clock wakes a waiter exactly when time is advanced past its deadline, and a stop wakes it at once.
- A tick's observation time comes from the clock, not from system_clock::now().
