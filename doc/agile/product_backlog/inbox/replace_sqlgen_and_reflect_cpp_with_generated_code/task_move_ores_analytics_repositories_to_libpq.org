* Notes

** What stays for the removal of sqlgen

These name sqlgen but compile nothing against it. They go with the
removal task, as they do for dq:
- the =sqlgen::sqlgen= link in the core and quant =CMakeLists.txt=;
- the sqlgen headers in the models' "Entity includes" blocks, which the
  loader already drops;
- the =sqlgen::PrimaryKey= labels in the core class diagram.

** Main did not build

The equity underlying entity in refdata was generated before #3923. Its
eventing and shell tests kept an anonymous =test_suite= that clashes with
the shared =test_suite.hpp=, and two refdata unity batches failed. A
separate commit regenerates the entity on the current templates.
