* Result

The seed profile tables are isolated by policy, and the ignore file no longer excuses them.

- Every tenant reads the profiles, because a tenant is provisioned from one. Only the system tenant writes them.
- Before the policy, a tenant session removed every profile. The delete rule runs with the owner's rights, so the policy alone did not stop it. The template now states the system tenant limit in the rule of an entity with system scope.
- The tenant model is not changed. It is visible to the system tenant and already has its own limit.
- =iam_seed_profiles_policy_test.sql= has 8 assertions and passes. The test failed before the rule change.
