* Goal

When =ORES_DB_POOLER_ENABLED= is 1, the tests that connect as a service find
pgbouncer listening:

- The local gate's =ctest= check starts NATS and the pooler before it runs
  the suites. It stops the marketdata and synthetic services as it does now.
- =compass test run='s preflight (=_test_run_preflight= in
  =projects/ores.compass/src/compass.py=) checks the pooler's port as it
  checks the NATS port, and refuses with the fix when it is closed.
- =compass services start= accepts =pooler= as a selector, as it accepts
  =nats=, so the fix is one command.

* Acceptance

- After =compass check='s =db= step, the =ctest= check passes the refdata,
  inbox and workflow suites with the pooler on and no manual step.
- =compass test run= with the pooler on and stopped exits non-zero, before
  ctest starts, and prints the command that starts the pooler.
- With the pooler off, neither the gate nor the preflight starts or asks for
  a pooler.
