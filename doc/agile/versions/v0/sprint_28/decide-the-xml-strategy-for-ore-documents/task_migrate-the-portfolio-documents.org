* Result

This task was done inside the reference data task. Its PRs are listed there:
[[https://github.com/OreStudio/OreStudio/pull/3549][#3549]], [[https://github.com/OreStudio/OreStudio/pull/3555][#3555]], [[https://github.com/OreStudio/OreStudio/pull/3556][#3556]] and [[https://github.com/OreStudio/OreStudio/pull/3560][#3560]].

The portfolio table and =portfolio_projection= read and write the document.
Eight instrument projections (bond, commodity, composite, credit, equity, fx,
rate, scripted) sit beside it in =projects/ores.ore/core/src/domain=. The
importer and the exporter call the projection. No hand-written
instrument mapper remains in that directory. The census reports Portfolio as
supported.

Proof recorded on that task: every portfolio in the example corpus exports a
document that binds. This record does not claim schema validation of the
exported documents.
