* Goal

A skill is a prompt, so changing one changes agent behaviour in a way reading the diff cannot show. Evaluating agent behaviour generally is hard because it needs a grader, but our case is easier than the general one: our work already carries mechanical verdicts. It compiles or it does not, the drift check is clean or it is not, the shell scenario passes or it does not. So a skill eval is a method run against a fixture task with a mechanical verdict. Take closed tasks whose outcome is recorded, re-run them in a throwaway worktree under the changed skill, and compare against what actually landed. Reserve this for skills the whole system leans on, because it is expensive and stochastic at the sample sizes we can afford; ordinary action-skill edits are evidenced by the selection instrumentation instead.

* Acceptance

- A fixture set of closed tasks with recorded outcomes exists and can be re-run in a throwaway worktree.
- Grading uses the independent checkers: compilation, tests, drift and the shell scenario. No judge model grades prose.
- An eval reports the verdict per fixture task and the difference against what actually landed.
- The harness is reserved for load-bearing skills, and which skills those are is stated.
- Where no mechanical verdict is available, the eval says so rather than substituting a model's opinion; the change is then labelled a judgement call.
- The harness is exercised on one real skill change before the task closes.
- The relationship to the selection instrumentation is documented: instrumentation is continuous evidence, the harness is for deliberate changes.
- Blinding follows pstack's protocol: no eval vocabulary anywhere the candidate sees, an organic prompt, sanitised directory names, no chain-eliciting cues, and the candidate is not told others exist.
- Chain-following is graded from the candidate's transcript — which files it actually opened — never from its own account of what it applied.
- The two steps of pstack's protocol that need a second model family are recorded as not portable, with the mechanical verdict named as the substitute.
