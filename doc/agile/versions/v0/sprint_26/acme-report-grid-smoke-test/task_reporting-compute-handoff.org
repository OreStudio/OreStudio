* Goal

The reporting submit path cannot run anything: it publishes an assignment on a subject no wrapper subscribes to, leaves result_id, package_uri, config_uri and output_uri empty, and hands over a bucket-prefixed URI where the wrapper fetches an HTTP path. The compute-side dispatch path does all three correctly and is the model to follow.
