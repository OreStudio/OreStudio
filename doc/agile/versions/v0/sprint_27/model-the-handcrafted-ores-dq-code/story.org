* Acceptance

- Every table and function in =create/dq= is generated from a model, or
  recorded with the reason it is not.
- The 49 artefact tables generate from the same entity model as their
  base table, with the archetypes that drop the audit and bitemporal
  columns and add =dataset_id=.
- The seven orphan artefact tables keep their consumers, each checked
  by census rather than by generated marker, and the hand-written
  =*_artefact_create.sql= files are generated from a model or deleted
  with the reason recorded.
- =dq= regenerates byte-identically and stays in =COMPONENTS_UNDER_TEST=.
