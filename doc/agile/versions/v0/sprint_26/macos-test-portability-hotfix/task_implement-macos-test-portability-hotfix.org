* Acceptance

- The two temp-directory assertions pass when the temp directory is
  spelled with a trailing separator, and they still fail if the file were
  created somewhere else.
- The abstract-socket case skips on a platform without an abstract
  namespace, and runs on Linux.
- =ores.platform.tests= and =ores.service.tests= pass on Linux.

* Plan

1. Reproduce the macOS spelling on Linux. =temp_directory_path()= honours
   ~TMPDIR~, so ~TMPDIR=/tmp/= makes it return a path with a trailing
   separator, which is the macOS condition.
2. Fix the assertion to compare the two paths as directories, and re-run
   under the reproduced spelling.
3. Make the abstract-socket case Linux-only with a skip that says why,
   mirroring the =/sys/class/net= skips next to it.
4. Scan the test tree for other Linux-only assumptions, and run both
   suites.

* Notes

- The first attempt used =lexically_normal()= on both paths and did not
  fix it: =path("/tmp/").lexically_normal()= is still ="/tmp/"=, measured
  with a three-line program. The assertion now compares the directories
  with =std::filesystem::equivalent=, which is what it always meant and
  which also survives macOS resolving =/var= through =/private/var=.
- The abstract socket is a Linux extension, not a boost one: the test's
  guard was =BOOST_ASIO_HAS_LOCAL_SOCKETS=, which macOS satisfies, so the
  case ran and =bind= failed with =No such file or directory=. The guard
  is now Linux-only with a skip message, the shape the platform net tests
  already use for =/sys/class/net=.
- The scan for other Linux-only assumptions in tests found two more
  patterns worth naming and no further fixes: the =/sys/class/net=
  cross-checks in =net_network_info_tests.cpp=, which already skip with a
  message, and =unistd.h= includes, which macOS provides.

* Result

Both macOS test failures are fixed in the tests.

The temp-directory assertions compare the two paths with
=std::filesystem::equivalent=, so the platform's spelling of its own temp
directory no longer matters. Proved against the reproduced condition:
with ~TMPDIR=/tmp/= the case failed before the change (~"/tmp" ==
"/tmp/"~) and passes after it; without it, the filesystem suite passes 44
assertions in 27 cases.

The abstract-socket case is skipped with =abstract unix sockets are a
Linux facility= where there is no abstract namespace, and still runs on
Linux, where the service suite passes 118 assertions in 42 cases.

The scan for the same class of assumption found the =/sys/class/net=
cross-checks, already guarded, and =unistd.h= includes, which macOS
provides; no further change was needed.
