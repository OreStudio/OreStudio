* Acceptance

- RAII handles for the connection and the result; no raw PQclear or PQfinish outside them.
- One ensure call checks every result; SQLSTATE classes map to our own exception types.
- Each connection prepares a statement once and reuses it.
- A batch runs in libpq pipeline mode; a bulk load runs through COPY.
- The pool sets the tenant and party settings on acquire, as the sqlgen pool does today.
- Tests against the database cover each of these, and the repository benchmark runs on the layer.
