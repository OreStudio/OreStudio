* Acceptance

- The IBOR indices the generated trades name are listed from the requirements function, with the ones not bootstrapped today.
- Each listed index has a bootstrap config, the quotes it reads, and a published curve under each party.
- The ACCOUK NPV run reports no 'did not find object' of type ibor index for a listed index.
- An index left out is named with its reason, such as a GENERIC index of a currency ORE does not know.
