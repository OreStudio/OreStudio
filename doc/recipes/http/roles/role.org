#+title: How do I call the roles endpoints over HTTP?
#+description: Every endpoint the roles resource answers over HTTP, with the request each one exports into the gateway's recipe library.
#+type: recipe
#+level: cross
#+filetags: :recipe:http:roles:

This file documents the roles resource over HTTP, one section per endpoint. Every section exports its own Hurl file into =projects/ores.http/scripts/library/=. Running a file sends that one request, so a failure names the endpoint it came from.

* Endpoints

** =GET /api/v1/iam/roles=
:PROPERTIES:
:ID: 37460C99-E3AD-5D18-A31D-6AB4022440B8
:END:

List roles. It needs a session.

It forwards to =iam.v1.roles.list=.

The request is:

#+begin_example
GET /api/v1/iam/roles
#+end_example

#+name: roles-list
#+begin_src hurl :tangle roles-list.hurl :exports none
GET {{base_url}}/api/v1/iam/roles
Accept: application/json
Authorization: Bearer {{token}}
HTTP 200
#+end_src
