* Result

A precompiled header of the common headers cut =ores.dq.core='s compile CPU by
45% and its wall time by 43%, with no change in peak memory. On top of a unity
build it adds little: 2 min 06 s becomes 1 min 53 s, because each unity batch
already parses its headers once. Use the unity build first. A precompiled header
is worth adding later only for targets that cannot build as a unity build.
