The test file for one entity's HTTP route unit. Every case stops at the
router, so the file needs no server, no NATS connection and no database. It
links against Catch2 and the part's own library.

Each case pins one thing the unit promises. Every derived verb appears in the
router's route list, which is the only public view of what the unit
registered. The count matches the derivation, so a route that stopped being
registered fails rather than passing as a smaller set. Each route carries the
authentication flag its own operation states, so a route that needs a session
cannot be registered without one and a route that needs none is not made
unreachable. Each route also carries the declaration itself, so a route the
builder would have refused cannot pass by being assembled another way.

A paged list route also gets cases that run its handler. The client is not
connected, so a request the route accepts fails at the forward step with a
server error, and a request the route refuses is a bad request. The cases read
that difference. A page and an order are accepted. Each declared filter is
accepted under the name its reader reads. An undeclared filter is refused and
named. An empty item in a one-of filter is refused.

* Mustache incantations

The expectations are built from ={{http_route.routes}}=, one entry per derived
route, each carrying the method, the path and the auth flag the projection
decided. The path is the pattern the route was registered under, so the case
compares registration against the same source the registration read.

Every case name starts with ={{entity_singular}}_routes=. A component's test
files link into one binary, so without the prefix two entities in the same
component declare each case name twice. Catch2 rejects the duplicate, and
=ctest= does not always surface the rejection, so the prefix is what keeps
the component's suite both startable and honest.

/// A router holding the unit's routes, registered against a bare client.
///
/// Registration touches no transport: the client is only what each route

    auto table = std::make_shared<router>();
    auto registry = std::make_shared<endpoint_registry>();
    {{entity_singular}}_routes::register_routes(table, registry, session);

/// Runs a handler to completion. The handler never reaches a socket, so the
/// context has no I/O to wait on.
[[maybe_unused]] http_response {{entity_singular}}{{^entity_singular}}{{name_singular}}{{/entity_singular}}_run(boost::asio::awaitable<http_response> work) {
    boost::asio::io_context io;
    std::optional<http_response> answer;
    boost::asio::co_spawn(
        io,
        [&answer, work = std::move(work)]() mutable -> boost::asio::awaitable<void> {
            answer = co_await std::move(work);
        },
        boost::asio::detached);
    io.run();
    return answer.value_or(http_response{});
}

    std::initializer_list<std::pair<const std::string, std::string>> params) {
    http_request req;
    req.method = http_method::get;
    req.query_params = params;
    return req;
}
