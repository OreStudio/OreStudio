* Notes

** What keeps reflect-cpp

=router.hpp= builds each endpoint's JSON schema with =rfl::json::to_schema= and
its example with =rfl::json::write=, =route.hpp= documents that, and
=endpoint_registry.cpp= resolves the schemas through =rfl::Generic=. Generated
schemas are part of [[id:7A1D09B8-B3F2-4E02-9669-3C2F6CC2C6EC][Remove reflect-cpp]],
so they stay. =router.hpp= now includes the reflectors itself: the generated
routes used to bring them into the unity build, and they no longer do.

** A junction's route did not see its opt-in

The route shape a junction renders from is built from the junction's sides, and
it did not carry =has_generated_wire_codec=, so =image_tag_routes.cpp= kept
reflect-cpp after the first regeneration. Codegen now copies the flag onto the
shape.
