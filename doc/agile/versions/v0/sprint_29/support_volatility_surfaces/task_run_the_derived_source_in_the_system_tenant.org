* Notes

** What failed

On a provisioned environment, for each of the ten pairs, the derived source logged "kept no history of PAIR: … Invalid derivation_kind: FX_VOL_DERIVATION". The system tenant held no FX option conventions (Acme held 865), and the four marketdata suites failed on counts the derived feed, scope rows, route, adapter and supplier raise by one.

** What each fix exposed

- Adding =ore.conventions= to =system_core= first returned =skipped_no_party=: the default party of a publish is the tenant's root party that is not the system party, and the system tenant holds no other.
- With a party, the publish ran ninth, before =iso.currencies=, and the zero-inflation convention's currency check refused EUR. The bundle sort was a plain topological sort, so datasets with no edge between them ran in an arbitrary order. An edge was not used: dependencies resolve transitively, so every =party_essentials= publish would republish the currencies and write a version of each per party.
- In member order, =synthetic.feeds.bloomberg= ran after the currencies and was refused CNH. The currency check lets any value through while no currency is stored, which is how the feeds published before. CNH is in =fpml.non_iso_currency=, which =base= publishes for a tenant and =system_core= did not.

** Found outside this task

- The committed =ores_schema.dq_staging.puml= was one line stale on main (=cut_kind_code=); regenerated here.
- =test_junction_events.py::test_the_events_are_published_on_the_junctions_collection= fails on this branch, which does not touch =ores.codegen=.

* Result

The derived source of FX volatility quotes now runs in the system tenant. Provisioning a recreated environment completes, the source writes its ten series under =FX_VOL_DERIVATION=, and it finds the FX option convention of each pair in the system tenant.

- =FX_VOL_DERIVATION= is a seeded derivation kind.
- =system_core= publishes =ore.conventions=, and =fpml.non_iso_currency= after =iso.currencies=.
- A party-scoped publish into the system tenant that names no party writes for its system party when the tenant has no root party.
- A bundle publishes its datasets after their dependencies and otherwise in its member order. Boost.Graph is no longer linked by dq core.
- The four marketdata suites count the derived source, and a new suite covers the kind and the party rule.

The source still keeps no history: no ECB fixing exists until the public rates are loaded, which [[id:BBCE9F48-939B-43DB-B703-99B3196942D4][Load the public rates as a workflow step]] now verifies.
