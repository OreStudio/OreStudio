* Notes

** A protocol codec without a protocol

=grid_sample=, =node_sample= and =workflow_batch_link= turn =ores.cpp.protocol=
off, because nothing reaches their tables over the wire. The protocol codec
archetype belongs to the wire-codec facet, so it rendered for them anyway and
included a header that does not exist. The archetype now states
=#+requires_facet: ores.cpp.protocol=, the dependency mechanism the recipe
facets already use, and =test_protocol_codec_requires_protocol.py= resolves
compute's real models both ways. No other component had an orphan codec.

** A junction's enriched code was off the wire

=app_version_platform= carries =platform_code=, which the repository fills from
the platform row because the junction table has no code column. reflect-cpp
wrote it; the junction codec named only the table's columns, so the byte test
failed on it. The codec template now names one code per side that sets
=:enrich_code:=, after the audit members where the struct declares it, and
=test_junction_codec_enriched_code.py= renders it both ways. No other model
enriches a code.

** What keeps reflect-cpp

=report_submit_handler.cpp= reads =submit_compute_request=, which belongs to
reporting and gets its codec in reporting's own task.

** The wrapper's manifest

=manifest.json= is a file inside the package, not a wire message. The wrapper
reads it through the struct codec with =wire_fields= on the hand-written
struct, and keeps its error message.
