* Summary

Booking is the journey [[id:F7987581-7AED-499C-9EEA-000AFB1FA95A][Book a trade]]. The [[id:BD492939-118E-4B55-AE5B-300F7A1C3B41][Entity screen specification]] allows a guided sequence only when it makes the task quicker or easier. The prototype draws the same form two ways so that a trader can try both: the page of cards (default) and the sequence (=?variant=steps=).

** What the prototype argues

- The trade type comes first. It decides which instrument card appears, because each trade type routes to one instrument table.
- 28 of the 121 trade types have no instrument table. The picker draws them disabled and says so. This is a real gap.
- A virtual book holds only a draft, a test or a hypothetical. The review step refuses a live, real trade in a virtual book.
- The review lists the writes. =book_trade= does not write the instrument today, so the prototype shows the second write and the half-booked outcome.
- A composite is built from its legs. The prototype links to the structure editor of the [[id:7B737119-099C-451D-9319-1D6BEE73A063][Trade Entry Prototype]], and a booked trade links to its pricing screen.

** What is fake

Everything. A booked trade is kept in the browser so that it appears on the trade list.
