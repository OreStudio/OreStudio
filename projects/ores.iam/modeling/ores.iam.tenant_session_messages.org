A system administrator reads a tenant's data from inside the tenant. Entering
issues a session scoped to the tenant, so row-level security scopes every
ordinary read from the token, and no read takes a tenant as a parameter. The
session acts as the tenant's system party, carries read permissions only, and
names the tenant the administrator acts from. Leaving records the exit; the
caller returns to the session it entered from.

Both are domain operations, because they act on a session and not on an
entity. Neither generates a shell command: the shell holds one session, and a
command that printed a bearer token would hand it to the terminal.
