* Goal

The CNB adapter reads a day with an empty rate as a day with no fixing, so every yearly file parses and a refresh across any window stores the days the bank fixed.

* Acceptance

- A row with an empty rate gives no fixing and does not refuse the file.
- A rate that is present but is not a number still refuses the file.
- The CZEONIA refresh stores fixings on a fresh environment, and the CZK coverage names a series for its overnight rate.

* Decisions

- An empty CZEONIA rate means the bank set no rate that day, so the row gives
  no fixing. Only an empty rate is read this way; any other text that is not a
  number still refuses the file.

* Out of scope

- The failed refresh of bcb-cdi, which another source causes.
- The start order on a fresh environment, which leaves the CZK curve on its fixed
  rate until the synthetic service starts again.
