* Goal

The journey document still describes the design that was rejected. It puts the request in ores.workflow as an instance that suspends and resumes, names five IAM request subjects that were never built, and lists seven gaps of which five are answered. Rewrite it around the design that was built: an approval request is its own record with a kind, ores.inbox holds the queue and the decision, and IAM holds only the detail of a role grant. State which gaps are closed and how, and which the two new tasks close.
