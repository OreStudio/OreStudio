The fan-out configuration of the [[id:25ED321D-A489-449C-BF60-15F1A1B3DBE7][identity workflow]]. The =ores-shell= block
below is tangled into the runnable script library as =identity_fan_out.ores=.

* Question

How do I run a workflow with more steps than I can watch one at a time?

* Answer

The request declares five steps and the engine dispatches them in order, advancing =current_step_index= after each completion. The materialised step list on the instance is what makes a restart re-dispatch the same sequence.

#+name: identity-fan-out
#+begin_src ores-shell :exports none
workflow start identity_workflow '{"steps":[{"name":"one"},{"name":"two"},{"name":"three"},{"name":"four"},{"name":"five"}]}' --instance-id 10000000-0000-4000-8000-000000000002
workflow wait 10000000-0000-4000-8000-000000000002 --timeout 60 --expect-state completed
#+end_src

=workflow wait= fails unless the instance reaches the state named, so this
script fails when the path it covers does nothing.
