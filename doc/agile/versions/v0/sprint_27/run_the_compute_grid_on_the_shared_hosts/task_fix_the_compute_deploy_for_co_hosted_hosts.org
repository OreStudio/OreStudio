- The grid screen's Refresh reloads its plots, for an operator and for a tenant administrator.

* Result

Done. The compute role keeps one directory per environment on a host
(=compute/<label>=), holding its env file, client certs, per-replica work
directories and logs, and =LABEL= is passed by =compass env deploy= rather
than read back from the host. =remote-stop.sh= takes the label the same way,
so stopping an environment no longer tears down whichever environment
deployed last. Replica scratch directories are named =replica_<n>=.

Building the images at all was blocked on the way here: =stage-runtime.sh=
hard-coded =linux-clang-debug-make=, =compass image build= never exported
=.env=, and the image set included =ores.web.service=, a node service with no
binary. All three are fixed, and the service list now comes from one helper
that applies the same node-runtime split the Quadlet generator already used.

The grid screen's Refresh read only the summary query, so its plots stayed
stale until a full page load, and a tenant administrator had no refresh
control at all. Both are fixed, and the control now states its load as the
existing ISO =LoadedAt= label rather than a hand-rolled =HH:MM:SS UTC= span.
The redundant back-to-operations button is gone from all six operations
screens, each of which already carries a breadcrumb.

Verified live on 2026-10-13: 19 wrappers deployed across newton (11), laptop
(3), simba (2) and goedel (3), all healthy and all registered in the serving
environment, with =claim_work= polling visible in the wrapper logs. A
five-minute soak then sent 70 jobs: 62 good ones finished Success and the 8
sent to fail finished ClientError, each carrying the archiver error for its
unreadable input.

Two limits. The refresh button was not clicked under test: the web package
has no interaction-testing setup, so it was verified by hand and by the
served bundle matching the build. And the runtime role shares the same
per-host state as the compute role but was not deployed, so its half of the
isolation is untested.
