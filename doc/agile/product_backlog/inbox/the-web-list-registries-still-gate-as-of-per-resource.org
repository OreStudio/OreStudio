* What

=records.ts= and =classifications.ts= in =projects/ores.web/packages/wire-protocol=
carry an =asOf= flag per resource, and the generic list adds =as_of= to its
request only where the flag is set. Since PR 2683 every generated entity list
accepts =as_of=, so the flag no longer says anything about the server.

* Why

A resource without the flag cannot ask for a past instant, though the server
would answer. A list without =as_of= still gets the current rows, so nothing is
wrong today; the gap is a capability the web does not offer. Retire the flag,
or set it everywhere, so every list can offer the point-in-time read.
