#+title: Conventions journeys
#+description: The market terms an instrument is built on: the convention entities, what each one fixes, and the picks from the reference data lists that a person must not edit from a convention.
#+type: knowledge
#+level: cross
#+filetags: :knowledge:user_journey:refdata:
#+created: 2026-10-07
#+updated: 2026-10-07

A convention is the set of market terms an instrument is built on: the day
count, the calendars, the payment frequency, the index, and whatever else the
instrument family fixes before a trade exists. There are 25 convention entities,
one per instrument family, from the deposit convention up to the cross-currency
basis swap.

A person starts from the instrument they want to trade, never from the entity
name. The journey walks from the instrument family to the convention that serves
it. Most of a convention's fields are picks from the reference data lists the
classifications journey maintains, so a convention references those lists and
never edits them.
