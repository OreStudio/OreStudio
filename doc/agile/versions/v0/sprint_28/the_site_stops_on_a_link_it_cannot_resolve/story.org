* Goal

The documentation site builds. A full build stops when org cannot resolve an
=id:= link, and two journey pages pointed at the report history page with an
upper-case id while the page defines it in lower case. org resolves ids by
exact string, so the link did not resolve and the export aborted:

#+begin_example
Build failed: Org export aborted.  Unable to resolve link:
"465CA244-C488-4C69-ACA3-C694D104A42A"
#+end_example

The same page is referenced six times in the tree and the other four
references already use the lower-case id.
