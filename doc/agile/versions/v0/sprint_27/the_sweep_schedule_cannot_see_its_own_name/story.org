* Decisions

- *Capture the name, not the object.* =[this]= would fix the lookup by capturing
  the whole sweep schedule for a predicate that reads one string. The lookup's
  own comment says the match is by name, so a local holding the name and a
  reference capture say the same thing with less in scope.
- *Read the rest of the feature before shipping this.* None of it had been
  compiled either, so the other hand-written files from the same commit were
  checked for the same fault. Their lambdas all capture what they read.

* Out of scope

- A gate for this. A lambda that reads a member without capturing =this= is a
  compile error every time, which is what the compiler is for; the cost here was
  that the file had never been compiled, not that the rule is hard to see.
