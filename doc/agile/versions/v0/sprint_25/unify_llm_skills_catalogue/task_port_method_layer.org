* Goal

The method plane is control flow with no effectors; our actions and recipes are effectors with no control flow. This task joins them. Port the adopted pstack playbooks and the Matt Pocock interview and design skills, rewriting every step that assumed a foreign host. Each method opens with the domain grounding phase, states a falsifiable predicate backed by an Allium spec where behaviour is involved, cites principles for the judgement calls, calls actions for anything touching an artefact, and reaches for a recipe rather than improvising a command. Steps that assumed Graphite stacks, model routing or an issue-tracker abstraction are dropped, because our agile layer already owns that ground.

* Acceptance

- Every ported method opens with the domain grounding phase and states a falsifiable predicate.
- Every method step names the action or recipe it calls; no step improvises a command inline.
- Steps that assumed a foreign host are dropped or rewritten, and the choice is recorded.
- The interview primitive is ported once and shared by the methods that need it.
- Every ported method carries its upstream repository, path and commit.
- At least one method is run end to end on real work before the task closes.
