A target a wrapper and engine can be built for, named by its triplet code
(for example =x64-linux=). A package belongs to an app version and a
platform, so the orchestrator matches incoming workunits against the host's
triplet through this row.

The platform registry is a global one: the platform rows ship under the
system tenant and every tenant reads them, which
=:system_tenant_visible: true= states on the repository.

=is_active= retires a triplet without deleting it, so a package that names
it still resolves. It is a plain column and not a declared filter, because
the generated read refuses a filter today and a filter the service rejects
is worse than no filter at all.

UUID primary key for the platform.

** code
:PROPERTIES:
:type:         text

:natural_key:  true
:END:

Triplet code, e.g. 'x64-linux'. This is the key callers address the row by.

** display_name
:PROPERTIES:
:type:     text
:cpp_type: std::string
:END:

Human-readable name, e.g. 'Linux x86-64'.

** description
:PROPERTIES:
:type:     text
:cpp_type: std::string
:END:

What the triplet targets.

** os_family
:PROPERTIES:
:type:     text
:cpp_type: std::string
:END:

Operating system family: linux, macos or windows.

** cpu_arch
:PROPERTIES:
:type:     text
:cpp_type: std::string
:END:

CPU architecture: x86_64 or aarch64.

** abi
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: true
:END:

Application binary interface, where the triplet distinguishes one. Empty
for a triplet that does not.

** is_active
:PROPERTIES:
:type:     boolean
:cpp_type: bool
:default:  true
:END:

Whether the triplet is offered to hosts. A retired triplet keeps its row so
packages that name it still resolve.
