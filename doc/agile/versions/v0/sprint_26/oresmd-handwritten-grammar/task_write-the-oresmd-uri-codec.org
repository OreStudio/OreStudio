* Acceptance

- The codec walks the datum's fields in schema order; it has no per-family branch.
- The writer leaves out a field that holds none. The reader reads a missing key as none only where the schema row allows none, and refuses a missing required key, an unknown key or a repeated key.
- The path is the row's subject field, percent-encoded with its case kept, and the query does not repeat it.
- A =type=quote= URI follows the strict contract: every required field of its schema row present, an optional field present only when it holds a value, nothing else, no default, no partial form, one to one with the canonical ORE key. The reader refuses any =type=quote= URI that breaks it.
- A =type=series= URI holds the identity fields only; the reader refuses a coordinate field in it.
- For every datum in the reference catalogue: =read(write(d)) == d=, =write(read(u)) == u=, and the series URI parses.
- Property tests generate datums from each schema row and each field's domain and round-trip them.

* Notes

Through today's URI, 7,254 corpus keys do not read back and 4,269 produce a URI

** The agreed shape

Agreed with the product owner on 2026-10-02:

#+begin_example
CDS/CREDIT_SPREAD/ACME/SNRFOR/USD/XR14/5Y
oresmd://credit/ACME?type=quote&instrument=cds&quote=credit_spread&seniority=SNRFOR&ccy=USD&doc_clause=XR14&term=5Y
oresmd://credit/ACME?type=series&instrument=cds&quote=credit_spread&seniority=SNRFOR&ccy=USD&doc_clause=XR14
#+end_example

- The query keys are the schema's field names, so the codec needs no table
  from fields to URI names. The instrument and quote values are ORE's names in
  lower case (=fx_spot=, =zc_inflationswap=), which needs no table either.
- A field that holds none is left out. The first proposal wrote every field,
  with an empty value for none. That rule came from the old grammar, where a
  missing key meant a default. In the typed model none has no default and the
  schema says which fields may be none, so the reader can tell a missing
  required key from none. Only one risk remains: a writer that forgets an
  optional field it meant to set. The codec is the only writer.
- A series URI has =type=series= and holds the identity fields only.

** What the schema gained

Each schema row now names its asset class and its subject field. Both are data
that the URI needs and that classification will need when the consumers move
over. A =static_assert= checks that every subject is an identity field of its
row that is never none. The asset class names are the oresmd authorities
=ores.refdata='s catalogue already maps: =ir=, =fx=, =credit=, =equity=,
=commodity=, =inflation=, =security=, =correlation=, =rating= and
=shape_profile=.

The subject is the currency for the rates rows, the reference entity or index
for credit, the unit currency for FX, the index for inflation, the name for
equity and commodity, and the security or contract for securities. Two rows
needed a choice: a cross-currency basis swap uses =ccy=, the curve being
built, not =flat_ccy=; a cross-currency fix-float swap uses =fixed_ccy=, the
curve being built.

** Strictness by the ORE key

A quote URI could name a datum that the schema admits but that no ORE key
can write, such as a CDS with a doc clause and no seniority. The reader and the
writer both call =ore_key_codec::write=, which reads its key back, so a quote
URI is one to one with the canonical ORE key by construction. The cost is the
corpus time above.

** Encoding

Boost.URL writes the URI. The query uses =space_as_plus = false=, because a
=+= is data in a strike or a free-text name, not an encoded space. Boost leaves
~=~ unencoded in a value; RFC 3986 allows it, and only the first ~=~ splits a
key from its value. The test =reserved_characters_are_percent_encoded_and_case_is_kept=
pins the exact text.

* Result

=oresmd_uri_codec= in =ores.marketdata.core= writes a datum or a series as an
oresmd URI and reads it back by walking the schema row. Every documented form
and every corpus key round trips as a datum and as a series, and gives back its
canonical ORE key. The reader refuses each break of the contract that the
refusal test lists. The old =market_data_urn.org= still describes the old
grammar; the design record task rewrites it.
