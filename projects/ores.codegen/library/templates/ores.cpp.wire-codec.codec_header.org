Declares a type's four wire functions — =to_json=, =from_json=, =to_msgpack=,
=from_msgpack= — and the =ores::utility::codec::wire_traits= specialisation that
names them.

The specialisation has to be visible in every translation unit that names the
trait for the type, because a template argument the compiler cannot see here is
resolved against the primary template there, and two translations of one type
disagreeing about its encoding is the one thing the seam exists to prevent. So
the specialisation is stated in a header, and this is it.

See the [[id:C4E8A91F-3B7D-4F2E-85A6-1D9C7E3B2F4A][Template variable reference]] for the complete list of available
variables and their semantics.
