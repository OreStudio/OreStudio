* Result

`compass db status` prints the timescaledb version a database records and
whether a library for it is on disk, under the schema block:

#+begin_example
    timescaledb: 2.30.2, and its library is on disk
#+end_example

A mismatch names both versions and the statement that fixes it:

#+begin_example
    timescaledb: recorded 2.30.1, but only 2.30.2 is on disk
    compass sql -- -c "alter extension timescaledb update;"
#+end_example

A database without the extension reads as "not installed in this database",
not as a fault. The compass suite passes: 453 passed, 1 skipped, with six
new cases.
