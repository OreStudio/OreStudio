* Goal

The Qt client leaves the repository. Its metadata does not. The entity models keep the drawer that describes a screen's columns and its form fields, under the name Presentation. Codegen projects that drawer into TypeScript, so the entities share one table component and one form component instead of one hand-written screen each.

* Decisions

- The drawer is renamed, not rewritten. Its vocabulary stays as the
  models authored it, including the properties the Qt templates were the
  only readers of. The alternative is a 109-file diff that changes what
  the models say.
- The twelve variability features move from the =qt= namespace to
  =presentation= by name only. Their docs and profiles are untouched.
- The projection emits what the models carry. A member the request names
  with no model source behind it — =maxLength= on =alpha2_code= — is
  omitted rather than invented.
- =style= follows the request's §3.5 table rather than the column style
  the C++ projection derives, so UUID and timestamp columns read
  =mono_left= in TypeScript while the C++ side still reads =text_left=.
  The request is explicit that the generator follows its table.
- The story stays open after PR 1. Its acceptance asks for the trees to
  be gone, which is PR 2.

* Out of scope

- Removing the drawer properties and the derived values that no reader
  uses now that the Qt templates are gone.
- The Qt prose that survives in the model bodies, the Qt recipes, the
  Qt skills and the product-backlog triage. PR 2 carries them.
