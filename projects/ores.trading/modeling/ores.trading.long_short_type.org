Reference data table defining valid position direction codes.

The set is closed and will not grow: the ORE =longShort= simple type under
=external/ore/xsd/ore_types.xsd= states exactly Long and Short. Defect 4 of
=trade_model_defects.org= records that the trading columns held this closed set
as free text with no reference table; this table is that reference.

The values are the ORE XSD spellings, so a stored value round-trips through the
ORE XML unchanged. No conversion is introduced here.
