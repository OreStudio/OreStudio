What a default curve built from market quotes states about those quotes, as
ORE's =DiscountCurve=, =Conventions= and =Quotes=. The CDS spread, hazard rate,
price, conventional spread and null constructions read them. A transition matrix
reads only its =Quotes=, but every transition matrix in the ORE examples also
states a discount curve and conventions, so the part holds them for that type
too and the document round trips as written.

A default curve configuration holds at most one row of this part, so the generated table
adds the unique index on the live rows of =(tenant_id, default_curve_configuration_id)=.
