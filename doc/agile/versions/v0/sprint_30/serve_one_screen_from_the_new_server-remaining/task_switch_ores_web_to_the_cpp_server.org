* Goal

Move the one switch that sends the requests of ores.web to the C++ server, and test ores.web end to end. If ores.web breaks, move the switch back, use the BFF, fix the fault and try again. Retiring the BFF is not part of this task. This task depends on all the other tasks of this story.

- The inventory shows that the C++ server answers every route ores.web calls.
