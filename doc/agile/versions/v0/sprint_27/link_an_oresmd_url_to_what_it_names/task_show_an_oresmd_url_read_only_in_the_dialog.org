* Acceptance

- The dialog without onApply shows labels and values in the grid of the record details, and no input, select or datalist.
- Each field shows its name and its text, a field the URL leaves out is not listed, and the path is labelled as the path.
- The codec's URL is shown under the values with Copy, and a URL the codec refuses shows its reason in place of the values.
- The dialog with onApply is the editor as it is today.
