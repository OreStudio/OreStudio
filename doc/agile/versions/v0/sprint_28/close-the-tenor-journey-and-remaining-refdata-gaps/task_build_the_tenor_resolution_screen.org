* Plan

The work is split between the wire layer and the screen.

The branch =feature/build-the-tenor-resolution-screen= carries the first half,
written 2026-10-10 and parked while the book prototypes were signed off:

- =bff/src/tenors.ts= with =tenors.test.ts= — the tenor list, read and resolve routes.
- =web/src/api/tenors.ts= — the typed client.
- =web/src/journeys/tenorsServer.ts= — the server half of the journey.
- =web/src/journeys/tenorsState.ts= — the journey state.

The screen half is not written. Every peer journey in this package carries five
files — =<x>State.ts=, =<x>State.test.ts=, =<x>Steps.tsx=, =<x>Steps.test.tsx=
and =<X>Journey.tsx= — so its state machine and its screen are proved by tests.
The tenor journey has the state file alone. The remaining work is:

1. =web/src/journeys/tenorsState.test.ts= — prove the state machine.
2. =web/src/journeys/tenorsSteps.tsx= and =tenorsSteps.test.tsx= — the steps.
3. =web/src/journeys/TenorJourney.tsx= — the screen, against
   =doc/prototypes/tenors/define-how-tenors-resolve/=.
4. Wire the journey into its route, then run the package suites.

The journeys it draws from are the list, the tenor, its convention, the
schedule, the resolved dates, the review, the refusal and the history.

* Built, 2026-10-15

All four steps above are done. The screen is a six-step rail — choose, tenor,
convention, review, outcome, history — and the convention is the second half of
the same rail rather than a journey of its own, because a tenor and the rule
that resolves it are read together and the review draws one difference list over
both.

Two decisions worth carrying to the story:

- The screen is reached from its own card, =Define how tenors resolve=, at
  =/refdata/tenors=, beside the instrument-convention card. Tenors are their own
  reference-data job, not a step inside the convention journey.
- The resolved-dates view is not drawn. The server serves no operation that
  resolves a tenor to a date; the BFF says so in =tenors.ts= and the state
  machine says so in =tenorsState.ts=. That view belongs to the sibling task
  =Resolve a tenor over the wire, with the refusal it carries=.

Tests: 20 on the state machine, 8 on the steps, 1 on the page.
