#+title: Codegen: has_parent_id without its two column properties fails silently
#+description: Turning has_parent_id on emits a recursive-CTE hierarchy function that names the entity's parent_id_column and hierarchy_name_field. If the model sets the feature without those two properties, the function is generated with empty column names and nothing fails. Eleven entities sat in exactly that state, hidden only by a separate namespace defect. A loader check that rejects the combination would turn the silence into a hard error at regeneration time.

This page is a [[id:671F18E4-E09C-4B3B-BD24-D33DF8AE38A6][capture]] in the *inbox* bucket of the product backlog — a pre-sprint idea, not yet pulled into a sprint as a story.

* What

When =has_parent_id= is true, the SQL facet generates a recursive-CTE
=hierarchy_fn= whose body names the entity's =parent_id_column= and
=hierarchy_name_field=. If the model sets the feature but not those two
properties, the generator emits the function with empty column names.
Nothing fails. Neither the loader nor any check inspects the
combination.

Add a check in =org_loader.py=, beside the profile merge: when the
resolved entity has =has_parent_id= true and either column property is
missing, raise. The check should run after =_apply_profile=, so a
profile-supplied feature is covered too.

* Why

The failure mode is silence, and silence is the expensive part. The
eleven entities described in
[[id:4B656AD0-DA7B-41BE-998F-F6AF5E03B6C2][the namespace capture]] sat in
exactly this state for as long as they did because no signal ever fired.
A separate defect hid them, but had the namespace been correct from the
start, those eleven would have generated hierarchy functions naming
empty columns and no one would have been told.

The profile documents the requirement in prose, in its Reference entity
section, and that was not enough. A model can bind
=self-referencing-hierarchy= and pass every existing check.

The check converts a silent wrong output into a hard error at
regeneration time, which is where the author can act on it.
