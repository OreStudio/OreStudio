* What

The codegen handler permission test fails on main: the commodity handler's permissions are not seeded. test_every_handler_permission_is_seeded and test_a_code_missing_from_the_seeds_is_reported in projects/ores.codegen/tests/test_handler_permissions.py fail on a clean checkout of origin/main b4585bf228, naming refdata::commodities:delete and two more codes that commodity_handler.hpp needs and iam_permissions_populate.sql lacks. Every branch that touches build/scripts now fails the tooling class of the local gate on main's defect. Found while raising the identifier PR of the UX epic.

The codes test_every_handler_permission_is_seeded names start with
refdata::commodities:delete; run the test for the other two. The fix is most
likely the three codes added to iam_permissions_populate.sql.

* Why

Every branch that touches build/scripts runs the tooling class of the local
gate, and the gate is red on main's defect, so a clean branch cannot show a
clean report until this is fixed.
