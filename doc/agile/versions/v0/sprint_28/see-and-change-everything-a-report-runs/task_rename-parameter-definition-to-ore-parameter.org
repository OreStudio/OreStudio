* Goal

The entity ore_parameter documents one leaf of an ORE XML document. A row says which leaf it is by the schema name (for example ore.xsd) and the XPath of the leaf. The documentation fields become required, except removed_in, in the task that documents the analytic parameters.

* Acceptance

- The table, domain, protocol, C++, TypeScript, shell and importer use the name ore_parameter.
- The entity has two new required columns, schema_name and xpath. The existing rows carry them.
- A test fails when a schema name and an XPath name more than one row, and when the XPath of an ore.xsd row does not follow from its scope, subtype and name.
- The model, SQL hygiene and drift checks pass.

* Plan

1. Rename the model files, the generated files and the hand-written references with one script, in a commit that only renames. The synthetic yield curve process parameter definition is a different entity and keeps its name.
2. Regenerate the four entities that the rename touches: ore_parameter, ore_parameter_value_domain, configuration_parameter and configuration_analytic_parameter.
3. Add the required columns schema_name and xpath. Give each existing row =ore.xsd= and its XPath: =/ORE/Setup/Parameter[@name='x']= for Setup and =/ORE/Analytics/Analytic[@type='t']/Parameter[@name='x']= for an analytic.
4. Keep scope, subtype and name. The run document service and the importer read them. A later task can drop scope and subtype when a second schema needs the table.

* Notes

- The column is =schema_name=, not =schema=, because =schema= is a keyword in SQL.
- The owner asked to add the schema and the path. This task keeps scope and subtype, so a row holds the same fact twice for =ore.xsd=. The pgTAP test =reporting_ore_parameters_test.sql= fails when the two disagree.
- The unique key on the schema name and the XPath is a test, not an index, because the model has no knob for a unique index on a natural key.
- The column =ore_parameter= of =file_type= was already named so. It holds the name of the Setup parameter that names a document. It could later refer to a row of this table.
