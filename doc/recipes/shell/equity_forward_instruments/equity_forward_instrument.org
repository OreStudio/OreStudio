#+title: How do I run the equity_forward_instruments commands from the shell?
#+description: Every command the equity_forward_instruments submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:equity_forward_instruments:

This file documents the equity_forward_instruments resource at the shell, one section per command. Every command is a subcommand of =equity_forward_instruments=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: C42185C2-2292-5619-AA88-3F21E13AEDB6
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
equity_forward_instruments list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =trading.v1.equity_forward_instruments.list=.

#+name: equity_forward_instruments-list
#+begin_src ores-shell :tangle equity_forward_instruments-list.ores :exports none
equity_forward_instruments list --limit 1
#+end_src

** =get=
:PROPERTIES:
:ID: EEBE345E-9DB9-574F-945E-1D7DB80D88FC

Reads the one row its key addresses. A key states every identifying column, so a partial key is refused rather than answered with an arbitrary row.

** =add=
:PROPERTIES:
:ID: C40C1FBE-631E-57BE-BE16-B0CA6ABCC4C8
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.


The command is shaped like this:

#+begin_example
equity_forward_instruments add <trade_type_code> <trade_id> <underlying_name> <currency> <quantity> <forward_price> <expiry_date> <long_short> <settlement_type> <description> <reason> <commentary>
#+end_example

It is addressed at =trading.v1.equity_forward_instruments.put=.

** =set=
:PROPERTIES:
:ID: B19358B9-1181-56BB-AB97-EE44D2081063
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved. Passing --version makes the write conditional on the version the caller last read.
