* Goal

For each of the three kinds, a test states the read rule after a withdrawal: the withdrawn set is never taken, the newest remaining set at or before the as-of is, and the set a superseded withdrawal left behind becomes live again.

* Acceptance

- For each kind, a read at an as-of before the withdrawn set takes the set before it.
- For each kind, withdrawing the live set makes the set it had superseded live again for the as-ofs it covered.
- A read of a withdrawn set by its publish still returns its values and the words that say it is withdrawn.
