* Result

The basket constituent carries the member's weight now, so a row holds what
the design says it holds: the name and the weight. E11 measured the basket as a
JSON string that kept the names and the weights nowhere, and the child table
had closed only the name half.

The weight is a continuous quantity and not money, so the column is a binary
float, and it is optional because a basket that names its members without
weighting them is valid. An absent weight stays null.

Verification. Full build clean, the whole suite passes 96 of 96 with the
database recreated for the new column, ores.trading.core.tests passes 1196
assertions in 178 cases and ores.trading.api.tests 410 assertions in 105 cases.
