* Acceptance

- each of the two types names an instrument table carrying the terms the product states
- the projection reads and writes each element, value for value
- each type has a builder, and the catalogue routes both
- the generator books one trade of each type through its builder, and the recorded trades hold it
- the ORE engine test reads and builds each, with no error of the trade kind
- every fact the element states is a column or a row: no list, basket or schedule is held as text

* Plan

- =EquityDoubleTouchOptionData= is the same schema type as
  =EquityTouchOptionData=, so the double touch routes to the equity digital
  option row, natively. The touch reader and writer take the element by name.
  Its two levels are one barrier's, in the shared barrier rows, which the
  writer prefers; the row keeps the lower level. The table's touch check names
  both touch types.
- =FxAsianOptionData= is the same schema type as =EquityAsianOptionData=. The fx
  family has no Asian option row, so the FX Asian option routes to the scripted
  instrument table through the class-read path.
- Builders: =equity_double_touch_option_builder= and =fx_asian_option_builder=.
  The FX Asian option states what both of ORE's examples state: the strike as
  a scalar, the underlying's weight, the settlement and daily observation
  rules with their term convention.

* Result

EquityDoubleTouchOption is held natively in the equity digital option row, its
two levels in the barrier rows. FxAsianOption is held in the scripted
instrument table, its option block in the option rows and its observation
dates in the schedule rows. The round-trip test reads a double touch and ORE's
FX Asian example and writes them back. Each type has a builder, the catalogue
routes both, and the generator books one trade of each. The ORE engine builds
the recorded trades with no error of the trade kind; the double touch raises
an engine configuration error, which the known list holds and the valuation
story owns. The recorded FX Asian trades state every path ORE's examples
state.

EquityAutoDeltaHedgedOption moved to its own task, because its batches each
state an option block.
