* Result

Already delivered on main before this branch was cut. No source change was
needed.

The insert overflow came from a write path that left =trades_per_book= unset
while the column is =integer=. Commit =c1153cc812= (Story 3DA9DFFB, Task
6172EE1E, solid_dirac) carries the count from the seed profile through the
parser and sets it on the write, and commit =bde83272d4= (Task
29DAA209, festive_dijkstra) makes the population size an =int=, as the column
is. Both are ancestors of this branch.

The failing run used binaries built before those commits. A rebuild and a
fresh =compass smoke ticks --fresh= on the current main pass the provisioning
step and every later step.
