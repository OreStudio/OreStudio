* Acceptance

- =ASSUMED_RECOVERY_RATE=, =BOND_FUTURE=, =BOND_FUTURE_OPTION= and =COMMODITY_CALENDAR_SPREAD_OPTION= have a struct, a reader, a writer and catalogue cases for every form ORE documents.
- =FX_SPOT=, =FX_FWD= and =RATE_GVOL= read, and write in their canonical spelling.
- The quote type enum holds all 16 ORE quote types, including =CREDIT_SPREAD=, =CONV_CREDIT_SPREAD=, =HAZARD_RATE= and =BASE_CORRELATION=, and every datum carries its quote type.
- A test asserts that every ORE =InstrumentType= and =QuoteType= has a modelled form, against a list taken from =marketdatum.hpp=.
- The asset class model and its seeds cover the classes the new types need.

* Plan

Do this after the key codec, as a set of additions to the model, the codec and
the catalogue.
