* Goal

`historicalreturnconfig.xsd` declares no global element: it defines the type `ReturnType`, a `Type` plus a `Displacement` with a required `key` attribute, and nothing that can be a document root. There is no `historicalreturnconfig.xml` to import, so the historical return configuration is a **section of the documents that reference it**, not a file type. This task proves the round trip where the section actually appears, and models it as the rows the section holds.
