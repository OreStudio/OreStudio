#+title: The junctions of assets, compute and reporting have no history
#+description: Three junctions state neither a history nor change events, because their components serve no generic history: the assets image tag, the compute app version platform and the reporting report type configuration type. A link that is closed there is a row whose end is in the past, with nobody able to read it back. The components need a history dispatch and a registrar, as iam, refdata, dq, inbox and marketdata have, and then each junction can state :history: true. Composing change events in the same components is a second step, since assets, compute, inbox, marketdata and reporting compose none today.
