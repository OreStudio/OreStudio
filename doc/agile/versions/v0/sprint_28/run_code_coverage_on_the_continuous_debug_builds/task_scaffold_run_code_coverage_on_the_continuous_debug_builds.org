* Decisions

- *Only the debug tier collects coverage.* =CTest.cmake= accepts
  =code_coverage=1= and picks the tool from the compiler: =gcov= for gcc and
  =llvm-cov= for clang. The Continuous matrix is clang-only, so its debug job
  needs nothing installed beyond the LLVM that the workflow already installs.
