Reference data table defining the valid =market_data_source.kind= values. A
source is one adapter instance of a provider, and its kind says how the adapter
gets its values: =live= from a real vendor session, =replay= from recorded vendor
ticks, =test= from a vendor test environment or a harness, =simulated= from a
generator, or =derived= from other series inside the service. The kind is data a
person can read. The pipeline never branches on it. The values are seeded and the
column is FK-validated rather than free text. Managed by the system tenant, like
other refdata code tables.
