* Notes

The check starts with what the first PR publishes. A definition is ready when it binds each type its report type requires, its run settings reach at least one book, and its run document has an analytic. It then lists, for each definition, the document an analytic reads that nothing stores yet. The reports blocked in that way are the ones the tasks "Add the analytic configuration documents with DQ support" and "Add the input documents the exposure reports read with DQ support" unblock.
