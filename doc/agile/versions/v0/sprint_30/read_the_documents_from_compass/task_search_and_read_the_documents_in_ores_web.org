* Goal

A person types a few words into a search bar in ores.web and sees the
matching documents, best first, each with its title, description and the
section that matched, filtered to what their role may see. Opening one shows
the document as compass renders it: a link to another document opens that
document in ores.web, and each heading has an anchor a result can point at.
ores.web reads only the ores.http document routes and parses no org.

* Acceptance

- The search bar answers as the person types, and a result opens its document
  at the section that matched.
- A link between documents opens the linked document in ores.web.
- The document view shows compass's sanitised HTML and nothing else; ores.web
  parses no org for it.
