* Summary

=ores.workspace.service= is the process that hosts the workspace component. It
parses the environment configuration, builds the database context, assembles
the PostgreSQL =LISTEN=/=NOTIFY= to NATS change-event pipeline through the
generated event registrar, and runs the domain service with the component's
registrar.

The change events the pipeline publishes are the workspace entity's: the
generated registrar owns the trigger's channel and the canonical event shape.

* Inputs

- The environment configuration: database credentials, the NATS endpoint and
  its TLS material, and the log destination.

* Outputs

- The =ores.workspace.service= process, subscribed to every workspace subject.
- Workspace change events published to NATS.

* Entry points

- =ores::workspace::service::app::application::run= — the service coroutine.
- =src/main.cpp= — the process entry point.

* Dependencies

- =ores.workspace.core= — the handlers and the registrar.
- =ores.eventing= — the change-event pipeline.
- =ores.service= — the domain service runner and the heartbeat publisher.
- =ores.database= — the connection context factory.
