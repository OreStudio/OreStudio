Reference data table defining the closed amortization set of a bond leg
notional schedule. The set is the ORE =amortizationType= simple type
under =external/ore/xsd/ore_types.xsd=.

The values are the ORE XSD spellings, so a stored value round-trips through the
ORE XML unchanged. No conversion is introduced here.
