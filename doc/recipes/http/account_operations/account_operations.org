#+title: How do I call the account_operations endpoints over HTTP?
#+description: Every endpoint the account_operations resource answers over HTTP, with the request each one exports into the gateway's recipe library.
#+type: recipe
#+level: cross
#+filetags: :recipe:http:account_operations:

This file documents the account_operations resource over HTTP, one section per endpoint. Every section exports its own Hurl file into =projects/ores.http/scripts/library/=. Running a file sends that one request, so a failure names the endpoint it came from.

* Endpoints

** =POST /api/v1/iam/accounts/save=
:PROPERTIES:
:ID: CECDEF58-CA57-54F5-9DE1-B4487D74A8CF
:END:

Save account. It needs a session.

It forwards to =iam.v1.accounts.save=.

The request is:

#+begin_example
POST /api/v1/iam/accounts/save
#+end_example

#+name: account_operations-save-account
#+begin_src hurl :tangle account_operations-save-account.hurl :exports none
POST {{base_url}}/api/v1/iam/accounts/save
Accept: application/json
Authorization: Bearer {{token}}
HTTP 200
#+end_src
