#+title: Task: Do not replay a compute assignment whose result is gone
#+description: The JetStream assignments stream outlives a database recreate. On the recreated environment the wrapper replayed assignments from the previous one and answered 'results.submit failed: Result not found' for each, because the result rows were gone. Either the recreate purges the stream, or the result-submit handler treats an unknown result as an expired assignment and acknowledges it instead of erroring, so a wrapper stops retrying work that cannot exist.
