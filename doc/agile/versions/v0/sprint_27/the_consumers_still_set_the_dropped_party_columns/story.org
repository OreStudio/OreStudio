* Decisions

- *Delete the assignments; do not repoint them.* The party and counterparty are
  reachable from a child through the key it already carries, by way of the
  security definer function =178610c4e8= added for row level security. Nothing
  the child does reads the copy.
- *Fix the tests too.* Two of the five files are test files. They still have to
  compile, and the assertions they lose were asserting the copy that is gone.

* Out of scope

- A gate for this family. A hand-written consumer that names a member the entity
  no longer has is a compile error, and stating the rule without compiling means
  knowing each receiver's type; there is nothing cheap and sound to add.

Merged in PR #2882. Verified on main at the green suite run: 85 suites, 9586 tests, 0 failures.
