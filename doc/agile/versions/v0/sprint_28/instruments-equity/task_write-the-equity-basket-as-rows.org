* Result

* Result

The worst-of basket now has a child table. =equity_basket_constituents= is
keyed by =trade_id= and =sequence_number=, so a list is rows and the order
the document stated is the order a read returns. One model declaration
generates the domain type, JSON I/O, the table, the entity, the repository,
the service, the messaging, the eventing, the shell commands, the SQL
create, drop and notify-trigger files, and the RLS policy.

Two checks hold the rows honest. The ordinal is positive, and the underlying
name is never empty.

=basket_json= stays on the swap model. The ORE import still writes the
basket there, and moving it onto these rows is the mapper work the operator
deferred to the xsdcpp removal. Retiring the column first would drop the
basket silently.

The unit also fixed a defect this session shipped: the generator expression
for =variance_strike= was hand-edited in the generated file, and codegen
reverted it, breaking the build. It is declared in the model now, which is
where codegen reads it.

Verification. Full build clean. The whole suite passes, 96 of 96, with the
database recreated for the new table. The workflow flake that failed twice
under parallel load did not recur.
