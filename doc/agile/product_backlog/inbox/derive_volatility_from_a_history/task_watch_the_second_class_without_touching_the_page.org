* Acceptance

- The swaption cube renders for a currency and an as-of, at one expiry or one term at a time, with the other axis along the panel, and the page names no asset class to do it.
- The page shows the derived level the cube started from, so a level that drifts away from the curve it prices against is visible.
- Every field the page needs and does not find is added to the surface's description. No change is made to the page's code for the class, and the task records any that were.
- A class whose surface declares no axes is refused with the axis it lacks, and the refusal names the surface and not the page.
- The journeys and the prototype are unchanged by the task. A change to either is a signal that the read did not state the axes.

* Notes

- This task is the test of the story's claim, not a feature of interest rates. If the page needs a branch, the fault is in the surface's description or in the read, and the fix belongs there.
- The FX page draws expiry by delta. The swaption cube declares an expiry and a term and holds one of them still. The difference between the two pages is data.
