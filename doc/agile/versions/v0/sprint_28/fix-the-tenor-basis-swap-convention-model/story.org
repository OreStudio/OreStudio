* Decisions

- The configuration document protocol fails C1202 by context accumulation across the handler unit, not by one over-wide literal. The control unit reflecting the same 24-member struct in 12 repository headers builds, while the handler reaches 103. Split the protocol and handler into one operation model per document family, conventions and curve configuration.
