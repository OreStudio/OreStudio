* Goal

Evidence that the generated tests detect a dropped member and a value the codec reads back wrong. A renamed member is out of reach for a roundtrip test, because the codec writes and reads under the same name.

* Acceptance

- Each mutation fails a named generated test, with the output saved under the story's evidence folder.
- The mutations are reverted and the tests pass again.

* Plan

Break the generated codec of one message, =ores::dq::messaging::artefact_type_write=,
one way at a time with =evidence/mutate.py=, rebuild =ores.dq.api.tests= and run
the generated case named by the type. The message has six string members, an
optional string and an integer, so it can show each kind of fault. Each
mutation edits one generated file and is reverted with =git checkout=.

1. =drop-member=: remove =target_subject= from =wire_fields=.
2. =json-loses-value=: the JSON read resets the optional =description=.
3. =msgpack-loses-value=: the MessagePack read sets =display_order= to 0.
4. =same-type-mixup=: the JSON read puts =code='s value in =name=, the case
   the review of PR 4406 named (finding 3).

* Notes

- The guard, not a test case, catches a dropped member, and only the test sees
  it: the library compiles with the member missing from =wire_fields=.
- A failed check prints ={?} == {?}=, because Catch2 has no way to print a
  message. The check's message names the value (sample or default) and the
  line names the format, so the failure is located, but not what differs.
- =sample<std::string>(0)= is one fixed text, so every string member of a
  sample holds the same value. The same holds for any two members of one type.
  A codec that reads one member's key into another member of the same type
  passes. A symmetric swap of two keys passes any roundtrip, whatever the
  values; only the fixed-bytes tests can catch that.

* Result

The generated test catches a dropped member at compile time, and a value the
JSON read or the MessagePack read loses, each in the case named by the message's
type. It does not catch a read that puts one member's value in another member of
the same type, because the sample gives both the same value. After the revert
the case passes again. Both acceptance bullets are met; the gap goes to a new
task in this story, Give each member of a sample its own value.
