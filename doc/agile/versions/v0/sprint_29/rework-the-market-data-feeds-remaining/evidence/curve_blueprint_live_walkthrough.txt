4. The picker's list: every series the party holds
--------------------------------------------------
POST /api/curves/series-by-id {"ids":[]}
  200, 329 series, each with its oresmd URI, including the two curve series
  a1a1a1a1-... (USD-SOFR-FOMC) and a2a2a2a-... (EUR-EURIBOR-6M).
  The ids are uuids whose version bits are not RFC's
  (a1eec62d-a758-f647-de09-d7f2c25d9196 is one), because the store's random
  generator does not set them; the route accepts the shape and not the version.

5. Adding a blueprint, with the output series chosen
----------------------------------------------------
PUT /api/refdata/ir-curve-bootstrap-configs
  {output_series_id: a2a2a2a2-..., currency EUR, index tenor 6M, FUNDING,
   LOG_LINEAR_DISCOUNT, A360, RATES_SPOT_FORWARD, 1Y, system.new_record}
  204
GET .../key/f1f1f1f1-0000-4000-8000-000000000001
  200, version 1, EUR 6M, series a2a2a2a2-..., LOG_LINEAR_DISCOUNT.
POST /api/curves/series-by-id with that id
  200, oresmd://ir/EUR?type=series&instrument=discount&quote=rate&
  curve_id=EUR-EURIBOR-6M

  A create that names the series the USD recipe already claims is refused:
  502, "duplicate key value violates unique constraint
  ir_curve_bootstrap_configs_output_series_id_uniq_idx". One series names one
  blueprint, which is what makes the column the record's natural key.

8. The check
------------
POST /api/curves/compute {"bootstrap_config_id":"b1b1b1b1-...","as_of":"2026-10-07 17:00:00Z"}
  422 {"code":"invalid-request","message":"pillar key:
  'IR_SWAP/RATE/USD/0D/1D/1F': '1F' is not a period, a date, ON, TN, SN or a
  continuation"}
  The Check tab draws this as the server's own words in a notice: the build
  refuses a schedule-resolved (FOMC) pillar, which the screen does not hide.

10. The badges the screen reads, on a fresh environment
-------------------------------------------------------
GET /api/labels, without any manual publish step: a provisioned tenant
publishes its catalogue from the artefact seeds, and the six curve domains
arrive with it:
  curve_family_role (2): Funding curve, Projection curve
  interpolation_method (3): Cubic spline, Flat forward then log-linear,
    Log-linear discount
  day_count_convention (4): 30/360, A360, A365, A365F
  tenor_convention (2): Rates, spot FOMC; Rates, spot forward
  bootstrap_curve_role (3): Deposit, FRA, Swap
  curve_publish_state (3): Published, Superseded, Withdrawn
