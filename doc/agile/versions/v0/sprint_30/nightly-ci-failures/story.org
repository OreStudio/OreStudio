* Goal

The nightly builds on Linux, macOS and Windows and the valgrind run are red.
The causes are separate: the =cli= 2.3.0 completion change, one GCC error, one
Windows compile error, a missing valgrind suppression, an uninitialised send,
and three macOS test failures. This story fixes each cause, so that the nightly
runs show only real defects.

- The 16 =ores.shell.*= suites pass with =cli= 2.3.0.

* Decisions

- Test the bare verb that =cli= 2.3.0 returns, and do not patch the overlay.
  =ores.shell= runs on =CliFileSession=, which has no tab completion, so no
  user sees the completion output.
- Carry every fix in one PR with one commit per fix. The nightly runs on =main=
  are the final proof, because no local environment reproduces macOS or Windows.
