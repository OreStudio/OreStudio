* Goal

One package turns org text into a tree and the tree into safe, formatted output, in Node and in the browser. Scenario docs, stories and tasks read as they do on the site.

* Acceptance

- The parser handles keywords, property drawers, headings, paragraphs, lists, tables, bold and italic, code, links and id links.
- The renderer escapes everything, so org text cannot inject markup.
- The package runs in Node for the BFF and in the browser for the web package.
- Tests cover each construct, a real compass-created scenario doc and a hostile input.
- The port keeps the behaviour of ores.org-js for the constructs the scenarios use.
