* Result

The row that says a run failed says it in one sentence. The engine's long
account, with the reasons it repeats, stays on the instance as the run's output
message, and the reasons are the rows beside it.

A reason that runs past two hundred characters is cut there, so the row stays a
sentence rather than a paragraph.

Proven by the reporting suites: a failure carrying the engine's five-line
account stores "The run's compute job failed with outcome 3: The engine's
analytic failed." and nothing of the lines that follow.
