* Goal

The series page asks for the latest 500 observations. A synthetic tick every two seconds fills that in about seventeen minutes, so the chart shows a narrow slice. The observation list filter has no date range today. Add an observed-since filter to the server, send it from the BFF, and offer a window on the page, such as an hour, a day, a month, a year and all, with the count cap kept as the limit on size.
