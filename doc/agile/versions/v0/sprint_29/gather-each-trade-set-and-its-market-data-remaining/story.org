* Goal

Partition a report's trade population into trade sets and record them against the run, export one trade set as an archive and map it into the ORE portfolio, resolve and export each set's market data at its as-of, hand each configuration to its owner by id at an as-of, and assemble the package only when every declared input is present.

* Acceptance

- The batcher records the sets it created against the run, and a strategy's parameters come from tables rather than the caller.
- One trade set exports as an archive by its batch key and as-of, and the archive maps into the ORE portfolio, failing on a trade it cannot express.
- A trade set's market data requirements resolve to series, observations and fixings read at the set's as-of, and the export is narrowed to them.
- A configuration is fetched from its owner by id and as-of, and the package step runs only when every declared artifact exists, naming the missing ones.
- Each convention kind that names an index or a curve holds an oresmd URI column.
