* Goal

The recorded spot series of every fixing-sourced feed is continuous from its first tick. Provisioning no longer starts the synthetic feeds. The official adapters load the public rates; when a provider's backfill finishes, the synthetic service runs an applied calibration of the feeds that read it, which sets each level and stores each GJR-GARCH input and proposed fit. A person reviews the fits and then starts the feeds, which start from the calibrated level.

* Acceptance

- On a fresh provisioning, no synthetic feed publishes a tick before a person starts it.
- When an official backfill finishes, an applied calibration runs once for the feeds whose items it serves, under system.calibration, and a second backfill of the same data changes nothing.
- A feed started after that calibration records a start from its fixing, and its first stored spot is within the feed's spread of that fixing.
- The calibration workflow note and the provisioning documentation state the order: load the public rates, calibrate, review, start.
