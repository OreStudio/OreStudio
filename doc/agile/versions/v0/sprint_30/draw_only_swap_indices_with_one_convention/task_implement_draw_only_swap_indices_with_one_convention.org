* Acceptance

- refdata.conventions is a system DQ dataset with its own methodology, built
  from a committed table that names the source of each row.
- ore.conventions, refdata_builtin_index_conventions_populate.sql and
  refdata_overnight_index_conventions_populate.sql are gone, and nothing
  writes an index convention straight into the system tenant.
- The dataset is in the bundles of the system party and of every party, and
  each dataset that names a convention depends on it.
- The gate checks the generated script, ORE's coverage and the generator.
- A fresh environment provisions the system and Acme to completion.

* Plan

(Implementation strategy. Written when work starts; key decisions
are distilled into the parent story's =* Decisions= at close, but the
plan itself stays — it is the historical record of what we did.)


One task, one PR. Its activities:

1. Decommission the hacks of the first attempt: a script that copied the
   system tenant's index conventions into ore.conventions at populate time,
   and a planner filter that hid an index with no definition.
2. Bootstrap the curated table from the three sources once: the ORE examples
   (ore.conventions), the ORE engine (the mined built-in index conventions)
   and the overnight index conventions OreStudio seeded by hand. The
   methodology records each overlap and its decision.
3. Move the generator to =projects/ores.seeder/datasets/conventions/=, read the
   table, register the methodology with the dataset, and rename the dataset
   refdata.conventions everywhere it is named.
4. Add =propose.py=, which compares the table with what ORE holds, for an ORE
   upgrade and for the gate.
5. Declare the dependencies that were missing: the FX volatility blueprints
   and Acme's market documents on the conventions.
6. Fix what provisioning stopped on: an index whose aliases state the same
   terms is one index; a schedule tenor such as 12M or 28D reads; the planner
   draws a swap convention by id, so an index whose conventions state other
   legs builds by the one it drew.
7. Prove it: unit and pgTAP tests, the gate checks, and a fresh environment
   provisioned to completion.
