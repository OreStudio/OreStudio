* Acceptance

- A filter on status, party or reference narrows the list on the server, and the total count reflects the filter.
- A party member cannot widen the result past their own party.

* Plan

The nats entity protocol already defines the filter record, so the work is to declare
the columns and carry the filter up.

- The batch model declares =status= and =party_id= filterable and =external_ref=
  searchable. The generator adds the equals, one-of and search members to the filter
  record, the repository condition and the limits of the service.
- The wire-protocol read takes a =BatchFilter=, and the BFF batch route takes
  =status=, =party= and =find=, each checked before a call goes out.
- The Jobs tab has a finder bar with a search, a status and, for a session that acts
  for more than one party, a party. The choice lives in the address.
