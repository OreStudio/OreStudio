* Plan

The task named five types. Three are containers: a CompositeTrade,
TotalReturnSwap or ContractForDifference books its embedded trades as trades of
their own, joined by a structure, and the plan, the writer and the recorded
export carry no such group yet. That is a unit of its own, now the task
[[id:742F9E67-CDCA-4FA6-BE8B-945C64C27A50][Generate the container trades]]. The equity outperformance
option has no rows of its own: the option row packs its two underlyings into one
name and keeps neither initial price, so it is modelled first, in the task
[[id:B14C4720-D757-4CAA-AD4D-09079CBC4D84][Model and generate the equity outperformance option]].

This task keeps SyntheticCDO and the coverage test. The CDO is cut from the
index its qualifier names, as ORE's sample is, and states no basket: ORE reads
the names from the index's reference data.

* Result

The generator books SyntheticCDO, and generation is held to the builders.

- synthetic_cdo_builder states a tranche on the index the qualifier names: the
  attachment and detachment points, refused unless ordered within zero and one,
  and the premium leg on the CDS convention. The header names the index as an
  internal name, as the reader does. The credit planner books the four standard
  tranches.
- The ORE engine reads and builds the CDO. It raises only the missing index
  reference data, which is market data like the index CDS's, so the test's
  patterns now name ORE's message for it.
- "the generator books every type a builder builds" holds the generated types
  equal to the built types. The trading api test already holds the built types
  against the catalogue's supported ones, so a type given a builder and no
  generator fails, and a planned type with no builder throws when planned.
- The engine test rewrites its known list from the run when the recorded trades
  are updated. It keeps the header and never writes a trade's own error.
- The containers and the outperformance option moved to tasks of their own, as
  the Plan says.

Verified: trading api 4645 cases and synthetic 146 with the ORE engine, all
passing.
