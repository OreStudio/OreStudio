#+title: Read a draft render before applying it
#+description: Read what generate would write before applying it: compass-ng diff --scope prints the rendered change of one model as a unified diff, which a list of paths does not show.
#+type: memory
#+memory_subtype: project
#+level: cross

#+updated: 2026-09-26

Read the rendered output of a draft model before applying the generation, not only the list of paths that would change.

*Why:* Reading the rendered artefacts, rather than the list of paths, is what found a codegen defect that no gate could see: a write record dropped a natural key spelled like a server-owned field, so a create could not say which party's row it wrote. A diff, the drift check and a typecheck all missed it. Generated output is also where a model's mistakes surface: two generator expressions mixed std::string with faker-cxx's std::string_view and only the compiler found them.

*How to apply:* After writing or editing a model, run ./compass.sh diff --scope <model.org> and read the diff it prints, before ./compass.sh generate. It writes nothing. Read the SQL, the protocol header and the write record as you would a hand-written change.
