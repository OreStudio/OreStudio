other, so a suite that writes a soft-FK parent leaves the parent active, and a

* Notes

The defect was found while running the end-to-end provisioning recipes: a
second run of =ores.iam.core.tests= failed with

#+begin_example
ERROR:  duplicate key value violates unique constraint "seed_profiles_code_uniq_idx"
DETAIL:  Key (code)=(CD_profile-2) already exists.
#+end_example

A generated entity's code restarts its sequence in every process, so the
parent a previous run seeded collides with the one this run writes. The suites
affected are the seed profile parameter and step ones in =ores.iam=, and 53
files carry the same seeded-parent pattern across five components.

The reproduction, the capture it came from and the workaround are recorded in
[[id:D42BD56B-584A-4CEF-8257-64AE14850DD9][A generated eventing integration test leaves the parent row it seeds active]].
