* Goal

The design document type was added to the register during this story, with a contract stating its folder, its lifecycle and its required fields. No template was written for it, so the document that established the type was produced by hand-editing a knowledge scaffold. A contract describing something the codegen cannot produce is worse than no contract, because it reads as available. Write the template, then audit the whole register: every type with a contract page should have a template, and every template should have a contract page. Report and close both directions of the mismatch.
