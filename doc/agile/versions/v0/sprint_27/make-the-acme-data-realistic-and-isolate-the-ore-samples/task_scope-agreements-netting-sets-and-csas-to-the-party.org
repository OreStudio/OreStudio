* Goal

A master agreement and its CSA are contracts between one ACME legal entity and
one counterparty. Today the agreement number and the netting set code are
unique per tenant, and the CSA has no party of its own. Two parties cannot
hold the same code, so every party must invent its own, and the ORE samples
bundle cannot install on every party.

Scope all three to the party. Agreement number and netting set code become
unique per party. The CSA gets its own =party_id=. This task comes before the
two bundle tasks, because both depend on it.

* Acceptance

- Two parties can each hold an agreement with the same number and a netting
  set with the same code.
- Agreement number is unique per tenant and party. Netting set code is unique
  per tenant and party.
- The CSA has a =party_id=. It is fixed for life, and it equals the party of
  its netting set. What happens for a netting set that has no party is the
  blocking open question below. Settle it before implementation.
- Every lookup of an agreement or netting set by number or code names the
  party. The DQ publish functions, the alias resolution and the ORE import are
  covered.
- pgTAP covers: the same code under two parties, a CSA whose party differs
  from its set's, and a lookup that names no party. That lookup raises an
  error. It never returns a row chosen from another party.
- A fresh ACME provision passes.

* Plan

1. Search for every lookup of an agreement by number and of a netting set by
   code, in SQL and in C++. List the ones that do not name a party.
2. Change the entity models =ores.refdata.netting_agreement=,
   =ores.refdata.netting_set= and =ores.refdata.csa=, and the DQ staging models
   =ores.dq.netting_agreement=, =ores.dq.netting_set= and =ores.dq.csa=, then
   regenerate the SQL and the C++. Do not edit generated files by hand.
3. Settle the rule for a netting set with no party (see Notes). This blocks
   steps 2 and 4.
4. Update the publish functions, the alias resolution and the ORE import to
   name the party in every lookup.
5. Update pgTAP. Provision ACME.

* Notes

*Blocking open question.* The netting set =party_id= is nullable today. A
party-scoped CSA needs a party. Choose one: make the netting set =party_id=
required, or allow a set with no party and refuse a CSA on it. Settle this
before implementation.
