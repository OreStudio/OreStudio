* Effect

Retired with the Qt client. It emitted the previous and next version
navigation controls on the detail dialog and its controller. That dialog is
gone, so setting or clearing this literal no longer changes generated
behaviour. It stays accepted on entity orgs and on the profiles below as
documentation only.

* Structural consequence

Yes — adds navigation methods/UI elements to the generated detail dialog and controller.
