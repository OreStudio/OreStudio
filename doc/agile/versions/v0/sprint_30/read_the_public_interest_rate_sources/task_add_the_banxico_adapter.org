* Goal

The overnight TIIE de Fondeo is stored as fixings in the system tenant, with its history, read from Banco de Mexico through the SIE API, =www.banxico.org.mx/SieAPIRest/service/v1/series/SF331451=, in JSON, with a free token. The adapter is specialised: it reads Banco de Mexico alone, and it supplies only its fetcher to the shared half of the official adapter.

* Acceptance

- The adapter reads Banco de Mexico alone, and it does not copy the announce, the demand, the backfill or the publish code.
- Banco de Mexico is a supplier in the catalogue, its series maps to the MXN overnight item that this task catalogues, and a session and a feed scoped to that item are seeded in the system tenant.
- A fresh environment stores the history as fixings within minutes of provisioning, and the log names the source and the count it stored.
- Each fixing is the decimal of the published percent, with the credit the source and Banco de Mexico's URL.
- The depth of the history is measured and written into the calibration sources note.
- Unit tests parse a recorded response, and a malformed response gives an error, not a fixing.

* Plan

(Implementation strategy. Written when work starts; key decisions
are distilled into the parent story's =* Decisions= at close, but the
plan itself stays — it is the historical record of what we did.)

- The SIE API needs a token, so this task also builds the path of a key, the
  first one any adapter needs: =.env= holds it, =compass env configure= keeps
  it, the seed names it as =env:NAME=, and =resolve_secret= reads it when the
  adapter starts. A gate check keeps a key out of every file git would commit.
- The fetcher sends the token as the =token= query parameter, so =redacted=
  masks it. =read_body= and =read_window= put an unmasked address in their
  errors, so they now mask it too.
- The Riksbank key the owner registered goes through the same path, as the
  optional =subscription-key=.
- The item is =oresmd://ir/MXN?type=fixing&index=ibor&name=FTIIE=, the item of
  the =MXN-FTIIE= overnight convention, which the MXN OIS conventions and Acme's
  =MXN1D= curve name. =MXN-TIIE= is the TIIE family whose swaps fix on the 28-day
  rate, so its item is not the TIIE de Fondeo.

* Result

The overnight TIIE de Fondeo is stored as fixings of the =MXN-FTIIE= item in
the system tenant, read from Banco de Mexico's SIE API with a token from
=.env=. A fresh environment stored 275 fixings after provisioning, the last
0.0626 for 2026-11-10. The API holds 5,244 rates from 2006-01-02.

Keys now have one path: =.env=, kept by =compass env configure=; an =env:NAME=
ref in the provider seed; =resolve_secret= when the adapter starts; and the
=no-committed-credentials= gate check. The Riksbank fetcher sends the
registered key and read 275 fixings again, so the capture /Register a
Riksbank API key/ is retired. Errors of a refused read now mask the address.

For the calibration: the synthetic MXN curve is named =MXN-TIIE= with the
family =tiie=, while the public fixing is of =MXN-FTIIE=, the overnight index.
The calibration maps the one to the other.
