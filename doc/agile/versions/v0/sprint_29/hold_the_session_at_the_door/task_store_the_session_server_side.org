* Notes

- The clock is injected, so the expiry cases decide what time it is instead of
  sleeping and hoping. One case had to be rewritten when it proved I had misread my
  own semantics: touching at twenty-nine seconds slides the expiry to fifty-nine, so
  the session is not quiet for thirty seconds. The sliding case is the one that says
  so now.
- The identifier is 256 bits from =std::random_device=, rendered as hex, and the store
  keys on its SHA-256. =key_of= is exposed so a case can assert the identifier never
  appears as a key.
- =rotate= exists for the change of privilege the design names, and a case pins it:
  the old identifier stops working and the session survives.
