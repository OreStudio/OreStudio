* Goal

* Acceptance

- A service's thread count is fixed by configuration and does not grow with its subscriptions.
- Requests, events and durable deliveries have separate bounded queues; a full queue answers busy, drops by policy, or delays redelivery, each under test.
- A worker skips an entry whose deadline has passed.
