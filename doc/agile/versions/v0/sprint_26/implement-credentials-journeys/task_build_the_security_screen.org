* Result

Done 2026-10-01.

=Security= is a route behind the signed-in shell. It reads the account's login
record, the tenant's sessions for the account and the server's password policy,
and changes the password through the route that already existed. The screen is
the accepted prototype's variant B.

Two things the server cannot do yet are stated on the screen rather than hidden:
ending one other sign-in has no operation, so no row offers it; and nothing
writes a session's end time, so the list holds every session the deployment has
created and an old one cannot be told from a live one.

Verification: 334 tests green in three packages (bff 97 in 20 files, web 186 in
17, wire-protocol 51 in 7), typecheck clean, Prettier clean. The screen's copy is
plain English and not in the three locales yet, which the story records as its
own follow-up.
