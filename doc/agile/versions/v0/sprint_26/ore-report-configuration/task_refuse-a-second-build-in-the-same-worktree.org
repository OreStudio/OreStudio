* Result

=compass build= and =compass test run= now take a per-worktree lock,
=build/output/compass-build.lock=, before they wait for a host slot. When
another process of the same worktree holds it, compass prints the holder's pid,
command and start time and exits 1, so a second build is refused at once
instead of taking the other host slot and racing the first in one build tree.
flock releases the lock when the holding process exits, however it exits, and a
repeat call in the same process keeps its lock. Builds in different worktrees
share the host slots as before.

Tests cover taking the lock, refusing a second holder and naming it, freeing
it when the first ends, and keeping it across calls in one process; a live run
of =compass build= against a held lock refused at once.
