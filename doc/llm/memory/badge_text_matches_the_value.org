A badge definition's name is the same word as the value it paints. A tenant type automation gets a badge named Automation, never a friendlier synonym such as Test.

*Why:* The user stated it on 2026-10-02, when the automation tenant type's new badge was named Test: a badge whose words differ from the value makes the reader translate between two vocabularies for one thing.

*How to apply:* When adding or editing a badge in dq_badge_definitions_artefact_populate.sql or dq_badge_system_populate.sql, name it with the value's own name, and give test fixtures the same label.
