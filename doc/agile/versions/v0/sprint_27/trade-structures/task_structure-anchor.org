* Result

=structure= is the immutable anchor of a composed deal: party, counterparty,
kind, an optional template and an optional parent, with no audit tail. The
parent is a database foreign key to the table itself, because the parent is
immutable too, and the insert trigger refuses a leg of a leg and a structure
that is its own parent — one level of nesting, no more.

Six pgTAP cases cover that rule and the two catalogue references.

No build, no ctest and no database run happened on this branch. Validation was
static only, by agreement this session: the hourly build and test on main is
swift curie's. The six pgTAP cases have never been executed. The nesting rule
in particular is proven only by reading the generated trigger, not by running
it, and it is the most likely of this task's claims to be wrong.
