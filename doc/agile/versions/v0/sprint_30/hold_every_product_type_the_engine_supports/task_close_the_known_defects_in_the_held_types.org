* Acceptance

- an inflation swap on a year-on-year leg is stored and roundtrips
- a range bound's leverage exports with the digits the document states

* Plan

The eleven captures fell into three groups. This task does the first; the
other two are their own tasks, [[id:E7E74289-0E3C-4C1C-9AA3-2CFC8D852BF2][Book every held trade type whole]] and
[[id:CD45F3CE-AD94-4259-891A-E10B5340C1C6][Type the trade vocabularies and check convention parts]], because the merge
guard holds one PR to one closed task.

1. *Representation.* The facts a held type loses or fails to check.
   - Callable bond call terms. ORE resolves each call term list (style,
     price, price type, accrual) to one value per call date
     (=buildCallabilityData=, callablebond.cpp lines 44-87). The call date
     row holds the four resolved values. The writer states a term once
     when it is the same on every date, and once per date when it changes.
   - Year-on-year inflation swap. The leg block already reads and writes a
     YY leg. The swap's fact took its index and lag from a CPI leg only, so
     the table refused a YY swap. The reader now takes them from a YY leg.
   - Leverage digits. The record binding now reads =Leverage= as a decimal,
     so the capture's defect is gone. A test proves 1.05 exports as 1.05.
   - Barrier direction. The barrier type row states its direction (Up,
     Down or none). The FX barrier option's insert trigger reads it in
     place of the two hard-coded style lists.
   - Swap leg index. The leg type row states the index family it observes.
     The swap leg's insert trigger refuses an address of another family,
     and an IBOR name that did not read as an address and is not in the
     floating index table.
2. *Booking.* =book_trade= writes the bond remainder, so the import books
   a bond through it as it books every other family. That deletes the
   import's field-by-field bond requests, which is where the dropped
   fields and the missing audit live. The import writes a parent and its
   embedded trades as one unit. A child array of the wrong family is
   refused by name. The export-and-rebook round trip runs for every
   family.
3. *Conventions and vocabularies.* A family put refuses a write that
   breaks a part's cardinality. The trade key fields that are still free
   text get their lookup.

* Result

Shipped in PR #4766.

- A callable bond's call date row holds the call's style, price, price type
  and accrual flag, resolved per date the way ORE resolves them. The writer
  states them rather than stand-ins, and a price that is not positive is
  refused by name. The builder and the generator state per-call terms, and
  the re-recorded callable bonds pass the ORE engine test.
- An inflation swap on a YY leg reads its index and lag from the leg, so the
  table stores it, and it roundtrips through the document.
- A leverage keeps the digits the document states; the binding already did,
  and a test now proves it.
- A swap leg's index is checked against the index family its leg type states,
  and an FX barrier's levels against the direction its style's row states.

Acceptance met for the five representation captures. The booking and
vocabulary captures moved to their own tasks. A callable bond's =PutData= and
a rule-based call schedule are still unread; the story's close-out holds them.
