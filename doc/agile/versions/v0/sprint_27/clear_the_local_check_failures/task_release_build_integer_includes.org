* Acceptance

- The release-preset build compiles the four affected headers.

* Plan

Both the domain class template and the operation protocol template take
their system includes from the model's =includes= block, so a self-contained
header depends on the model declaring every header its fields need. Audit
every =projects/*/modeling/*.org= that names an integer =:cpp_type:= and has
an =includes= block; add =<cstdint>= where it is missing; regenerate the
affected components. The debug include graph had supplied the type
transitively, so only the release build saw it.
