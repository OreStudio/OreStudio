* Acceptance

- The generated handler, service and repository carry the list request's as_of through to the query.
- With as_of, the list and its total use valid_from <= as_of < valid_to; without it, the current rows as today.
- The four refdata entities that set the flag honour it, and a test proves a past instant returns the old version of a row.
- Codegen drift is clean for every component the change regenerates.
