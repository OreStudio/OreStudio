* Goal

Audit application.cpp, host.cpp, config/options and config/parser across all services and CLI/shell/compute-wrapper tools for duplicated and divergent boilerplate (prompted by ores.cli's std::optional-wrapped database_options tripping up a mechanical pool_size edit). Extract common logic into shared ores.database/ores.service utilities, bring identical files under codegen where they are not already, and collapse remaining differences into a small set of variability switches on the component-service archetype rather than ad-hoc hand-written divergence.
