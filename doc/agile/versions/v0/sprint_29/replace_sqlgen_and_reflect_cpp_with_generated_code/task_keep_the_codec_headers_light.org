* Notes

** The premise did not hold in a real build

The numbers this task was filed on came from a file that included one header
and nothing else. A real unit compiles 16 sources against a precompiled
header, and every codec library precompiles =ores.utility/rfl/reflectors.hpp=,
which already includes =decimal.hpp=, =boost/asio/ip/address.hpp=,
=boost/lexical_cast.hpp=, =uuid_io.hpp=, =<format>= and =<chrono>=: the set
this task meant to move out of =text_form.hpp=. Inside a real unit
=text_form.hpp= costs 0.077s, so splitting it would save about 5 CPU seconds
over the whole build. The backend is 72% of the unit.

** Where the lever is

The weight returns when reflect-cpp goes, because its precompiled header goes
with it. The fix then is a codec precompiled header holding
=struct_codec.hpp= in place of =ores.rfl.pch=, which makes the codec headers
nearly free in every unit with no split of declarations from definitions.
That is now part of the acceptance of [[id:7A1D09B8-B3F2-4E02-9669-3C2F6CC2C6EC][Remove reflect-cpp]].
