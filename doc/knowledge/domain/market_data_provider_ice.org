* Summary

ICE Data Services publishes pricing and reference data through its Consolidated Feed and other feeds. Its own symbology is based on exchange tickers. We record the ICE symbol and the field as ICE names them. The public documents give less detail than for Bloomberg or LSEG, so this page says what is decided and what the mapping inventory must settle.

* Detail

** The id scheme

The scheme code is =ice_symbol=. The Consolidated Feed uses its own symbology, based on exchange tickers. The feed also accepts other identifiers: RIC, CUSIP, ISIN, SEDOL and Bloomberg ticker. A catalogue row uses the ICE symbol. If a row needs an alternative identifier, it has its own scheme code such as =isin=, so a row never mixes two notations.

** The fields

ICE gives each reference value in a normalised form and in the native exchange form. Instrument status and market phase use one value set. ICE system times are in UTC and the native exchange times keep the exchange time zone. A client can ask for a subset of fields. We store the field name that ICE uses and take the normalised form first.

*Not yet decided:* the list of pricing fields we map. The mapping inventory task sets it.

** On the wire

An adapter of this provider sends the tick fields below. See [[id:97208391-AE4B-4032-9744-8F8B228FD567][The adapter subjects]] for the subject.

| Tick field | Example |
|------------+---------|
| id scheme | =ice_symbol= |
| external id | =(an ICE symbol)= |
| field | =(an ICE field name)= |
| value | =(decimal text)= (decimal text) |

The ingress subject token for the id is =(the encoded symbol)=. The service never decodes the token. It reads the id from the payload.

** The mapping

An ICE vendor instrument maps to an oresmd item in the same way as any other. ICE is strongest in fixed income and in exchange data, so its first mappings are bond and futures items. The rows are not written yet.

** Minted ids

The same rule applies. A minted ICE symbol has the form of an ICE symbol, and the deviation note says why.

** What the simulator does

The simulated ICE source publishes ticks with =ice_symbol=, a symbol and a field. It does not speak any ICE feed protocol.
