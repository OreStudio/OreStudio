* Goal

A request that declares a body larger than the server ceiling gets a closed
connection and no response. Beast compares the declared length with the parser's
own body limit as the headers finish, and that limit stood at the ceiling. So a
silent close replaced the refusal this story exists to add, on the one path no
test covered. The headers must be read under no body limit. The route's limit must
govern the body alone.

* Acceptance

- A body that declares more than the server ceiling is answered 413, not a closed
  connection.
- A route that states a limit below the ceiling refuses a body past its own limit.
- A route that states a limit above the ceiling is capped by the ceiling.
- A body past a megabyte is still accepted on a route that states the room for it,
  so the header read imposes no limit of its own.
- The test client reports no answer as no answer, not as the default status 200.
- The =ores.http.api= suite passes.

* Plan

1. Trace the limit the session computes into a file for the investigation, then
   remove the trace, because a request that is never answered reads as status 200
   on a default-constructed response.
2. Find that Beast reports =body_limit= from =finish_header= while the headers are
   read, so the declared length is compared with the parser's limit before any
   route is resolved.
3. Read the headers under no body limit, and set the route's limit on the body
   alone, where the declared-size check and the chunked read both apply it.
4. Return no response from the test client when none arrives, so a silent close
   cannot read as a success.
5. Test the route's own limit, the ceiling over a stated route limit, and a body
   past a megabyte on a route that states the room for it.

* Result

The session reads the request headers under no body limit, resolves the route, and
applies the route's limit capped by the server ceiling to the body alone. A body
that declares more than the ceiling gets 413 instead of a closed connection. A
route that states less than the ceiling refuses past its own limit, and a body past
a megabyte still arrives on a route that states the room for it. The test client
returns nothing when the server answers nothing, so a silent close can no longer
pass as status 200.

The ceiling case posts a body that is inside the route's stated limit and past the
ceiling, so the clamp is the only thing that can refuse it. Deleting the clamp
fails the case.
