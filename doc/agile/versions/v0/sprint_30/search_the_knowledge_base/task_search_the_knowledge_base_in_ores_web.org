* Goal

A person types a few words into a search bar in ores.web and sees the matching pages, best first, each with its title, description and the section that matched. Opening one shows the page, rendered from its org text with @ores/org: a link to another knowledge page opens that page, and each heading has an anchor a result can point at.

* Acceptance

- The search bar answers as the person types, and a result opens its page at the section that matched.
- A link between knowledge pages opens the linked page in ores.web.
- The page view renders org through @ores/org's sanitised HTML and nothing else.
