* Summary

=ores.storage.api= is the part a consumer is allowed to link. It holds the
bucket and key path and URL helpers that turn a bucket, a key and an endpoint
into an address, and the modelled operation surface that both interfaces are
generated from. It holds no bucket name of its own.

* Entry points

- =include/ores.storage.api/net/storage_paths.hpp= — bucket and key to path and URL.
- =include/ores.storage.api/messaging/= — the generated protocol messages.

* Inputs

- A bucket name, an object key and an endpoint, from the caller.
- The generated protocol messages, once the operation surface is modelled.

* Outputs

- The =/api/v1/storage/{bucket}/{key}= path, and its absolute URL against a base.

* Dependencies

- None beyond the standard library. The part is header-only, so a consumer
  linking it takes on no socket, no archive library and no logging.
