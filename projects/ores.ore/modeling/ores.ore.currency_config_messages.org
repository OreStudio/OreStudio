#+title: ores.ore.currency_config_messages
#+description: Codegen operation model for the ORE currency configuration's exchange: the export that writes currencyconfig.xml, the preview that says what a file would change, and the import that writes it with the person's choices. Rendered to C++ and TypeScript from one source.

#+brief: Export, preview and import the ORE currency configuration.
#+filetags: :model:operation:ore:
#+created: 2026-10-25
#+updated: 2026-10-25

The currency configuration is the ORE document =currencyconfig.xml=, whose root
element is =CurrencyConfig=. These three operations are the first triple of
the record screen standard's Import and Export pair: =export_<document>=
returns the document as a file, =preview_<document>_import= parses a file and
says what the import would do, and =import_<document>= writes with the
person's choices. The ORE service reads and writes the currencies through
refdata's own messages, under the caller's delegated session, and never
touches refdata's tables. The pair's screen is the currencies list.

* Physical space

The shell commands are switched off for the same reason as the ORE import's: the
component has no part under =projects/ores.shell=.
