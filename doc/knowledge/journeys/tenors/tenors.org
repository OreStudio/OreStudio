A tenor is two things at once. It is a code a person reads, "3M" or "1Y1Y", and
it is a resolution the system computes from that code: a unit, an anchor, a
schedule and an algorithm, ending in a date on a named calendar. A screen that
shows only the code hides the half that decides what a trade pays.

Tenors are shared by everything that has a term, so this group holds the tenor
machinery itself rather than the conventions that name it. The short code lists
that classify tenors are kept with the other classification lists.
