* Goal

The node sample carries the count of failed tasks and the longest task the
node ran: =tasks_failed= and =max_task_duration_ms=. The reply's per-node
summary, =node_stats_summary=, carries neither, so both fields are stored and
dropped on the way out — and a node failing every task reads as a node doing
nothing
([[id:8C1D6E61-3661-49F2-90BB-00ED7C4F113C][The node summary drops the failure fields]]).
This task carries both fields into =node_stats_summary=, so the node row
states the failures beside the completions.

* Acceptance

- =node_stats_summary= carries =tasks_failed= (int, default 0) and
  =max_task_duration_ms= (std::int64_t, default 0), each documented for what
  the summary states rather than for what the sample stores.
- =get_grid_stats= fills both fields on every node summary from the node's
  most recent sample, so the reply never drops them.
- The shell's =compute grid-stats= node table prints both fields beside the
  completions, and the table's header row names both columns.
- The capture [[id:8C1D6E61-3661-49F2-90BB-00ED7C4F113C][The node summary drops the failure fields]]
  moves out of the inbox with this task's evidence.

* Plan

- Add =tasks_failed= and =max_task_duration_ms= to =node_stats_summary= in
  the telemetry model and regenerate the =compute-cpp= component.
- Fill both in =get_grid_stats= from each node's newest sample.
- Print both in the shell's =compute grid-stats= node table and name them in
  its header row.
- No handler unit test: the class is header-only with an injected NATS client
  and inline repositories, so the mapping has no seam. Verify it on the live
  fleet instead, and write plainly in the Result what stays unproven.

What is not tested: the handler has no automated test. It is header-only, holds
an injected NATS client and a database context, constructs its repositories
inline, and replies over NATS, so no test can call the mapping without a live
broker and database. A model test would only assert that the generated struct
declares the fields, which would still pass if =get_grid_stats= dropped both
assignments, so none was added. The live read above is the proof; a future edit
that removes the two assignments would fail no automated test.
