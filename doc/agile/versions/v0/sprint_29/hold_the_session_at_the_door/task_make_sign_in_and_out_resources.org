* Notes

- =me= and signing out are proven without IAM, because neither needs it: =me= reads
  the claims the session already resolved, and signing out closes a session the test
  opened. Both are cases in =ores.http.iam.tests=.
- Signing in has a case of its own, and it has not run: it signs in against the
  running fleet with the demo account the checkout's =.env= names, and the fleet is
  stopped. With no fleet it skips rather than passes or fails, so the suite is honest
  either way and the round trip stays the outstanding item the state row names.
- To run it: =compass services start= (which asks for =db recreate= when the schema
  moved), then =./ores.http.iam.tests "[live]"= from the preset's =publish/bin= with
  the environment file loaded.
- The cookie's name comes from =--web-session-name= and its =Secure= from the
  deployment's TLS flag, so one deployment cannot read another's session.
