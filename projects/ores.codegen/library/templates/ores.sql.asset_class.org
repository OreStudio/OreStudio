* Summary

One template projecting the /asset-class catalogue/ onto the seed SQL that
used to be hand-written: the refdata product taxonomy, one row per class,
with the prose the seed carried on each row. The catalogue model declares
the taxonomy, the oresmd namespace and the mapping between them; this
facet renders the taxonomy. The DQ badge rows and the briefs are separate
archetypes of the same model.

* The ores.sql.asset_class facet

Driven by the /asset-class catalogue/ model — a =taxonomy= list carrying
=code=, =name=, =display_order= and the class's prose, plus a =namespace=
list of the oresmd authorities and the class each maps onto — rather than
by an entity. The generated script replaces the hand-written
=refdata_asset_class_codes_populate.sql=, so the taxonomy has one author.
