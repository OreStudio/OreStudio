A system administrator opens one tenant and reads its parties. Every other party
read answers the parties of the caller's own tenant, and a system
administrator's tenant is the system tenant, so none of them answers "the
parties of tenant X". This read names the tenant. It is served only to a caller
in the system tenant, and it reads with a context scoped to the named tenant,
so the party table's own policy admits that tenant's rows and no others.

The entity singular is =tenant_party= because the =parties= shell menu belongs
to the generated party entity unit.
