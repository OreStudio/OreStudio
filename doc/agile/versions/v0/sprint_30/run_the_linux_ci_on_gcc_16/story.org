* Decisions

- The compiler comes from the Ubuntu toolchain PPA rather than from a newer
  base image. =g++-16= exists only in Ubuntu 26.04 and later, so bumping
  =UBUNTU_VERSION= would also move the PostgreSQL and LLVM repositories to a
  codename those projects may not serve yet. The PPA carries =g++-16= for the
  current LTS, so the base image stays.
- =gcc= and =g++= point at the versioned pair through =/usr/local/bin=, which
  comes first on PATH. The gcc preset names =g++= rather than a versioned
  binary, and this is the same technique =install_llvm.sh= already uses to put
  clang first.

* Out of scope

- The compiler versions of the macOS and Windows builds.
- Re-enabling =ORES_WARNINGS_AS_ERRORS=, which needs the warnings cleared on
  every platform.
