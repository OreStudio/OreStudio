* Acceptance

- A generator config carries a calibration entry: a source code (ecb.eurofxref, fed.h10, ust.par_yield or an overnight rate), an as-of date and a window for the volatility.
- A table of daily rates holds each rate with its source, provider key, pair or series, as-of date and time of retrieval. A day is asked for once: a feed looks in the table first, reuses a rate that is there, and otherwise fetches, stores and reuses it.
- The date to read comes from one clock that the feeds check. Until the system clock of the capture exists, the host clock gives the date.
- A retrieval step, separate from the simulator, reads the latest day on or before that date, and keeps the last stored day when the source cannot be reached.
- The feed screen shows the time of retrieval and the as-of date. A pair that no source covers keeps a fixed level and says so.
- No value of a source is stored until its terms page is read and recorded on the sources page. The page lists the sources whose terms are not read, and that list is empty when the task closes. The credit or notice each source asks for is kept, and a value is stored as published.
- The 2016 ORE vintage calibrates no generator.
