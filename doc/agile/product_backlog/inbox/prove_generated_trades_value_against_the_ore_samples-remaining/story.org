* Acceptance

- The roundtrip tests read every ORE sample trade of each product type the
  generator books, write it back, and fail on any element ORE needs that we drop
  or rename. The cause of each gap the run below found is stated.
- The generator's output for each product type is compared with the ORE sample of
  that type, and the comparison fails on a missing or empty element ORE needs.
- A run of the Acme portfolio builds every trade the generator books: no trade
  fails to parse or to build for want of a field, a curve or an index name.
- Every FX option type and every bond type that ORE prices has the market data and
  the pricing engine configuration to value it, or is left out of the generator
  with the reason stated.
