This page is a [[id:671F18E4-E09C-4B3B-BD24-D33DF8AE38A6][capture]] in the *inbox* bucket of the product backlog — a pre-sprint idea, not yet pulled into a sprint as a story.

* What

The refdata and IAM lookups carry =display_order= with a default of zero and no uniqueness. Two rows with the same order read in an undefined order. Add a unique index per list, or state a tie-break by code. The web screen sorts by order then code as a stopgap.

* Why

Lists reorder themselves between reads when two rows share an order.
