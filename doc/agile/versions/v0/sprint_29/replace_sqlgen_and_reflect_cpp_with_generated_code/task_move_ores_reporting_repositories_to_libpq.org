The hand-written report_input_bundle entity and repository are ported to the query builder. The pastes of the risk_report_config, report_instance and report_error_event models are ported too, including the three projection structs of risk_report_config, which now state their columns.

main's report_result_row_repository carried a read_by_run that df1f68f11d added to the generated files and not to the model, so a regenerate dropped it. It is now a paste in the model. The regenerate is limited to the repository address: a full regenerate of reporting brings in main's unrelated report_result_row drift (a protocol field renamed from report_result_rows to rows, and new generated files), which belongs to that entity's own change.
