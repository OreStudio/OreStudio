* Effect

Table is system-tenant-scoped: tenant_id defaults to the system tenant and the insert trigger forces it.

* Structural consequence

Yes — changes the =tenant_id= column's default. Mutually exclusive with =nullable_tenant_id=; together they form a single tenant-scoping policy, see [[id:729E44CA-6AB7-4ADB-BA54-B1AD5A12DD27][Codegen entity meta-model — SQL]].
