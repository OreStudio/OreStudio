* Plan

- Opt the 39 marketdata models into the wire codec and regenerate.
- Move the dq publish handler onto the codec, keeping its error message, and
  drop the include-only reflect-cpp uses in the import service, the feed ingest
  loop, the adapter supervisor, the official adapter and the client.

* Notes

** Failures that come from the environment

Two feed ingest cases in =app_feed_ingest_loop_tests.cpp= and the synthetic
case =the adapter announces again until the service answers= fail while this
environment's services run, because a running service answers or consumes on
the subjects the cases use. With the services stopped and only NATS running,
all three pass, and so does the whole marketdata service suite. The three core
failures need =market_*_values= tables from #4364, and the services' start
reports that the database schema does not match this checkout.

* Result

ores.marketdata encodes and decodes without reflect-cpp. Its 39 models use the
generated codec, its dq publish handler reads and writes through it, and no
marketdata source outside the tests includes reflect-cpp. The bytes match
reflect-cpp's.
