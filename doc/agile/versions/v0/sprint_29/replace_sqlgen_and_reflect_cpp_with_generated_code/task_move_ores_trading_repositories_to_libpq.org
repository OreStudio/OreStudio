* Notes

** Hand-written code

The pastes of eleven models are ported by port_paste, and trade_component_queries, parent_scoped_queries and two repository tests by port_hand. The write observer header names the entity keys without .value().

** What else

The query builder's execute_write_query now observes writes as sqlgen's did, in one unit with the write. Two new tests drive it: a component write refreshes its trade's digest, and a component write rolled back with its unit of work leaves the digest. The first failed at first: only trade_economic_digest_writer.cpp included the observer header, so a repository saw the observer specialisation only when a unity batch happened to put it after that file, and otherwise never observed its writes. The 32 observed models now include the header in their repositories.
