#+title: How do I list compute hosts from the shell?

The compute grid verbs live in the shell's =compute= menu. They talk to
the ~ores.compute~ service over NATS; the domain shapes and table
renderers come from ~ores.compute.api~.

* Question

How do I list compute hosts from the shell?

* Answer

Log in as the system super admin (principals are
=username@hostname=), then =compute list-hosts=: the shell prints the
grid nodes as a table — id, external id, display name, location, CPU,
RAM, GPU, last RPC time, credit total, modified by, recorded at. The
table is empty until a host registers with the grid.

#+name: list-compute-hosts
#+begin_src ores-shell :exports none
connect $ORES_NATS_URL
login super_admin@localhost Secure-Password-123
compute list-hosts
logout
exit
#+end_src

#+begin_src sh :noweb yes :results output :wrap example
./ores.shell ${log_args} ${connect_args} << 'EOF'
<<list-compute-hosts>>
EOF
#+end_src
