* Goal

Every shell command dq answers is produced by a generated unit. Two units do not come from dq's own models today. The hand-written lei menu answers the three reads the lei_entity_summary operation model declares, but that model has no shell unit, so a hand-written unit serves what a generated one should. The report_definition entity's unit is withheld because the entity is a staging shim whose plural reporting also models, and the shell resolves a duplicate by registration order. The task generates the operation's unit and retires the hand-written menu, and records the shim.
