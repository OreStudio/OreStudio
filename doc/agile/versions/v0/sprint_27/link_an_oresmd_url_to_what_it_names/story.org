* Goal

An oresmd URL behaves like every other reference in the app. The link goes to the thing it names, a series to its page. A small icon button opens the URL in the dialog, which shows it as labelled values in the layout of the record screens when the screen cannot change it, and as the editor when it can.

* Acceptance

- A series URL and a quote URL are a link to the series page, so they open in a new tab and copy as a link, and a fixing URL, which has no page of its own, is plain text.
- An icon button beside the URL opens the dialog: the code icon for the read-only view and the edit icon where the screen stores the URL.
- The read-only view of the dialog shows the kind, the instrument, the quote, the path and the fields as labels and values in the layout of the record screens, with the codec's URL under them and Copy, and no inputs.
- The IR curve feed and the FX feed screens use the link and the button.

* Decisions

- A click on an oresmd URL goes to the object it names. This is the least astonishing result: a link goes to a thing, a real address opens in a new tab and copies as a link, and the other references of the app work this way. Editing is a different intention, so it is a separate small button. Marco agreed on 2026-10-12.
- The button is an icon, as the record screens draw their actions. The icon reference has the =code= icon, for code and a script, and the file is in the set but not in the web icon table. The read-only view uses it, because the view shows the structure of the URL. A screen that stores the URL uses the =edit= icon.
- The read-only view of the dialog is laid out as the non-edit mode of the record screens: label and value pairs in a grid, and no inputs, so a URL is read the same way everywhere. Marco asked for this on 2026-10-12.
- The object of a series URL is its series. The object of a quote URL is the series of its datum, because a quote is one point of a series and the series has the page. The identity the page needs is the asset, the path as the scope, the instrument, the quote type and the identity fields of the row, which the series list already builds from the same URL. A fixing names no series, so it has no link.
- The link carries the URL in the address, as =uri=, and the Evolution page reads it through the server's parse. The link holds no part of the grammar.

* Out of scope

- A page for a quote or a fixing of its own.
- Writing a URL back from the feed screens. A feed's URL follows from its currencies and its curve.
- Changing the editor's grammar or the server's operations.
