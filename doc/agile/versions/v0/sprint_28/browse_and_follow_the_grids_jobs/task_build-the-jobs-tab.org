* Acceptance

- The tree opens a batch, then a workunit, and reads one page of children at a time.
- The details panel shows the entity's own fields under the model's headers, with state and outcome as badges and references as links.
- The screen shows loading, empty, error and refused states in words, and the filters, open rows and pages live in the URL.
- (Moved) The Outcome filter lands with the task Find a result by its outcome, and the Follow this job link lands with the task Build the job page. Neither read nor page exists yet.
- The tabs are the ones the grid screen has, and the build follows =doc/prototypes/compute/browse-the-grids-jobs/=.

* Plan

Add a sixth tab, Jobs, to the grid screen, and a Jobs tab to the tenant and
party view. One component, =GridJobs.tsx=, holds the tree and the details panel.

- The tree reads one page of batches, and one page of workunits or results for
  each open row, from the six BFF routes. The page size of a child is 5.
- The address holds the batch page and size, the open rows (=open=), the selected
  record (=sel=, as kind:id) and the child pages (=wp.<id>=, =rp.<id>=).
- The details panel reads the selected record by id and draws its fields under
  the model headers. A reference is a link that selects the record it names.
- A refused read says the role cannot read jobs. Any other failure says what
  failed and offers a retry.

* Notes

- The tab does not show the party of a batch in the tree. A session that acts in a
  party has the mode application, so the mode cannot tell a tenant administrator
  from a party member. The details panel shows the party id.
- The dispatch command writes the batch status dispatched, and the model page lists
  four statuses without it. The tab draws a status it does not know as stated.
- A batch moves to the top of the list when its status changes, because the order is
  by the latest change. The first screenshot read jobs-check-b, jobs-check-a and
  jobs-check-c, and c was created last.
- The Follow this job link and the App Version ID link wait for the pages they open.
