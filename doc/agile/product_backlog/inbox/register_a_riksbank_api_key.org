#+title: Register a Riksbank API key
#+description: The Riksbank SWESTR API refused this host's calls for five days with 'Out of call volume quota'; a registered key raises the limit and the adapter needs a way to send it.

This page is a [[id:671F18E4-E09C-4B3B-BD24-D33DF8AE38A6][capture]] in the *inbox* bucket of the product backlog — a pre-sprint idea, not yet pulled into a sprint as a story.

* What

Register an account on the Riksbank API portal, and give the official rates adapter a way to send its key in the =Ocp-Apim-Subscription-Key= header. The key is a secret, so it comes from the environment, not from the seeds.

* Why

On 2026-11-10 the SWESTR API answered this host with =403= and ="Out of call volume quota. Quota will be replenished in 5.01:45:50."=, with =Retry-After: 438358=. A call with the old user agent gave the same answer, so the agent did not cause it. The adapter of this environment polled once an hour. That is 24 calls a day, and the Riksbank FAQ gives 5 calls a minute and 1,000 a day to a caller without a key. The cause of a quota of several days is not known. The development of the adapter on 2026-11-10 also made calls, so a weekly limit is a guess. A registered key gives 200 calls a minute and 30,000 a week.

Until the quota is replenished, the riksbank-swestr feed stores no new SWESTR fixing. The fixings stored before stay.
