* Notes

- The method code is derived from the method and is never typed. The method's row states both forms; the table checks that the class is null exactly for the trade-level method.
- The screen manages keys only. A key's shift sizes, tenors and shift schemes belong to the sensitivity configuration, and its =key= attributes are how a template reaches market keys of any class.
- The seeded 19 keys are the ones ORE's examples use. A tenant may add a key of its own; the table does not hold the key to a spelling, because ORE resolves the key a configuration states.
- The asset class is a soft reference to the reference data asset class codes. The prefix the key carries (*COMM* for commodity) comes from the bridge the screen reads.
