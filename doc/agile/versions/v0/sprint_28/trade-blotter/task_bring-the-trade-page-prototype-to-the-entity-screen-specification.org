against the entity screen specification".

| 1 | The list reads =trading.v1.trade_summaries.list= with =book_id_one_of=, state, counterparty, type, search and =trade_date_from= and =_to=. A date range is drawn. The =server=today= mode keeps =trades.list= with a trade id filter |

| 8 | A tab switches in place and puts its address in the history, so a save and the stale mark stay. Back returns to the earlier tab |
| 9 | The chart draws hour bars up to two days and day bars after, every bucket including the empty ones, and the first and last time. One emblem marks the newest version of each record |

The decisions applied: the page title is the trade code, and a trade history
entry offers no Revert. The specification still lacks a line for which
permission shows each trade tab, and the prototype still draws every tab.

Checked in headless Chrome at =6b0451ee62= plus this change. The nine pages of
the five prototypes load without a console error. Scripted runs of the list, the
edit-then-History flow, the lifecycle workflow, the empty state and the stale
state pass. The scripts are not kept.

=common.js= is identical in all five prototype folders and =prototype.css= got
the same appended rules. The other four prototypes were not reviewed against the
specification. They get the shared =timeline=, header and footer changes only.
