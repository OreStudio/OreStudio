* Goal

Each supported currency has a named public source for its overnight rate, or a stated reason it has none. The public curve sources documented so far are the US Treasury par curve, SOFR, SONIA and the ECB's euro short-term rate; the other currencies' publishers, their access routes and their terms are not yet known.

* Acceptance

- The calibration sources note has one row per currency: overnight index, publisher, access route, history available, terms and whether the terms allow the use.
- The eight currencies of the derived FX pairs are covered first, and each of the other twenty has a row, even where the answer is no source.

* Plan

1. List each currency's synthetic overnight index from the system tenant's IR curve generation configs.
2. For the eight currencies of the derived FX pairs, read each publisher's terms page and probe its data route with a script.
3. For the other twenty, name the index's administrator and mark the route and terms as not read.
4. Check the indices that look ceased or misnamed against the publishers' own statements.
5. Write the table into the calibration sources note, with each page read and when.

* Result

The calibration sources note now has a section, "The overnight rate of each IR currency", with one row for each of the 28 currencies.

- Of the eight currencies of the derived FX pairs, USD, EUR, GBP and CAD are usable now: each has terms that allow our use and a route that answered a script.
- AUD's terms allow the use, but the RBA's server refused a script, so its route is open.
- JPY needs the Bank of Japan's permission for any commercial use.
- CHF's history may be stored, but SIX names yield-curve building as derived data, which needs a SIX Data License even for internal use.
- NZD's terms page and data both refused a script, so both are open.
- The other twenty have a row naming the index's administrator, with the route and terms not read.
- Four feeds quote an index that is not the currency's overnight average: TELBOR for ILS, which ceased after 30 June 2025 and was replaced by SHIR, HIBOR for CNH, the BUBOR overnight quote for HUF, and TAIBOR for TWD. PLN's index is unresolved. The task "Replace the synthetic feeds of ceased or misnamed indices" now covers them with LIBOR.

Not met: the history available from each source was not checked, so the table has no history column. That check moved to "Read the public overnight rates through an adapter", which stores the history.
