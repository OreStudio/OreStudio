Reference data table defining the averaging method a commodity or equity
Asian-style option uses: =Arithmetic= or =Geometric=.

*This set is trading-local by decision, and the divergence from ORE is
deliberate.* ORE states no averaging member and no averaging enumeration
for either family. =commodityAveragePriceOptionData= carries no average
member and =singleUnderlyingAsianOptionData= carries none either; there is
no =averageType= simple type anywhere under =external/ore/xsd/=, and no
=AverageType= element appears under =external/ore/examples/=. The only
=Arithmetic= token in ORE is part of the scripted product names
=EquityAsianOptionArithmeticPrice= and =...ArithmeticStrike=, and ORE never
states =Geometric= at all. The set is therefore the two values the columns
already deploy, and it is not derived from an ORE schema.
