An agent key redeems an [[id:ED9E53BF-27A3-4261-9767-3A25B98BFCA4][agent grant]]: an LLM agent presents it as a
bearer token, and IAM exchanges it for a short token that names the grant's
person and the agent ([[id:1162906F-BB72-486E-9A11-30D567C65F3E][Delegation tokens for LLM agents: subject and actor claims]]). The key is shown once, when it is made, and is
=ores_ak_<tenant id>_<key id>_<secret>=. Only its id, which finds it, and the
SHA-256 hash of its secret, which checks it, are stored. A grant may have
several keys, so a key can be replaced before the old one is revoked.

The table is readable over the wire and written only by IAM's own operations:
=:client_read_only:= removes the generic write verbs from the wire.

The SHA-256 hash of the key's secret, in hexadecimal. A fast hash suffices
because the secret is 256 random bits, not a password a person chose.
