* Quote types

The class carries no currency, no tenor and no point: the entity is the security
and the metric is the whole qualifier. ORE writes the metric as the second
segment, so each metric is its own quote type here -- the class has no other
dimension to tell them apart, and the `metric` query key is one of the IR-only
keys every other class rejects.

| enum_name | ore_type | ore_constant | ore_metric | point_semantics | qualifier_shape | comment |
|-----------+----------+--------------+------------+-----------------+-----------------+---------|
| bond_price | BOND | bond | PRICE | scalar | no_ccy | BOND/PRICE (bond clean price). |
| bond_yield_spread | BOND | bond | YIELD_SPREAD | scalar | no_ccy | BOND/YIELD_SPREAD (bond yield spread). |
| bond_conversion_factor | BOND | bond | CONVERSION_FACTOR | scalar | no_ccy | BOND/CONVERSION_FACTOR (bond futures conversion factor). |
| recovery_rate | RECOVERY_RATE | recovery_rate | RATE | scalar | no_ccy | RECOVERY_RATE/RATE (recovery assumption named by a security rather than by an entity and a seniority). |
| cpr | CPR | cpr | RATE | scalar | no_ccy | CPR/RATE (conditional prepayment rate). The corpus keys it by ISIN, inside `<Security>` blocks in curveconfig.xml, so it belongs to this class rather than to commodity, which carried it as a simplification while no security-level identifier existed. |

* Enum brief

The `quote` query key for security instruments. Security-only; only meaningful
when `type=quote`.

* Identifier brief

A fully-resolved oresmd identifier for a security (asset_class=security).

* Requirement brief

A logical, possibly-partial oresmd requirement for a security instrument.
