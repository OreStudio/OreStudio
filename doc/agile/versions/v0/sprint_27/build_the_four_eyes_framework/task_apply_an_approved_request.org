* Acceptance

- The last approval starts an apply workflow whose steps re-check, apply every line in one transaction, marking each applied once, and tell the maker.
- A refusal at apply moves the request to apply_failed with the line and reason and ends the run as failed.
- An infrastructure failure or missed deadline stops the run, and the retry verb resumes it until the kind's window ends, then the request moves to apply_failed.
- The run shows on the workflow screens.
- apply_failed is final, and a new request needs every part to approve again.
