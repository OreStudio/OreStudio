* Result


=Audit: sign-ins= reads the five panels the journey names off one filter bar,
with Refresh as the only page action. An open session carries *End session*,
which calls =iam.v1.ops.end_session= and re-reads. The session-activity panel
states that its data is not available, because nothing writes a session
sample row yet.

The browser reaches the BFF rather than the domain services, so the three
missing reads also needed BFF routes and wire-protocol reads: =GET
/api/auth-events=, =GET /api/session-statistics=, =POST
/api/sessions/:sessionId/end= and =GET /api/geo/country=.

Verification: =npm run typecheck= in wire-protocol, bff and web passes;
=vitest= passes 432 web, 305 bff and 159 wire-protocol tests; prettier is
clean. No browser screenshot was taken, so the prototype match is by markup
and tests.
