* Result

stage-runtime.sh now strips every staged binary and library with
strip --strip-all, and skips the files that are not object files (the build
manifest sits in bin/). The previous strip --strip-debug command failed on
that manifest, and its error was discarded, so the files were never stripped:
the staged libraries were 841 MB. With --strip-all they are 625 MB and the
library image is 667 MB instead of 895 MB. A failed strip now aborts the
staging instead of shipping unstripped files.
