* Acceptance

- ORE's construction and pricing needs are recorded per generated trade type, from ORE's own code.
- A required term a builder is not given does not compile or names itself, and every generated type is built by its builder.
- ORE builds every generated trade: no trade fails to parse or build for want of a field, a curve or an index name.
- Every generated type has the market data and pricing engine configuration to value it, or is left out of the generator with the reason stated.
- A report over every generated type completes, and each type matches ORE's own NPV within a stated tolerance, within 0.01% of the reference NPV, or 0.0001% of notional if larger.
- A test fails when the trade XML, the generated data or a value drifts from ORE.
