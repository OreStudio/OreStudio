One step of a swap leg's amortization schedule, keyed to the leg and the
step's ordinal.

ORE states a leg's amortization on =LegData/Amortizations= as a list of
=AmortizationData= blocks. A block is a rule, not an amount: it states how
the notional amortizes (=Type=), by how much (=Value=), over which window
(=StartDate= and =EndDate=), how often (=Frequency=) and whether the notional
may fall below zero (=Underflow=). ORE derives the notional schedule from the
rules, so the rules are what the document states and what this row keeps.

The type is required and the other five members are optional, so the type
is not null here and the rest are nullable.

The row is a child of the leg rather than an entity with a life of its own:
=swap_leg= names the trade and the ordinal, and this row adds its own ordinal
within that leg. The bond legs keep the same block in =bond_leg_amortization=.

** Custom repository methods

The trade read path fetches the amortizations of many instruments' legs at
once, and no generated read covers that: the generated reads address one key
group at a time. The batch read below is one statement over the instrument
set.

*** read_by_instruments_batch
:PROPERTIES:
:ID: 795336D7-EBE4-4F03-AD7A-AD83EF9497BC
:END:

Reads every current amortization step of the given instruments' legs,
ordered by instrument, leg and sequence, in one statement. An empty input
reads nothing.

#+begin_src cpp :name implementation :implements F2EB1914-5E94-42CA-9C77-46BDB364BF9E
std::vector<domain::swap_leg_amortization>
swap_leg_amortization_repository::read_by_instruments_batch(
    context ctx, const std::vector<std::string>& trade_ids) {
    if (trade_ids.empty())
        return {};
    static constexpr auto max = db_timestamp::max();
    const auto tid = ctx.tenant_id().to_string();
    const auto query = query_builder::read<std::vector<swap_leg_amortization_entity>> |
                       query_builder::where("tenant_id"_c == tid &&
                             "trade_id"_c.in(trade_ids) && "valid_to"_c == max) |
                       query_builder::order_by("trade_id"_c, "leg_number"_c, "sequence_number"_c);
    return query_builder::execute_read_query<swap_leg_amortization_entity,
                                             domain::swap_leg_amortization>(
        ctx,
        query,
        [](const auto& entities) { return swap_leg_amortization_mapper::map(entities); },
        lg(),
        "Reading swap leg amortizations for multiple instruments.");
}
