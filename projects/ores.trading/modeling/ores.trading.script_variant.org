One variant of a library script. Every script has a default variant, and
a few add one for another purpose, such as a finite-difference engine. The
variant holds the payoff code and the variable the NPV is read from.

** purpose
:PROPERTIES:
:type:        text
:cpp_type:    std::string
:primary_key: true
:nullable:    false
:economic: false
:END:

The purpose the variant serves: =default= for the one a trade runs unless the engine asks for another, else ORE's =purpose= attribute, such as =FD=.

std::string("default")
#+end_src
