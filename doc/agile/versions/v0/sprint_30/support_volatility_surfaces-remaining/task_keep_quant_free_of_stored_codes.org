* Goal

Quant holds only its own types: enums and small value types its engines need, testable with no other component. Today it also holds fifteen functions that translate refdata's stored spellings, such as ModifiedFollowing or DEPOSIT, into its enums and back. Their callers are all mappers in refdata.core and the market data service. The component that owns a record owns its mapping into quant, so these move into refdata.core, and the market data service calls them instead of parsing codes itself. The FX option convention, which the surface calibration needs, gets one mapper there too, and the synthetic source's private copy goes.

* Acceptance

- Quant declares no function that reads or writes a stored code, and its engine headers name only enums.
- refdata.core holds the code mappers in one unit with one error style, and every former caller uses it.
- A round-trip test reads and writes every value of every enum, so a new value without a spelling fails.
- One mapper reads an fx_option_convention row into quant's fx_quote_convention, choosing the long-term types at or past the switch tenor by comparing periods, and the synthetic source uses it.
- Behaviour does not change: the quant, refdata, market data and synthetic tests pass.

* Result

Done on 2026-11-10. Quant declares no function that reads or writes a stored code. The fifteen functions moved into =ores.refdata.core/mapping/quant_codes=, each code spelled once in an explicit table, so a quant enum no longer has to match a stored spelling for magic_enum. The five callers in refdata.core and the market data service use it, and refdata.core now links quant publicly because the mapping headers hand quant's types to their callers. Quant gained =domain::compare_periods=, which orders periods as QuantLib does. =ores.refdata.core/mapping/fx_option_convention_mapping= reads a tenor's text and an =fx_option_convention= row into quant's =fx_quote_convention=, and the synthetic source calls it in place of its own copy.

Tests: quant 619 cases, refdata.core 545 cases with the database, synthetic API 861, market data service 231 and synthetic service 78, all passing. The market data and synthetic service suites pass only with the services stopped, because their NATS tests share the services' subject prefix; that defect is the capture NATS tests share the running services' subject prefix. The string process type of quant's process factory is the capture Quant's process factory takes a string process type.
