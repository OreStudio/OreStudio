* Result

The tenant administrator's home has the system home's shape: the tenant's name with one status beside it, three tabs held in the address (Dashboard, Active modules, Upcoming modules), and a dashboard of panels that share the Panel, Metric tile and footer code with the system home, which moved into DashboardParts. The panels are People (accounts, locked accounts, password resets due), Sign-ins (signed in now, accounts with failed sign-ins), Access requests (waiting, answered; only for a person who may assign roles) and Parties (how many, with a way to add one). A panel that is fine shows a check beside its title, and one that needs the person says why in the same words. The top status counts the panels that need the person, and says Everything is running only when none needs them and none is still being read. Every figure comes from a read that exists; the locked, failed and password-reset counts come from the login records, which the sign-ins screen already reads, and share its cache keys. The Active modules tab holds the cards the home had, and the Upcoming modules tab holds Market data, Trading and Reporting. The failed sign-in rule is any account with failed attempts since its last good sign-in. The tenant home moved into its own file. The web package passes 712 tests and the format check. I did not look at the home in a browser.
