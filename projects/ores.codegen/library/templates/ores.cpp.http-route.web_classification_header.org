The header of one code list's classification routes. The classification screen
names a list by a key in the address, such as
=/api/classifications/monetary-nature=, reads every row with its label, and
creates, corrects, reorders, removes and labels rows. This unit answers those
addresses on the C++ server for one list.

The unit renders only for a model that states =#+web_classification:=. The
output path names ={web_classification_entity}=, which resolves only for such a
model.
