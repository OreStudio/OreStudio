* Goal

The pr.yml workflow still runs site, roundtrip, cmake-sources-drift, and codegen-drift on every PR, gating every merge even though the submit-PR skills now run these checks locally. Delete those jobs from the PR gate: pr.yml keeps only classify (the path classifier) and pr-gate (the required check that aggregates it). Branch protection keeps pr-gate as the single required check. The site job's CTestSite CDash submission also goes, since experimental submissions now happen locally via compass test run --cdash Experimental.
