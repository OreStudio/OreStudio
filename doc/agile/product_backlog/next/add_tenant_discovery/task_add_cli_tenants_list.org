* Goal

The =ores.shell= already carries a =tenants= resource whose verbs live
in =doc/recipes/shell/tenants/=. The discovery command is:

#+begin_example
tenants list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

…addressed at =iam.v1.tenants.list=. It returns the active tenants from
the IAM domain over NATS, showing =code=, =name=, and =tenant_id= (the
UUID developers need for =ORES_TENANT=).

This task re-points the discovery half from the retired =ores.cli= to
the shell and confirms the existing verb meets the story's need; no new
verb has to be written.

* Notes

Tenant table: =ores_iam_tenants_tbl=

Relevant columns:
| Column      | Type | Notes                                            |
|-------------+------+--------------------------------------------------|
| =tenant_id= | uuid | The UUID required for =ORES_TENANT= / =--tenant= |
| =code=      | text | Short code, e.g. =barclays=, =acme=             |
| =name=      | text | Display name                                     |
| =valid_to=  | timestamptz | =ores_utility_infinity_timestamp_fn()= = active |

Active-tenant SQL (confirmed working):
#+begin_src sql
SELECT code, name, tenant_id
FROM ores_iam_tenants_tbl
WHERE valid_to = ores_utility_infinity_timestamp_fn()
ORDER BY code;
#+end_src
