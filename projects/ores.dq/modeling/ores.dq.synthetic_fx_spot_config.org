Synthetic FX Spot Config artefacts - denormalized parent+child FX generation config rows for the synthetic market data bundle. Each row is a complete FX config combining the parent market_data_generation_config fields (name, description, enabled) with the FX spot sub-config fields (currency pair, initial price, tick cadence, process type).

* Notes

Bound to [[id:5D3A6D13-73E0-41A5-9E08-0C8C11BD609E][Artefact staging only]] (alongside its shape profile): this
artefact type's own row in =ores_dq_artefact_types_tbl=
(=synthetic_theme=, covering =synthetic_fx_spot_configs= among its
sibling asset-class tables) publishes to =target_table:
synthetic_market_data_generation_configs_tbl= -- the authoritative
production table is owned by =ores.synthetic=, not =ores.dq=. This
model exists to describe the DQ import/staging shape only; a
=ores.dq=-owned main table would be a wrongly-owned duplicate.

No Qt UI: this is a DQ-side staging view onto data that isn't
authoritative here (see above) -- an editable window in =ores.dq= would
be a second, confusing, edit-capable copy of import data whose real home
is =ores.synthetic=. See the Physical space table below.
