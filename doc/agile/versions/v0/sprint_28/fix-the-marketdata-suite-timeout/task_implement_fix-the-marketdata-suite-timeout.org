* Result

The marketdata core suite now has a 3600 s timeout and runs alone. The suite took
307 s, then 480 s, in CI, and passed 600 s in the debug job, so ctest killed it.
A regeneration had dropped the earlier =RUN_SERIAL= setting. Both properties
now come from the =extra_test_dependencies= block of the component model, set
through =cmake_language(DEFER)=. The suite passes locally in 633 s.
