The system administrator's roster reads the tenants a deployment holds through
this search. The generated tenant list pages the registry and nothing more; the
roster also searches, filters by type and status, and leaves out the system
tenant, which is the deployment's own bookkeeping rather than a tenant somebody
set up. The rule lives on the server, beside the registry, so every reader of
the roster gets it.

The entity singular is =tenant_roster= because the =tenants= shell menu belongs
to the generated tenant entity unit.
