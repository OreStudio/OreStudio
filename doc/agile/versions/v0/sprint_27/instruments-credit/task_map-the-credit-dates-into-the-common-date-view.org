* Notes

- Unit 5 already declared the dates and generated the eventing tests, so this
  unit adds the proof only.
- The credit view has no expiry. An index option's expiry is its first exercise
  date, which is a row of the shared schedule tables, not a column of the option
  row, so the view leaves =expiry_date= null for the family. A later task can map
  it when the option child holds one expiry column.
- The probe gives its rows the =probe= audit name and reads only those, because
  the suites leave committed credit rows in the database.
