* Plan

The review arrives as a long list, so the list is the task. Each comment gets
one row in the =* Review= table, in the order it was given, and one checkbox in
the =* Checklist= below. A comment is never dropped silently: it ends as done,
declined with a reason, or deferred to a named task.

1. Enter every comment of a batch in =* Review= and =* Checklist= before changing any code.
2. Settle each comment's decision: accept, decline with a reason, or defer.
3. Work the accepted comments in the order listed. Commit in small steps and tick the box as each lands.
4. Run the web suites after each group, and the C++ suites when a server change is part of it.
5. At the end every row has a decision, every accepted box is ticked, and the Result names what was declined or deferred.

* Checklist

Tick a box when its change has landed. Add =declined= or =deferred= with the
reason beside any box that does not.
