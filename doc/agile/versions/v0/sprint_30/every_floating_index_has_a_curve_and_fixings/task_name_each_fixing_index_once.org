* Goal

The simulated curve writer names the EUR, JPY and MXN overnight indices ESTR, TONA and TIIE, while the public publishers map them as ESTER, TONAR and FTIIE, and the floating index catalogue holds both EUR-ESTER and EUR-ESTR. Each half lands in its own series, so a public value cannot stand over a simulated one. Choose one name per index, the one ORE reads, and make the curve families, the mappings and the floating index catalogue agree.
