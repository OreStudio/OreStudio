* Goal

Record one run of a process over a set of trades: its identity, its
state machine, the process it is a run of, and the trade groups that
carry what the run read and what it wrote. The record is what lets a
process be undone or repeated.

* Acceptance

- The process enumeration is seeded, so a run names which process ran.
- A run has an identity and a state machine over its evolution.
- A trade group carries a foreign key to its run, and its membership names each trade and the role it played.
- One detail table per kind of run records what that kind of run records.
- An ORE import is one run.
