* Goal

A report definition states what kind of run it is, and that kind selects the workflow and its parameters, so a new kind of report adds a workflow and a block rather than columns on the definition.

* Acceptance

- The definition carries one classification field and no workflow-shaped columns.
- Each kind resolves to a registered workflow and to that workflow's own start payload.
- An imported, a composite and a diff report can each be described without changing the definition's columns.
