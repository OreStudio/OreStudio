#+title: The evolution screen picker and the object form name a serie…
#+description: The evolution screen picker and the object form name a series by four words and its identity fields, such as fx / EUR / fx_option / rate_lnvol · ccy=CHF. The market data URL, oresmd://fx/EUR?type=quote&instrument=fx_option..., is the one name the rest of the product uses, and the screen already opens a series from an oresmd URL in the address. Show the URL as the series name, with the words as a secondary label, so a person can copy it, paste it into a link and read the same name in the shell and the logs. The server already composes the URL from a typed identity (compose_oresmd_uri), so the screen needs no codec of its own. Open questions: whether a long URL fits a select, and whether the words stay as the visible label with the URL on copy.
