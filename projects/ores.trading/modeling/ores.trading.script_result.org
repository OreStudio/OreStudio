One result a library script variant reports beside its NPV: the script
variable it reads and, when the library renames it, the name it reports it
under.

* Flags
:PROPERTIES:
:schema:           public
:product:          ores
:component:        trading
:has_tenant_id:    true
:END:

* Columns

** script_name
:PROPERTIES:
:type:        text
:cpp_type:    std::string
:primary_key: true
:nullable:    false
:economic: false
:END:

The library name of the script, as a scripted trade names it.

#+begin_src cpp :name generator
std::string("WindowBarrierOption")
#+end_src

** purpose
:PROPERTIES:
:type:        text
:cpp_type:    std::string
:primary_key: true
:nullable:    false
:economic: false
:END:

The purpose the variant serves: =default= for the one a trade runs unless the engine asks for another, else ORE's =purpose= attribute, such as =FD=.

#+begin_src cpp :name generator

#+end_src
