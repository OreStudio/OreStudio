* Goal

Every model with ores.cpp.wire-codec.enabled gets a generated test that writes its types in JSON and MessagePack, reads them back and writes the same bytes, for the default and a filled value.

* Acceptance

- A codegen archetype emits the roundtrip test per opted-in model, for domain entities, junctions and protocol messages.
- The generated test fills values with the entity generator where one exists, and with set members otherwise.
- The drift check covers the generated tests, and the hand-written codec_wire_bytes_tests.cpp files are deleted or reduced to the reflect-cpp comparison.
- ores.http, which has an opted-in model and no codec test today, is covered.
