registry entry, which the standard's own exception rule covers.

so the model, protocol, wiring and shell sections do not apply. Each item
that does not apply is recorded with its reason. The work that did apply:
the two generated CMake source lists regained their generated marker, the

inherited repo-wide CMake source-list drift that G06 records.

lists generating. The proof is the two dry runs recorded in the table, which
a reviewer can rerun.
