* Notes

Review of PR #3687 triage:
- Worker exceptions (point 1) and partial start (point 2): accepted and fixed. The fleet builds and starts into a local vector, stops what started if one start throws, and retries after a backoff.
- Environments populated before the grant (point 3): accepted in part. A permission error now logs a hint to populate the IAM roles again. No upgrade note is written.
- Rows published in session time (point 4): declined for now. Only a database that holds a vintage published before #3687 is affected, and the dev flow recreates the database.
- Cast precision (point 5): checked. =observation_date= is a =date= column in the DQ artefact table.
- Tests (point 6): not added in this task.

A restart with ticks stored found a second defect. Vintage series (provider =ore=) and tick series (provider =bloomberg=) share one identity, and the vintage read took the first match, so 6 of 26 generators failed to start. The read now scans every series of the identity.
