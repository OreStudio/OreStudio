The saga configuration of the [[id:0442FD13-1833-427F-B6CA-C4B5877C452B][identity workflow]]. The =ores-shell= block
below is tangled into the runnable script library as =identity_saga.ores=.

* Question

How do I exercise the engine's rollback path?

* Answer

The first step declares a compensation; the second fails. The engine dispatches the compensation for the completed step, records it at a negative step index, and settles the instance at =compensated= once every rollback has finished.

#+name: identity-saga
#+begin_src ores-shell :exports none
workflow start identity_workflow '{"steps":[{"name":"ok","compensate":true},{"name":"boom","behaviour":"fail"}]}' --instance-id 10000000-0000-4000-8000-000000000005
workflow wait 10000000-0000-4000-8000-000000000005 --timeout 60 --expect-state compensated
#+end_src

=workflow wait= fails unless the instance reaches the state named, so this
script fails when the path it covers does nothing.
