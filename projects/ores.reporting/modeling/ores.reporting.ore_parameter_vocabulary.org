#+updated: 2026-10-28

An ORE document spells some of its values in a vocabulary it defines: a
=Currency=, a =DayCounter=, a =BusinessDayConvention=. A leaf with one of those
names takes that vocabulary's value set wherever it appears, so the declaration
is stated once here rather than inferred from the name inside a generator.

A row says which element name, in which schema, takes which value set, and where
the rule comes from: the ORE source that reads the element, or the curator who
decided it. These rows are seeded from =ore_parameter_vocabularies.json=, and
the generator that links a curve's leaves to their sets reads that same
declaration, so a vocabulary added to it is a row here and needs no change to
a generator.

* Columns

** code
:PROPERTIES:
:type:         text
:cpp_type:     std::string
:primary_key:  true
:END:

The vocabulary's code, which names the schema and the element it applies to, for
example =curveconfig.xsd|Currency=.

** schema_name
:PROPERTIES:
:type:         text
:cpp_type:     std::string
:nullable:     false
:END:

The schema whose leaves the row applies to, for example =curveconfig.xsd=.

** xpath
:PROPERTIES:
:type:         text
:cpp_type:     std::string
:nullable:     false
:END:

The leaf's address in its schema, for example
=/CurveConfiguration/YieldCurves/YieldCurve/DayCounter=. Two leaves of one name
are two rows here when their addresses differ.

** element_name
:PROPERTIES:
:type:         text
:cpp_type:     std::string
:nullable:     false
:END:

The ORE element name, spelled as the schema spells it, for example =Currency=.
It is what a reader searches by; the address is what the rule is keyed by.

** value_set_code
:PROPERTIES:
:type:         text
:cpp_type:     std::string
:nullable:     false
:END:

The value set every leaf of that name takes, for example =curve.currency=.

** name
:PROPERTIES:
:type:         text
:cpp_type:     std::string
:nullable:     false
:END:

The name a person reads, for example =Currencies=.

** source
:PROPERTIES:
:type:         text
:cpp_type:     std::string
:nullable:     false
:END:

Where the rule comes from, for example =ore_code= for a rule the ORE source
states, or =curator= for one a person decided.

** source_ref
:PROPERTIES:
:type:         text
:cpp_type:     std::string
:nullable:     false
:END:

The file and line the rule is read from, for example
=OREData/ored/utilities/parsers.cpp:361=, and empty when no single place states
it.

** reason
:PROPERTIES:
:type:         text
:cpp_type:     std::string
:nullable:     false
:END:

Why the element takes that set, in a sentence a reviewer can check.
