* Notes

The scan that found these walks the hand-written tree for =.party_id= and
=.counterparty_id= on a receiver named for one of the eight children. A file
that reaches a child indirectly, as =xml::trade_import_item.booking= does, has
no mention of the child's own name, so the first pass over the tree missed
=ore_import_planner.cpp= and =importer.cpp= entirely; the receiver-name pass is
what caught them.
