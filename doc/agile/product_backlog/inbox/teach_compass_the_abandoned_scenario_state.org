* What

The web QA runner has a fourth scenario state, ABANDONED, for a scenario nobody will run. A person sets it by hand in the doc: the State row, a dated note, and ABANDONED in the #+todo line. The test_scenario template and compass do not know it, so the template todo line lacks it and no compass verb sets it. Add it to the template, add a verb that abandons a scenario, and let sprint audit and the indexes treat it as closed.

* Why

The state exists in the web runner, but compass cannot create or set it. People edit the docs by hand until it can.
