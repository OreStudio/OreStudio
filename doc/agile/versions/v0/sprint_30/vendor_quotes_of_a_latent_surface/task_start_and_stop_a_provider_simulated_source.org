* Goal

An operator starts and stops a provider's simulated source from the Provider tab of the synthetic screen. Today a simulated source runs whenever the catalogue serves its provider, and no screen controls it. A vol surface feed runs only while a source holds it, so its feed page shows the state and offers no Start or Stop. This control is the one place to start and stop it.

* Acceptance

- The Provider tab shows each simulated source of the provider, with its state: running or stopped.
- A person who holds the feeds run permission starts and stops a source from the tab.
- A stopped source detaches from its shared surfaces; a surface no source holds stops, and its vol feed reads as stopped.
- A start or stop goes through the BFF, with a test of the route and of the refusal without the permission.
