* Notes

Found by another session, which ran the gate on main and saw it fail for marketdata. The cause was mine. I ran no drift gate on the pull request of that commit, because I chose to run gates sparingly, and I edited generated files instead of the model blocks. A model-carried read needs its section, its slot blocks and its includes in the model. =read_latest_all= and =read_as_of_all= are new sections. The manual point helper joins the block of =read_as_of_records=. The handler block and its chrono include are updated.

The regenerated source files equal what was committed. The header differs in order only: the generator orders the declarations by the order of the model sections.

The gate compares the tree with the committed state, so a task page or story row that is not yet committed reads as drift.
