* Goal

A run knows, before the engine sees it, which trades its market can answer: the readiness of every address and of every trade is recorded against the run, the incomplete trades are left out, and a run with no complete trade never reaches the engine.

* Acceptance

- The run records, per address, whether the party's market answers it at the as-of, the series that answers it, and the cause when it does not.
- The run records, per trade, whether it is complete and the addresses and causes that make it incomplete.
- An incomplete trade does not travel to the engine, and the counts of booked, complete and excluded trades are recorded on the run.
- A run none of whose trades is complete fails in preprocessing, naming the causes, and never submits work to the grid.

* Plan

- Decide the set before anything is written. A new =resolve_market_readiness=
  step runs before =gather_trades=: it asks trading which trades the scope
  holds and what each one needs, asks market data which addresses it answers,
  records the answer, and hands the surviving trades to the export. Gathering
  the trades afterwards writes only what the engine will see, so no second
  export and no filtering of a blob are needed.
- A gap names a cause the read can state. The coverage function already tells a
  missing series from a series that holds no point at or before the as-of. The
  coverage repository keeps those apart and a new market data op carries the
  cause, so the record says =no_series= or =no_point= rather than "unanswered".
- Readiness is three records, at the three grains the design page states: the
  counts on the run, one row per trade, and one row per address. The counts go
  on =report_instance=, which the step already loads to mark the run running;
  the two detail grains are new tables.
- The decision is a pure function of the per-trade requirements and the
  coverage answer, so the rule is tested without a database, a NATS client or a
  workflow.
- A run with no complete trade fails in the readiness step, which is
  preprocessing, names the causes, and never reaches submission.
