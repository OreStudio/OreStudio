* Acceptance

- A route returns a page of batches, newest first, with the total count.
- A route returns a page of the workunits of one batch, and a page of the results of one workunit.
- A route returns one batch, one workunit or one result by id.
- Each route checks the entity's read code, and the row-level policy narrows a party member to their own party.
