** Surfaces to touch

The G2 wiring task established the row-based parameter architecture:
definitions catalogue (read-only reference), per-config value rows
(EAV child), the mapping layer that joins them and constructs the
typed engine, seed rows, and the data-driven parameter table in
IrCurveEditor. Black-Karasinski fits that machinery as-is — four
scalar parameters, no schema change, no codegen. The surfaces are:

1. =yield_curve_process_parameter_mapping.cpp=: =expected_parameters=
   entry + dispatch branch constructing =black_karasinski_process=
   from =black_karasinski_params= — direct construction in the
   mapping layer, per the G2 precedent (=make_yield_curve_process()=
   stays flat-arg, used by its own tests only; no new branch).

2. Seed data: =BLACK_KARASINSKI= row in
   =synthetic_yield_curve_process_types_populate.sql= (display_order
   5) + 4 definition rows in the definitions populate script, defaults
   matching the quant test values. Parameterization decisions:
   =theta= is the long-run level of =ln r= (default
   =log(0.04) = -3.218876=, honest log-level default with an
   explanatory description); =kappa= unbounded below (=kappa <= 0= is
   a valid, degenerate driftless case — unlike Vasicek's min 0);
   =sigma= min 0; =initial_rate= min =1e-6=, a small positive epsilon
   so the catalogue expresses the engine's strict =initial_rate > 0=
   bound and the mapping layer rejects 0 (the engine's own strict
   check stays as the last line of defence).

3. =IrCurveEditor.cpp=: one =kEngines= row + one tooltip entry — the
   data-driven parameter table needs no dialog work.

4. Doc comment: enumerate =BLACK_KARASINSKI= in
   =ir_curve_generation_config.process_type=.

* Result

Implemented =black_karasinski_process=: a one-factor log-normal short-rate
engine. =ln r= follows an Ornstein-Uhlenbeck process with the exact one-step
Gaussian transition, so the rate stays positive for all time. There is no
closed-form bond price under a log-normal short rate, so =discount_factor()=
builds per call a centered adaptive trinomial lattice of =ln r= and
propagates state prices through the generic =rate_tree= utility;
=sigma == 0= short-circuits to the deterministic closed form along the
mean-reversion path. 24 Catch2 tests covering Gaussian-OU moment checks
(statistical), tree-vs-Monte-Carlo agreement, dt convergence, zero-vol
closed form, deep-tree validity, seed determinism and validation.
Registered in =component_files.cmake=.

All 368 =ores.analytics.quant= tests pass on Linux. Not yet wired into
=process_factory= (deferred to PR 2: system infra wiring).
