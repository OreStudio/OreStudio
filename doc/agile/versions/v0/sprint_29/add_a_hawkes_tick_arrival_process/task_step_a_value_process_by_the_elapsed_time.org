* Acceptance

- next() equals next(1.0): the same seed gives the same prices as before, and the existing tests pass unchanged.
- The sum of the steps over a fixed span has the same variance whatever the number of ticks in it.
- A process that cannot take a variable step throws for an elapsed other than one, and validation refuses a non-periodic mode for it.
