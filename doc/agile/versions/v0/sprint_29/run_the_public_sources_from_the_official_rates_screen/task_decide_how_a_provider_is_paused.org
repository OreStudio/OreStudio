* Acceptance

- The decision names whether a pause is a fact about demand or about the provider, with the reason for the choice.
- The decision states what happens to stored fixings, to a feed that started from one, and to a running adapter's demand set.
- The decision states what the screen shows while a provider is paused, in one sentence.
- If the choice needs a provider state, the task names the model change and the consumers that must honour it.
