* Goal

A type's wire shape is a property of the type, not of a value. The four walks that read a value's members through rfl::to_view need the member names as constants, which a shape taken from a value does not give on every toolchain. They walk the stated shape instead.

* Acceptance

- Every stated shape takes the type's std::type_identity, and the carriers call it so.
- economic_digest, trade_operations_service, party_scope and handler_helpers walk the stated shape and do not name rfl.
- A test proves the digest of a trading type is unchanged.

* Plan

1. =wire_fields= takes =std::type_identity<T>=, by a codemod over every
   definition, template and hand-written header. The carriers call it so.
2. The digest is generated. Each type that declares its economic columns gets
   a plain =canonical_form(const T&)= beside its struct, which renders the
   declared columns, and each group whose own model declares economic fields,
   in member order. The leaf rendering moves to =ores.utility=, so a group in
   any component can state its form. =economic_fields_of= and the compile-time
   name search go.
3. =stamp_document=, =assign_party= and the bond check walk the generated
   shape with a plain =std::apply=. They need no member name as a constant,
   so nothing else is generated for them: the shape is already stated for
   every type, and a second per-type list for 15,000 messages would cost more
   to parse than the fold costs to instantiate.
4. A test pins three digests measured with =rfl::to_view= on main at
   f8adc1abcc: a bond instrument, a classified trade and a fixed leg.

* Notes

The codemod rewrote each definition with one regular expression,
=wire_fields\(\s*const\s+([^&()]+?)\s*&\s*\)= to
=wire_fields(std::type_identity<\1>)=, over every tracked =.hpp=, =.cpp=,
=.mustache= and =.org= file under =projects=. No definition named its
parameter, so no body read the value. The regeneration then wrote the
generated files in their formatted layout, and =clang-format= laid out the
hand-written ones.

A guard in =stamp_document= and =assign_party= refuses a struct with no stated
shape, where the reflect-cpp walk would have walked it. It found four that the
walk would otherwise have skipped without a word, and so left unstamped: the
refdata curve configuration document, whose model had no wire codec, two
hand-written test documents, and =mapped_credit_simulation= in ores.ore.

* Result

=wire_fields= takes =std::type_identity<T>= everywhere, so a type's wire shape
is a property of the type. The economic digest no longer walks a value: every
type that declares its economic columns has a generated =canonical_form=, which
renders those columns, and each group whose own model declares economic
fields, in member order. The leaf rendering moved to =ores.utility=, and
=economic_fields_of= and its compile-time name search are gone. The party
stamp, the audit stamp and the bond part check walk the stated shape with one
=std::apply=, and none of the four walks names rfl. A test pins three digests
measured with the reflect-cpp walk on main, and all three are unchanged, so no
stored digest moves.
