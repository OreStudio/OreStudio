* Goal

A code is shown the way the rest of the platform shows it. A screen that holds
a row's own code — a tenor's kind, a convention's anchor — draws the badge its
code domain paints, with that badge's words and colours, and falls back to the
code only where the catalogue has painted nothing.

The rule is one function, called everywhere: a screen never prints a catalogue
code as text and never builds its own pill. See =CodedValue= in
=projects/ores.web/packages/web/src/refdata/shared.tsx=.
