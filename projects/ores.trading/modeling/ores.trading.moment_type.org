Reference data table defining the closed moment set of a variance
or volatility swap. The set is the ORE =momentType= simple type under
=external/ore/xsd/ore_types.xsd=.

The values are the ORE XSD spellings, so a stored value round-trips through the
ORE XML unchanged. No conversion is introduced here.
