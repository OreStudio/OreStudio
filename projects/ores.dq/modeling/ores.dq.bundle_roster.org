The bundle roster verb: one request that names a bundle or none, and one reply
that carries every bundle and, for the one named, its members.

It is an operation rather than an entity verb because the answer is a shape the
tables do not hold: the level a bundle publishes at, the count of its members,
and per member the count of rows its artefact table has staged. Three SQL
functions compute that answer, and the handler that serves it stays hand-written
beside this model.

A request that names no bundle answers the roster alone, without members. The
staged count costs one count per member's artefact table, so it is taken for the
bundle a caller names and never for every bundle on the roster.
