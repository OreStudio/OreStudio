* Goal

Give the kernel the second primitive the vault needs: a value sealed to a
recipient's public key, which only that recipient's private key opens. The two
sides share no secret beforehand, so the vault can seal to a consumer it has
never spoken to, and the consumer opens the answer without a channel to agree a
key on. The class carries the key agreement, the derivation and the
authenticated encryption, and it sits beside the symmetric sealer in the same
facet. It links no database, no bus and no credential. Its tests prove the round
trip and refuse a wrong key, a changed byte and a ciphertext sealed to somebody
else.

* Acceptance

- A value sealed to a public key opens with the matching private key and with no other.
- The two sides share no secret beforehand: the derived key, the nonce and the tag are all the ciphertext needs.
- A changed byte, a wrong private key and a ciphertext sealed to another recipient each fail to open, and the primitive links no database and no bus.
