#+title: How do I run the equity_accumulator_instruments commands from the shell?
#+description: Every command the equity_accumulator_instruments submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:equity_accumulator_instruments:

This file documents the equity_accumulator_instruments resource at the shell, one section per command. Every command is a subcommand of =equity_accumulator_instruments=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: A9D866E4-5AC8-5F63-BB55-D08CF62FE8BE
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
equity_accumulator_instruments list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =trading.v1.equity_accumulator_instruments.list=.

#+name: equity_accumulator_instruments-list
#+begin_src ores-shell :tangle equity_accumulator_instruments-list.ores :exports none
equity_accumulator_instruments list --limit 1
#+end_src

:PROPERTIES:
:ID: E8CA5259-18AE-5FCB-99A5-0A63A2E6B0FA

** =add=
:PROPERTIES:
:ID: B3A097E3-B823-5005-89AC-50CEA2A15492
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.

#+end_example

** =set=
:PROPERTIES:
:ID: 778ECBD4-88D6-5440-9A5A-A9B911D22E5A
:END:

Writes a row. The change states no precondition, so it replaces whatever row the key already addresses. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved. Passing --version makes the write conditional on the version the caller last read.


The command is shaped like this:

#+begin_example
