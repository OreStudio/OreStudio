* Goal

Codegen is the clearest working instance of this architecture, built independently and further along: meta-types are typed targets, the eleven named profiles are a closed register, the twenty-five features are the axes it is built from, generated-versus-hand-written is a target property that gates legal operations, and zero-diff regeneration is a falsifiable predicate. Bind the two together. The dispatcher must resolve generated-ness before it offers any verb, and must not offer hand-editing on a generated artefact; the edit goes to the model or the template. Profile selection joins method selection as a match-against-a-closed-register decision with the same fallback discipline: exact match, else nearest by Hamming distance, then read the diff as either a gap to close or a novel combination worth naming. Promote the fix-the-template memory into a principle so a method can cite it.

* Acceptance

- The dispatcher resolves whether a target is generated before offering verbs.
- Hand-editing is never offered on a generated artefact; the model and the template are offered instead.
- Profile selection follows the register discipline: exact match, nearest match, then gap or new profile named.
- No entity is left with loose knobs and no profile, and the rule is stated where an author will meet it.
- Fix the template, never the output is a principle in the citation function, not only a memory.
- Where this architecture and the variability model disagree, the variability model wins and the divergence is recorded.
