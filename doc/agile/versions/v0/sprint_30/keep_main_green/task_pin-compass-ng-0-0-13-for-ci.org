* Goal

The install step added in #5032 runs and puts the release's bin on PATH, and the
nightly of 2026-11-23 still stops in =Init environment= with "compass-ng is not
on the PATH". The release archive carries one binary, named =compass=, and
=compass env configure= looks for =compass-ng=. The pin also still named
v0.0.12 while v0.0.13 has been released.

* Acceptance

- The workflows install v0.0.13 and expose it under both names.
- The nightly reaches the build and submits to CDash.

* Plan

Raise =build/scripts/compass_ng.pin= to v0.0.13 with the commit it was built from
(8259d8b2ae, 2026-11-22T22:11:00Z), and, in the two Linux workflows, symlink
=compass-ng= beside the extracted =compass= before adding its directory to PATH.
The archive layout is =opt/compass/<version>/bin/compass=, checked by unpacking
the release here.
