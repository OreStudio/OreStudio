* Goal

A client such as Claude Desktop or claude.ai connects to /mcp, is sent to ORE's own sign-in page, and the person signs in and approves the agent, which creates the same agent grant an API key does. ores.http publishes protected resource metadata, answers 401 with WWW-Authenticate, and serves authorization server metadata, an authorize endpoint with the consent page, and a token endpoint with PKCE S256, rotating refresh tokens and tokens bound to ORE by resource indicator, as MCP's authorization specification asks. Done when a client needs it, after the API keys.
