One =Configuration= block. It is not a collection of entries: it is a bundle of
references, each naming one entry of one collection, so that a report can select
a coherent set of curves and volatilities by name instead of restating them.

It identifies itself by a required =id= attribute, which is unique within a
document. The references it makes live on
=todays_market_configuration_binding=.

** configuration_id
:PROPERTIES:
:type:     text
:cpp_type: std::string
:nullable: false
:END:

The =id= attribute the document wrote on the =Configuration= element.

Unique within a document, not within a tenant: two documents may each have a
configuration called 'default'. So it is not a natural key, and uniqueness is
held by the pair of the document and this value rather than by this value alone.
Examples: 'default', 'collateral_inccy', 'ois'.
