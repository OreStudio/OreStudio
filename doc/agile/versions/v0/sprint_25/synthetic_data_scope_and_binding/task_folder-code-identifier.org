* Goal

Market simulator folders currently have only a human-readable name (multi-word, spaces allowed), so shell commands must address them by exact full name or UUID. Add a stable, slug-like code (like tenant.code) so folders can be addressed by a short unambiguous token; resolver order: uuid first, then code, then exact name.
