* Goal

While a window is open it sends a small heartbeat on a timer, including when it is in a background tab, so the server can tell a window that is open from one that is gone.

* Acceptance

- The web sends a heartbeat every thirty seconds while a person is signed in, and stops when they sign out.
- The heartbeat is its own route and does not count as activity for any idle rule.
- A background tab keeps sending it, within the limits the browser sets on timers.
