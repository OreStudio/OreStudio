profile system" task, `compass codegen entity generate market_fixing`
(=ores.marketdata=) — run on clean, unmodified =origin/main= to
isolate the effect of that task's change — produced real, pre-existing
drift: new untracked files the template wants to generate that don't
exist in the repo yet (=messaging/market_fixing_registrar.hpp/.cpp=,
=presentation/market_fixing_history_field_mapper.hpp/.cpp=,
=service/messaging/market_fixing_event_registrar.hpp=). This is the
same class of "additive" drift this story already catalogues and
fixes component-by-component, but =ores.marketdata= was never in
scope of the original 75-model drift catalog. Extend the catalog with
a "marketdata" section and apply safe drift following the
refdata-cpp pilot pattern.
