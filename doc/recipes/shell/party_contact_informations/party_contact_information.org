#+title: How do I run the party_contact_informations commands from the shell?
#+description: Every command the party_contact_informations submenu answers, with the script each one exports into the shell's script library.
#+type: recipe
#+level: cross
#+filetags: :recipe:shell:party_contact_informations:

This file documents the party_contact_informations resource at the shell, one section per command. Every command is a subcommand of =party_contact_informations=, and every section exports its own script into =projects/ores.shell/scripts/library/=. Loading a script runs that one command, so a failure names the command it came from.

* Commands

** =list=
:PROPERTIES:
:ID: 5F7D580E-4472-5F62-B30A-7BFBB68F5529
:END:

Reads one page of the collection. Nothing addresses it but the caller's tenant, so it is the read that shows what exists.


The command is shaped like this:

#+begin_example
party_contact_informations list [--offset <n>] [--limit <n>] [--order <field>] [--desc]
#+end_example

It is addressed at =refdata.v1.party_contact_informations.list=.

#+name: party_contact_informations-list
#+begin_src ores-shell :tangle party_contact_informations-list.ores :exports none
party_contact_informations list --limit 1
#+end_src

** =add=
:PROPERTIES:
:ID: 39156A1F-1B7D-59D0-A812-7AF8FCBBABF2
:END:

Writes a row. The change states that the row must not exist, so a create that collides with an existing row is refused rather than replacing it. The change carries a reason and a commentary, which the server records on it so the row's history says why it moved.

** =set=
:PROPERTIES:
:ID: B27DFC4F-2A0F-5A03-8B08-9BC99E3B2C44
