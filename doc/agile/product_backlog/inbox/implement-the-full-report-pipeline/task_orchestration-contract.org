* Goal

A report run coordinates four services through ores.workflow, and the contract between the coordinator and a stage is implicit today. State it: the participant interface, the idempotency every stage owes because dispatch is at-least-once with no timeout, what compensation undoes in each mode, and which of the two state machines is authoritative. Then make the engine's known silent failures loud.

* Acceptance

- Every stage is idempotent under a re-dispatch, demonstrated by restarting mid-run.
- A stage that cannot answer fails the run within a stated budget instead of leaving it in progress for ever.
- An unknown or mis-selected step chain fails the trigger rather than answering success.
- The relationship between the workflow instance and the report instance is stated, and the terminal transition is enforced through the FSM guard.
