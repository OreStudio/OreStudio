* Result

A run's rows now name the trade and the counterparty the way a person knows
them, and open onto the trade.

The table shows the trade id in full, as a link to the trade, and the
counterparty by its name, as a link to the counterparty. The engine writes the
counterparty's id into =npv.csv=, so the BFF resolves it against the tenant's
counterparties and leaves the cell empty rather than guessing when the name
cannot be read.

Opening a row states that trade's figures below the table: its id, its type, its
NPV, its base NPV, its notional and its counterparty, each id leading to its
record. It also states what the run recorded about that trade, or that the run
recorded no error against it. A row whose trade the run recorded an error
against carries an =error= tag.

The run that shows it is =9ff0e92e-f21d-4137-bb24-ad4956fa99f0=: eight bond
trades whose counterparties read =OCBC Bank (Hong Kong) Limited=, =DBS BANK
LTD.=, =The Bank of East Asia, Limited= and others, and no error against any of
them, because the run completed.
