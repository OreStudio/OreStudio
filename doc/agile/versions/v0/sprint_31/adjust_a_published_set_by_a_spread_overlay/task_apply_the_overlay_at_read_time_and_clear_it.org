* Goal

A read at an as-of applies the overlay to the automatic values of the nodes it covers, and clearing it restores them, so the overlay behaves as the manual point's precedence at many nodes.

* Acceptance

- A read at an as-of returns the automatic value plus the shift at each covered node, and the unshifted value outside the extent.
- Clearing the overlay restores every covered node in one act.
- A later automatic write is still seen through the overlay, so a shift tracks the market rather than freezing it.
