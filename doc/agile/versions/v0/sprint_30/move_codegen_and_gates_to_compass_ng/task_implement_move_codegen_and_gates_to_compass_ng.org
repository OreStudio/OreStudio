* Acceptance

- A recorded comparison lists every disagreement between compass check and local_checks.py on one commit, with its cause and which side is right.
- compass check reports nothing on main: the real drift is regenerated, and each baseline entry is an inline exception.
- ./compass.sh check runs compass check for the ported gates, and runs Python only for the gates compass does not cover.
- compass generate replaces regenerate --all and the ores.codegen regeneration verbs.
- CI runs compass check --ratchet from a pinned compass release, and the ported Python CI workflows are removed.
- Every environment and every external developer installs a pinned compass release with one documented command, and bearings reports a missing or out-of-date binary.
- The Python gates and generators that compass replaces are deleted, together with their baseline files.
