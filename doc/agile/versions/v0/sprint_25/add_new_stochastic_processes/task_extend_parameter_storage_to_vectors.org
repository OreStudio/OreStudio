* Goal

The process parameter definition and value model supports vector-valued parameters: a definition can declare a vector type, a value row can store a serialized vector, and the mapping layer parses and validates it (element count, per-element bounds). This is the shared storage groundwork for the BDT, HJM, and LMM wirings; scalar parameters behave exactly as before.
