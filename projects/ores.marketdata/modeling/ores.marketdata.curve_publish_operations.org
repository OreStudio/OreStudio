#+brief: The approval-gated curve publish.
#+filetags: :model:operation:marketdata:
#+created: 2026-10-27
#+updated: 2026-10-27

A publish is a request, not a save. The trader who owns the curve asks for the
candidate set to become the curve the desk prices from, a person holding the
permission the kind names decides it, and only an approved request publishes.

The ask is the generic approval operation,
=inbox.v1.ops.raise_approval=, raised with the kind =marketdata.curve_publish=.
This operation is the other half: it refuses to publish unless it is given the
approved request of that kind, and it publishes when it is. The publish it
applies is =curve_republish_service::republish()=, the write
=marketdata.v1.ops.republish_curve= already triggers; the difference is that
this operation carries the decision.

A request names the curve, the as-of and the party it authorises in its own
detail table -- [[id:9BC6FEDE-01E5-43B8-8A04-ACF0A5AB12B6][ores.marketdata.curve_publish]]
-- which the raise writes and the publish reads. The trade that was missing is
therefore closed: the publish compares the subject it is about with the subject
the request holds, and refuses a different configuration, as-of or party with the
words that name both. The apply stamps the same row with the publisher and the
instant, so a request publishes once.

#+begin_src cpp :name comment
/**
 * @brief Publishes a bootstrapped curve's output under the approval that
 * permits it.
 *
 * The call is the second half of a decision: the person asking raised an
 * approval request of the kind marketdata.curve_publish, somebody else
 * decided it, and this names the approved request. A call that names no
 * approved request publishes nothing, and the answer states the kind the
 * request must be of. A call whose curve, as-of or party is not the subject the
 * request names publishes nothing either, and the answer names both subjects.
 * The request publishes once: a request that already moved the set is refused,
 * and the answer says who applied it and when.
 */
#+end_src
