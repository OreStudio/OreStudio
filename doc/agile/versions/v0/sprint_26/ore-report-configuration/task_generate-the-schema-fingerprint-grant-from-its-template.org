* Result

The db grants template now emits the schema fingerprint grant for every
service in the registry. [[https://github.com/OreStudio/OreStudio/pull/2574][#2574]] had added it to the generated
=iam_service_db_grants_create.sql= by hand, so regenerating the grants from the
service registry, as any new service or grant change does, deleted it, and
every service would then have refused to start for want of SELECT on
=ores_database_info_tbl=. Regenerating the grants after this change leaves the
checked-in file byte-for-byte as it was.
