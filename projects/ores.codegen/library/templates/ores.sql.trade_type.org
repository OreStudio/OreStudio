* Summary

One template projecting the /trade-type catalogue/ onto the trade types seed
that used to be hand-written: one row per trade type, with its description,
product type and flags. The catalogue also routes each type to the instrument
table that holds it; the instrument tables' checks read that routing through
=:routed_column:=, and the C++ routing is a separate facet.
