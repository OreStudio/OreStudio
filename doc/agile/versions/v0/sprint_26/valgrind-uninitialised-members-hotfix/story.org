under =tmp/= are the CDash pages for them:

Two different defects wear the same number.

The uninitialised-value defects are one class: a generated struct member
with no in-class initialiser. Only =:default_value:= reaches the member
initialiser the class template emits, and a model that declares none leaves
a default-constructed object indeterminate. Nothing detects that until a
write path reads the member, and sqlgen reads every member when it
stringifies an entity for its INSERT:

- =ores.analytics.core.tests=: =credit_simulation_matrix_config.t0= and
  =t1=, and the eight =p_*= probabilities of
  =credit_simulation_matrix_row_config=, are =double= columns with no
  default. The generated generator cannot fill them, so a synthetic row
  reaches the INSERT with eight indeterminate members.
- =ores.ore.core.tests=: 40 of the 43 defects are =yyjson= reading
  =bond_trs::funding_rate= while the roundtrip test writes the payload, and
  3 are the date reflector reading =bond_future='s two unset dates.
  =funding_rate= is =nullable: true= with a bare =double=, so the entity
  wraps it and the mapper maps zero to NULL; the domain member was
  indeterminate instead of zero.
- =ores.trading.api.tests=: the test builds a =vanilla_swap_instrument= by
  default-initialising it and writing it out, which reads both dates.
- =ores.analytics.core.tests= again, for =credit_simulation_config='s
  nullable bare =bool= and =int= members, which the generated entity
  config test builds and inserts.

The 3329 records for =ores.refdata.core.tests= are all *still reachable*,
not lost: 3254 are the coverage runtime registering every translation
unit's counters at load, and the rest are glibc's atexit handler nodes,
libpq's per-connection state (the pool lives for the process), and the
Catch2 reporter's output stream. =build/valgrind/custom.supp= already
carries 196 rules of exactly that kind; these categories were missing.

* Decisions

- The defaults are declared in the models rather than synthesised in the
  templates. The estate's mechanism for this is =:default_value:=, the sprint
  25 compute-host fix used it for the same defect, and the value that means
  "absent" is the model's to state. The alternative -- synthesising a default
  for every arithmetic and chrono type in =core.py= -- closes the whole class
  at once but decides a semantic value on the model's behalf; it is filed as
  a capture with the census so the decision is taken with the size known.
- The gate refuses the nullable half of the shape and not the non-nullable
  half. A nullable column with a bare =double= cannot carry NULL, so the
  convention that zero is the absence has to be stated; that is the shape
  that produced =bond_trs::funding_rate=. The non-nullable half is 87 columns
  today and refusing it would make this branch a catalogue-wide model change.
- The suppressions name the allocation site's library frame, not the loader.
  A rule anchored on =llvm_gcov_init=, =__cxa_atexit=, =PQconnectdb= or the
  Catch2 reporter suppresses the category and leaves any allocation through
  another path visible.
- Each finding was reproduced locally with =--track-origins=yes= before it
  was fixed. The saved CDash pages are truncated at about a megabyte, and the
  first version of this work fixed 64 of the 214 analytics defects because it
  trusted the page; the second entity's 146 only appeared when the binary was
  re-run.
