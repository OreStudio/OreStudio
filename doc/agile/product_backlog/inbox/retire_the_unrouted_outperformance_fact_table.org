* What

Remove the entity =equity_outperformance_option_instrument= and its table
=ores_trading_equity_outperformance_options_tbl=: the model, the SQL, the C++
domain, repository, service, protocol and shell commands that codegen made
for it.

* Why

Sprint 28 authored the table for EquityOutperformanceOption, but the routing
never sent a trade to it. The trade type routes to the equity option row, which
now holds the initial prices, the strike return and the knock prices as
columns, and the two underlyings as rows of the shared underlying table. The
table is a second home for the same terms that nothing writes. The only terms
it holds that the option row does not are the two optional initial price
currencies.
