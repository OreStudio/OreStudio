* Plan

Eighteen auth routes ores.web calls lack a C++ route at their own address. This
task serves the four of the audit screens in a hand-written unit,
=audit_routes=: the sign-in events and the session statistics of a period, the
country an address is in, and an administrator ending one session. The window
query is read strictly, as the BFF's schema read it: only its keys, a period of
hour, day, week or all reaching back from now, and a page of 1 to 500. A
session id that is not one is refused before the forward, where the BFF passed
it to the service to refuse.

The others move to [[id:ED0F19DB-E589-4895-B297-9BDB0E335867][Serve the login records and the sessions]]
and [[id:D4275B6D-BF22-4A77-9F00-018D776966CB][Serve the browser's cookie session routes]].
