* Decisions

- *Both preset settings are needed to see the warnings.* =warnings.uninitialized=
  alone does not report them, because each variable carries the =CMAKE_=
  prefix; =warnings.systemVars= (the =--check-system-vars= equivalent) is what
  puts them in scope. The reproduction therefore passes both flags, and a
  reproduction that passes only the first shows nothing.
