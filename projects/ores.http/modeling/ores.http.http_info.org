The HTTP service-discovery surface: one request and one reply, through
which a client learns where the companion HTTP server listens. It is an
operation rather than an entity verb, so it is declared here instead of
being derived from an entity. The base URL is runtime configuration, not a
row a caller addresses by key.

The subject follows the naming every other component uses, a component
token followed by the version and the verb, so the gateway is
=http.v1.info.get= and not =http-server.v1.info.get=.

The handler that serves it stays hand-written beside this model, because it
reads the base URL the server's own options supply.
