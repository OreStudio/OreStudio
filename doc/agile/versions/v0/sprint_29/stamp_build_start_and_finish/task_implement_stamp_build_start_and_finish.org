* Goal

A person who reads a build's console output or its log can tell when the build started, when it ended, and how it ended.

* Acceptance

- compass build prints the start time after the parallel jobs line
- compass build prints the finish time, the outcome and the elapsed time when the build ends
- Both lines are in the build log

* Plan

Stamp only the cmake path of =cmd_build=, because that is the output a person
reads to see when a build ran. The start line goes after the parallel jobs line,
when the slot and the job count are known. The finish line goes in the =finally=
block, so a failed or interrupted build also gets one. One helper,
=_build_stamp=, prints each line and writes it to the build log. A dry run gets
no stamps, because nothing runs.

* Result

=compass build= now prints =🕒 Build started: <date> <time> <zone>= after the
parallel jobs line. When the build ends, it prints =🕒 Build finished (<outcome>,
took <h:mm:ss>): <date> <time> <zone>=. The outcome is =succeeded=, =failed,
exit N= or =interrupted=. Both lines also go into the slot's build log, so
=compass build --status= shows when the last build ended. A real
=compass build -j2 ores.platform.lib= printed both lines and wrote both to
=tmp/ores-build.log.b=. The =--direct= emacs path is unchanged.
