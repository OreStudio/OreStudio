# Artwork

The icon set is `icons/`: Microsoft Fluent UI System Icons, the vocabulary the
interface draws on. `doc/knowledge/ui/icon_guidelines.org` is the source of
truth for the artwork, and `projects/ores.web/modeling/icon_reference.org`
lists the subset this client uses.

Two brand images were removed on 2026-09-23 with the screens that carried them:
the splash was the landing page hero, and the icon was the header mark and the
favicon. Nothing in the shell renders either today. Both came from the main site
at `orestudio.github.io/OreStudio`, so copy one back from `assets/images/` there
if a screen needs it.
