* Acceptance

- =build/scripts/expand_catch2_cases.py= rewrites a Test.xml in place, and
  its tests cover each case where a suite entry is kept.
- CTest.cmake runs it between =ctest_test= and the final =ctest_submit=.

* Plan

Read each suite's results file from the =xml::out== path on its command
line. Keep the entry if the file is missing, older than the test's start
time, unreadable, or green while the suite failed. Otherwise replace the
entry and its TestList line with one entry per =TestCase=.
