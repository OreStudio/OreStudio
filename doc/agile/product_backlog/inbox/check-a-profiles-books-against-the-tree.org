#+description: A seed profile's generate_trades config names a book by name, and nothing checks that name against the tree the same dataset seeds. The ACME tree review removed the equity and commodity desks while the acme_demo profile still named 'GBP Equity Derivatives' and 'USD Commodity Derivatives', so every provisioning run stopped at the first config whose book no entity held — and it stopped after the data was published, which makes the failure look like the population's fault. The northwind profile names two books of its own, 'GBP Bonds Book' and 'USD Bonds Book', and the same absence would stop it silently. Check the profile's book names against the dataset's books before the step runs, and refuse with the config's name rather than the book's.
