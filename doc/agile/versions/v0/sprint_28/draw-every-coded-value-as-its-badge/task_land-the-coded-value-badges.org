* Goal

Every coded value is drawn as its badge, wherever it is read, and chosen the same way: one renderer and one shared control, so a list and its badge cannot be two renderings of one fact that drift apart. The badge story described the work; this lands it.

* Acceptance

- One shared renderer draws every coded value, resolving a field's badge through the code domain that owns it.
- One shared control chooses a coded value, drawing its options as badges rather than as text.
- The tenor kinds and units carry their own badges rather than borrowing another domain's.
- The tenor journey uses both, and the web and BFF suites pass with the i18n key sets equal across the three locales.
