* Acceptance

- One constructor per routed bond code, with the trade type fixed by it.
- Terms hold only the columns each product's shape states, and the closed vocabularies are refused at construction.
- The writer hands the constructed row to the batch and no longer translates a bond.
- A provisioning run books the same bond population as before this change, and the suites are green.
