* Question

How do I smoke test that a provisioned tenant ticks?

* Answer

Run compass smoke ticks. It recreates the database, starts the services, provisions the Acme tenant and waits for a tick. It prints the evidence: the tenant, its subscriptions and routes, the tick counts and instants, and each adapter's accepted, rejected and demanded ids. It fails when the tenant has no subscription or route, when no adapter gets a demand, when the adapters accept fewer ids than demanded, when no tick arrives, or when a tick is dated in the future. Use --start-services to keep the database, and --skip-provision to watch a tenant that is already provisioned.

* Script

./compass.sh smoke ticks --fresh

* Tested by

The local check gate runs it after the test suite when the marketdata, synthetic or provisioning code changes.
