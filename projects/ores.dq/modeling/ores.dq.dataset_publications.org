The dataset publications verb: one request that names a dataset, and one reply
that carries every run that published it, newest first.

It is an operation rather than an entity verb because the answer is read by a
dataset's own page and by nothing else: the log is append-only, it is read by
code, and the list the entity generates states no filters. The handler that
serves it stays hand-written beside this model.
