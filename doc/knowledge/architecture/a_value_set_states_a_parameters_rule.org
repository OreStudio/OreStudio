* Summary

A *value set* states what values one ORE parameter accepts, once.

| Table | States |
|-------+--------|
| =ores_reporting_ore_parameter_value_sets_tbl= | the set: its kind, catalogue, bounds and pattern |
| =ores_reporting_ore_parameter_value_set_values_tbl= | the values of an enumerated set, with a label and an order |
| =ores_reporting_ore_parameter_value_set_catalogues_tbl= | the relation a catalogue set reads |
| =ores_reporting_ore_parameter_setting_value_sets_tbl= | the link from =(scope, name)= to its set |
| =ores_reporting_ore_parameter_vocabularies_tbl= | the link from an ORE element =(schema, element)= to its set |

The kinds are =text=, =integer=, =number=, =range=, =enumerated=, =catalogue=,
=regex= and =boolean=, and one function, =ores_reporting_value_in_set_fn=,
answers whether a value is one the set states. The parameter trigger, the curve
column guard and the engine settings part guard all call it, so a value the
store refuses is refused the same way on every path.
