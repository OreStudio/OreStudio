* Acceptance

- A list call returns every product type with its axis codes and names, and a count for each group.
- A detail call returns one type with its description, source, note, routing table, allowed books, permission and pricing engines.
- The wire-protocol schemas cover both calls, and the BFF routes have tests.
- The joins that read trade types today move onto the route, and none keeps a list of its own.
