* Acceptance

- The fifteen tables are generated by the canonical template from domain_entity models.
- sql_schema_artefact_create is deleted once no model uses it.

* Plan

The table belongs to the model of the data it stages, so each of the
fifteen gets an owning model in the component that owns its rows, with
=:ores.sql.schema.domain_entity_artefact_create.enabled: true= and an
=* Artefact columns= section, because the staging shape is not a
projection of the entity. Twelve had no model at all and are new;
=party_roles= and =asset_classes= are the two that needed more than the
flag.

The task description says these tables came through
=ores.codegen.lookup_entity= models. They did not: no =*_lookup_entity.org=
file exists in the tree or in its history under these names, so the
tables were orphaned output that no run rewrote. The files were the real
target and the premise was stale.

* Notes

- =asset_classes= was the one table that needed a redesign rather than a
  flag. It had no entity but did have an =asset_class_messages= operation
  model over a hand-written repository and service, and the joined list it
  served had no consumer outside its own handler. The hand-written pair and
  the operation model are retired; the entity generates the table, its
  staging table and the read and write stacks in their place.
- The refdata =account_types= codelist collides with the IAM account type
  of a login account: the shell menu name is the entity plural and has no
  override, so two components generated a menu named =account_types=. The
  codelist is renamed =trading_account_type=, which names what it
  classifies -- a trading account, by whose activity it carries -- and
  clears the menu.
- The first pass overwrote the IAM =account_types= shell recipe, because
  the codelist briefly claimed the same menu. Regeneration restored it from
  the IAM model; the drift check is what caught it.
- The per-entity =ores_refdata_validate_<entity>_fn= functions the orphan
  tables carried are not generated by the entity template. Nothing called
  them, so they go with the orphans.
