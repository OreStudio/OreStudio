* Result

* Result

=ores_geo_ip2country_lookup_fn= ignored the tenant whose ranges it searched
and returned the first match in the table. It now takes the tenant, so the
same address resolves only against the ranges that tenant published.

=geolocation_service= passes the tenant from its context and binds the
address as a parameter rather than splicing it into the statement. =ores.iam.core=
links =ores.geo=, and the login path fills the session's =country_code= from
the lookup, so a session now says where it came from. =iam.v1.ops.lookup_country=
serves the lookup over the wire, with =iam::geo:lookup= and a BFF route.
