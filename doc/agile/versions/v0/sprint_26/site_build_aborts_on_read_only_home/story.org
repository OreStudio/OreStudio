* Decisions

- One file for the fix, not one edit per script. Five batch scripts share the same bootstrap, so the rule belongs in a single place; the alternative was five copies free to drift apart.
- Guard the override with =fboundp=. =package--quickstart-maybe-refresh= is internal to Emacs, so the fix must go inert if a future release renames it, rather than break the load of every script that loads the file.
- Suppress the cleanup rather than teach it about a read-only path. The cache describes the user's package directory, not the checkout's =./.packages=, so a batch install has no business refreshing it even on a writable HOME.
- Fix the page rather than the exporter. Backticks are not org markup, so the two pages were wrong and the exporter was right to abort.
- Track the work on the branch that already carried it. The story was created after the branch and the PR existed, so the branch is =fix/site-build-blockers= rather than the =hotfix/= name the runbook scaffolds.

* Out of scope

- Whether the batch scripts should share their whole package bootstrap. They duplicate =package-user-dir= and =package-archives= as well, which is a larger consolidation than a hotfix should carry.

* Result

=compass build --direct site= completes on a cold, read-only HOME and writes =graphdata.json=.

The install aborted because =package--quickstart-maybe-refresh= deletes the user's quickstart cache under =~/.emacs.d= whenever =package-quickstart= is nil, and =delete-file= signals when HOME is read-only. One shared file now overrides that function, and the four scripts that install a package load it before their first =package-install=; =ores-build-site.el= reaches it through =ores-site-packages.el=, which it already loaded.

The export then aborted on two =clean-platform= pages because =[[no_unique_address]]= sat inside Markdown backticks, which org does not read, so the exporter treated the brackets as an unresolved link. Both pages now use org verbatim, the markup the standard's own page already used.

Evidence. With a quickstart cache under a read-only =.emacs.d=, the bare call signals =Removing old name=, and the same call with the shared file loaded reports no signal and leaves the cache in place. The site build reports =Build succeeded= and writes =graphdata.json= for 6570 nodes and 34141 links. =compass lint= passes.
