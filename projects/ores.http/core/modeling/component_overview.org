* Summary

=ores.http.core= implements the concrete HTTP route handlers for the ORE Studio
REST API. It registers routes for each domain it still owns in process:
storage and variability (configuration). The domain components served through
generated NATS-forwarding route units live in their own adapter parts under
=projects/ores.http/= — =ores.http.iam=, =ores.http.assets= and
=ores.http.refdata=. Each route handler translates the incoming HTTP request
into NATS calls to the appropriate domain service and returns the NATS
response as an HTTP response.

* Inputs

- Incoming HTTP requests dispatched from =ores.http.api= router.
- NATS responses from =ores.iam.service=, =ores.variability.service=,
  =ores.storage.service=, etc.

* Outputs

- HTTP responses constructed from NATS domain service responses.
- Route registrations added to the =ores.http.api= router and OpenAPI registry.

* Entry points

- =include/ores.http.core/routes/variability_routes.hpp= — config handlers.
- =include/ores.http.core/routes/storage_routes.hpp= — storage handlers.

* Dependencies

- =ores.http.api= — server infrastructure, router, JWT claims.
- =ores.iam.api=, =ores.variability.api=, =ores.storage.api=
  — NATS protocol types for each domain service called.
- =nats.c= — NATS client for forwarding requests.
