* What

Pass the loaded time to the record dialog and the classification row dialogs. RS-WRITE-16 and ES-REFRESH-28 say a dialog over a record says under its title when the record it started from was loaded. The harness baseline of 2026-10-25 finds no dialog does: RecordDialog and the classification row dialog open the shared Dialog without its loadedAt. 23 dialogs.

* Why

The harness measured every record screen before the screen pipeline changed
any, so each topic starts from a known gap and the sign off has a before and an
after. This is one of the four rules the baseline found broken.
