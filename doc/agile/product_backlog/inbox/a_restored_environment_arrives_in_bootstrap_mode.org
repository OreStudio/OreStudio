#+title: A restored environment arrives in bootstrap mode with no human admin
#+description: After a database recreate the database came back in bootstrap mode with no human administrator, so a soak run could not log in until the documented bootstrap create-initial-admin step was performed mid-run. A freshly restored environment that nobody can authenticate against is a provisioning gap, and the step is discoverable only if you already know it exists. Seed the initial admin as part of the restore, or have the restore report that it is in bootstrap mode.
