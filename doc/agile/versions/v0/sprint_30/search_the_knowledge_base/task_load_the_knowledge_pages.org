* Goal

Declare on each page whether it is user-facing, with a tag or a keyword, and mark the domain knowledge, the manual and the glossary. Add a table of raw knowledge pages in the system tenant, read by every tenant: org id as the key, the file's path, its org text unchanged, when it was loaded. Write the script that loads every user-facing page into it, replacing the previous load.

* Acceptance

- Every user-facing page carries the declaration, and a gate refuses a page whose declaration is malformed.
- The script loads every user-facing page into the raw table as org, unchanged, keyed by its org id; a second run replaces the first.
- Every tenant can read the raw table and none can write it.
