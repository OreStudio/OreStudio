The happy path configuration of the [[id:0442FD13-1833-427F-B6CA-C4B5877C452B][identity workflow]]. The =ores-shell= block
below is tangled into the runnable script library as =identity_happy_path.ores=.

* Question

How do I run a workflow whose every step succeeds?

* Answer

Both steps report completion, so the instance settles at =completed= and =workflow wait= says every step completed.

#+name: identity-happy-path
#+begin_src ores-shell :exports none
workflow start identity_workflow '{"steps":[{"name":"one"},{"name":"two"}]}' --instance-id 10000000-0000-4000-8000-000000000001
workflow wait 10000000-0000-4000-8000-000000000001 --timeout 60 --expect-state completed
#+end_src

=workflow wait= fails unless the instance reaches the state named, so this
script fails when the path it covers does nothing.
