* Acceptance

- One read states one =as_of=, and the state and the booking in a row come from that instant.
- The identifier search is measured on a large list, and a trigram index is added if the scan is too slow.
- A portfolio scope over more than 1000 books is refused by the client, never truncated.
- The generator supports a read-model entity that has no table of its own. It reads from a set-returning SQL function that takes the =as_of= and applies it to every part it joins.
- The trade summary is such an entity, with generated protocol, repository, service and TypeScript twin.
- It filters by state, book, counterparty, trade type and the enum columns, and searches every identifier.
- A repository test covers each filter, the search and the total.
