* Goal

The ORE codec holds no database session and calls no other component's repository. Its only remaining knowledge of a run is where each file sits inside an ORE input directory.

* Acceptance

- store::import_run and store::export_run are gone, and nothing calls them.
- The package helpers — the run document's name, where each file sits in the archive, and the paths the run document declares — stay and are covered by tests.
- ores.ore.core links no ores.database, ores.analytics.core or ores.reporting.core library, and none of its public headers includes their headers.
- The codec suite passes with the run store's database tests deleted.
