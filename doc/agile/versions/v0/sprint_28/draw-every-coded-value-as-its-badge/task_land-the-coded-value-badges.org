* Goal

Every coded value is drawn as its badge, wherever it is read, and chosen the same way: one renderer and one shared control, so a list and its badge cannot be two renderings of one fact that drift apart. The badge story described the work; this lands it.

* Result

The badge story lands: one renderer for coded values wherever they are read,
one shared control for choosing one, and the tenor kinds and units carrying
badges of their own in every seed that maps them. The tenor journey uses both
and splits choosing a tenor from choosing its convention. =ORES_WEB_DOC_ROOT=
reaches a generated =.env= (format 32), and the services page asks for a class
that exists.

Two review axes ran over the diff and found thirteen things. Eight are fixed
(seven code and doc defects, most of them merge artifacts, plus the system
tenant's borrowed badges). Two are deferred to the story's remaining work: the
other screens that still draw badges by hand, and the two convention domains
with no badges. Two more are recorded: the republish defect that leaves two
current rows, and the missing type for the mapped catalogue. One is declined.
None is left silent.

Web: 141 files and 1583 tests pass, typecheck is clean, prettier is clean, and
the local gate is green once the backlog indexes are regenerated.
