* Notes

- The release defines two adapter modules, and only two: =frankfurter=, the
  official-rates adapter behind =ores.marketdata.official=, and =synthetic=,
  the simulator behind =ores.synthetic.service=. The catalogue holds no module
  the code does not have.
- A module is a class. Its announce carries =adapter_code= and
  =module_version=; the service refuses a module the catalogue does not
  define, and the announce is what marks the module installed on this
  installation. A catalogue row is a definition; the status list is the
  installation claim.
