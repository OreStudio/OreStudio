* Acceptance

- env_packages.py installs no X11, GL or xcb header package.
- No script, SQL file or workflow installs, preloads or grants pg_cron or pgmq.
- shared_preload_libraries is timescaledb only, in the setup script and in CI.
- compass db recreate succeeds and creates the timescaledb extension.
- The full debug build succeeds on a machine without the removed packages.

* Plan

1. Check what still uses each dependency before removing it: =vcpkg.json=
   and every =find_package= for Qt, OpenGL, X11 and GLUT; every call into
   the =cron= and =pgmq= schemas.
2. Remove the X11, GL and xcb headers from =env_packages.py=, and pg_cron
   and pgmq from =setup_postgres_extensions.sh=, the database SQL and CI.
   Keep autotools, =libltdl-dev= and =pkg-config= for the vcpkg ports, and
   timescaledb as the only preloaded library.
3. Remove what pgmq and pg_cron left in the code: the =pgmq_msg_id= field on
   the compute result (a model change, regenerated by entity), the
   =Credentials= query overloads that existed only to reach pg_cron, and the
   comments that still describe either as live. Add a migration for
   databases created before the column drop.
4. Prove it: recreate the database, build in full on a machine without the
   removed packages, run ctest, start the fleet, and bootstrap through
   =ores.web=.

* Result

The setup now installs and configures only what the build and the services
use.

- =env_packages.py= installs no X11, GL or xcb headers; the full install adds
  =nodejs= and =npm=, which =ores.web= needs.
- =setup_postgres_extensions.sh= installs timescaledb only and preloads it
  alone. CI preloads timescaledb alone, and the macOS and Windows workflows
  no longer build pgmq.
- The database SQL no longer grants on the =cron= or =pgmq= schemas or
  includes the empty =setup_extensions_postgres.sql=.
- The compute result no longer carries =pgmq_msg_id=, with a migration for
  existing databases; =ores.database= no longer has the =Credentials= query
  overloads that existed only for pg_cron.
- =ores.web= declares the =goedel= environment.

Every acceptance item is met: the debug build passed on =goedel=, which has
none of the removed packages, and =compass db recreate= creates the
timescaledb extension and 14 hypertables. The component shapes did not
change: the task removed a field, two overloads and comments, and added no
part, facet or dependency.
