* Result

The C1202 is context accumulation, not one over-wide literal. The
=windows-msvc-debug-ninja= job of run =38451315943= has exactly one
failed unit, the handler. The control unit
=tenor_basis_swap_convention_json_io.cpp= reflects the same 24-member
struct from 12 repository headers and built at step =[974/7099]=, while
the handler reaches 103 repository headers, 58 document element types
and failed at =[2017/7099]=.

The per-entity split does not reach the handler because the document
model is an operation model that hand-lists 60+ domain includes and
re-aggregates what the 149 per-entity protocols separate.

The smallest split is two operation models, one per document family.
The findings are on
[[id:1B13CDFF-BDA0-4D2E-8E05-ECB3EC3B9259][Why the configuration
document protocol unit is wide]], and the durable rule is on
[[id:BBD43BF2-9FEE-42B0-A667-9468AF759DC2][Data-Oriented Design in ORE
Studio]]. The lever and its raw output are in =evidence/= beside this
task. =compass check= passed 6/6.
