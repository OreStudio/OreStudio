Every machine on the local network runs this environment's compute nodes beside the environments already there, and each environment's deploy, stop and logs touch only its own state.

* Acceptance

- A second environment deploys to a host without changing the first environment's env file, certs, work tree or units.
- Stopping one environment's compute nodes leaves a co-hosted environment's wrappers running.
- compass image build stages the environment's own preset and leaves out a service that has no binary.
- The grid screen's Refresh reloads its plots, for an operator and for a tenant administrator.
