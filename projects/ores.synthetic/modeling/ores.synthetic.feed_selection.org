#+title: ores.synthetic.feed_selection
#+description: Codegen operation model for starting and stopping the feeds a person picked, or the feeds a filter matches.
#+type: ores.codegen.operation
#+component: synthetic
#+subcomponent: api
#+entity_singular: feed_selection
#+namespace: ores::synthetic::messaging
#+brief: Start or stop a set of feeds named by ids, or by the filter of the feed table.
#+filetags: :model:operation:synthetic:
#+created: 2026-10-13
#+updated: 2026-10-13

The write behind the feed table's Start and Stop. A person picks feeds one by one, or
asks for every feed the table's filter matches, less those left out. The request carries
the filter and the ids, not the feeds: the service finds the feeds, so a set of
thousands costs one small request. The service starts or stops each feed as the folder
verbs do and reports what it did.
