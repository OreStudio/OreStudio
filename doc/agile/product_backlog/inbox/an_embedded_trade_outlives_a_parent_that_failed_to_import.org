#+title: An embedded trade outlives a parent that failed to import
#+description: The ORE import books a total return swap's, a composite's or a contract for difference's embedded trades before the parent and skips the parent when one of them fails, but the embedded trades that did save stay in the book with no parent. The parent and its embedded trades should be written as one unit.

This page is a [[id:671F18E4-E09C-4B3B-BD24-D33DF8AE38A6][capture]] in the *inbox* bucket of the product backlog — a pre-sprint idea, not yet pulled into a sprint as a story.

* What

The ORE import books the trades a total return swap, a composite trade or a
contract for difference embeds before it books the parent, and it does not
book the parent when one of them fails. The embedded trades that did save
stay in the book, joined to nothing. In the TRS roundtrip of 2026-11-04 three
equity positions saved while the cash swap beside them failed, and the swap
itself was refused.

* Why

A parent is its embedded trades as much as its own terms, so half of one in
the book is a trade nobody booked. The parent and its embedded trades should
be written as one unit, so a failure leaves nothing behind.
